## Accessibility infrastructure

The **[complete accessible English Open Logic book](https://kokunoyumeto.github.io/OpenLogic-translations/accessible/en/)** is published here with **80/80 planned source tranches accepted**. It provides Read, Listen / words only, Explore equations with native MathML, and Source and provenance. Download the corrected [EPUB 3.3](https://github.com/KokunoYumeto/OpenLogic-translations/releases/download/accessible-en-20260910/OpenLogic-Accessible-Complete-English-20260910.epub) or [offline HTML ZIP](https://github.com/KokunoYumeto/OpenLogic-translations/releases/download/accessible-en-20260910/OpenLogic-Accessible-Complete-English-HTML-20260910.zip). The [previous Zenodo edition](https://doi.org/10.5281/zenodo.22647454) remains preserved; its successor has not yet been published because the archive service is returning errors.

The 80 accessibility tranches cover the canonical book projection (78 mathematical chapters, About, and part-wrapper material). This count is distinct from the 722-file preservation edition and does not claim a rendered counterpart for every optional upstream file. Automated and silent runtime checks pass; a prerecorded audiobook, complete audible screen-reader evaluation, physical braille-display testing and formal human accessibility certification remain unclaimed. Across editions, semantic responsive HTML, reflowable EPUB, native MathML, image descriptions, offline packaging, and applicable low-bitrate media remain publication baselines.

## Active research editions

- **Paired Dutch registers:** one complete standard scholarly Dutch edition and one complete adult **gewone-mensentaal** Dutch register translation have been commissioned from the same 722-unit source and segment spine. The pair is intended to permit direct within-language comparison: information, mathematics and proof obligations remain identical while academic-register choices change. The ordinary-register edition is not abridged, remedial or child-directed. The dedicated owner task is still completing worktree setup, so zero translated units and no repository, reader, release or DOI are claimed yet; see the [commission record](evidence/DUTCH_DUAL_REGISTER_COMMISSION_20260906.json).
- **Inter-Farsi OpenLogic:** active corpus-wide scaffold/edition work. Its design separates a controlled pluricentric register from Iranian Persian and keeps Perso-Arabic and Tajik Cyrillic realization, regional adaptation, and notation profiles as typed layers. It is not yet listed as a public complete translation.
- **Romance interlanguage:** 722 provisional baseline files are loaded in the local standalone reader. The event-486 admission-record snapshot has **55/722 source-critical units complete**, 667 pending and 424 material decisions. This is ongoing research, not a complete canon-validated edition or a new manager certification of every choice.
- **Latin:** planned as a complete `la-Latn` Neo-Latin edition plus a separate bilingual learner companion for mathematically minded Latin readers. Historical mathematical and logical Latin, modern Latinity guidance, and an explicit neologism ledger will govern the prose; Peano's *Latino sine flexione* is comparative evidence, not the target register. No translated unit or owner is claimed yet.

## What “done” means here

A new complete edition must translate all 722 tracked source files **and** provide one coherent standalone reader containing the complete declared closure. It must bind every segment to the language’s actual scholarly canon, preserve formulas and identifiers, pass script-aware structural and visual QA, publish editable sources and evidence, and verify released bytes anonymously. See [`TRANSLATION_STANDARD.md`](TRANSLATION_STANDARD.md).

The next-language shortlist and its limitations are in [`PRIORITIES.md`](PRIORITIES.md). The frozen v3 order is a historical planning input under which lanes were commissioned; the current allocation study does not establish a live global Top 10. Its actionable production constraints are recorded in the [adjacent-evidence audit](evidence/ADJACENT_COMPUTE_ACTIONABLE_FINDINGS_20260905.json).
