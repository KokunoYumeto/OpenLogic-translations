# Recovered mathematics translations

The fuller laptop copy was supplied to recover a known incomplete GitHub upload. It contains substantial work in nine language lanes. The source books are mainly **OpenStax mathematics**, not nine finished OpenLogic editions. Existing canon, terminology and script-aware infrastructure may help subsequent OpenLogic work after exact-language and subject checks.

No completed whole assigned textbook or programme is established by these counts. This does not imply that the supplied copy is incomplete: it is a recovery copy of projects at their actual production boundaries.

## Recovery and provenance

The [existing review branch](https://github.com/KokunoYumeto/allocating-ai-translation-compute-for-educational-access/tree/codex/additional-translations-review/translations) has all nine locale directories, but it does not yet contain the fuller recovered payload. The laptop copy, not that incomplete upload, establishes the recovered work. This catalogue update publishes inventory metadata, not the missing translation payload or a new textbook release.

The bounded inventory covers 8,758 files and rechecks 4,192 selected artifact hashes. Selected-lane paths and uncompressed sizes agree with the supplied ZIP directory inventories. Four supplemental handoff copies contribute 1,309 selected textual files: 1,194 match the main-lane bytes, 115 are different snapshots, and none adds a new path. These copies were preserved and not double-counted.

The [machine-readable catalogue](catalogue/related-mathematics.json) records actual source IDs, reader-entry locators, canon-use records and limitations. These locators refer to the fuller locale trees and are not promises that every file is already in the incomplete remote snapshot.

Some saved QA receipts reference older builders, figures, reports or translation inputs. Their historical PASS records are not fresh QA certification. Canon-use logs were located, but this inventory does not claim to have reviewed every translated sentence. In particular, the later Indian Bengali m81295 reader needs its changed inputs reconciled. The Bangladesh historical offline ZIPs contain documented private workflow text and must not be re-uploaded unchanged; preserve originals and make explicitly sanitized derivatives.

## OpenLogic coordination

Seven next-language targets already have relevant mathematics work here: Punjabi, Indian Bengali, Marathi, Telugu, Tamil, Javanese and Gujarati. Bangladesh Bengali and Vietnamese add two further lanes. No Pashto lane was present in this dump. Avoid duplicate mathematics producers, but do not count these OpenStax units toward OpenLogic's 722-file translation closure.

Reuse canon only where its language, region, register and mathematical subject actually support the new segment. The programme's [translation standard](TRANSLATION_STANDARD.md) still requires explicit canon consultation, source alignment, formula/citation preservation, script-aware QA and verified public bytes for each declared complete edition.
