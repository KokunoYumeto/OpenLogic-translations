The fuller laptop copy was supplied to recover a known incomplete GitHub upload. It contains substantial work in nine language lanes. The source books are mainly **OpenStax mathematics**, not nine finished OpenLogic editions. Existing canon, terminology and script-aware infrastructure may help subsequent OpenLogic work after exact-language and subject checks.

## Recovery and provenance

The fuller payload is now public on the [existing review branch](https://github.com/KokunoYumeto/allocating-ai-translation-compute-for-educational-access/tree/codex/additional-translations-review/translations). The export recovered 8,744 files, added 7,628 previously absent paths and updated 95 existing paths. It retained one other public file and added/replaced 13 navigation/manifest/QA files. All 8,758 published files, totaling 441,591,922 bytes, matched the anonymous exact-commit archive by path, size and SHA-256. No public file was deleted. Fourteen operational/duplicate/scratch originals remain locally preserved and excluded from the public derivative. Source HTML/PDF/CNXML/SVG bytes were unchanged; explicit sanitization applies to other documented derivatives.

The bounded inventory covers 8,758 files and rechecks 4,192 selected artifact hashes. Selected-lane paths and uncompressed sizes agree with the supplied ZIP directory inventories. Four supplemental handoff copies contribute 1,309 selected textual files: 1,194 match the main-lane bytes, 115 are different snapshots, and none adds a new path. These copies were preserved and not double-counted.

The [machine-readable catalogue](catalogue/related-mathematics.json) records actual source IDs, reader-entry locators, canon-use records, limitations and the public recovery identity. The referenced reader trees are now included in the verified public snapshot. Keep each nested workspace intact when downloading readers and their local figures/styles.

Some saved QA receipts reference older builders, figures, reports or translation inputs. Their historical PASS records are not fresh QA certification. Canon-use logs were located, but this inventory does not claim to have reviewed every translated sentence. In particular, the later Indian Bengali m81295 reader needs its changed inputs reconciled. The Bangladesh historical offline ZIPs contained documented private workflow text; the exported ZIPs are explicitly sanitized derivatives with repaired current manifests, and originals remain preserved.

## OpenLogic coordination

Seven next-language targets already have relevant mathematics work here: Punjabi, Indian Bengali, Marathi, Telugu, Tamil, Javanese and Gujarati. Bangladesh Bengali and Vietnamese add two further candidates outside the frozen Top 10. No Pashto lane was present in this dump. A bounded scan of 1,293 indexed target-source/reader files established no translated OpenLogic section: Punjabi's OpenLogic name hits are Levin manifests describing auxiliary acquisitions. Avoid duplicate mathematics producers, and do not count these textbook units toward OpenLogic's 722-file translation closure.

The recovered work is routed to existing Indonesian production owners **by book**, so each can finish a coherent bounded multilingual package using the source/canon/QA methodology already established for that work. The local-needs rationale remains part of provenance: diagnostic/remediation routes, worked answers, prerequisite bridges, register variants and nonvisual reading support are not interchangeable, and must remain distinct from faithful source translation. See the [OpenLogic candidate pipeline](catalogue/candidate-editions.json) for the separate logic-edition plans.

Reuse canon only where its language, region, register and mathematical subject actually support the new segment. The programme's [translation standard](TRANSLATION_STANDARD.md) still requires explicit canon consultation, source alignment, formula/citation preservation, script-aware QA and verified public bytes for each declared complete edition.
