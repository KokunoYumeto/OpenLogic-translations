THE OPEN LOGIC TEXT — COMPLETE ACCESSIBLE ENGLISH EDITION

Start here: open index.html in a modern browser. No network connection is needed for the book.

Read keeps native MathML. Listen / words only supplies continuous, context-reviewed speech text and a one-button player that uses an installed browser/Windows voice after you press Play. Explore equations explains formulas and formal structures. Source and provenance exposes line-addressable, byte-exact source material.

The synchronized EPUB 3.3 is distributed beside this HTML ZIP. Use an EPUB 3 reading app with MathML support. Reading-system support varies.

Limitations: no prerecorded audio is included. Automated and silent headless tests passed, but audible operating-system Read Aloud, complete real screen-reader navigation, physical refreshable braille, voice-control, and dedicated magnifier testing remain unperformed. Automated results are not human accessibility certification.
