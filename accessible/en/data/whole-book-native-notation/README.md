# Whole-book native-notation repair overlay

This sparse overlay repairs the remaining source-defined `Lang`, `Setabs`, and optional `Sat` assignment structures found by an exhaustive scan of all 79 Read/Explore route pairs. It changes only affected MathML roots and adds evidence/index files. Read prose, Listen, Source, speech, IDs, and the frozen Open Logic tree are unchanged.

The overlay is not a standalone reader and does not claim independent acceptance or real assistive-technology certification.
