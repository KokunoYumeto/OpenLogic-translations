  13. \olsection{Rules and \usetoken{P}{derivation}}
  15. \begin{explain}
  16. Axiomatic !!{derivation}s are perhaps the simplest !!{derivation} system for
  17. logic. !!^a{derivation} is just a sequence of !!{formula}s. To
  18. count as !!a{derivation}, every !!{formula} in the sequence must
  19. either be an instance of an axiom, or must follow from one or more
  20. !!{formula}s that precede it in the sequence by a rule of inference.
  21. !!^a{derivation} !!{derive}s its last !!{formula}.
  22. \end{explain}
  24. \begin{defn}[!!^{derivability}]
  25. If $\Gamma$ is a set of !!{formula}s of $\Lang L$ then a
  26. \emph{!!{derivation}} from~$\Gamma$ is a finite sequence $!A_1$,
  27. \dots,~$!A_n$ of !!{formula}s where for each $i \le n$ one of the
  28. following holds:
  29. \begin{enumerate}
  30. \item $!A_i \in \Gamma$; or
  31. \item $!A_i$ is an axiom; or
  32. \item $!A_i$ follows from some $!A_j$ (and $!A_k$) with $j < i$ (and
  33. $k < i$) by a rule of inference.
  34. \end{enumerate}
  35. \end{defn}
  37. What counts as a correct !!{derivation} depends on which inference
  38. rules we allow (and of course what we take to be axioms). And an
  39. inference rule is an if-then statement that tells us that, under
  40. certain conditions, a step~$A_i$ in !!a{derivation} is a correct
  41. inference step.
  43. \begin{defn}[Rule of inference]
  44. A \emph{rule of inference} gives a sufficient condition for what
  45. counts as a correct inference step in !!a{derivation} from~$\Gamma$.
  46. \end{defn}
  48. For instance, since any one-element sequence $!A$ with $!A \in \Gamma$
  49. trivially counts as !!a{derivation}, the following might be a very
  50. simple rule of inference:
  51. \begin{quote}
  52. If $!A \in \Gamma$, then $!A$ is always a correct inference step in
  53. any !!{derivation} from~$\Gamma$.
  54. \end{quote}
  55. Similarly, if $!A$ is one of the axioms, then $!A$ by itself is
  56. !!a{derivation}, and so this is also a rule of inference:
  57. \begin{quote}
  58. If $!A$ is an axiom, then $!A$ is a correct inference step.
  59. \end{quote}
  60. It gets more interesting if the rule of inference appeals to
  61. !!{formula}s that appear before the step considered. The following
  62. rule is called \emph{modus ponens:}
  63. \begin{quote}
  64. If $!B \lif !A$ and $!B$ occur higher up in the !!{derivation},
  65. then~$!A$ is a correct inference step.
  66. \end{quote}
  67. If this is the only rule of inference, then our definition of
  68. !!{derivation} above amounts to this: $!A_1$, \dots,~$!A_n$ is
  69. !!a{derivation} iff for each $i \le n$ one of the following holds:
  70. \begin{enumerate}
  71. \item $!A_i \in \Gamma$; or
  72. \item $!A_i$ is an axiom; or
  73. \item for some $j < i$, $!A_j$ is $!B \lif !A_i$, and for some $k < i$,
  74. $!A_k$ is~$!B$.
  75. \end{enumerate}
  76. The last clause says that $!A_i$ follows from~$!A_j$ ($!B \lif !A_i$) and $!A_k$
  77. ($!B$) by modus ponens. If we can go from $1$ to~$n$, and
  78. each time we find !!a{formula}~$!A_i$ that is either in~$\Gamma$, an
  79. axiom, or which a rule of inference tells us that it is a correct
  80. inference step, then the entire sequence counts as a correct
  81. !!{derivation}.
  83. \begin{defn}[!!^{derivability}]
  84. A !!{formula}~$!A$ is \emph{!!{derivable}} from $\Gamma$, written
  85. $\Gamma \Proves !A$, if there is !!a{derivation} from $\Gamma$ ending
  86. in $!A$.
  87. \end{defn}
  89. \begin{defn}[Theorems]
  90. !!^a{formula}~$!A$ is a \emph{theorem} if there is !!a{derivation}
  91. of~$!A$ from the empty set. We write $\Proves !A$ if $!A$ is a
  92. theorem and $\Proves/ !A$ if it is not.
  93. \end{defn}
