Introduction

Explanation

The development of the axiomatic method is a significant achievement in the history of science, and is of special importance in the history of mathematics. An axiomatic development of a field involves the clarification of many questions: What is the field about? What are the most fundamental concepts? How are they related? Can all the concepts of the field be defined in terms of these fundamental concepts? What laws do, and must, these concepts obey?

The axiomatic method and logic were made for each other. Formal logic provides the tools for formulating axiomatic theories, for proving theorems from the axioms of the theory in a precisely specified way, for studying the properties of all systems satisfying the axioms in a systematic way.

Definition of a closed theory and its closure

A set of sentences Gamma is closed if and only if, whenever Gamma semantically entails A then A belongs to Gamma. The closure of a set of sentences Gamma is the set of all A such that Gamma semantically entails A.

We say that Gamma is axiomatized by a set of sentences Delta if Gamma is the closure of Delta.

Explanation

We can think of an axiomatic theory as the set of sentences that is axiomatized by its set of axioms Delta. In other words, when we have a first-order language which contains non-logical symbols for the primitives of the axiomatically developed science we wish to study, together with a set of sentences that express the fundamental laws of the science, we can think of the theory as represented by all the sentences in this language that are entailed by the axioms. This ranges from simple examples with only a single primitive and simple axioms, such as the theory of partial orders, to complex theories such as Newtonian mechanics.

The important logical facts that make this formal approach to the axiomatic method so important are the following. Suppose Gamma is an axiom system for a theory, that is, a set of sentences.

  1. We can state precisely when an axiom system captures an intended class of structures. That is, if we are interested in a certain class of structures, we will successfully capture that class by an axiom system Gamma if and only if the structures are exactly those structure M such that structure M satisfies Gamma.

  2. We may fail in this respect because there are structure M such that structure M satisfies Gamma, but structure M is not one of the structures we intend. This may lead us to add axioms which are not true in structure M.

  3. If we are successful at least in the respect that Gamma is true in all the intended structures, then a sentence A is true in all intended structures whenever Gamma semantically entails A. Thus we can use logical tools (such as derivation methods) to show that sentences are true in all intended structures simply by showing that they are entailed by the axioms.

  4. Sometimes we don't have intended structures in mind, but instead start from the axioms themselves: we begin with some primitives that we want to satisfy certain laws which we codify in an axiom system. One thing that we would like to verify right away is that the axioms do not contradict each other: if they do, there can be no concepts that obey these laws, and we have tried to set up an incoherent theory. We can verify that this doesn't happen by finding a model of Gamma. And if there are models of our theory, we can use logical methods to investigate them, and we can also use logical methods to construct models.

  5. The independence of the axioms is likewise an important question. It may happen that one of the axioms is actually a consequence of the others, and so is redundant. We can prove that an axiom A in Gamma is redundant by proving Gamma without A semantically entails A. We can also prove that an axiom is not redundant by showing that Gamma without A together with not A is satisfiable. For instance, this is how it was shown that the parallel postulate is independent of the other axioms of geometry.

  6. Another important question is that of definability of concepts in a theory: The choice of the language determines what the models of a theory consist of. But not every aspect of a theory must be represented separately in its models. For instance, every ordering less than or equal to determines a corresponding strict ordering less than—given one, we can define the other. So it is not necessary that a model of a theory involving such an order must also contain the corresponding strict ordering. When is it the case, in general, that one relation can be defined in terms of others? When is it impossible to define a relation in terms of others (and hence must add it to the primitives of the language)?

Expressing Properties of Structures

Explanation

It is often useful and important to express conditions on functions and relations, or more generally, that the functions and relations in a structure satisfy these conditions. For instance, we would like to have ways of distinguishing those structures for a language which “capture” what we want the predicates to “mean” from those that do not. Of course we're completely free to specify which structures we “intend,” for example, we can specify that the interpretation of the predicate less than or equal to must be an ordering, or that we are only interested in interpretations of language L in which the domain consists of sets and object language membership predicate is interpreted by the “is a element of” relation. But can we do this with sentences of the language? In other words, which conditions on a structure M can we express by a sentence (or perhaps a set of sentences) in the language of structure M? There are some conditions that we will not be able to express. For instance, there is no sentence of the language of arithmetic which is only true in a structure M if the domain of structure M equals the natural numbers. We cannot express “the domain contains only natural numbers.” But there are “structural properties” of structures that we perhaps can express. Which properties of structures can we express by sentences? Or, to put it another way, which collections of structures can we describe as those making a sentence (or set of sentences) true?

Definition of a model of a sentence set

Source title: Model of a set.

Let Gamma be a set of sentences in a language L. We say that a structure M is a model of Gamma if structure M satisfies A for all A in Gamma.

Example axiomatizing partial orders

The sentence for every x, x is less than or equal to itself is true in structure M if and only if the interpretation of less than or equal to in structure M is a reflexive relation. The sentence for every x and y, if x is less than or equal to y and y is less than or equal to x, then x equals y is true in structure M if and only if the interpretation of less than or equal to in structure M is anti-symmetric. The sentence for all x y and z, if x is less than or equal to y and y is less than or equal to z, then x is less than or equal to z is true in structure M if and only if the interpretation of less than or equal to in structure M is transitive. Thus, the models of Displayed partial-order axioms the three axioms of reflexivity antisymmetry and transitivity for less than or equal to are exactly those structures in which the interpretation of less than or equal to in structure M is reflexive, anti-symmetric, and transitive, that is, a partial order. Hence, we can take them as axioms for the first-order theory of partial orders.

The theory of Peano arithmetic is axiomatized by the following sentences in the language of arithmetic denoted L sub A. Example candidate theory of pure sets

The theory of pure sets plays an important role in the foundations (and in the philosophy) of mathematics. A set is pure if all its elements are also pure sets. The empty set counts therefore as pure, but a set that has something as a element that is not a set would not be pure. So the pure sets are those that are formed just from the empty set and no “urelements,” that is, objects that are not themselves sets.

The first axiom says that there is a set with no elements (that is, the empty set exists); the second says that sets are extensional; the third that for any sets X and Y, the set containing X and Y exists; the fourth that for any set X, the set denoted by union X exists, where the union of X is the union of all the elements of set X.

The sentences mentioned last are collectively called the naive comprehension scheme. It essentially says that for every formula A of x, the set of all x for which A of x holds exists—so at first glance a true, useful, and perhaps even necessary axiom. It is called “naive” because, as it turns out, it makes this theory unsatisfiable: if you take formula A of y to be y is not an element of itself, you get the sentence there exists a set x containing exactly the y that are not elements of themselves and this sentence is not satisfied in any structure.

Example theory of mereological parthood

In the area of mereology, the relation of parthood is a fundamental relation. Just like theories of sets, there are theories of parthood that axiomatize various conceptions (sometimes conflicting) of this relation.

The language of mereology contains a single two-place predicate symbol object language P, and predicate P applied to x and y “means” that x is a part of y. When we have this interpretation in mind, a structure for this language is called a parthood structure. Of course, not every structure for a single two-place predicate will really deserve this name. To have a chance of capturing “parthood,” the interpretation of predicate P in structure M must satisfy some conditions, which we can lay down as axioms for a theory of parthood. For instance, parthood is a partial order on objects: every object is a part (albeit an improper part) of itself; no two different objects can be parts of each other; a part of a part of an object is itself part of that object. Note that in this sense “is a part of” resembles “is a subset of,” but does not resemble “is an element of” which is neither reflexive nor transitive. Displayed mereology axioms parthood is reflexive antisymmetric and transitive, and every two objects have a least common whole These are only some of the basic principles of parthood considered by metaphysicians. Further principles, however, quickly become hard to formulate or write down without first introducing some defined relations. For instance, most metaphysicians interested in mereology also view the following as a valid principle: whenever an object x has a proper part y, it also has a part z that has no parts in common with y, and so that the fusion of y and z is x.

Expressing Relations in a Structure

Explanation

One main use formulas can be put to is to express properties and relations in a structure M in terms of the primitives of the language L of structure M. By this we mean the following: the domain of structure M is a set of objects. The constants, functions, and predicates are interpreted in structure M by some objects in the domain of structure M, functions on the domain of structure M, and relations on the domain of structure M. For instance, if object language predicate A superscript two sub zero is in language L, then structure M assigns to it a relation R equals the interpretation of predicate A superscript two sub zero in structure M. Then the formula A superscript two sub zero applied to object language v sub one and object language v sub two expresses that very relation, in the following sense: if a variable assignment s maps object language variable v sub one to a in the domain of structure M and object language variable v sub two to b in the domain of structure M, then R holds of a and b if and only if structure M under assignment s satisfies predicate A superscript two sub zero of v sub one and v sub two Note that we have to involve variable assignments here: we can't just say “R holds of a and b if and only if the deliberately invalid notation structure M satisfies predicate A superscript two sub zero applied to domain elements a and b” because a and b are not symbols of our language: they are elements of the domain of structure M.

Since we don't just have atomic formulas, but can combine them using the logical connectives and the quantifiers, more complex formulas can define other relations which aren't directly built into structure M. We're interested in how to do that, and specifically, which relations we can define in a structure.

Definition of a formula expressing a relation

Let formula A with free variables v sub one through v sub n be a formula of language L in which only object language variable v sub one, and so on, object language variable v sub n occur free, and let structure M be a structure for language L. formula A with free variables v sub one through v sub n expresses the relation R contained in the n fold Cartesian power of the domain of M if and only if R holds of a sub one through a sub n if and only if structure M under assignment s satisfies A of v sub one through v sub n for any variable assignment s with s mapping object language v sub i to a sub i (i ranges from one through n).

Explanation

This idea is not just interesting in specific structures, but generally whenever we use a language to describe an intended model or models, that is, when we consider theories. These theories often only contain a few predicates as basic symbols, but in the domain they are used to describe often many other relations play an important role. If these other relations can be systematically expressed by the relations that interpret the basic predicates of the language, we say we can define them in the language.

The Theory of Sets

Almost all of mathematics can be developed in the theory of sets. Developing mathematics in this theory involves a number of things. First, it requires a set of axioms for the relation membership. A number of different axiom systems have been developed, sometimes with conflicting properties of membership. The axiom system known as Z F C, Zermelo–Fraenkel set theory with the axiom of choice stands out: it is by far the most widely used and studied, because it turns out that its axioms suffice to prove almost all the things mathematicians expect to be able to prove. But before that can be established, it first is necessary to make clear how we can even express all the things mathematicians would like to express. For starters, the language contains no constants or functions, so it seems at first glance unclear that we can talk about particular sets (such as the empty set or the natural numbers), can talk about operations on sets (such as the union of X and Y and the power set of X), let alone other constructions which involve things other than sets, such as relations and functions.

To begin with, “is an element of” is not the only relation we are interested in: “is a subset of” seems almost as important. But we can define “is a subset of” in terms of “is an element of.” To do this, we have to find a formula A with free variables x and y in the language of set theory which is satisfied by a pair of sets X comma Y, in that order if and only if X is a subset of Y. But set X is a subset of set Y just in case all elements of set X are also elements of set Y. So we can define the subset relation by the formula for every z, if z is an element of x then z is an element of y Now, whenever we want to use the relation called subset inclusion in a formula, we could instead use that formula (with x and y suitably replaced, and the bound variable z renamed if necessary). For instance, extensionality of sets means that if any sets x and y are contained in each other, then x and y must be the same set. This can be expressed by for every x and y, if x is a subset of y and y is a subset of x, then x equals y, or, if we replace the subset relation by the above definition, by for every x and y, if every element of x is in y and every element of y is in x, then x equals y This is in fact one of the axioms of Z F C, the “axiom of extensionality.”

There is no constant for the empty set, but we can express “x is empty” by there is no y that is an element of x. Then “the empty set exists” becomes the sentence there exists an x with no elements. This is another axiom of Z F C. (Note that the axiom of extensionality implies that there is only one empty set.) Whenever we want to talk about the empty set in the language of set theory, we would write this as “there is a set that's empty and so on” As an example, to express the fact that the empty set is a subset of every set, we could write there exists an empty x that is a subset of every z where, of course, x is a subset of z would in turn have to be replaced by its definition.

To talk about operations on sets, such as the union of X and Y and the power set of X, we have to use a similar trick. There are no function symbols in the language of set theory, but we can express the functional relations the union of X and Y equals Z and the power set of X equals Y by Displayed definitions of union and power set u belongs to z exactly when it belongs to x or y, and u belongs to y exactly when it is a subset of x since the elements of the union of X and Y are exactly the sets that are either elements of set X or elements of set Y, and the elements of the power set of X are exactly the subsets of set X. However, this doesn't allow us to use the union of x and y or the power set of x as if they were terms: we can only use the entire formulas that define the relations the union of X and Y equals Z and the power set of X equals Y. In fact, we do not know that these relations are ever satisfied, that is, we do not know that unions and power sets always exist. For instance, the sentence for every x there exists a y equal to the power set of x is another axiom of Z F C (the power set axiom).

Now what about talk of ordered pairs or functions? Here we have to explain how we can think of ordered pairs and functions as special kinds of sets. One way to define the ordered pair x comma y is as the set containing the singleton of x and the pair set of x and y. But like before, we cannot introduce a function that names this set; we can only define the relation the ordered pair x comma y equals z, that is, the set containing the singleton of x and the pair set of x and y equals z: for every u, u belongs to z if and only if u is the singleton of x or the pair set of x and y This says that the elements u of z are exactly those sets which either have x as its only element or have x and y as its only elements (in other words, those sets that are either identical to the singleton containing x or identical to the set containing x and y). Once we have this, we can say further things, for example, that the Cartesian product of X and Y equals Z: for every z, z belongs to Z exactly when it is an ordered pair of an x in X and a y in Y

A function f from X to Y can be thought of as the relation f of x equals y, that is, as the set of pairs x comma y for which f of x equals y. One might think that set theory requires another axiom that guarantees the existence of a set for every defining property. If formula A of x is a formula of set theory with the variable x free, we can consider the sentence there exists a set y containing exactly the x for which A of x holds This sentence states that there is a set y whose elements are all and only those x that satisfy formula A of x. This schema is called the “comprehension principle.” It looks very useful; unfortunately it is inconsistent. Take formula A of x is defined as x is not an element of itself, then the comprehension principle states there exists a set y containing exactly the x that are not elements of themselves that is, it states the existence of a set of all sets that are not elements of themselves. No such set can exist—this is Russell's Paradox. Z F C, in fact, contains a restricted—and consistent—version of this principle, the separation principle: for every z there exists a y containing exactly those x in z for which A of x holds

Expressing the Size of Structures

Explanation

There are some properties of structures we can express even without using the non-logical symbols of a language. For instance, there are sentences which are true in a structure if and only if the domain of the structure has at least, at most, or exactly a certain number n of elements.

Proposition expressing at least and at most n elements

The sentence Displayed sentence for at least n elements A sub at least n says that there exist n pairwise distinct objects is true in a structure M if and only if the domain of structure M contains at least n elements. Consequently, structure M satisfies the negation of A sub at least n plus one if and only if the domain of structure M contains at most n elements.

Proposition expressing exactly n elements

The sentence Displayed sentence for exactly n elements A sub exactly n says that there exist n pairwise distinct objects and every object equals one of them is true in a structure M if and only if the domain of structure M contains exactly n elements.

Proposition characterizing infinite structures

A structure is infinite if and only if it is a model of the set containing A sub at least one, A sub at least two, A sub at least three, and every continuation of that pattern

There is no single purely logical sentence which is true in structure M if and only if the domain of structure M is infinite. However, one can give sentences with non-logical predicates which only have infinite models (although not every infinite structure is a model of them). The property of being a finite structure, and the property of being a nonenumerable structure cannot even be expressed with an infinite set of sentences. These facts follow from the compactness and Löwenheim–Skolem theorems.
