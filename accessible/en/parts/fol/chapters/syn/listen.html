Introduction

In order to develop the theory and metatheory of first-order logic, we must first define the syntax and semantics of its expressions. The expressions of first-order logic are terms and formulas. Terms are formed from variables, constants, and functions. Formulas, in turn, are formed from predicates together with terms (these form the smallest, “atomic” formulas), and then from atomic formulas we can form more complex ones using logical connectives and quantifiers. There are many different ways to set down the formation rules; we give just one possible one. Other systems will chose different symbols, will select different sets of connectives as primitive, will use parentheses differently (or even not at all, as in the case of so-called Polish notation). What all approaches have in common, though, is that the formation rules define the set of terms and formulas inductively. If done properly, every expression can result essentially in only one way according to the formation rules. The inductive definition resulting in expressions that are uniquely readable means we can give meanings to these expressions using the same method—inductive definition.

First-Order Languages

Expressions of first-order logic are built up from a basic vocabulary containing variables, constants, predicates and sometimes functions. From them, together with logical connectives, quantifiers, and punctuation symbols such as parentheses and commas, terms and formulas are formed.

Explanation

Informally, predicates are names for properties and relations, constants are names for individual objects, and functions are names for mappings. These, except for the identity equals sign, are the non-logical symbols and together make up a language. Any first-order language L is determined by its non-logical symbols. In the most general case, L contains infinitely many symbols of each kind.

In the general case, we make use of the following symbols in first-order logic:

  1. Logical symbols

    1. Logical connectives: not sign (negation), and sign (conjunction), or sign (disjunction), if then sign (conditional)

      for every sign (universal quantifier), there exists sign (existential quantifier). The propositional constant for falsity falsum sign.

    2. The two-place identity equals sign.

    3. A denumerables set of variables: v sub zero, v sub one, v sub two, and so on

  2. Non-logical symbols, making up the standard language of first-order logic

    1. A denumerables set of n-place predicates for each n is greater than zero: A superscript n sub zero, A superscript n sub one, A superscript n sub two, and so on

    2. A denumerables set of constants: c sub zero, c sub one, c sub two, and so on.

    3. A denumerables set of n-place functions for each n is greater than zero: f superscript n sub zero, f superscript n sub one, f superscript n sub two, and so on

  3. Punctuation marks: opening parenthesis, closing parenthesis, and the comma.

Most of our definitions and results will be formulated for the full standard language of first-order logic. However, depending on the application, we may also restrict the language to only a few predicates, constants, and functions.

Arithmetic language example

The language L sub A of arithmetic contains a single two-place predicate less than sign, a single constant zero, one one-place function successor prime, and two two-place functions plus sign and multiplication sign.

Set-theory language example

The language of set theory L sub Z contains only the single two-place predicate membership sign.

Order language example

The language of orders L sub less than or equal to contains only the two-place predicate less than or equal to sign.

Again, these are conventions: officially, these are just aliases, e.g., less than sign, membership sign, and less than or equal to sign are aliases for A superscript two sub zero, zero for c sub zero, successor prime for f superscript one sub zero, plus sign for f superscript two sub zero, multiplication sign for f superscript two sub one.

In addition to the primitive connectives and quantifiers introduced above, we also use the following defined symbols:

if and only if sign (biconditional)

Truth top sign.

Explanation

A defined symbol is not officially part of the language, but is introduced as an informal abbreviation: it allows us to abbreviate formulas which would, if we only used primitive symbols, get quite long. This is obviously an advantage. The bigger advantage, however, is that proofs become shorter. If a symbol is primitive, it has to be treated separately in proofs. The more primitive symbols, therefore, the longer our proofs.

Introduction

You may be familiar with different terminology and symbols than the ones we use above. Logic texts (and teachers) commonly use tilde negation symbol, not sign, or exclamation mark for “negation”, wedge conjunction symbol, centered dot conjunction symbol, or ampersand conjunction symbol for “conjunction”. Commonly used symbols for the “conditional” or “implication” are right arrow conditional symbol, double right arrow conditional symbol, and horseshoe conditional symbol. Symbols for “biconditional,” “bi-implication,” or “(material) equivalence” are left right arrow biconditional symbol, double arrow biconditional symbol, and triple bar equivalence symbol. The falsum sign symbol is variously called “falsity,” “falsum,”, “absurdity,” or “bottom.” The truth sign symbol is variously called “truth,” “verum,” or “top.”

It is conventional to use lower case letters (e.g., a, b, c) from the beginning of the Latin alphabet for constants (sometimes called names), and lower case letters from the end (e.g., x, y, z) for variables. Quantifiers combine with variables, e.g., x; notational variations include for every x, parenthesized universal quantifier for x, parenthesized x quantifier, capital pi quantifier for x, large conjunction indexed by x for the universal quantifier and there exists x, parenthesized existential quantifier for x, parenthesized E x existential quantifier, capital sigma quantifier for x, large disjunction indexed by x for the existential quantifier.

Explanation

We might instead choose a smaller stock of primitive symbols and treat the other operators as defined. “Truth functionally complete” sets of Boolean operators include the set containing negation and disjunction, the set containing negation and conjunction, and the set containing negation and the conditional—these can be combined with either quantifier for an expressively complete first-order language.

You may be familiar with two other operators: the Sheffer stroke vertical bar (named after Henry Sheffer), and Peirce's arrow pointing down, also known as Quine's dagger. Terms and formula

Once a first-order language L is given, we can define expressions built up from the basic vocabulary of L. These include in particular terms and formulas.

Inductive definition of first-order terms

The set of terms denoted T R M of L is defined inductively by:

  1. Every variable is a term.

  2. Every constant of L is a term.

  3. If f is an n-place function and t sub one, and so on, t sub n are terms, then function f of terms t sub one through t sub n is a term.

    Nothing else is a term.

A term containing no variables is a closed term.

Explanation

The constants appear in our specification of the language and the terms as a separate category of symbols, but they could instead have been included as zero-place functions. We could then do without the second clause in the definition of terms. We just have to understand function f of terms t sub one through t sub n as just f by itself if n equals zero.

Inductive definition of first-order formulas

The set of formulas denoted F R M of the language L is defined inductively as follows:

falsum sign is an atomic formula.

  1. If R is an n-place predicate of L and t sub one, and so on, t sub n are terms of L, then predicate R of terms t sub one through t sub n is an atomic formula.

  2. If t sub one and t sub two are terms of L, then the identity formula between t sub one and t sub two is an atomic formula.

    If A is a formula, then not A is a formula.

    If A and B are formulas, then open parenthesis A and B close parenthesis is a formula.

    If A and B are formulas, then open parenthesis A or B close parenthesis is a formula.

    If A and B are formulas, then open parenthesis if A then B close parenthesis is a formula.

    If A is a formula and x is a variable, then for every x, A is a formula.

    If A is a formula and x is a variable, then there exists x such that A is a formula.

    Nothing else is a formula.

Explanation

The definitions of the set of terms and that of formulas are inductive definitions. Essentially, we construct the set of formulas in infinitely many stages. In the initial stage, we pronounce all atomic formulas to be formulas; this corresponds to the first few cases of the definition, i.e., the cases for

falsum sign, predicate R of terms t sub one through t sub n and t sub one is identical to t sub two. “Atomic formula” thus means any formula of this form.

The other cases of the definition give rules for constructing new formulas out of formulas already constructed. At the second stage, we can use them to construct formulas out of atomic formulas. At the third stage, we construct new formulas from the atomic formulas and those obtained in the second stage, and so on. A formula is anything that is eventually constructed at such a stage, and nothing else.

By convention, we write equals sign between its arguments and leave out the parentheses: the infix identity formula between t sub one and t sub two is an abbreviation for t sub one is identical to t sub two. Moreover, not, t sub one is identical to t sub two is abbreviated as t sub one is not identical to t sub two. When writing a formula open parenthesis B binary connective star C close parenthesis constructed from B, C using a two-place connective binary connective star, we will often leave out the outermost pair of parentheses and write simply B binary connective star C.

Definitions of derived logical operators

Formulas constructed using the defined operators are to be understood as follows:

If we work in a language for a specific application, we will often write two-place predicates and functions between the respective terms, e.g., t sub one is less than t sub two and open parenthesis t sub one plus t sub two close parenthesis in the language of arithmetic and t sub one is an element of t sub two in the language of set theory. The successor function in the language of arithmetic is even written conventionally after its argument: term t prime. Officially, however, these are just conventional abbreviations for predicate A superscript two sub zero of t sub one and t sub two, function f superscript two sub zero of t sub one and t sub two, predicate A superscript two sub zero of t sub one and t sub two and function f superscript one sub zero of t, respectively.

Definition of syntactic identity

The symbol triple bar expresses syntactic identity between strings of symbols, i.e., A is syntactically identical to B if and only if A and B are strings of symbols of the same length and which contain the same symbol in each place.

The triple bar symbol may be flanked by strings obtained by concatenation, e.g., A is syntactically identical to open parenthesis B or C close parenthesis means: the string of symbols A is the same string as the one obtained by concatenating an opening parenthesis, the string B, the or sign symbol, the string C, and a closing parenthesis, in this order. If this is the case, then we know that the first symbol of A is an opening parenthesis, A contains B as a substring (starting at the second symbol), that substring is followed by or sign, etc.

As terms and formulas are built up from basic elements via inductive definitions, we can use the following induction principles to prove things about them.

Principle of induction on terms

Let L be a first-order language. If some property P is such that

  1. it holds for every variable v,

  2. it holds for every constant a of L, and

  3. it holds for function f of terms t sub one through t sub n whenever it holds for t sub one, and so on, t sub n and f is an n-place function of L

(assuming t sub one, and so on, t sub n are terms of L), then P holds for every term in term set of L.

Let L be a first-order language. If some property P holds for all the atomic formulas and is such that

it holds for not A whenever it holds for A; it holds for open parenthesis A and B close parenthesis whenever it holds for A and B; it holds for open parenthesis A or B close parenthesis whenever it holds for A and B; it holds for open parenthesis if A then B close parenthesis whenever it holds for A and B;

(assuming A and B are formulas of L), then P holds for all formulas in formula set of L.

Unique Readability

Explanation

The way we defined formulas guarantees that every formula has a unique reading, i.e., there is essentially only one way of constructing it according to our formation rules for formulas and only one way of “interpreting” it. If this were not so, we would have ambiguous formulas, i.e., formulas that have more than one reading or intepretation—and that is clearly something we want to avoid. But more importantly, without this property, most of the definitions and proofs we are going to give will not go through.

Perhaps the best way to make this clear is to see what would happen if we had given bad rules for forming formulas that would not guarantee unique readability. For instance, we could have forgotten the parentheses in the formation rules for connectives, e.g., we might have allowed this:

If A and B are formulas, then so is the conditional from A to B.

Starting from an atomic formula D, this would allow us to form if D then D. From this, together with D, we would get if D then D, then D. But there are two ways to do this:

  1. We take D to be A and if D then D to be B.

  2. We take A to be if D then D and B is D.

Correspondingly, there are two ways to “read” the formula if D then D, then D. It is of the form if B then C where B is D and C is if D then D, but it is also of the form if B then C with B being if D then D and C being D.

If this happens, our definitions will not always work. For instance, when we define the main operator of a formula, we say: in a formula of the form if B then C, the main operator is the indicated occurrence of if then sign. But if we can match the formula if D then D, then D with if B then C in the two different ways mentioned above, then in one case we get the first occurrence of if then sign as the main operator, and in the second case the second occurrence. But we intend the main operator to be a function of the formula, i.e., every formula must have exactly one main operator occurrence.

The number of left and right parentheses in a formula A are equal.

Unique readability proposition

Every formula satisfies one, and only one of the following conditions.

  1. A is atomic.

    A is of the form not B.

    A is of the form open parenthesis B and C close parenthesis.

    A is of the form open parenthesis B or C close parenthesis.

    A is of the form open parenthesis if B then C close parenthesis.

    A is of the form for every x, B.

    A is of the form there exists x such that B.

Moreover, in each case B, or B and C, are uniquely determined. This means that, e.g., there are no different pairs B, C and B prime, C prime so that A is both of the form open parenthesis if B then C close parenthesis and open parenthesis if B prime then C prime close parenthesis.

Proof

The formation rules require that if a formula is not atomic, it must start with an opening parenthesis, not sign, or a quantifier. On the other hand, every formula that starts with one of the following symbols must be atomic: a predicate, a function, a constant, falsum sign.

So we really only have to show that if A is of the form open parenthesis B binary connective star C close parenthesis and also of the form open parenthesis B prime, binary connective star prime, C prime, close parenthesis, then B is syntactically identical to B prime, C is syntactically identical to C prime, and binary connective star equals binary connective star prime.

So suppose both A is syntactically identical to open parenthesis B binary connective star C close parenthesis and A is syntactically identical to open parenthesis B prime, binary connective star prime, C prime, close parenthesis. Then either B is syntactically identical to B prime or not. If it is, clearly binary connective star equals binary connective star prime and C is syntactically identical to C prime, since they then are substrings of A that begin in the same place and are of the same length. The other case is B is not syntactically identical to B prime. Since B and B prime are both substrings of A that begin at the same place, one must be a proper prefix of the other. But this is impossible by No-formula-prefix lemma.

End of proof.

main operator of a Formula

Explanation

It is often useful to talk about the last operator used in constructing a formula A. This operator is called the main operator of A. Intuitively, it is the “outermost” operator of A. For example, the main operator of not A is not sign, the main operator of open parenthesis A or B close parenthesis is or sign, etc.

Definition of a formula's main operator

The main operator of a formula A is defined as follows:

  1. Case: the current formula has no main operator.

    Case: the main operator of the current formula is not sign.

    Case: the main operator of the current formula is and sign.

    Case: the main operator of the current formula is or sign.

    Case: the main operator of the current formula is if then sign.

    Case: the main operator of the current formula is for every sign.

    Case: the main operator of the current formula is there exists sign.

In each case, we intend the specific indicated occurrence of the main operator in the formula. For instance, since the formula open parenthesis, if: if D then E; then: if E then D; close parenthesis is of the form open parenthesis if B then C close parenthesis where B is open parenthesis if D then E close parenthesis and C is open parenthesis if E then D close parenthesis, the second occurrence of if then sign is the main operator.

Explanation

This is a recursive definition of a function which maps all non-atomic formulas to their main operator occurrence. Because of the way formulas are defined inductively, every formula A satisfies one of the cases in Definition of a formula's main operator. This guarantees that for each non-atomic formula A a main operator exists. Because each formula satisfies only one of these conditions, and because the smaller formulas from which A is constructed are uniquely determined in each case, the main operator occurrence of A is unique, and so we have defined a function.

We call formulas by the names in Table of main operators and formula types depending on which symbol their main operator is. Recall, however, that defined operators do not officially appear in formulas. They are just abbreviations, so officially they cannot be the main operator of a formula. In proofs about all formulas they therefore do not have to be treated separately.

subformula

Explanation

It is often useful to talk about the formulas that “make up” a given formula. We call these its subformulas. Any formula counts as a subformula of itself; a subformula of A other than A itself is a proper subformula.

Definition of immediate subformulas

If A is a formula, the immediate subformulas of A are defined inductively as follows:

  1. Atomic formulas have no immediate subformulas.

    Case: The only immediate subformula of the current formula is B.

  2. Case: The immediate subformulas of the current formula are B and C (binary connective star is any one of the two-place connectives).

    Case: The only immediate subformula of the current formula is B.

    Case: The only immediate subformula of the current formula is B.

Definition of proper subformulas

If A is a formula, the proper subformulas of A are defined recursively as follows:

  1. Atomic formulas have no proper subformulas.

    Case: The proper subformulas of the current formula are B together with all proper subformulas of B.

  2. Case: The proper subformulas of the current formula are B, C, together with all proper subformulas of B and those of C.

    Case: The proper subformulas of the current formula are B together with all proper subformulas of B.

    Case: The proper subformulas of the current formula are B together with all proper subformulas of B.

Definition of subformula

The subformulas of A are A itself together with all its proper subformulas.

Explanation

Note the subtle difference in how we have defined immediate subformulas and proper subformulas. In the first case, we have directly defined the immediate subformulas of a formula A for each possible form of A. It is an explicit definition by cases, and the cases mirror the inductive definition of the set of formulas. In the second case, we have also mirrored the way the set of all formulas is defined, but in each case we have also included the proper subformulas of the smaller formulas B, C in addition to these formulas themselves. This makes the definition recursive. In general, a definition of a function on an inductively defined set (in our case, formulas) is recursive if the cases in the definition of the function make use of the function itself. To be well defined, we must make sure, however, that we only ever use the values of the function for arguments that come “before” the one we are defining—in our case, when defining “proper subformula” for open parenthesis B binary connective star C close parenthesis we only use the proper subformulas of the “earlier” formulas B and C.

Transitivity of the subformula relation

Suppose B is a subformula of A and C is a subformula of B. Then C is a subformula of A. In other words, the subformula relation is transitive.

Formation Sequences

Defining formulas via an inductive definition, and the complementary technique of proving properties of formulas via induction, is an elegant and efficient approach. However, it can also be useful to consider a more bottom-up, step-by-step approach to the construction of formulas, which we do here using the notion of a formation sequence.

To show how terms and formulas can be introduced in this way without needing to refer to their inductive definitions, we first introduce the notion of an arbitrary string of symbols drawn from some language L.

Definition of language strings

Suppose L is a first-order language. An L-string is a finite sequence of symbols of L. Where the language L is clearly fixed by the context, we will often refer to a L-string simply as a string.

Example of a string that is not a formula

For any first-order language L, all L-formulas are L-strings, but not conversely. For example, close parenthesis, open parenthesis, v sub zero, conditional, existential quantifier is an L-string but not an L-formula.

Definition of term formation sequence

Definition of formula formation sequence

A finite sequence of L-strings sequence A sub zero through A sub n is a formation sequence for A if A is syntactically identical to A sub n and for all i less than or equal to n, either A sub i is an atomic formula or there exist indices j and k, each less than i, and a variable x such that one of the following holds:

A sub i is syntactically identical to not A sub j. A sub i is syntactically identical to open parenthesis A sub j and A sub k close parenthesis. A sub i is syntactically identical to open parenthesis A sub j or A sub k close parenthesis. A sub i is syntactically identical to open parenthesis if A sub j then A sub k close parenthesis.

A sub i is syntactically identical to: for every x, A sub j. A sub i is syntactically identical to: there exists x such that A sub j.

When it is necessary to distinguish, we will refer to formation sequences for formulas as formula formation sequences.

Existence of formula formation sequences

Every formula A in formula set of L has a formation sequence.

Proof

Suppose A is atomic. Then the sequence containing A is a formation sequence for A.

Now suppose that B and C have formation sequences sequence B sub zero through B sub n and sequence C sub zero through C sub m respectively.

If A is syntactically identical to not B, then sequence B sub zero through B sub n, followed by not B sub n is a formation sequence for A. If A is syntactically identical to open parenthesis B and C close parenthesis, then sequence B sub zero through B sub n, then C sub zero through C sub m, followed by their final conjunction is a formation sequence for A. If A is syntactically identical to open parenthesis B or C close parenthesis, then sequence B sub zero through B sub n, then C sub zero through C sub m, followed by their final disjunction is a formation sequence for A. If A is syntactically identical to open parenthesis if B then C close parenthesis, then sequence B sub zero through B sub n, then C sub zero through C sub m, followed by: if B sub n then C sub m is a formation sequence for A.

If A is syntactically identical to: for every x, B, then sequence B sub zero through B sub n, followed by for every x, B sub n is a formation sequence for A. If A is syntactically identical to: there exists x such that B, then sequence B sub zero through B sub n, followed by there exists x such that B sub n is a formation sequence for A.

By the principle of induction on formulas, every formula has a formation sequence.

End of proof.

There are two types of “junk” that can appear in formation sequences: repeated elements, and elements that are irrelevant to the construction of the formation or term. We can eliminate both by looking at minimal formation sequences.

Definition of minimal formation sequence

A formation sequence A sub zero through A sub n for a formula A is a minimal formation sequence for A if for every other formation sequence s for A, the length of s is greater than or equal to n plus one.

Similarly, a formation sequence t sub zero through t sub n for a term t is a minimal formation sequence for t if for every other formation sequence s for t, the length of s is greater than or equal to n plus one.

Note that a formula or term can have more than one minimal formation sequence, but they will contain exactly the same strings.

Formation-sequence characterization of subformulas

The following are equivalent:

  1. B is a sub-formula of A.

  2. B occurs in every formation sequence of A.

  3. B occurs in a minimal formation sequence of A.

Historical note

Formation sequences were introduced by Raymond Smullyan in his textbook First-Order Logic (Raymond M. Smullyan, one thousand nine hundred sixty eight). Additional properties of formation sequences were established by Martin M. Zuckerman (one thousand nine hundred seventy three).

Definition of free variable occurrences

The free occurrences of a variable in a formula are defined inductively as follows:

  1. Case: A is atomic: all variable occurrences in the current formula are free.

    Case: the free variable occurrences of the current formula are exactly those of B.

  2. Case: the free variable occurrences of the current formula are those in B together with those in C.

    Case: the free variable occurrences in the current formula are all of those in B except for occurrences of x.

Definition of quantifier scope and binding

If for every x, B is an occurrence of a subformula in a formula A, then the corresponding occurrence of B in A is called the scope of the corresponding occurrence of the universal quantifier for x. Similarly for the existential quantifier for x.

If B is the scope of a quantifier occurrence, namely the universal quantifier for x or the existential quantifier for x, in A, then the free occurrences of x in B are bound in for every x, B and there exists x such that B. We say that these occurrences are bound by the mentioned quantifier occurrence.

Examples of scope, binding, and free variables

Consider the following formula: there exists v sub zero such that predicate A superscript two sub zero holds of v sub zero and v sub one, with that atomic formula marked B. B represents the scope of the existential quantifier for variable v sub zero. The quantifier binds the occurrence of v sub zero in B, but does not bind the occurrence of v sub one. So v sub one is a free variable in this case.

We can now see how this might work in a more complicated formula A: a conditional whose complete antecedent is: for every v sub zero, scope B, where B is, if A superscript one sub zero of v sub zero then A superscript two sub zero of v sub zero and v sub one; and whose complete consequent is: there exists v sub one such that scope C, where C is, either A superscript two sub one of v sub zero and v sub one, or, for every v sub zero, scope D, where D is, not A superscript one sub one of v sub zero. B is the scope of the first universal quantifier for variable v sub zero, C is the scope of the existential quantifier for variable v sub one, and D is the scope of the second universal quantifier for variable v sub zero. The first universal quantifier for variable v sub zero binds the occurrences of v sub zero in B, the existential quantifier for variable v sub one binds the occurrence of v sub one in C, and the second universal quantifier for variable v sub zero binds the occurrence of v sub zero in D. The first occurrence of v sub one and the fourth occurrence of v sub zero are free in A. The last occurrence of v sub zero is free in D, but bound in C and A.

Definition of sentence

A formula A is a sentence if and only if it contains no free occurrences of variables.

Substitution

Recursive definition of substitution in a term

We define term s with term t substituted for variable x, the result of substituting t for every occurrence of x in s, recursively:

  1. Case: the result of substituting term t for variable x in the current term is just s.

  2. Case: the result of substituting term t for variable x in the current term is also just s, provided y is a variable and y is not syntactically identical to x.

  3. Case: the result of substituting term t for variable x in the current term is t.

  4. Case: the result of substituting term t for variable x in the current function term is function f applied to t sub one with t substituted for x, through t sub n with t substituted for x.

Definition of a term being free for a variable

A term t is free for x in A if none of the free occurrences of x in A occur in the scope of a quantifier that binds a variable in t.

Examples of terms free and not free for substitution

  1. v sub eight is free for v sub one in there exists v sub three such that predicate A superscript two sub four holds of v sub three and v sub one

  2. function f superscript two sub one of v sub one and v sub two is not free for v sub zero in for every v sub two, predicate A superscript two sub four holds of v sub zero and v sub two

Recursive definition of substitution in a formula

If A is a formula, x is a variable, and t is a term free for x in A, then formula A with term t substituted for variable x is the result of substituting t for all free occurrences of x in A.

Case: the result of substituting term t for variable x in the current formula is falsum sign.

  1. Case: the result of substituting term t for variable x in the current formula is P of t sub one with t substituted for x, through t sub n with t substituted for x.

  2. Case: the result of substituting term t for variable x in the current expression is t sub one with t substituted for x equals t sub two with t substituted for x.

    Case: the result of substituting term t for variable x in the current expression is not, formula B with term t substituted for x.

    Case: the result of substituting term t for variable x in the current expression is open parenthesis B with t substituted for x, and C with t substituted for x, close parenthesis.

    Case: the result of substituting term t for variable x in the current expression is open parenthesis B with t substituted for x, or C with t substituted for x, close parenthesis.

    Case: the result of substituting term t for variable x in the current expression is open parenthesis if B with t substituted for x, then C with t substituted for x, close parenthesis.

    Case: the result of substituting term t for variable x in the current expression is for every y, B with term t substituted for x, provided y is a variable other than x; otherwise the result of substituting term t for variable x in the current expression is just the current formula.

    Case: the result of substituting term t for variable x in the current expression is there exists y such that B with term t substituted for x, provided y is a variable other than x; otherwise the result of substituting term t for variable x in the current expression is just the current formula.

Explanation

Note that substitution may be vacuous: If x does not occur in A at all, then formula A with term t substituted for variable x is just A.

The restriction that t must be free for x in A is necessary to exclude cases like the following. If A is syntactically identical to: there exists y such that x is less than y and term t is syntactically identical to variable y, then formula A with term t substituted for variable x would be there exists y such that y is less than y. In this case the free variable y is “captured” by the quantifier there exists y upon substitution, and that is undesirable. For instance, we would like it to be the case that whenever for every x, B holds, so does formula B with term t substituted for variable x. But consider for every x, there exists y such that x is less than y (here B is there exists y such that x is less than y). It is a sentence that is true about, e.g., the natural numbers: for every number x there is a number y greater than it. If we allowed y as a possible substitution for x, we would end up with formula B with y substituted for x is syntactically identical to: there exists y such that y is less than y, which is false. We prevent this by requiring that none of the free variables in t would end up being bound by a quantifier in A.

We often use the following convention to avoid cumbersome notation: If A is a formula which may contain the variable x free, we also write A of x to indicate this. When it is clear which A and x we have in mind, and t is a term (assumed to be free for x in A of x), then we write A of t as short for formula A with term t substituted for variable x. So for instance, we might say, “we call A of t an instance of for every x, A of x.” By this we mean that if A is any formula, x a variable, and t a term that's free for x in A, then formula A with term t substituted for variable x is an instance of for every x, A.
