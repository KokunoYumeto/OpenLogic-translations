  13. In order to develop the theory and metatheory of first-order logic, we
  14. must first define the syntax and semantics of its expressions. The
  15. expressions of first-order logic are terms and !!{formula}s. Terms
  16. are formed from !!{variable}s, !!{constant}s, and !!{function}s.
  17. !!^{formula}s, in turn, are formed from !!{predicate}s together with
  18. terms (these form the smallest, ``atomic'' !!{formula}s), and then
  19. from atomic !!{formula}s we can form more complex ones using logical
  20. connectives and quantifiers. There are many different ways to set
  21. down the formation rules; we give just one possible one. Other systems
  22. will chose different symbols, will select different sets of
  23. connectives as primitive, will use parentheses differently (or even not
  24. at all, as in the case of so-called Polish notation). What all
  25. approaches have in common, though, is that the formation rules define
  26. the set of terms and !!{formula}s \emph{inductively}. If done
  27. properly, every expression can result essentially in only one way
  28. according to the formation rules. The inductive definition resulting
  29. in expressions that are \emph{uniquely readable} means we can give
  30. meanings to these expressions using the same method---inductive
  31. definition.

  26. \tagitem{limitClause}{
  27. Nothing else is a term.}{}
  28. \end{enumerate}
  29. A term containing no !!{variable}s is a \emph{closed term}.
  30. \end{defn}

  35. been included as zero-place !!{function}s. We could then do without
  36. the second clause in the definition of terms. We just have to

  66. \tagitem{prvAnd}{\indcase{!A}{(!B \land
  67. !C)}{$\Subst{\indfrmp}{t}{x}$ is $(\Subst{!B}{t}{x} \land
  68. \Subst{!C}{t}{x})$.}}{}
  70. \tagitem{prvOr}{\indcase{!A}{(!B \lor
  71. !C)}{$\Subst{\indfrmp}{t}{x}$ is $(\Subst{!B}{t}{x} \lor
  72. \Subst{!C}{t}{x})$.}}{}
  74. \tagitem{prvIf}{\indcase{!A}{(!B \lif
  75. !C)}{$\Subst{\indfrmp}{t}{x}$ is $(\Subst{!B}{t}{x} \lif
  76. \Subst{!C}{t}{x})$.}}{}
  78. \tagitem{prvIff}{\indcase{!A}{(!B \liff
  79. !C)}{$\Subst{\indfrmp}{t}{x}$ is $(\Subst{!B}{t}{x} \liff
  80. \Subst{!C}{t}{x})$.}}{}
  82. \tagitem{prvAll}{
  83. \indcase{!A}{\lforall[y][!B]}{$\Subst{\indfrmp}{t}{x}$
  84. is $\lforall[y][\Subst{!B}{t}{x}]$, provided $y$ is a variable
  85. other than $x$; otherwise $\Subst{\indfrmp}{t}{x}$
  86. is just $\indfrm$.}}{}
  88. \tagitem{prvEx}{
  89. \indcase{!A}{\lexists[y][!B]}{$\Subst{\indfrmp}{t}{x}$
  90. is $\lexists[y][\Subst{!B}{t}{x}]$, provided $y$ is a variable
  91. other than $x$; otherwise $\Subst{\indfrmp}{t}{x}$
  92. is just $\indfrm$.}}{}
  93. \end{enumerate}
  94. \end{defn}
  96. \begin{explain}
  97. Note that substitution may be vacuous: If $x$ does not occur in $!A$
  98. at all, then $\Subst{!A}{t}{x}$ is just~$!A$.
  100. The restriction that $t$ must be !!{free for}~$x$ in~$!A$ is necessary to
  101. exclude cases like the following. If $!A \ident \lexists[y][x < y]$
  102. and $t \ident y$, then $\Subst{!A}{t}{x}$ would be $\lexists[y][y <
  103. y]$. In this case the free variable $y$ is ``captured'' by the
  104. quantifier $\lexists[y]$ upon substitution, and that is undesirable.
  105. For instance, we would like it to be the case that whenever
  106. $\lforall[x][!B]$ holds, so does $\Subst{!B}{t}{x}$. But consider
  107. $\lforall[x][\lexists[y][x < y]]$ (here $!B$ is $\lexists[y][x <
  108. y]$). It is a sentence that is true about, e.g., the natural numbers:
  109. for every number~$x$ there is a number~$y$ greater than it. If we
  110. allowed $y$ as a possible substitution for~$x$, we would end up with
  111. $\Subst{!B}{y}{x} \ident \lexists[y][y < y]$, which is false. We
  112. prevent this by requiring that none of the free variables in~$t$ would
  113. end up being bound by a quantifier in~$!A$.
  114. \end{explain}
  116. We often use the following convention to avoid cumbersome notation: If
  117. $!A$ is !!a{formula} which may contain the !!{variable}~$x$ free, we
  118. also write~$!A(x)$ to indicate this. When it is clear which $!A$
  119. and~$x$ we have in mind, and $t$ is a term (assumed to be free for $x$
  120. in $!A(x)$), then we write $!A(t)$ as short for $\Subst{!A}{t}{x}$. So
  121. for instance, we might say, ``we call $!A(t)$ an instance
  122. of~$\lforall[x][!A(x)]$.'' By this we mean that if $!A$~is any
  123. !!{formula}, $x$~!!a{variable}, and $t$~a term that's free for~$x$
  124. in~$!A$, then $\Subst{!A}{t}{x}$ is an instance of~$\lforall[x][!A]$.
