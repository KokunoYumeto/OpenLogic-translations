  13. \olsection{Rules and \usetoken{P}{tableau}}
  15. !!^a{tableau} is a systematic survey of the possible ways
  16. !!a{sentence} can be true or false in !!a{structure}. The building
  17. blocks of a tableau are !!{signed formula}s: !!{sentence}s plus a
  18. truth value ``sign,'' either $\True$ or~$\False$. These signed
  19. !!{formula}s are arranged in a (downward growing) tree.
  21. \begin{defn}
  22. A \emph{!!{signed formula}} is a pair consisting of a truth value
  23. and !!a{sentence}, i.e., either:
  24. \[
  25. \sFmla{\True}{!A} \text{ or } \sFmla{\False}{!A}.
  26. \]
  27. \end{defn}
  29. Intuitively, we might read $\sFmla{\True}{!A}$ as ``$!A$ might be
  30. true'' and $\sFmla{\False}{!A}$ as ``$!A$ might be false'' (in some
  31. !!{structure}).
  33. Each !!{signed formula} in the tree is either an \emph{assumption}
  34. (which are listed at the very top of the tree), or it is obtained from
  35. !!a{signed formula} above it by one of a number of rules of
  36. inference. There are two rules for each possible !!{main operator} of
  37. the preceding !!{formula}, one for the case where the sign is~$\True$,
  38. and one for the case where the sign is~$\False$. Some rules allow the
  39. tree to branch, and some only add !!{signed formula}s to the branch.
  40. A rule may be (and often must be) applied not to the immediately
  41. preceding !!{signed formula}, but to any !!{signed formula} in the
  42. branch from the root to the place the rule is applied.
  44. A branch is \emph{closed} when it contains both $\sFmla{\True}{!A}$
  45. and $\sFmla{\False}{!A}$. A closed !!{tableau} is one where every branch
  46. is closed. Under the intuitive interpretation, any branch describes a
  47. joint possibility, but $\sFmla{\True}{!A}$ and $\sFmla{\False}{!A}$
  48. are not jointly possible. In other words, if a branch is closed, the
  49. possibility it describes has been ruled out. In particular, that means
  50. that a closed !!{tableau} rules out all possibilities of simultaneously
  51. making every assumption of the form $\sFmla{\True}{!A}$ true and every
  52. assumption of the form~$\sFmla{\False}{!A}$ false.
  54. A closed !!{tableau} \emph{for $!A$} is a closed !!{tableau} with
  55. root~$\sFmla{\False}{!A}$. If such a closed !!{tableau} exists, all
  56. possibilities for~$!A$ being false have been ruled out; i.e., $!A$
  57. must be true in every !!{structure}.
  59. \end{document}

  17. inference. !!^{tableau}s are inductively generated from these: each
  18. !!{tableau} either is a single branch consisting of one or more
  19. assumptions, or it results from !!a{tableau} by applying one of the
  20. rules of inference on a branch.
  21. \end{explain}
  23. \begin{defn}[!!^{tableau}]
  24. !!^a{tableau} for assumptions $\sFmla{S_1}{!A_1}$, \dots,
  25. $\sFmla{S_n}{!A_n}$ (where each $S_i$ is either $\True$ or~$\False$) is
  26. a finite tree of !!{signed formula}s satisfying the following conditions:
  27. \begin{enumerate}
  28. \item The $n$ topmost !!{signed formula}s of the tree are
  29. $\sFmla{S_i}{!A_i}$, one below the other.
  30. \item Every !!{signed formula} in the tree that is not one of the
  31. assumptions results from a correct application of an inference rule
  32. to !!a{signed formula} in the branch above it.
  33. \end{enumerate}
  34. A branch of !!a{tableau} is \emph{closed} iff it contains both
  35. $\sFmla{\True}{!A}$ and~$\sFmla{\False}{!A}$, and \emph{open}
  36. otherwise. !!^a{tableau} in which every branch is closed is a
  37. \emph{closed !!{tableau}} (for its set of assumptions). If !!a{tableau} is
  38. not closed, i.e., if it contains at least one open branch, it is
  39. \emph{open}.
  40. \end{defn}
  42. \begin{ex}

  44. generally not be closed. (Obviously, it is closed only if the
  45. assumptions already contain a pair of !!{signed formula}s
  46. $\sFmla{\True}{!A}$ and~$\sFmla{\False}{!A}$.)

  49. applying one of the rules of inference to !!a{signed formula}~$!A$
  50. in it. The rule will append one or more !!{signed formula}s to the end of

  52. rule.

  13. \olsection{Proof-Theoretic Notions}
  15. \begin{editorial}
  16. This section collects the definitions of the provability relation
  17. and consistency for tableaux.
  18. \end{editorial}
  20. \begin{explain}
  21. Just as we've defined a number of important semantic notions
  22. (validity, entailment, satisfiability), we now define corresponding
  23. \emph{proof-theoretic notions}. These are not defined by appeal to
  24. satisfaction of !!{sentence}s in !!{structure}s, but by appeal to the
  25. existence of certain closed !!{tableau}x. It was an important
  26. discovery that these notions coincide. That they do is the content of
  27. the \emph{soundness} and \emph{completeness theorems}.
  28. \end{explain}
  31. \begin{defn}[Theorems]
  32. A !!{sentence}~$!A$ is a \emph{theorem} if there is a closed
  33. !!{tableau} for~$\sFmla{\False}{!A}$. We write $\Proves !A$ if $!A$
  34. is a theorem and $\Proves/ !A$ if it is not.
  35. \end{defn}
  37. \begin{defn}[!!^{derivability}]
  38. !!^a{sentence} $!A$ is \emph{!!{derivable} from} a set of
  39. !!{sentence}s~$\Gamma$, $\Gamma \Proves !A$ iff there is a
  40. finite set $\{!B_1, \dots, !B_n\} \subseteq \Gamma$
  41. and a closed !!{tableau} for the set
  42. \[
  43. \{
  44. \sFmla{\False}{!A},
  45. \sFmla{\True}{!B_1}, \dots,
  46. \sFmla{\True}{!B_n}
  47. \}.
  48. \]
  49. If $!A$ is not !!{derivable} from $\Gamma$ we write $\Gamma \Proves/
  50. !A$.
  51. \end{defn}
  53. \begin{defn}[Consistency]
  54. A set of !!{sentence}s~$\Gamma$ is \emph{inconsistent} iff there is a
  55. finite set $\{!B_1, \dots, !B_n\} \subseteq \Gamma$ and a closed
  56. !!{tableau} for the set
  57. \[
  58. \{
  59. \sFmla{\True}{!B_1}, \dots,
  60. \sFmla{\True}{!B_n}
  61. \}.
  62. \]
  63. If $\Gamma$ is not inconsistent, we say it is \emph{consistent}.
  64. \end{defn}
  66. \begin{prop}[Reflexivity]
  67. \ollabel{prop:reflexivity}
  68. If $!A \in \Gamma$, then $\Gamma \Proves !A$.
  69. \end{prop}
  71. \begin{proof}
  72. If $!A \in \Gamma$, $\{!A\}$ is a finite subset of~$\Gamma$ and the !!{tableau}
  73. \begin{oltableau}
  74. [\sFmla{\False}{\formula{A}}, just = \TAss
  75. [\sFmla{\True}{\formula{A}}, just = \TAss,close]
  76. ]
  77. \end{oltableau}
  78. is closed.
  79. \end{proof}
  82. \begin{prop}[Monotonicity]
  83. \ollabel{prop:monotonicity}
  84. If $\Gamma \subseteq \Delta$ and $\Gamma \Proves !A$, then $\Delta
  85. \Proves !A$.
  86. \end{prop}
  88. \begin{proof}
  89. Any finite subset of~$\Gamma$ is also a finite subset of~$\Delta$.
  90. \end{proof}
  92. \begin{prop}[Transitivity]
  93. \ollabel{prop:transitivity}
  94. If $\Gamma \Proves !A$ and $\{!A\} \cup
  95. \Delta \Proves !B$, then $\Gamma \cup \Delta \Proves !B$.

  138. $\Gamma \Proves !B$.

  19. We just have to show as before that if !!a{tableau} has a satisfiable
  20. branch, the branch resulting from applying one of the rules for~$\eq$
  21. to it is also satisfiable. Let $\Gamma$ be the set of signed
  22. !!{formula}s on the branch, and let $\Struct{M}$ be !!a{structure}
  23. satisfying~$\Gamma$.
  25. Suppose the branch is expanded using~$\eq$, i.e., by adding the signed
  26. !!{formula}~$\sFmla{\True}{\eq[t][t]}$. Trivially,
  27. $\Sat{M}{\eq[t][t]}$, so $\Struct{M}$ also satisfies $\Gamma \cup
  28. \{\sFmla{\True}{\eq[t][t]}\}$.
  30. If the branch is expanded using $\TRule{\True}{\eq}$, we add a signed
  31. !!{formula}~$\sFmla{S}{!A(t_2)}$, but $\Gamma$ contains
  32. both~$\sFmla{\True}{\eq[t_1][t_2]}$ and $\sFmla{\True}{!A(t_1)}$. Thus
  33. we have $\Sat{M}{\eq[t_1][t_2]}$ and $\Sat{M}{!A(t_1)}$. Let $s$ be a
  34. variable assignment with $s(x) = \Value{t_1}{M}$. By
  35. \olref[syn][ass]{prop:sentence-sat-true}, $\Sat{M}{!A(t_1)}[s]$. Since
  36. $\varAssign{s}{s}{x}$, by \olref[syn][ext]{prop:ext-formulas},
  37. $\Sat{M}{!A(x)}[s]$. since $\Sat{M}{\eq[t_1][t_2]}$, we have
  38. $\Value{t_1}{M} = \Value{t_2}{M}$, and hence $s(x) = \Value{t_2}{M}$.
  39. By applying \olref[syn][ext]{prop:ext-formulas} again, we also have
  40. $\Sat{M}{!A(t_2)}[s]$. By \olref[syn][ass]{prop:sentence-sat-true},
  41. $\Sat{M}{!A(t_2)}$. The case of $\TRule{\False}{\eq}$ is treated
  42. similarly.
  43. \end{proof}
