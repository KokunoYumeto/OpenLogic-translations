In fact, it is a complete16  !!{c.e.} set.17\end{thm}1819\begin{proof}20It is not hard to see that $\Th{Q}$ is !!{c.e.}, since it is the set of21(codes for) sentences $y$ such that there is a proof $x$ of $y$ in22$\Th{Q}$:23\[24Q = \Setabs{y}{\lexists[x][\Prf[\Th{Q}](x,y)]}.25\]26But we know that $\Prf[\Th{Q}](x,y)$ is computable (in fact, primitive27recursive), and any set that can be written in the above form is c.e.2829Saying that it is a complete c.e.\ set is equivalent to saying that $K30\leq_m Q$, where $K = \Setabs{x}{!A_x(x) \downarrow}$. So let us show31that $K$ is reducible to $\Th{Q}$. Since Kleene's predicate $T(e,x,s)$ is32primitive recursive, it is representable in $\Th{Q}$, say, by $!A_T$. Then33for every $x$, we have34\begin{align*}35x \in K & \lif \lexists[s][T(x,x,s)] \\36& \lif \lexists[s][(\Th{Q} \Proves !A_T(\num x,\num x, \num s))]37  \\38& \lif \Th{Q} \Proves \lexists[s][!A_T(\num x, \num x, s)].39\end{align*}40Conversely, if $\Th{Q} \Proves \lexists[s][!A_T(\num x, \num x, s)]$,41then, in fact, for some natural number $n$ the formula $!A_T(\num x,42\num x, \num n)$ must be true.  Now, if $T(x,x,n)$ were false,43$\Th{Q}$ would prove $\lnot !A_T(\num x, \num x, \num n)$, since44$!A_T$ represents $T$.  But then $\Th{Q}$ proves a false formula,45which is a contradiction. So $T(x,x,n)$ must be true, which implies46$!A_x(x) \downarrow$.4748In short, we have that for every $x$, $x$ is in $K$ if and only if49$\Th{Q}$ proves $\lexists[s][T(\num x,\num x,s)]$. So the function $f$50which takes $x$ to (a code for) the sentence $\lexists[s][T(\num x,51  \num x, s)]$ is a reduction of $K$ to $\Th{Q}$.52\end{proof}5354\end{document}

Since anything follows from16a contradiction, an inconsistent theory is trivial: every sentence is17provable. Clearly, if a theory if $\omega$-consistent, then it is18consistent. But being consistent is a weaker requirement (i.e., there19are theories that are consistent but not $\omega$-consistent.). We can20weaken the assumption in \olref[oqn]{thm:oconsis-q} to simple21consistency to obtain a stronger theorem.22\end{explain}2324\begin{lem}25There is no ``universal computable relation.'' That is, there is no26binary computable relation $R(x,y)$, with the following property:27whenever $S(y)$ is a unary computable relation, there is some $k$ such28that for every $y$, $S(y)$ is true if and only if $R(k,y)$ is true.29\end{lem}3031\begin{proof}32Suppose $R(x,y)$ is a universal computable relation. Let $S(y)$33be the relation $\lnot R(y,y)$. Since $S(y)$ is computable, for some34$k$, $S(y)$ is equivalent to $R(k,y)$. But then we have that $S(k)$ is35equivalent to both $R(k,k)$ and $\lnot R(k,k)$, which is a36contradiction.37\end{proof}383940\begin{thm}41Let $\Th{T}$ be any consistent theory that includes $\Th{Q}$. Then42$\Th{T}$ is not decidable.43\end{thm}444546\begin{proof}47Suppose $\Th{T}$ is a consistent, decidable48extension of $\Th{Q}$. We will obtain a contradiction by using $\Th{T}$ to49define a universal computable relation.5051Let $R(x,y)$ hold if and only if52\begin{quote}53$x$ codes a formula $!D(u)$, and $\Th{T}$ proves $!D(\num y)$.54\end{quote}55Since we are assuming that $\Th{T}$ is decidable, $R$ is computable. Let us56show that $R$ is universal. If $S(y)$ is any computable relation, then57it is representable in $\Th{Q}$ (and hence $\Th{T}$) by a formula58$!D_S(u)$. Then for every $n$, we have59\begin{eqnarray*}60S(\num n) & \lif & T \vdash !D_S(\num n) \\61& \lif & R(\Gn{!D_S(u)}, n)62\end{eqnarray*}63and64\begin{eqnarray*}65\lnot S(\num n) & \lif & T \vdash \lnot !D_S(\num n) \\66& \lif & T \not\vdash !D_S(\num n) \quad \text{(since $\Th{T}$ is67  consistent)} \\68& \lif & \lnot R(\Gn{!D_S(u)}, n).69\end{eqnarray*}70That is, for every $y$, $S(y)$ is true if and only if71$R(\Gn{!D_S(u)}, y)$ is. So $R$ is universal, and we have the72contradiction we were looking for.73\end{proof}7475Let ``true arithmetic'' be the theory $\Setabs{!A}{ \Sat{\Nat}{!A}}$,76that is, the set of sentences in the language of arithmetic that are77true in the standard interpretation.7879\begin{cor}80True arithmetic is not decidable.81\end{cor}8283%In Section~\olref{undefinability:truth:section} we will state a stronger84%result, due to Tarski.8586\end{document}87

Then $\Th{T}$ is undecidable.20\end{thm}2122\begin{proof}23Remember that $\Th{Q}$ has a finite set of axioms, $!Q_1$, \dots,24$!Q_8$. We can even replace these by a single axiom, $!E = !Q_1 \land25\dots \land !Q_8$.2627Suppose $\Th{T}$ is a decidable theory consistent with~$\Th{Q}$. Let28\[29C = \Setabs{!A}{\Th{T} \Proves !E \lif !A}.30\]31We show that $C$ would be a computable separation of $\Th{Q}$ and32$\Th{\bar Q}$, a contradiction. First, if $!A$ is in $\Th{Q}$, then33$!A$ is provable from the axioms of $\Th{Q}$; by the deduction34theorem, there is !!a{derivation} of $!E \lif !A$ in first-order logic. So35$!A$ is in~$C$.3637On the other hand, if $!A$ is in $\Th{\bar Q}$, then there is a proof38of $!E \lif \lnot !A$ in first-order logic. If $\Th{T}$ also proves39$!E \lif !A$, then $\Th{T}$ proves $\lnot !E$, in which case $\Th{T}40\cup \Th{Q}$ is inconsistent. But we are assuming $\Th{T} \cup \Th{Q}$41is consistent, so $\Th{T}$ does not prove $!E \lif !A$, and so $!A$42is not in~$C$.4344We've shown that if $!A$ is in $\Th{Q}$, then it is in $C$, and if45$!A$ is in $\Th{\bar Q}$, then it is in $\Complement{C}$. So $C$ is a46computable separation, which is the contradiction we were looking for.47\end{proof}4849This theorem is very powerful.
