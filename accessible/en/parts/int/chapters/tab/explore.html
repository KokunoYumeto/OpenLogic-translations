Definition of an interpretation of prefixes

An interpretation maps a set of nonempty finite positive-integer prefixes into model worlds and respects R whenever both a prefix and its one-step extension occur. It also defines satisfaction of signed true and signed false formulas.

A model satisfies a set Gamma of prefixed formulas relative to an interpretation f when it satisfies every member; Gamma is satisfiable when such a model and interpretation exist.
