Section. Introduction. The number of truth values of a matrix need not be finite. Like three valued Goedel logic , infinite valued Goedel logic has all intuitionistically valid formulas as tautologies, and the same examples of non-tautologies are non-tautologies of infinite valued Goedel logic : Displayed expression. Six formulas, read across each source row from left to right. Row one, left: p or not p. Row one, right: if the conditional if p then q holds, then not p or q. Row two, left: if not not p then p. Row two, right: if it is not the case that both not p and not q, then p or q. Row three, left: if the conditional from if p then q to p holds, then p. Row three, right: if it is not the case that if p then q, then both p and not q. End of six formulas. End displayed expression. The example of an intuitionistically invalid formula that is nevertheless a tautology of three valued Goedel logic , the disjunction of if p then q with if q then p , is also a tautology in infinite valued Goedel logic . In fact, infinite valued Goedel logic can be characterized as intuitionistic logic to which the schema the disjunction of if A then B with if B then A is added. This was shown by Michael Dummett, and so infinite valued Goedel logic is often referred to as Goedel—Dummett logic L C . Exercise.
