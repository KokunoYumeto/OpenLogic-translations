Chapter. Sequent Calculus.

Section. Introduction. The sequent calculus for classical logic is an efficient and simple derivation system. If a many-valued logic is defined by a matrix with finitely many truth values, that is, the set V of truth values is finite, it is possible to provide a sequent calculus for it. The idea for how to do this comes from considering the meanings of sequents and the form of inference rules in the classical case. Now recall that a sequent Displayed expression. In other words, A valuation v satisfies a sequent with antecedent Gamma and succedent Delta if and only if either the value of formula A under valuation v is false for some A in Gamma or the value of formula A under valuation v is true for some A in Delta . Premise node one: the two sided sequent with antecedent empty and succedent formula A . Premise node two: the two sided sequent with antecedent formula B and succedent empty . The label of the next inference is left conditional rule . End proof tree. Proof tree. Classical right conditional rule. Premise node one: the two sided sequent with antecedent formula A and succedent formula B . The label of the next inference is right conditional rule . From node one, in that order, infer node two: the two sided sequent with antecedent empty and succedent the conditional from formula A to formula B . The root conclusion is node two. End proof tree. If we apply the above semantic interpretation of a sequent, we can read the left conditional rule as saying that if the value of formula A under valuation v is true and the value of formula B under valuation v is false , then the value of the conditional from A to B under valuation v is false . Similarly, the right conditional rule says that if either the value of formula A under valuation v is false or the value of formula B under valuation v is true , then the value of the conditional from A to B under valuation v is true . And in fact, these conditionals are actually biconditionals. In the case of the left conjunction and right disjunction rules in their standard formulation, the corresponding conditionals would not be biconditionals. But there are alternative versions of these rules where they are: Proof tree. Alternative classical left conjunction rule. Premise node one: the two sided sequent with antecedent formula A, followed by formula B, followed by Gamma and succedent Delta . The label of the next inference is left conjunction rule . From node one, in that order, infer node two: the two sided sequent with antecedent the conjunction of formulas A and B, followed by Gamma and succedent Delta . The root conclusion is node two. End proof tree. Proof tree. Alternative classical right disjunction rule. Premise node one: the two sided sequent with antecedent Gamma and succedent Delta, followed by formula A, followed by formula B . The label of the next inference is right disjunction rule . From node one, in that order, infer node two: the two sided sequent with antecedent Gamma and succedent Delta, followed by the disjunction of formulas A and B . The root conclusion is node two. End proof tree. This basic idea, applied to an n valued logic, then results in a sequent calculus with n instead of two places, one for each truth value. For a three-valued logic with V equal to the set containing the false, middle, and true truth values , a sequent is an expression with Gamma in the false position, Pi in the middle position, and Delta in the true position . It is satisfied in a valuation v if and only if either the value of formula A under valuation v is false for some A in Gamma or the value of formula A under valuation v is true for some A in Delta or the value of formula A under valuation v is the middle truth value for some A in Pi . Consequently, initial sequents with A in each of the false, middle, and true positions are always satisfied. End section.

Section. Rules and Derivations. For the following, let Gamma, Delta, Pi, and Lambda represent finite sequences of sentences. Definition. Sequent. An n -sided sequent is an expression of the form Displayed expression. the n sided sequent whose positions, in order, contain Gamma sub one through Gamma sub n. End displayed expression. where each Gamma sub one is a finite (possibly empty) sequences of sentences of the language L . End definition. Source anomaly note. The source says each Gamma sub one and uses the plural sequences after a singular subject. Its displayed n sided list and definition concern one finite sequence at each position. These wording defects are retained with this note. Original source remains available in Source view. End note. Definition. Initial Sequent. An n -sided initial sequent is an n -sided sequent of the form the n sided sequent with formula A alone in every position for any sentence A in the language. If the language contains a zero place connective star , that is, a propositional constant, then we also take the sequent with star in one position where the propositional constant star appears in the space for the truth value associated with the truth value assigned by the nullary truth function for star, which belongs to V , and is empty otherwise. End definition. For each connective of an n valued logic L , there is a logical rule for each truth value that this connective can take in logic L . Derivations in an n -sided sequent calculus for logic L are trees of sequents, where the topmost sequents are initial sequents, and if a sequent stands below one or more other sequents, it must follow correctly by a rule of inference for the connectives of logic L . Definition. Theorems. A sentence A is a theorem of an n valued logic L if there is a derivation of the n -sequent containing formula A in each position corresponding to a designated truth value of logic L . We write formula A is a theorem of logic L if formula A is a theorem and formula A is not a theorem of logic L if it is not. End definition. Definition. Derivability. A sentence A is derivable from a set of sentences Gamma in an n valued logic L , formula A is derivable from Gamma in logic L , if and only if there is a finite subset Gamma sub zero of Gamma and a sequence Gamma sub zero prime of the sentences in Gamma sub zero such that the following sequent has a derivation: Displayed expression. the n sided sequent whose positions, in order, contain Lambda sub one through Lambda sub n. End displayed expression. where Lambda sub i is formula A if position i corresponds to a designated truth value, and Gamma sub zero prime otherwise. If formula A is not derivable from Gamma we write formula A is not derivable from Gamma . End definition. For instance, three valued Łukasiewicz logic has a three -sided sequent calculus. In a three -sided sequent with Gamma in the false position, Pi in the middle position, and Delta in the true position , Gamma corresponds to the false truth value , Delta to the true truth value , and Pi to the middle truth value . Axioms are all three sided sequents with formula A in every position . Since only the true truth value is designated, formula A is derivable from Gamma in three valued Lukasiewicz logic if and only if the sequent with Gamma in the false position, Gamma in the middle position, and A in the true position has a derivation. (If the middle truth value were also designated, we would need a derivation of the three sided sequent with false position Gamma; middle position formula A; and true position formula A .) End section.

Section. Structural Rules. The structural rules for n -sided sequent calculus operate as in the classical case, except for each position i . Proof tree. Weakening at an arbitrary position. Premise node one: the n sided sequent containing Gamma sub one through Gamma sub n, with Gamma sub i in position i; the phantom formula is alignment space only . The label of the next inference is weakening rule at position i . From node one, in that order, infer node two: the n sided sequent containing Gamma sub one through Gamma sub n, except that position i contains formula A followed by Gamma sub i . The root conclusion is node two. End proof tree. Proof tree. Contraction at an arbitrary position. Premise node one: the n sided sequent containing Gamma sub one through Gamma sub n, except that position i contains two consecutive copies of formula A followed by Gamma sub i . The label of the next inference is contraction rule at position i . From node one, in that order, infer node two: the n sided sequent containing Gamma sub one through Gamma sub n, except that position i contains one visible copy of formula A followed by Gamma sub i; the phantom copy is alignment space only . The root conclusion is node two. End proof tree. Proof tree. Exchange at an arbitrary position. Premise node one: the n sided sequent with position i containing Gamma sub i, formula A, formula B, then Gamma sub i prime; all other positions retain their respective Gamma sequences . The label of the next inference is exchange rule at position i . From node one, in that order, infer node two: the n sided sequent with position i containing Gamma sub i, formula B, formula A, then Gamma sub i prime; all other positions retain their respective Gamma sequences . The root conclusion is node two. End proof tree. A series of weakening, contraction, and exchange inferences will often be indicated by double inference lines. The cut rule comes in several forms, one for every combination of distinct positions in the sequent where i differs from j : Displayed expression. Cut rule at distinct positions i and j. The first premise is the n sided sequent with formula A followed by Gamma sub i in position i and Gamma sub k in every other position k. The second premise has formula A followed by Delta sub j in position j and Delta sub k in every other position k. From both premises, in this order, infer the n sided sequent whose position k contains Gamma sub k followed by Delta sub k. Formula A is removed from the two distinguished positions. End cut rule. End displayed expression. End section.

Section. Propositional Rules for Selected Logics. The inference rules for a connective in an n -sided sequent calculus only depend on the characteristic truth function for the connective.
