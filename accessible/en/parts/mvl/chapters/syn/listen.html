Chapter. Syntax and Semantics.

Section. Introduction. In classical logic, we deal with formulas that are built from propositional variables using the propositional connectives negation , conjunction , disjunction , conditional , and biconditional . When we define a semantics for classical logic, we do so using the two truth values true and false . We interpret propositional variables in a valuation v , which assigns these truth values true , false to the propositional variables. Any valuation then determines a truth value of A under v for any formula A , and A formula is satisfied in a valuation v , valuation v satisfies A , if and only if the value of A under v equals true . Many-valued logics are generalizations of classical two-valued logic by allowing more truth values than just true and false . So in many-valued logic, a valuation v is a function assigning to every propositional variable p one of a range of possible truth values. We'll generally call the set of allowed truth values V . Classical logic is a many-valued logic where V equals the set containing true and false , and the truth value of A under v is computed using the familiar characteristic truth tables for the connectives. Once we add additional truth values, we have more than one natural option for how to compute the value of A under v for the connectives we read as “and,” “or,” “not,” and “if—then.” So a many-valued logic is determined not just by the set of truth values, but also by the truth functions we decide to use for each connective. Once these are selected for a many-valued logic L , however, the truth value of A under v in logic L is uniquely determined by the valuation, just like in classical logic. Many-valued logics, like classical logic, are truth functional. With this semantic building blocks in hand, we can go on to define the analogs of the semantic concepts of tautology, entailment, and satisfiability. In classical logic, a formula is a tautology if its truth value of A under v equals true for any v . In many-valued logic, we have to generalize this a bit as well. First of all, there is no requirement that the set of truth values V contains true . For instance, some many-valued logics use numbers, such as all rational numbers between zero and one as their set of truth values. In such a case, one usually plays the rule of true . In other logics, not just one but several truth values do. So, we require that every many-valued logic have a set V plus of designated values. We can then say that a formula is satisfied in a valuation v , valuation v satisfies A in logic L , if and only if the value of A under v in logic L belongs to the set of designated values V plus . A formula A is a tautology of the logic, A is a tautology of logic L , if and only if the value of A under v belongs to the set of designated values V plus for any v . And, finally, we say that A is entailed by a set of formulas, Gamma entails A in logic L , if every valuation that satisfies all the formulas in Gamma also satisfies A . End section.

Section. Languages and Connectives. Classical propositional logic, and many other logics, use a set supply of propositional constants and connectives. For instance, we use the following as primitives: List. Next item. The propositional constant for falsity the falsity constant . Next item. The logical connectives: negation (negation), conjunction (conjunction), disjunction (disjunction), conditional (conditional) End list. In addition to the primitive connectives above, we also use symbols defined as abbreviations, such as biconditional (biconditional), the truth constant (truth) The same connectives are used in many-valued logics as well. However, it is often useful to include different versions of, say, conjunction, in the same logic, and that would require different symbols to keep the versions separate. Some many-valued logics also include connectives that have no equivalent in classical logic. So, we'll be a bit more general than usual. Definition. A propositional language consists of a set L of connectives. Each connective star has an arity; a connective of arity n is said to be n place . Connectives of arity zero are also called constants; connectives of arity one are called unary, and connectives of arity two , binary. End definition. Example. The standard language of propositional logic L subscript zero consists of the following connectives (with associated arities): the falsity constant ( zero ) negation ( one ), conjunction ( two ), disjunction ( two ), conditional ( two ). Most logics we consider will use this language. Some logics by tradition an convention use different symbols for some connectives. For instance, in product logic, the conjunction symbol is often the circled dot conjunction symbol instead of conjunction . Sometimes it is convenient to add a new operator, for example, the determinateness operator triangle ( one place ). End example. End section.

Section. Formulas. Definition. Formula. The set F R M of L of formulas of a propositional language L is defined inductively as follows: List. Next item. Every propositional variable p subscript i is an atomic formula. Next item. Every zero place connective (propositional constant) of L is an atomic formula. Next item. If star is an n place connective of L , and A subscript one , and so on, A subscript n are formulas, then star applied to A subscript one through A subscript n in that order is a formula. Next item. Nothing else is a formula. End list. If star is one place , then star applied to A subscript one will often be written simply as star followed by A subscript one . If star is two place star applied to A subscript one and A subscript two in that order will often be written as A subscript one, star, A subscript two, enclosed together in parentheses . End definition. As usual, we will often silently leave out the outermost parentheses. Example. In the standard language L subscript zero , the conditional with antecedent p subscript one and consequent the conjunction of p subscript one with not p subscript two is a formula. In the language of product logic, it would be written instead as the conditional with antecedent p subscript one and consequent the product conjunction of p subscript one with not p subscript two . If we add the one place triangle to the language, we would also have formulas such as the conditional whose antecedent is triangle applied to the conjunction of p subscript one and p subscript two, and whose consequent is the conjunction of triangle applied to p subscript one with triangle applied to p subscript two . End example. End section.

Section. Matrices. A many-valued logic is defined by its language, its set of truth values V , a subset of designated truth values, and truth functions for its connective. Section. Valuations and Satisfaction. Definition. Valuations. Let V be a set of truth values. A valuation for L into V is a function v assigning an element of V to the propositional variables of the language, that is, valuation v maps the propositional variables to V . End definition. Definition. Given a valuation v into the set of truth values V of a many-valued logic L , define the evaluation function determined by v, from formulas of language L to values in V, inductively by: List. Next item. the value of p subscript n under the evaluation function determined by v equals the value assigned to p subscript n by v ; Next item. If star is a zero place connective, then the value of the constant star under v equals the truth value assigned to that constant by the matrix of logic L ; Next item. If star is an n place connective, then Displayed expression. The value under v of star applied to A subscript one through A subscript n equals the truth function for star in logic L applied, in that order, to the values under v of A subscript one through A subscript n. End displayed expression. End list. End definition. Definition. Satisfaction. The formula A is satisfied by a valuation v , valuation v satisfies A in logic L , if and only if the value of A under v in logic L belongs to the set of designated values V plus , where V plus is the set of designated truth values of L . We write valuation v does not satisfy A in logic L to mean “not valuation v satisfies A in logic L .” If Gamma is a set of formulas, valuation v satisfies every formula in Gamma in logic L if and only if valuation v satisfies A in logic L for every A in Gamma . End definition. End section.

Section. Semantic Notions. Suppose a many-valued logic L is given by a matrix. Then we can define the usual semantic notions for L . Definition. List. Next item. A formula A is satisfiable if for some v , valuation v satisfies A ; it is unsatisfiable if for no v , valuation v satisfies A ; Next item. A formula A is a tautology if valuation v satisfies A for all valuations v ; Next item. If Gamma is a set of formulas, Gamma entails A (“ Gamma entails A ”) if and only if valuation v satisfies A for every valuation v for which valuation v satisfies every formula in Gamma . Next item. If Gamma is a set of formulas, Gamma is satisfiable if there is a valuation v for which valuation v satisfies every formula in Gamma , and Gamma is unsatisfiable otherwise. End list. End definition. Monotonicity: if Gamma is a subset of Delta and Gamma entails A then also Delta entails A ; Next item. Transitivity: if Gamma entails A and Delta together with A entails B then the union of Gamma and Delta entails B ; End list. End proposition. Proof. Exercise. End proof. Exercise. For instance, we have the validity of modus ponens: If Gamma entails A and Gamma entails the conditional if A then B then Gamma entails B . Another important relationship between semantic entailment and conditional in classical logic is the semantic deduction theorem: Gamma entails the conditional if A then B if and only if Gamma together with A entails B . These results do not always hold in many-valued logics. Whether they do depends on the truth function for the conditional . End section.

Section. Many-valued logics as sublogics of classical logic . The usual many-valued logics are all defined using matrices in which the value of a truth-function for arguments in the set containing true and false agrees with the classical truth functions. Specifically, in these logics, if x belongs to the set containing true and false , then the negation truth function of logic L at x equals the classical negation truth function at x , and for star any one of conjunction , disjunction , conditional , if x and y both belong to the set containing true and false , then the truth function for star in logic L at x and y equals the classical truth function for star at x and y . In other words, the truth functions for negation , conjunction , disjunction , conditional restricted to the set containing true and false are exactly the classical truth functions. Proposition. Suppose that a many-valued logic L contains the connectives negation , conjunction , disjunction , conditional in its language, true and false both belong to V , and its truth functions satisfy: List. Next item. the negation truth function of logic L at x equals the classical negation truth function at x if x equals true or x equals false ; Next item. the conjunction truth function of logic L at x and y equals the classical conjunction truth function at x and y , Next item. the disjunction truth function of logic L at x and y equals the classical disjunction truth function at x and y , Next item. the conditional truth function of logic L at x and y equals the classical conditional truth function at x and y , if x and y both belong to the set containing true and false . End list. Then, for any valuation v into V such that the value assigned to p by v belongs to the set containing true and false , the value of A under v in logic L equals its value under v in classical logic .
