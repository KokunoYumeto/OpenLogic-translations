Chapter. Completeness and Canonical Models.

Section. Introduction. If Sigma is a modal system, then the soundness theorem establishes that if Sigma derives formula A , then formula A is valid in any class class C of models in which all instances of all formulas in Sigma are valid. In particular that means that if logic K derives formula A then formula A is true in all models; if logic K T derives formula A then formula A is true in all reflexive models; if logic K D derives formula A then formula A is true in all serial models, etc. Completeness is the converse of soundness: that K is complete means that if a formula A is valid, formula A is derivable , for instance. Proving completeness is a lot harder to do than proving soundness. It is useful, first, to consider the contrapositive: K is complete if and only if whenever formula A is not derivable , there is a countermodel, that is, a model model M such that formula A is not true throughout model M . Equivalently (negating formula A ), we could prove that whenever not formula A is not derivable , there is a model of formula A . In the construction of such a model, we can use information contained in formula A . When we find models for specific formulas we often do the same: for example, if we want to find a countermodel to p implies necessarily q , we know that it has to contain a world where p is true and necessarily q is false. And a world where necessarily q is false means there has to be a world accessible from it where q is false. And that's all we need to know: which worlds make the propositional variables true, and which worlds are accessible from which worlds. In the case of proving completeness, however, we don't have a specific formula A for which we are constructing a model. We want to establish that a model exists for every formula A such that not formula A is not derivable in system Sigma . This is a minimal requirement, since if not formula A is derivable in system Sigma , by soundness, there is no model for formula A (in which Sigma is true). Now note that not formula A is not derivable in system Sigma if and only if formula A is Sigma -consistent. (Recall that Sigma does not derive not formula A in system Sigma and formula A does not derive falsity in system Sigma are equivalent.) So our task is to construct a model for every Sigma -consistent formula. The trick we'll use is to find a Sigma -consistent set of formulas that contains formula A , but also other formulas which tell us what the world that makes formula A true has to look like. Such sets are complete Sigma -consistent sets. It's not enough to construct a model with a single world to make formula A true, it will have to contain multiple worlds and an accessibility relation. The complete Sigma -consistent set containing formula A will also contain other formulas of the form necessarily formula B and possibly formula C . In all accessible worlds, formula B has to be true; in at least one, formula C has to be true. In order to accomplish this, we'll simply take all possible complete Sigma -consistent sets as the basis for the set of worlds. A tricky part will be to figure out when a complete Sigma -consistent set should count as being accessible from another in our model. We'll show that in the model so defined, formula A is true at a world—which is also a complete Sigma -consistent set—if and only if formula A is an element of that set. If formula A is Sigma -consistent, it will be an element of at least one complete Sigma -consistent set (a fact we'll prove), and so there will be a world where formula A is true. So we will have a single model where every Sigma -consistent formula A is true at some world. This single model is the canonical model for Sigma . End section.

Section. Lindenbaum's Lemma. Lindenbaum's Lemma establishes that every Sigma -consistent set of formulas is contained in at least one complete Sigma -consistent set.
