1% Part: normal-modal-logic2% Chapter: completeness3% Section: introduction45\documentclass[../../../include/open-logic-section]{subfiles}67\begin{document}89\olfileid{nml}{com}{int}1011\olsection{Introduction}1213If $\Sigma$ is a modal system, then the soundness theorem establishes14that if $\Sigma \Proves !A$, then $!A$ is valid in any class15$\mClass{C}$ of models in which all instances of all !!{formula}s16in~$\Sigma$ are valid. In particular that means that if $\Log{K}17\Proves !A$ then $!A$ is true in all models; if $\Log{KT} \Proves !A$18then $!A$ is true in all reflexive models; if $\Log{KD} \Proves !A$19then $!A$ is true in all serial models, etc.2021Completeness is the converse of soundness: that \Log{K} is complete22means that if !!a{formula}~$!A$ is valid, $\Proves !A$, for instance.23Proving completeness is a lot harder to do than proving soundness.  It24is useful, first, to consider the contrapositive: \Log{K} is complete25iff whenever $\Proves/ !A$, there is a countermodel, i.e., a26model~$\mModel{M}$ such that $\mSat/{M}{!A}$. Equivalently (negating27$!A$), we could prove that whenever $\Proves/ \lnot !A$, there is a28model of~$!A$.  In the construction of such a model, we can use29information contained in $!A$.  When we find models for specific30!!{formula}s we often do the same: e.g., if we want to find a31countermodel to $p \lif \Box q$, we know that it has to contain a32world where $p$ is true and $\Box q$ is false. And a world where $\Box33q$ is false means there has to be a world accessible from it where $q$34is false. And that's all we need to know: which worlds make the35!!{propositional variable}s true, and which worlds are accessible from36which worlds.3738In the case of proving completeness, however, we don't have a specific39!!{formula}~$!A$ for which we are constructing a model. We want to40establish that a model exists for every $!A$ such that41$\Proves/[\Sigma] \lnot !A$. This is a minimal requirement, since42\emph{if} $\Proves[\Sigma] \lnot !A$, by soundness, there is no model43for~$!A$ (in which $\Sigma$ is true).  Now note that $\Proves/[\Sigma]44\lnot !A$ iff $!A$ is $\Sigma$-consistent.  (Recall that $\Sigma45\Proves/[\Sigma] \lnot !A$ and $!A \Proves/[\Sigma] \lfalse$ are46equivalent.)  So our task is to construct a model for every47$\Sigma$-consistent !!{formula}.4849The trick we'll use is to find a $\Sigma$-consistent set of50!!{formula}s that contains~$!A$, but also other formulas which tell us51what the world that makes $!A$ true has to look like. Such sets are52\emph{complete} $\Sigma$-consistent sets. It's not enough to53construct a model with a single world to make~$!A$ true, it will have54to contain multiple worlds and an accessibility relation. The complete55$\Sigma$-consistent set containing~$!A$ will also contain other56!!{formula}s of the form $\Box !B$ and~$\Diamond !C$. In all57accessible worlds, $!B$ has to be true; in at least one, $!C$ has to58be true. In order to accomplish this, we'll simply take \emph{all}59possible complete $\Sigma$-consistent sets as the basis for the set of60worlds. A tricky part will be to figure out when a complete61$\Sigma$-consistent set should count as being accessible from another62in our model.6364We'll show that in the model so defined, $!A$ is true at a65world---which is also a complete $\Sigma$-consistent set---iff $!A$ is66!!a{element} of that set.  If $!A$ is $\Sigma$-consistent, it will be67!!a{element} of at least one complete $\Sigma$-consistent set (a fact68we'll prove), and so there will be a world where $!A$~is true. So we69will have a single model where every $\Sigma$-consistent70!!{formula}~$!A$ is true at some world.  This single model is the71\emph{canonical} model for~$\Sigma$.7273\end{document}

Our construction of the canonical model will16show that for each complete $\Sigma$-consistent set~$\Delta$, there is17a world in the canonical model where all and only the !!{formula}s18in~$\Delta$ are true. So Lindenbaum's Lemma guarantees that every19$\Sigma$-consistent set is true at some world in the canonical model.2021\begin{thm}[Lindenbaum's Lemma]\ollabel{thm:lindenbaum}22  If $\Gamma$ is $\Sigma$-consistent then there is a complete23  $\Sigma$-consistent set $\Delta$ extending~$\Gamma$.24\end{thm}2526\begin{proof}27Let $!A_0$, $!A_1$, \dots{} be an exhaustive listing of all formulas28of the language (repetitions are allowed). For instance, start by29listing $\Obj p_0$, and at each stage $n \ge 1$ list the finitely many30formulas of length~$n$ using only variables among $\Obj p_0$,31\dots,~$\Obj p_n$. We define sets of !!{formula}s $\Delta_n$ by32induction on~$n$, and we then set $\Delta = \bigcup_n \Delta_n$. We33first put $\Delta_0 = \Gamma$. In fact, $\Delta_n51\subseteq \Delta$ for all~$n$, since $\Delta$ is the union of52all~$\Delta_n$. At each stage of the construction, we56either add $!A_n$ or $\lnot !A_n$, and every !!{formula} appears (at57least once) in the list of all~$!A_n$. To do62this, we show that (a) if $\Delta$ were $\Sigma$-inconsistent, then63some $\Delta_n$ would be $\Sigma$-inconsistent, and (b) all $\Delta_n$64are $\Sigma$-consistent.6566So suppose $\Delta$ were $\Sigma$-inconsistent. This would mean $\Delta_n73\Proves[\Sigma] \lfalse$, i.e., $\Delta_n$ is $\Sigma$-inconsistent.7475To show that each $\Delta_n$ is $\Sigma$-consistent, we use a simple76induction on~$n$. $\Delta_0 = \Gamma$, and we assumed $\Gamma$ was77$\Sigma$-consistent. So the claim holds for $n = 0$. Now suppose it78holds for $n$, i.e., $\Delta_n$ is $\Sigma$-consistent. $\Delta_{n+1}$79is either $\Delta_n \cup \{!A_n\}$ if that is $\Sigma$-consistent,80otherwise it is $\Delta_n \cup \{\lnot!A_n\}$. In the first case,81$\Delta_{n+1}$ is clearly $\Sigma$-consistent. However, by82\olref[prf][con]{prop:consistencyfacts}\olref[prf][con]{prop:consistencyfacts-c},83either $\Delta_n \cup \{!A_n\}$ or $\Delta_n \cup \{\lnot!A_n\}$ is84consistent, so $\Delta_{n+1}$ is consistent in the other case as well.85\end{proof}8687\begin{cor}\ollabel{cor:provability-characterization}88  $\Gamma \Proves[\Sigma] !A$ if and only if $!A \in \Delta$ for89  each  complete $\Sigma$-consistent set $\Delta$ extending $\Gamma$90  (including when $\Gamma = \emptyset$, in which case we get another91  characterization of the modal system $\Sigma$.)92\end{cor}9394\begin{proof}95  Suppose $\Gamma \Proves[\Sigma] !A$, and let $\Delta$ be any96  complete $\Sigma$-consistent set extending $\Gamma$. By consistency, $!A104  \notin \Delta$.105\end{proof}106107\end{document}
