Chapter. Filtrations and Decidability.

Section. Introduction. One important question about a logic is always whether it is decidable, that is, if there is an effective procedure which will answer the question “is this formula valid.” Propositional logic is decidable: we can effectively test if a formula is a tautology by constructing a truth table, and for a given formula, the truth table is finite. But we can't obviously test if a modal formula is true in all models, for there are infinitely many of them. We can list all the finite models relevant to a given formula, since only the assignment of subsets of worlds to propositional variables which actually occur in the formula are relevant. If the accessibility relation is fixed, the possible different assignments valuation V applied to p are just all the subsets of world set W , and if the cardinality of world set W equals n there are two raised to the power n of those. If our formula A contains m propositional variables there are then two raised to the power n times m different models with n worlds. For each one, we can test if formula A is true at all worlds, simply by computing the truth value of formula A in each. Of course, we also have to check all possible accessibility relations, but there are only finitely many relations on n worlds as well (specifically, the number of subsets of the Cartesian product of world set W with itself , that is, two raised to the power n squared . If we are not interested in the logic K, but a logic defined by some class of models (for example, the reflexive transitive models), we also have to be able to test if the accessibility relation is of the right kind. We can do that whenever the frames we are interested in are definable by modal formulas (for example, by testing if axiom T and axiom four valid in the frame). So, the idea would be to run through all the finite frames, test each one if it is a frame in the class we're interested in, then list all the possible models on that frame and test if formula A is true in each. If not, stop: formula A is not valid in the class of models of interest. There is a problem with this idea: we don't know when, if ever, we can stop looking. If the formula has a finite countermodel, our procedure will find it. But if it has no finite countermodel, we won't get an answer. The formula may be valid (no countermodels at all), or it may have only an infinite countermodel, which we'll never look at. This problem can be overcome if we can show that every formula that has a countermodel has a finite countermodel. If this is the case we say the logic has the finite model property. But how would we show that a logic has the finite model property? One way of doing this would be to find a way to turn an infinite (counter)model of formula A into a finite one. If that can be done, then whenever there is a model in which formula A is not true, then the resulting finite model also makes formula A not true. That finite model will show up on our list of all finite models, and we will eventually determine, for every formula that is not valid, that it isn't. Our procedure won't terminate if the formula is valid. If we can show in addition that there is some maximum size that the finite model our procedure provides can have, and that this maximum size depends only on the formula A , we will have a size up to which we have to test finite models in our search for countermodels. If we haven't found a countermodel by then, there are none. Then our procedure will, in fact, decide the question “is formula A valid?” for any formula A . A strategy that often works for turning infinite structures into finite structures is that of “identifying” elements of the structure which behave the same way in relevant respects. If there are infinitely many worlds in model M that behave the same in relevant respects, then we may be able to collect all worlds in finitely many (possibly infinite) “classes” of such worlds. In other words, we should partition the set of worlds in the right way, that is, in such a way that each partition contains infinitely many worlds, but there are only finitely many partitions. Then we define a new model model M star where the worlds are the partitions. Finitely many partitions in the old model give us finitely many worlds in the new model, that is, a finite model. Let's call the partition a world world w is in the equivalence class of world w . We'll want it to be the case that formula A is true at world w in model M if and only if formula A is true at the equivalence class of world w in model M star , since we want the new model to be a countermodel to formula A if the old one was. This requires that we define the partition, as well as the accessibility relation of model M star in the right way. To see how this would go, first imagine we have no accessibility relation. necessarily formula B is true at world w in model M if and only if for some world v belongs to world set W , necessarily formula B is true at world v in model M , and the same for model M star , except with the equivalence class of world w and the equivalence class of world v . As a first idea, let's say that two worlds world u and world v are equivalent (belong to the same partition) if they agree on all propositional variables in model M , that is, p is true at world u in model M if and only if p is true at world v in model M . Let valuation V star assigns p to the equivalence classes of worlds w at which p is true in model M . Our aim is to show that formula A is true at world w in model M if and only if formula A is true at the equivalence class of world w in model M star . Obviously, we'd prove this by induction: The base case would be formula A is syntactically identical to p . First suppose p is true at world w in model M . Then the equivalence class of world w belongs to valuation V star by definition, so p is true at the equivalence class of world w in model M star . Now suppose that p is true at the equivalence class of world w in model M star . That means that the equivalence class of world w belongs to valuation V star applied to p , that is, for some world v equivalent to world w , p is true at world v in model M . But “ world w equivalent to world v ” means “ world w and world v make all the same propositional variables true,” so p is true at world w in model M . Now for the inductive step, for example, formula A is syntactically identical to not formula B . Then not formula B is true at world w in model M if and only if formula B is false at world w in model M if and only if formula B is false at the equivalence class of world w in model M star (by inductive hypothesis) if and only if not formula B is true at the equivalence class of world w in model M star . Similarly for the other non-modal operators. It also works for the necessity operator : suppose necessarily formula B is true at the equivalence class of world w in model M star . That means that for every the equivalence class of world u , formula B is true at the equivalence class of world u in model M star . By inductive hypothesis, for every world u , formula B is true at world u in model M . Consequently, necessarily formula B is true at world w in model M . Source anomaly note. Source semantic caveat. In the general case, where we have to also define the accessibility relation for model M star , things are more complicated. We'll call a model model M star a filtration if its accessibility relation accessibility relation R star satisfies the conditions required to make the inductive proof above go through. Then any filtration model M star will make formula A true at the equivalence class of world w if and only if model M makes formula A true at world w . However, now we also have to show that there are filtrations, that is, we can define accessibility relation R star so that it satisfies the required conditions. In order for this to work, however, we have to require that worlds world u , world v count as equivalent not just when they agree on all propositional variables, but on all sub-formulas of formula A . Since formula A has only finitely many sub-formulas, this will still guarantee that the filtration is finite. There is not just one way to define a filtration, and in order to make sure that the accessibility relation of the filtration satisfies the required properties (for example, reflexive, transitive, etc.) we have to be inventive with the definition of accessibility relation R star . Section. Preliminaries. Filtrations allow us to establish the decidability of our systems of modal logic by showing that they have the finite model property, that is, that any formula that is true (false) in a model is also true (false) in a finite model. Filtrations are defined relative to sets of formulas which are closed under subformulas. Definition. A set Gamma of formulas is closed under subformulas if it contains every subformula of a formula in Gamma . Further, Gamma is modally closed if it is closed under subformulas and moreover formula A belongs to Gamma implies necessarily A and possibly A both belong to Gamma . End definition. For instance, given a formula A , the set of all its sub-formulas is closed under sub-formulas. When we're defining a filtration of a model through the set of sub-formulas of formula A , it will have the property we're after: it makes formula A true (false) if and only if the original model does. The set of worlds of a filtration of model M through Gamma is defined as the set of all equivalence classes of the following equivalence relation. Definition. End displayed expression. End definition. Proposition. Given model M and Gamma , the filtration equivalence relation as defined above is an equivalence relation, that is, it is reflexive, symmetric, and transitive. End proposition. Proof. The relation the filtration equivalence relation is reflexive, since world w makes exactly the same formulas from Gamma true as itself. It is symmetric since if world u makes the same formulas from Gamma true as world v , the same holds for world v and world u . The relation the filtration equivalence relation , like any equivalence relation, divides world set W into partitions, that is, subsets of world set W which are pairwise disjoint, and together cover all of world set W . Every world w belongs to world set W is an element of one of the partitions, namely of the equivalence class of world w , since world w is equivalent to world w . So the partitions the equivalence class of world w cover all of world set W . They are pairwise disjoint, for if world u belongs to the equivalence class of world w and world u belongs to the equivalence class of world v , then world u is equivalent to world w and world u is equivalent to world v , and by symmetry and transitivity, world w is equivalent to world v , and so the equivalence class of world w equals the equivalence class of world v . Section. Examples of Filtrations. We have not yet shown that there are any filtrations. But indeed, for any model model M , there are many filtrations of model M through Gamma . We identify two, in particular: the finest and coarsest filtrations. Filtrations of the same models will differ in their accessibility relation (as the definition of a filtration stipulates directly what world set W star and valuation V star should be). Section. Filtrations are Finite. We've defined filtrations for any set Gamma that is closed under sub-formulas. Nothing in the definition itself guarantees that filtrations are finite. No two different classes the equivalence class of world u and the equivalence class of world v correspond to the same subset of Gamma . Section. Sfive is Decidable.
