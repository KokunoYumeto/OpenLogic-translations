Chapter. Frame Definability.

Section. Introduction. One question that interests modal logicians is the relationship between the accessibility relation and the truth of certain formulas in models with that accessibility relation. For instance, suppose the accessibility relation is reflexive, that is, for every w belongs to W , R relates w to itself . In other words, every world is accessible from itself. That means that when necessarily A is true at a world w , w itself is among the accessible worlds at which A must therefore be true. So, if the accessibility relation R of M is reflexive, then whatever world w and formula A we take, if necessarily A, then A will be true there (in other words, the schema if necessarily p, then p and all its substitution instances are true in M ). The converse, however, is false. It's not the case, for example, that if if necessarily p, then p is true in M , then R is reflexive. For we can easily find a non-reflexive model M where if necessarily p, then p is true at all worlds: take the model with a single world w , not accessible from itself, but with w belongs to V of p . By picking the truth value of p suitably, we can make if necessarily A, then A true in a model that is not reflexive. The solution is to remove the variable assignment V from the equation. If we require that if necessarily p, then p is true at all worlds in M , regardless of which worlds are in V of p , then it is necessary that R is reflexive. For in any non-reflexive model, there will be at least one world w such that not R relates w to itself . If we set V of p equals W with w removed , then p will be true at all worlds other than w , and so at all worlds accessible from w (since w is guaranteed not to be accessible from w , and w is the only world where p is false). On the other hand, p is false at w , so if necessarily p, then p is false at w . This suggests that we should introduce a notation for model structures without a valuation: we call these frames. A frame F is simply a pair the ordered pair W, R consisting of a set of worlds with an accessibility relation. Every model the ordered triple W, R, V is then, as we say, based on the frame the ordered pair W, R . Conversely, a frame determines the class of models based on it; and a class of frames determines the class of models which are based on any frame in the class. And we can define A is valid in frame F , the notion of a formula being valid in a frame as: A is true in modal model M for all M based on F . With this notation, we can establish correspondence relations between formulas and classes of frames: for example, the conditional from necessarily p to p is valid in frame F if, and only if, F is reflexive. End section.

Although we will focus on the five classical formulas axiom D, axiom T, axiom B, axiom four, and axiom five, we record in the table of five additional correspondence facts a few more properties of accessibility relations. The accessibility relation R is partially functional, if from every world at most one world is accessible. If it is the case that from every world exactly one world is accessible, we call it functional. (Thus the functional relations are precisely those that are both serial and partially functional). They are called “functional” because the accessibility relation operates like a (partial) function. A relation is weakly dense if whenever R relates u to v , there is a w “between” u and v . So weakly dense relations are in a sense the opposite of transitive relations: in a transitive relation, whenever you can reach v from u by a detour via w , you can reach v from u directly; in a weakly dense relation, whenever you can reach v from u directly, you can also reach it by a detour via some w . Section. Frames. Definition. A frame is a pair frame F equals the ordered pair W, R where W is a non-empty set of worlds and R a binary relation on W . A model M is based on a frame frame F equals the ordered pair W, R if and only if modal model M equals the ordered triple W, R, V for some valuation V . End definition. Definition. If F is a frame, we say that A is valid in F , A is valid in frame F , if A is true in modal model M for every model M based on F . If F is a class of frames, we say A is valid in F , A is valid in the class of frames F , if and only if A is valid in frame F for every frame frame F belongs to the class of frames F . End definition. The reason frames are interesting is that correspondence between schemas and properties of the accessibility relation R is at the level of frames, not of models. For instance, although axiom T is true in all reflexive models, not every model in which axiom T is true is reflexive. However, it is true that not only is axiom T valid on all reflexive frames, also every frame in which axiom T is valid is reflexive. Remark. Validity in a class of frames is a special case of the notion of validity in a class of models: A is valid in the class of frames F if and only if A is valid in the class of models C where C is the class of all models based on a frame in F . Obviously, if a formula or a schema is valid, that is, valid with respect to the class of all models, it is also valid with respect to any class F of frames. End remark. Disclosed reader correction. The source remark is announced as a remark and its closing boundary is preserved. Its prose and mathematics are unchanged. Original source remains available in Source view. End note. End section.

Section. First-order Definability. We've seen that a number of properties of accessibility relations of frames can be defined by modal formulas. For instance, symmetry of frames can be defined by the formula axiom B, if p, then necessarily possibly p . The conditions we've encountered so far can all be expressed by first-order formulas in a language involving a single two-place predicate symbol. For instance, symmetry is defined by for every x and every y, if Q relates x to y, then Q relates y to x in the sense that a first-order structure M with the domain of structure M equals W and the interpretation of Q in structure M equals R satisfies the preceding formula if and only if R is symmetric. A class F of frames is first-order definable if there is a sentence A in the first-order language with a single two-place predicate symbol Q such that frame F, equal to the ordered pair W, R, belongs to the class of frames F if and only if structure M satisfies A in the first-order structure M with the domain of structure M equals W and the interpretation of Q in structure M equals R . Section. Equivalence Relations and Sfive. The modal logic Sfive is characterized as the set of formulas valid on all universal frames, that is, every world is accessible from every world, including itself. In such a scenario, the necessity operator corresponds to necessity and the possibility operator to possibility: necessarily A is true if A is true at every world, and possibly A is true if A is true at some world. It turns out that Sfive can also be characterized as the formulas valid on all reflexive, symmetric, and transitive frames, that is, on all equivalence relations. Definition. A binary relation R on W is an equivalence relation if and only if it is reflexive, symmetric and transitive. A relation R on W is universal if and only if R relates u to v for all u and v belong to W . End definition. Since axiom T, axiom B, and axiom four characterize the reflexive, symmetric, and transitive frames, the frames where the accessibility relation is an equivalence relation are exactly those in which all three formulas are valid. Section. Second-order Definability. Not every frame property definable by modal formulas is first-order definable. However, if we allow quantification over one-place predicates (that is, monadic second-order quantification), we define all modally definable frame properties.
