1% Part: normal-modal-logic2% Chapter: frame-correspondence3% Section: introduction45\documentclass[../../../include/open-logic-section]{subfiles}67\begin{document}89\olfileid{nml}{frd}{int}1011\olsection{Introduction}1213One question that interests modal logicians is the relationship14between the accessibility relation and the truth of certain15!!{formula}s in models with that accessibility relation. For instance,16suppose the accessibility relation is reflexive, i.e., for every $w17\in W$, $Rww$. In other words, every world is accessible from18itself. That means that when $\Box !A$ is true at a world~$w$, $w$19itself is among the accessible worlds at which~$!A$ must therefore be20true. So, if the accessibility relation~$R$ of~$\mModel{M}$ is21reflexive, then whatever world $w$ and formula $!A$ we take, $\Box !A22\lif !A$ will be true there (in other words, the schema $\Box p \lif23p$ and all its substitution instances are true in~$\mModel{M}$).2425The converse, however, is false. It's not the case, e.g., that if26$\Box p \lif p$ is true in~$\mModel{M}$, then $R$ is reflexive. For we27can easily find a non-reflexive model~$\mModel{M}$ where $\Box p \lif28p$ is true at all worlds: take the model with a single world~$w$, not29accessible from itself, but with $w \in V(p)$. By picking the truth30value of $p$ suitably, we can make $\Box !A \lif !A$ true in a model31that is not reflexive.3233The solution is to remove the variable assignment~$V$ from the34equation. If we require that $\Box p \lif p$ is true at all worlds35in~$\mModel{M}$, regardless of which worlds are in~$V(p)$, then it is36necessary that $R$ is reflexive. For in any non-reflexive model, there37will be at least one world~$w$ such that not $Rww$. If we set $V(p) =38W \setminus \{w\}$, then $p$ will be true at all worlds other39than~$w$, and so at all worlds accessible from~$w$ (since $w$ is40guaranteed not to be accessible from~$w$, and $w$ is the only world41where~$p$ is false). On the other hand, $p$ is false at $w$, so $\Box42p \lif p$ is false at~$w$.4344This suggests that we should introduce a notation for model structures45without a valuation: we call these \emph{frames}. A frame $\mModel{F}$46is simply a pair $\tuple{W, R}$ consisting of a set of worlds with an47accessibility relation. Every model $\tuple{W, R, V}$ is then, as we48say, \emph{based on} the frame $\tuple{W, R}$. Conversely, a frame49determines the class of models based on it; and a class of frames50determines the class of models which are based on any frame in the51class. And we can define $\mModel{F} \Entails !A$, the notion of !!a{formula}52being \emph{valid} in a frame as: $\mSat{M}{!A}$ for all $\mModel{M}$53based on~$\mModel{F}$.5455With this notation, we can establish correspondence relations between56!!{formula}s and classes of frames: e.g., $\mModel{F} \Entails \Box p \lif p$57if, and only if, $\mModel{F}$ is reflexive.5859\end{document}

1% Part: normal-modal-logic2% Chapter: frame-correspondence3% Section: frames45\documentclass[../../../include/open-logic-section]{subfiles}67\begin{document}89\olfileid{nml}{frd}{fra}1011\olsection{Frames}1213\begin{defn}14  A \emph{frame} is a pair $\mModel{F} = \tuple{W,R}$ where $W$ is a15  non-empty set of worlds and $R$ a binary relation on~$W$. A model16  $\mModel{M}$ is \emph{based on} a frame $\mModel{F} = \tuple{W,R}$17  if and only if $\mModel{M} = \tuple{W, R, V}$ for some valuation $V$.18\end{defn}1920\begin{defn}21  If $\mModel{F}$ is a frame, we say that $!A$ is \emph{valid in22    $\mModel{F}$,} $\mModel{F} \Entails !A$, if $\mSat{M}{!A}$ for23  every model~$\mModel{M}$ based on~$\mModel{F}$.24  25  If $\mClass{F}$ is a class of frames, we say $!A$ is \emph{valid in26    $\mClass{F}$,} $\mClass{F} \Entails !A$, iff $\mModel{F} \Entails27  !A$ for every frame~$\mModel{F} \in \mClass{F}$.28\end{defn}2930The reason frames are interesting is that correspondence between31schemas and properties of the accessibility relation~$R$ is at the32level of frames, \emph{not of models}. For instance, although \Ax{T}33is true in all reflexive models, not every model in which \Ax{T} is34true is reflexive. However, it \emph{is} true that not only is \Ax{T}35\emph{valid} on all reflexive \emph{frames}, also every frame in36which \Ax{T} is valid is reflexive.3738\begin{rem}39Validity in a class of frames is a special case of the notion of40validity in a class of models: $\mClass{F} \Entails !A$ iff41$\mClass{C} \Entails !A$ where $\mClass{C}$ is the class of all models42based on a frame in~$\mClass{F}$.4344Obviously, if !!a{formula} or a schema is valid, i.e., valid with45respect to the class of \emph{all} models, it is also valid with46respect to any class~$\mClass{F}$ of frames.47\end{rem}4849\end{document}
