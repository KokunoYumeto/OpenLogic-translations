Rules and derivation

Explanation

Axiomatic derivations are perhaps the simplest derivation system for logic. A derivation is just a sequence of formulas. To count as a derivation, every formula in the sequence must either be an instance of an axiom, or must follow from one or more formulas that precede it in the sequence by a rule of inference. A derivation derives its last formula.

Definition of an axiomatic derivation from Gamma

If Gamma is a set of formulas of language L then a derivation from Gamma is a finite sequence A sub one, and so on, A sub n of formulas where for each i is less than or equal to n one of the following holds:

  1. A sub i belongs to Gamma; or

  2. A sub i is an axiom; or

  3. A sub i follows from some A sub j (and A sub k) with j is less than i (and k is less than i) by a rule of inference.

What counts as a correct derivation depends on which inference rules we allow (and of course what we take to be axioms). And an inference rule is an if-then statement that tells us that, under certain conditions, a step A sub i in a derivation is a correct inference step.

Definition of a rule of inference

A rule of inference gives a sufficient condition for what counts as a correct inference step in a derivation from Gamma.

For instance, since any one-element sequence A with A belongs to Gamma trivially counts as a derivation, the following might be a very simple rule of inference:

If A belongs to Gamma, then A is always a correct inference step in any derivation from Gamma.

Similarly, if A is one of the axioms, then A by itself is a derivation, and so this is also a rule of inference:

If A is an axiom, then A is a correct inference step.

It gets more interesting if the rule of inference appeals to formulas that appear before the step considered. The following rule is called modus ponens:

If B implies A and B occur higher up in the derivation, then A is a correct inference step.

If this is the only rule of inference, then our definition of derivation above amounts to this: A sub one, and so on, A sub n is a derivation if and only if for each i is less than or equal to n one of the following holds:

  1. A sub i belongs to Gamma; or

  2. A sub i is an axiom; or

  3. for some j is less than i, A sub j is B implies A sub i, and for some k is less than i, A sub k is B.

The last clause says that A sub i follows from A sub j (B implies A sub i) and A sub k (B) by modus ponens. If we can go from one to n, and each time we find a formula A sub i that is either in Gamma, an axiom, or which a rule of inference tells us that it is a correct inference step, then the entire sequence counts as a correct derivation.

Definition of derivability in Rules and derivations

A formula A is derivable from Gamma, written the complete formula A is axiomatically derivable from premise set Gamma, if there is a derivation from Gamma ending in A.

Definition of theoremhood in Rules and derivations

A formula A is a theorem if there is a derivation of A from the empty set. We write the complete formula A is derivable with no premises if A is a theorem and the complete formula A is not derivable with no premises if it is not.

Proof-Theoretic Notions

Explanation

Just as we've defined a number of important semantic notions (tautology, entailment, satisfiability), we now define corresponding proof-theoretic notions. These are not defined by appeal to satisfaction of sentences in structures, but by appeal to the derivability or nonderivability of certain formulas. It was an important discovery that these notions coincide. That they do is the content of the soundness and completeness theorems.

Definition of derivability in Proof-Theoretic Notions

A formula A is derivable from Gamma, written the complete formula A is axiomatically derivable from premise set Gamma, if there is a derivation from Gamma ending in A.

Definition of theoremhood in Proof-Theoretic Notions

A formula A is a theorem if there is a derivation of A from the empty set. We write the complete formula A is derivable with no premises if A is a theorem and the complete formula A is not derivable with no premises if it is not.

Definition of consistency

A set Gamma of formulas is consistent if and only if the complete formula falsum is not axiomatically derivable from premise set Gamma; it is inconsistent otherwise.

Proposition: reflexivity of derivability

If A belongs to Gamma, then the complete formula A is axiomatically derivable from premise set Gamma.

Proof

The formula A by itself is a derivation of A from Gamma.

End of proof.

Proposition: monotonicity of derivability

If Gamma is a subset of Delta and the complete formula A is axiomatically derivable from premise set Gamma, then the complete formula A is axiomatically derivable from premise set Delta.

Proof

Any derivation of A from Gamma is also a derivation of A from Delta.

End of proof.

Proposition: transitivity of derivability

If the complete formula A is axiomatically derivable from premise set Gamma and the complete formula B is axiomatically derivable from the union of the singleton set containing A and Delta, then the complete formula B is axiomatically derivable from the union of premise sets Gamma and Delta.

Proof

Then there is a derivation B sub one, and so on, B sub l equals B from the set containing A union Delta. Some of the steps in that derivation will be correct because of a rule which refers to a prior line B sub i equals A. The Deduction Theorem

As we've seen, giving derivations in an axiomatic system is cumbersome, and derivations may be hard to find. Rather than actually write out long lists of formulas, it is generally easier to argue that such derivations exist, by making use of a few simple results. We've already established three such results: Reference to the reflexivity proposition for derivability says we can always assert that the complete formula A is axiomatically derivable from premise set Gamma when we know that A belongs to Gamma. Reference to the monotonicity proposition for derivability says that if the complete formula A is axiomatically derivable from premise set Gamma then also the complete formula A is axiomatically derivable from the union of Gamma and the singleton set containing B. And Reference to the transitivity proposition for derivability implies that if the complete formula A is axiomatically derivable from premise set Gamma and the complete formula B is axiomatically derivable from premise A, then the complete formula B is axiomatically derivable from premise set Gamma. Here's another simple result, a “meta”-version of modus ponens:

If the complete formula A is axiomatically derivable from premise set Gamma and the complete formula A implies B is axiomatically derivable from premise set Gamma, then the complete formula B is axiomatically derivable from premise set Gamma.

The most important result we'll use in this context is the deduction theorem:

The Deduction Theorem

the complete formula B is axiomatically derivable from the union of Gamma and the singleton set containing A if and only if the complete formula A implies B is axiomatically derivable from premise set Gamma.

Proof

The “if” direction is immediate. If the complete formula A implies B is axiomatically derivable from premise set Gamma then also the complete formula A implies B is axiomatically derivable from the union of Gamma and the singleton set containing A by Reference to the monotonicity proposition for derivability. Also, the complete formula A is axiomatically derivable from the union of Gamma and the singleton set containing A by Reference to the reflexivity proposition for derivability. So, by Reference to the meta-level modus ponens proposition, the complete formula B is axiomatically derivable from the union of Gamma and the singleton set containing A.

For the “only if” direction, we proceed by induction on the length of the derivation of B from Gamma union the set containing A.

For the induction basis, we prove the claim for every derivation of length one. A derivation of B from Gamma union the set containing A of length one consists of B by itself; and if it is correct B is either B belongs to the union of Gamma and the singleton set containing A or is an axiom. If B belongs to Gamma or is an axiom, then the complete formula B is axiomatically derivable from premise set Gamma. Proposition: removing a provable assumption from an inconsistency

Proof

Soundness

Explanation

A derivation system, such as axiomatic deduction, is sound if it cannot derive things that do not actually hold. Soundness is thus a kind of guaranteed safety property for derivation systems. Depending on which proof theoretic property is in question, we would like to know for instance, that

  1. every derivable A is valid;

  2. if A is derivable from some others Gamma, it is also a consequence of them;

  3. if a set of formulas Gamma is inconsistent, it is unsatisfiable.

These are important properties of a derivation system. If any of them do not hold, the derivation system is deficient—it would derive too much. Consequently, establishing the soundness of a derivation system is of the utmost importance.

Proposition: every propositional axiom is a tautology

If A is an axiom, then valuation v satisfies A for each valuation v.

Proof

Do truth tables for each axiom to verify that they are tautologies.

End of proof.

Theorem: soundness of axiomatic deduction

If the complete formula A is axiomatically derivable from premise set Gamma then the complete formula A is semantically entailed by premise set Gamma.

Proof

By induction on the length of the derivation of A from Gamma. If there are no steps justified by inferences, then all formulas in the derivation are either instances of axioms or are in Gamma. By the previous proposition, all the axioms are tautologies, and hence if A is an axiom then the complete formula A is semantically entailed by premise set Gamma. If A belongs to Gamma, then trivially the complete formula A is semantically entailed by premise set Gamma.

If the last step of the derivation of A is justified by modus ponens, then there are formulas B and B implies A in the derivation, and the induction hypothesis applies to the part of the derivation ending in those formulas (since they contain at least one fewer step justified by an inference). So, by induction hypothesis, the complete formula B is semantically entailed by premise set Gamma and the complete formula B implies A is semantically entailed by premise set Gamma. Then the complete formula A is semantically entailed by premise set Gamma by Reference to the Semantic Deduction Theorem.

End of proof.

Corollary: every theorem is a tautology

If the complete formula A is derivable with no premises, then A is a tautology.

Corollary: every satisfiable premise set is consistent

If Gamma is satisfiable, then it is consistent.

Proof

We prove the contrapositive. Suppose that Gamma is not consistent. Then the complete formula falsum is axiomatically derivable from premise set Gamma, i.e., there is a derivation of falsum from Gamma. By Reference to the soundness theorem for axiomatic deduction, any valuation v that satisfies Gamma must satisfy falsum. Since valuation v does not satisfy falsum for every valuation v, no valuation v can satisfy Gamma, i.e., Gamma is not satisfiable.

End of proof.
