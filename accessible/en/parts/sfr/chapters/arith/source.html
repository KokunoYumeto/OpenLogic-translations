  12. \olsection{From $\Nat$ to $\Int$}
  14. Here are two basic realisations:
  15. \begin{enumerate}
  16. \item Every integer can be written in the form $n - m$, with $n, m \in\Nat$.
  17. \item The information encoded in an expression $n - m$ can equally be encoded by an ordered pair $\tuple{n, m}$.
  18. \end{enumerate}
  19. We already know that the ordered pairs of natural numbers are the !!{element}s of $\Nat^2$. And we are assuming that we understand $\Nat$. So here is a na\"{i}ve suggestion, based on the two realisations we have had: \emph{let's treat integers as ordered pairs of natural numbers}.
  21. In fact, this suggestion is too na\"{i}ve. Obviously we want it to be the case that $0- 2 = 4 - 6$. But evidently $\tuple{0, 2 }\neq \tuple{4, 6}$. So we cannot simply say that $\Nat^2$ is the set of integers.
  23. Generalising from the preceding problem, what we want is the following:
  24. $$a - b = c - d \text{ iff }a + d = c + b$$
  25. (It should be obvious that this is how integers are \emph{meant} to behave: just add $b$ and $d$ to both sides.) And the easy way to guarantee this behaviour is just to define an equivalence relation between ordered pairs, $\Intequiv$, as follows:
  26. $$\tuple{ a, b } \Intequiv \tuple{c, d}\text{ iff }a + d = c + b$$
  27. We now have to show that this is an equivalence relation.
  28. \begin{prop} $\Intequiv$ is an equivalence relation.
  29. \end{prop}
  30. \begin{proof}
  31. We must show that $\Intequiv$ is reflexive, symmetric, and transitive.
  33. \emph{Reflexivity:} Evidently $\tuple{a, b} \Intequiv \tuple{a, b}$, since $a + b = b + a$.
  35. \emph{Symmetry:} Suppose $\tuple{a, b} \Intequiv \tuple{c, d}$, so $a + d = c + b$. Then $c + b = a + d$, so that $\tuple{c, d} \Intequiv \tuple{a, b}$.
  37. \emph{Transitivity:} Suppose $\tuple{a, b} \Intequiv \tuple{c, d}\Intequiv \tuple{m, n}$. So $a + d = c + b$ and $c + n = m + d$. So $a + d + c + n = c + b + m + d$, and so $a + n = m + b$. Hence $\tuple{a, b } \Intequiv \tuple{m, n}$.
  38. \end{proof}
  40. Now we can use this equivalence relation to take equivalence classes:
  42. \begin{defn}
  43. The integers are the equivalence classes, under $\Intequiv$, of ordered pairs of natural numbers; that is, $\Int = \equivclass{\Nat^2}{\Intequiv}$.
  44. \end{defn}
  46. Now, one might have plenty of different \emph{philosophical} reactions to this stipulative definition. Before we consider those reactions, though, it is worth continuing with some of the technicalities.
  48. Having said what the integers are, we shall need to define basic functions and relations on them. Let's write $\equivrep{m, n}{\Intequiv}$ for the equivalence class under $\Intequiv$ with $\tuple{m, n}$ as !!a{element}.\footnote{Note: using the notation introduced in \olref[sfr][rel][eqv]{def:equivalenceclass}, we would have written $\equivrep{\tuple{m,n}}{\Intequiv}$ for the same thing. But that's just a bit harder to read.} That is:
  49. $$\equivrep{m, n}{\Intequiv} = \Setabs{\tuple{a, b} \in \Nat^2}{\tuple{a, b}\Intequiv \tuple{m, n}}$$
  50. So now we offer some definitions:
  51. \begin{align*}
  52. \equivrep{a, b}{\Intequiv} + \equivrep{c, d}{\Intequiv} &= \equivrep{a + c, b + d}{\Intequiv}\\
  53. \equivrep{a, b}{\Intequiv} \times \equivrep{c, d}{\Intequiv} &= \equivrep{a c + b d, a d + b c}{\Intequiv}\\
  54. \equivrep{a, b}{\Intequiv} \leq \equivrep{c, d}{\Intequiv} &\text{ iff }a + d \leq b + c
  55. \end{align*}
  56. (As is common, I'm using `$ab$' stand for `$(a \times b)$', just to make the axioms easier to read.) Now, we need to make sure that these definitions behave as they \emph{ought} to. Spelling out what this means, and checking it through, is rather laborious; we relegate the details to \olref[check]{sec}. But the short point is: everything works!
  58. One final thing remains. We have constructed the integers using
  59. natural numbers. But this will mean that the natural numbers \emph{are
  60. not themselves integers}. We will return to the philosophical
  61. significance of this in \olref[ref]{sec}. On a purely technical front,
  62. though, we will need some way to be able to treat natural numbers
  63. \emph{as} integers. The idea is quite easy: for each $n \in \Nat$, we
  64. just stipulate that $n_\Int = \equivrep{n, 0}{\Intequiv}$. We need to
  65. confirm that this definition is well-behaved, i.e., that for any $m, n
  66. \in \Nat$
  67. \begin{align*}
  68. (m + n)_\Int &= m_\Int + n_\Int\\
  69. (m \times n)_\Int &= m_\Int \times n_\Int\\
  70. m \leq n &\liff m_\Int \leq n_\Int
  71. \end{align*}
  72. But this is all pretty straightforward. For example, to show that the
  73. second of these obtains, we can simply help ourselves to the behaviour
  74. of the natural numbers and reason as follows:
  77. \begin{align*}
  79. (m \times n)_\Int &= \equivrep{m \times n, 0}{\Intequiv} \\
  80. &= \equivrep{m \times n + 0 \times 0, m \times 0 + 0 \times n}{\Intequiv} \\
  81. &= \equivrep{m, 0}{\Intequiv} \times \equivrep{n, 0}{\Intequiv} \\
  82. &= m_\Int \times n_\Int
  83. \end{align*}
  85. We leave it as an exercise to confirm that the other two conditions hold.
  86. \begin{prob}
  87. Show that $(m + n)_\Int = m_\Int + n_\Int$ and $m \leq n \liff m_\Int \leq n_\Int$, for any $m, n \in \Nat$.
  88. \end{prob}

  93. \olsection{From $\Int$ to $\Rat$}
  95. We just saw how to construct the integers from the natural numbers,
  96. using some na\"{i}ve set theory. We shall now see how to construct the
  97. rationals from the integers in a very similar way. Our initial
  98. realisations are:
  99. \begin{enumerate}
  100. \item Every rational can be written in the form $\nicefrac{i}{j}$,
  101. where both $i$ and $j$ are integers but $j$ is non-zero.
  102. \item The information encoded in an expression $\nicefrac{i}{j}$
  103. can equally be encoded in an ordered pair $\tuple{ i, j}$.
  104. \end{enumerate}
  105. The obvious approach would be to think of the rationals \emph{as}
  106. ordered pairs drawn from $\Int \times (\Int \setminus \{0_\Int\})$. As
  107. before, though, that would be a bit too na\"ive, since we want
  108. $\nicefrac{3}{2} = \nicefrac{6}{4}$, but $\tuple{ 3, 2}\neq \tuple{ 6,
  109. 4}$. More generally, we will want the following:
  110. \[
  111. \nicefrac{a}{b} = \nicefrac{c}{d} \text{ iff } a \times d = b \times c
  112. \]
  113. To get this, we define an {equivalence relation} on $\Int \times
  114. (\Int \setminus \{0_\Int\})$ thus:
  115. \[
  116. \tuple{ a, b }\Ratequiv \tuple{ c, d} \text{ iff }a \times d = b \times c
  117. \]
  118. We must check that this is an equivalence relation. This is very much
  119. like the case of $\Intequiv$, and we will leave it as an exercise.
  120. \begin{prob}
  121. Show that $\Ratequiv$ is an equivalence relation.
  122. \end{prob}
  123. But it allows us to say:
  124. \begin{defn}
  125. The rationals are the equivalence classes, under $\Ratequiv$, of pairs
  126. of integers (whose second element is non-zero). That is, $\Rat =
  127. \equivclass{(\Int \times (\Int\setminus \{0_\Int\}))}{\Ratequiv}$.
  128. \end{defn}
  130. As with the integers, we also want to define some basic operations.
  131. Where $\equivrep{i,j}{\Ratequiv}$ is the equivalence class under
  132. $\Ratequiv$ with $\tuple{i, j}$ as !!a{element}, we say:
  133. \begin{align*}
  134. \equivrep{a, b}{\Ratequiv} + \equivrep{c, d}{\Ratequiv} &= \equivrep{ad + bc, bd}{\Ratequiv}\\
  135. \equivrep{a, b}{\Ratequiv} \times \equivrep{c, d}{\Ratequiv} &= \equivrep{a c, b d}{\Ratequiv}.
  136. \intertext{To define $r \leq s$ on these rationals, we use the fact that
  137. $r \le s$ iff $s - r$ is not negative, i.e., $r - s$ can be written as
  138. $\nicefrac{i}{j}$ with $i$ non-negative and $j$~positive:}
  139. \equivrep{a, b}{\Ratequiv} \leq \equivrep{c, d}{\Ratequiv} &\text{ iff }
  140. \equivrep{c, d}{\Ratequiv} - \equivrep{a, b}{\Ratequiv} =
  141. \equivrep{i_\Int, j_\Int}{\Ratequiv}
  142. \end{align*}
  143. for some $i \in \Nat$ and $0 \neq j \in \Nat$.
  145. We then need to check that these definitions behave as they
  146. \emph{ought} to; and we relegate this to \olref[check]{sec}. But they
  147. indeed do!{} Finally, we want some way to treat integers \emph{as}
  148. rationals; so for each $i \in \Int$, we stipulate that $i_\Rat =
  149. \equivrep{i, 1_\Int}{\Ratequiv}$. Again, we check that all of this
  150. behaves correctly in \olref[check]{sec}.
  152. \begin{prob}
  153. Show that $(i + j)_\Rat = i_\Rat+ j_\Rat$ and $(i \times j)_\Rat =
  154. i_\Rat \times j_\Rat$ and $i \leq j \liff i_\Rat \leq j_\Rat$, for any
  155. $i, j \in \Int$.
  156. \end{prob}

  162. \olsection{The Real Line}
  164. The next step is to show how to construct the reals from the
  165. rationals. Before that, we need to understand what is
  166. \emph{distinctive} about the reals.
  168. The reals behave very much like the rationals. (Technically, both are
  169. examples of \emph{ordered fields}; for the definition of this, see
  170. \olref[check]{orderedfield}.) Now, if you worked through the exercises
  171. to \olref[sfr][siz][]{chap}, you will know that there are strictly
  172. more reals than rationals, i.e., that $\cardless{\Rat}{\Real}$. This
  173. was first proved by Cantor. But it's been known for about two and a
  174. half millennia that there are irrational numbers, i.e., reals which
  175. are not rational. Indeed:
  177. \begin{thm}\ollabel{root2irrational}
  178. $\sqrt{2}$ is not rational, i.e., $\sqrt{2} \notin \Rat$
  179. \end{thm}
  181. \begin{proof}
  182. Suppose, for reductio, that $\sqrt{2}$ is rational. So $\sqrt{2} =
  183. \nicefrac{m}{n}$ for some natural numbers $m$ and $n$. Indeed, we can
  184. choose $m$ and $n$ so that the fraction cannot be reduced any further.
  185. Re-organising, $m^{2} = 2n^{2}$. From here, we can complete the proof
  186. in two ways:
  188. \emph{First, geometrically} (following Tennenbaum).\footnote{This
  189. proof is reported by \cite{Conway2006}.} Consider these squares:
  190. \begin{center}
  191. \begin{tikzpicture}
  192. \draw[thick] (0,0) rectangle (3,3);
  193. \draw[thick, fill=red!50] (0,0) rectangle (2.3,2.3);
  194. \draw[thick, fill=yellow!50] (0.7,0.7) rectangle (3, 3);
  195. \draw[thick, fill=orange!50] (0.7,0.7) rectangle (2.3, 2.3);
  196. \draw[<->] (4, 0.7)--(4, 3);
  197. \node at (4.25, 1.85) (n) {$n$};
  198. \draw[<->] (5, 0)--(5, 3);
  199. \node at (5.25, 1.5) (m) {$m$};
  200. \end{tikzpicture}
  201. \end{center}
  202. Since $m^2 = 2n^2$, the region where the two squares of side $n$
  203. overlap has the same area as the region which neither of the two
  204. squares cover; i.e., the area of the orange square equals the sum of
  205. the area of the two unshaded squares. So where the orange square has
  206. side $p$, and each unshaded square has side $q$, $p^2 = 2q^2$. But now
  207. $\sqrt{2} = \nicefrac{p}{q}$, with $p < m$ and $q < n$ and $p, q \in
  208. \Nat$. This contradicts the fact that $m$ and $n$ were chosen to be as
  209. small as possible.
  211. \emph{Second, formally.} Since $m^{2} = 2n^{2}$, it follows that $m$
  212. is even. (It is easy to show that, if $x$ is odd, then $x^2$ is odd.)
  213. So $m = 2r$, for some $r \in \Nat$. Rearranging, $2r^2 = n^2$,
  219. so $n$ is also even. So both $m$ and $n$ are even, and hence the
  220. fraction $\nicefrac{m}{n}$ \emph{can} be reduced further.
  221. Contradiction!
  222. \end{proof}
  224. In passing, this diagrammatic proof allows us to revisit the material from \olref[his][set][mythology]{sec}. Tennenbaum (1927--2006) was a thoroughly modern mathematician; but the proof is undeniably lovely, completely rigorous, and appeals to geometric intuition!
  226. In any case: the reals are ``more expansive'' than the rationals. In some sense, there are ``gaps'' in the rationals, and these are filled by the reals. Weierstrass realised that this describes a single property of the real numbers, which distinguishes them from the rationals, namely the Completeness Property: \emph{Every non-empty set of real numbers with an upper bound has a least upper bound.}
  228. It is easy to see that the rationals do not have the Completeness Property. For example, consider the set of rationals less than $\sqrt{2}$, i.e.:
  229. \[
  230. \Setabs{p \in \Rat}{p^2 < 2 \text{ or }p < 0}
  231. \]
  232. This has an upper bound in the rationals; its !!{element}s< are all smaller than $3$, for example. But what is its least upper bound? We want to say `$\sqrt{2}$'; but we have just seen that $\sqrt{2}$ is \emph{not} rational. And there is no \emph{least} rational number greater than $\sqrt{2}$. So the set has an upper bound but no least upper bound. Hence the rationals lack the Completeness Property.
  234. By contrast, the continuum ``morally ought'' to have the Completeness Property. We do not just want $\sqrt{2}$ to be a real number; we want to fill all the ``gaps'' in the rational line. Indeed, we want the continuum itself to have no ``gaps'' in it. That is just what we will get via Completeness.

  240. \olsection{From $\Rat$ to $\Real$}
  242. In essence, the Completeness Property shows that any point $\alpha$ of
  243. the real line divides that line into two halves perfectly: those for
  244. which $\alpha$ is the least upper bound, and those for which $\alpha$
  245. is the greatest lower bound. To \emph{construct} the real numbers from
  246. the rational numbers, Dedekind suggested that we simply think of the
  247. reals as the \emph{cuts} that partition the rationals. That is, we
  248. identify $\sqrt{2}$ with the \emph{cut} which separates the rationals
  249. $< \sqrt{2}$ from the rationals $> \sqrt{2}$.
  251. Let's tidy this up. If we cut the rational numbers into two halves, we
  252. can uniquely identify the partition we made just by considering its
  253. \emph{bottom} half. So, getting precise, we offer the following
  254. definition:
  256. \begin{defn}[Cut]
  257. A \emph{cut} $\alpha$ is any non-empty proper
  258. initial segment of the rationals with no greatest element. That is,
  259. $\alpha$ is a cut iff:
  260. \begin{enumerate}
  261. \item \emph{non-empty, proper}: $\emptyset \neq \alpha \subsetneq \Rat$
  262. \item \emph{initial}: for all $p,q \in \Rat$: if $p < q \in \alpha$ then $p \in \alpha$
  263. \item \emph{no maximum}: for all $p \in \alpha$ there is a $q \in \alpha$ such that $p < q$
  264. \end{enumerate}
  265. Then $\Real$ is the set of cuts.
  266. \end{defn}
  268. So now we can say that $\sqrt{2} = \Setabs{p \in \Rat}{p^2 < 2\text{
  269. or }p < 0}$. Of course, we need to check that this \emph{is} a cut,
  270. but we relegate that to \olref[check]{sec}.
  272. As before, having defined some entities, we next need to define basic
  273. functions and relations upon them. We begin with an easy one:
  274. \begin{align*}
  275. \alpha \leq \beta \text{ iff }\alpha \subseteq \beta
  276. \end{align*}
  277. This definition of an order allows to \emph{state} the central result,
  278. that the set of cuts has the Completeness Property. Spelled out fully,
  279. the statement has this shape. If $S$ is a non-empty set of cuts with
  280. an upper bound, then $S$ has a least upper bound. In more detail: there is a cut, $\lambda$, which is an upper bound for $S$, i.e.\ $(\forall \alpha \in S)\alpha \subseteq
  281. \lambda$, and $\lambda$ is the least such cut, i.e.\ $(\forall \beta \in \Real)((\forall \alpha \in S)\alpha \subseteq \beta \lif \lambda \subseteq \beta)$. Now here is
  282. the proof of the result:
  284. \begin{thm}\ollabel{realcompleteness}
  285. The set of cuts has the Completeness Property.
  286. \end{thm}
  288. \begin{proof}
  289. Let $S$ be any non-empty set of cuts with an upper bound. Let $\lambda
  290. = \bigcup S$.
  292. We first claim that $\lambda$ is a cut:
  293. \begin{enumerate}
  294. \item Since $S$ has an upper bound, at least one cut is in $S$, so
  295. $\emptyset \neq \lambda$. Since $S$ is a set of cuts, $\lambda
  296. \subseteq \Rat$. Since $S$ has an upper bound, some $p \in \Rat$ is
  297. absent from every cut $\alpha \in S$. So $p\notin \lambda$, and hence
  298. $\lambda \subsetneq \Rat$.
  299. \item Suppose $p < q \in \lambda$. So there is some $\alpha \in S$
  300. such that $q \in \alpha$. Since $\alpha$ is a cut, $p \in \alpha$. So
  301. $p \in \lambda$.
  302. \item Suppose $p \in \lambda$. So there is some $\alpha \in S$ such
  303. that $p \in \alpha$. Since $\alpha$ is a cut, there is some $q \in
  304. \alpha$ such that $p < q$. So $q \in \lambda$.
  305. \end{enumerate}
  306. This proves the claim. Moreover, clearly $(\forall \alpha \in S)\alpha
  307. \subseteq \bigcup S = \lambda$, i.e.\ $\lambda$ is an upper bound on $S$. So now suppose $\beta \in \mathbb{R}$ is also an upper bound, i.e.\ $(\forall \alpha \in S)\alpha \subseteq \beta$. For any $p \in \Rat$, if $p \in \lambda$, then there is $\alpha \in S$ such that $p \in \alpha$, so that $p \in \beta$. Generalizing, $\lambda \subseteq \beta$. So $\lambda$ is the \emph{least} upper bound on $S$.
  308. \end{proof}
  310. So we have a bunch of entities which satisfy the Completeness
  311. Property. And one way to put this is: there are no ``gaps'' in our
  312. cuts. (So: taking further ``cuts'' of reals, rather than rationals,
  313. would yield no interesting new objects.)
  315. Next, we must define some operations on the reals. We start by
  316. embedding the rationals into the reals by stipulating that $p_\Real =
  317. \Setabs{q \in \Rat}{q < p}$ for each $p \in \Rat$. We then define:
  318. \begin{align*}
  319. \alpha + \beta &= \Setabs{p + q}{p \in \alpha \land q \in \beta}\\
  321. \alpha \times \beta &=
  322. \Setabs{p \times q}{0 \leq p \in \alpha \land 0 \leq q \in \beta} \cup 0^\mathbb{R} & \text{if }\alpha, \beta \geq 0_\Real
  325. \end{align*}
  326. To handle the other multiplication cases, first let:
  327. \begin{align*}
  328. -\alpha &= \Setabs{p - q}{p < 0 \land q \notin \alpha}
  329. \end{align*}
  330. and then stipulate:
  331. \begin{align*}
  332. \alpha \times \beta &\defis
  333. \begin{cases}
  334. \mathord{-}\alpha \times \mathord{-}\beta &\text{if }\alpha < 0_\Real\text{ and }\beta < 0_\Real\\
  335. \mathord{-}(\mathord{-}\alpha \times \beta) &\text{if }\alpha < 0_\Real \text{ and }\beta > 0_\Real\\
  336. \mathord{-}(\alpha \times \mathord{-}\beta) &\text{if }\alpha > 0_\Real \text{ and }\beta < 0_\Real
  337. \end{cases}
  338. \end{align*}
  339. We then need to check that each of these definitions always yields a
  340. cut. And finally, we need to go through an easy (but long-winded)
  341. demonstration that the cuts, so defined, behave exactly as they
  342. should. But we relegate all of this to \olref[check]{sec}.

  347. \olsection{Some Philosophical Reflections}
  349. So much for the technicalities. But what did they achieve?
  351. Well, pretty uncontestably, they gave us some {lovely} pure mathematics. Moreover,
  352. there were some deep conceptual achievements. It was a profound
  353. insight, to see that the Completeness Property expresses the crucial
  354. difference between the reals and the rationals. Moreover, the explicit
  355. construction of reals, as Dedekind cuts, puts the subject matter of
  356. analysis on a firm footing. We know that the notion of a
  357. \emph{complete ordered field} is coherent, for the cuts form just such
  358. a field.
  360. For all that, we should air a few reservations about these achievements.
  362. First, it is not clear that thinking of reals in terms of cuts is any
  363. \emph{more} rigorous than thinking of reals in terms of their familiar
  364. (possibly infinite) decimal expansions. This latter ``construction''
  365. of the reals has some resemblance to the construction of the reals via
  366. Cauchy sequence; but in fact, it was essentially known to
  367. mathematicians from the early 17th century onwards (see
  368. \olref[cauchy]{sec}). The real increase in rigour came from the
  369. realisation that the reals have the Completeness Property; the ability
  370. to construct real numbers as particular sets is perhaps not, by
  371. itself, so very interesting.
  373. It is even less clear that the (much easier) arithmetization of the
  374. integers, or of the rationals, increases rigour in those areas. Here,
  375. it is worth making a simple observation. Having \emph{constructed} the
  376. integers as equivalence classes of ordered pairs of naturals, and then
  377. constructed the rationals as equivalence classes of ordered pairs of
  378. integers, and then constructed the reals as sets of rationals, we
  379. immediately \emph{forget about} the constructions. In particular: no
  380. one would ever want to \emph{invoke} these constructions during a
  381. mathematical proof (excepting, of course, a proof that the
  382. constructions behaved as they were supposed to). It's much easier to
  383. speak about a real, directly, than to speak about some set of sets of
  384. sets of sets of sets of sets of sets of naturals.
  399. It is most doubtful of all that these definitions tell us what the
  400. integers, rationals, or reals \emph{are}, \emph{metaphysically
  401. speaking}. That is, it is doubtful that the reals (say) \emph{are}
  402. certain sets (of sets of sets\ldots). The main barrier to such a view
  403. is that the construction could have been done in many different ways.
  404. In the case of the reals, there are some genuinely interestingly
  405. different constructions (see \olref[cauchy]{sec}). But here is a
  406. really trivial way to obtain some different constructions: as in
  407. \olref[sfr][rel][ref]{sec}, we could have defined ordered pairs
  408. slightly differently; if we had used this alternative notion of an
  409. ordered pair, then our constructions would have worked precisely as
  410. well as they did, but we would have ended up with different objects.
  411. As such, there are many rival set-theoretic constructions of the
  412. integers, the rationals, and the reals. And now it would just be
  413. arbitrary (and embarrassing) to claim that the integers (say) are
  414. \emph{these} sets, rather than \emph{those}. (As in
  415. \olref[sfr][rel][ref]{sec}, this is an instance of an argument made
  416. famous by \citealt{Benacerraf1965}.)
  418. A further point is worth raising: there is something quite \emph{odd}
  419. about our constructions. We started with the natural numbers. We then
  420. construct the integers, and construct ``the $0$ of the integers'',
  421. i.e., $ \equivrep{0,0}{\Intequiv}$. But $0 \neq
  422. \equivrep{0,0}{\Intequiv}$. Indeed, given our constructions,
  423. \emph{no} natural number is an integer. But that seems extremely

  425. without much argument that $\Nat \subseteq \Rat$. If the constructions

  427. false.

  432. sense, we can \emph{embed} the theories of these entities within a set
  433. theory. But the philosophical import of this embedding is just not
  434. that straightforward.

  449. \olsection{Ordered Rings and Fields}
  451. Throughout this chapter, we claimed that certain definitions behave
  452. ``as they ought''. In this technical appendix, we will spell out what
  453. we mean, and (sketch how to) show that the definitions do behave
  454. ``correctly''.
  456. In \olref[int]{sec}, we defined addition and multiplication on $\Int$.
  457. We want to show that, as defined, they endow $\Int$ with the structure
  458. we ``would want'' it to have. In particular, the structure in question
  459. is that of a commutative ring.
  461. \begin{defn}
  462. A \emph{commutative ring} is a set $S$, equipped with specific elements $0$ and $1$ and operations $+$ and $\times$, satisfying these eight formulas:
  463. \begin{align*}
  464. \emph{Associativity}&&a + (b+ c) & = (a + b) + c \\
  465. && (a \times b) \times c & = a \times (b\times c)\\
  466. \emph{Commutativity}&&a + b &= b+ a \\
  467. && a \times b&= b\times a\\
  468. \emph{Identities}&&a + 0 &= a \\
  469. && a \times 1 &= a\\
  470. \emph{Additive Inverse}&&(\exists b\in S)0&=a + b\\
  471. \emph{Distributivity}&&a \times (b+ c ) &= (a \times b) + (a \times c)
  472. \end{align*}
  473. Implicitly, these are all bound with universal quantifiers restricted to $S$. And note that the elements $0$ and~$1$ here need not be the natural numbers with the same name.
  474. \end{defn}
  476. So, to check that the integers form a commutative ring, we just need
  477. to check that we meet these eight conditions. None of the conditions
  478. is {difficult} to establish, but this is a bit laborious. For example,
  479. here is how to prove \emph{Associativity}, in the case of addition:
  481. \begin{proof}
  482. Fix $i, j, k \in \Int$. So there are $a_1, b_1, a_2, b_2, a_3, b_3 \in
  483. \Nat$ such that $i = \equivrep{a_1, b_1}{}$ and $j =
  484. \equivrep{a_2,b_2}{}$ and $k = \equivrep{a_3, b_3}{}$. (For
  485. legibility, we write ``$\equivrep{x, y}{}$'' rather than
  486. ``$\equivrep{x, y}{\Intequiv}$''; we'll do this throughout this
  487. section.) Now:
  488. \begin{align*}
  489. i + (j + k) &= \equivrep{a_1, b_1}{}+(\equivrep{a_2, b_2}{} + \equivrep{a_3, b_3}{}) \\
  490. &= \equivrep{a_1, b_1}{} + \equivrep{a_2+a_3, b_2+b_3}{}\\
  491. &= \equivrep{a_1 + (a_2 + a_3), b_1 + (b_2 + b_3)}{}\\
  492. &= \equivrep{(a_1 + a_2) + a_3, (b_1 + b_2) + b_3}{}\\
  493. &= \equivrep{a_1 + a_2, b_1 + b_2}{} + \equivrep{a_3, b_3}{}\\
  494. &= (\equivrep{a_1, b_1}{} + \equivrep{a_2, b_2}{}) + \equivrep{a_3, b_3}{}\\
  495. &= (i+j) + k
  496. \end{align*}
  497. helping ourselves freely to the behavior of addition on $\Nat$.
  498. \end{proof}
  500. Equally, here is how to prove \emph{Additive Inverse}:
  502. \begin{proof}
  503. Fix $i \in \Int$, so that $i = \equivrep{a,b}{}$ for some $a,b \in
  504. \Nat$. Let $j = \equivrep{b,a}{} \in \Int$. Helping ourselves to the
  505. behaviour of the naturals, $(a+b) + 0 = 0 + (a+b)$, so that
  506. $\tuple{a+b, b+a} \sim_\Int \tuple{0,0}$ by definition, and hence
  507. $\equivrep{a+b, b+a}{} = \equivrep{0, 0}{} = 0_\Int$. So now $i + j =
  508. \equivrep{a,b}{}+\equivrep{b,a}{}=\equivrep{a+b, b+a}{}= \equivrep{0,
  509. 0}{} = 0_\Int$.
  510. \end{proof}
  512. And here is a proof of \emph{Distributivity}:
  514. \begin{proof}
  515. As above, fix $i = \equivrep{a_1, b_1}{}$ and $j =
  516. \equivrep{a_2,b_2}{}$ and $k = \equivrep{a_3, b_3}{}$. Now:
  517. \begin{align*}
  518. i \times (j + k)
  519. &= \equivrep{a_1, b_1}{} \times (\equivrep{a_2,b_2}{} + \equivrep{a_3, b_3}{})\\
  520. &= \equivrep{a_1, b_1}{} \times \equivrep{a_2 + a_3,b_2+b_3}{}\\
  521. &= \equivrep{a_1 (a_2 + a_3) + b_1 (b_2+b_3), a_1 (b_2 + b_3) + b_1 (a_2 + a_3)}{}\\
  522. &= \equivrep{a_1 a_2 + a_1a_3 + b_1 b_2+b_1b_3, a_1 b_2 + a_1b_3 + a_2b_1 + a_3b_1}{}\\
  524. &= \equivrep{a_1a_2 + b_1b_2, a_1b_2 + a_2b_1}{} + \equivrep{a_1a_3 + b_1b_3, a_1b_3 + a_3b_1}{}\\
  525. &= (\equivrep{a_1, b_1}{} \times \equivrep{a_2,b_2}{}) + (\equivrep{a_1, b_1}{} \times \equivrep{a_3, b_3}{})\\
  526. &= (i \times j) + (i \times k)
  527. \end{align*}
  528. \end{proof}
  530. We leave it as an exercise to prove the remaining five conditions.
  531. Having done that, we have shown that $\Int$ constitutes a commutative
  532. ring, i.e., that addition and multiplication (as defined) behave as
  533. they should.
  535. \begin{prob}
  536. Prove that $\Int$ is a commutative ring.
  537. \end{prob}
  539. But our task is not over. As well as defining addition and
  540. multiplication over $\Int$, we defined an ordering relation, $\leq$,
  541. and we must check that this behaves as it should. In more detail, we
  542. must show that $\Int$ constitutes an \emph{ordered} ring.\footnote{Recall
  543. from \olref[sfr][rel][ord]{def:linearorder} that a total order
  544. is a relation which is reflexive, transitive, anti-symmetric, and connected.
  545. In the context of order relations, connectedness is sometimes called
  546. \emph{trichotomy}, since for any $a$ and $b$ we have $a \leq b \lor a
  547. = b \lor a \geq b$.}
  549. \begin{defn}
  550. An \emph{ordered ring} is a commutative ring which is also equipped
  551. with a total order relation, $\leq$, such that:
  552. \begin{align*}
  553. a \leq b &\lif a + c \leq b + c\\
  554. (a \leq b \land 0 \leq c) &\lif a \times c \leq b \times c
  555. \end{align*}
  556. \end{defn}
  558. \begin{prob}
  559. Prove that $\Int$ is an ordered ring.
  560. \end{prob}
  562. As before, it is laborious but routine to show that~$\Int$, as
  563. constructed, is an ordered ring. We will leave that to you.
  565. This takes care of the integers. But now we need to show very similar
  566. things of the rationals. In particular, we now need to show that the
  567. rationals form an ordered \emph{field}, under our given definitions of
  568. $+$, $\times$, and $\leq$:
  569. \begin{defn}\ollabel{orderedfield}
  570. An \emph{ordered field} is an ordered ring which also satisfies:
  571. \begin{align*}
  572. \emph{Multiplicative Inverse}& & (\forall a \in S \setminus \{0\})(\exists b \in S) a\times b& = 1
  573. \end{align*}
  574. \end{defn}
  576. Once you have shown that $\Int$ constitutes an ordered ring, it is
  577. easy but laborious to show that $\Rat$ constitutes an ordered field.
  579. \begin{prob}
  580. Prove that $\Rat$ is an ordered field.
  581. \end{prob}
  583. Having dealt with the integers and the rationals, it only remains to
  584. deal with the reals. In particular, we need to show that $\Real$
  585. constitutes a \emph{complete} ordered field, i.e., an ordered field
  586. with the Completeness Property. Now, \olref[cuts]{realcompleteness}
  587. established that $\Real$ has the Completeness Property. However, it
  588. remains to run through the (tedious) of checking that $\Real$ is an
  589. ordered field.
  591. Before tearing off into \emph{that} laborious exercise, we need to
  592. check some more ``immediate'' things. For example, we need a guarantee
  593. that $\alpha + \beta$, as defined, is indeed a \emph{cut}, for any
  594. cuts $\alpha$ and $\beta$. Here is a proof of that fact:
  596. \begin{proof}
  597. Since $\alpha$ and $\beta$ are both cuts, $\alpha + \beta = \Setabs{p
  598. + q}{p \in \alpha \land q \in \beta}$ is a non-empty proper subset of
  599. $\Rat$. Now suppose $x < p + q$ for some $p \in \alpha$ and $q \in \beta$.
  600. Then $x - p < q$, so $x - p \in \beta$, and $x = p + (x - p) \in
  601. \alpha + \beta$. So $\alpha + \beta$ is an initial segment of $\Rat$.
  602. Finally, for any $p + q \in \alpha + \beta$, since $\alpha$ and
  603. $\beta$ are both cuts, there are $p_1 \in \alpha$ and $q_1 \in \beta$
  604. such that $p < p_1$ and $q < q_1$; so $p + q < p_1 + q_1 \in \alpha +
  605. \beta$; so $\alpha + \beta$ has no maximum.
  606. \end{proof}
  608. Similar efforts will allow you to check that $\alpha - \beta$ and
  609. $\alpha \times \beta$ and $\alpha \div \beta$ are cuts (in the last
  610. case, ignoring the case where $\beta$ is the zero-cut). Again, though,
  611. we will simply leave this to you.
  613. \begin{prob}
  614. Prove that $\Real$ is an ordered field.
  615. \end{prob}
  617. But here is a small loose end to tidy up. In
  618. \olref[cuts]{sec}, we suggest that we can take $\sqrt{2} =
  619. \Setabs{p \in \Rat}{p < 0 \text{ or }p^2 < 2}$. But we do need to show
  620. that this set is a \emph{cut}. Here is a proof of that fact:
  622. \begin{proof}
  623. Clearly this is a nonempty proper initial segment of the rationals; so
  624. it suffices to show that it has no maximum. In particular, it suffices
  625. to show that, where $p$ is a positive rational with $p^2 < 2$ and $q =
  626. \frac{2p+2}{p+2}$, both $p < q$ and $q^2 < 2$. To see that $p < q$,
  627. just note:
  628. \begin{align*}
  629. p^2 &< 2\\
  630. p^2 + 2p &< 2 + 2p\\
  631. p(p + 2) &< 2 + 2p\\
  632. p &< \tfrac{2+2p}{p+2} = q
  633. \end{align*}
  634. To see that $q^2 < 2$, just note:
  635. \begin{align*}
  636. p^2 &< 2\\
  637. 2p^2 + 4p + 2 &< p^2 + 4p+ 4\\
  638. 4p^2 + 8p + 4 &< 2(p^2 + 4p + 4)\\
  639. (2p+2)^2 & <2(p+2)^2\\
  640. \tfrac{(2p+2)^2}{(p+2)^2} &< 2\\
  641. q^2 &< 2
  642. \end{align*}
  643. \end{proof}

  649. \olsection{Appendix: the Reals as Cauchy Sequences}
  651. In \olref[cuts]{sec}, we constructed the reals as Dedekind cuts. In
  652. this section, we explain an alternative construction. It builds on
  653. Cauchy's definition of (what we now call) a Cauchy sequence; but the
  654. use of this definition to \emph{construct} the reals is due to other
  655. nineteenth-century authors, notably Weierstrass, Heine, M\'{e}ray and
  656. Cantor. (For a nice history, see \citeauthor{OConnorRobertson:RN}
  657. \citeyear{OConnorRobertson:RN}.)
  659. Before we get to the nineteenth century, it's worth considering Simon
  660. Stevin (1548--1620). In brief, Stevin realised that we can think of
  661. each real in terms of its decimal expansion. Thus even an irrational
  662. number, like $\sqrt{2}$, has a nice decimal expansion, beginning:
  663. \[
  664. 1.41421356237\ldots
  665. \]
  666. It is very easy to model decimal expansions in set theory: simply
  667. consider them as functions $d \colon \Nat \to \Nat$, where $d(n)$ is
  668. the $n$th decimal place that we are interested in. We will then need a
  669. bit of tweak, to handle the bit of the real number that comes before
  670. the decimal point (here, just $1$). We will also need a further tweak
  671. (an equivalence relation) to guarantee that, for example, $0.999\ldots
  672. = 1$. But it is not difficult to offer a perfectly rigorous
  673. construction of the real numbers, in the manner of Stevin, within set
  674. theory.
  676. Stevin is not our focus. (For more on Stevin, see
  677. \citealt{KatzKatz2012}.) But here is a closely related thought.
  678. Instead of treating $\sqrt{2}$'s decimal expansion directly, we can
  679. instead consider a \emph{sequence} of increasingly accurate rational
  680. approximations to $\sqrt{2}$, by considering the increasingly precise
  681. expansions:
  682. \[
  683. 1, 1.4, 1.414, 1.4142, 1.41421,\ldots
  684. \]
  685. The idea that reals can be considered via ``increasingly good
  686. approximations'' provides us with the basis for another sequence of
  687. insights (akin to the realisations that we used when constructing
  688. $\Rat$ from $\Int$, or $\Int$ from $\Nat$). The basic insights are
  689. these:
  690. \begin{enumerate}
  691. \item Every real can be written as a (perhaps infinite) decimal
  692. expansion.
  693. \item The information encoded by a (perhaps infinite) decimal
  694. expansion can be equally be encoded by a sequence of rational
  695. numbers.
  696. \item A sequence of rational numbers can be thought of as a
  697. function from $\Nat$ to $\Rat$; just let $f(n)$ be the $n$th
  698. rational in the sequence.
  699. \end{enumerate}
  700. Of course, not just \emph{any} function from $\Nat$ to $\Rat$ will
  701. give us a real number. For instance, consider this function:
  702. \[
  703. f(n) =\begin{cases}
  704. 1 & \text{if }n\text{ is odd}\\
  705. 0 &\text{if }n\text{ is even}
  706. \end{cases}
  707. \]
  708. Essentially the worry here is that the sequence $0,1,0,1,0,1,0,\ldots$
  709. doesn't seem to ``hone in'' on any real. So: to ensure that we
  710. consider sequences which do hone in on some real, we need to restrict
  711. our attention to sequences which have some \emph{limit}.
  713. We have already encountered the idea of a limit, in
  714. \olref[his][set][limits]{sec}. But we cannot use \emph{quite} the same
  715. definition as we used there. The expression ``$(\forall \epsilon>0)$''
  716. there tacitly involved quantification over the real numbers; and we
  717. were considering the limits of functions on the real numbers; so
  718. invoking that definition would be to help ourselves to the real
  719. numbers; and they are exactly what we were aiming to \emph{construct}.
  720. Fortunately, we can work with a closely related idea of a limit.
  721. \begin{defn}\ollabel{def:CauchySequence}
  722. A function $f: \Nat \to \Rat$ is a \emph{Cauchy sequence} iff for
  723. any positive $\epsilon \in \Rat$ we have that $(\exists \ell \in
  724. \Nat)(\forall m, n > \ell)|f(m) - f(n)| < \epsilon$.
  725. \end{defn}
  727. The general idea of a limit is the same as before: if you want a
  728. certain level of precision (measured by~$\epsilon$), there is a
  729. ``region'' to look in (any input greater than~$\ell$). And it is easy
  730. to see that our sequence $1$, $1.4$, $1.414$, $1.4142$,
  731. $1.41421$\ldots has a limit: if you want to approximate $\sqrt{2}$ to
  732. within an error of $\nicefrac{1}{10^{n}}$, then just look to any entry
  733. after the $n$th.
  735. The obvious thought, then, would be to say that a real number just
  736. \emph{is} any Cauchy sequence. But, as in the constructions of $\Int$
  737. and $\Rat$, this would be too na\"{i}ve: for any given real number,
  738. multiple different Cauchy sequences indicate that real number. A
  739. simple way to see this as follows. Given a Cauchy sequence~$f$, define
  740. $g$ to be exactly the same function as~$f$, except that $g(0)\neq
  741. f(0)$. Since the two sequences agree everywhere after the first
  742. number, we will (ultimately) want to say that they have the same
  743. limit, in the sense employed in \olref{def:CauchySequence},
  744. and so should be thought of ``defining'' the same real. So, we should
  745. really think of these Cauchy sequences as the same real number.
  747. Consequently, we again need to define an equivalence relation on the
  748. Cauchy sequences, and identify real numbers with equivalence
  749. relations. First we need the idea of a function which tends to $0$ in
  750. the limit. For any function $h : \Nat \to \Rat$, say that \emph{$h$
  751. tends to $0$} iff for any positive $\epsilon \in \Rat$ we have that
  752. $(\exists \ell \in \Nat)(\forall n > \ell)|h(n)| <
  753. \epsilon$.\footnote{Compare this with the definition of $\lim_{x
  754. \mathord{\rightarrow}\infty}f(x) = 0$ in
  755. \olref[his][set][limits]{sec}.} Further, where $f$ and $g$ are
  756. functions $\Nat \to \Rat$, let $(f-g)(n) = f(n) - g(n)$. Now define:
  757. \[
  758. f \Realequiv g \text{ iff $(f-g)$ tends to $0$}.
  759. \]
  760. We need to check that $\Realequiv$ is an equivalence relation; and it
  761. is. We can then, if we like, define the reals as the equivalence
  762. classes, under $\Realequiv$, of all Cauchy sequences from $\Nat \to
  763. \Rat$.
  765. \begin{prob}
  766. Let $f(n) = 0$ for every $n$. Let $g(n) = \frac{1}{(n+1)^2}$. Show
  767. that both are Cauchy sequences, and indeed that the limit of both
  768. functions is $0$, so that also $f \sim_\Real g$.
  769. \end{prob}
  771. Having done this, we shall as usual write $\equivrep{f}{\Realequiv}$
  772. for the equivalence class with $f$ as !!a{element}. However, to keep
  773. things readable, in what follows we will drop the subscript and write
  774. just $\equivrep{f}{}$. We also stipulate that, for each $q \in \Rat$,
  775. we have $q_{\Real} = \equivrep{c_{q}}{}$, where $c_{q}$ is the
  776. constant function $c_q(n) = q$ for all $n \in \Nat$. We then define
  777. basic relations and operations on the reals, e.g.:
  778. \begin{align*}
  779. \equivrep{f}{} + \equivrep{g}{} &= \equivrep{(f + g)}{} \\
  780. \equivrep{f}{} \times \equivrep{g}{} &= \equivrep{(f \times g)}{}
  781. \end{align*}
  782. where $(f + g)(n) = f(n) + g(n)$ and $(f \times g)(n) = f(n) \times
  783. g(n)$. Of course, we also need to check that each of $(f + g)$,
  784. $(f-g)$ and $(f\times g)$ are Cauchy sequences when $f$ and $g$ are;
  785. but they are, and we leave this to you.
  787. Finally, we define we a notion of order. Say $\equivrep{f}{}$ is
  788. \emph{positive} iff both $\equivrep{f}{}\neq 0_\Rat$ and $(\exists
  789. \ell \in \Nat)(\forall n > \ell)0 < f(n)$. Then say $\equivrep{f}{} <
  790. \equivrep{g}{}$ iff $\equivrep{(g - f)}{}$ is positive. We have to
  791. check that this is well-defined (i.e., that it does not depend upon
  792. choice of ``representative'' function from the equivalence class).
  797. But having done this, it is quite easy to show that these yield the
  798. right algebraic properties; that is:
  799. \begin{thm}\ollabel{thm:cauchyorderedfield}
  800. The Cauchy sequences constitute an ordered field.
  801. \end{thm}
  803. \begin{proof}
  804. Exercise.
  805. \end{proof}
  807. \begin{prob}
  808. Prove that the Cauchy sequences constitute an ordered field.
  809. \end{prob}
  811. It is harder to prove that the reals, so constructed, have the
  812. Completeness Property, so we will give the proof.
  814. \begin{thm}
  815. Every non-empty set of Cauchy sequences with an upper bound has a
  816. least upper bound.
  817. \end{thm}
  819. \begin{proof}[Proof sketch] Let $S$ be any non-empty set of Cauchy
  820. sequences with an upper bound. So there is some $p \in \Rat$ such that
  821. $p_{\Real}$ is an upper bound for $S$. Let $r \in S$; then there is
  822. some $q \in \Rat$ such that $q_{\Real} < r$. So if a least upper bound
  823. on $S$ exists, it is between $q_\Real$ and $p_\Real$ (inclusive).
  825. We will hone in on the l.u.b., by approaching it simultaneously from
  826. below and above. In particular, we define two functions, $f, g \colon
  827. \Nat \to \Rat$, with the aim that $f$ will hone in on the l.u.b.\ from
  828. above, and $g$ will hone on in it from below. We start by defining:
  829. \begin{align*}
  830. f(0) &= p \\
  831. g(0) &= q
  832. \end{align*}
  833. Then, where $a_n = \frac{f(n) + g(n)}{2}$, let:\footnote{This is a
  834. recursive definition. But we have not \emph{yet} given any reason to
  835. think that recursive definitions are ok.}
  836. \begin{align*}
  837. f(n+1) &=
  838. \begin{cases}
  839. a_n &\text{if }(\forall h \in S)\equivrep{h}{} \leq (a_n)_\Real\\
  840. f(n)&\text{otherwise}
  841. \end{cases}\\
  842. g(n+1) &=
  843. \begin{cases}
  844. a_n &\text{if }(\exists h \in S)\equivrep{h}{} \geq (a_n)_\Real\\
  845. g(n) &\text{otherwise}
  846. \end{cases}
  847. \end{align*}
  848. Both $f$ and $g$ are Cauchy sequences. (This can be checked fairly
  849. easily, but we leave it as an exercise.) Note that the function $(f-g)$
  850. tends to $0$, since the difference between $f$ and $g$ halves at each
  851. step. Hence $\equivrep{f}{} = \equivrep{g}{}$.
  853. We first show that $\equivrep{f}{}$ is an upper bound on $S$, i.e.\ that $(\forall h \in S)\equivrep{h}{} \leq \equivrep{f}{}$.
  854. (We will invoke \olref{thm:cauchyorderedfield} as we go.) Let $h \in S$ and
  855. suppose, for reductio, that $\equivrep{f}{} < \equivrep{h}{}$, so that
  856. $0_\Real < \equivrep{(h-f)}{}$. Since $f$ is a monotonically
  857. decreasing Cauchy sequence, there is some $n \in \Nat$ such that
  858. $\equivrep{(c_{f(n)} - f)}{} < \equivrep{(h-f)}{}$. So:
  859. \[
  860. (f(n))_\Real = \equivrep{c_{f(n)}}{} < \equivrep{f}{} + \equivrep{(h-f)}{} = \equivrep{h}{},
  861. \]
  862. contradicting the fact that, by construction, $\equivrep{h}{} \leq (f(n))_\Real$.
  864. We next show that $\equivrep{f}{} = \equivrep{g}{}$ is the \emph{least} upper bound on $S$. So let $j$ be any Cauchy sequence and suppose $\equivrep{j}{} < \equivrep{g}{}$. Reasoning as above (using the fact that $g$ is \emph{increasing}), there is $n \in \Nat$ such that $\equivrep{j}{} < (g(n))_\Real$. But by construction there is $h \in S$ such that $(g(n))_\Real \leq \equivrep{h}{}$, so $\equivrep{j}{} < \equivrep{h}{}$ and therefore $\equivrep{j}{}$ is not an upper bound on $S$.
  865. \end{proof}
