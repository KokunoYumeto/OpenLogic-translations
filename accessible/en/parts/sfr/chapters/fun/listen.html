Basics

Explanation

A function is a map which sends each element of a given set to a specific element in some (other) given set. For instance, the operation of adding one defines a function: each number n is mapped to a unique number n plus one.

More generally, functions may take pairs, triples, etc., as inputs and return some kind of output. Many functions are familiar to us from basic arithmetic. For instance, addition and multiplication are functions. They take in two numbers and return a third.

In this mathematical, abstract sense, a function is a black box: what matters is only what output is paired with what input, not the method for calculating the output.

Definition: Function

A function f is a function from A to B is a mapping of each element of A to an element of B.

We call A the domain of f and B the codomain of f. The elements of A are called inputs or arguments of f, and the element of B that is paired with an argument x by f is called the value of f for argument x, written f of x.

The range the range of f of f is the subset of the codomain consisting of the values of f for some argument; the range of f equals the set of values f of x for x in A.

The diagram in Figure: Function from a three-element domain to a four-element codomain may help to think about functions. The ellipse on the left represents the function's domain; the ellipse on the right represents the function's codomain; and an arrow points from an argument in the domain to the corresponding value in the codomain.

Example: Multiplication on natural numbers

Multiplication takes pairs of natural numbers as inputs and maps them to natural numbers as outputs, so goes from the natural numbers cross the natural numbers (the domain) to the natural numbers (the codomain). As it turns out, the range is also the natural numbers, since every n is a natural number is n times one.

Example: Multiplication and square-root mappings

Multiplication is a function because it pairs each input—each pair of natural numbers—with a single output: multiplication is a function from pairs of natural numbers to the natural numbers. By contrast, mapping a natural number n to a real x such that x squared equals n is not functional, since each positive integer n has two square roots: the square root of n and negative the square root of n. We can make it functional by only returning the positive square root: the square-root function is a function from the natural numbers to the real numbers.

Example: Student grades and parents

The relation that pairs each student in a class with their final grade is a function—no student can get two different final grades in the same class. The relation that pairs each student in a class with their parents is not a function: students can have zero, or two, or more parents.

Explanation

We can define functions by specifying in some precise way what the value of the function is for every possible argument. Different ways of doing this are by giving a formula, describing a method for computing the value, or listing the values for each argument. However functions are defined, we must make sure that for each argument we specify one, and only one, value.

Example: Successor function and its range

Let f is a function from the natural numbers to the natural numbers be defined such that f of x equals x plus one. This is a definition that specifies f as a function which takes in natural numbers and outputs natural numbers. It tells us that, given a natural number x, f will output its successor x plus one. In this case, the codomain the natural numbers is not the range of f, since the natural number zero is not the successor of any natural number. The range of f is the set of all positive integers, the positive integers.

Example: Extensionally equal successor functions

Let g is a function from the natural numbers to the natural numbers be defined such that g of x equals x plus two minus one. This tells us that g is a function which takes in natural numbers and outputs natural numbers. Given a natural number n, g will output the predecessor of the successor of the successor of x, i.e., x plus one.

Explanation

We just considered two functions, f and g, with different definitions. However, these are the same function. After all, for any natural number n, we have that f of n equals n plus one, which equals n plus two minus one, which equals g of n. Otherwise put: our definitions for f and g specify the same mapping by means of different equations. Implicitly, then, we are relying upon a principle of extensionality for functions, if f of x equals g of x for every x, then f equals g provided that f and g share the same domain and codomain.

Example: Function defined by even and odd cases

We can also define functions by cases. For instance, we could define h is a function from the natural numbers to the natural numbers by h of x equals x divided by two if x is even, and the quantity x plus one, divided by two, if x is odd Since every natural number is either even or odd, the output of this function will always be a natural number. Just remember that if you define a function by cases, every possible input must fall into exactly one case. In some cases, this will require a proof that the cases are exhaustive and exclusive.

Kinds of Functions

Explanation

It will be useful to introduce a kind of taxonomy for some of the kinds of functions which we encounter most frequently.

To start, we might want to consider functions which have the property that every member of the codomain is a value of the function. Such functions are called surjective, and can be pictured as in Figure: Surjective function from three domain elements onto two codomain elements.

Definition: Surjective function

A function f is a function from A to B is surjective if and only if B is also the range of f, i.e., for every y is an element of B there is at least one x is an element of A such that f of x equals y, or in symbols: for every y in B, there exists an x in A such that f of x equals y We call such a function a surjection from A to B.

Explanation

If you want to show that f is a surjection, then you need to show that every object in f's codomain is the value of f of x for some input x.

Note that any function induces a surjection. After all, given a function f is a function from A to B, let f prime is a function from A onto the range of f be defined by f prime of x equals f of x. Since the range of f is defined as the set of values f of x in B for x in A, this function f prime is guaranteed to be a surjection

Now, any function maps each possible input to a unique output. But there are also functions which never map different inputs to the same outputs. Such functions are called injective, and can be pictured as in Figure: Injective function from three domain elements into a seven-element codomain.

Definition: Injective function

A function f is a function from A to B is injective if and only if for each y is an element of B there is at most one x is an element of A such that f of x equals y. We call such a function a injection from A to B.

Explanation

If you want to show that f is a injection, you need to show that for any elements x and y of f's domain, if f of x equals f of y, then x equals y.

Example: Injective and surjective combinations

The constant function f is a function from the natural numbers to the natural numbers given by f of x equals one is neither injective, nor surjective.

The identity function f is a function from the natural numbers to the natural numbers given by f of x equals x is both injective and surjective.

The successor function f is a function from the natural numbers to the natural numbers given by f of x equals x plus one is injective but not surjective.

The function f is a function from the natural numbers to the natural numbers defined by: f of x equals x divided by two if x is even, and the quantity x plus one, divided by two, if x is odd is surjective, but not injective.

Explanation

Often enough, we want to consider functions which are both injective and surjective. We call such functions bijective. They look like the function pictured in Figure: Bijective function pairing three domain elements with three codomain elements. Bijections are also sometimes called one-to-one correspondences, since they uniquely pair elements of the codomain with elements of the domain.

Definition: Bijection

A function f is a function from A to B is bijective if and only if it is both surjective and injective. We call such a function a bijection from A to B (or between A and B).

Functions as Relations

Explanation

A function which maps elements of A to elements of B obviously defines a relation between A and B, namely the relation which holds between x and y if and only if f of x equals y. In fact, we might even—if we are interested in reducing the building blocks of mathematics for instance—identify the function f with this relation, i.e., with a set of pairs. This then raises the question: which relations define functions in this way?

Definition: Graph of a function

Let f is a function from A to B be a function. The graph of f is the relation the graph R sub f is a subset of A cross B defined by the graph R sub f is the set of ordered pairs x, y such that f of x equals y

Explanation

The graph of a function is uniquely determined, by extensionality. Moreover, extensionality (on sets) will immediately vindicate the implicit principle of extensionality for functions, whereby if f and g share a domain and codomain then they are identical if they agree on all values.

Similarly, if a relation is “functional”, then it is the graph of a function.

Proposition: Relations that are function graphs

Let R is a subset of A cross B be such that:

  1. If R relates x to y and R relates x to z then y equals z; and

  2. for every x is an element of A there is some y is an element of B such that the ordered pair x, y is in R.

Then R is the graph of the function f is a function from A to B defined by f of x equals y if and only if R relates x to y.

Proof

Suppose there is a y such that R relates x to y. If there were another z is not equal to y such that R relates x to z, the condition on R would be violated. Hence, if there is a y such that R relates x to y, this y is unique, and so f is well-defined. Obviously, R sub f equals R.

End of proof.

Every function f is a function from A to B has a graph, i.e., a relation on A cross B defined by f of x equals y. On the other hand, every relation R is a subset of A cross B with the properties given in Proposition: Relations that are function graphs is the graph of a function f is a function from A to B. Because of this close connection between functions and their graphs, we can think of a function simply as its graph. In other words, functions can be identified with certain relations, i.e., with certain sets of tuples. Note, though, that the spirit of this “identification” is as in Philosophical Reflections: it is not a claim about the metaphysics of functions, but an observation that it is convenient to treat functions as certain sets. One reason that this is so convenient, is that we can now consider performing similar operations on functions as we performed on relations (see Operations on Relations). In particular:

Let f is a function from A to B be a function with C is a subset of A.

The restriction of f to C is the function the restriction of f to C, from C to B defined by the restriction of f to C, evaluated at x, equals f of x for all x is an element of C. In other words, the restriction of f to C equals the ordered pairs x, y in the graph of f whose first coordinate is in C.

The application of f to C is the image of C under f equals the set of values f of x for x in C. We also call this the image of C under f.

Explanation

It follows from these definitions that the range of f equals the image of the domain of f under f, for any function f. These notions are exactly as one would expect, given the definitions in Operations on Relations and our identification of functions with relations. But two other operations—inverses and relative products—require a little more detail. We will provide that in Inverses of Functions and Composition of Functions.

Inverses of Functions

Explanation

We think of functions as maps. An obvious question to ask about functions, then, is whether the mapping can be “reversed.” For instance, the successor function f of x equals x plus one can be reversed, in the sense that the function g of y equals y minus one “undoes” what f does.

But we must be careful. Although the definition of g defines a function from the integers to the integers, it does not define a function from the natural numbers to the natural numbers, since g of zero is not a natural number. So even in simple cases, it is not quite obvious whether a function can be reversed; it may depend on the domain and codomain.

This is made more precise by the notion of an inverse of a function.

Definition: Inverse function

A function g is a function from B to A is an inverse of a function f is a function from A to B if f of g of y equals y and g of f of x equals x for all x is an element of A and y is an element of B.

If f has an inverse g, we often write f inverse instead of g.

Explanation

Now we will determine when functions have inverses. A good candidate for an inverse of f is a function from A to B is g is a function from B to A “defined by” g of y equals the x such that f of x equals y But the scare quotes around “defined by” (and “the”) suggest that this is not a definition. At least, it will not always work, with complete generality. For, in order for this definition to specify a function, there has to be one and only one x such that f of x equals y—the output of g has to be uniquely specified. Moreover, it has to be specified for every y is an element of B. If there are x sub one and x sub two is an element of A with x sub one is not equal to x sub two but f of x sub one equals f of x sub two, then g of y would not be uniquely specified for y equals f of x sub one, which equals f of x sub two. And if there is no x at all such that f of x equals y, then g of y is not specified at all. In other words, for g to be defined, f must be both injective and surjective.

Let's go slowly. We'll divide the question into two: Given a function f is a function from A to B, when is there a function g is a function from B to A so that g of f of x equals x? Such a g “undoes” what f does, and is called a left inverse of f. Secondly, when is there a function h is a function from B to A so that f of h of y equals y? Such an h is called a right inverse of f—f “undoes” what h does.

Proposition: Injective functions have left inverses

If f is a function from A to B is injective, then there is a left inverse g is a function from B to A of f so that g of f of x equals x for all x is an element of A.

Proof

Suppose that f is a function from A to B is injective. Consider a y is an element of B. If y is in the range of f, there is an x is an element of A so that f of x equals y. Because f is injective, there is only one such x is an element of A. Then we can define: g of y equals x, i.e., g of y is “the” x is an element of A such that f of x equals y. If y is not in the range of f, we can map it to any a is an element of A. So, we can pick an a is an element of A and define g is a function from B to A by: g of y equals x when f of x equals y, and equals a when y is not in the range of f It is defined for all y is an element of B, since for each such y is in the range of f there is exactly one x is an element of A such that f of x equals y. By definition, if y equals f of x, then g of y equals x, i.e., g of f of x equals x.

End of proof.

Proposition: Surjective functions have right inverses

If f is a function from A to B is surjective, then there is a right inverse h is a function from B to A of f so that f of h of y equals y for all y is an element of B.

Proof

Suppose that f is a function from A to B is surjective. Consider a y is an element of B. Since f is surjective, there is an x sub y is an element of A with f of x sub y equals y. Then we can define: h of y equals x sub y, i.e., for each y is an element of B we choose some x is an element of A so that f of x equals y; since f is surjective there is always at least one to choose from. Note: Since f is surjective, for every y is an element of B the set the set of x such that f of x equals y is nonempty. Our definition of h requires that we choose a single x from each of these sets. That this is always possible is actually not obvious—the possibility of making these choices is simply assumed as an axiom. In other words, this proposition assumes the so-called Axiom of Choice, an issue we will revisit in the Choice chapter. However, in many specific cases, e.g., when A equals the natural numbers or is finite, or when f is bijective, the Axiom of Choice is not required. (In the particular case when f is bijective, for each y is an element of B the set the set of x such that f of x equals y has exactly one element, so that there is no choice to make.) By definition, if x equals h of y, then f of x equals y, i.e., for any y is an element of B, f of h of y equals y.

End of proof.

Composition of Functions

Explanation

We saw in Inverses of Functions that the inverse f inverse of a bijection f is itself a function. Another operation on functions is composition: we can define a new function by composing two functions, f and g, i.e., by first applying f and then g. Of course, this is only possible if the ranges and domains match, i.e., the range of f must be a subset of the domain of g. This operation on functions is the analogue of the operation of relative product on relations from Operations on Relations.

A diagram might help to explain the idea of composition. In Figure: Composition of f from A to B and g from B to C, we depict two functions f is a function from A to B and g is a function from B to C and their composition g composed with f. The function g composed with f is a function from A to C pairs each element of A with a element of C. We specify which element of C a element of A is paired with as follows: given an input x is an element of A, first apply the function f to x, which will output some f of x equals y, and y is an element of B, then apply the function g to y, which will output some g of f of x equals g of y, which equals z, and z is an element of C.

Definition: Composition

Let f is a function from A to B and g is a function from B to C be functions. The composition of f with g is g composed with f is a function from A to C, where g composed with f, evaluated at x, equals g of f of x.

Example: Composing successor and doubling

Consider the functions f of x equals x plus one, and g of x equals two times x. Since g composed with f, evaluated at x, equals g of f of x, for each input x you must first take its successor, then multiply the result by two. So their composition is given by g composed with f, evaluated at x, equals two times the quantity x plus one.

Partial Functions

Explanation

It is sometimes useful to relax the definition of function so that it is not required that the output of the function is defined for all possible inputs. Such mappings are called partial functions.

Definition: Partial function and its domain

A partial function f is a partial function from A to B is a mapping which assigns to every element of A at most one element of B. If f assigns an element of B to x is an element of A, we say f of x is defined, and otherwise undefined. If f of x is defined, we write f of x is defined, otherwise f of x is undefined. The domain of a partial function f is the subset of A where it is defined, i.e., the domain of f equals the set of x in A for which f of x is defined.

Example: Total functions as partial functions

Every function f is a function from A to B is also a partial function. Partial functions that are defined everywhere on A—i.e., what we so far have simply called a function—are also called total functions.

Example: Reciprocal as a partial function

The partial function f is a partial function from the real numbers to the real numbers given by f of x equals one divided by x is undefined for x equals zero, and defined everywhere else.
