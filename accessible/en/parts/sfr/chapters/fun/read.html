Basics

Explanation

A function is a map which sends each element of a given set to a specific element in some (other) given set. For instance, the operation of adding 1source 15 defines a function: each number nsource 15 is mapped to a unique number n+1source 16.

More generally, functions may take pairs, triples, etc., as inputs and return some kind of output. Many functions are familiar to us from basic arithmetic. For instance, addition and multiplication are functions. They take in two numbers and return a third.

In this mathematical, abstract sense, a function is a black box: what matters is only what output is paired with what input, not the method for calculating the output.

Inverses of Functions

Explanation

We think of functions as maps. An obvious question to ask about functions, then, is whether the mapping can be “reversed.” For instance, the successor function f(x)=x+1source 15 can be reversed, in the sense that the function g(y)=y−1source 16 “undoes” what fsource 16 does.

But we must be careful. Although the definition of gsource 18 defines a function Z→Zsource 19, it does not define a function N→Nsource 19, since g(0)∉Nsource 20. So even in simple cases, it is not quite obvious whether a function can be reversed; it may depend on the domain and codomain.

This is made more precise by the notion of an inverse of a function.
