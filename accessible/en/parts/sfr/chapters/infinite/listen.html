Editorial note

This chapter on infinite sets is taken from Tim Button's Open Set Theory.

Hilbert's Hotel

The set of the natural numbers is obviously infinite. So, if we do not want to help ourselves to the natural numbers, our first step must characterize an infinite set in terms that do not require mentioning the natural numbers themselves. Here is a nice approach, presented by Hilbert in a lecture from 1924. He asks us to imagine

[and so on] a hotel with a finite number of rooms. All of these rooms should be occupied by exactly one guest. If the guests now swap their rooms somehow, [but] so that each room still contains no more than one person, then no rooms will become free, and the hotel-owner cannot in this way create a new place for a newly arriving guest [paragraph omitted]

Now we stipulate that the hotel shall have infinitely many numbered rooms one, two, three, four, five, and so on, each of which is occupied by exactly one guest. As soon as a new guest comes along, the owner only needs to move each of the old guests into the room associated with the number one higher, and room one will be free for the newly-arriving guest.

(published in David Hilbert two thousand thirteen, seven hundred thirty; our translation)

The crucial point is that Hilbert's Hotel has infinitely many rooms; and we can take his explanation to define what it means to say this. Indeed, this was Dedekind's approach (presented here, of course, with massive anachronism; Dedekind's definition is from one thousand eight hundred eighty eight):

Definition of a Dedekind-infinite set

A set A is Dedekind infinite iff there is an injection from A to a proper subset of A. That is, there is some o in A and an injection f from A to A such that o is not an element of the range of f.

Dedekind Algebras

We not only want natural numbers to be infinite; we want them to have certain (algebraic) properties: they need to behave well under addition, multiplication, and so forth.

Dedekind's idea was to take the idea of the successor function as basic, and then characterise the numbers as those with the following properties:

  1. There is a number, zero, which is not the successor of any number that is, zero is not an element of the range of s that is, for every x, s of x is not equal to zero

  2. Distinct numbers have distinct successors that is, s is an injection that is, for every x and every y, if s of x equals s of y, then x equals y

  3. Every number is obtained from zero by repeated applications of the successor function.

The first two conditions are easy to deal with using first-order logic (see above). But we cannot deal with condition three, repeated application of the successor function just using first-order logic. Dedekind's breakthrough was to reformulate condition three, repeated application of the successor function, set-theoretically, as follows:

  1. 3 prime.

    The natural numbers are the smallest set that is closed under the successor function: that is, if we apply s to any element of the set, we obtain another element of the set.

But we shall need to spell this out slowly.

Definition of closure under a function

For any function f, the set X is f-closed iff for every x in X, f of x is in X. Now define, for any o: the closure of o under f equals the intersection of all sets X such that o is in X and X is f closed

So the closure of o under f is the intersection of all the f-closed sets with o as an element. Intuitively, then, the closure of o under f is the smallest f-closed set with o as an element. This next result makes that intuitive thought precise;

Lemma on closure properties

For any function f and any o in A:

  1. o is an element of the closure of o under f; and

  2. the closure of o under f is f-closed; and

  3. if X is f-closed and o is an element of X, then the closure of o under f is a subset of X

Proof

Note that there is at least one f-closed set with o as an element, namely the range of f union the singleton containing o. So the closure of o under f, the intersection of all such sets, exists. We must now check the closure-contains-o clause–the least-closure clause.

Concerning the closure-contains-o clause: o is an element of the closure of o under f as it is an intersection of sets which all have o as an element.

Concerning the closure-is-f-closed clause: suppose x is an element of the closure of o under f. So if o is an element of X and X is f-closed, then x is an element of X, and now f open parenthesis x close parenthesis is an element of X as X is f-closed. So f open parenthesis x close parenthesis is an element of the closure of o under f.

Concerning the least-closure clause: quite generally, if X is an element of C then the intersection of C is a subset of X.

End of proof.

Using this, we can say:

Definition of a Dedekind algebra

A Dedekind algebra is a set A together with a function f from A to A and some o in A such that:

  1. o is not an element of the range of f

  2. f is an injection

  3. A equals the closure of o under f

Since A equals the closure of o under f, our earlier result tells us that A is the smallest f-closed set with o as an element. Clearly a Dedekind algebra is Dedekind infinite; just look at clauses placing o outside the range and requiring f to be injective of the definition. But the more exciting fact is that any Dedekind infinite set can be turned into a Dedekind algebra.

Theorem producing a Dedekind algebra

If there is a Dedekind infinite set, then there is a Dedekind algebra.

Proof

Let D be Dedekind infinite. So there is an injection g from D to D and an element o of D that lies outside the range of g. Now let A equals the closure of o under g; by the lemma on closure properties, A exists and o is an element of A. Let f equals the restriction of g to A. We will show that A, f, and o comprise a Dedekind algebra.

Concerning the clause placing o outside the range: o is not an element of the range of g and the range of f is a subset of the range of g so o is not an element of the range of f.

Concerning the injection clause: g is an injection on D; so f is a subset of g must be an injection.

Concerning the closure-generates-A clause: by the lemma on closure properties, A is g-closed; a fortiori, A is f-closed. So the closure of o under f is a subset of A by the lemma on closure properties. Since also the closure of o under f is f-closed and f equals the restriction of g to A, it follows that the closure of o under f is g-closed. So A is a subset of the closure of o under f by the lemma on closure properties.

End of proof.

Dedekind Algebras and Arithmetical Induction

Crucially, now, a Dedekind algebra—indeed, any Dedekind algebra—will serve as a surrogate for the natural numbers. This is thanks to the following trivial consequence:

Arithmetical induction theorem for Dedekind algebras

Let N comma s comma o comprise a Dedekind algebra. Then for any set X:

if o is an element of X and for every n in N intersect X, s of n is in X, then N is a subset of X.

Proof

By the definition of a Dedekind algebra, N equals the closure of o under s. Now if both o is an element of X and for every n in N, if n is in X then s of n is in X, then N equals the closure of o under s, and this closure is a subset of X.

End of proof.

Since induction is characteristic of the natural numbers, the point is this. Given any Dedekind infinite set, we can form a Dedekind algebra, and use that algebra as our surrogate for the natural numbers.

Admittedly, the arithmetical induction theorem formulates induction in set-theoretic terms. But we can easily put the principle in terms which might be more familiar:

Formula induction schema for Dedekind algebras

Let N comma s comma o comprise a Dedekind algebra. Then for any formula phi open parenthesis x close parenthesis, which may have parameters:

if phi open parenthesis o close parenthesis and for every n in N, if phi of n holds then phi of s of n holds, then for every n in N, phi of n holds

Proof

Let X equals the set of n in N such that phi of n holds, and now use the arithmetical induction theorem

End of proof.

In this result, we spoke of a formula “having parameters”. What this means, roughly, is that for any objects c sub one comma and so on comma c sub k, we can work with phi open parenthesis x comma c sub one comma and so on comma c sub k close parenthesis. More precisely, we can state the result without mentioning “parameters” as follows. For any formula phi open parenthesis x comma v sub one comma and so on comma v sub k close parenthesis, whose free variables are all displayed, we have: for every v sub one through v sub k: if phi of o, with those parameters, holds, and for every x in N, phi of x, with those parameters, implies phi of s of x, with those parameters, then for every x in N, phi of x, with those parameters, holds Evidently, speaking of “having parameters” can make things much easier to read. (In the Set Theory part, we will use this device rather frequently.)

Returning to Dedekind algebras: given any Dedekind algebra, we can also define the usual arithmetical functions of addition, multiplication and exponentiation. This is non-trivial, however, and it involves the technique of recursive definition. That is a technique which we shall introduce and justify much later, and in a much more general context. (Enthusiasts might want to revisit this after the Ordinal Arithmetic chapter, or perhaps read an alternative treatment, such as Michael Potter two thousand four, pages ninety five through ninety eight.) But, where N comma s comma o comprise a Dedekind algebra, we will ultimately be able to stipulate the following: six recursive arithmetic clauses: a plus o equals a; a times o equals o; a to the power o equals s of o; a plus s of b equals s of the sum a plus b; a times s of b equals a times b plus a; and a to the power s of b equals a to the power b times a and show that these behave as one would hope.

Dedekind's “Proof” of the Existence of an Infinite Set

In this chapter, we have offered a set-theoretic treatment of the natural numbers, in terms of Dedekind algebras. In the reflections section of Arithmetization, we reflected on the philosophical significance of the arithmetisation of analysis (among other things). Now we should reflect on the significance of what we have achieved here.

Throughout the Arithmetization chapter, we took the natural numbers as given, and used them to construct the integers, rationals, and reals, explicitly. In this chapter, we have not given an explicit construction of the natural numbers. We have just shown that, given any Dedekind infinite set, we can define a set which will behave just like we want the natural numbers to behave.

Obviously, then, we cannot claim to have answered a metaphysical question, such as which objects are the natural numbers. But that's a good thing. After all, in the reflections section of Arithmetization, we emphasized that we would be wrong to think of the definition of the real numbers as the set of Dedekind cuts as a discovery, rather than a convenient stipulation. The crucial observation is that the Dedekind cuts exemplify the key mathematical properties of the real numbers. So too here: the crucial observation is that any Dedekind algebra exemplifies the key mathematical properties of the natural numbers. (Indeed, Dedekind pushed this point home by proving that all Dedekind algebras are isomorphic (one thousand eight hundred eighty eight, Theorems one hundred thirty two through one hundred thirty three). It is no surprise, then, that many contemporary “structuralists” cite Dedekind as a forerunner.)

Moreover, we have shown how to embed the theory of the natural numbers into a naïve simple set theory, which itself still remains rather informal, but which doesn't (apparently) assume the natural numbers as given. So, we may be on the way to realising Dedekind's own ambitious project, which he explained thus:

In science nothing capable of proof ought to be believed without proof. Though this demand seems reasonable, I cannot regard it as having been met even in the most recent methods of laying the foundations of the simplest science; viz., that part of logic which deals with the theory of numbers. In speaking of arithmetic (algebra, analysis) as merely a part of logic I mean to imply that I consider the number-concept entirely independent of the notions or intuitions of space and time—that I rather consider it an immediate product of the pure laws of thought. (Richard Dedekind, one thousand eight hundred eighty eight, preface)

Dedekind's bold idea is this. We have just shown how to build the natural numbers using (naïve) set theory alone. In the Arithmetization chapter, we saw how to construct the reals given the natural numbers and some set theory. So, perhaps, “arithmetic (algebra, analysis)” turn out to be “merely a part of logic” (in Dedekind's extended sense of the word “logic”).

That's the idea. But hold on for a moment. Our construction of a Dedekind algebra (our surrogate for the natural numbers) is conditional on the existence of a Dedekind infinite set. (Just look back to the theorem that a Dedekind-infinite set yields a Dedekind algebra.) Unless the existence of a Dedekind infinite set can be established via “logic” or “the pure laws of thought”, the project stalls.

So, can the existence of a Dedekind infinite set be established by “the pure laws of thought”? Here was Dedekind's effort:

My own realm of thoughts, i.e., the totality S of all things which can be objects of my thought, is infinite. For if s signifies an element of S, then the thought s prime that s can be an object of my thought, is itself an element of S. If we regard this as an image phi open parenthesis s close parenthesis of the element s, then and so on S is [Dedekind] infinite, which was to be proved. (Richard Dedekind, one thousand eight hundred eighty eight, section sixty six)

This is quite an astonishing thing to find in the middle of a book which largely consists of highly rigorous mathematical proofs. Two remarks are worth making.

First: this “proof” scarcely has what we would now recognize as a “mathematical” character. It speaks of psychological objects (thoughts), and merely possible ones at that.

Second: at least as we have presented Dedekind algebras, this “proof” has a straightforward technical shortcoming. If Dedekind's argument is successful, it establishes only that there are infinitely many things (specifically, infinitely many thoughts). But Dedekind also needs to give us a reason to regard S as a single set, with infinitely many elements, rather than thinking of S as some things (in the plural).

The fact that Dedekind did not see a gap here might suggest that his use of the word “totality” does not precisely track our use of the word “set”.Indeed, we have other reasons to think it did not; see Michael Potter (two thousand four), page twenty three. But this would not be too surprising. The project we have pursued in the last two chapters—a “construction” of the naturals, and from them a “construction” of the integers, reals and rationals—has all been carried out naïvely. We have helped ourselves to this set, or that set, as and when we have needed them, without laying down many general principles concerning exactly which sets exist, and when. But we know that we need some general principles, for otherwise we will fall into Russell's Paradox.

The time has come for us to outgrow our naïvety.

Appendix: Proving Schröder-Bernstein

Before we depart from naïve set theory, we have one last naïve (but sophisticated!) proof to consider. This is a proof of Schröder-Bernstein (the Schröder-Bernstein theorem in Size of Sets): if A has cardinality no greater than B and B has cardinality no greater than A then A is equinumerous with B; i.e., given injections f from A to B and g from B to A there is a bijection h from A to B.

In this chapter, we followed Dedekind's notion of closures. In fact, Dedekind provided a lovely proof of Schröder-Bernstein using this notion, and we will present it here. The proof closely follows Michael Potter (two thousand four), pages one hundred fifty seven through one hundred fifty eight, if you want a slightly different but essentially similar treatment. A little googling will also convince you that this is a theorem—rather like the irrationality of the square root of two—for which many interesting and different proofs exist.

Using similar notation as the definition of closure generated from one element, let the closure of B under f equals the intersection of all sets X such that B is a subset of X and X is f closed for each set B and function f. Defined thus, the closure of B under f is the smallest f-closed set containing B, in that:

Lemma on closure of a set under a function

For any function f, and any B:

  1. B is a subset of the closure of B under f; and

  2. the closure of B under f is f-closed; and

  3. if X is f-closed and B is a subset of X, then the closure of B under f is a subset of X.

Proof

Exactly as in the lemma on closure properties.

End of proof.

We need one last fact to get to Schröder-Bernstein:

Sandwich proposition for equinumerous sets

If A is a subset of B, and B is a subset of C and A is equinumerous with C, then A is equinumerous with B, and B is equinumerous with C.

Proof

Given a bijection f from C to A, let F equals the closure under f of the set difference C minus B and define a function g with domain C as follows: g of x equals f of x if x is in F, and equals x otherwise We'll show that g is a bijection from C to B, from which it will follow that g composed with f inverse, from A to B is a bijection, completing the proof.

First we claim that if x is an element of F but y is not an element of F then g open parenthesis x close parenthesis is not equal to g open parenthesis y close parenthesis. For reductio suppose otherwise, so that y equals g of y, which equals g of x, which equals f of x. Since x is an element of F and F is f-closed by the lemma on closure of a set under a function, we have y equals f open parenthesis x close parenthesis is an element of F, a contradiction.

Now suppose g open parenthesis x close parenthesis equals g open parenthesis y close parenthesis. So, by the above, x is an element of F iff y is an element of F. If x and y are in F, then f of x equals g of x, which equals g of y, which equals f of y so that x equals y since f is a bijection. If x and y are not in F, then x equals g open parenthesis x close parenthesis equals g open parenthesis y close parenthesis equals y. So g is an injection.

It remains to show that the range of g equals B. So fix x is in B, and B is a subset of C. If x is not an element of F, then g open parenthesis x close parenthesis equals x. If x is an element of F, then x equals f open parenthesis y close parenthesis for some y in F, since otherwise F without open brace x close brace would be f-closed and extend C without B, which is impossible by the lemma on closure of a set under a function; now g open parenthesis y close parenthesis equals f open parenthesis y close parenthesis equals x.

End of proof.

Finally, here is the proof of the main result. Recall that given a function h and set D, we define the image of D under h equals the set of all h of x such that x is in D.

Proof of Schröder-Bernstein

Let f from A to B and g from B to A be injections. Since the image of A under f is a subset of B we have that the image under g of the image of A under f is a subset of the image of B under g, which is a subset of A. Also, g composed with f, from A to the image under g of the image of A under f is an injection since both g and f are; and indeed g composed with f is a bijection, just by the way we defined its codomain. So the image under g of the image of A under f is equinumerous with A, and hence by the sandwich proposition for equinumerous sets there is a bijection h from A to the image of B under g. Moreover, g inverse is a bijection from the image of B under g to B. So g inverse composed with h, from A to B is a bijection.

End of proof.
