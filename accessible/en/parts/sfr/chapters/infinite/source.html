  11. \olsection{Hilbert's Hotel}
  13. The set of the natural numbers is obviously infinite. So, if we do not
  14. want to \emph{help ourselves} to the natural numbers, our first step
  15. must be characterize an infinite set in terms that do not require
  16. mentioning the natural numbers themselves. Here is a nice approach,
  17. presented by Hilbert in a lecture from 1924. He asks us to imagine
  18. \begin{quote}
  19. [\ldots] a hotel with a finite number of rooms. All of these rooms
  20. should be occupied by exactly one guest. If the guests now swap their
  21. rooms somehow, [but] so that each room still contains no more than one
  22. person, then no rooms will become free, and the hotel-owner cannot in
  23. this way create a new place for a newly arriving guest [\ldots
  24. \textparagraph \ldots]
  26. Now we stipulate that the hotel shall have infinitely many numbered
  27. rooms $1$, $2$, $3$, $4$, $5$, \dots, each of which is occupied by
  28. exactly one guest. As soon as a new guest comes along, the owner only
  29. needs to move each of the old guests into the room associated with the
  30. number one higher, and room~$1$ will be free for the newly-arriving
  31. guest.
  32. \begin{center}
  33. \begin{tikzpicture}[scale = .75]
  34. \foreach \x in {1, 2, 3, 4, 5, 6, 7, 8, 9}
  35. {
  36. \node (\x a) at (\x, 1) {\small{\x}};
  37. \node (\x b) at (\x, 2) {\small{\x}};
  38. }
  39. \node (dotsa) at (10, 1) {\small{\ldots}};
  40. \node (dotsb) at (10, 2) {\small{\ldots}};
  41. \draw[->] (1b)--(2a);
  42. \draw[->] (2b)--(3a);
  43. \draw[->] (3b)--(4a);
  44. \draw[->] (4b)--(5a);
  45. \draw[->] (5b)--(6a);
  46. \draw[->] (6b)--(7a);
  47. \draw[->] (7b)--(8a);
  48. \draw[->] (8b)--(9a);
  49. \draw[->] (9b)--(dotsa);
  50. \draw (1,1) circle (.4);
  51. \end{tikzpicture}
  52. \end{center}
  53. (published in \citealt[730]{EwaldSieg2013}; our translation)
  54. \end{quote}
  55. The crucial point is that Hilbert's Hotel has infinitely many rooms;
  56. and we can take his explanation to define what it means to say this.
  57. Indeed, this was Dedekind's approach (presented here, of course, with
  58. massive anachronism; Dedekind's definition is from
  59. \citeyear{Dedekind1888}):
  61. \begin{defn}\ollabel{defn:DedekindInfinite}
  62. A set $A$ is \emph{Dedekind infinite} iff there is !!a{injection}
  63. from~$A$ to a proper subset of~$A$. That is, there is some $o \in A$
  64. and !!a{injection} $f \colon A \to A$ such that $o \notin \ran{f}$.
  65. \end{defn}

  71. \olsection{Dedekind Algebras}
  73. We not only want natural numbers to be infinite; we want them to have
  74. certain (algebraic) properties: they need to behave well under
  75. addition, multiplication, and so forth.
  77. Dedekind's idea was to take the idea of the \emph{successor function}
  78. as basic, and then characterise the numbers as those with the
  79. following properties:
  80. \begin{enumerate}
  81. \item There is a number, $0$, which is not the successor of any number
  82. \\i.e., $0 \notin \ran{s}$
  83. \\i.e., $\forall x\ s(x) \neq 0$
  84. \item Distinct numbers have distinct successors
  85. \\i.e., $s$ is !!a{injection}
  86. \\i.e., $\forall x \forall y (s(x) = s(y) \lif x = y)$
  87. \item\ollabel{repeatedapplication} Every number is obtained from
  88. $0$ by repeated applications of the successor function.
  89. \end{enumerate}
  90. The first two conditions are easy to deal with using first-order logic
  91. (see above). But we cannot deal with \olref{repeatedapplication} just
  92. using first-order logic. Dedekind's breakthrough was to reformulate
  93. condition \olref{repeatedapplication}, set-theoretically, as follows:
  94. \begin{enumerate}
  95. \item[3$'$.] The natural numbers are the smallest set that is
  96. \emph{closed under the successor function}: that is, if we apply
  97. $s$ to any !!{element} of the set, we obtain another !!{element}
  98. of the set.
  99. \end{enumerate}
  100. But we shall need to spell this out slowly.
  102. \begin{defn}\ollabel{Closure}
  103. For any function $f$, the set $X$ is $f$-\emph{closed} {iff}
  104. $(\forall x \in X)f(x) \in X$. Now define, for any $o$:
  105. $$\closureofunder{f}{o} = \bigcap\Setabs{X}{o \in X\text{ and }X
  106. \text{ is $f$-closed}}$$
  107. \end{defn}
  109. So $\closureofunder{f}{o}$ is the intersection of all the $f$-closed
  110. sets with $o$ as !!a{element}. Intuitively, then,
  111. $\closureofunder{f}{o}$ is the \emph{smallest} $f$-closed set with $o$
  112. as !!a{element}. This next result makes that intuitive thought
  113. precise;
  114. \begin{lem}\ollabel{closureproperties}
  115. For any function $f$ and any $o \in A$:
  116. \begin{enumerate}
  117. \item\ollabel{closurehaselem} $o \in \closureofunder{f}{o}$; and
  118. \item\ollabel{closureclosed} $\closureofunder{f}{o}$ is $f$-closed; and
  119. \item\ollabel{closuresmallest} if $X$ is $f$-closed and $o \in
  120. X$, then $\closureofunder{f}{o} \subseteq X$
  121. \end{enumerate}
  122. \end{lem}
  124. \begin{proof}
  125. Note that there is at least one $f$-closed set with $o$ as !!a{element}, namely $\ran{f}\cup
  126. \{o\}$. So $\closureofunder{f}{o}$, the intersection of \emph{all}
  127. such sets, exists. We must now check
  128. \olref{closurehaselem}--\olref{closuresmallest}.
  130. Concerning \olref{closurehaselem}: $o \in \closureofunder{f}{o}$ as it is an
  131. intersection of sets which all have $o$ as !!a{element}.
  133. Concerning \olref{closureclosed}: suppose $x \in \closureofunder{f}{o}$. So if $o \in X$ and $X$ is $f$-closed, then $x \in X$, and now $f(x) \in X$ as $X$ is
  134. $f$-closed. So $f(x) \in \closureofunder{f}{o}$.
  136. Concerning \olref{closuresmallest}: quite generally, if $X
  137. \in C$ then $\bigcap C \subseteq X$.
  138. \end{proof}
  140. Using this, we can say:
  142. \begin{defn}
  143. A \emph{Dedekind algebra} is a set $A$ together with a function $f
  144. \colon A \to A$ and some $o \in A$ such that:
  145. \begin{enumerate}
  146. \item \ollabel{ded:proper} $o \notin \ran{f}$
  147. \item \ollabel{ded:injection} $f$ is !!a{injection}
  148. \item \ollabel{ded:closure} $A = \closureofunder{f}{o}$
  149. \end{enumerate}
  150. \end{defn}
  152. Since $A = \closureofunder{f}{o}$, our earlier result tells us that
  153. $A$ is the smallest $f$-closed set with $o$ as !!a{element}. Clearly a
  154. Dedekind algebra is Dedekind infinite; just look at clauses
  155. \olref{ded:proper} and \olref{ded:injection} of the definition. But
  156. the more exciting fact is that any Dedekind infinite set can be turned
  157. into a Dedekind algebra.
  159. \begin{thm}\ollabel{thm:DedekindInfiniteAlgebra}
  160. If there is a Dedekind infinite set, then there is a Dedekind algebra.
  161. \end{thm}
  163. \begin{proof}
  164. Let $D$ be Dedekind infinite. So there is an injection $g \colon D \to
  165. D$ and an element $o \in D \setminus \ran{g}$. Now let $A =
  166. \closureofunder{g}{o}$; by \olref{closureproperties}, $A$ exists and $o \in A$. Let $f =
  167. \funrestrictionto{g}{A}$. We will show that $A, f, o$ comprise a Dedekind
  168. algebra.
  170. Concerning \olref{ded:proper}: $o \notin \ran{g}$ and $\ran{f}
  171. \subseteq \ran{g}$ so $o\notin \ran{f}$.
  173. Concerning \olref{ded:injection}: $g$ is an injection on $D$; so $f
  174. \subseteq g$ must be an injection.
  176. Concerning \olref{ded:closure}: by \olref{closureproperties}, $A$ is $g$-closed; a fortiori, $A$ is $f$-closed. So $\closureofunder{f}{o} \subseteq A$ by \olref{closureproperties}. Since also $\closureofunder{f}{o}$ is $f$-closed and $f = \funrestrictionto{g}{A}$, it follows that $\closureofunder{f}{o}$ is $g$-closed. So $A \subseteq \closureofunder{f}{o}$ by \olref{closureproperties}.
  177. \end{proof}

  183. \olsection[Arithmetical Induction]{Dedekind Algebras and Arithmetical Induction}
  185. Crucially, now, a Dedekind algebra---indeed, \emph{any} Dedekind
  186. algebra---will serve as a surrogate for the natural numbers. This is
  187. thanks to the following trivial consequence:
  189. \begin{thm}[Arithmetical induction]\ollabel{thm:dedinfiniteinduction}
  190. Let $N, s, o$ comprise a Dedekind algebra. Then for any set $X$:
  191. \begin{center}
  192. if $o \in X$ and $(\forall {n} \in N \cap X){s}({n}) \in X$, {then} $N \subseteq X$.
  193. \end{center}
  194. \end{thm}
  196. \begin{proof}
  197. By the definition of a Dedekind algebra, $N = \closureofunder{s}{o}$.
  198. Now if both ${o} \in X$ and $(\forall {n} \in N)(n \in X \lif
  199. {s}({n}) \in X)$, then $N = \closureofunder{s}{o} \subseteq X$.
  200. \end{proof}
  202. Since induction is characteristic of the natural numbers, the point is
  203. this. Given any Dedekind infinite set, we can form a Dedekind algebra,
  204. and use that algebra as our surrogate for the natural numbers.
  206. Admittedly, \olref{thm:dedinfiniteinduction} formulates induction in
  207. \emph{set-theoretic} terms. But we can easily put the principle in
  208. terms which might be more familiar:
  210. \begin{cor}\ollabel{natinductionschema}
  211. Let $N, s, o$ comprise a Dedekind algebra. Then for any formula
  212. $\phi(x)$, which may have parameters:
  213. \begin{center}
  214. if $\phi(o)$ and $(\forall {n} \in N)(\phi(n)\lif
  215. \phi({s}({n})))$, {then} $(\forall n \in N)\phi(n)$
  216. \end{center}
  217. \end{cor}
  219. \begin{proof}
  220. Let $X = \Setabs{n \in N}{\phi(n)}$, and now use
  221. \olref{thm:dedinfiniteinduction}
  222. \end{proof}
  224. In this result, we spoke of a formula ``having parameters''. What this
  225. means, roughly, is that for any objects $c_1, \ldots, c_k$, we can
  226. work with $\phi(x, c_1, \ldots, c_k)$. More precisely, we can state
  227. the result without mentioning ``parameters'' as follows. For any
  228. formula $\phi(x, v_1, \ldots, v_k)$, whose free variables are all
  229. displayed, we have:
  230. \begin{align*}
  231. \forall v_1 \ldots \forall v_k((&\phi(o, v_1,\ldots, v_k) \land {}\\
  232. & (\forall x \in N)(\phi(x,v_1, \ldots, v_k) \lif \phi(s(x), v_1,\ldots, v_k))) \lif {}\\
  233. &\hspace{3em} (\forall x \in N)\phi(x, v_1,\ldots, v_k))
  234. \end{align*}
  235. Evidently, speaking of ``having parameters'' can make things much
  236. easier to read. (In \olref[sth][][]{part}, we will use this device
  237. rather frequently.)
  239. Returning to Dedekind algebras: given any Dedekind algebra, we can
  240. also define the usual arithmetical functions of addition,
  241. multiplication and exponentiation. This is non-trivial, however, and
  242. it involves the technique of \emph{recursive definition}. That is a
  243. technique which we shall introduce and justify much later, and in a
  244. much more general context. (Enthusiasts might want to revisit this
  245. after \olref[sth][ord-arithmetic][]{chap}, or perhaps read an alternative
  246. treatment, such as \citealt[pp.~95--8]{Potter2004}.) But, where $N, s, o$
  247. comprise a Dedekind algebra, we will ultimately be able to stipulate the
  248. following:
  249. \begin{align*}
  250. {a} + {o} &= {a} & & & {a} \times {o} &= {o} & & & {a}^{o} &= s(o)\\
  251. {a} + {s}({b}) &= {s}({a}+{b}) &&& {a} \times {s}({b}) &= ({a}\times {b}) + {a} & & & {a}^{{s}({b})} &= {a}^{b} \times {a}
  252. \end{align*}
  253. and show that these behave as one would hope.

  260. \olsection[Dedekind's ``Proof'']{Dedekind's ``Proof'' of the
  261. Existence of an Infinite Set}
  263. In this chapter, we have offered a set-theoretic treatment of the
  264. natural numbers, in terms of Dedekind algebras. In
  265. \olref[arith][ref]{sec}, we reflected on the philosophical
  266. significance of the arithmetisation of analysis (among other things).
  267. Now we should reflect on the significance of what we have achieved
  268. here.
  270. Throughout \olref[sfr][arith][]{chap}, we took the natural numbers as
  271. given, and used them to construct the integers, rationals, and reals,
  272. explicitly. In this chapter, we have not given an explicit
  273. construction of the natural numbers. We have just shown that,
  274. \emph{given any Dedekind infinite set}, we can define a set which will
  275. behave just like we want~$\Nat$ to behave.
  277. Obviously, then, we cannot claim to have answered a metaphysical
  278. question, such as \emph{which objects are the natural numbers}. But
  279. that's a good thing. After all, in \olref[sfr][arith][ref]{sec}, we
  280. emphasized that we would be wrong to think of the definition of
  281. $\Real$ as the set of Dedekind cuts as a \emph{discovery}, rather than
  282. a convenient stipulation. The crucial observation is that the Dedekind
  283. cuts exemplify the key mathematical properties of the real
  284. numbers. So too here: the crucial observation is that \emph{any}
  285. Dedekind algebra exemplifies the key mathematical properties of the
  286. natural numbers. (Indeed, Dedekind pushed this point home by proving
  287. that all Dedekind algebras are \emph{isomorphic} (\citeyear[Theorems
  288. 132--3]{Dedekind1888}). It is no surprise, then, that many
  289. contemporary ``structuralists'' cite Dedekind as a forerunner.)
  291. Moreover, we have shown how to embed the theory of the natural
  292. numbers into a na\"ive simple set theory, which itself still remains
  293. rather informal, but which doesn't (apparently) assume the natural
  294. numbers as given. So, we may be on the way to realising Dedekind's
  295. own ambitious project, which he explained thus:
  296. \begin{quote}
  297. In science nothing capable of proof ought to be believed without
  298. proof. Though this demand seems reasonable, I cannot regard it as
  299. having been met even in the most recent methods of laying the
  300. foundations of the simplest science; viz., that part of logic
  301. which deals with the theory of numbers. In speaking of arithmetic
  302. (algebra, analysis) as merely a part of logic I mean to imply that
  303. I consider the number-concept entirely independent of the notions
  304. or intuitions of space and time---that I rather consider it an
  305. immediate product of the pure laws of thought.
  306. \citep[preface]{Dedekind1888}
  307. \end{quote}
  308. Dedekind's bold idea is this. We have just shown how to build the
  309. natural numbers using (na\"ive) set theory alone. In
  310. \olref[sfr][arith][]{chap}, we saw how to construct the reals given
  311. the natural numbers and some set theory. So, perhaps, ``arithmetic
  312. (algebra, analysis)'' turn out to be ``merely a part of logic'' (in
  313. Dedekind's extended sense of the word ``logic'').
  315. That's the idea. But hold on for a moment. Our construction of a
  316. Dedekind algebra (our surrogate for the natural numbers) is
  317. conditional on the existence of a Dedekind infinite set. (Just look
  318. back to \olref[sfr][infinite][dedekind]{thm:DedekindInfiniteAlgebra}.)
  319. Unless the existence of a Dedekind infinite set can be established via
  320. ``logic'' or ``the pure laws of thought'', the project stalls.
  322. So, \emph{can} the existence of a Dedekind infinite set be established
  323. by ``the pure laws of thought''? Here was Dedekind's effort:
  324. \begin{quote}
  325. My own realm of thoughts, i.e., the totality $S$ of all things which
  326. can be objects of my thought, is infinite. For if $s$ signifies an
  327. element of~$S$, then the thought $s'$ that~$s$ can be an object of
  328. my thought, is itself an element of~$S$. If we regard this as an
  329. image $\phi(s)$ of the element~$s$, then \dots~$S$ is [Dedekind]
  330. infinite, which was to be proved.
  331. \citep[\S66]{Dedekind1888}
  332. \end{quote}
  333. This is quite an astonishing thing to find in the middle of a book
  334. which largely consists of highly rigorous mathematical proofs. Two
  335. remarks are worth making.
  337. First: this ``proof'' scarcely has what we would now recognize as a
  338. ``mathematical'' character. It speaks of psychological objects
  339. (thoughts), and merely \emph{possible} ones at that.
  341. Second: at least as we have presented Dedekind algebras, this
  342. ``proof'' has a straightforward technical shortcoming. If Dedekind's
  343. argument is successful, it establishes only that there are infinitely
  344. many things (specifically, infinitely many thoughts). But Dedekind
  345. also needs to give us a reason to regard~$S$ as a single \emph{set},
  346. with infinitely many !!{element}s, rather than thinking of~$S$ as
  347. \emph{some things} (in the plural).
  349. The fact that Dedekind did not see a gap here might suggest that his
  350. use of the word ``totality'' does not precisely track \emph{our} use
  351. of the word ``set''.\footnote{Indeed, we have other reasons to think
  352. it did not; see \citet[p.~23]{Potter2004}.} But this would not be
  353. too surprising. The project we have pursued in the last two
  354. chapters---a ``construction'' of the naturals, and from them a
  355. ``construction'' of the integers, reals and rationals---has all been
  356. carried out na\"ively. We have helped ourselves to this set, or that
  357. set, as and when we have needed them, without laying down many general
  358. principles concerning exactly which sets exist, and when. But we know
  359. that we need \emph{some} general principles, for otherwise we will
  360. fall into Russell's Paradox.
  362. The time has come for us to outgrow our na\"ivety.

  369. \olsection{Appendix: Proving Schr\"oder-Bernstein}
  371. Before we depart from na\"ive set theory, we have one last na\"ive
  372. (but sophisticated!) proof to consider. This is a proof of
  373. Schr\"oder-Bernstein (\olref[sfr][siz][sb]{thm:schroder-bernstein}): if
  374. $\cardle{A}{B}$ and $\cardle{B}{A}$ then $\cardeq{A}{B}$; i.e., given
  375. !!{injection}s $f \colon A \to B$ and $g \colon B \to A$ there is
  376. !!a{bijection} $h \colon A \to B$.
  378. In this chapter, we followed Dedekind's notion of \emph{closures}. In
  379. fact, Dedekind provided a lovely proof of Schr\"oder-Bernstein using this notion, and we
  380. will present it here. The proof closely follows
  381. \citet[pp.~157--8]{Potter2004}, if you want a slightly different but
  382. essentially similar treatment. A little googling will also convince
  383. you that this is a theorem---rather like the irrationality of
  384. $\sqrt{2}$---for which \emph{many} interesting and different proofs
  385. exist.
  387. Using similar notation as \olref[sfr][infinite][dedekind]{Closure},
  388. let
  389. \[
  390. \Closureofunder{f}{B} = \bigcap \Setabs{X}{B \subseteq X
  391. \text{ and $X$ is $f$-closed}}
  392. \]
  393. for each set $B$ and function~$f$. Defined thus,
  394. $\Closureofunder{f}{B}$ is the smallest $f$-closed set containing~$B$,
  395. in that:
  397. \begin{lem}\ollabel{Closureprops}
  398. For any function $f$, and any $B$:
  399. \begin{enumerate}
  400. \item\ollabel{Closurehaselem} $B \subseteq \Closureofunder{f}{B}$; and
  401. \item\ollabel{Closureclosed} $\Closureofunder{f}{B}$ is $f$-closed; and
  402. \item\ollabel{Closuresmallest} if $X$ is $f$-closed and $B
  403. \subseteq X$, then $\Closureofunder{f}{B} \subseteq X$.
  404. \end{enumerate}
  405. \end{lem}
  407. \begin{proof}
  408. Exactly as in \olref[sfr][infinite][dedekind]{closureproperties}.
  409. \end{proof}
  411. We need one last fact to get to Schr\"oder-Bernstein:
  413. \begin{prop}\ollabel{sbhelper}
  414. If $A \subseteq B \subseteq C$ and $A \approx C$, then $\cardeq{\cardeq{A}{B}}{C}$.
  415. \end{prop}
  417. \begin{proof}
  418. Given !!a{bijection} $f \colon C \to A$, let $F =
  419. \Closureofunder{f}{C \setminus B}$ and define a function $g$ with
  420. domain $C$ as follows:
  421. \[
  422. g(x) =
  423. \begin{cases}
  424. f(x) &\text{if $x \in F$}\\
  425. x & \text{otherwise}
  426. \end{cases}
  427. \]
  428. We'll show that $g$ is !!a{bijection} from $C \to B$, from which it
  429. will follow that $\comp{f^{-1}}{g} \colon A \to B$ is !!a{bijection},
  430. completing the proof.
  432. First we claim that if $x \in F$ but $y\notin F$ then $g(x) \neq
  433. g(y)$. For reductio suppose otherwise, so that $y = g(y) = g(x) =
  434. f(x)$. Since $x \in F$ and $F$ is $f$-closed by \olref{Closureprops},
  435. we have $y = f(x) \in F$, a contradiction.
  437. Now suppose $g(x) = g(y)$. So, by the above, $x \in F$ iff $y \in F$.
  438. If $x, y \in F$, then $f(x) = g (x) = g(y) = f(y)$ so that $x = y$
  439. since $f$ is !!a{bijection}. If $x, y \notin F$, then $x = g(x) =
  440. g(y) = y$. So $g$ is !!a{injection}.
  442. It remains to show that $\ran{g} = B$. So fix $x \in B \subseteq C$.
  443. If $x \notin F$, then $g(x) = x$. If $x \in F$, then $x = f(y)$ for
  444. some $y \in F$, since otherwise $F \setminus \{x\}$ would be $f$-closed and extend $C\setminus B$, which is impossible by \olref{Closureprops}; now $g(y) = f(y) = x$.
  445. \end{proof}
  447. Finally, here is the proof of the main result. Recall that given a
  448. function $h$ and set $D$, we define $\funimage{h}{D} = \Setabs{h(x)}{x
  449. \in D}$.
  451. \begin{proof}[Proof of Schr\"oder-Bernstein] Let $f \colon A \to B$
  452. and $g \colon B \to A$ be !!{injection}s. Since $\funimage{f}{A}
  453. \subseteq B$ we have that $\funimage{g}{\funimage{f}{A}} \subseteq
  454. g[B] \subseteq A$. Also, $\comp{f}{g} \colon A \to
  455. \funimage{g}{\funimage{f}{A}}$ is an !!{injection} since both $g$ and
  456. $f$ are; and indeed $\comp{f}{g}$ is !!a{bijection}, just by the way
