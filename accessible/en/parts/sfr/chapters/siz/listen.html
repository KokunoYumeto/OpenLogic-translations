Introduction

When Georg Cantor developed set theory in the 1870s, one of his aims was to make palatable the idea of an infinite collection—an actual infinity, as the medievals would say. A key part of this was his treatment of the size of different sets. If a, b and c are all distinct, then the set open brace a comma b comma c close brace is intuitively larger than open brace a comma b close brace. But what about infinite sets? Are they all as large as each other? It turns out that they are not.

The first important idea here is that of an enumeration. We can list every finite set by listing all its elements. For some infinite sets, we can also list all their elements if we allow the list itself to be infinite. Such sets are called enumerable. Cantor's surprising result, which we will fully understand by the end of this chapter, was that some infinite sets are not enumerable.

Definition: Informal enumeration

Informally, an enumeration of a set A is a list (possibly infinite) of elements of A such that every element of A appears on the list at some finite position. If A has an enumeration, then A is said to be enumerable.

Explanation

A couple of points about enumerations:

  1. We count as enumerations only lists which have a beginning and in which every element other than the first has a single element immediately preceding it. In other words, there are only finitely many elements between the first element of the list and any other element. In particular, this means that every element of an enumeration has a finite position: the first element has position 1, the second position 2, etc.

  2. We can have different enumerations of the same set A which differ by the order in which the elements appear: 4, 1, 25, 16, 9 enumerates the (set of the) first five square numbers just as well as 1, 4, 9, 16, 25 does.

  3. Redundant enumerations are still enumerations: 1, 1, 2, 2, 3, 3, and so on enumerates the same set as 1, 2, 3, and so on does.

  4. Order and redundancy do matter when we specify an enumeration: we can enumerate the positive integers beginning with 1, 2, 3, 1, and so on, but the pattern is easier to see when enumerated in the standard way as 1, 2, 3, 4, and so on

Nonenumerable Sets

Editorial note

This section proves the non-enumerability of the set of binary digits to the power omega and the power set of the positive integers using the definition in Enumerations and Enumerable Sets. It is designed to be a little more elementary and a little more detailed than the version in Enumerations and Enumerable Sets

Some sets, such as the set the positive integers of positive integers, are infinite. So far we've seen examples of infinite sets which were all enumerable. However, there are also infinite sets which do not have this property. Such sets are called nonenumerable.

First of all, it is perhaps already surprising that there are nonenumerable sets. For any enumerable set A there is a surjective function f from the positive integers to A. If a set is nonenumerable there is no such function. That is, no function mapping the infinitely many elements of the positive integers to A can exhaust all of A. So there are “more” elements of A than the infinitely many positive integers.

How would one prove that a set is nonenumerable? You have to show that no such surjective function can exist. Equivalently, you have to show that the elements of A cannot be enumerated in a one way infinite list. The best way to do this is to show that every list of elements of A must leave at least one element out; or that no function f from the positive integers to A can be surjective. We can do this using Cantor's diagonal method. Given a list of elements of A, say, x sub 1, x sub 2, and so on, we construct another element of A which, by its construction, cannot possibly be on that list.

Our first example is the set the set of binary digits to the power omega of all infinite, non-gappy sequences of 0's and 1's.

Explanation

The set the natural numbers of natural numbers is infinite. It is also trivially enumerable. But the remarkable fact is that there are nonenumerable sets, i.e., sets which are not enumerable (see Definition: Enumerable and nonenumerable sets in the set-theoretic presentation).

This might be surprising. After all, to say that A is nonenumerable is to say that there is no bijection f from the natural numbers to A; that is, no function mapping the infinitely many elements of the natural numbers to A exhausts all of A. So if A is nonenumerable, there are “more” elements of A than there are natural numbers.

To prove that a set is nonenumerable, you have to show that no appropriate bijection can exist. The best way to do this is to show that every attempt to enumerate elements of A must leave at least one element out; this shows that no function f from the natural numbers to A is surjective. And a general strategy for establishing this is to use Cantor's diagonal method. Given a list of elements of A, say, x sub 1, x sub 2, and so on, we construct another element of A which, by its construction, cannot possibly be on that list.

But all of this is best understood by example. So, our first example is the set the set of binary digits to the power omega of all infinite strings of 0's and 1's. We proved that the set of binary digits to the power omega is nonenumerable by a diagonalization argument.
