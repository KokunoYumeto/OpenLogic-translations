  11. \olsection{Sets of Different Sizes, and Cantor's Theorem}
  13. \begin{explain}
  14. We have offered a precise statement of the idea that two sets have the
  15. same size. We can also offer a precise statement of the idea that one
  16. set is smaller than another. Our definition of ``is smaller than (or
  17. equinumerous)'' will require, instead of !!a{bijection} between the
  18. sets, !!a{injection} from the first set to the second. If such a
  19. function exists, the size of the first set is less than or equal to
  20. the size of the second. Intuitively, !!a{injection} from one set to
  21. another guarantees that the range of the function has at least as many
  22. !!{element}s as the domain, since no two !!{element}s of the domain
  23. map to the same !!{element} of the range.
  24. \end{explain}
  26. \begin{defn}
  27. $A$ is \emph{no larger than}~$B$, written $\cardle{A}{B}$, iff there
  28. is !!a{injection} $f \colon A \to B$.
  29. \end{defn}
  31. It is clear that this is a reflexive and transitive relation, but that
  32. it is not symmetric (this is left as an exercise). We can also
  33. introduce a notion, which states that one set is (strictly) smaller
  34. than another.
  36. \begin{defn}
  37. $A$ is \emph{smaller than}~$B$, written $\cardless{A}{B}$, iff there
  38. is !!a{injection}~$f\colon A \to B$ but no !!{bijection}~$g\colon A
  39. \to B$, i.e., $\cardle{A}{B}$ and $\cardneq{A}{B}$.
  40. \end{defn}
  42. It is clear that this relation is irreflexive
  43. and transitive. (This is left as an exercise.) Using this notation, we
  44. can say that a set $A$ is !!{enumerable} iff $\cardle{A}{\Nat}$, and
  45. that $A$ is !!{nonenumerable} iff $\cardless{\Nat}{A}$. This allows us
  46. to restate
  47. \oliflabeldef{sfr:siz:nen-alt:thm:nonenum-pownat}{%
  48. \olref[sfr][siz][nen-alt]{thm:nonenum-pownat}
  49. as the observation that
  50. $\cardless{\Nat}{\Pow{\Nat}}$}{%
  51. \olref[sfr][siz][nen]{thm:nonenum-pownat}
  52. as the observation that $\cardless{\PosInt}{\Pow{\PosInt}}$}. In fact,
  53. \citet{Cantor1892} proved that this last point is \emph{perfectly
  54. general}:
  56. \begin{thm}[Cantor]\ollabel{thm:cantor}
  57. $\cardless{A}{\Pow{A}}$, for any set $A$.
  58. \end{thm}
  60. \begin{proof}
  61. The map $f(x) = \{x\}$ is !!a{injection} $f \colon A \to \Pow{A}$,
  62. since if $x \neq y$, then also $\{x\} \neq \{y\}$ by extensionality,
  63. and so $f(x) \neq f(y)$. So we have that $\cardle{A}{\Pow{A}}$.

  13. \begin{editorial}
  14. This section defines enumerations as bijections with (initial
  15. segments) of $\Nat$, the way it's done in set theory. So it
  16. conflicts slightly with the definitions in \olref[enm]{sec}, and
  17. repeats all the examples there. It is also a bit more terse than
  18. that section.
  19. \end{editorial}
  21. We can specify finite set is by simply enumerating its
  22. !!{element}s. We do this when we define a set like so:
  23. \[
  24. A = \{a_1, a_2, \ldots, a_n\}.
  25. \]
  26. Assuming that the !!{element}s $a_1$, \dots, $a_n$ are all distinct,
  27. this gives us !!a{bijection} between $A$ and the first $n$ natural
  28. numbers $0$, \dots, $n-1$. Conversely, since every finite set has only
  29. finitely many !!{element}s, every finite set can be put into such a
  30. correspondence. In other words, if $A$ is finite, there is
  31. !!a{bijection} between $A$ and $\{0, \dots, n-1\}$, where $n$ is the
  32. number of !!{element}s of~$A$.
  34. If we allow for certain kinds of infinite sets, then we will also
  35. allow some infinite sets to be enumerated. We can make this precise by
  36. saying that an infinite set is enumerated by !!a{bijection} between it
  37. and all of~$\Nat$.
  39. \begin{defn}[Enumeration, set-theoretic]
  40. An \emph{enumeration} of a set $A$ is !!a{bijection} whose range is
  41. $A$ and whose domain is either an initial set of natural numbers $\{0,
  42. 1, \ldots, n\}$ {or} the entire set of natural numbers~$\Nat$.
  43. \end{defn}
  45. \begin{explain}
  46. There is an intuitive underpinning to this use of the word
  47. \emph{enumeration}. For to say that we have enumerated a set $A$ is to
  48. say that there is !!a{bijection} $f$ which allows us to count out the
  49. elements of the set $A$. The $0$th element is $f(0)$, the 1st is
  50. $f(1)$, \ldots the $n$th is $f(n)$\ldots.\footnote{Yes, we count
  51. from $0$. Of course we could also start with~$1$. This would
  52. make no big difference. We would just have to replace~$\Nat$
  53. by~$\PosInt$.} The rationale for this may be made even clearer by
  54. adding the following:
  55. \end{explain}
  57. \begin{defn}
  58. \ollabel{defn:enumerable}
  59. A set~$A$ is !!{enumerable} iff either $A = \emptyset$ or there is
  60. an enumeration of~$A$. We say that $A$ is !!{nonenumerable} iff $A$
  61. is not !!{enumerable}.
  62. \end{defn}
  64. \begin{explain}

  66. enumeration to count out its !!{element}s.
  67. \end{explain}

  11. \olsection{Enumerations and \usetoken{S}{enumerable} Sets}
  13. \begin{editorial}
  14. This section discusses enumerations of sets, defining them as
  15. surjections from $\PosInt$. It does things slowly, for readers with
  16. little mathematical background. An alternative, terser
  17. version is given in \olref[enm-alt]{sec}, which defines enumerations
  18. differently: as bijections with $\Nat$ (or an initial segment).
  19. \end{editorial}
  21. \begin{explain}
  22. We've already given examples of sets by listing their !!{element}s.
  23. Let's discuss in more general terms how and when we can list the
  24. !!{element}s of a set, even if that set is infinite.
  25. \end{explain}
  27. \begin{defn}[Enumeration, informally]
  28. Informally, an \emph{enumeration} of a set~$A$ is a list (possibly
  29. infinite) of !!{element}s of~$A$ such that every !!{element} of $A$
  30. appears on the list at some finite position. If $A$ has an
  31. enumeration, then $A$ is said to be \emph{!!{enumerable}}.
  32. \end{defn}
  34. \begin{explain}
  35. A couple of points about enumerations:
  36. \begin{enumerate}
  37. \item We count as enumerations only lists which have a beginning and
  38. in which every !!{element} other than the first has a single
  39. !!{element} immediately preceding it. In other words, there are
  40. only finitely many elements between the first !!{element} of the
  41. list and any other !!{element}. In particular, this means that every
  42. !!{element} of an enumeration has a finite position: the first
  43. !!{element} has position~$1$, the second position~$2$, etc.
  44. \item We can have different enumerations of the same set~$A$ which
  45. differ by the order in which the !!{element}s appear: $4$, $1$,
  46. $25$, $16$,~$9$ enumerates the (set of the) first five square
  47. numbers just as well as $1$, $4$, $9$, $16$,~$25$ does.
  48. \item Redundant enumerations are still enumerations: $1$, $1$, $2$,
  49. $2$, $3$, $3$,~\dots{} enumerates the same set as $1$, $2$,
  50. $3$,~\dots{} does.
  51. \item Order and redundancy \emph{do} matter when we specify an
  52. enumeration: we can enumerate the positive integers beginning with
  53. $1$, $2$, $3$, $1$, \dots{}, but the pattern is easier to see when
  54. enumerated in the standard way as $1$, $2$, $3$, $4$,~\dots
  55. \item Enumerations must have a beginning: \dots, $3$, $2$, $1$ is not
  56. an enumeration of the positive integers because it has no first
  57. !!{element}. To see how this follows from the informal definition,
  58. ask yourself, ``at what position in the list does the number 76
  59. appear?''
  60. \item The following is not an enumeration of the positive integers:
  61. $1$, $3$, $5$, \dots, $2$, $4$, $6$, \dots\@ The problem is that the
  62. even numbers occur at places $\infty + 1$, $\infty + 2$, $\infty +
  63. 3$, rather than at finite positions.
  64. \item The empty set is enumerable: it is enumerated by the empty list!{}
  65. \end{enumerate}
  66. \end{explain}
  68. \begin{prop}
  69. If $A$ has an enumeration, it has an enumeration without
  70. repetitions.
  71. \end{prop}
  73. \begin{proof}
  74. Suppose $A$ has an enumeration $x_1$, $x_2$, \dots{} in which each
  75. $x_i$ is an !!{element} of~$A$. We can remove repetitions from an
  76. enumeration by removing repeated !!{element}s. For instance, we can
  77. turn the enumeration into a new one in which we list $x_i$ if
  78. it is !!a{element} of~$A$ that is not among $x_1$, \dots,
  79. $x_{i-1}$ or remove $x_i$ from the list if it already appears among
  80. $x_1$, \dots,~$x_{i-1}$.
  81. \end{proof}
  83. The last argument shows that in order to get a good handle on
  84. enumerations and !!{enumerable} sets and to prove things about them,
  85. we need a more precise definition. The following provides it.
  87. \begin{defn}[Enumeration, formally]
  88. An \emph{enumeration} of a set $A \neq \emptyset$ is any
  89. !!{surjective} function $f \colon \PosInt \to A$.
  90. \end{defn}
  92. \begin{explain}
  93. Let's convince ourselves that the formal definition and the informal
  94. definition using a possibly infinite list are equivalent. First, any
  95. !!{surjective} function from $\PosInt$ to a set~$A$ enumerates~$A$.
  96. Such a function determines an enumeration as defined informally above:
  97. the list $f(1)$, $f(2)$, $f(3)$, \dots. Since $f$ is !!{surjective},
  98. every !!{element} of~$A$ is guaranteed to be the value of~$f(n)$ for
  99. some~$n \in \PosInt$. Hence, every !!{element} of $A$ appears at some
  100. finite position in the list. Since the function may not be
  101. !!{injective}, the list may be redundant, but that is acceptable (as
  102. noted above).
  104. On the other hand, given a list that enumerates all !!{element}s
  105. of~$A$, we can define !!a{surjective} function $f\colon \PosInt \to A$
  106. by letting $f(n)$ be the $n$th !!{element} of the list, or the final
  107. !!{element} of the list if there is no $n$th !!{element}. The only
  108. case where this does not produce !!a{surjective} function is when $A$ is
  109. empty, and hence the list is empty. So, every non-empty list
  110. determines !!a{surjective} function $f\colon \PosInt \to A$.
  111. \end{explain}
  113. \begin{defn}
  114. \ollabel{defn:enumerable}
  115. A set~$A$ is !!{enumerable} iff it is empty or has an enumeration.
  116. \end{defn}
  118. \begin{ex}
  119. A function enumerating the positive integers ($\PosInt$) is simply the
  120. identity function given by $f(n) = n$. A function enumerating the
  121. natural numbers $\Nat$ is the function $g(n) = n - 1$.
  122. \end{ex}
  124. \begin{ex}
  125. The functions $f\colon \PosInt \to \PosInt$ and $g \colon \PosInt \to
  126. \PosInt$ given by
  127. \begin{align*}
  128. f(n) & = 2n \text{ and}\\
  129. g(n) & = 2n - 1
  130. \end{align*}
  131. enumerate the even positive integers and the odd positive integers,
  132. respectively. However, neither function is an enumeration of
  133. $\PosInt$, since neither is !!{surjective}.
  134. \end{ex}

  30. exhaust all of~$A$. So there are ``more'' !!{element}s of~$A$ than
  31. the infinitely many positive integers.
  33. How would one prove that a set is !!{nonenumerable}? You have to show
  34. that no such surjective function can exist. Equivalently, you have to
  35. show that the elements of~$A$ cannot be enumerated in a one way
  36. infinite list. The best way to do this is to show that every list of
  37. !!{element}s of~$A$ must leave at least one element out; or that no
  38. function $f\colon \PosInt \to A$ can be !!{surjective}. We can do this
  39. using Cantor's \emph{diagonal method}. Given a list of !!{element}s
  40. of~$A$, say, $x_1$, $x_2$, \dots, we construct another element of~$A$
  41. which, by its construction, cannot possibly be on that list.
  43. Our first example is the set~$\Bin^\omega$ of all infinite, non-gappy
  44. sequences of $0$'s and $1$'s.
  46. \begin{thm}
  47. \ollabel{thm:nonenum-bin-omega}
  48. $\Bin^\omega$~is !!{nonenumerable}.
  49. \end{thm}
  51. \begin{proof}
  52. Suppose, by way of contradiction, that $\Bin^\omega$ is
  53. !!{enumerable}, i.e., suppose that there is a list $s_{1}$, $s_{2}$,
  54. $s_{3}$, $s_{4}$, \dots{} of all !!{element}s of~$\Bin^\omega$. Each
  55. of these $s_i$ is itself an infinite sequence of $0$'s and~$1$'s.
  56. Let's call the $j$-th element of the $i$-th sequence in this list
  57. $s_i(j)$. Then the $i$-th sequence~$s_i$ is
  58. \[
  59. s_i(1), s_i(2), s_i(3), \dots
  60. \]
  62. We may arrange this list, and the elements of each sequence $s_i$ in
  63. it, in an array:
  64. \[
  65. \begin{array}{c|c|c|c|c|c}
  66. & 1 & 2 & 3 & 4 & \dots \\\hline
  67. 1 & \mathbf{s_{1}(1)} & s_{1}(2) & s_{1}(3) & s_1(4) & \dots \\\hline
  68. 2 & s_{2}(1)& \mathbf{s_{2}(2)} & s_2(3) & s_2(4) & \dots \\\hline
  69. 3 & s_{3}(1)& s_{3}(2) & \mathbf{s_3(3)} & s_3(4) & \dots \\\hline
  70. 4 & s_{4}(1)& s_{4}(2) & s_4(3) & \mathbf{s_4(4)} & \dots \\\hline
  71. \vdots & \vdots & \vdots & \vdots & \vdots & \mathbf{\ddots}
  72. \end{array}
  73. \]
  74. The labels down the side give the number of the sequence in the list
  75. $s_1$, $s_2$, \dots; the numbers across the top label the !!{element}s
  76. of the individual sequences. For instance, $s_{1}(1)$ is a name for
  77. whatever number, a $0$ or a~$1$, is the first !!{element} in the
  78. sequence $s_{1}$, and so on.
  80. Now we construct an infinite sequence, $\overline{s}$, of $0$'s and
  81. $1$'s which cannot possibly be on this list. The definition of
  82. $\overline{s}$ will depend on the list $s_1$, $s_2$, \dots. Any
  83. infinite list of infinite sequences of $0$'s and $1$'s gives rise to
  84. an infinite sequence~$\overline{s}$ which is guaranteed to not appear
  85. on the list.
  87. To define $\overline{s}$, we specify what all its !!{element}s are,
  88. i.e., we specify $\overline{s}(n)$ for all $n \in \PosInt$. We do this
  89. by reading down the diagonal of the array above (hence the name
  90. ``diagonal method'') and then changing every $1$ to a $0$ and every
  91. $0$ to a~$1$. More abstractly, we define $\overline{s}(n)$ to be $0$
  92. or $1$ according to whether the $n$-th !!{element} of the diagonal,
  93. $s_n(n)$, is $1$ or $0$.
  94. \[
  95. \overline{s}(n) =
  96. \begin{cases}
  97. 1 & \text{if $s_{n}(n) = 0$}\\
  98. 0 & \text{if $s_{n}(n) = 1$}.
  99. \end{cases}
  100. \]
  101. If you like formulas better than definitions by cases, you could also
  102. define $\overline{s}(n) = 1 - s_n(n)$.
  104. Clearly $\overline{s}$ is an infinite sequence of $0$'s and
  105. $1$'s, since it is just the mirror sequence to the sequence of $0$'s
  106. and $1$'s that appear on the diagonal of our array. So $\overline{s}$
  107. is !!a{element} of~$\Bin^\omega$. But it cannot be on the list $s_1$,
  108. $s_2$, \dots{} Why not?
  110. It can't be the first sequence in the list, $s_1$, because it differs from
  111. $s_1$ in the first !!{element}. Whatever $s_1(1)$ is, we defined
  112. $\overline{s}(1)$ to be the opposite. It can't be the second
  113. sequence in the list, because $\overline{s}$ differs from $s_2$ in the second
  114. element: if $s_2(2)$ is $0$, $\overline{s}(2)$ is $1$, and vice
  115. versa. And so on.
  117. More precisely: if $\overline{s}$ were on the list, there would be
  118. some $k$ so that $\overline{s} = s_{k}$. Two sequences are identical
  119. iff they agree at every place, i.e., for any~$n$, $\overline{s}(n) =
  120. s_{k}(n)$. So in particular, taking $n = k$ as a special case,
  121. $\overline{s}(k) = s_{k}(k)$ would have to hold. $s_k(k)$ is either
  122. $0$ or~$1$. If it is $0$ then $\overline{s}(k)$ must be~$1$---that's
  123. how we defined $\overline{s}$. But if $s_k(k) = 1$ then, again because
  124. of the way we defined $\overline{s}$, $\overline{s}(k) = 0$. In either
  125. case $\overline{s}(k) \neq s_{k}(k)$.
  127. We started by assuming that there is a list of !!{element}s of
  128. $\Bin^\omega$, $s_1$, $s_2$, \dots{} From this list we constructed a
  129. sequence~$\overline{s}$ which we proved cannot be on the list. But it
  130. definitely is a sequence of $0$'s and $1$'s if all the $s_i$ are
  131. sequences of $0$'s and $1$'s, i.e., $\overline{s} \in
  132. \Bin^\omega$. This shows in particular that there can be no list of
  133. \emph{all} !!{element}s of~$\Bin^\omega$, since for any such list we
  134. could also construct a sequence~$\overline{s}$ guaranteed to not be on
  135. the list, so the assumption that there is a list of all sequences
  136. in~$\Bin^\omega$ leads to a contradiction.
  137. \end{proof}
  139. \begin{explain}
  140. This proof method is called ``diagonalization'' because it uses the
  141. diagonal of the array to define~$\overline{s}$. Diagonalization need
  142. not involve the presence of an array: we can show that sets are not
  143. !!{enumerable} by using a similar idea even when no array and no
  144. actual diagonal is involved.
  145. \end{explain}

  30. if the $n$th row and $m$th column contains value~$v$, then the
  31. $(n+1)$st row and $(m-1)$st column contains value $v + 1$. Second: the
  32. first row of our enumeration consists of the triangular numbers,
  33. starting with $0$, $1$, $3$, $6$, etc. The $k$th triangular number is
  34. the sum of the natural numbers $< k$, which can be computed as
  35. $k(k+1)/2$. Putting these two observations together, consider this
  36. function:

  61. using a \emph{single} number. Using the inverse of the pairing
  62. function, we can \emph{decode} the number, i.e., find out which
  63. pair it represents.

  20. We proved that $\Bin^\omega$ is !!{nonenumerable} by a diagonalization
  21. argument. We used a similar diagonalization argument to show that
  22. $\Pow{\Nat}$ is !!{nonenumerable}. But here's another way we can prove
  23. that $\Pow{\Nat}$ is !!{nonenumerable}: show that \emph{if
  24. $\Pow{\Nat}$ is !!{enumerable} then $\Bin^\omega$ is also
  25. !!{enumerable}}. Since we know $\Bin^\omega$ is !!{nonenumerable}, it
  26. will follow that $\Pow{\Nat}$ is too.
  28. This is called \emph{reducing} one problem to another. In this case,
  29. we reduce the problem of enumerating $\Bin^\omega$ to the problem of
  30. enumerating $\Pow{\Nat}$. A solution to the latter---an enumeration
  31. of $\Pow{\Nat}$---would yield a solution to the former---an
  32. enumeration of $\Bin^\omega$.
  34. To reduce the problem of enumerating a set~$B$ to that of enumerating
  35. a set~$A$, we provide a way of turning an enumeration of~$A$ into an
  36. enumeration of~$B$. The easiest way to do that is to define

  13. \begin{explain}
  14. Here is an intuitive thought: if $A$ is no larger than $B$ and $B$ is
  15. no larger than $A$, then $A$ and $B$ are equinumerous. To be honest,
  16. if this thought were \emph{wrong}, then we could scarcely justify the
  17. thought that our defined notion of equinumerosity has anything to do
  18. with comparisons of ``sizes'' between sets!{} Fortunately, though,
  19. the intuitive thought is correct. This is justified by the
  20. Schr\"oder-Bernstein Theorem.
  21. \end{explain}
  23. \begin{thm}[Schr\"oder-Bernstein]
  24. \ollabel{thm:schroder-bernstein}
  25. If $\cardle{A}{B}$ and $\cardle{B}{A}$,
  26. then $\cardeq{A}{B}$.
  27. \end{thm}
  29. \begin{explain}
  30. In other words, if there is !!a{injection} from $A$ to~$B$, and
  31. !!a{injection} from $B$ to~$A$, then there is !!a{bijection} from $A$
  32. to~$B$.
  34. This result, however, is really rather \emph{difficult} to prove.
  35. Indeed, although Cantor stated the result, others proved
  36. it.\footnote{For more on the history, see e.g.,
  37. \citet[pp.~165--6]{Potter2004}.}
  38. \oliflabeldef{sfr:cardinals:card-sb:sec}{We will only be in
  39. a position to \emph{prove} Schr\"oder-Bernstein in
  40. \olref[sfr][cardinals][card-sb]{sec}.}{}%
  41. For now, you can (and must)
  42. take it on trust.
  44. Fortunately, Schr\"oder-Bernstein is \emph{correct}, and it
  45. vindicates our thinking of the relations we defined, i.e.,
  46. $\cardeq{A}{B}$ and $\cardle{A}{B}$, as having something to do with
  47. ``size''. Moreover, Schr\"oder-Bernstein is very \emph{useful}. It
  48. can be difficult to think of !!a{bijection} between two equinumerous
  49. sets. The Schr\"oder-Bernstein Theorem allows us to break the comparison
  50. down into cases so we only have to think of !!a{injection} from the
