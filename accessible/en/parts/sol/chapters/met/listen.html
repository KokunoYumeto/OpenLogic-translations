Chapter. Metatheory of Second-order Logic.

Section. Introduction. First-order logic has a number of nice properties. We know it is not decidable, but at least it is axiomatizable. That is, there are proof systems for first-order logic which are sound and complete, that is, they give rise to a derivability relation the derivability relation with the property that for any set of sentences Gamma and sentence A , Gamma logically entails A if and only if A is derivable from Gamma . This means in particular that the validities of first-order logic are computably enumerable. There is a computable function f from the natural numbers to the sentences of language L such that the values of f are all and only the valid sentences of the language L . This is so because derivations can be enumerated, and those that derive a single sentence are then mapped to that sentence. Second-order logic is more expressive than first-order logic, and so it is in general more complicated to capture its validities. In fact, we'll show that second-order logic is not only undecidable, but its validities are not even computably enumerable. This means there can be no sound and complete proof system for second-order logic (although sound, but incomplete proof systems are available and in fact are important objects of research). First-order logic also has two more properties: it is compact (if every finite subset of a set Gamma of sentences is satisfiable, Gamma itself is satisfiable) and the Loewenheim—Skolem Theorem holds for it (if Gamma has an infinite model it has a denumerable model). Both of these results fail for second-order logic. Again, the reason is that second-order logic can express facts about the size of domains that first-order logic cannot. End section.

Section. Second-order Logic is not Axiomatizable. Theorem. Second-order logic is undecidable. End theorem. Proof. Section. Second-order Logic is not Compact. Call a set of sentences Gamma finitely satisfiable if every one of its finite subsets is satisfiable. First-order logic has the property that if a set of sentences Gamma is finitely satisfiable, it is satisfiable. This property is called compactness. It has an equivalent version involving entailment: if Gamma logically entails A , then already Gamma subscript zero logically entails A for some finite subset Gamma subscript zero of Gamma . In this version it is an immediate corollary of the completeness theorem: for if Gamma logically entails A , by completeness A is derivable from Gamma . But a derivation can only make use of finitely many sentences of Gamma . Compactness is not true for second-order logic. There are sets of second-order sentences that are finitely satisfiable but not satisfiable, and that entail some A without a finite subset entailing A . Theorem. Second-order logic is not compact. Section. The Loewenheim—Skolem Theorem Fails for Second-order Logic. The (Downward) Loewenheim—Skolem Theorem states that every set of sentences with an infinite model has an enumerable model. It, too, is a consequence of the completeness theorem: the proof of completeness generates a model for any consistent set of sentences, and that model is enumerable. There is also an Upward Loewenheim—Skolem Theorem, which guarantees that if a set of sentences has a denumerable model it also has a non-enumerable model. Both theorems fail in second-order logic. Theorem. The Loewenheim—Skolem Theorem fails for second-order logic: There are sentences with infinite models but no enumerable models. End theorem. Proof. Recall that Displayed expression. Count abbreviates: there exists an object lower case z and a unary function u such that for every unary relation capital X, if capital X holds of z and, for every lower case x, capital X holding of x implies capital X holding of u of x, then capital X holds of every lower case x. There are such structures—take any non-enumerable set as the domain, for example, the power set of the natural numbers or the real numbers . So not Count has infinite models but no enumerable models.
