Section. The Continuum Hypothesis. The previous result hints (correctly) that cardinal exponentiation would be quite easy, if infinite cardinals are guaranteed to “play straightforwardly” with powers of two , that is, (by the lemma on Size Powersettwo Exp ) with taking powersets. Certainly if that were the case, then the infinite cardinals would “play straightforwardly” with the operation of taking powersets. Indeed, we would have the following: Generalized Continuum Hypothesis (GCH). aleph subscript alpha of equals beth subscript alpha , for all alpha . Moreover, if GCH held, then we could make some considerable simplifications with cardinal exponentiation. Footnote. The condition is dictated by cofinality. End footnote. But GCH is a hypothesis, not a theorem. In fact, Kurt Gödel (one thousand nine hundred thirty eight) proved that if set theory Z F C is consistent, then so is set theory Z F C plus GCH . But it later turned out that we can equally add negation GCH to set theory Z F C . Indeed, consider the simplest non-trivial instance of GCH, namely: Continuum Hypothesis (CH). aleph subscript one of equals beth subscript one . Paul J. Cohen (one thousand nine hundred sixty three) proved that if set theory Z F C is consistent then so is set theory Z F C plus not CH . So the Continuum Hypothesis is independent from set theory Z F C . The Continuum Hypothesis is so-called, since “the continuum” is another name for the real line, the real numbers . theorem one in chapter Cardinal Arithmetic tells us that the cardinality of the real numbers equals beth subscript one . So the Continuum Hypothesis states that there is no cardinal between the cardinality of the natural numbers, aleph subscript zero of equals beth subscript zero , and the cardinality of the continuum, beth subscript one . Given the independence of (G)CH from set theory Z F C , what should say about their truth? Well, there is much to say. Indeed, and much fertile recent work in set theory has been directed at investigating these issues. But two very quick points are certainly worth emphasising. First: it does not immediately follow from these formal independence results that either GCH or CH is indeterminate in truth value. After all, maybe we just need to add more axioms, which strike us as natural, and which will settle the question one way or another. Gödel himself suggested that this was the right response. Second: the independence of CH from set theory Z F C is certainly striking, but it is certainly not incredible (in the literal sense). The point is simply that, for all set theory Z F C tells us, moving from cardinals to their successors may involve a less blunt tool than simply taking powersets. With those two observations made, if you want to know more, you will now have to turn to the various philosophers and mathematicians with horses in the race. Footnote.
