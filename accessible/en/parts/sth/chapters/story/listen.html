Chapter. The Iterative Conception.

Section. Extensionality. The very first thing to say is that sets are individuated by their elements. More precisely: Axiom. Extensionality. If sets capital A and capital B have the same elements, then capital A and capital B are the same set. Displayed expression. for every set capital A and every set capital B, if every object x is a member of capital A if and only if x is a member of capital B, then capital A equals capital B. End displayed expression. End axiom. We assumed this throughout the part on sets, functions, and relations . But it bears repeating. The Axiom of Extensionality expresses the basic idea that a set is determined by its elements. (So sets might be contrasted with concepts, where precisely the same objects might fall under many different concepts.) Why embrace this principle? Well, it is plausible to say that any denial of Extensionality is a decision to abandon anything which might even be called set theory. Set theory is no more nor less than the theory of extensional collections. The real challenge in the part on set theory , though, is to lay down principles which tell us which sets exist. And it turns out that the only truly “obvious” answer to this question is provably wrong. End section.

Section. Russell's Paradox (again). In the part on sets, functions, and relations , we worked with a naïve set theory. But according to a very naïve conception, sets are just the extensions of predicates. This naïve thought would mandate the following principle: Naïve Comprehension. the set of all x such that phi holds of x exists for any formula phi . Tempting as this principle is, it is provably inconsistent. We saw this in the section Russell's Paradox , but the result is so important, and so straightforward, that it's worth repeating. Verbatim. Theorem. Russell's Paradox. There is no set capital R equals the set of all x such that x is not a member of itself End theorem. Proof. If capital R equals the set of all x such that x is not a member of itself exists, then capital R is a member of itself if and only if capital R is not a member of itself , which is a contradiction. End proof. Russell discovered this result in June one thousand nine hundred one. (He did not, though, put the paradox in quite the form we just presented it, since he was considering Frege's set theory, as outlined in Grundgesetze. We will return to this in the section on Frege's Basic Law Five .) Russell wrote to Frege on June sixteen, one thousand nine hundred two, explaining the inconsistency in Frege's system. For the correspondence, and a bit of background, see Jean van Heijenoort (one thousand nine hundred sixty seven), pages one hundred twenty four through one hundred twenty eight . It is worth emphasising that this two-line proof is a result of pure logic. Granted, we implicitly used a (non-logical?) axiom, Extensionality, in our notation the set of all x such that x is not a member of itself ; for the set of all x such that phi holds of x is to be the unique (by Extensionality) set of the phi s, if one exists. But we can avoid even the hint of Extensionality, just by stating the result as follows: there is no set whose members are exactly the non-self-membered sets. And this has nothing much to do with sets. As Russell himself observed, exactly similar reasoning will lead you to conclude: no man shaves exactly the men who do not shave themselves. Or: no pug sniffs exactly the pugs which don't sniff themselves. And so on. Schematically, the shape of the result is just: Displayed expression. it is not the case that there exists an object x such that, for every object z, capital R relates z to x if and only if capital R does not relate z to itself. End displayed expression. And that's just a theorem (scheme) of first-order logic. Consequently, we can't avoid Russell's Paradox just by tinkering with our set theory; it arises before we even get to set theory. If we're going to use (classical) first-order logic, we simply have to accept that there is no set capital R equals the set of all x such that x is not a member of itself . The upshot is this. If you want to accept Naïve Comprehension whilst avoiding inconsistency, you cannot just tinker with the set theory. Instead, you would have to overhaul your logic. Of course, set theories with non-classical logics have been presented. But they are—to say the least—non-standard. The standard approach to Russell's Paradox is to treat it as a straightforward non-existence proof, and then to try to learn how to live with it. That is the approach we will follow. End section.

Section. Predicative and Impredicative. The Russell set, capital R , was defined via the set of all x such that x is not a member of itself . Spelled out more fully, capital R would be the set which contains all and only those sets which are not non-self-membered. So in defining capital R , we quantify over the domain which would contain capital R (if it existed). Source anomaly note. Source semantic caveat. More generally, we might say that a definition is impredicative if and only if it quantifies over a domain which contains the object that is being defined. In the wake of the paradoxes, Whitehead, Russell, Poincaré and Weyl rejected such impredicative definitions as “viciously circular”: Quotation. An analysis of the paradoxes to be avoided shows that they all result from a kind of vicious circle. The vicious circles in question arise from supposing that a collection of objects may contain members which can only be defined by means of the collection as a whole Open bracket. Ellipsis. Paragraph mark. Close bracket. The principle which enables us to avoid illegitimate totalities may be stated as follows: `Whatever involves all of a collection must not be one of the collection'; or, conversely: `If, provided a certain collection had a total, it would have members only definable in terms of that total, then the said collection has no total.' We shall call this the `vicious-circle principle,' because it enables us to avoid the vicious circles involved in the assumption of illegitimate totalities. (Alfred North Whitehead and Bertrand Russell, one thousand nine hundred ten, page thirty seven) End quotation. If we follow them in rejecting the vicious-circle principle, then we might attempt to replace the disastrous Naïve Comprehension Scheme (of the section Russell's Paradox again ) with something like this: Predicative Comprehension. For every formula phi quantifying only over sets: the set prime the set of all x such that phi holds of x exists. Source anomaly note. Source semantic caveat. So long as sets prime are not sets, no contradiction will ensue. Unfortunately, Predicative Comprehension is not very comprehensive. After all, it introduces us to new entities, sets prime . So we will have to consider formulas which quantify over sets prime . If they always yield a set prime , then Russell's paradox will arise again, just by considering the set prime of all non-self-membered sets prime . So, pursuing the same thought, we must say that a formula quantifying over sets prime yields a corresponding set double prime . And then we will need sets triple prime , sets quadruple prime , etc. To prevent a rash of primes, it will be easier to think of these as sets subscript zero , sets subscript one , sets subscript two , sets subscript three , sets subscript four , and so on. And this would give us a way into the (simple) theory of types. There are a few obvious objections against such a theory (though it is not obvious that they are overwhelming objections). In brief: the resulting theory is cumbersome to use; it is profligate in postulating different kinds of objects; and it is not clear, in the end, that impredicative definitions are even all that bad. To bring out the last point, consider this remark from Frank Plumpton Ramsey : Quotation. we may refer to a man as the tallest in a group, thus identifying him by means of a totality of which he is himself a member without there being any vicious circle. (Frank Plumpton Ramsey, one thousand nine hundred twenty five) End quotation. Ramsey's point is that “the tallest man in the group” is an impredicative definition; but it is obviously perfectly kosher. One might respond that, in this case, we could pick out the tallest person by predicative means. For example, maybe we could just point at the man in question. The objection against impredicative definitions, then, would clearly need to be limited to entities which can only be picked out impredicatively. But even then, we would need to hear more, about why such “essential impredicativity” would be so bad. Footnote. For more, see Øystein Linnebo (two thousand ten) . End footnote. Admittedly, impredicative definitions are extremely bad news, if we want our definitions to provide us with something like a recipe for creating an object. For, given an impredicative definition, one would genuinely be caught in a vicious circle: to create the impredicatively specified object, one would first need to create all the objects (including the impredicatively specified object), since the impredicatively specified object is specified in terms of all the objects; so one would need to create the impredicatively specified object before one had created it itself. But again, this is only a serious objection against “essentially impredicatively” specified sets, if we think of sets as things that we create. And we (probably) don't. As such—for better or worse—the approach which became common does not involve taking a hard line concerning (im)predicativity. Rather, it involves what is now regarded as the cumulative-iterative approach. In the end, this will allow us to stratify our sets into “stages”—a bit like the predicative approach stratifies entities into sets subscript zero , sets subscript one , sets subscript two , and so on —but we will not postulate any difference in kind between them. End section.

Section. The Cumulative-Iterative Approach. Here is a slightly fuller statement of how we will stratify sets into stages: Quotation. Sets are formed in stages. For each stage capital S , there are certain stages which are before capital S . At stage capital S , each collection consisting of sets formed at stages before capital S is formed into a set. There are no sets other than the sets which are formed at stages. (Joseph R. Shoenfield, one thousand nine hundred seventy seven, page three hundred twenty three) End quotation. This is a sketch of the cumulative-iterative conception of set. It will underpin the formal set theory that we present in the part on set theory . Let's explore this in a little more detail. As Shoenfield describes the process, at every stage, we form new sets from the sets which were available to us from earlier stages. So, on Shoenfield's picture, at the initial stage, stage zero , there are no earlier stages, and so a fortiori there are no sets available to us from earlier stages. Footnote. Why should we assume that there is a first stage? See the footnote to Stages are ordered in the section The Story in More Detail . End footnote. So we form only one set: the set with no elements the empty set . At stage one , exactly one set is available to us from earlier stages, so only one new set is the singleton set containing the empty set . At stage two , two sets are available to us from earlier stages, and we form two new sets the singleton set containing the singleton set containing the empty set and the set containing the empty set and the singleton containing the empty set . At stage three , four sets are available to us from earlier stages, so we form twelve new sets and so on. As such, the cumulative-iterative picture of the sets will look a bit like this (with numbers indicating stages): Cumulative iterative hierarchy diagram. The solid outer boundary has a single pointed bottom at stage zero and widens upward. Six horizontal solid boundaries mark stages one through six. The printed labels from bottom to top are zero , then one , then two , then three , then four , then five , and finally six . Dotted extensions continue both sloping sides beyond stage six. No individual set, urelement, membership arrow, or quantity of objects is printed. End diagram. So: why should we embrace this story? One reason is that it is a nice, tractable story. Given the demise of the most obvious story, that is, Naïve Comprehension, we are in want of something nice. But the story is not just nice. We have a good reason to believe that any set theory based on this story will be consistent. Here is why. Given the cumulative-iterative conception of set, we form sets at stages; and their elements must be objects which were available already. So, for any stage capital S , we can form the set Displayed expression. the stage indexed Russell set capital R subscript capital S equals the set of all x such that x is not a member of itself and x was available before stage capital S. End displayed expression. The reasoning involved in proving Russell's Paradox will now establish that capital R subscript capital S itself is not available before stage capital S . And that's not a contradiction. Moreover, if we embrace the cumulative-iterative conception of set, then we shouldn't even have expected to be able to form the Russell set itself. For that would be the set of all non-self-membered sets that “will ever be available”. In short: the fact that we (provably) can't form the Russell set isn't surprising, given the cumulative-iterative story; it's what we would predict. End section.

Section. Urelements or Not?. In the next few chapters, we will try to extract axioms from the cumulative-iterative conception of set. But, before going any further, we need to say something more about urelements. The picture of the section The Cumulative Iterative Approach allowed us only to form new sets from old sets. However, we might want to allow that certain non-sets —cows, pigs, grains of sand, or whatever—can be elements of sets. In that case, we would start with certain basic elements, urelements, and then say that at each stage capital S we would form “all possible” sets consisting of urelements or sets formed at stages before capital S (in any combination). The resulting picture would look more like this: Hierarchy with urelements diagram. The solid outer boundary has a flat base at stage zero and widens upward. Six horizontal solid boundaries mark stages one through six. The printed labels from bottom to top are zero , then one , then two , then three , then four , then five , and finally six . Dotted extensions continue both sloping sides beyond stage six. No individual set, urelement, membership arrow, or quantity of objects is printed. End diagram. So now we have a decision to take: Should we allow urelements? Philosophically, it makes sense to include urelements in our theorising. The main reason for this is to make our set theory applicable. To illustrate the point, recall from the chapter The Size of Sets that we say that two sets capital A and capital B have the same size, that is, capital A and capital B are equinumerous , if and only if there is a bijection between them. Now, if the cows in the field and the pigs in the sty both form sets, we can offer a set-theoretical treatment of the claim “there are as many cows as pigs”. But if we ban urelements, so that the cows and the pigs do not form sets, then that set-theoretical treatment will be unavailable. Indeed, we will have no straightforward ability to apply set theory to anything other than sets themselves. (For more reasons to include urelements, see Michael Potter two thousand four, pages six, twenty four, fifty through fifty one .) Mathematically, however, it is quite rare to allow urelements. In part, this is because it is very slightly easier to formulate set theory without urelements. But, occasionally, one finds more interesting justifications for excluding urelement from set theory: Quotation. In accordance with the belief that set theory is the foundation of mathematics, we should be able to capture all of mathematics by just talking about sets, so our variable should not range over objects like cows and pigs. (Kenneth Kunen, one thousand nine hundred eighty, page eight) End quotation. So: a focus on applicability would suggest including urelements; a focus on a reductive foundational goal (reducing mathematics to pure set theory) might suggest excluding them. Mild laziness, too, points in the direction of excluding urelements. We will follow the laziest path. Partly, though, there is a pedagogical justification. Our aim is to introduce you to the elements of set theory that you would need in order to get started on the philosophy of set theory. And most of that philosophical literature discusses set theories formulated without urelements. So this book will, perhaps, be of more use, if it hews fairly closely to that literature. End section.

Section. Appendix: Frege's Basic Law V. In the section Russell's Paradox again , we explained that Russell's formulated his paradox as a problem for the system Frege outlined in his Grundgesetze. Frege's system did not include a direct formulation of Naïve Comprehension. So, in this appendix, we will very briefly explain what Frege's system did include, and how it relates to Naïve Comprehension and how it relates to Russell's Paradox. Frege's system is second-order, and was designed to formulate the notion of an extension of a concept. Footnote. Strictly speaking, Frege attempts to formalize a more general notion: the “value-range” of a function. Extensions of concepts are a special case of the more general notion. See Richard Kimberly Heck (two thousand twelve), pages eight through nine for the details. End footnote. Using notation inspired by Frege, we will write the extension of concept capital F for the extension of the concept capital F . This is a device which takes a predicate, “ capital F ”, and turns it into a (first-order) term, “ the extension of concept capital F ”. Using this device, Frege offered the following definition of membership: Displayed expression. object a is a member of object b is defined to mean that there exists a concept capital G such that b is the extension of G and G applies to a. End displayed expression. roughly: a is a member of b if and only if a falls under a concept whose extension is b . (Note that the quantifier “ there exists a concept capital G ” is second-order.) Frege also maintained the following principle, known as Basic Law V: Displayed expression. the extension of concept capital F equals the extension of concept capital G if and only if, for every object x, F applies to x if and only if G applies to x. End displayed expression. roughly: concepts have identical extensions if and only if they are coextensive. (Again, both “ capital F ” and “ capital G ” are in predicate position.) Now a simple principle connects membership with property-satisfaction: Lemma. in Grundgesetze. for every concept capital F and every object a, a is a member of the extension of F if and only if F applies to a End lemma. Proof. Fix capital F and a . Now object a is a member of the extension of concept capital F if and only if there exists a concept capital G such that the extension of concept capital F equals the extension of concept capital G and G applies to object a (by the definition of membership) if and only if there exists a concept capital G such that for every object x, capital F applies to x if and only if capital G applies to x, and capital G applies to object a (by Basic Law V) if and only if a falls under capital F (by elementary second-order logic). End proof. And this yields Naïve Comprehension almost immediately: Lemma. in Grundgesetze.. for every concept capital F, there exists a set s such that for every object a, a is a member of s if and only if F applies to a End lemma. Proof. Fix capital F ; now the lemma on membership in Frege extensions yields for every object a, a is a member of the extension of concept capital F if and only if capital F applies to a ; so there exists a set s such that for every object a, a is a member of s if and only if concept capital F applies to a by existential generalisation. The result follows since capital F was arbitrary. End proof. Russell's Paradox follows by taking capital F as given by for every object x, concept capital F applies to x if and only if x is not a member of itself . End section. End chapter.
