Axiom scheme of Separation

For every formula phi of x and every set capital A, the subset of capital A containing exactly the x for which phi holds exists. This is an axiom scheme, not one axiom.

Source

Formal version of the Separation scheme

For any formula phi of x that does not contain capital S, and for every capital A, there exists a capital S whose members are exactly the x that satisfy phi and belong to capital A.

Source

Theorem that there is no universal set

There is no set containing every object. The source states this as the nonexistence of the set of every x equal to itself.

Source

Proposition establishing the empty set

If any set exists, then the empty set exists. Separation forms it from the members of an arbitrary set that are not equal to themselves.

Source

Proposition establishing set difference

For any capital A and capital B, their set difference exists. Separation selects the members of capital A that do not belong to capital B.

Source

Proposition establishing nonempty intersections

If capital A is not empty, its intersection exists and contains exactly the x that belong to every y in capital A. The nonemptiness condition is essential because the intersection of the empty set would be universal.

Source

Axiom of Union

For every capital A there exists a capital U whose members are exactly the members of members of capital A. Equivalently, the union of capital A exists.

Source

Axiom of Pairs

For any a and b there exists a capital P whose members are exactly a and b. Extensionality permits a and b to be the same set.

Source

Proposition deriving basic pair constructions

For arbitrary a and b, the proposition derives the singleton containing a, the binary union of a and b, and the ordered pair a, b. The proof uses Pairs, Union, and Extensionality in source order.

Source

Exercise constructing a three-member set

Show that the set containing a, b, and c exists for arbitrary sets a, b, and c. The exercise is preserved as stated and no solution is supplied.

Source

Exercise constructing a finite set

Show that the set containing a subscript one through a subscript n exists for arbitrary sets in that finite list. The exercise is preserved as stated and no solution is supplied.

Source

Axiom of Powersets

For every capital A, its power set exists and contains exactly the subsets of capital A. The displayed formula characterizes those subsets by their members.

Source

Proposition establishing Cartesian products

For any capital A and capital B, the Cartesian product of capital A with capital B exists. The proof separates the ordered pairs x, y from the power set of the power set of capital A union capital B.

Source

Exercise constructing relations and functions

For arbitrary capital A and capital B, show first that all relations with domain capital A and range capital B form a set, and second that all functions from capital A to capital B form a set. No solution is supplied.

Source

Exercise constructing a quotient set

Given a set capital A and an equivalence relation tilde on it, prove that the set of equivalence classes of capital A under tilde exists. No solution is supplied.

Source

Axiom of Infinity

There is a set capital I containing an empty object and closed under the operation that sends x to x union its singleton. The source gives both the prose statement and its formal quantified version.

Source

Formal statement of the Axiom of Infinity

There exists a capital I with an element o that has no members, and for every x in capital I there is an s in capital I whose members are exactly the members of x together with x itself.

Source

Definition of the natural numbers and omega

Choose a set supplied by Infinity, define s of x as x union the singleton containing x, and define omega as the closure of the empty set under s. Members of omega are called natural numbers.

Source

Proposition that natural numbers are not Dedekind infinite

No natural number is Dedekind infinite. The source proof proceeds by induction and proves the contrapositive step through two cases for the range of an injection.

Source

Definition of set theory Z minus

Set theory Z minus consists of Extensionality, Union, Pairs, Powersets, Infinity, and every instance of the Separation scheme.

Source

Zermelo alternative Axiom of Infinity

There is a capital A containing the empty set and containing the singleton of every one of its members. The source contrasts this with the von Neumann successor operation.

Source

Closure and intersection display

The display first defines the closure of o under f as the intersection of all f-closed sets containing o. It then gives the general form: capital C is the intersection of all capital X satisfying phi.

Source

Intersection membership condition tagged star

For every x, x belongs to capital C exactly when x belongs to every capital X for which phi holds. This is the condition later obtained by Separation from one witness capital S satisfying phi.
