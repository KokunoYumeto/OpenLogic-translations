Chapter. Steps towards set theory Z .

Section. The Story in More Detail. In the earlier section on the cumulative iterative approach , we quoted Schoenfield's description of the process of set-formation. We now want to write down a few more principles, to make this story a bit more precise. Here they are: List. Next item.. Stages are key. Every set is formed at some stage. Next item.. Stages are ordered. Stages are ordered: some come before others. Footnote. We will actually assume—tacitly—that the stages are well-ordered. What this amounts to is explained in the chapter on ordinals . This is a substantial assumption. In fact, using a very clever technique due to Dana Scott (one thousand nine hundred seventy four) , this assumption can be avoided and then derived. (This will also explain why we should think that there is an initial stage.) We cannot go into that here; for more, see Tim Button (two thousand twenty one) . End footnote. Next item.. Stages accumulate. For any stage capital S , and for any sets which were formed before stage capital S : a set is formed at stage capital S whose members are exactly those sets. Nothing else is formed at stage capital S . End list. These are informal principles, but we will be able to use them to vindicate several of the axioms of Zermelo's set theory. (We should offer a word of caution. Although we will be presenting some completely standard axioms, with completely standard names, the italicized principles we have just presented have no particular names in the literature. We simply monikers which we hope are helpful.) End section.

Section. Separation. We start with a principle to replace Naïve Comprehension: Axiom. Scheme of Separation. For every formula phi of x , this is an axiom: for any capital A , the set the set of x in capital A such that phi holds of x exists. End axiom. Note that this is not a single axiom. It is a scheme of axioms. There are infinitely many Separation axioms; one for every formula phi of x . The scheme can equally well be (and normally is) written down as follows: For any formula phi of x which does not contain “ capital S ”, this is an axiom: Displayed expression. for every capital A there exists a capital S such that, for every x, x belongs to capital S if and only if phi holds of x and x belongs to capital A. End displayed expression. In keeping with the convention noted at the start of the Set Theory part , the formulas phi in the Separation axioms may have parameters. Footnote. For an explanation of what this means, see the discussion immediately after the natural number induction schema . End footnote. Separation is immediately justified by our cumulative-iterative conception of sets we have been telling. To see why, let capital A be a set. So capital A is formed by some stage capital S (by Stages are key ). Since capital A was formed at stage capital S , all of capital A apostrophe s members were formed before stage capital S (by Stages accumulate ). Now in particular, consider all the sets which are members of capital A and which also satisfy phi ; clearly all of these sets, too, were formed before stage capital S . So they are formed into a set the set of x in capital A such that phi holds of x at stage capital S too (by Stages accumulate ). Unlike Naïve Comprehension, this avoid Russell's Paradox. For we cannot simply assert the existence of the set the set of x such that x does not belong to x . Rather, given some set capital A , we can assert the existence of the set capital R subscript capital A equals the set of x in capital A such that x does not belong to itself . But all this proves is that capital R subscript capital A does not belong to capital R subscript capital A and capital R subscript capital A does not belong to capital A , none of which is very worrying. However, Separation has an immediate and striking consequence: Theorem. There is no universal set, that is, the set of x such that x equals x does not exist. End theorem. Proof. For reductio, suppose capital V is a universal set. Then by Separation, capital R equals the set of x in capital V that do not belong to themselves, and also equals the unrestricted set of every x that does not belong to itself exists, contradicting Russell's Paradox. End proof. The absence of a universal set—indeed, the open-endedness of the hierarchy of sets—is one of the most fundamental ideas behind the cumulative-iterative conception. So it is worth seeing that, intuitively, we could reach it via a different route. A universal set must be an element of itself. But, on our cumulative-iterative conception, every set appears (for the first time) in the hierarchy at the first stage immediately after all of its elements. But this entails that no set is self-membered. For any self-membered set would have to first occur immediately after the stage at which it first occurred, which is absurd. (We will see in the definition of the rank of a set how to make this explanation more rigorous, by using the notion of the “rank” of a set. However, we will need to have a few more axioms in place to do this.) Here are a few more consequences of Separation and Extensionality. Proposition. If any set exists, then the empty set exists. End proposition. Proof. If capital A is a set, the empty set equals the set of x in capital A such that x is not equal to itself exists by Separation. End proof. Proposition. capital A set minus capital B exists for any sets capital A and capital B End proposition. Proof. capital A set minus capital B equals the set of x in capital A such that x does not belong to capital B exists by Separation. End proof. It also turns out that (almost) arbitrary intersections exist: Proposition. If capital A is not equal to the empty set , then the intersection of capital A equals the set of every x that belongs to every y in capital A exists. End proposition. Proof. Let capital A is not equal to the empty set , so there is some c belongs to capital A . Then the intersection of capital A equals the set of every x that belongs to every y in capital A, and also equals the set of those x in c that belong to every y in capital A , which exists by Separation. End proof. Note the condition that capital A is not equal to the empty set , though; for the intersection of the empty set would be the universal set, vacuously, contradicting the theorem that there is no universal set . End section.

Section. Union. the proposition establishing nonempty intersections gave us intersections. But if we want arbitrary unions to exist, we need to lay down another axiom: Axiom. Union. For any set capital A , the set the union of capital A equals the set of every x that belongs to at least one b in capital A exists. Displayed expression. for every capital A there exists a capital U such that, for every x, x belongs to capital U if and only if there exists a b in capital A for which x belongs to b. End displayed expression. End axiom. This axiom is also justified by the cumulative-iterative conception. Let capital A be a set, so capital A is formed at some stage capital S (by Stages are key ). Every member of capital A was formed before capital S (by Stages accumulate ); so, reasoning similarly, every member of every member of capital A was formed before capital S . Thus all of those sets are available before capital S , to be formed into a set at capital S . And that set is just the union of capital A . End section.

Section. Pairs. The next axiom to consider is the following: Axiom. Pairs. For any sets a, then b , the set the set containing a, then b exists. Displayed expression. for every a and every b there exists a capital P such that, for every x, x belongs to capital P if and only if x equals a or x equals b. End displayed expression. End axiom. Here is how to justify this axiom, using the iterative conception. Suppose a is available at stage capital S , and b is available at stage capital T . Let capital M be whichever of stages capital S and capital T comes later. Then since a and b are both available at stage capital M , the set the set containing a, then b is a possible collection available at any stage after capital M (whichever is the greater). But hold on! Why assume that there are any stages after capital M ? If there are none, then our justification will fail. So, to justify Pairs, we will have to add another principle to the story we told in the section giving the iterative story in more detail , namely: List. Next item.. Stages keep going. There is no last stage. End list. Is this principle justified? Nothing in Shoenfield's story stated explicitly that there is no last stage. Still, even if it is (strictly speaking) an extra addition to our story, it fits well with the basic idea that sets are formed in stages. We will simply accept it in what follows. And so, we will accept the Axiom of Pairs too. Armed with this new Axiom, we can prove the existence of plenty more sets. For example: Proposition. For any sets a and b , the following sets exist: List. Next item. the set containing a Next item. a union b Next item. the ordered pair a, then b End list. End proposition. Proof. the singleton item of the basic pair constructions proposition . By Pairs, the set containing a, then a exists, which is the set containing a by Extensionality. the binary union item of the basic pair constructions proposition . By Pairs, the set containing a, then b exists. Now a union b equals the union of the set containing a, then b exists by Union. the ordered-pair item of the basic pair constructions proposition . By the singleton item of the basic pair constructions proposition , the set containing a exists. By Pairs, the set containing a, then b exists. Now the set whose members are the singleton containing a and the unordered pair containing a and b equals the ordered pair a, b exists, by Pairs again. End proof. Exercise. Show that, for any sets a, then b, then c , the set the set containing a, then b, then c exists. End exercise. This exercise remains unsolved. Exercise. Show that, for any sets a subscript one through a subscript n , the set the set containing a subscript one through a subscript n exists. End exercise. This exercise remains unsolved. End section.

Section. Powersets. We will proceed with another axiom: Axiom. Powersets. For any set capital A , the set the power set of capital A equals the set of every x that is a subset of capital A exists. Displayed expression. for every capital A there exists a capital P such that, for every x, x belongs to capital P if and only if every z in x belongs to capital A. End displayed expression. End axiom. Our justification for this is pretty straightforward. Suppose capital A is formed at stage capital S . Then all of capital A apostrophe s members were available before capital S (by Stages accumulate ). So, reasoning as in our justification for Separation, every subset of capital A is formed by stage capital S . So they are all available, to be formed into a single set, at any stage after capital S . And we know that there is some such stage, since capital S is not the last stage (by Stages keep going ). So the power set of capital A exists. Here is a nice consequence of Powersets: Proposition. Given any sets capital A, then capital B , their Cartesian product capital A times capital B exists. End proposition. Proof. The set the power set of the power set of capital A union capital B exists by Powersets and the proposition deriving basic pair constructions . So by Separation, this set exists: Displayed expression. capital C is the set of z in the power set of the power set of capital A union capital B such that there exists an x in capital A and a y in capital B for which z is the ordered pair x, y. End displayed expression. Now, for any x belongs to capital A and y belongs to capital B , the set the ordered pair x, then y exists by the proposition deriving basic pair constructions . Moreover, since x and y both belong to capital A union capital B , we have that the singleton set containing x and the unordered pair containing x and y both belong to the power set of capital A union capital B , and the ordered pair x, y belongs to the power set of the power set of capital A union capital B . So capital A times capital B equals capital C . End proof. In this proof, Powerset interacts with Separation. And that is no surprise. Without Separation, Powersets wouldn't be a very powerful principle. After all, Separation tells us which subsets of a set exist, and hence determines just how “fat” each Powerset is. Exercise. Show that, for any sets capital A, then capital B : (i) the set of all relations with domain capital A and range capital B exists; and (ii) the set of all functions from capital A to capital B exists. End exercise. This exercise remains unsolved. Exercise. Let capital A be a set, and let the equivalence relation symbol tilde be an equivalence relation on capital A . Prove that the set of equivalence classes under the equivalence relation symbol tilde on capital A , that is, the set of equivalence classes of capital A under the equivalence relation tilde , exists. End exercise. This exercise remains unsolved. End section.

Section. Infinity. We already have enough axioms to ensure that there are infinitely many sets (if there are any). For suppose some set exists, and so the empty set exists (by the proposition establishing the empty set ). Now for any set x , the set x union the set containing x exists by the proposition deriving basic pair constructions . So, applying this a few times, we will get sets as follows: List. Next item. zero.. the empty set Next item. one.. the set containing the empty set Next item. two.. the set with two members: the empty set and the singleton containing the empty set Next item. three.. the set with three members: the empty set; the singleton containing the empty set; and the set containing the empty set and that singleton Next item. four.. the set with four members: the empty set; the singleton containing the empty set; the set containing the empty set and that singleton; and the set containing the empty set, that singleton, and the preceding two-member set End list. and we can check that each of these sets is distinct. We have started the numbering from zero , for a few reasons. But one of them is this. It is not that hard to check that the set we have labelled “ n ” has exactly n members, and (intuitively) is formed at the n indexed stage. But. This gives us infinitely many sets, but it does not guarantee that there is an infinite set, that is, a set with infinitely many members. And this really matters: unless we can find a (Dedekind) infinite set, we cannot construct a Dedekind algebra. But we want a Dedekind algebra, so that we can treat it as the set of natural numbers. (Compare the section on Dedekind's argument for an infinite set .) Importantly, the axioms we have laid down so far do not guarantee the existence of any infinite set. So we have to lay down a new axiom: Axiom. Infinity. There is a set, capital I , such that the empty set belongs to capital I and x union the set containing x belongs to capital I whenever x belongs to capital I . Displayed expression. there exists a capital I satisfying two conditions. First, some o belongs to capital I and no x belongs to o. Second, for every x in capital I there exists an s in capital I such that, for every z, z belongs to s if and only if z belongs to x or z equals x. End conditions. End displayed expression. End axiom. It is easy to see that the set capital I given to us by the Axiom of Infinity is Dedekind infinite. Its distinguished element is the empty set , and the injection on capital I is given by s of x equals x union the set containing x . Now, the theorem extracting a Dedekind algebra from a Dedekind-infinite set showed how to extract a Dedekind Algebra from a Dedekind infinite set; and we will treat this as our set of natural numbers. More precisely: Definition. Let capital I be any set given to us by the Axiom of Infinity. Let s be the function s of x equals x union the set containing x . Let omega equals the closure of the empty set under s . We call the members of omega the natural numbers, and say that n is the result of n -many applications of s to the empty set . End definition. You can now look back and check that the set labelled “ n ”, a few paragraphs earlier, will be treated as the number n . We will discuss this significance of this stipulation in the section on selecting the natural numbers . For now, it enables us to prove an intuitive result: Proposition. No natural number is Dedekind infinite. End proposition. Proof. The proof is by induction, that is, the theorem proving by induction that no natural number is Dedekind infinite . Clearly zero equals the empty set is not Dedekind infinite. For the induction step, we will establish the contrapositive: if (absurdly) s of n is Dedekind infinite, then n is Dedekind infinite. So suppose that s of n is Dedekind infinite, that is, there is some injection f with the range of f is a proper subset of the domain of f; the domain of f equals s of n; and s of n equals n union the singleton containing n . There are two cases to consider. Case one: n does not belong to the range of f . So the range of f is a subset of n , and f of n belongs to n . Let g equals the restriction of f to n ; now the range of g equals the range of f with f of n removed; this is a proper subset of n; and n equals the domain of g . Hence n is Dedekind infinite. Case two: n belongs to the range of f . Fix m belongs to the set difference between the domain of f and the range of f , and define a function h with domain s of n equals n union the set containing n : Displayed expression. h of x is defined by two cases. If f of x is not equal to n, h of x equals f of x. If f of x equals n, h of x equals m. End cases. End displayed expression. So h and f agree everywhere, except that h of the inverse image of n under f equals m; m is not equal to n; and n equals f of the inverse image of n under f . Since f is an injection, n does not belong to the range of h ; and the range of h is a proper subset of the domain of h, and the domain of h equals s of n . Now n is Dedekind infinite, using the argument of Case one. End proof. The question remains, though, of how we might justify the Axiom of Infinity. The short answer is that we will need to add another principle to the story we have been telling. That principle is as follows: List. Next item.. Stages hit infinity. There is an infinite stage. That is, there is a stage which (a) is not the first stage, and which (b) has some stages before it, but which (c) has no immediate predecessor. End list. The Axiom of Infinity follows straightforwardly from this principle. We know that natural number n is formed at stage n . So the set omega is formed at the first infinite stage. And omega itself witnesses the Axiom of Infinity. This, however, simply pushes us back to the question of how we might justify Stages hit infinity. As with Stages keep going, it was not an explicit part of the story we told about the cumulative-iterative hierarchy. But more than that: nothing in the very idea of an iterative hierarchy, in which sets are formed stage by stage, forces us to think that the process involves an infinite stage. It seems perfectly coherent to think that the stages are ordered like the natural numbers. This, however, gives rise to an obvious problem. In the section on Dedekind's argument for an infinite set , we considered Dedekind's “proof” that there is a Dedekind infinite set (of thoughts). This may not have struck you as very satisfying. But if Stages hit infinity is not “forced upon us” by the iterative conception of set (or by “the laws of thought”), then we are still left without an intrinsic justification for the claim that there is a Dedekind infinite set. There is much more to say here, of course. But hopefully you are now at a point to start thinking about what it might take to justify an axiom (or principle). In what follows we will simply take Stages hit infinity for granted. End section.

Section. set theory Z minus : a Milestone. We will revisit Stages hit infinity in the next section. However, with the Axiom of Infinity, we have reached an important milestone. We now have all the axioms required for the theory set theory Z minus . In detail: Definition. The theory set theory Z minus has these axioms: Extensionality, Union, Pairs, Powersets, Infinity, and all instances of the Separation scheme. End definition. The name stands for Zermelo set theory ( minus something which we will come to later). Zermelo deserves the honour, since he essentially formulated this theory in his one thousand nine hundred eight . Footnote. For interesting comments on the history and technicalities, see Michael Potter (two thousand four), Appendix A . End footnote. This theory is powerful enough to allow us to do an enormous amount of mathematics. In particular, you should look back through the Sets, Functions, and Relations part , and convince yourself that everything we did, naïvely, could be done more formally within set theory Z minus . (Once you have done that for a bit, you might want to skip ahead and read the appendix on closure, comprehension, and intersection .) So, henceforth, and without any further comment, we will take ourselves to be working in set theory Z minus (at least). End section.

Section. Selecting our Natural Numbers. In the definition of omega and the natural numbers , we explicitly defined the expression “natural numbers”. How should you understand this stipulation? It is not a metaphysical claim, but just a decision to treat certain sets as the natural numbers. We touched upon reasons for thinking this in the reflections section on relations , the reflections section on arithmetization and the section on Dedekind's argument for an infinite set . But we can make these reasons even more pointed. Our Axiom of Infinity follows John von Neumann (one thousand nine hundred twenty five) . But here is another axiom, which we could have adopted instead: Zermelo's one thousand nine hundred eight Axiom of Infinity. There is a set capital A such that the empty set belongs to capital A and for every x in capital A, the set containing x belongs to capital A . Had we used Zermelo's axiom, instead of our (von Neumann-inspired) Axiom of Infinity, we would equally well have been given a Dedekind infinite set, and so a Dedekind algebra. On Zermelo's approach, the distinguished element of our algebra would again have been the empty set (our surrogate for zero ), but the injection would have been given by the map x maps to the set containing x , rather than x maps to x union the set containing x . The simplest upshot of this is that Zermelo treats two as the set containing the set containing the empty set , whereas we (with von Neumann) treat two as the set with two members: the empty set and the singleton containing the empty set . Why choose one axiom of Infinity rather than the other? The main practical reason is that von Neumann's approach “scales up” to handle transfinite numbers rather well. We will explore this from the chapter on ordinals onwards. However, from the simple perspective of doing arithmetic, both approaches would do equally well. So if someone tells you that the natural numbers are sets, the obvious question is: Which sets are they? This precise question was made famous by Paul Benacerraf (one thousand nine hundred sixty five) . But it is worth emphasising that it is just the most famous example of a phenomenon that we have encountered many times already. The basic point is this. Set theory gives us a way to simulate a bunch of “intuitive” kinds of entities: the reals, rationals, integers, and naturals, yes; but also ordered pairs, functions, and relations. However, set theory never provides us with a unique choice of simulation. There are always alternatives which—straightforwardly—would have served us just as well. End section.

Section. Appendix: Closure, Comprehension, and Intersection. In the section presenting set theory Z minus as a milestone , we suggested that you should look back through the naïve work of the Sets, Functions, and Relations part and check that it can be carried out in set theory Z minus . If you followed that advice, one point might have tripped you up: the use of intersection in Dedekind's treatment of closures. Recall from the definition of closure under a function that Displayed expression. Source-ordered display. The closure of o under f equals the intersection of the set of all capital X such that o belongs to capital X and capital X is closed under f. The general shape is this: capital C equals the intersection of the set of all capital X such that phi holds of capital X. End display. End displayed expression. But this should ring alarm bells: since Naïve Comprehension fails, there is no guarantee that the set of capital X such that phi of capital X exists. It looks dangerously, then, like such definitions are cheating. Fortunately, they are not cheating; or rather, if they are cheating as they stand, then we can engage in some honest toil to render them kosher. That honest toil was foreshadowed in the proposition establishing nonempty intersections , when we explained why the intersection of capital A exists for any capital A is not equal to the empty set . But we will spell it out explicitly. Given Extensionality, if we attempt to define capital C as the intersection of the set of capital X such that phi of capital X , all we are really asking is for an object capital C which obeys the following: Displayed expression. for every x, x belongs to capital C if and only if, for every capital X, if phi holds of capital X then x belongs to capital X; equation tagged star. End displayed expression. Now, suppose there is some set, capital S , such that phi of capital S . Then to deliver the intersection membership condition tagged star , we can simply define capital C using Separation, as follows: Displayed expression. capital C is the set of x in capital S such that, for every capital X, if phi holds of capital X then x belongs to capital X. End displayed expression. We leave it as an exercise to check that this definition yields the intersection membership condition tagged star , as desired. And this general strategy will allow us to circumvent any apparent use of Naïve Comprehension in defining intersections. In the particular case which got us started on this line of thought, namely that of the closure of o under f , here is how that would work. We began the proof of the result giving the properties of closure under a function by noting that o belongs to the range of f union the set containing o and that the range of f union the set containing o is f -closed. So, we can define what we want thus: Displayed expression. the closure of o under f equals the set of x in the union of the range of f with the singleton containing o such that, for every capital X containing o, if capital X is closed under f then x belongs to capital X. End displayed expression. End section. End chapter.
