ભાષાઓની સૂચિમાં પાછા જાઓગુજરાતી પ્રોજેક્ટZenodo સંગ્રહ

ગુજરાતી OpenLogic: 722 એકમોનો સંપૂર્ણ PDF

સ્થિર અંગ્રેજી મૂળના બધા 722 એકમો 960 પાનાંની ગુજરાતી આવૃત્તિમાં સમાવાયા છે. સંપૂર્ણ PDF, સીધી સંપાદનીય LaTeX અને તે જ આવૃત્તિ ફરી બનાવવા માટેનું સ્રોત ZIP આ ક્રમે છે.

  1. સંપૂર્ણ PDF વાંચો — 722 એકમો
  2. સીધી સંપૂર્ણ LaTeX — 722 એકમો
  3. સંપૂર્ણ સંપાદનીય સ્રોત ZIP — 722 એકમો

સંપૂર્ણ EPUB હજી તૈયાર થઈ રહ્યું છે. અગાઉનું EPUB માત્ર 270 એકમોનું છે. પ્રકાશિત HTML સ્રોત-સૂચિ આખા પુસ્તકનો HTML પાઠ નથી.

શું તપાસ્યું અને શું બાકી છે?

GitHub અને Zenodoમાંથી PDF, સીધી LaTeX અને ZIPની છ અનામી ડાઉનલોડના નામ, કદ અને SHA-256 સરખાવ્યા. ZIPના 2829 નોંધાયેલા સભ્યો, 722 મૂળ અંગ્રેજી અને 722 ગુજરાતી ફાઇલો, સંપૂર્ણ LaTeXના 722 એકમ-ચિહ્નો અને 6732 હાલના સ્રોત–ભાષાંતર ખંડોના હૅશ મળ્યા. દરેક બંધનમાં દર્શાવેલા પ્રમાણ-અવતરણોની ઓળખ પણ મળી.

આ આખા ભાષાંતરની સ્વતંત્ર ભાષાકીય સમીક્ષા નથી. વ્યવસ્થાપકે PDFનાં પાનાં 1, 58 અને 960 જોયાં; ત્યાં લખાણ કાપાયેલું દેખાયું નહીં. પ્રકાશકની 133 નમૂના-પાનાંની તપાસ અને ફરી બનેલા PDFની બાઇટ-સમાનતાની નોંધ અલગ છે; વ્યવસ્થાપકે ફરી TeX ચલાવ્યું નથી. PDFમાંથી ટેક્સ્ટ કાઢતી વખતે કેટલાક ગુજરાતી જોડાક્ષરોમાં મુશ્કેલી રહે છે.

મૂળ, ભાષાંતર અને પ્રમાણગ્રંથનો નવો નમૂનો

OLP-0576-B004, ક્રમવાચકોનો સરવાળો: મૂળ અને ગુજરાતી બંનેમાં પહેલાં αની નકલ, ત્યાર પછી βની નકલ, સુક્રમ અને અનન્ય ક્રમવાચકનો અર્થ જળવાયો. નકલ મૂકવાના વાક્યમાં ચલોના ઉલ્લેખનો ક્રમ બદલાય છે, પરંતુ નકલોનો ગણિતીય ક્રમ બદલાતો નથી. બંને મૂળ સંદર્ભો અને સૂત્રો મળ્યાં.

ગુજરાતી વિશ્વકોશના ગણસિદ્ધાંત લેખના GU-P013 અને GU-P049 અવતરણો મૂળ HTML સામે તપાસ્યાં. સત્તાવાર ગણિતીય શબ્દાવલીનું GU-P086, PDF પાનું 127, મુદ્રિત પાનું 102, ખરેખર જોઈને “સુરેખ ક્રમ”નો આધાર ચકાસ્યો. આ ગણવિષયક ગદ્ય અને ક્રમ-શબ્દનો આધાર છે; ક્રમવાચકોના સરવાળાની આખી પરિભાષાનું સીધું પ્રમાણ નથી.

નિષ્ણાત સમીક્ષામાં ખાસ તપાસવા જેવી પસંદગીઓ: ક્રમવાચક, સુક્રમિત અને ક્રમ-એકરૂપ માટે વધુ વિશિષ્ટ ગુજરાતી સાક્ષ્ય અને આખા વાક્યની સ્વાભાવિકતા. કામચલાઉ પસંદગીઓની મર્યાદા ખુલ્લી રાખી છે; નમૂનામાં ગણિતીય અર્થનો વિરોધ મળ્યો નથી.
