भाषासूचीतील मराठी आवृत्ती

मुक्त तर्कशास्त्र: संपूर्ण मराठी वाचक

PDF, ऑफलाइन HTML आणि EPUB: ७२२/७२२ स्रोत एकके. PDF मध्ये ९२१ पाने; EPUB मध्ये ९८ वाचनभाग आणि स्वतंत्र अनुक्रमणिका. हे व्याप्तीचे विधान आहे; संपूर्ण भाषिक अचूकतेचे प्रमाणपत्र नाही.

Zenodo वरील संपूर्ण प्रकाशित संच · PDF चे पूर्वदर्शन

नेमके काय तपासले?

प्रमाणीकरणाविना डाउनलोड केलेल्या GitHub वरील १६ नव्या किंवा बदललेल्या फाइलांचे आणि Zenodo वरील सर्व ९४ फाइलांचे नाव, आकार व SHA-256 जुळतात: ११० नव्या जुळण्या. GitHub च्या complete-v1.0 मधील ७८ न बदललेल्या फाइलांची आधीची पडताळणी जतन आहे. नवी GitHub आवृत्ती आणि तिची पूर्वीची आवृत्ती मिळून संपूर्ण संच उपलब्ध आहे; Zenodo वर सर्व ९४ फाइल्स एकत्र आहेत.

स्रोत ZIP मध्ये सर्व ७२२ गोठवलेले इंग्रजी स्रोत व ७२२ मराठी लक्ष्यफाइल्स आहेत; ६,६४४ खंडांच्या नोंदी वर्तमान फाइलांच्या हॅशशी जुळतात. एक लक्ष्यएकक बदलले: ॲरिस्टॉटलविषयीचा परिच्छेद. उर्वरित ७२१ लक्ष्यफाइल्स पूर्वीच्या स्वीकारलेल्या आवृत्तीप्रमाणेच आहेत. थेट संचयी LaTeX पॅकेजमधील मजकुराशी तंतोतंत जुळतो; आवश्यक संकलन-साधने व परवाने आहेत.

EPUB च्या ९८ वाचनभागांत ३८,४५६ MathML अभिव्यक्ती व तितक्याच TeX नोंदी आहेत. ६८ विशेष चिन्हांची स्पष्ट glyph रूपांतरे आहेत. स्वतंत्र, मुख्य वाचनक्रमाबाहेरील अनुक्रमणिकेत शीर्षकांतील ५१ सूत्रे पुन्हा येतात; ती मूळ मजकूरातील सूत्रांमध्ये पुन्हा मोजलेली नाहीत. प्रकाशनकर्त्याची EPUBCheck 5.3.0 शून्य-संदेश नोंद आणि २,२१,३२२ जतन-पडताळे उपलब्ध आहेत. व्यवस्थापकाने पूर्ण निर्मिती-चाचणी पुन्हा चालवलेली नाही.

प्रकाशनकर्त्याच्या पुनरुत्पादन-नोंदीतील PDF, EPUB, LaTeX व सर्व ७८ HTML फाइलांचे हॅश प्रकाशित पॅकेजशी जुळतात. व्यवस्थापकाने मुखपृष्ठ प्रत्यक्ष पाहिले: वाचकासाठी अनावश्यक कच्चा revision hash काढलेला आहे. नव्याने TeX संकलन किंवा सर्व पानांची दृश्यतपासणी केलेली नाही.

संदर्भ आणि मर्यादा

१०१ संदर्भखंडांची २९ सप्टेंबर २०२६ रोजी पूर्वलक्षी तपासणी नोंदली आहे: ९६ ठिकाणी मर्यादित शब्दसाक्ष, तर पाच स्रोताधीन खंडांसाठी संबंधित थेट मराठी साक्ष नाही. ही नवी साक्ष मूळ भाषांतराच्या वेळी वापरली होती, असा दावा नाही.

व्यवस्थापकाने मराठी विश्वकोशातील ॲरिस्टॉटल लेख, इंग्रजी मूळ आणि सुधारित परिच्छेद यांची तुलना केली. कॅटेगरीज, प्रायर ॲनॅलिटिक्स, पोस्टीरियर ॲनॅलिटिक्स आणि संवाक्य या रूपांना थेट आधार आहे. हा एक नमुना आहे; सर्व १०१ निवडींचे स्वतंत्र भाषिक प्रमाणन नाही.

  • १०१ संदर्भखंडांची पूर्वलक्षी तपासणी नोंदली आहे: ९६ ठिकाणी मर्यादित थेट शब्दसाक्ष; पाच स्रोताधीन खंडांसाठी संबंधित मराठी साक्ष नाही. ही साक्ष मूळ भाषांतराच्या वेळी वापरल्याचा दावा नाही.
  • अवकाश भरणारा वक्र या संपूर्ण विशेष संज्ञेची स्वतंत्र साक्ष अद्याप नाही. पुनरावलोकनातील पुराव्यांच्या मर्यादा जतन आहेत.
  • अधिक तपशीलवार ऐतिहासिक पुनरावलोकन २८१/७२२ एककांपुरते आहे; पूर्ण भाषिक किंवा मानवी प्रमाणनाचा दावा नाही.
  • व्यवस्थापकाने नवे मुखपृष्ठ आणि स्रोत-पॅकेज तपासले; सर्व पानांची दृश्य तपासणी किंवा नवे TeX संकलन केलेले नाही.
  • EPUB मधील MathML चे प्रदर्शन वाचन-प्रणालीनुसार बदलू शकते.
