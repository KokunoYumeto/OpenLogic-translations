மூலத் தொகுப்பில் உறையவைக்கப்பட்ட 722 ஆங்கிலக் கோப்புகளும் அவற்றின் 722 தமிழாக்கங்களும் உள்ளன. இரு PDF கோப்புகளுக்கும் முழு உரையுள்ள நேரடி LaTeX கோப்புகள் உள்ளன. இரண்டுக்கும் தேவையான பாணிக் கோப்புகள், படங்கள், நூற்பட்டியல் மற்றும் கட்டமைப்பு நிரல்கள் ஒரே மூல ZIP கோப்பில் உள்ளன.

முக்கிய வேறுபாடு: இப்போது 722 அலகுகளும் ஒரே PDF கோப்பில் இல்லை. முதன்மை நூலும் துணைநூலும் சேர்ந்து முழு மூலத் தொகுப்பை உள்ளடக்குகின்றன. EPUB பதிப்புகள் இன்னும் வெளியிடப்படவில்லை.

PDF இணைப்புகளைப் பயன்படுத்த

தற்போதைய PDF கோப்புகளுக்கிடையிலான இணைப்புகளில் உள்ள கோப்புப் பெயர்கள் பதிவிறக்கப் பெயர்களுடன் பொருந்தவில்லை. பதிவிறக்கிய கோப்புகளைப் பின்வருமாறு பெயர்மாற்றி ஒரே கோப்புறையில் வைக்கவும்:

  • 01-openlogic-ta-Taml-IN-complete.pdf → tamil-complete.pdf
  • 04-openlogic-ta-Taml-IN-source-companion.pdf → tamil-source-companion.pdf

இந்தக் குறை பதிப்பின் பொறுப்பாளருக்குத் தெரிவிக்கப்பட்டுள்ளது. கோப்புகளைப் படிப்பதற்குப் பெயர்மாற்றம் தேவையில்லை; இரண்டு கோப்புகளுக்கிடையிலான இணைப்புகளுக்காக மட்டுமே இது தேவை.

என்ன சரிபார்க்கப்பட்டது?

ஐந்து வெளியீட்டுக் கோப்புகளும் GitHub மற்றும் Zenodo ஆகிய இரு இடங்களிலிருந்தும் உள்நுழையாமல் பதிவிறக்கப்பட்டன: பத்து பதிவிறக்கங்களிலும் பெயர், அளவு, SHA-256 பொருந்தின. மூல ZIP தொகுப்பில் 1,559 கோப்புகளின் அளவும் குறியீடும் சரிபார்க்கப்பட்டன. 722 ஆங்கில மூலக் கோப்புகளும் 722 தமிழாக்கக் கோப்புகளும் அவற்றின் பதிவுகளுடன் பொருந்தின. இரண்டு நேரடி LaTeX கோப்புகளும் ZIP தொகுப்பிலுள்ள கோப்புகளுடன் அப்படியே பொருந்தின.

முதன்மை நூலின் 1, 625 ஆம் பக்கங்களும் துணைநூலின் 22 ஆம் பக்கமும் படங்களாகப் பார்க்கப்பட்டன; அந்த மாதிரிகளில் வெளிப்படையான எழுத்து வெட்டோ ஒன்றன்மேல் ஒன்று படிதலோ காணப்படவில்லை. இது எல்லாப் பக்கங்களின் மொழி அல்லது கணிதத் துல்லியத்திற்கான சான்றல்ல. பதிப்பின் தானியக்கப் பக்க ஆய்வு மற்றும் மறுகட்டமைப்புச் சான்றுகள் மூலத் தொகுப்பில் உள்ளன; முழு அளவிலான சுயாதீன மதிப்புரையாக அவை கருதப்படக்கூடாது.

PDF உரை எடுப்பில் ஒரு கணிதக் குறியின் வரிசைப் பிழை வெளியீட்டில் குறிப்பிடப்பட்டுள்ளது. வாய்பாடுகளைத் துல்லியமாக மீண்டும் பயன்படுத்த நேரடி LaTeX மூலத்தைப் பயன்படுத்துக. முழுமையான PDF அணுகல் குறியிடல் அல்லது எல்லாக் கருவிகளிலும் ஒரே விளைவு கிடைப்பதாகக் கூறப்படவில்லை.

பங்களிப்பும் சான்றுகளும்

முதல் 570 அலகுகளின் இயந்திரத் தமிழாக்கமும் திருத்தங்களும் OpenAI Codex — GPT-5.6 Sol, Ultra சிந்தனை நிலையில் செய்யப்பட்டன. மீதமுள்ள 152 அலகுகளும் பின்னைய திருத்தங்களும் GPT-6 Sol, Ultra சிந்தனை நிலையில் செய்யப்பட்டன. இத்திட்டப் பட்டியல், வரையறுக்கப்பட்ட சரிபார்ப்பு மற்றும் இந்த வழிகாட்டி: OpenAI Codex — GPT-6 Astra, Ultra. சுயாதீனமான மனித அல்லது தாய்மொழி நிபுணர் ஒப்புதல் கிடைத்ததாகக் கூறப்படவில்லை.

கோப்பு அடையாளங்களும் இயந்திரம் படிக்கக்கூடிய சரிபார்ப்புப் பதிவும். மூலமும் தமிழ்ப் பதிப்பின் புதிய உள்ளடக்கமும் CC BY 4.0 உரிமத்தில் வழங்கப்படுகின்றன; கூறு வாரியான உரிமக் குறிப்புகள் மூலத் தொகுப்பில் உள்ளன.
