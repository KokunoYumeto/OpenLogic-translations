தமிழ் Open Logic: முழு வாசிப்பு நூல்

29 செப்டம்பர் 2026 · பதிப்பு 1.1.1 · GitHub வெளியீடு · Zenodo பதிவு

மூலத் தொகுப்பின் 722 அலகுகளும் ஒரே PDF கோப்பிலும் ஒரே EPUB கோப்பிலும் உள்ளன. முதன்மைப் பகுதியின் 695 அலகுகளும் இணைப்பின் 27 அலகுகளும் சேர்ந்து முழு நூலை உருவாக்குகின்றன. PDF: 1,227 பக்கங்கள். இணைப்பின் அலகுகள் கூடுதல் மொழிபெயர்ப்பாக மீண்டும் எண்ணப்படவில்லை.

பதிவிறக்கங்கள்

  1. முழு PDF வாசிப்பு நூல் — 722 அலகுகள்
  2. முழு உரையுள்ள, நேரடியாகத் திருத்தக்கூடிய LaTeX
  3. முழுத் திருத்தக்கூடிய மூலத் தொகுப்பு — ZIP
  4. முழு EPUB — 722 அலகுகள்

தனித்த முதன்மை நூலும் இணைப்பும், அவற்றின் LaTeX மற்றும் EPUB கோப்புகளும் அதே வெளியீட்டில் உள்ளன. பழைய பதிப்புகளும் தனி அத்தியாயங்களும் நீக்கப்படவில்லை.

என்ன திருத்தப்பட்டது?

இணைப்புப் பகுதியின் ஐந்து தவறான பக்க இணைப்புகளும் அவற்றுக்குரிய பக்கக் குறியீடுகளும் திருத்தப்பட்டன. 1,227 பக்கங்களின் உள்ளடக்கம் வெளியிடப்பட்ட இரு கூறுகளுடன் மாறாமல் பொருந்துகிறது. மொத்தம் 2,823 இணைப்பு இலக்குகளும் 718 மூலப் பக்கக் குறியீடுகளும் ஒப்பிடப்பட்டன. முழு நூலுக்கான நேரடி LaTeX கோப்பு சேர்க்கப்பட்டது; EPUB மீளமைப்பு நிரல்களில் தனிப்பட்ட கணினிப் பாதைகளைச் சார்ந்திருந்த இடங்கள் சரிசெய்யப்பட்டன.

மூலக் கோப்புகளும் மீளமைப்பும்

நேரடி LaTeX கோப்பில் 722 அலகுகளின் முழு உரையும் உள்ளது; வெளியிடப்படாத கோப்புகளைச் சுட்டும் சிறு முதன்மைக் கோப்பு மட்டும் அல்ல. ZIP தொகுப்பில் தனித்த மூலக் கோப்புகள், தேவையான பாணிக் கோப்புகள், படங்கள், நூற்பட்டியல், கட்டமைப்பு நிரல்கள் மற்றும் வழிமுறைகள் உள்ளன. உறையவைக்கப்பட்ட 722 ஆங்கிலக் கோப்புகளும் அவற்றின் 722 தமிழாக்கக் கோப்புகளும் பதிவுசெய்யப்பட்ட குறியீடுகளுடன் பொருந்தின.

மீளமைப்புச் சரிபார்ப்பின் வரம்பு: வெளியிடப்பட்ட இரு கூறுகளிலிருந்து PDF மற்றும் EPUB மீளமைப்பு பதிப்பாளரால் சரிபார்க்கப்பட்டது; அதன் சான்று இங்குள்ள கோப்புகளுடன் பொருந்துகிறது. புதிய TeX அல்லது TeX4ht கட்டமைப்பு இந்தச் சுற்றில் மீண்டும் இயக்கப்படவில்லை. முழு உரையுள்ள LaTeX கோப்பைக் கட்டமைத்தால் பக்க அமைப்பு மாறலாம். வெளியீட்டு PDF, முதன்மை நூலையும் இணைப்பையும் தனித்தனியாகக் கட்டமைத்துப் பின்னர் இணைக்கும் முறையில் உருவாகிறது.

சரிபார்க்கப்பட்ட அளவும் அதன் வரம்புகளும்

GitHub மற்றும் Zenodo ஆகிய இரு இடங்களிலிருந்தும் பத்துக் கோப்புகள் வீதம் உள்நுழையாமல் பதிவிறக்கப்பட்டன. இருபது பதிவிறக்கங்களின் பெயர், அளவு, SHA-256 ஆகியவை பொருந்தின. மூல ZIP தொகுப்பின் 1,574 கோப்புகளின் குறியீடுகள் சரிபார்க்கப்பட்டன. நேரடி முழு LaTeX கோப்பின் 722 அலகுகளும் ஏற்கெனவே வெளியிடப்பட்ட கூறுகளின் உரையுடன் பொருந்தின.

EPUB கோப்பின் இரு கூறுகளிலிருந்தும் 37,983 MathML அமைப்புகளும் 1,046 துணைக் கோப்புகளும் பாதுகாக்கப்பட்டுள்ளன; 4,010 உள்ளக இணைப்புகள் சரிபார்க்கப்பட்டன. இந்தப் பதிப்பின் EPUB முந்தைய ஒப்பீட்டில் சரிபார்க்கப்பட்ட அதே கோப்பு. இவை கட்டமைப்பு மற்றும் கோப்பு அடையாளச் சோதனைகள்; முழு மொழிபெயர்ப்பின் பொருள் துல்லியத்திற்கான சான்றல்ல.

PDF உரை எடுப்பில் குறிகளின் வரிசையும் இடைவெளியும் எல்லா இடங்களிலும் அச்சுப் பக்கத்தை அப்படியே பிரதிபலிக்காது. கணித உரையைத் திருத்த அல்லது மீண்டும் பயன்படுத்த LaTeX மூலத்தைப் பயன்படுத்துக. முழுமையான PDF அணுகல் குறியிடல் அல்லது எல்லாக் கருவிகளிலும் ஒரே விளைவு கிடைப்பதாகக் கூறப்படவில்லை.

கலைச்சொல் தேர்வுகளும் பயன்படுத்தப்பட்ட ஆதாரங்களும் மூலத் தொகுப்பில் பதிவு செய்யப்பட்டுள்ளன. சுயாதீன மனித அல்லது தாய்மொழி நிபுணர் ஒப்புதல் கூறப்படவில்லை; பின்னர் மதிப்புரையும் திருத்தங்களும் வரவேற்கப்படுகின்றன.

கோப்பு அடையாளங்களும் இயந்திரம் படிக்கக்கூடிய சரிபார்ப்புப் பதிவும் · முந்தைய இரு நூல் பதிப்பின் பட்டியல் பதிவு · முந்தைய வெளியீடு

முதல் 570 அலகுகளின் இயந்திரத் தமிழாக்கமும் திருத்தங்களும்: OpenAI Codex — GPT-5.6 Sol, Ultra. மீதமுள்ள 152 அலகுகளும் பின்னைய திருத்தங்களும்: GPT-6 Sol, Ultra. இத்திட்டப் பட்டியல், வரையறுக்கப்பட்ட சரிபார்ப்பு மற்றும் இந்த வழிகாட்டி: OpenAI Codex — GPT-6 Astra, Ultra. மனித மதிப்புரை செய்யப்பட்டதாகக் கூறப்படவில்லை.

மூலமும் தமிழ்ப் பதிப்பின் புதிய உள்ளடக்கமும் CC BY 4.0 உரிமத்தில் வழங்கப்படுகின்றன; கூறு வாரியான உரிமக் குறிப்புகள் மூலத் தொகுப்பில் உள்ளன.
