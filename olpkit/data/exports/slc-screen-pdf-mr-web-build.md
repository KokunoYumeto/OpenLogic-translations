# संच, तर्कशास्त्र, संगणन — HTML, EPUB आणि PDF तयार करणे

या स्रोतसंचात मराठी पाठ्यपुस्तकाचा संपादनयोग्य LaTeX मजकूर, आकृत्या, मुद्राक्षरे, संदर्भसूची आणि संकेतस्थळावर किंवा ई-पुस्तकात वाचण्यासाठी लागणारी साधने आहेत. सूत्रे मोठ्याने वाचण्यासाठी वापरलेला मराठी मजकूर आणि आकृत्यांची मराठी वर्णनेही यात आहेत. मूळ पुस्तक, छायाचित्रे, मुद्राक्षरे आणि भाषांतर यांचे श्रेय व परवाने पुस्तकाच्या सुरुवातीला आणि `source/` मधील संबंधित फायलींत दिले आहेत.

## HTML आणि EPUB

1. ZIP फाइल स्वतंत्र फोल्डरमध्ये उलगडा. संगणकावर Python 3.13, Pandoc 3.9.0.2, Poppler 24.04.0 मधील `pdftocairo` आणि Java 21 उपलब्ध असावेत. या आवृत्त्या वापरल्यास आकृत्यांचे रूपांतर आणि पुस्तकाची मांडणी पुनरुत्पादित करता येते. HTML आणि EPUB तयार करण्यासाठी TeX चालवावे लागत नाही.
2. EPUBCheck 5.3.0 चा संपूर्ण ZIP उलगडा. त्यातील `epubcheck.jar` आणि `lib` एकाच फोल्डरमध्ये ठेवा. [EPUBCheck 5.3.0](https://github.com/w3c/epubcheck/releases/tag/v5.3.0)
3. पुस्तकाच्या स्रोतसंचाच्या मूळ फोल्डरमध्ये पुढील आज्ञा द्या. दुसऱ्या आज्ञेत `epubcheck.jar` चा आपल्या संगणकावरील मार्ग द्या. तयार होणाऱ्या पुस्तकासाठी स्रोतसंचाबाहेर एका नव्या फोल्डरचे नाव द्या.

```sh
python -m pip install -r requirements.txt
python rebuild_web.py --epubcheck-jar ../epubcheck-5.3.0/epubcheck.jar --out ../marathi-readers
```

`marathi-readers/reader.html` ब्राउझरमध्ये उघडा. चित्रे आणि मुद्राक्षरे दिसण्यासाठी त्याच्या शेजारील `assets/` फोल्डर ठेवा. वाचकांना हे सर्व एकत्र देण्यासाठी `reader-html.zip` वापरा. ई-पुस्तक वाचण्यासाठी `reader.epub` उघडा. साधन EPUBCheck चालवते आणि तिन्ही फायलींचे SHA-256 मूल्य या आवृत्तीच्या नोंदीशी जुळते का ते तपासते.

## PDF आणि संपादनयोग्य स्रोत

PDF तयार करण्याच्या आज्ञा [source/BUILD.md](source/BUILD.md) मध्ये आहेत. एकत्रित LaTeX फाइल आणि विभागवार स्रोत दोन्ही `source/` मध्ये आहेत. HTML मधील प्रत्येक विभागाचा ओळखक्रमांक मूळ मराठी आवृत्तीतील त्याच विभागाकडे निर्देश करतो. संपादनयोग्य मजकुरातून अंतर्गत टिप्पण्या वगळलेल्या ठिकाणी मूळ आणि वितरणातील फायलींची स्वतंत्र SHA-256 मूल्ये `web/profile.json` मध्ये दिली आहेत.

ही पद्धत याच आवृत्तीच्या फायली पुन्हा तयार करते. गणित किंवा भाषांतर बदलल्यावर बदललेल्या सूत्रांचे वाचन आणि आकृत्यांची वर्णने नव्या मजकुराशी तपासून पुढील आवृत्ती तयार करावी. या पुनर्बांधणीचे साधन OpenAI Codex (GPT-6 Astra, Ultra) यांनी तयार केले आहे.
