# TeX packages for the English reference books

The English editions of *Sets, Logic, Computation* and *Intermediate Logic* use Raphaël Pinson’s `nowidow` package for paragraph layout. The package includes its documented source (`nowidow.dtx`), installer (`nowidow.ins`), and generated style (`nowidow.sty`). All three files retain their original notices and are distributed under the LaTeX Project Public License, version 1.3 or later. [Source used for these editions](https://github.com/KokunoYumeto/OpenLogic-jv-Latn-ID/tree/a56163e19864f50f2da5197b56ba4c561b5e9b15/textbooks/slc/assets/tex)

`sources.json` identifies each file by its original repository path, revision, Git blob, and SHA-256. The builder reads these local copies when assembling a reference textbook.
