5 Aritmetisasi

Materi dalam bab ini menyajikan konstruksi sistem-sistem bilangan dalam teori himpunan naif. Materi ini diambil dari teks Open Set Theory karya Tim Button.

5.1 Dari ℕ ke ℤ

Berikut dua pengamatan dasar:

  1. Setiap bilangan bulat dapat ditulis dalam bentuk n − m , dengan n , m ∈ ℕ .

  2. Informasi yang dikodekan dalam suatu ekspresi n − m dapat pula dikodekan oleh pasangan terurut ⟨ n , m ⟩ .

Kita sudah mengetahui bahwa pasangan-pasangan terurut bilangan asli merupakan anggota dari ℕ 2 . Kita juga mengandaikan bahwa kita memahami ℕ . Maka, berdasarkan dua pengamatan tadi, berikut sebuah usulan naif: mari kita perlakukan bilangan bulat sebagai pasangan terurut bilangan asli.

Sebenarnya, usulan ini terlalu naif. Kita tentu menginginkan 0 − 2 = 4 − 6 . Akan tetapi, jelas bahwa ⟨ 0 , 2 ⟩ ≠ ⟨ 4 , 6 ⟩ . Jadi, kita tidak dapat begitu saja mengatakan bahwa ℕ 2 adalah himpunan bilangan bulat.

Dengan menggeneralisasi masalah tadi, yang kita inginkan adalah: a − b = c − d  jika dan hanya jika  a + d = c + b (Sudah semestinya jelas bahwa begitulah bilangan bulat dimaksudkan berperilaku: cukup tambahkan b dan d pada kedua ruas.) Cara mudah untuk menjamin perilaku ini ialah dengan mendefinisikan suatu relasi ekuivalensi antara pasangan-pasangan terurut, ∼ , sebagai berikut: ⟨ a , b ⟩ ∼ ⟨ c , d ⟩  jika dan hanya jika  a + d = c + b Sekarang kita harus menunjukkan bahwa relasi ini merupakan relasi ekuivalensi.

Proposisi 5.1.

∼ merupakan relasi ekuivalensi.

Bukti.

Kita harus menunjukkan bahwa ∼ bersifat refleksif, simetris, dan transitif.

Refleksivitas: Jelas bahwa ⟨ a , b ⟩ ∼ ⟨ a , b ⟩ , karena a + b = b + a .

Simetri: Andaikan ⟨ a , b ⟩ ∼ ⟨ c , d ⟩ , sehingga a + d = c + b . Maka c + b = a + d , sehingga ⟨ c , d ⟩ ∼ ⟨ a , b ⟩ .

Transitivitas: Andaikan ⟨ a , b ⟩ ∼ ⟨ c , d ⟩ ∼ ⟨ m , n ⟩ . Maka a + d = c + b dan c + n = m + d . Jadi a + d + c + n = c + b + m + d , dan dengan demikian a + n = m + b . Oleh karena itu, ⟨ a , b ⟩ ∼ ⟨ m , n ⟩ .

Sekarang kita dapat menggunakan relasi ekuivalensi ini untuk membentuk kelas-kelas ekuivalensi:

Definisi 5.2.

Bilangan bulat adalah kelas-kelas ekuivalensi, di bawah ∼ , dari pasangan-pasangan terurut bilangan asli; yakni, ℤ = ℕ 2 / ∼ .

Orang mungkin mempunyai berbagai reaksi filosofis terhadap definisi stipulatif ini. Namun, sebelum mempertimbangkan reaksi-reaksi tersebut, ada baiknya kita melanjutkan beberapa rincian teknis.

Setelah menyatakan apa itu bilangan bulat, kita perlu mendefinisikan fungsi dan relasi dasar padanya. Mari kita tulis [ m , n ] ∼ untuk kelas ekuivalensi di bawah ∼ yang memuat ⟨ m , n ⟩ sebagai anggota.4 Yakni: [ m , n ] ∼ = { ⟨ a , b ⟩ ∈ ℕ 2 : ⟨ a , b ⟩ ∼ ⟨ m , n ⟩ } Sekarang kita memberikan beberapa definisi: [ a , b ] ∼ + [ c , d ] ∼ = [ a + c , b + d ] ∼ [ a , b ] ∼ × [ c , d ] ∼ = [ a c + b d , a d + b c ] ∼ [ a , b ] ∼ ≤ [ c , d ] ∼  jika dan hanya jika  a + d ≤ b + c (Sebagaimana lazimnya, saya menggunakan ‘ a b ’ untuk menyatakan ‘ ( a × b ) ’, semata-mata agar aksioma-aksioma tersebut lebih mudah dibaca.) Sekarang kita perlu memastikan bahwa definisi-definisi ini berperilaku sebagaimana semestinya. Menjabarkan apa artinya dan memeriksanya satu per satu cukup melelahkan; rinciannya kita tempatkan dalam Bagian 5.6. Namun, intinya: semuanya berhasil!

Masih ada satu hal terakhir. Kita telah membangun bilangan bulat dengan menggunakan bilangan asli. Akan tetapi, ini berarti bahwa bilangan asli bukan bilangan bulat itu sendiri. Kita akan kembali membahas arti filosofisnya dalam Bagian 5.5. Namun, dari sudut pandang teknis murni, kita memerlukan suatu cara agar dapat memperlakukan bilangan asli sebagai bilangan bulat. Gagasannya cukup mudah: untuk setiap n ∈ ℕ , kita menetapkan bahwa n ℤ = [ n , 0 ] ∼ . Kita perlu memastikan bahwa definisi ini berperilaku baik, yaitu bahwa untuk sembarang m , n ∈ ℕ ( m + n ) ℤ = m ℤ + n ℤ ( m × n ) ℤ = m ℤ × n ℤ m ≤ n ↔ m ℤ ≤ n ℤ Namun, semua ini cukup langsung. Sebagai contoh, untuk menunjukkan bahwa kondisi kedua berlaku, kita cukup memanfaatkan perilaku bilangan asli dan bernalar sebagai berikut: ( m × n ) ℤ = [ m × n , 0 ] ∼ = [ m × n + 0 × 0 , m × 0 + 0 × n ] ∼ = [ m , 0 ] ∼ × [ n , 0 ] ∼ = m ℤ × n ℤ Sebagai latihan, silakan pastikan bahwa kedua kondisi lainnya berlaku.

5.2 Dari ℤ ke ℚ

Kita baru saja melihat cara membangun bilangan bulat dari bilangan asli, dengan menggunakan teori himpunan naif. Sekarang kita akan melihat cara membangun bilangan rasional dari bilangan bulat dengan cara yang sangat mirip. Pengamatan awal kita adalah:

  1. Setiap bilangan rasional dapat ditulis dalam bentuk i j , dengan i dan j keduanya bilangan bulat, tetapi j taknol.

  2. Informasi yang dikodekan dalam suatu ekspresi i j dapat pula dikodekan dalam pasangan terurut ⟨ i , j ⟩ .

Pendekatan yang jelas ialah memandang bilangan rasional sebagai pasangan terurut yang diambil dari ℤ × ( ℤ ∖ { 0 ℤ } ) . Namun, seperti sebelumnya, pendekatan itu agak terlalu naif, karena kita menginginkan 3 2 = 6 4 , sedangkan ⟨ 3 , 2 ⟩ ≠ ⟨ 6 , 4 ⟩ . Secara lebih umum, kita menginginkan: a b = c d  jika dan hanya jika  a × d = b × c Untuk memperolehnya, kita mendefinisikan suatu relasi ekuivalensi pada ℤ × ( ℤ ∖ { 0 ℤ } ) sebagai berikut: ⟨ a , b ⟩ ∽ ⟨ c , d ⟩  jika dan hanya jika  a × d = b × c Kita harus memeriksa bahwa relasi ini merupakan relasi ekuivalensi. Hal ini sangat mirip dengan kasus ∼ , dan kita serahkan sebagai latihan.

Namun, relasi ini memungkinkan kita mengatakan:

Definisi 5.3.

Bilangan rasional adalah kelas-kelas ekuivalensi, di bawah ∽ , dari pasangan-pasangan bilangan bulat (dengan elemen kedua yang taknol). Yakni, ℚ = ( ℤ × ( ℤ ∖ { 0 ℤ } ) ) / ∽ .

Seperti halnya bilangan bulat, kita juga ingin mendefinisikan beberapa operasi dasar. Jika [ i , j ] ∽ adalah kelas ekuivalensi di bawah ∽ yang memuat ⟨ i , j ⟩ sebagai anggota, kita menetapkan: [ a , b ] ∽ + [ c , d ] ∽ = [ a d + b c , b d ] ∽ [ a , b ] ∽ × [ c , d ] ∽ = [ a c , b d ] ∽ . Untuk mendefinisikan  r ≤ s  pada bilangan rasional ini, kita menggunakan fakta bahwa  r ≤ s  jika dan hanya jika  s − r  tidak negatif, yaitu  s − r  dapat ditulis sebagai  i j  dengan  i  taknegatif dan  j  positif: [ a , b ] ∽ ≤ [ c , d ] ∽  jika dan hanya jika  [ c , d ] ∽ − [ a , b ] ∽ = [ i ℤ , j ℤ ] ∽ untuk suatu i ∈ ℕ dan 0 ≠ j ∈ ℕ .

Selanjutnya, kita perlu memeriksa bahwa definisi-definisi tersebut berperilaku sebagaimana semestinya; hal ini kita tempatkan dalam Bagian 5.6. Namun, semuanya memang berperilaku demikian! Terakhir, kita menginginkan suatu cara untuk memperlakukan bilangan bulat sebagai bilangan rasional; maka, untuk setiap i ∈ ℤ , kita menetapkan bahwa i ℚ = [ i , 1 ℤ ] ∽ . Sekali lagi, kita memeriksa dalam Bagian 5.6 bahwa semua ini berperilaku dengan tepat.

5.3 Garis Bilangan Real

Langkah selanjutnya ialah menunjukkan cara membangun bilangan real dari bilangan rasional. Sebelum itu, kita perlu memahami apa yang khas pada bilangan real.

Bilangan real berperilaku sangat mirip dengan bilangan rasional. (Secara teknis, keduanya merupakan contoh lapangan terurut; untuk definisinya, lihat Definisi 5.9.) Jika Anda telah mengerjakan latihan-latihan untuk Bab 4, Anda akan mengetahui bahwa himpunan bilangan real mempunyai kardinalitas yang secara ketat lebih besar daripada himpunan bilangan rasional, yakni ℚ ≺ ℝ . Hal ini pertama kali dibuktikan oleh Cantor. Namun, selama sekitar dua setengah milenium telah diketahui bahwa ada bilangan irasional, yakni bilangan real yang bukan bilangan rasional. Bahkan:

Teorema 5.4.

2 bukan bilangan rasional, yakni 2 ∉ ℚ

Bukti.

Untuk memperoleh kontradiksi, andaikan 2 adalah bilangan rasional. Jadi 2 = m n untuk suatu bilangan asli m dan n . Kita bahkan dapat memilih m dan n sebagai pasangan terkecil yang mewakili rasio tersebut, sehingga pecahannya tidak dapat disederhanakan lagi. Dengan menata ulang, m 2 = 2 n 2 . Dari sini, kita dapat menyelesaikan pembuktian dengan dua cara:

Pertama, secara geometris (mengikuti Tennenbaum).5 Perhatikan persegi-persegi berikut:

Karena m 2 = 2 n 2 , daerah tumpang tindih kedua persegi bersisi n mempunyai luas yang sama dengan daerah yang tidak ditutupi oleh kedua persegi tersebut; yakni, luas persegi jingga sama dengan jumlah luas kedua persegi yang tidak diarsir. Jadi, jika persegi jingga bersisi p dan setiap persegi yang tidak diarsir bersisi q , maka p 2 = 2 q 2 . Namun, sekarang 2 = p q , dengan p < m dan q < n dan p , q ∈ ℕ . Hal ini bertentangan dengan fakta bahwa m dan n dipilih sekecil mungkin.

Kedua, secara formal. Karena m 2 = 2 n 2 , diperoleh bahwa m genap. (Mudah ditunjukkan bahwa jika x ganjil, maka x 2 ganjil.) Jadi m = 2 r , untuk suatu r ∈ ℕ . Dengan menata ulang, 2 r 2 = n 2 , maka n juga genap. Jadi m dan n keduanya genap, sehingga pecahan m n dapat disederhanakan lagi. Kontradiksi!

Sambil lalu, bukti diagramatis ini memungkinkan kita meninjau kembali materi dari Bagian 76.4. Tennenbaum (1927–2006) adalah seorang matematikawan yang sepenuhnya modern; tetapi bukti tersebut tidak dapat disangkal keindahannya, sepenuhnya ketat secara matematis, dan menggunakan intuisi geometris!

Bagaimanapun, bilangan real “lebih luas” daripada bilangan rasional. Dalam arti tertentu, terdapat “celah-celah” pada bilangan rasional, dan celah-celah ini diisi oleh bilangan real. Weierstrass menyadari bahwa hal ini menggambarkan satu sifat bilangan real yang membedakannya dari bilangan rasional, yakni Sifat Kelengkapan: Setiap himpunan takkosong bilangan real yang mempunyai suatu batas atas mempunyai suatu batas atas terkecil.

Mudah dilihat bahwa bilangan rasional tidak memiliki Sifat Kelengkapan. Sebagai contoh, perhatikan himpunan bilangan rasional yang lebih kecil daripada 2 , yakni: { p ∈ ℚ : p 2 < 2  atau  p < 0 } Himpunan ini mempunyai suatu batas atas dalam bilangan rasional; sebagai contoh, semua anggota< himpunan ini lebih kecil daripada 3 . Namun, apa batas atas terkecilnya? Kita ingin mengatakan ‘ 2 ’; tetapi kita baru saja melihat bahwa 2 bukan bilangan rasional. Tidak ada pula bilangan rasional terkecil yang lebih besar daripada 2 . Jadi, himpunan tersebut mempunyai suatu batas atas tetapi tidak mempunyai batas atas terkecil. Oleh karena itu, bilangan rasional tidak memiliki Sifat Kelengkapan.

Sebaliknya, kontinuum “secara moral semestinya” memiliki Sifat Kelengkapan. Kita tidak hanya menginginkan 2 menjadi bilangan real; kita ingin mengisi semua “celah” pada garis bilangan rasional. Bahkan, kita ingin kontinuum itu sendiri tidak memiliki “celah”. Itulah tepatnya yang akan kita peroleh melalui Kelengkapan.

5.4 Dari ℚ ke ℝ

Pada dasarnya, Sifat Kelengkapan menunjukkan bahwa setiap titik α pada garis bilangan real membagi garis itu secara sempurna menjadi dua bagian: bagian yang batas atas terkecilnya adalah α , dan bagian yang batas bawah terbesarnya adalah α . Untuk membangun bilangan real dari bilangan rasional, Dedekind mengusulkan agar kita cukup memandang bilangan real sebagai potongan yang membagi bilangan rasional. Dengan kata lain, kita mengidentifikasi 2 dengan potongan yang memisahkan bilangan rasional < 2 dari bilangan rasional > 2 .

Mari kita rapikan gagasan ini. Jika kita memotong bilangan rasional menjadi dua bagian, kita dapat mengidentifikasi secara unik partisi yang kita buat hanya dengan memperhatikan bagian bawahnya. Maka, secara saksama, kita memberikan definisi berikut:

Definisi 5.5.

Potongan

Suatu potongan α adalah setiap segmen awal sejati takkosong dari bilangan rasional yang tidak mempunyai elemen terbesar. Dengan kata lain, α merupakan suatu potongan jika dan hanya jika:

  1. takkosong, sejati: ∅ ≠ α ⊊ ℚ

  2. awal: untuk semua p , q ∈ ℚ : jika p < q ∈ α maka p ∈ α

  3. tanpa maksimum: untuk setiap p ∈ α terdapat q ∈ α sedemikian sehingga p < q

Kemudian ℝ adalah himpunan semua potongan.

Sekarang kita dapat mengatakan bahwa 2 = { p ∈ ℚ : p 2 < 2  atau  p < 0 } . Tentu saja, kita perlu memeriksa bahwa objek ini memang suatu potongan, tetapi hal itu kita tempatkan dalam Bagian 5.6.

Seperti sebelumnya, setelah mendefinisikan beberapa entitas, selanjutnya kita perlu mendefinisikan fungsi dan relasi dasar padanya. Kita mulai dengan yang mudah: α ≤ β  jika dan hanya jika  α ⊆ β Definisi urutan ini memungkinkan kita menyatakan hasil utama, yaitu bahwa himpunan semua potongan memiliki Sifat Kelengkapan. Jika dijabarkan sepenuhnya, pernyataannya berbentuk sebagai berikut. Jika S adalah himpunan takkosong yang terdiri atas potongan-potongan dan mempunyai suatu batas atas, maka S mempunyai suatu batas atas terkecil. Secara lebih rinci: terdapat suatu potongan, λ , yang merupakan batas atas bagi S , yakni  ( ∀ α ∈ S ) α ⊆ λ , dan λ adalah potongan terkecil semacam itu, yakni  ( ∀ β ∈ ℝ ) ( ( ∀ α ∈ S ) α ⊆ β → λ ⊆ β ) . Berikut pembuktian hasil tersebut:

Teorema 5.6.

Himpunan semua potongan memiliki Sifat Kelengkapan.

Bukti.

Misalkan S adalah sembarang himpunan takkosong yang terdiri atas potongan-potongan dan mempunyai suatu batas atas. Misalkan λ = ⋃ S . Pertama-tama kita menyatakan bahwa λ adalah suatu potongan:

  1. Karena S takkosong, sekurang-kurangnya satu potongan termasuk dalam S , sehingga ∅ ≠ λ . Karena S adalah himpunan yang terdiri atas potongan-potongan, λ ⊆ ℚ . Karena S mempunyai suatu batas atas, terdapat suatu p ∈ ℚ yang tidak termasuk dalam satu pun potongan α ∈ S . Jadi p ∉ λ , sehingga λ ⊊ ℚ .

  2. Andaikan p < q ∈ λ . Maka terdapat suatu α ∈ S sedemikian sehingga q ∈ α . Karena α adalah suatu potongan, p ∈ α . Jadi p ∈ λ .

  3. Andaikan p ∈ λ . Maka terdapat suatu α ∈ S sedemikian sehingga p ∈ α . Karena α adalah suatu potongan, terdapat suatu q ∈ α sedemikian sehingga p < q . Jadi q ∈ λ .

Hal ini membuktikan pernyataan tersebut. Selain itu, jelas bahwa ( ∀ α ∈ S ) α ⊆ ⋃ S = λ , yakni  λ merupakan suatu batas atas bagi S . Sekarang andaikan β ∈ ℝ juga merupakan suatu batas atas, yakni  ( ∀ α ∈ S ) α ⊆ β . Untuk setiap p ∈ ℚ , jika p ∈ λ , maka terdapat α ∈ S sedemikian sehingga p ∈ α , sehingga p ∈ β . Secara umum, λ ⊆ β . Jadi λ merupakan batas atas terkecil bagi S .

Jadi, kita mempunyai sekumpulan entitas yang memenuhi Sifat Kelengkapan. Salah satu cara untuk mengungkapkannya ialah: tidak ada “celah” pada potongan-potongan kita. (Dengan demikian, membuat “potongan” lanjutan dari bilangan real, bukan dari bilangan rasional, tidak akan menghasilkan objek baru yang menarik.)

Selanjutnya, kita harus mendefinisikan beberapa operasi pada bilangan real. Kita mulai dengan menanamkan bilangan rasional ke dalam bilangan real dengan menetapkan bahwa p ℝ = { q ∈ ℚ : q < p } untuk setiap p ∈ ℚ . Kemudian kita mendefinisikan: α + β = { p + q : p ∈ α ∧ q ∈ β } α × β = { p × q : 0 ≤ p ∈ α ∧ 0 ≤ q ∈ β } ∪ 0 ℝ jika  α , β ≥ 0 ℝ Untuk menangani kasus-kasus perkalian lainnya, pertama-tama tetapkan: − α = { p − q : p < 0 ∧ q ∉ α } dan kemudian tetapkan: α × β = { − α × − β jika  α < 0 ℝ  dan  β < 0 ℝ − ( − α × β ) jika  α < 0 ℝ  dan  β > 0 ℝ − ( α × − β ) jika  α > 0 ℝ  dan  β < 0 ℝ Selanjutnya, kita perlu memeriksa bahwa setiap definisi tersebut selalu menghasilkan suatu potongan. Terakhir, kita perlu menjalani pembuktian yang mudah (tetapi panjang lebar) bahwa potongan-potongan yang didefinisikan demikian berperilaku tepat sebagaimana semestinya. Namun, semua ini kita tempatkan dalam Bagian 5.6.

5.5 Beberapa Refleksi Filosofis

Demikianlah rincian teknisnya. Namun, apa yang telah dicapai oleh semua itu?

Hampir tidak terbantahkan bahwa semua itu memberi kita matematika murni yang indah. Selain itu, terdapat beberapa pencapaian konseptual yang mendalam. Menyadari bahwa Sifat Kelengkapan mengungkapkan perbedaan penting antara bilangan real dan bilangan rasional merupakan wawasan yang mendalam. Selain itu, konstruksi eksplisit bilangan real sebagai potongan Dedekind memberi landasan yang kokoh bagi pokok bahasan analisis. Kita mengetahui bahwa gagasan lapangan terurut lengkap bersifat koheren, karena potongan-potongan tersebut membentuk tepat lapangan semacam itu.

Meskipun demikian, kita perlu mengemukakan beberapa keberatan terhadap pencapaian-pencapaian tersebut.

Pertama, tidak jelas bahwa memikirkan bilangan real dalam kerangka potongan lebih ketat secara matematis daripada memikirkan bilangan real dalam kerangka ekspansi desimalnya yang sudah dikenal (yang mungkin tak berhingga). “Konstruksi” bilangan real yang disebut terakhir ini agak menyerupai konstruksi bilangan real melalui barisan Cauchy; tetapi sebenarnya konstruksi itu pada intinya telah dikenal para matematikawan sejak awal abad ke-17 (lihat Bagian 5.7). Peningkatan ketelitian matematis yang sebenarnya berasal dari kesadaran bahwa bilangan real memiliki Sifat Kelengkapan; kemampuan membangun bilangan real sebagai himpunan tertentu mungkin, dengan sendirinya, tidak begitu menarik.

Lebih tidak jelas lagi bahwa aritmetisasi bilangan bulat, atau bilangan rasional, yang jauh lebih mudah, meningkatkan ketelitian matematis dalam ranah-ranah tersebut. Di sini ada baiknya kita membuat suatu pengamatan sederhana. Setelah membangun bilangan bulat sebagai kelas-kelas ekuivalensi dari pasangan terurut bilangan asli, lalu membangun bilangan rasional sebagai kelas-kelas ekuivalensi dari pasangan terurut bilangan bulat, dan kemudian membangun bilangan real sebagai himpunan bilangan rasional, kita segera melupakan konstruksi-konstruksi tersebut. Secara khusus: tidak seorang pun akan pernah ingin menggunakan konstruksi-konstruksi tersebut dalam suatu pembuktian matematis (kecuali, tentu saja, pembuktian bahwa konstruksi-konstruksi itu berperilaku sebagaimana yang dimaksudkan). Jauh lebih mudah berbicara langsung tentang suatu bilangan real daripada berbicara tentang suatu himpunan dari himpunan dari himpunan dari himpunan dari himpunan dari himpunan dari himpunan bilangan asli.

Yang paling meragukan dari semuanya ialah bahwa definisi-definisi ini memberi tahu kita apa hakikat bilangan bulat, bilangan rasional, atau bilangan real secara metafisis. Artinya, patut diragukan bahwa bilangan real (misalnya) adalah himpunan tertentu (dari himpunan dari himpunan…). Penghalang utama bagi pandangan semacam itu ialah bahwa konstruksinya dapat dilakukan dengan banyak cara berbeda. Dalam kasus bilangan real, ada beberapa konstruksi berbeda yang benar-benar menarik (lihat Bagian 5.7). Namun, berikut cara yang sungguh sepele untuk memperoleh beberapa konstruksi berbeda: seperti dalam Bagian 2.2, kita dapat mendefinisikan pasangan terurut secara agak berbeda; seandainya kita menggunakan gagasan alternatif tentang pasangan terurut ini, konstruksi kita akan berhasil sama baiknya dengan sebelumnya, tetapi kita akan berakhir dengan objek-objek berbeda. Dengan demikian, terdapat banyak konstruksi berbasis teori himpunan yang saling bersaing bagi bilangan bulat, bilangan rasional, dan bilangan real. Maka, akan semena-mena (dan memalukan) jika kita mengklaim bahwa bilangan bulat (misalnya) adalah himpunan-himpunan ini, dan bukan himpunan-himpunan itu. (Seperti dalam Bagian 2.2, ini merupakan suatu contoh argumen yang dimasyhurkan oleh Benacerraf 1965.)

Ada satu hal lebih lanjut yang patut dikemukakan: ada sesuatu yang cukup ganjil pada konstruksi kita. Kita mulai dengan bilangan asli. Kemudian kita membangun bilangan bulat, dan membangun “ 0 dari bilangan bulat”, yakni [ 0 , 0 ] ∼ . Akan tetapi, 0 ≠ [ 0 , 0 ] ∼ . Bahkan, berdasarkan konstruksi kita, tidak ada bilangan asli yang merupakan bilangan bulat. Namun, hal ini tampak sangat berlawanan dengan intuisi. Bahkan, dalam Bagian 1.3, tanpa banyak argumentasi kita mengklaim bahwa ℕ ⊆ ℚ . Jika konstruksi tersebut memberi tahu kita secara persis hakikat bilangan, klaim ini jelas keliru.

Jika kita melihatnya secara menyeluruh, apa kesimpulan kita? Dengan bekerja dalam teori himpunan naif, dan memanfaatkan bilangan asli, kita dapat memperlakukan bilangan bulat, bilangan rasional, dan bilangan real sebagai himpunan-himpunan tertentu. Dalam arti itu, kita dapat menanamkan teori-teori tentang entitas tersebut di dalam suatu teori himpunan. Namun, makna filosofis penanaman ini sama sekali tidak sederhana.

Tentu saja, semua ini bukan kata akhir! Intinya hanya ini. Untuk menunjukkan bahwa aritmetisasi bilangan real memang memiliki arti filosofis yang mendalam, diperlukan suatu argumen filosofis tambahan.

5.6 Ring dan Lapangan Terurut

Sepanjang bab ini, kita mengklaim bahwa definisi-definisi tertentu berperilaku “sebagaimana semestinya”. Dalam lampiran teknis ini, kita akan menjabarkan apa yang kita maksud, serta (menguraikan cara) menunjukkan bahwa definisi-definisi itu memang berperilaku “dengan tepat”.

Dalam Bagian 5.1, kita mendefinisikan penjumlahan dan perkalian pada ℤ . Kita ingin menunjukkan bahwa, sebagaimana didefinisikan, keduanya memberi ℤ struktur yang “kita inginkan”. Secara khusus, struktur yang dimaksud adalah ring komutatif.

Definisi 5.7.

Suatu ring komutatif adalah himpunan S , yang dilengkapi elemen-elemen khusus 0 dan 1 serta operasi + dan × , yang memenuhi kedelapan rumus berikut: 𝐴𝑠𝑜𝑠𝑖𝑎𝑡𝑖𝑣𝑖𝑡𝑎𝑠 a + ( b + c ) = ( a + b ) + c ( a × b ) × c = a × ( b × c ) 𝐾𝑜𝑚𝑢𝑡𝑎𝑡𝑖𝑣𝑖𝑡𝑎𝑠 a + b = b + a a × b = b × a 𝐸𝑙𝑒𝑚𝑒𝑛 𝑖𝑑𝑒𝑛𝑡𝑖𝑡𝑎𝑠 a + 0 = a a × 1 = a 𝐼𝑛𝑣𝑒𝑟𝑠 𝑎𝑑𝑖𝑡𝑖𝑓 ( ∃ b ∈ S ) 0 = a + b 𝐷𝑖𝑠𝑡𝑟𝑖𝑏𝑢𝑡𝑖𝑣𝑖𝑡𝑎𝑠 a × ( b + c ) = ( a × b ) + ( a × c ) Secara implisit, semua rumus ini terikat oleh kuantor universal yang dibatasi pada S . Perhatikan pula bahwa elemen 0 dan  1 di sini tidak harus merupakan bilangan asli yang bernama sama.

Jadi, untuk memeriksa bahwa bilangan bulat membentuk suatu ring komutatif, kita hanya perlu memeriksa bahwa kedelapan kondisi tersebut terpenuhi. Tidak ada kondisi yang sulit dibuktikan, tetapi pemeriksaannya agak panjang. Sebagai contoh, berikut cara membuktikan Asosiativitas untuk penjumlahan:

Bukti.

Tetapkan i , j , k ∈ ℤ . Jadi terdapat a 1 , b 1 , a 2 , b 2 , a 3 , b 3 ∈ ℕ sedemikian sehingga i = [ a 1 , b 1 ] dan j = [ a 2 , b 2 ] dan k = [ a 3 , b 3 ] . (Agar mudah dibaca, kita menulis “ [ x , y ] ” alih-alih “ [ x , y ] ∼ ”; kita akan melakukannya sepanjang bagian ini.) Sekarang: i + ( j + k ) = [ a 1 , b 1 ] + ( [ a 2 , b 2 ] + [ a 3 , b 3 ] ) = [ a 1 , b 1 ] + [ a 2 + a 3 , b 2 + b 3 ] = [ a 1 + ( a 2 + a 3 ) , b 1 + ( b 2 + b 3 ) ] = [ ( a 1 + a 2 ) + a 3 , ( b 1 + b 2 ) + b 3 ] = [ a 1 + a 2 , b 1 + b 2 ] + [ a 3 , b 3 ] = ( [ a 1 , b 1 ] + [ a 2 , b 2 ] ) + [ a 3 , b 3 ] = ( i + j ) + k dengan bebas memanfaatkan perilaku penjumlahan pada ℕ .

Begitu pula, berikut cara membuktikan Invers aditif:

Bukti.

Tetapkan i ∈ ℤ , sehingga i = [ a , b ] untuk suatu a , b ∈ ℕ . Misalkan j = [ b , a ] ∈ ℤ . Dengan memanfaatkan perilaku bilangan asli, ( a + b ) + 0 = 0 + ( a + b ) , sehingga ⟨ a + b , b + a ⟩ ∼ ℤ ⟨ 0 , 0 ⟩ menurut definisi, dan dengan demikian [ a + b , b + a ] = [ 0 , 0 ] = 0 ℤ . Maka sekarang i + j = [ a , b ] + [ b , a ] = [ a + b , b + a ] = [ 0 , 0 ] = 0 ℤ .

Berikut pula pembuktian Distributivitas:

Bukti.

Sekarang: i × ( j + k ) = [ a 1 , b 1 ] × ( [ a 2 , b 2 ] + [ a 3 , b 3 ] ) = [ a 1 , b 1 ] × [ a 2 + a 3 , b 2 + b 3 ] = [ a 1 ( a 2 + a 3 ) + b 1 ( b 2 + b 3 ) , a 1 ( b 2 + b 3 ) + b 1 ( a 2 + a 3 ) ] = [ a 1 a 2 + a 1 a 3 + b 1 b 2 + b 1 b 3 , a 1 b 2 + a 1 b 3 + a 2 b 1 + a 3 b 1 ] = [ a 1 a 2 + b 1 b 2 , a 1 b 2 + a 2 b 1 ] + [ a 1 a 3 + b 1 b 3 , a 1 b 3 + a 3 b 1 ] = ( [ a 1 , b 1 ] × [ a 2 , b 2 ] ) + ( [ a 1 , b 1 ] × [ a 3 , b 3 ] ) = ( i × j ) + ( i × k )

Sebagai latihan, silakan buktikan kelima kondisi lainnya. Setelah melakukannya, kita telah menunjukkan bahwa ℤ merupakan ring komutatif, yakni bahwa penjumlahan dan perkalian (sebagaimana didefinisikan) berperilaku sebagaimana semestinya.

Namun, tugas kita belum selesai. Selain mendefinisikan penjumlahan dan perkalian pada ℤ , kita mendefinisikan suatu relasi urutan, ≤ , dan kita harus memeriksa bahwa relasi ini berperilaku sebagaimana semestinya. Secara lebih rinci, kita harus menunjukkan bahwa ℤ merupakan ring terurut.6

Definisi 5.8.

Suatu ring terurut adalah ring komutatif yang juga dilengkapi dengan suatu relasi urutan total, ≤ , sedemikian sehingga: a ≤ b → a + c ≤ b + c ( a ≤ b ∧ 0 ≤ c ) → a × c ≤ b × c

Seperti sebelumnya, menunjukkan bahwa  ℤ , sebagaimana dibangun, merupakan ring terurut adalah pekerjaan rutin tetapi panjang. Hal itu kita serahkan kepada Anda.

Dengan demikian, bilangan bulat telah selesai ditangani. Namun, sekarang kita perlu menunjukkan hal-hal yang sangat mirip mengenai bilangan rasional. Secara khusus, sekarang kita perlu menunjukkan bahwa bilangan rasional membentuk suatu lapangan terurut berdasarkan definisi kita bagi + , × , dan ≤ :

Definisi 5.9.

Suatu lapangan terurut adalah ring terurut yang juga memenuhi: 𝐼𝑛𝑣𝑒𝑟𝑠 𝑝𝑒𝑟𝑘𝑎𝑙𝑖𝑎𝑛 ( ∀ a ∈ S ∖ { 0 } ) ( ∃ b ∈ S ) a × b = 1

Setelah Anda menunjukkan bahwa ℤ merupakan ring terurut, menunjukkan bahwa ℚ merupakan lapangan terurut adalah pekerjaan yang mudah tetapi panjang.

Setelah menangani bilangan bulat dan bilangan rasional, tinggal bilangan real yang perlu ditangani. Secara khusus, kita perlu menunjukkan bahwa ℝ merupakan lapangan terurut yang lengkap, yakni lapangan terurut yang memiliki Sifat Kelengkapan. Teorema 5.6 telah membuktikan bahwa ℝ memiliki Sifat Kelengkapan. Namun, kita masih perlu menjalani proses (yang melelahkan) untuk memeriksa bahwa ℝ merupakan lapangan terurut.

Sebelum bergegas mengerjakan latihan panjang itu, kita perlu memeriksa beberapa hal yang lebih “langsung”. Sebagai contoh, kita memerlukan jaminan bahwa α + β , sebagaimana didefinisikan, memang suatu potongan, untuk sembarang potongan α dan β . Berikut pembuktian fakta tersebut:

Bukti.

5.7 Lampiran: Bilangan Real sebagai Barisan Cauchy

Dalam Bagian 5.4, kita membangun bilangan real sebagai potongan Dedekind. Dalam bagian ini, kita menjelaskan suatu konstruksi alternatif. Konstruksi ini bertumpu pada definisi Cauchy tentang (apa yang kini kita sebut) barisan Cauchy; tetapi penggunaan definisi ini untuk membangun bilangan real berasal dari para penulis lain pada abad ke-19, khususnya Weierstrass, Heine, Méray, dan Cantor. (Untuk sejarah yang menarik, lihat O’Connor and Robertson 2005.)

Sebelum memasuki abad ke-19, ada baiknya kita mempertimbangkan Simon Stevin (1548–1620). Singkatnya, Stevin menyadari bahwa kita dapat memikirkan setiap bilangan real melalui ekspansi desimalnya. Maka, bahkan bilangan irasional seperti 2 mempunyai ekspansi desimal yang baik, yang dimulai dengan: 1.41421356237 … Sangat mudah memodelkan ekspansi desimal dalam teori himpunan: cukup pandang ekspansi itu sebagai fungsi d : ℕ → ℕ , dengan d ( n ) yang menyatakan digit pada tempat desimal ke- n yang kita perhatikan. Kemudian kita memerlukan sedikit penyesuaian untuk menangani bagian bilangan real sebelum tanda desimal (di sini, hanya 1 ). Kita juga memerlukan penyesuaian lebih lanjut (suatu relasi ekuivalensi) untuk menjamin bahwa, misalnya, 0.999 … = 1 . Namun, tidak sulit memberikan konstruksi bilangan real yang sepenuhnya ketat secara matematis, dengan cara Stevin, di dalam teori himpunan.

Stevin bukan fokus kita. (Untuk pembahasan lebih lanjut mengenai Stevin, lihat Katz and Katz 2012.) Namun, berikut suatu gagasan yang berkaitan erat. Alih-alih memperlakukan ekspansi desimal 2 secara langsung, kita dapat mempertimbangkan suatu barisan hampiran rasional yang semakin akurat terhadap 2 , dengan memperhatikan ekspansi yang semakin teliti: 1 , 1.4 , 1.414 , 1.4142 , 1.41421 , … Gagasan bahwa bilangan real dapat dipandang melalui “hampiran yang semakin baik” memberi kita landasan bagi rangkaian wawasan lainnya (serupa dengan pengamatan yang kita gunakan ketika membangun ℚ dari ℤ , atau ℤ dari ℕ ). Wawasan dasarnya adalah:

  1. Setiap bilangan real dapat ditulis sebagai ekspansi desimal (yang mungkin tak berhingga).

  2. Informasi yang dikodekan oleh ekspansi desimal (yang mungkin tak berhingga) dapat pula dikodekan oleh suatu barisan bilangan rasional.

  3. Suatu barisan bilangan rasional dapat dipandang sebagai fungsi dari ℕ ke ℚ ; cukup tetapkan f ( n ) sebagai bilangan rasional ke- n dalam barisan tersebut.

Tentu saja, tidak setiap fungsi dari ℕ ke ℚ akan memberi kita suatu bilangan real. Sebagai contoh, perhatikan fungsi berikut: f ( n ) = { 1 jika  n  ganjil 0 jika  n  genap Pada dasarnya, kekhawatirannya ialah bahwa barisan 0 , 1 , 0 , 1 , 0 , 1 , 0 , … tampaknya tidak “mendekati” bilangan real mana pun. Jadi, untuk memastikan bahwa kita mempertimbangkan barisan yang memang mendekati suatu bilangan real, kita perlu membatasi perhatian pada barisan yang mempunyai suatu limit.

Kita telah menjumpai gagasan limit dalam Bagian 76.2. Namun, kita tidak dapat menggunakan definisi yang persis sama seperti yang kita gunakan di sana. Ekspresi “ ( ∀ ε > 0 ) ” di sana secara tersirat melibatkan kuantifikasi atas bilangan real; dan kita sedang mempertimbangkan limit fungsi pada bilangan real; jadi, menggunakan definisi tersebut berarti memanfaatkan bilangan real; padahal bilangan real itulah yang sedang kita upayakan untuk bangun. Untungnya, kita dapat bekerja dengan gagasan limit yang berkaitan erat.

Definisi 5.10.

Suatu fungsi f : ℕ → ℚ merupakan barisan Cauchy jika dan hanya jika untuk setiap ε ∈ ℚ positif berlaku ( ∃ ℓ ∈ ℕ ) ( ∀ m , n > ℓ ) | f ( m ) − f ( n ) | < ε .

Gagasan umum mengenai limit tetap sama seperti sebelumnya: jika Anda menginginkan tingkat ketelitian tertentu (yang diukur oleh  ε ), ada suatu “wilayah” tempat mencarinya (setiap masukan yang lebih besar daripada  ℓ ). Mudah dilihat bahwa barisan kita 1 , 1.4 , 1.414 , 1.4142 , 1.41421 …mempunyai suatu limit: jika Anda ingin menghampiri 2 dengan galat kurang dari 1 10 n , cukup perhatikan sembarang suku setelah suku ke- n .

Gagasan yang jelas, dengan demikian, ialah mengatakan bahwa suatu bilangan real adalah sembarang barisan Cauchy. Namun, seperti dalam konstruksi ℤ dan ℚ , gagasan ini terlalu naif: untuk setiap bilangan real tertentu, ada beberapa barisan Cauchy berbeda yang menunjukkan bilangan real tersebut. Cara sederhana untuk melihat hal ini adalah sebagai berikut. Jika diberikan suatu barisan Cauchy  f , definisikan g sebagai fungsi yang sama persis dengan  f , kecuali bahwa g ( 0 ) ≠ f ( 0 ) . Karena kedua barisan itu setelah suku pertama, selisih keduanya mendekati nol menurut kriteria yang berkaitan dengan Definisi 5.10; karena itu, keduanya seharusnya dipandang “mendefinisikan” bilangan real yang sama. Jadi, sebenarnya kita harus memandang barisan-barisan Cauchy tersebut sebagai bilangan real yang sama.

Oleh karena itu, sekali lagi kita perlu mendefinisikan suatu relasi ekuivalensi pada barisan-barisan Cauchy, dan mengidentifikasi bilangan real dengan kelas-kelas ekuivalensi. Pertama-tama, kita memerlukan gagasan tentang suatu fungsi yang mendekati 0 pada limitnya. Untuk setiap fungsi h : ℕ → ℚ , katakan bahwa h mendekati 0 jika dan hanya jika untuk setiap ε ∈ ℚ positif berlaku ( ∃ ℓ ∈ ℕ ) ( ∀ n > ℓ ) | h ( n ) | < ε .7 Selanjutnya, jika f dan g adalah fungsi ℕ → ℚ , tetapkan ( f − g ) ( n ) = f ( n ) − g ( n ) . Sekarang definisikan: f ≎ g  jika dan hanya jika  ( f − g )  mendekati  0 . Kita perlu memeriksa bahwa ≎ merupakan relasi ekuivalensi; dan memang demikian. Kemudian, jika kita mau, kita dapat mendefinisikan bilangan real sebagai kelas-kelas ekuivalensi, di bawah ≎ , dari semua barisan Cauchy dari ℕ → ℚ .

Setelah melakukan ini, seperti biasa kita menulis [ f ] ≎ untuk kelas ekuivalensi yang memuat f sebagai anggota. Namun, agar tetap mudah dibaca, selanjutnya kita akan menghilangkan subskrip dan hanya menulis [ f ] . Kita juga menetapkan bahwa, untuk setiap q ∈ ℚ , berlaku q ℝ = [ c q ] , dengan c q sebagai fungsi konstan c q ( n ) = q untuk semua n ∈ ℕ . Kemudian kita mendefinisikan relasi dan operasi dasar pada bilangan real, misalnya: [ f ] + [ g ] = [ ( f + g ) ] [ f ] × [ g ] = [ ( f × g ) ] dengan ( f + g ) ( n ) = f ( n ) + g ( n ) dan ( f × g ) ( n ) = f ( n ) × g ( n ) . Tentu saja, kita juga perlu memeriksa bahwa masing-masing ( f + g ) , ( f − g ) , dan ( f × g ) merupakan barisan Cauchy jika f dan g demikian; memang benar, dan hal ini kita serahkan kepada Anda.

Terakhir, kita mendefinisikan suatu gagasan urutan. Katakan bahwa [ f ] positif jika dan hanya jika [ f ] ≠ 0 ℝ dan ( ∃ ℓ ∈ ℕ ) ( ∀ n > ℓ ) 0 < f ( n ) keduanya berlaku. Kemudian katakan bahwa [ f ] < [ g ] jika dan hanya jika [ ( g − f ) ] positif. Kita harus memeriksa bahwa definisi ini terdefinisi dengan baik (yakni, tidak bergantung pada pemilihan fungsi “wakil” dari kelas ekuivalensi). Setelah melakukan ini, cukup mudah menunjukkan bahwa semuanya menghasilkan sifat-sifat aljabar yang tepat; yakni:

Teorema 5.11.

Kelas-kelas ekuivalensi barisan Cauchy membentuk suatu lapangan terurut.

Bukti.

Latihan.

Membuktikan bahwa bilangan real yang dibangun demikian memiliki Sifat Kelengkapan lebih sulit, sehingga kita akan memberikan pembuktiannya.

Teorema 5.12.

Setiap himpunan takkosong barisan Cauchy yang mempunyai suatu batas atas mempunyai suatu batas atas terkecil.

Sketsa pembuktian

Misalkan S adalah sembarang himpunan takkosong barisan Cauchy yang mempunyai suatu batas atas. Maka terdapat suatu p ∈ ℚ sedemikian sehingga p ℝ merupakan batas atas bagi S . Ambil r ∈ S ; maka terdapat suatu q ∈ ℚ sedemikian sehingga q ℝ < [ r ] . Jadi, jika batas atas terkecil bagi S ada, batas itu berada di antara q ℝ dan p ℝ (inklusif).

Kita akan semakin mendekati b.a.t. tersebut secara bersamaan dari bawah dan atas. Secara khusus, kita mendefinisikan dua fungsi, f , g : ℕ → ℚ , dengan tujuan agar f semakin mendekati b.a.t. dari atas, dan g semakin mendekatinya dari bawah. Kita mulai dengan mendefinisikan: f ( 0 ) = p g ( 0 ) = q Kemudian, dengan a n = f ( n ) + g ( n ) 2 , tetapkan:8 f ( n + 1 ) = { a n jika  ( ∀ h ∈ S ) [ h ] ≤ ( a n ) ℝ f ( n ) jika tidak g ( n + 1 ) = { a n jika  ( ∃ h ∈ S ) [ h ] ≥ ( a n ) ℝ g ( n ) jika tidak Baik f maupun g merupakan barisan Cauchy. (Hal ini dapat diperiksa dengan cukup mudah, tetapi kita serahkan sebagai latihan.) Perhatikan bahwa fungsi ( f − g ) mendekati 0 , karena selisih antara f dan g menjadi paling banyak setengah pada setiap langkah. Oleh karena itu, [ f ] = [ g ] .

Pertama-tama kita menunjukkan bahwa [ f ] merupakan suatu batas atas bagi S , yakni  ( ∀ h ∈ S ) [ h ] ≤ [ f ] . (Selama pembuktian, kita akan menggunakan Teorema 5.11.) Ambil h ∈ S dan andaikan, untuk memperoleh kontradiksi, bahwa [ f ] < [ h ] , sehingga 0 ℝ < [ ( h − f ) ] . Karena f adalah barisan Cauchy yang menurun secara monoton, terdapat suatu n ∈ ℕ sedemikian sehingga [ ( c f ( n ) − f ) ] < [ ( h − f ) ] . Jadi: ( f ( n ) ) ℝ = [ c f ( n ) ] < [ f ] + [ ( h − f ) ] = [ h ] , yang bertentangan dengan fakta bahwa, menurut konstruksi, [ h ] ≤ ( f ( n ) ) ℝ .

Selanjutnya kita menunjukkan bahwa [ f ] = [ g ] adalah batas atas terkecil bagi S . Jadi, misalkan j adalah sembarang barisan Cauchy dan andaikan [ j ] < [ g ] . Dengan bernalar seperti di atas (menggunakan fakta bahwa g meningkat), terdapat n ∈ ℕ sedemikian sehingga [ j ] < ( g ( n ) ) ℝ . Namun, menurut konstruksi terdapat h ∈ S sedemikian sehingga ( g ( n ) ) ℝ ≤ [ h ] , sehingga [ j ] < [ h ] dan oleh karena itu [ j ] bukan batas atas bagi S .

Buktikan bahwa kelas-kelas ekuivalensi barisan Cauchy membentuk suatu lapangan terurut.
