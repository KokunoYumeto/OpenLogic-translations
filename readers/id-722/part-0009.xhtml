6 Himpunan Tak Hingga

Bab mengenai himpunan tak hingga ini diambil dari Open Set Theory karya Tim Button.

6.1 Hotel Hilbert

Himpunan bilangan asli jelas bersifat tak hingga. Jadi, jika kita tidak ingin begitu saja mengandaikan tersedianya bilangan asli, langkah pertama kita harus mencirikan himpunan tak hingga dengan istilah yang tidak perlu menyebut bilangan asli itu sendiri. Berikut suatu pendekatan yang elok, disampaikan Hilbert dalam sebuah kuliah pada tahun 1924. Ia meminta kita membayangkan

[…] sebuah hotel dengan sejumlah hingga kamar. Setiap kamar itu harus dihuni tepat oleh satu tamu. Jika para tamu kemudian saling bertukar kamar dengan suatu cara, [tetapi] sedemikian sehingga setiap kamar tetap dihuni tidak lebih dari satu orang, tidak ada kamar yang akan menjadi kosong, dan dengan cara ini pemilik hotel tidak dapat menciptakan tempat baru bagi tamu yang baru datang [… ¶…]

Sekarang kita tetapkan bahwa hotel itu mempunyai kamar-kamar bernomor yang banyaknya tak hingga, 1 , 2 , 3 , 4 , 5 , …, dan masing-masing dihuni tepat oleh satu tamu. Begitu seorang tamu baru datang, pemilik hanya perlu memindahkan setiap tamu lama ke kamar yang nomornya satu lebih besar, dan kamar  1 akan kosong bagi tamu yang baru datang itu.

(diterbitkan dalam Hilbert 2013, 730; terjemahan kami)

Pokok yang menentukan ialah bahwa Hotel Hilbert mempunyai kamar yang banyaknya tak hingga; dan penjelasannya dapat kita gunakan untuk mendefinisikan arti pernyataan tersebut. Memang, inilah pendekatan Dedekind (tentu saja disajikan di sini dengan anakronisme yang sangat besar; definisi Dedekind berasal dari 1888):

Definisi 6.1.

Suatu himpunan A bersifat tak hingga Dedekind jika dan hanya jika terdapat injeksi dari  A ke suatu himpunan bagian sejati dari  A . Artinya, terdapat suatu o ∈ A dan injeksi f : A → A sedemikian sehingga o ∉ ran ( f ) .

6.2 Aljabar Dedekind

Kita tidak hanya menghendaki bilangan asli itu tak hingga; kita menghendaki agar bilangan-bilangan tersebut mempunyai sifat-sifat (aljabar) tertentu: bilangan-bilangan itu harus berperilaku baik terhadap penjumlahan, perkalian, dan seterusnya.

Gagasan Dedekind ialah menjadikan gagasan fungsi penerus sebagai dasar, lalu mencirikan bilangan sebagai objek yang mempunyai sifat-sifat berikut:

  1. Terdapat suatu bilangan, 0 , yang bukan penerus bilangan mana pun
    yakni, 0 ∉ ran ( s )
    yakni, ∀ x   s ( x ) ≠ 0

  2. Bilangan-bilangan yang berbeda mempunyai penerus yang berbeda
    yakni, s adalah injeksi
    yakni, ∀ x ∀ y ( s ( x ) = s ( y ) → x = y )

  3. Setiap bilangan diperoleh dari 0 melalui penerapan berulang fungsi penerus.

Dua syarat pertama mudah ditangani dengan logika orde pertama (lihat di atas). Namun, kita tidak dapat menangani enumi 3 hanya dengan logika orde pertama. Terobosan Dedekind ialah merumuskan ulang syarat enumi 3, dalam istilah teori himpunan, sebagai berikut:

  1. Bilangan asli adalah himpunan terkecil yang tertutup terhadap fungsi penerus: yakni, jika kita menerapkan s pada sembarang anggota dari himpunan tersebut, kita memperoleh anggota lain dari himpunan itu.

Namun, kita perlu menguraikan hal ini secara perlahan.

Definisi 6.2.

Untuk sembarang fungsi f , himpunan X bersifat f -tertutup jika dan hanya jika ( ∀ x ∈ X ) f ( x ) ∈ X . Sekarang, untuk setiap o , definisikan clo f ( o ) = ⋂ { X : o ∈ X  dan  X  bersifat  f -tertutup }

Jadi, clo f ( o ) adalah irisan semua himpunan f -tertutup yang mempunyai o sebagai anggota. Secara intuitif, clo f ( o ) merupakan himpunan f -tertutup terkecil yang mempunyai o sebagai anggota. Hasil berikutnya membuat gagasan intuitif itu menjadi saksama:

Lema 6.3.

Untuk sembarang fungsi f dan sembarang o ∈ A :

  1. o ∈ clo f ( o ) ; dan

  2. clo f ( o ) bersifat f -tertutup; dan

  3. jika X bersifat f -tertutup dan o ∈ X , maka clo f ( o ) ⊆ X .

Bukti.

Ada sekurang-kurangnya satu himpunan f -tertutup yang mempunyai o sebagai anggota, yakni ran ( f ) ∪ { o } . Jadi, clo f ( o ) , yaitu irisan dari semua himpunan semacam itu, ada. Sekarang kita harus memeriksa enumi 1–enumi 3.

Mengenai enumi 1: o ∈ clo f ( o ) karena himpunan tersebut merupakan irisan himpunan-himpunan yang semuanya mempunyai o sebagai anggota.

Mengenai enumi 2: andaikan x ∈ clo f ( o ) . Jadi, jika o ∈ X dan X bersifat f -tertutup, maka x ∈ X ; dan karena X bersifat f -tertutup, sekarang f ( x ) ∈ X . Maka f ( x ) ∈ clo f ( o ) .

Mengenai enumi 3: secara umum, jika X ∈ C , maka ⋂ C ⊆ X .

Dengan ini, kita dapat mengatakan:

Definisi 6.4.

Suatu aljabar Dedekind adalah suatu himpunan A , bersama dengan fungsi f : A → A dan suatu o ∈ A , sedemikian sehingga:

  1. o ∉ ran ( f )

  2. f adalah injeksi

  3. A = clo f ( o )

Karena A = clo f ( o ) , hasil kita sebelumnya memberi tahu bahwa A adalah himpunan f -tertutup terkecil yang mempunyai o sebagai anggota. Jelaslah bahwa suatu aljabar Dedekind bersifat tak hingga Dedekind; lihat saja klausa enumi 1 dan enumi 2 dalam definisi tersebut. Namun, fakta yang lebih menarik ialah bahwa setiap himpunan yang tak hingga Dedekind dapat dijadikan suatu aljabar Dedekind.

Teorema 6.5.

Jika terdapat suatu himpunan yang tak hingga Dedekind, maka terdapat suatu aljabar Dedekind.

Bukti.

Misalkan D bersifat tak hingga Dedekind. Jadi, terdapat suatu injeksi g : D → D dan suatu elemen o ∈ D ∖ ran ( g ) . Sekarang, misalkan A = clo g ( o ) ; berdasarkan Lema 6.3, A ada dan o ∈ A . Misalkan f = g ↾ A . Kita akan menunjukkan bahwa A , f , o membentuk suatu aljabar Dedekind.

Mengenai enumi 1: o ∉ ran ( g ) dan ran ( f ) ⊆ ran ( g ) , sehingga o ∉ ran ( f ) .

Mengenai enumi 2: g adalah suatu injeksi pada D ; maka f ⊆ g harus merupakan suatu injeksi.

Mengenai enumi 3: berdasarkan Lema 6.3, A bersifat g -tertutup; terlebih lagi, A bersifat f -tertutup. Maka clo f ( o ) ⊆ A berdasarkan Lema 6.3. Karena clo f ( o ) juga bersifat f -tertutup dan f = g ↾ A , diperoleh bahwa clo f ( o ) bersifat g -tertutup. Jadi, A ⊆ clo f ( o ) berdasarkan Lema 6.3.

6.3 Aljabar Dedekind dan Induksi Aritmetis

Hal yang sangat penting ialah bahwa suatu aljabar Dedekind—bahkan, setiap aljabar Dedekind—dapat berfungsi sebagai pengganti bilangan asli. Hal ini diperoleh berkat konsekuensi sederhana berikut:

Teorema 6.6.

Induksi aritmetis

Misalkan N , s , o membentuk suatu aljabar Dedekind. Maka, untuk sembarang himpunan X :

jika o ∈ X dan ( ∀ n ∈ N ∩ X ) s ( n ) ∈ X , maka N ⊆ X .

Bukti.

Berdasarkan definisi aljabar Dedekind, N = clo s ( o ) . Sekarang, jika o ∈ X dan ( ∀ n ∈ N ) ( n ∈ X → s ( n ) ∈ X ) , maka N = clo s ( o ) ⊆ X .

Karena induksi merupakan ciri bilangan asli, pokoknya adalah sebagai berikut. Dari sembarang himpunan yang tak hingga Dedekind, kita dapat membentuk suatu aljabar Dedekind dan menggunakan aljabar tersebut sebagai pengganti bilangan asli.

Memang, Teorema 6.6 merumuskan induksi dalam istilah teori himpunan. Namun, prinsip itu mudah kita nyatakan dalam istilah yang mungkin lebih akrab:

Akibat 6.7.

Misalkan N , s , o membentuk suatu aljabar Dedekind. Maka, untuk sembarang rumus φ ( x ) , yang boleh mempunyai parameter:

jika φ ( o ) dan ( ∀ n ∈ N ) ( φ ( n ) → φ ( s ( n ) ) ) , maka ( ∀ n ∈ N ) φ ( n ) .

Bukti.

Misalkan X = { n ∈ N : φ ( n ) } , lalu gunakan Teorema 6.6.

Dalam hasil ini, kita berbicara tentang suatu rumus yang “mempunyai parameter”. Secara kasar, maksudnya ialah bahwa untuk sembarang objek c 1 , … , c k , kita dapat bekerja dengan φ ( x , c 1 , … , c k ) . Secara lebih saksama, kita dapat menyatakan hasil tersebut tanpa menyebut “parameter” sebagai berikut. Untuk sembarang rumus φ ( x , v 1 , … , v k ) , yang semua variabel bebasnya ditampilkan, kita mempunyai: ∀ v 1 … ∀ v k ( ( φ ( o , v 1 , … , v k ) ∧ ( ∀ x ∈ N ) ( φ ( x , v 1 , … , v k ) → φ ( s ( x ) , v 1 , … , v k ) ) ) → ( ∀ x ∈ N ) φ ( x , v 1 , … , v k ) ) Jelaslah bahwa pembicaraan mengenai “mempunyai parameter” dapat membuat uraian jauh lebih mudah dibaca. (Dalam Bagian XV, kita akan cukup sering menggunakan perangkat ini.)

Kembali ke aljabar Dedekind: dari sembarang aljabar Dedekind, kita juga dapat mendefinisikan fungsi-fungsi aritmetis yang biasa, yakni penjumlahan, perkalian, dan perpangkatan. Namun, hal ini tidak sepele dan melibatkan teknik definisi rekursif. Teknik tersebut akan kita perkenalkan dan benarkan jauh kemudian, dan dalam konteks yang jauh lebih umum. (Pembaca yang berminat mungkin ingin meninjau kembali hal ini setelah Bab 69, atau mungkin membaca pembahasan alternatif, misalnya Potter 2004, pp. 95–8.) Namun, jika N , s , o membentuk suatu aljabar Dedekind, pada akhirnya kita akan dapat menetapkan hal-hal berikut: a + o = a a × o = o a o = s ( o ) a + s ( b ) = s ( a + b ) a × s ( b ) = ( a × b ) + a a s ( b ) = a b × a dan menunjukkan bahwa semuanya berperilaku sebagaimana yang diharapkan.

6.4 “Bukti” Dedekind tentang Keberadaan Himpunan Tak Hingga

Dalam bab ini, kita telah menyajikan pembahasan bilangan asli dalam teori himpunan, dengan menggunakan aljabar Dedekind. Dalam Bagian 5.5, kita merenungkan makna filosofis aritmetisasi analisis (di antara hal-hal lain). Sekarang kita perlu merenungkan makna dari apa yang telah kita capai di sini.

Sepanjang Bab 5, kita menganggap bilangan asli sebagai sesuatu yang telah tersedia dan menggunakannya untuk membangun bilangan bulat, rasional, dan real secara eksplisit. Dalam bab ini, kita belum memberikan konstruksi eksplisit bilangan asli. Kita hanya menunjukkan bahwa, jika diberikan sembarang himpunan yang tak hingga Dedekind, kita dapat mendefinisikan suatu himpunan yang akan berperilaku persis sebagaimana kita kehendaki  ℕ berperilaku.

Jelaslah bahwa kita tidak dapat mengaku telah menjawab suatu pertanyaan metafisis, seperti objek manakah yang merupakan bilangan asli. Namun, hal itu justru baik. Lagi pula, dalam Bagian 5.5, kita menekankan bahwa kita akan keliru jika menganggap definisi ℝ sebagai himpunan potongan Dedekind sebagai suatu penemuan, alih-alih suatu penetapan yang memudahkan. Pengamatan yang menentukan ialah bahwa potongan Dedekind mencontohkan sifat-sifat matematis utama bilangan real. Demikian pula di sini: pengamatan yang menentukan ialah bahwa setiap aljabar Dedekind mencontohkan sifat-sifat matematis utama bilangan asli. (Bahkan, Dedekind menegaskan pokok ini dengan membuktikan bahwa semua aljabar Dedekind isomorfik (1888, Theorems 132–3). Maka tidak mengherankan bahwa banyak “strukturalis” kontemporer menyebut Dedekind sebagai seorang perintis.)

Selain itu, kita telah menunjukkan cara menanamkan teori bilangan asli ke dalam suatu teori himpunan sederhana yang naif. Teori itu sendiri masih cukup informal, tetapi (tampaknya) tidak mengandaikan bilangan asli sebagai sesuatu yang telah tersedia. Jadi, mungkin kita sedang menuju realisasi proyek ambisius Dedekind sendiri, yang ia jelaskan sebagai berikut:

Dalam ilmu pengetahuan, tidak ada sesuatu yang dapat dibuktikan yang patut dipercayai tanpa bukti. Meskipun tuntutan ini tampak masuk akal, saya tidak dapat menganggapnya telah dipenuhi bahkan dalam metode-metode paling mutakhir untuk meletakkan landasan ilmu yang paling sederhana; yakni, bagian logika yang berurusan dengan teori bilangan. Dengan menyebut aritmetika (aljabar, analisis) sekadar bagian dari logika, maksud saya ialah bahwa saya menganggap konsep bilangan sepenuhnya tidak bergantung pada gagasan atau intuisi ruang dan waktu—bahwa saya justru menganggapnya sebagai produk langsung hukum-hukum pemikiran murni. (Dedekind, 1888, preface)

Gagasan berani Dedekind adalah sebagai berikut. Kita baru saja menunjukkan cara membangun bilangan asli hanya dengan menggunakan teori himpunan (naif). Dalam Bab 5, kita melihat cara membangun bilangan real jika bilangan asli dan sedikit teori himpunan telah diberikan. Jadi, mungkin “aritmetika (aljabar, analisis)” ternyata “sekadar bagian dari logika” (dalam pengertian luas Dedekind atas kata “logika”).

Itulah gagasannya. Namun, tunggu sejenak. Konstruksi aljabar Dedekind kita (pengganti bilangan asli yang kita gunakan) bergantung pada syarat bahwa suatu himpunan yang tak hingga Dedekind ada. (Lihat kembali Teorema 6.5.) Jika keberadaan suatu himpunan yang tak hingga Dedekind tidak dapat ditetapkan melalui “logika” atau “hukum-hukum pemikiran murni”, proyek tersebut terhenti.

Jadi, dapatkah keberadaan suatu himpunan yang tak hingga Dedekind ditetapkan oleh “hukum-hukum pemikiran murni”? Berikut upaya Dedekind:

Ranah pemikiran saya sendiri, yakni totalitas S dari segala hal yang dapat menjadi objek pemikiran saya, bersifat tak hingga. Sebab, jika s menandai suatu elemen dari  S , maka pemikiran s ′ bahwa  s dapat menjadi objek pemikiran saya itu sendiri merupakan suatu elemen dari  S . Jika kita memandangnya sebagai suatu citra φ ( s ) dari elemen  s , maka …  S bersifat [tak hingga Dedekind], sebagaimana hendak dibuktikan. (Dedekind, 1888, §66)

Ini merupakan hal yang sangat mencengangkan untuk ditemukan di tengah-tengah sebuah buku yang sebagian besarnya terdiri atas bukti-bukti matematis yang sangat ketat. Dua catatan patut dikemukakan.

Pertama: “bukti” ini hampir tidak mempunyai sifat yang sekarang akan kita kenali sebagai sifat “matematis”. Bukti ini berbicara tentang objek psikologis (pemikiran), dan bahkan sekadar objek yang mungkin ada.

Kedua: sekurang-kurangnya sebagaimana kita telah menyajikan aljabar Dedekind, “bukti” ini mempunyai kekurangan teknis yang langsung terlihat. Jika argumen Dedekind berhasil, argumen itu hanya menetapkan bahwa terdapat hal yang banyaknya tak hingga (secara khusus, pemikiran yang banyaknya tak hingga). Namun, Dedekind juga perlu memberi kita alasan untuk memandang  S sebagai satu himpunan, dengan anggota yang banyaknya tak hingga, alih-alih memandang  S sebagai sejumlah hal (dalam bentuk jamak).

Fakta bahwa Dedekind tidak melihat kesenjangan di sini mungkin menunjukkan bahwa penggunaan kata “totalitas” olehnya tidak secara tepat sejalan dengan penggunaan kata “himpunan” oleh kita.9 Namun, hal ini tidak terlalu mengejutkan. Proyek yang kita kerjakan dalam dua bab terakhir—suatu “konstruksi” bilangan asli, lalu dari bilangan itu suatu “konstruksi” bilangan bulat, real, dan rasional—seluruhnya dilaksanakan secara naif. Kita begitu saja menggunakan himpunan ini atau himpunan itu ketika membutuhkannya, tanpa menetapkan banyak prinsip umum mengenai himpunan mana tepatnya yang ada, dan kapan. Namun, kita tahu bahwa kita memerlukan beberapa prinsip umum; jika tidak, kita akan terjerumus ke dalam Paradoks Russell.

Kini tibalah waktunya bagi kita untuk meninggalkan kenaifan tersebut.

6.5 Lampiran: Membuktikan Schröder–Bernstein

Sebelum meninggalkan teori himpunan naif, masih ada satu bukti naif terakhir (tetapi canggih!) yang perlu kita bahas. Ini adalah bukti teorema Schröder–Bernstein (Teorema 4.25): jika A ⪯ B dan B ⪯ A , maka A ≈ B ; yakni, jika diberikan injeksi f : A → B dan g : B → A , maka terdapat bijeksi h : A → B .

Dalam bab ini, kita mengikuti gagasan Dedekind mengenai penutupan. Pada kenyataannya, Dedekind memberikan suatu bukti yang elok bagi teorema Schröder–Bernstein dengan menggunakan gagasan tersebut, dan bukti itu akan kita sajikan di sini. Bukti ini mengikuti secara dekat Potter (2004, pp. 157–8), jika Anda menghendaki pembahasan yang sedikit berbeda tetapi pada dasarnya serupa. Sedikit pencarian di internet juga akan meyakinkan Anda bahwa teorema ini—agak menyerupai irasionalitas 2 —mempunyai banyak bukti menarik yang berbeda-beda.

Dengan menggunakan notasi yang serupa dengan Definisi 6.2, misalkan Clo f ( B ) = ⋂ { X : B ⊆ X  dan  X  bersifat  f -tertutup } untuk setiap himpunan B dan fungsi  f . Dengan definisi ini, Clo f ( B ) adalah himpunan f -tertutup terkecil yang memuat  B , dalam arti berikut:

Lema 6.8.

Untuk sembarang fungsi f dan sembarang B :

  1. B ⊆ Clo f ( B ) ; dan

  2. Clo f ( B ) bersifat f -tertutup; dan

  3. jika X bersifat f -tertutup dan B ⊆ X , maka Clo f ( B ) ⊆ X .

Bukti.

Persis seperti dalam Lema 6.3.

Kita memerlukan satu fakta terakhir untuk sampai pada teorema Schröder–Bernstein:

Proposisi 6.9.

Jika A ⊆ B ⊆ C dan A ≈ C , maka B ≈ C .

Bukti.

Jika diberikan bijeksi f : C → A , misalkan F = Clo f ( C ∖ B ) dan definisikan suatu fungsi g dengan domain C sebagai berikut: g ( x ) = { f ( x ) jika  x ∈ F x jika tidak Kita akan menunjukkan bahwa g merupakan bijeksi dari C → B ; dari sini akan diperoleh bahwa g ∘ f − 1 : A → B merupakan bijeksi, sehingga bukti selesai.

Pertama, kita menyatakan bahwa jika x ∈ F , sedangkan y ∉ F , maka g ( x ) ≠ g ( y ) . Untuk mendapatkan kontradiksi, andaikan sebaliknya, sehingga y = g ( y ) = g ( x ) = f ( x ) . Karena x ∈ F dan F bersifat f -tertutup berdasarkan Lema 6.8, kita mempunyai y = f ( x ) ∈ F , suatu kontradiksi.

Sekarang andaikan g ( x ) = g ( y ) . Jadi, berdasarkan uraian di atas, x ∈ F jika dan hanya jika y ∈ F . Jika x , y ∈ F , maka f ( x ) = g ( x ) = g ( y ) = f ( y ) , sehingga x = y karena f merupakan bijeksi. Jika x , y ∉ F , maka x = g ( x ) = g ( y ) = y . Jadi, g merupakan injeksi.

Tinggal ditunjukkan bahwa ran ( g ) = B . Pertama, ran ( g ) ⊆ B : jika x ∈ F , maka g ( x ) = f ( x ) ∈ A ⊆ B ; jika x ∉ F , maka x ∈ B karena C ∖ B ⊆ F , dan karena itu g ( x ) = x ∈ B . Untuk inklusi sebaliknya, tetapkan x ∈ B ⊆ C . Jika x ∉ F , maka g ( x ) = x . Jika x ∈ F , maka x = f ( y ) untuk suatu y ∈ F , sebab jika tidak demikian, F ∖ { x } akan bersifat f -tertutup dan memuat C ∖ B , yang mustahil berdasarkan Lema 6.8; sekarang g ( y ) = f ( y ) = x .

Akhirnya, berikut bukti hasil utamanya. Ingatlah bahwa jika diberikan suatu fungsi h dan himpunan D , kita mendefinisikan h [ D ] = { h ( x ) : x ∈ D } .

Bukti Teorema Schröder–Bernstein

Misalkan f : A → B dan g : B → A merupakan injeksi. Karena f [ A ] ⊆ B , kita mempunyai g [ f [ A ] ] ⊆ g [ B ] ⊆ A . Selain itu, g ∘ f : A → g [ f [ A ] ] merupakan injeksi karena g dan f keduanya demikian; bahkan, g ∘ f merupakan bijeksi, semata-mata berdasarkan cara kita mendefinisikan kodomainnya. Jadi, g [ f [ A ] ] ≈ A , dan karenanya, berdasarkan Proposisi 6.9, terdapat bijeksi h : A → g [ B ] . Selain itu, g − 1 merupakan bijeksi g [ B ] → B . Jadi, g − 1 ∘ h : A → B merupakan bijeksi.
