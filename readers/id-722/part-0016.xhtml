12 Derivasi Aksiomatik

Belum dilakukan upaya untuk memastikan bahwa materi dalam bab ini mematuhi berbagai tag yang menunjukkan penghubung dan kuantor mana yang primitif atau terdefinisi: semuanya dianggap primitif, kecuali ↔ yang dianggap terdefinisi. Jika tag FOL bernilai benar, kita menghasilkan versi dengan kuantor; jika tidak, versi tanpa kuantor.

12.1 Aturan dan Derivasi

Dalam logika, derivasi aksiomatik barangkali merupakan sistem derivasi yang paling sederhana. Suatu derivasi hanyalah suatu urutan formula. Agar terhitung sebagai derivasi, setiap formula dalam urutan itu harus merupakan instansiasi suatu aksioma, atau harus mengikuti satu atau lebih formula yang mendahuluinya dalam urutan melalui suatu aturan inferensi. Suatu derivasi menurunkan formula terakhirnya.

Definisi 12.1.

Keterderivasian

Jika Γ adalah himpunan formula dari ℒ , maka sebuah derivasi dari  Γ adalah urutan berhingga φ 1 , …,  φ n dari formula sedemikian sehingga, untuk setiap i ≤ n , salah satu hal berikut berlaku:

  1. φ i ∈ Γ ; atau

  2. φ i adalah suatu aksioma; atau

  3. φ i mengikuti dari suatu φ j (dan φ k ) dengan j < i (dan k < i ) melalui suatu aturan inferensi.

Apa yang terhitung sebagai derivasi yang benar bergantung pada aturan inferensi mana yang kita izinkan (dan tentu saja pada apa yang kita anggap sebagai aksioma). Suatu aturan inferensi adalah pernyataan jika-maka yang memberi tahu kita bahwa, dalam kondisi tertentu, sebuah langkah  φ i dalam derivasi merupakan langkah inferensi yang benar.

Definisi 12.2.

Aturan inferensi

Suatu aturan inferensi memberikan syarat cukup bagi apa yang terhitung sebagai langkah inferensi yang benar dalam derivasi dari  Γ .

Sebagai contoh, karena setiap urutan satu unsur φ dengan φ ∈ Γ secara langsung terhitung sebagai derivasi, pernyataan berikut dapat menjadi aturan inferensi yang sangat sederhana:

Jika φ ∈ Γ , maka φ selalu merupakan langkah inferensi yang benar dalam setiap derivasi dari  Γ .

Demikian pula, jika φ merupakan salah satu aksioma, maka φ sendiri adalah derivasi, sehingga pernyataan berikut juga merupakan aturan inferensi:

Jika φ merupakan suatu aksioma, maka φ merupakan langkah inferensi yang benar.

Keadaannya menjadi lebih menarik jika aturan inferensi mengacu pada formula yang muncul sebelum langkah yang sedang diperiksa. Aturan berikut disebut modus ponens:

Jika ψ → φ dan ψ muncul lebih dahulu dalam derivasi, maka  φ merupakan langkah inferensi yang benar.

Jika ini merupakan satu-satunya aturan inferensi, maka definisi derivasi kita di atas berarti sebagai berikut: φ 1 , …,  φ n adalah derivasi jika dan hanya jika, untuk setiap i ≤ n , salah satu hal berikut berlaku:

  1. φ i ∈ Γ ; atau

  2. φ i adalah suatu aksioma; atau

  3. untuk suatu j < i , φ j adalah ψ → φ i , dan untuk suatu k < i , φ k adalah  ψ .

Klausa terakhir mengatakan bahwa φ i mengikuti dari  φ j ( ψ → φ i ) dan φ k ( ψ ) melalui modus ponens. Jika kita dapat bergerak dari 1 hingga  n , dan setiap kali menemukan formula  φ i yang berada dalam  Γ , merupakan suatu aksioma, atau dinyatakan sebagai langkah inferensi yang benar oleh suatu aturan inferensi, maka seluruh urutan tersebut terhitung sebagai derivasi yang benar.

Definisi 12.3.

Keterderivasian

Suatu formula  φ dapat diturunkan dari Γ , ditulis Γ ⊢ φ , jika terdapat derivasi dari Γ yang berakhir dengan  φ .

Definisi 12.4.

Teorema

formula  φ merupakan suatu teorema jika terdapat derivasi atas  φ dari himpunan kosong. Kita menulis ⊢ φ jika φ merupakan teorema dan ⊬ φ jika bukan.

12.2 Aksioma dan Aturan untuk Penghubung Proposisional

Definisi 12.5.

Aksioma

Himpunan yang dilambangkan dengan Ax 0 terdiri atas aksioma-aksioma untuk penghubung proposisional dalam semua bentuk formula berikut: ( φ ∧ ψ ) → φ ( φ ∧ ψ ) → ψ φ → ( ψ → ( φ ∧ ψ ) ) φ → ( φ ∨ ψ ) φ → ( ψ ∨ φ ) ( φ → χ ) → ( ( ψ → χ ) → ( ( φ ∨ ψ ) → χ ) ) φ → ( ψ → φ ) ( φ → ( ψ → χ ) ) → ( ( φ → ψ ) → ( φ → χ ) ) ( φ → ψ ) → ( ( φ → ¬ ψ ) → ¬ φ ) ¬ φ → ( φ → ψ ) ⊤ ⊥ → φ ( φ → ⊥ ) → ¬ φ ¬ ¬ φ → φ

Definisi 12.6.

Modus ponens

Jika ψ dan ψ → φ sudah muncul dalam derivasi, maka φ merupakan langkah inferensi yang benar.

Kita menyingkat aturan modus ponens sebagai “ mp .”

12.3 Contoh Derivasi

Contoh 12.7.

Misalkan kita ingin membuktikan ( ¬ θ ∨ α ) → ( θ → α ) . Jelas bahwa ini bukan instansiasi dari aksioma mana pun, sehingga kita harus menggunakan aturan mp untuk menurunkannya. Aturan yang kita perlukan di sini adalah MP, yang, jika diberikan φ dan φ → ψ , memungkinkan kita membenarkan  ψ . Salah satu strategi ialah menggunakan Pers. 12.6 dengan φ sebagai ¬ θ , ψ sebagai α , dan χ sebagai θ → α , yakni instansiasi ( ¬ θ → ( θ → α ) ) → ( ( α → ( θ → α ) ) → ( ( ¬ θ ∨ α ) → ( θ → α ) ) ) . Mengapa? Dua penerapan MP menghasilkan bagian terakhir, dan bagian itulah yang kita inginkan. Kita juga mudah melihat bahwa ¬ θ → ( θ → α ) merupakan instansiasi dari Pers. 12.10, dan α → ( θ → α ) merupakan instansiasi dari Pers. 12.7. Jadi, derivasi kita adalah:

1. ¬ θ → ( θ → α ) Pers. 12.10
2. ( ¬ θ → ( θ → α ) ) →
( ( α → ( θ → α ) ) → ( ( ¬ θ ∨ α ) → ( θ → α ) ) ) Pers. 12.6
3. ( α → ( θ → α ) ) → ( ( ¬ θ ∨ α ) → ( θ → α ) ) 1, 2, mp
4. α → ( θ → α ) Pers. 12.7
5. ( ¬ θ ∨ α ) → ( θ → α ) 3, 4, mp

Contoh 12.8.

Mari kita coba mencari derivasi atas θ → θ . Formula ini bukan instansiasi suatu aksioma, sehingga kita harus menggunakan mp untuk menurunkannya. Pers. 12.7 adalah aksioma berbentuk φ → ψ yang dapat kita kenai  mp . Agar berguna, tentu saja ψ yang dibenarkan sebagai langkah benar oleh mp dalam kasus ini haruslah θ → θ , sebab itulah yang ingin kita menurunkan. Ini berarti φ juga harus berupa θ ; dengan kata lain, kita dapat memeriksa instansiasi Pers. 12.7 berikut: θ → ( θ → θ ) Untuk menerapkan mp , kita juga harus membenarkan premis kedua yang bersesuaian, yakni  φ . Namun, dalam kasus kita premis itu adalah  θ , dan kita tidak akan dapat menurunkan  θ dengan sendirinya. Jadi, kita memerlukan strategi lain.

Aksioma lain yang hanya melibatkan  → adalah Pers. 12.8, yakni ( φ → ( ψ → χ ) ) → ( ( φ → ψ ) → ( φ → χ ) ) Kita dapat mencapai implikasi bersarang terakhir dengan menerapkan mp dua kali. Sekali lagi, ini berarti kita menginginkan instansiasi Pers. 12.8 dengan φ → χ berupa θ → θ , yaitu formula yang kita tuju. Dengan demikian, φ dan χ tentu keduanya adalah  θ . Bagaimana sebaiknya kita memilih  ψ agar baik φ → ( ψ → χ ) maupun φ → ψ , yakni dalam kasus kita θ → ( ψ → θ ) dan θ → ψ , juga dapat diturunkan? Formula pertama sudah merupakan instansiasi dari Pers. 12.7, apa pun pilihan kita untuk  ψ . Sementara itu, θ → ψ akan menjadi instansiasi lain dari Pers. 12.7 jika ψ berupa ( θ → θ ) . Jadi, derivasi kita adalah:

1. θ → ( ( θ → θ ) → θ ) Pers. 12.7
2. ( θ → ( ( θ → θ ) → θ ) ) →
( ( θ → ( θ → θ ) ) → ( θ → θ ) ) Pers. 12.8
3. ( θ → ( θ → θ ) ) → ( θ → θ ) 1, 2, mp
4. θ → ( θ → θ ) Pers. 12.7
5. θ → θ 3, 4, mp

Contoh 12.9.

Kadang-kadang kita ingin menunjukkan bahwa terdapat derivasi atas suatu formula dari sejumlah formula lain  Γ . Sebagai contoh, mari kita tunjukkan bahwa kita dapat menurunkan φ → χ dari Γ = { φ → ψ , ψ → χ } .

1. φ → ψ Hip
2. ψ → χ Hip
3. ( ψ → χ ) → ( φ → ( ψ → χ ) ) Pers. 12.7
4. φ → ( ψ → χ ) 2, 3, mp
5. ( φ → ( ψ → χ ) ) →
( ( φ → ψ ) → ( φ → χ ) ) Pers. 12.8
6. ( ( φ → ψ ) → ( φ → χ ) ) 4, 5, mp
7. φ → χ 1, 6, mp

Baris-baris yang berlabel “ Hip ” (untuk “hipotesis”) menunjukkan bahwa formula pada baris tersebut merupakan anggota dari  Γ .

Proposisi 12.10.

Jika Γ ⊢ φ → ψ dan Γ ⊢ ψ → χ , maka Γ ⊢ φ → χ .

Bukti.

Misalkan Γ ⊢ φ → ψ dan Γ ⊢ ψ → χ . Maka terdapat derivasi atas φ → ψ dari  Γ , serta derivasi atas  ψ → χ dari  Γ . Gabungkan keduanya menjadi satu derivasi dengan mengonkatenasikannya. Sekarang tambahkan baris 3–7 dari derivasi dalam contoh sebelumnya. Hasilnya merupakan derivasi atas φ → χ — yaitu baris terakhir derivasi baru tersebut—dari  Γ . Perhatikan bahwa pembenaran baris 4 dan 7 tetap berlaku jika acuan kepada nomor baris 1 diganti dengan acuan kepada baris terakhir derivasi atas  φ → ψ , dan acuan kepada nomor baris 2 diganti dengan acuan kepada baris terakhir derivasi atas  ψ → χ .

12.4 Gagasan Teori-Bukti

Sebagaimana kita telah mendefinisikan sejumlah gagasan semantik penting (tautologi, perikutan, keterpenuhan), kini kita mendefinisikan gagasan teori-bukti yang bersesuaian. Gagasan-gagasan ini tidak didefinisikan dengan mengacu pada terpenuhinya kalimat di dalam valuasi, melainkan dengan mengacu pada keterderivasian atau ketakterderivasian formula-formula tertentu. Penemuan bahwa gagasan-gagasan tersebut berimpit merupakan penemuan penting. Keberimpitan itu adalah isi teorema kesahihan dan teorema kelengkapan.

Definisi 12.11.

Keterderivasian

formula  φ dapat diturunkan dari Γ , ditulis Γ ⊢ φ , jika terdapat derivasi dari  Γ yang berakhir dengan  φ .

Definisi 12.12.

Teorema

formula  φ merupakan suatu teorema jika terdapat derivasi atas φ dari himpunan kosong. Kita menulis ⊢ φ jika φ merupakan teorema dan ⊬ φ jika bukan.

Definisi 12.13.

Konsistensi

Suatu himpunan formula  Γ konsisten jika dan hanya jika Γ ⊬ ⊥ ; jika tidak, himpunan itu tak konsisten.

Proposisi 12.14.

Refleksivitas

Jika φ ∈ Γ , maka Γ ⊢ φ .

Bukti.

Secara langsung, formula  φ sendiri merupakan derivasi atas  φ dari  Γ .

Proposisi 12.15.

Monotonisitas

Jika Γ ⊆ Δ dan Γ ⊢ φ , maka Δ ⊢ φ .

Bukti.

Setiap derivasi atas φ dari Γ juga merupakan derivasi atas φ dari  Δ .

Proposisi 12.16.

Transitivitas

Jika Γ ⊢ φ dan { φ } ∪ Δ ⊢ ψ , maka Γ ∪ Δ ⊢ ψ .

Bukti.

Misalkan { φ } ∪ Δ ⊢ ψ . Maka terdapat derivasi ψ 1 , …, ψ l = ψ dari  { φ } ∪ Δ . Beberapa langkah dalam derivasi tersebut akan benar karena suatu aturan yang mengacu pada baris sebelumnya  ψ i = φ . Menurut hipotesis, terdapat derivasi atas  φ dari  Γ , yakni derivasi  φ 1 , …, φ k = φ dengan setiap φ i merupakan suatu aksioma, anggota dari  Γ , atau benar menurut suatu aturan inferensi. Sekarang perhatikan urutan φ 1 , … , φ k = φ , ψ 1 , … , ψ l = ψ . Urutan ini merupakan derivasi yang benar atas  ψ dari Γ ∪ Δ , sebab setiap ψ i = φ sekarang dibenarkan oleh pembenaran yang sama dengan yang membenarkan  φ k = φ .

Perhatikan bahwa, khususnya, ini berarti bahwa jika Γ ⊢ φ dan φ ⊢ ψ , maka Γ ⊢ ψ . Diperoleh pula bahwa jika φ 1 , … , φ n ⊢ ψ dan Γ ⊢ φ i untuk setiap  i , maka Γ ⊢ ψ .

Proposisi 12.17.

Γ tak konsisten jika dan hanya jika Γ ⊢ φ untuk setiap  φ .

Bukti.

Latihan.

Proposisi 12.18.

Kekompakan

  1. Jika Γ ⊢ φ , maka terdapat himpunan bagian berhingga Γ 0 ⊆ Γ sedemikian sehingga Γ 0 ⊢ φ .

  2. Jika setiap himpunan bagian berhingga dari  Γ konsisten, maka Γ konsisten.

Bukti.

  1. Jika Γ ⊢ φ , maka terdapat urutan berhingga formula φ 1 , …,  φ n sedemikian sehingga φ ≡ φ n dan setiap φ i merupakan suatu aksioma logis, anggota dari  Γ , atau mengikuti formula sebelumnya melalui suatu aturan inferensi. Ambil Γ 0 sebagai himpunan semua φ i yang berada dalam  Γ . Maka derivasi tersebut juga merupakan derivasi dari  Γ 0 , sehingga Γ 0 ⊢ φ .

  2. Ini adalah kontraposisi dari (1) untuk kasus khusus φ ≡ ⊥ .

12.5 Teorema Deduksi

Seperti telah kita lihat, memberikan derivasi dalam sistem aksiomatik itu merepotkan, dan derivasi semacam itu mungkin sulit ditemukan. Daripada benar-benar menuliskan daftar panjang formula, umumnya lebih mudah berargumen bahwa derivasi tersebut ada dengan memanfaatkan beberapa hasil sederhana. Kita telah membuktikan tiga hasil semacam itu: Proposisi 12.14 menyatakan bahwa kita selalu dapat menegaskan Γ ⊢ φ apabila diketahui bahwa φ ∈ Γ . Proposisi 12.15 menyatakan bahwa jika Γ ⊢ φ , maka Γ ∪ { ψ } ⊢ φ juga. Selanjutnya, Proposisi 12.16 menyiratkan bahwa jika Γ ⊢ φ dan φ ⊢ ψ , maka Γ ⊢ ψ . Berikut satu hasil sederhana lainnya, yaitu versi “meta” dari modus ponens:

Proposisi 12.19.

Jika Γ ⊢ φ dan Γ ⊢ φ → ψ , maka Γ ⊢ ψ .

Bukti.

Kita mempunyai { φ , φ → ψ } ⊢ ψ :

1. φ Hip.
2. φ → ψ Hip.
3. ψ 1, 2, MP

Menurut Proposisi 12.16, Γ ⊢ ψ .

Hasil terpenting yang akan kita gunakan dalam konteks ini adalah teorema deduksi:

Teorema 12.20.

Teorema Deduksi

Γ ∪ { φ } ⊢ ψ jika dan hanya jika Γ ⊢ φ → ψ .

Bukti.

Arah “jika” langsung diperoleh. Jika Γ ⊢ φ → ψ , maka menurut Proposisi 12.15, Γ ∪ { φ } ⊢ φ → ψ juga. Selain itu, menurut Proposisi 12.14, Γ ∪ { φ } ⊢ φ . Jadi, menurut Proposisi 12.19, Γ ∪ { φ } ⊢ ψ .

Untuk arah “hanya jika”, kita melakukan induksi pada panjang derivasi dari ψ berdasarkan Γ ∪ { φ } .

Sebagai basis induksi, kita membuktikan klaim tersebut untuk setiap derivasi yang panjangnya  1 . Suatu derivasi dari  ψ berdasarkan Γ ∪ { φ } yang panjangnya  1 hanya terdiri atas ψ ; dan jika derivasi itu benar, maka ψ merupakan anggota Γ ∪ { φ } atau sebuah aksioma. Jika ψ ∈ Γ atau merupakan aksioma, maka Γ ⊢ ψ . Kita juga mempunyai Γ ⊢ ψ → ( φ → ψ ) menurut Pers. 12.7, dan Proposisi 12.19 memberikan Γ ⊢ φ → ψ . Jika ψ ∈ { φ } , maka Γ ⊢ φ → ψ karena formula terakhir  φ → ψ sama dengan φ → φ , dan kita telah menurunkan formula itu dalam Contoh 12.8.

Untuk langkah induksi, andaikan derivasi dari  ψ berdasarkan Γ ∪ { φ } berakhir dengan suatu langkah  ψ yang dijustifikasi oleh modus ponens. Jika langkah itu tidak dijustifikasi oleh modus ponens, maka ψ ∈ Γ , ψ ≡ φ , atau ψ merupakan aksioma, dan penalaran yang sama seperti pada basis induksi berlaku.

Dengan demikian, sejumlah langkah sebelumnya dalam derivasi tersebut adalah χ → ψ dan χ , untuk suatu formula  χ ; yakni, Γ ∪ { φ } ⊢ χ → ψ dan Γ ∪ { φ } ⊢ χ . Derivasi masing-masing lebih pendek, sehingga hipotesis induksi berlaku untuk keduanya. Jadi, kita mempunyai kedua hal berikut: Γ ⊢ φ → ( χ → ψ ) ; Γ ⊢ φ → χ . Namun, menurut Pers. 12.8, kita juga mempunyai Γ ⊢ ( φ → ( χ → ψ ) ) → ( ( φ → χ ) → ( φ → ψ ) ) , dan dua penerapan Proposisi 12.19 memberikan Γ ⊢ φ → ψ , sebagaimana diperlukan.

Perhatikan bagaimana Pers. 12.7 dan Pers. 12.8 dipilih tepat agar Teorema Deduksi berlaku.

Berikut beberapa fakta berguna tentang keterderivasian yang kita tinggalkan sebagai latihan.

Proposisi 12.21.

  1. ⊢ ( φ → ψ ) → ( ( ψ → χ ) → ( φ → χ ) ) ;

  2. Jika Γ ∪ { ¬ φ } ⊢ ¬ ψ , maka Γ ∪ { ψ } ⊢ φ (Kontraposisi);

  3. { φ , ¬ φ } ⊢ ψ (Ex Falso Quodlibet, Eksplosi);

  4. { ¬ ¬ φ } ⊢ φ (Eliminasi Negasi Ganda);

  5. Jika Γ ⊢ ¬ ¬ φ , maka Γ ⊢ φ ;

12.6 Keterderivasian dan Konsistensi

Sekarang kita akan membuktikan sejumlah sifat relasi keterderivasian. Sifat-sifat tersebut menarik secara mandiri, tetapi masing-masing akan berperan dalam pembuktian teorema kelengkapan.

Proposisi 12.22.

Jika Γ ⊢ φ dan Γ ∪ { φ } tak konsisten, maka Γ tak konsisten.

Bukti.

Jika Γ ∪ { φ } tak konsisten, maka Γ ∪ { φ } ⊢ ⊥ . Menurut Proposisi 12.14, Γ ⊢ ψ untuk setiap ψ ∈ Γ . Karena menurut hipotesis kita juga mempunyai Γ ⊢ φ , maka Γ ⊢ ψ untuk setiap ψ ∈ Γ ∪ { φ } . Menurut Proposisi 12.16, Γ ⊢ ⊥ ; yakni, Γ tak konsisten.

Proposisi 12.23.

Γ ⊢ φ jika dan hanya jika Γ ∪ { ¬ φ } tak konsisten.

Bukti.

Pertama, andaikan Γ ⊢ φ . Maka menurut Proposisi 12.15, Γ ∪ { ¬ φ } ⊢ φ . Menurut Proposisi 12.14, Γ ∪ { ¬ φ } ⊢ ¬ φ . Kita juga mempunyai ⊢ ¬ φ → ( φ → ⊥ ) menurut Pers. 12.10. Jadi, melalui dua penerapan Proposisi 12.19, kita memperoleh Γ ∪ { ¬ φ } ⊢ ⊥ .

Sekarang andaikan Γ ∪ { ¬ φ } tak konsisten; yakni, Γ ∪ { ¬ φ } ⊢ ⊥ . Menurut teorema deduksi, Γ ⊢ ¬ φ → ⊥ . Menurut Pers. 12.13, Γ ⊢ ( ¬ φ → ⊥ ) → ¬ ¬ φ , sehingga Proposisi 12.19 memberikan Γ ⊢ ¬ ¬ φ . Karena Γ ⊢ ¬ ¬ φ → φ (Pers. 12.14), penerapan Proposisi 12.19 sekali lagi memberikan Γ ⊢ φ .

Proposisi 12.24.

Jika Γ ⊢ φ dan ¬ φ ∈ Γ , maka Γ tak konsisten.

Bukti.

Menurut Pers. 12.10, Γ ⊢ ¬ φ → ( φ → ⊥ ) . Dua penerapan Proposisi 12.19 memberikan Γ ⊢ ⊥ .

Proposisi 12.25.

Jika Γ ∪ { φ } dan Γ ∪ { ¬ φ } keduanya tak konsisten, maka Γ tak konsisten.

Bukti.

Latihan.

12.7 Keterderivasian dan Penghubung Proposisional

Kita membuktikan bahwa relasi keterderivasian  ⊢ dari deduksi aksiomatik cukup kuat untuk membuktikan beberapa fakta dasar yang melibatkan penghubung proposisional, seperti φ ∧ ψ ⊢ φ dan φ , φ → ψ ⊢ ψ (modus ponens). Fakta-fakta ini diperlukan dalam pembuktian teorema kelengkapan.

Proposisi 12.26.

  1. Baik φ ∧ ψ ⊢ φ maupun φ ∧ ψ ⊢ ψ .

  2. φ , ψ ⊢ φ ∧ ψ .

Bukti.

  1. Diperoleh dari Pers. 12.1 dan Pers. 12.2 melalui modus ponens.

  2. Diperoleh dari Pers. 12.3 melalui dua penerapan modus ponens.

Proposisi 12.27.

  1. φ ∨ ψ , ¬ φ , ¬ ψ tak konsisten.

  2. Baik φ ⊢ φ ∨ ψ maupun ψ ⊢ φ ∨ ψ .

Bukti.

  1. Dari Pers. 12.10, kita memperoleh ⊢ ¬ φ → ( φ → ⊥ ) dan ⊢ ¬ ψ → ( ψ → ⊥ ) . Jadi, menurut teorema deduksi, kita mempunyai { ¬ φ } ⊢ φ → ⊥ dan { ¬ ψ } ⊢ ψ → ⊥ . Dari Pers. 12.6, kita memperoleh { ¬ φ , ¬ ψ } ⊢ ( φ ∨ ψ ) → ⊥ . Menurut teorema deduksi, { φ ∨ ψ , ¬ φ , ¬ ψ } ⊢ ⊥ .

  2. Diperoleh dari Pers. 12.4 dan Pers. 12.5 melalui modus ponens.

Proposisi 12.28.

  1. φ , φ → ψ ⊢ ψ .

  2. Baik ¬ φ ⊢ φ → ψ maupun ψ ⊢ φ → ψ .

Bukti.

  1. Kita dapat menurunkan:

    1. φ Hip
    2. φ → ψ Hip
    3. ψ 1, 2, mp

  2. Masing-masing diperoleh dari Pers. 12.10 dan Pers. 12.7 menurut teorema deduksi.

12.8 Kesahihan

Sebuah sistem derivasi, seperti deduksi aksiomatik, disebut sahih jika sistem tersebut tidak dapat menurunkan kesimpulan yang sebenarnya tidak mengikuti premis-premisnya. Dengan demikian, kesahihan merupakan sejenis sifat keselamatan yang dijamin bagi sistem derivasi. Bergantung pada sifat teori-bukti yang sedang dibahas, kita ingin mengetahui, misalnya, bahwa

  1. setiap  φ yang dapat diturunkan bersifat valid;

  2. jika φ dapat diturunkan dari beberapa formula lain  Γ , formula itu juga merupakan konsekuensi dari formula-formula tersebut;

  3. jika suatu himpunan formula  Γ tak konsisten, himpunan itu tak dapat dipenuhi.

Ini adalah sifat-sifat penting dari suatu sistem derivasi. Jika salah satunya tidak berlaku, sistem derivasi tersebut cacat—sistem itu akan menurunkan terlalu banyak. Oleh karena itu, membuktikan kesahihan suatu sistem derivasi sangatlah penting.

Proposisi 12.29.

Jika φ merupakan aksioma, maka 𝔳 ⊨ φ untuk setiap valuasi  𝔳 .

Bukti.

Buatlah tabel kebenaran bagi setiap aksioma untuk memverifikasi bahwa semuanya merupakan tautologi.

Teorema 12.30.

Kesahihan

Jika Γ ⊢ φ , maka Γ ⊨ φ .

Bukti.

Kita melakukan induksi pada jumlah langkah dalam derivasi dari φ berdasarkan Γ yang dijustifikasi oleh aturan inferensi. Jika tidak ada langkah yang dijustifikasi oleh inferensi, maka semua formula dalam derivasi tersebut merupakan instans aksioma atau anggota  Γ . Menurut proposisi sebelumnya, semua aksioma merupakan tautologi; jadi, jika φ merupakan aksioma, maka Γ ⊨ φ . Jika φ ∈ Γ , maka secara trivial Γ ⊨ φ .

Jika langkah terakhir derivasi dari  φ dijustifikasi oleh modus ponens, maka derivasi tersebut memuat formula ψ dan ψ → φ , dan hipotesis induksi berlaku pada bagian derivasi yang berakhir dengan masing-masing formula tersebut (karena bagian-bagian itu memuat setidaknya satu langkah yang dijustifikasi oleh inferensi lebih sedikit). Jadi, menurut hipotesis induksi, Γ ⊨ ψ dan Γ ⊨ ψ → φ . Selanjutnya, Γ ⊨ φ menurut Teorema 7.21.

Akibat 12.31.

Jika ⊢ φ , maka φ merupakan tautologi.

Akibat 12.32.

Jika Γ dapat dipenuhi, maka himpunan tersebut konsisten.

Bukti.

Kita membuktikan kontraposisinya. Andaikan Γ tidak konsisten. Maka Γ ⊢ ⊥ ; yakni, terdapat derivasi dari ⊥ berdasarkan  Γ . Menurut Teorema 12.30, setiap valuasi  𝔳 yang memenuhi Γ harus memenuhi  ⊥ . Karena 𝔳 ⊭ ⊥ untuk setiap valuasi  𝔳 , tidak ada 𝔳 yang dapat memenuhi Γ ; yakni, Γ tidak dapat dipenuhi.

Soal

Soal 12.1.

Tunjukkan bahwa pernyataan-pernyataan berikut berlaku dengan menyajikan derivasi dari aksioma-aksioma:

  1. ( φ ∧ ψ ) → ( ψ ∧ φ )

  2. ( ( φ ∧ ψ ) → χ ) → ( φ → ( ψ → χ ) )

  3. ¬ ( φ ∨ ψ ) → ¬ φ

Soal 12.2.

Buktikan Proposisi 12.17.

Soal 12.3.

Buktikan Proposisi 12.21.

Soal 12.4.

Buktikan bahwa Γ ⊢ ¬ φ jika dan hanya jika Γ ∪ { φ } tak konsisten.
