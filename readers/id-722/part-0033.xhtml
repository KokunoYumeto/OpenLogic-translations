27 Teorema Interpolasi

27.1 Pendahuluan

Teorema interpolasi adalah hasil berikut: Andaikan ⊨ φ → ψ . Maka terdapat kalimat χ sedemikian sehingga ⊨ φ → χ dan ⊨ χ → ψ . Selain itu, setiap simbol konstanta, simbol fungsi, dan simbol predikat (selain = ) dalam χ terdapat dalam φ maupun  ψ . Kalimat χ disebut interpolan dari φ dan  ψ .

Teorema interpolasi menarik dalam dirinya sendiri, tetapi kepentingan utamanya terletak pada kenyataan bahwa teorema ini dapat digunakan untuk membuktikan hasil-hasil tentang keterdefinisian dalam suatu teori dan tentang syarat-syarat yang membuat penggabungan dua teori konsisten menghasilkan teori yang konsisten. Hasil pertama dikenal sebagai teorema keterdefinisian Beth; hasil kedua sebagai teorema konsistensi gabungan Robinson.

27.2 Pemisahan Kalimat

Kita memerlukan sedikit persiapan sebelum melanjutkan ke bukti teorema interpolasi. Interpolan bagi φ dan ψ adalah kalimat  χ sedemikian sehingga φ ⊨ χ dan χ ⊨ ψ . Dengan kontraposisi, yang terakhir berlaku jika dan hanya jika ¬ ψ ⊨ ¬ χ . kalimat  χ dengan sifat ini dikatakan memisahkan φ dan ¬ ψ . Jadi, mencari interpolan bagi φ dan ψ sama dengan mencari kalimat yang memisahkan φ dan ¬ ψ . Seperti sering terjadi, akan berguna untuk meninjau suatu generalisasi: kalimat yang memisahkan dua himpunan kalimat.

Definisi 27.1.

Suatu kalimat χ memisahkan himpunan kalimat Γ dan Δ jika dan hanya jika Γ ⊨ χ dan Δ ⊨ ¬ χ . Jika tidak ada kalimat semacam itu, maka Γ dan Δ tidak terpisahkan.

Relasi inklusi antara kelas-kelas model dari Γ , Δ , dan χ digambarkan di bawah ini:

Lema 27.2.

Andaikan ℒ 0 adalah bahasa yang memuat setiap simbol konstanta, simbol fungsi, dan simbol predikat (selain ≐ ) yang terdapat dalam keduanya, Γ dan Δ , dan misalkan ℒ 0 ′ diperoleh dengan menambahkan tak hingga banyak simbol konstanta baru 𝘤 n untuk n ≥ 0 . Jika Γ dan Δ tidak terpisahkan dalam ℒ 0 , maka keduanya juga tidak terpisahkan dalam ℒ 0 ′ .

Bukti.

Kita menggunakan pembuktian tak langsung: andaikan, demi memperoleh kontradiksi, bahwa Γ dan Δ terpisahkan dalam ℒ 0 ′ . Maka Γ ⊨ χ [ c / x ] dan Δ ⊨ ¬ χ [ c / x ] bagi suatu χ ∈ ℒ 0 (dengan c suatu simbol konstanta baru—kasus ketika χ memuat lebih dari satu simbol konstanta baru semacam itu serupa). Menurut kekompakan, terdapat himpunan bagian hingga Γ 0 dari Γ dan Δ 0 dari Δ sedemikian sehingga Γ 0 ⊨ χ [ c / x ] dan Δ 0 ⊨ ¬ χ [ c / x ] . Misalkan γ konjungsi semua formula dalam Γ 0 dan δ konjungsi semua formula dalam Δ 0 . Maka γ ⊨ χ [ c / x ] , δ ⊨ ¬ χ [ c / x ] . Dari yang pertama, melalui Generalisasi, kita memperoleh γ ⊨ ∀ x χ ; dari yang kedua, melalui kontraposisi, χ [ c / x ] ⊨ ¬ δ , sehingga juga ∀ x χ ⊨ ¬ δ . Kontraposisi sekali lagi memberikan δ ⊨ ¬ ∀ x χ . Menurut monotonisitas, Γ ⊨ ∀ x χ , Δ ⊨ ¬ ∀ x χ , sehingga ∀ x χ memisahkan Γ dan Δ dalam ℒ 0 .

Lema 27.3.

Andaikan Γ ∪ { ∃ x σ } dan Δ tidak terpisahkan, dan c adalah simbol konstanta baru yang tidak terdapat dalam Γ , Δ , ataupun σ . Maka Γ ∪ { ∃ x σ , σ [ c / x ] } dan Δ juga tidak terpisahkan.

Bukti.

Andaikan, demi memperoleh kontradiksi, bahwa χ memisahkan Γ ∪ { ∃ x σ , σ [ c / x ] } dan Δ , sementara Γ ∪ { ∃ x σ } dan Δ tidak terpisahkan. Kita membedakan dua kasus:

  1. c tidak terdapat dalam χ : dalam hal ini Γ ∪ { ∃ x σ , ¬ χ } dapat dipenuhi (jika tidak, χ memisahkan Γ ∪ { ∃ x σ } dan Δ ). Himpunan itu tetap dapat dipenuhi setelah σ [ c / x ] ditambahkan, sehingga pada akhirnya χ tidak memisahkan Γ ∪ { ∃ x σ , σ [ c / x ] } dan Δ .

  2. c terdapat dalam χ , sehingga χ berbentuk χ [ c / x ] . Maka kita mempunyai Γ ∪ { ∃ x σ , σ [ c / x ] } ⊨ χ [ c / x ] , sehingga Γ , ∃ x σ ⊨ ∀ x ( σ → χ ) menurut Teorema Deduksi dan Generalisasi, dan akhirnya Γ ∪ { ∃ x σ } ⊨ ∃ x χ . Di sisi lain, Δ ⊨ ¬ χ [ c / x ] dan karenanya, menurut Generalisasi, Δ ⊨ ¬ ∃ x χ . Jadi Γ ∪ { ∃ x σ } dan Δ terpisahkan, suatu kontradiksi.

27.3 Teorema Interpolasi Craig

Teorema 27.4.

Teorema Interpolasi Craig

Jika ⊨ φ → ψ , maka terdapat kalimat χ sedemikian sehingga ⊨ φ → χ dan ⊨ χ → ψ , dan setiap simbol konstanta, simbol fungsi, serta simbol predikat (selain = ) dalam χ terdapat dalam φ maupun  ψ . Kalimat χ disebut interpolan dari φ dan  ψ .

Bukti.

Andaikan ℒ 1 adalah bahasa dari φ dan ℒ 2 adalah bahasa dari ψ . Misalkan ℒ 0 = ℒ 1 ∩ ℒ 2 . Bagi setiap i ∈ { 0 , 1 , 2 } , misalkan ℒ i ′ diperoleh dari ℒ i dengan menambahkan tak hingga banyak simbol konstanta baru 𝘤 0 , 𝘤 1 , 𝘤 2 , … .

Jika φ tidak dapat dipenuhi, maka ∃ x x ≠ x adalah suatu interpolan. Jika ¬ ψ tidak dapat dipenuhi (sehingga ψ valid), maka ∃ x x = x adalah suatu interpolan. Karena itu, kita juga dapat mengandaikan bahwa φ dan ¬ ψ keduanya dapat dipenuhi.

Untuk membuktikan kontraposisi Teorema Interpolasi, andaikan tidak ada interpolan bagi φ dan ψ . Dengan kata lain, andaikan { φ } dan { ¬ ψ } tidak terpisahkan dalam ℒ 0 .

Tujuan kita ialah memperluas pasangan ( { φ } , { ¬ ψ } ) menjadi pasangan yang tidak terpisahkan secara maksimal ( Γ ∗ , Δ ∗ ) . Misalkan φ 0 , φ 1 , φ 2 , …mencacah kalimat dari ℒ 1 ′ , dan ψ 0 , ψ 1 , ψ 2 , …mencacah kalimat dari  ℒ 2 ′ . Kita mendefinisikan dua barisan naik himpunan kalimat ( Γ n , Δ n ) , untuk n ≥ 0 , sebagai berikut. Tetapkan Γ 0 = { φ } dan Δ 0 = { ¬ ψ } . Dengan mengandaikan ( Γ n , Δ n ) telah didefinisikan, definisikan Γ n + 1 dan Δ n + 1 sebagai berikut:

  1. Jika Γ n ∪ { φ n } dan Δ n tidak terpisahkan dalam ℒ 0 ′ , masukkan φ n ke dalam Γ n + 1 ; jika keduanya terpisahkan, tetapkan Γ n + 1 = Γ n . Dalam kasus pertama tersebut, jika φ n adalah formula eksistensial ∃ x σ , pilih suatu simbol konstanta baru c yang tidak terdapat dalam Γ n , Δ n , φ n , ataupun ψ n , lalu masukkan σ [ c / x ] ke dalam Γ n + 1 .

  2. Jika Γ n + 1 dan Δ n ∪ { ψ n } tidak terpisahkan dalam ℒ 0 ′ , masukkan ψ n ke dalam Δ n + 1 ; jika keduanya terpisahkan, tetapkan Δ n + 1 = Δ n . Dalam kasus pertama tersebut, jika ψ n adalah formula eksistensial ∃ x σ , pilih suatu simbol konstanta baru c yang tidak terdapat dalam Γ n + 1 , Δ n , φ n , ataupun ψ n , lalu masukkan σ [ c / x ] ke dalam Δ n + 1 .

Terakhir, definisikan: Γ ∗ = ⋃ n ≥ 0 Γ n , Δ ∗ = ⋃ n ≥ 0 Δ n . Dengan induksi serentak pada n , kini kita dapat membuktikan:

  1. Γ n dan Δ n tidak terpisahkan dalam ℒ 0 ′ ;

  2. Γ n + 1 dan Δ n tidak terpisahkan dalam ℒ 0 ′ .

Dasar bagi enumi 1 diberikan oleh Lema 27.2. Untuk bagian enumi 2, kita perlu membedakan tiga kasus:

  1. Jika Γ 0 ∪ { φ 0 } dan Δ 0 terpisahkan, maka Γ 1 = Γ 0 dan enumi 2 hanyalah enumi 1;

  2. Jika Γ 1 = Γ 0 ∪ { φ 0 } , maka Γ 1 dan Δ 0 tidak terpisahkan berdasarkan konstruksi.

  3. Tersisa kasus ketika φ 0 eksistensial, sehingga Γ 1 = Γ 0 ∪ { ∃ x σ , σ [ c / x ] } . Berdasarkan konstruksi, Γ 0 ∪ { ∃ x σ } dan Δ 0 tidak terpisahkan; maka, menurut Lema 27.3, Γ 0 ∪ { ∃ x σ , σ [ c / x ] } dan Δ 0 juga tidak terpisahkan.

Ini menyelesaikan dasar induksi bagi enumi 1 dan enumi 2 di atas. Sekarang tinjau langkah induksi. Untuk enumi 1, jika Δ n + 1 = Δ n ∪ { ψ n } , maka Γ n + 1 dan Δ n + 1 tidak terpisahkan berdasarkan konstruksi (bahkan ketika ψ n eksistensial, menurut Lema 27.3); jika Δ n + 1 = Δ n (karena Γ n + 1 dan Δ n ∪ { ψ n } terpisahkan), kita menggunakan hipotesis induksi pada enumi 2. Untuk langkah induksi bagi enumi 2, jika Γ n + 2 = Γ n + 1 ∪ { φ n + 1 } , maka Γ n + 2 dan Δ n + 1 tidak terpisahkan berdasarkan konstruksi (bahkan ketika φ n + 1 eksistensial, menurut Lema 27.3); jika Γ n + 2 = Γ n + 1 , kita menggunakan kasus induksi bagi enumi 1 yang baru saja dibuktikan. Ini menyelesaikan induksi pada enumi 1 dan enumi 2.

Akibatnya, Γ ∗ dan Δ ∗ tidak terpisahkan. Jika tidak, menurut kekompakan terdapat suatu kalimat pemisah dan suatu n ≥ 0 sehingga kalimat itu memisahkan Γ n dan Δ n , bertentangan dengan enumi 1. Khususnya, Γ ∗ dan Δ ∗ konsisten: sebab jika yang pertama atau yang kedua tidak konsisten, keduanya masing-masing akan dipisahkan oleh ∃ x x ≠ x atau ∀ x x = x .

Sekarang kita tunjukkan bahwa Γ ∗ konsisten maksimal dalam ℒ 1 ′ , dan demikian pula Δ ∗ dalam ℒ 2 ′ . Untuk yang pertama, andaikan φ n ∉ Γ ∗ dan ¬ φ n ∉ Γ ∗ bagi suatu n ≥ 0 . Jika φ n ∉ Γ ∗ , maka Γ n ∪ { φ n } terpisahkan dari Δ n , sehingga terdapat χ ∈ ℒ 0 ′ sedemikian sehingga keduanya berlaku: Γ ∗ ⊨ φ n → χ , Δ ∗ ⊨ ¬ χ . Demikian pula, jika ¬ φ n ∉ Γ ∗ , terdapat χ ′ ∈ ℒ 0 ′ sedemikian sehingga keduanya berlaku: Γ ∗ ⊨ ¬ φ n → χ ′ , Δ ∗ ⊨ ¬ χ ′ . Menurut logika proposisional, Γ ∗ ⊨ χ ∨ χ ′ dan Δ ∗ ⊨ ¬ ( χ ∨ χ ′ ) , sehingga χ ∨ χ ′ memisahkan Γ ∗ dan Δ ∗ . Argumen serupa menetapkan bahwa Δ ∗ maksimal.

Terakhir, kita tunjukkan bahwa Γ ∗ ∩ Δ ∗ konsisten maksimal dalam ℒ 0 ′ . Himpunan ini jelas konsisten karena merupakan irisan himpunan-himpunan konsisten. Untuk menunjukkan kemaksimalannya, misalkan σ ∈ ℒ 0 ′ . Sekarang, Γ ∗ maksimal dalam ℒ 1 ′ ⊇ ℒ 0 ′ , dan demikian pula Δ ∗ maksimal dalam ℒ 2 ′ ⊇ ℒ 0 ′ . Akibatnya, σ ∈ Γ ∗ atau ¬ σ ∈ Γ ∗ , dan σ ∈ Δ ∗ atau ¬ σ ∈ Δ ∗ . Jika σ ∈ Γ ∗ dan ¬ σ ∈ Δ ∗ , maka σ akan memisahkan Γ ∗ dan Δ ∗ ; dan jika ¬ σ ∈ Γ ∗ dan σ ∈ Δ ∗ , maka Γ ∗ dan Δ ∗ akan dipisahkan oleh ¬ σ . Karena itu, σ ∈ Γ ∗ ∩ Δ ∗ atau ¬ σ ∈ Γ ∗ ∩ Δ ∗ , dan Γ ∗ ∩ Δ ∗ maksimal.

Karena Γ ∗ konsisten maksimal, himpunan ini mempunyai model 𝔐 1 ′ yang domainnya, | 𝔐 1 ′ | , terdiri atas tepat semua unsur c 𝔐 1 ′ yang menafsirkan simbol konstanta—seperti dalam bukti teorema kelengkapan (Teorema 23.20). Demikian pula, Δ ∗ mempunyai model 𝔐 2 ′ yang domainnya, | 𝔐 2 ′ | , diberikan oleh interpretasi c 𝔐 2 ′ dari simbol konstanta.

Misalkan 𝔐 1 diperoleh dari 𝔐 1 ′ dengan membuang interpretasi bagi simbol konstanta, simbol fungsi, dan simbol predikat dalam ℒ 1 ′ ∖ ℒ 0 ′ , dan lakukan hal serupa untuk 𝔐 2 . Maka pemetaan h : M 1 → M 2 yang didefinisikan oleh h ( c 𝔐 1 ′ ) = c 𝔐 2 ′ merupakan isomorfisme dalam ℒ 0 ′ , karena Γ ∗ ∩ Δ ∗ konsisten maksimal dalam ℒ 0 ′ , sebagaimana telah ditunjukkan. Hal ini mengikuti karena setiap ℒ 0 ′ -kalimat termasuk dalam Γ ∗ dan Δ ∗ sekaligus, atau tidak termasuk dalam keduanya: sehingga c 𝔐 1 ′ ∈ P 𝔐 1 ′ jika dan hanya jika P ( c ) ∈ Γ ∗ jika dan hanya jika P ( c ) ∈ Δ ∗ jika dan hanya jika c 𝔐 2 ′ ∈ P 𝔐 2 ′ . Syarat-syarat isomorfisme lainnya dapat ditetapkan dengan cara serupa.

Sekarang kita definisikan suatu model 𝔐 bagi bahasa ℒ 1 ′ ∪ ℒ 2 ′ sebagai berikut:

  1. Domain | 𝔐 | tidak lain adalah | 𝔐 2 | , yakni himpunan semua unsur c 𝔐 2 ′ ;

  2. Jika simbol predikat  P berada dalam ℒ 2 ′ ∖ ℒ 1 ′ , maka P 𝔐 = P 𝔐 2 ′ ;

  3. Jika suatu predikat P berada dalam ℒ 1 ′ ∖ ℒ 2 ′ , maka P 𝔐 = h ( P 𝔐 1 ′ ) , yakni ⟨ c 1 𝔐 2 ′ , … , c n 𝔐 2 ′ ⟩ ∈ P 𝔐 jika dan hanya jika ⟨ c 1 𝔐 1 ′ , … , c n 𝔐 1 ′ ⟩ ∈ P 𝔐 1 ′ .

  4. Jika simbol predikat P berada dalam ℒ 0 ′ , maka P 𝔐 = P 𝔐 2 ′ = h ( P 𝔐 1 ′ ) .

  5. Simbol fungsi dari ℒ 1 ′ ∪ ℒ 2 ′ , termasuk simbol konstanta, ditangani dengan cara serupa.

Terakhir, dengan induksi pada formula ditunjukkan bahwa 𝔐 bersepakat dengan 𝔐 1 ′ pada semua formula dari ℒ 1 ′ dan dengan 𝔐 2 ′ pada semua formula dari ℒ 2 ′ . Khususnya, 𝔐 ⊨ Γ ∗ ∪ Δ ∗ , sehingga 𝔐 ⊨ φ dan 𝔐 ⊨ ¬ ψ , dan ⊭ φ → ψ . Ini menyelesaikan bukti Teorema Interpolasi Craig.

27.4 Teorema Keterdefinisian

Salah satu penerapan penting teorema interpolasi adalah teorema keterdefinisian Beth. Untuk mendefinisikan relasi n -tempat  R , kita dapat memberikan formula  χ dengan n variabel bebas yang tidak melibatkan  R . Ini merupakan definisi eksplisit atas  R dalam kerangka  χ . Selanjutnya, kita juga dapat mengatakan bahwa suatu teori  Σ ( P ) dalam bahasa yang memuat simbol predikat beraritas- n   P mendefinisikan  P secara eksplisit jika teori tersebut memuat (atau setidaknya mengakibatkan) suatu definisi eksplisit yang diformalkan, yakni Σ ( P ) ⊨ ∀ x 1 … ∀ x n ( P ( x 1 , … , x n ) ↔ χ ( x 1 , … , x n ) ) . Namun, definisi eksplisit hanyalah salah satu cara mendefinisikan—dalam arti menentukan sepenuhnya—suatu relasi. Suatu teori juga dapat bersifat sedemikian rupa sehingga interpretasi  P ditetapkan oleh interpretasi bagian lain dari bahasa dalam setiap model. Teorema keterdefinisian menyatakan bahwa setiap kali suatu teori menetapkan interpretasi  P dengan cara ini—setiap kali teori itu mendefinisikan P secara implisit—teori tersebut juga mendefinisikannya secara eksplisit.

Definisi 27.5.

Andaikan ℒ adalah bahasa yang tidak memuat simbol predikat  P . Suatu himpunan Σ ( P ) dari kalimat dalam ℒ ∪ { P } mendefinisikan P secara eksplisit jika dan hanya jika terdapat formula  χ ( x 1 , … , x n ) dari ℒ sedemikian sehingga Σ ( P ) ⊨ ∀ x 1 … ∀ x n ( P ( x 1 , … , x n ) ↔ χ ( x 1 , … , x n ) ) .

Definisi 27.6.

Andaikan ℒ adalah bahasa yang tidak memuat simbol predikat  P dan  P ′ . Suatu himpunan Σ ( P ) dari kalimat dalam ℒ ∪ { P } mendefinisikan P secara implisit jika dan hanya jika Σ ( P ) ∪ Σ ( P ′ ) ⊨ ∀ x 1 … ∀ x n ( P ( x 1 , … , x n ) ↔ P ′ ( x 1 , … , x n ) ) , dengan Σ ( P ′ ) sebagai hasil penggantian seragam P oleh P ′ dalam Σ ( P ) .

Dengan kata lain, bagi setiap model 𝔐 dan R , R ′ ⊆ | 𝔐 | n , jika ( 𝔐 , R ) ⊨ Σ ( P ) dan ( 𝔐 , R ′ ) ⊨ Σ ( P ′ ) , maka R = R ′ ; di sini ( 𝔐 , R ) adalah struktur  𝔐 ′ bagi ekspansi ℒ menjadi ℒ ∪ { P } sedemikian sehingga P 𝔐 ′ = R , dan demikian pula bagi ( 𝔐 , R ′ ) .

Teorema 27.7.

Teorema Keterdefinisian Beth

Suatu himpunan Σ ( P ) dari ℒ ∪ { P } -kalimat mendefinisikan P secara implisit jika dan hanya jika Σ ( P ) mendefinisikan P secara eksplisit.

Bukti.

Jika Σ ( P ) mendefinisikan P secara eksplisit, maka keduanya berlaku: Σ ( P ) ⊨ ∀ x 1 … ∀ x n ( P ( x 1 , … , x n ) ↔ χ ( x 1 , … , x n ) ) Σ ( P ′ ) ⊨ ∀ x 1 … ∀ x n ( P ′ ( x 1 , … , x n ) ↔ χ ( x 1 , … , x n ) ) dan kesimpulannya mengikuti. Untuk arah sebaliknya, andaikan Σ ( P ) mendefinisikan P secara implisit. Mula-mula, kita menambahkan simbol konstanta c 1 , …,  c n ke ℒ . Maka Σ ( P ) ∪ Σ ( P ′ ) ⊨ P ( c 1 , … , c n ) → P ′ ( c 1 , … , c n ) . Menurut kekompakan, terdapat himpunan hingga Δ 0 ⊆ Σ ( P ) dan Δ 1 ⊆ Σ ( P ′ ) sedemikian sehingga Δ 0 ∪ Δ 1 ⊨ P ( c 1 , … , c n ) → P ′ ( c 1 , … , c n ) . Misalkan θ ( P ) adalah konjungsi semua kalimat φ ( P ) sedemikian sehingga φ ( P ) ∈ Δ 0 atau φ ( P ′ ) ∈ Δ 1 , dan misalkan θ ( P ′ ) adalah konjungsi semua kalimat φ ( P ′ ) sedemikian sehingga φ ( P ) ∈ Δ 0 atau φ ( P ′ ) ∈ Δ 1 . Maka θ ( P ) ∧ θ ( P ′ ) ⊨ P ( c 1 , … , c n ) → P ′ ( c 1 , … , c n ) . Kita dapat menyusun ulang ini sehingga setiap simbol predikat terdapat pada satu sisi ⊨ : θ ( P ) ∧ P ( c 1 , … , c n ) ⊨ θ ( P ′ ) → P ′ ( c 1 , … , c n ) . Menurut Teorema Interpolasi Craig, terdapat kalimat χ ( c 1 , … , c n ) yang tidak memuat P ataupun P ′ sedemikian sehingga: θ ( P ) ∧ P ( c 1 , … , c n ) ⊨ χ ( c 1 , … , c n ) ; χ ( c 1 , … , c n ) ⊨ θ ( P ′ ) → P ′ ( c 1 , … , c n ) . Dari perikutan yang pertama, kita memperoleh θ ( P ) ⊨ P ( c 1 , … , c n ) → χ ( c 1 , … , c n ) . Dari yang kedua, karena ( 𝔐 , R ) ⊨ φ ( P ) dalam bahasa ℒ ∪ { P } jika dan hanya jika ( 𝔐 , R ) ⊨ φ ( P ′ ) dalam bahasa ℒ ∪ { P ′ } yang bersesuaian, kita memperoleh χ ( c 1 , … , c n ) ⊨ θ ( P ) → P ( c 1 , … , c n ) , dan dari sini: θ ( P ) ⊨ χ ( c 1 , … , c n ) → P ( c 1 , … , c n ) . Dengan menggabungkan keduanya, θ ( P ) ⊨ P ( c 1 , … , c n ) ↔ χ ( c 1 , … , c n ) , dan menurut monotonisitas serta generalisasi juga Σ ( P ) ⊨ ∀ x 1 … ∀ x n ( P ( x 1 , … , x n ) ↔ χ ( x 1 , … , x n ) ) .
