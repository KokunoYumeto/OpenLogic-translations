35.1 Pengantar

Teorema-teorema ketaklengkapan berlaku bagi teori-teori yang memungkinkan fakta-fakta dasar tentang fungsi yang dapat dihitung dinyatakan dan dibuktikan. Kita akan menguraikan teori semacam itu yang sangat minimal, bernama “ 𝐐 ” (atau kadang-kadang “ Q Robinson,” menurut Raphael Robinson). Kita akan menjelaskan apa artinya suatu fungsi dapat direpresentasikan dalam 𝐐 , lalu membuktikan hal berikut:

Suatu fungsi dapat direpresentasikan dalam 𝐐 jika dan hanya jika fungsi itu dapat dihitung.

Antara lain, hal ini memberi kita model komputabilitas lain. Namun, kita juga akan menggunakannya untuk menunjukkan bahwa himpunan { φ : 𝐐 ⊢ φ } tidak dapat diputuskan, dengan mereduksi masalah penghentian kepadanya. Pada akhir pembahasan, kita bahkan akan telah membuktikan hal-hal yang jauh lebih kuat daripada ini.

Bahasa 𝐐 ialah bahasa aritmetika; 𝐐 terdiri atas aksioma-aksioma berikut (yang digunakan bersama aksioma dan aturan logika orde pertama lainnya dengan predikat identitas): ∀ x ∀ y ( x ′ = y ′ → x = y ) ( Q 1 ) ∀ x 0 ≠ x ′ ( Q 2 ) ∀ x ( x = 0 ∨ ∃ y x = y ′ ) ( Q 3 ) ∀ x ( x + 0 ) = x ( Q 4 ) ∀ x ∀ y ( x + y ′ ) = ( x + y ) ′ ( Q 5 ) ∀ x ( x × 0 ) = 0 ( Q 6 ) ∀ x ∀ y ( x × y ′ ) = ( ( x × y ) + x ) ( Q 7 ) ∀ x ∀ y ( x < y ↔ ∃ z ( z ′ + x ) = y ) ( Q 8 ) Untuk setiap bilangan asli n , definisikan numeral n ― sebagai suku 0 ′ ′ … ′ dengan jumlah tanda prima seluruhnya sebanyak n . Jadi, 0 ― ialah simbol konstanta  0 itu sendiri, 1 ― ialah 0 ′ , 2 ― ialah 0 ″ , dan seterusnya.

Sebagai teori aritmetika, 𝐐 sangat lemah; misalnya, kita bahkan tidak dapat membuktikan fakta sangat sederhana seperti ∀ x x ≠ x ′ atau ∀ x ∀ y ( x + y ) = ( y + x ) . Namun, akan kita lihat bahwa sebagian besar alasan mengapa 𝐐 begitu menarik ialah karena teori itu begitu lemah. Bahkan, teori itu persis cukup kuat agar teorema ketaklengkapan berlaku. Alasan lain 𝐐 menarik ialah karena teori itu memiliki himpunan aksioma yang berhingga.

Teori yang lebih kuat daripada 𝐐 (disebut aritmetika Peano 𝐏𝐀 ) diperoleh dengan menambahkan skema induksi pada  𝐐 : ( φ ( 0 ) ∧ ∀ x ( φ ( x ) → φ ( x ′ ) ) ) → ∀ x φ ( x ) dengan φ ( x ) sebarang formula. Jika φ ( x ) memuat variabel bebas selain x , kita tambahkan kuantor universal di bagian depan untuk mengikat semuanya (sehingga contoh skema induksi yang bersesuaian merupakan kalimat). Misalnya, jika φ ( x , y ) juga memuat variabel  y yang bebas, contoh yang bersesuaian ialah ∀ y ( ( φ ( 0 ) ∧ ∀ x ( φ ( x ) → φ ( x ′ ) ) ) → ∀ x φ ( x ) ) Dengan menggunakan contoh-contoh skema induksi, kita dapat membuktikan jauh lebih banyak dari aksioma-aksioma  𝐏𝐀 daripada dari aksioma-aksioma 𝐐 . Bahkan, diperlukan cukup banyak kerja untuk menemukan pernyataan “alami” tentang bilangan asli yang tidak dapat dibuktikan dalam aritmetika Peano!

Definisi 35.1.

Fungsi f ( x 0 , … , x k ) dari bilangan asli ke bilangan asli dikatakan dapat direpresentasikan dalam 𝐐 jika terdapat formula φ f ( x 0 , … , x k , y ) sedemikian sehingga setiap kali f ( n 0 , … , n k ) = m , 𝐐 membuktikan

  1. φ f ( n 0 ― , … , n k ― , m ― )

  2. ∀ y ( φ f ( n 0 ― , … , n k ― , y ) → m ― = y ) .

Ada cara lain untuk menyatakan definisi ini; misalnya, secara ekuivalen kita dapat mensyaratkan bahwa 𝐐 membuktikan ∀ y ( φ f ( n 0 ― , … , n k ― , y ) ↔ y = m ― ) .

Teorema 35.2.

Suatu fungsi dapat direpresentasikan dalam 𝐐 jika dan hanya jika fungsi itu dapat dihitung.

Ada dua arah dalam membuktikan teorema tersebut. Arah dari kiri ke kanan cukup langsung setelah aritmetisasi sintaksis tersedia. Arah lainnya memerlukan lebih banyak kerja. Gagasan dasarnya sebagai berikut: kita memilih “rekursif umum” sebagai cara untuk membuat istilah “dapat dihitung” tepat, lalu menunjukkan bahwa setiap fungsi rekursif umum dapat direpresentasikan dalam  𝐐 . Ingat bahwa suatu fungsi bersifat rekursif umum jika dapat didefinisikan dari zero , fungsi penerus  succ , dan fungsi-fungsi proyeksi  P i n , dengan menggunakan komposisi, rekursi primitif, dan pencarian tak berbatas pada fungsi reguler. Jadi, salah satu cara menunjukkan bahwa setiap fungsi rekursif umum dapat direpresentasikan dalam  𝐐 ialah menunjukkan bahwa fungsi-fungsi dasar dapat direpresentasikan, dan bahwa setiap kali beberapa fungsi dapat direpresentasikan, fungsi-fungsi yang didefinisikan darinya dengan komposisi, rekursi primitif, dan pencarian tak berbatas pada fungsi reguler juga dapat direpresentasikan. Dengan kata lain, kita dapat menunjukkan bahwa fungsi-fungsi dasar dapat direpresentasikan dan bahwa fungsi-fungsi yang dapat direpresentasikan “tertutup terhadap” komposisi, rekursi primitif, dan pencarian tak berbatas pada fungsi reguler. Hal ini menjamin bahwa setiap fungsi rekursif umum dapat direpresentasikan.

Ternyata langkah untuk menunjukkan bahwa fungsi-fungsi yang dapat direpresentasikan tertutup terhadap rekursi primitif itu sulit. Untuk menghindari langkah ini, pertama kita menunjukkan bahwa sebenarnya rekursi primitif dapat ditiadakan. Artinya, kita menunjukkan bahwa setiap fungsi rekursif umum dapat didefinisikan dari fungsi-fungsi dasar hanya dengan komposisi dan pencarian tak berbatas pada fungsi reguler. Untuk itu, kita menunjukkan bahwa rekursi primitif sesungguhnya dapat dilakukan dengan suatu pencarian tak berbatas tertentu pada fungsi reguler. Akan tetapi, agar hal ini berhasil, kita harus menambahkan beberapa fungsi dasar lain: penjumlahan, perkalian, dan fungsi karakteristik relasi identitas  χ = . Kemudian, kita dapat membuktikan teorema tersebut dengan menunjukkan bahwa semua fungsi dasar ini dapat direpresentasikan dalam  𝐐 dan bahwa fungsi-fungsi yang dapat direpresentasikan tertutup terhadap komposisi dan pencarian tak berbatas pada fungsi reguler.

35.2 Fungsi yang Dapat Direpresentasikan dalam 𝐐 Dapat Dihitung

Kita akan membuktikan bahwa setiap fungsi yang dapat direpresentasikan dalam  𝐐 dapat dihitung. Pertama-tama kita harus menetapkan sebuah lema tentang fungsi-fungsi yang dapat direpresentasikan dalam  𝐐 .

Lema 35.3.

Jika f ( x 0 , … , x k ) dapat direpresentasikan dalam  𝐐 , terdapat formula  φ f ( x 0 , … , x k , y ) sedemikian sehingga 𝐐 ⊢ φ f ( n 0 ― , … , n k ― , m ― ) jika dan hanya jika m = f ( n 0 , … , n k ) .

Bukti.

Bagian “jika” ialah Definisi 35.1enumi 1. Bagian “hanya jika” terlihat sebagai berikut. Andaikan 𝐐 ⊢ φ f ( n 0 ― , … , n k ― , m ― ) , tetapi m ≠ f ( n 0 , … , n k ) . Misalkan l = f ( n 0 , … , n k ) . Menurut Definisi 35.1enumi 1, 𝐐 ⊢ φ f ( n 0 ― , … , n k ― , l ― ) . Menurut Definisi 35.1enumi 2, 𝐐 membuktikan ∀ y ( φ f ( n 0 ― , … , n k ― , y ) → l ― = y ) . Dengan menggunakan logika dan asumsi bahwa 𝐐 ⊢ φ f ( n 0 ― , … , n k ― , m ― ) , kita memperoleh bahwa 𝐐 ⊢ l ― = m ― . Di sisi lain, menurut Lema 35.14, 𝐐 ⊢ l ― ≠ m ― . Jadi 𝐐 tidak konsisten. Namun, hal itu mustahil karena 𝐐 dipenuhi oleh model standar (lihat Definisi 33.2), 𝔑 ⊨ 𝐐 , dan teori yang dapat dipenuhi selalu konsisten menurut Teorema Kesahihan (Akibat 22.38, Akibat 19.31, Akibat 20.29, dan Akibat 21.31).

35.3 Lema Fungsi Beta

Untuk menunjukkan bahwa kita dapat melaksanakan rekursi primitif jika penjumlahan, perkalian, dan χ = tersedia, kita perlu mengembangkan fungsi-fungsi yang menangani barisan. (Jika perpangkatan juga tersedia, tugas kita akan lebih mudah.) Ketika rekursi primitif tersedia, kita dapat mendefinisikan hal-hal seperti “bilangan prima ke- n ,” lalu memilih pengodean yang cukup langsung. Namun, di sini rekursi primitif tidak tersedia—bahkan, kita ingin menunjukkan bahwa rekursi primitif dapat dilakukan dengan menggunakan pencarian tak berbatas—sehingga kita harus lebih cerdik.

Lema 35.5.

Terdapat fungsi β ( d , i ) sedemikian sehingga, untuk setiap barisan a 0 , …,  a n , terdapat bilangan  d sedemikian sehingga untuk setiap i ≤ n , β ( d , i ) = a i . Selain itu, β dapat didefinisikan dari fungsi-fungsi dasar hanya dengan komposisi dan pencarian tak berbatas pada fungsi reguler.

Bayangkan d sebagai kode barisan ⟨ a 0 , … , a n ⟩ dan β ( d , i ) sebagai fungsi yang mengembalikan elemen ke- i . (Perhatikan bahwa “pengodean” ini tidak menggunakan pengodean dengan pangkat bilangan prima yang sudah kita kenal!) Lema tersebut cukup minimal; lema itu tidak mengatakan bahwa kita dapat menggabungkan barisan, menambahkan elemen, atau bahkan menghitung  d dari a 0 , …,  a n dengan fungsi yang dapat didefinisikan melalui komposisi dan pencarian tak berbatas pada fungsi reguler. Lema itu hanya mengatakan bahwa terdapat suatu fungsi “pengurai kode” sedemikian sehingga setiap barisan “dikodekan.”

Penggunaan notasi β berasal dari Gödel. Sekali lagi, bagian sulit dalam membuktikan lema tersebut ialah mendefinisikan  β yang sesuai dengan sumber daya yang tampaknya terbatas, yakni hanya menggunakan komposisi dan pencarian tak berbatas—namun, kita diperbolehkan menggunakan penjumlahan, perkalian, dan  χ = . Ada berbagai cara untuk membuktikan lema ini, tetapi salah satu yang paling jernih tetap metode asli Gödel, yang menggunakan fakta teori bilangan bernama Teorema Sunzi (secara tradisional, “Teorema Sisa Tiongkok”).

35.5 Fungsi-Fungsi Dasar Dapat Direpresentasikan dalam  𝐐

Pertama-tama kita harus menunjukkan bahwa semua fungsi dasar dapat direpresentasikan dalam  𝐐 . Pada akhirnya, kita perlu menunjukkan cara menetapkan kepada setiap fungsi dasar berargumen k f ( x 0 , … , x k − 1 ) suatu formula φ f ( x 0 , … , x k − 1 , y ) yang merepresentasikannya.

35.8 Fungsi yang Dapat Dihitung Dapat Direpresentasikan dalam 𝐐

Teorema 35.27.

Setiap fungsi yang dapat dihitung dapat direpresentasikan dalam  𝐐 .

Bukti.

Agar pasti, dan dengan menggunakan Tesis Church–Turing, katakanlah bahwa suatu fungsi dapat dihitung jika dan hanya jika fungsi itu rekursif umum. Fungsi-fungsi rekursif umum ialah fungsi-fungsi yang dapat didefinisikan dari fungsi nol  zero , fungsi penerus  succ , dan fungsi proyeksi  P i n dengan menggunakan komposisi, rekursi primitif, dan pencarian tak berbatas pada fungsi reguler. Menurut Lema 35.9, setiap fungsi  h yang dapat didefinisikan dari f dan  g dengan rekursi primitif juga dapat didefinisikan melalui komposisi dan pencarian tak berbatas pada fungsi reguler dari f , g , dan zero , succ , P i n , add , mult , χ = . Akibatnya, suatu fungsi rekursif umum jika dan hanya jika fungsi itu dapat didefinisikan dari zero , succ , P i n , add , mult , χ = dengan menggunakan komposisi dan pencarian tak berbatas pada fungsi reguler.

Selain itu, telah kita tunjukkan bahwa fungsi-fungsi dasar yang bersangkutan dapat direpresentasikan dalam  𝐐 (Proposisi 35.10, Proposisi 35.11, Proposisi 35.12, Proposisi 35.13, Proposisi 35.15, dan Proposisi 35.17), dan bahwa setiap fungsi yang didefinisikan dari fungsi-fungsi yang dapat direpresentasikan melalui komposisi atau pencarian tak berbatas pada fungsi reguler (Proposisi 35.21, Proposisi 35.26) juga dapat direpresentasikan. Jadi, setiap fungsi rekursif umum dapat direpresentasikan dalam  𝐐 .

Telah kita tunjukkan bahwa himpunan fungsi yang dapat dihitung dapat dicirikan sebagai himpunan fungsi yang dapat direpresentasikan dalam 𝐐 . Sebenarnya, pembuktian tersebut lebih umum. Dari definisi representasi, tidak sulit melihat bahwa setiap teori yang memperluas 𝐐 (atau yang memungkinkan 𝐐 ditafsirkan di dalamnya) dapat merepresentasikan fungsi-fungsi yang dapat dihitung. Namun, sebaliknya, dalam setiap sistem derivasi yang gagasan derivasi-nya dapat dihitung, setiap fungsi yang dapat direpresentasikan dapat dihitung. Jadi, misalnya, himpunan fungsi yang dapat dihitung dapat dicirikan sebagai himpunan fungsi yang dapat direpresentasikan dalam aritmetika Peano, atau bahkan teori himpunan Zermelo–Fraenkel. Seperti dicatat Gödel, hal ini agak mengejutkan. Akan kita lihat bahwa dalam perkara keterbuktian, jawabannya sangat peka terhadap teori mana yang dipertimbangkan; secara kasar, semakin kuat aksiomanya, semakin banyak yang dapat dibuktikan. Namun, dalam cakupan luas teori-teori aksiomatik, fungsi-fungsi yang dapat direpresentasikan tepat merupakan fungsi-fungsi yang dapat dihitung; teori yang lebih kuat tidak merepresentasikan lebih banyak fungsi selama teori tersebut dapat diaksiomatisasi.

35.9 Merepresentasikan Relasi

Mari kita nyatakan apa artinya suatu relasi dapat direpresentasikan.

Definisi 35.28.

Relasi R ( x 0 , … , x k ) pada bilangan asli dapat direpresentasikan dalam 𝐐 jika terdapat formula φ R ( x 0 , … , x k ) sedemikian sehingga, setiap kali R ( n 0 , … , n k ) benar, 𝐐 membuktikan φ R ( n 0 ― , … , n k ― ) , dan setiap kali R ( n 0 , … , n k ) salah, 𝐐 membuktikan ¬ φ R ( n 0 ― , … , n k ― ) .

Teorema 35.29.

Suatu relasi dapat direpresentasikan dalam 𝐐 jika dan hanya jika relasi itu dapat dihitung.

Bukti.

Untuk arah maju, andaikan R ( x 0 , … , x k ) direpresentasikan oleh formula φ R ( x 0 , … , x k ) . Berikut algoritme untuk menghitung R : dengan masukan n 0 , …,  n k , carilah secara serentak pembuktian atas φ R ( n 0 ― , … , n k ― ) dan pembuktian atas ¬ φ R ( n 0 ― , … , n k ― ) . Menurut hipotesis kita, pencarian pasti menemukan salah satunya; jika yang ditemukan ialah yang pertama, laporkan “ya,” dan jika tidak, laporkan “tidak.”

Untuk arah lainnya, andaikan R ( x 0 , … , x k ) dapat dihitung. Menurut definisi, ini berarti bahwa fungsi χ R ( x 0 , … , x k ) dapat dihitung. Menurut Teorema 35.2, χ R direpresentasikan oleh suatu formula, misalnya φ χ R ( x 0 , … , x k , y ) . Misalkan φ R ( x 0 , … , x k ) merupakan formula φ χ R ( x 0 , … , x k , 1 ― ) . Maka, bagi sebarang n 0 , …,  n k , jika R ( n 0 , … , n k ) benar, maka χ R ( n 0 , … , n k ) = 1 ; dalam hal ini, 𝐐 membuktikan φ χ R ( n 0 ― , … , n k ― , 1 ― ) , sehingga 𝐐 membuktikan φ R ( n 0 ― , … , n k ― ) . Di sisi lain, jika R ( n 0 , … , n k ) salah, maka χ R ( n 0 , … , n k ) = 0 . Ini berarti bahwa 𝐐 membuktikan ∀ y ( φ χ R ( n 0 ― , … , n k ― , y ) → y = 0 ― ) . Karena 𝐐 membuktikan 0 ― ≠ 1 ― , 𝐐 membuktikan ¬ φ χ R ( n 0 ― , … , n k ― , 1 ― ) , dan dengan demikian membuktikan ¬ φ R ( n 0 ― , … , n k ― ) .

Kita menyebut teori 𝐓 tidak dapat diputuskan jika tidak ada prosedur komputasional yang, setelah sejumlah langkah berhingga, selalu memberikan jawaban yang benar atas pertanyaan “apakah 𝐓 membuktikan  φ ?” bagi sebarang kalimat  φ dalam bahasa  𝐓 . Jadi, 𝐐 dapat diputuskan jika dan hanya jika terdapat prosedur komputasional yang memutuskan, apabila diberikan kalimat  φ dalam bahasa aritmetika, apakah 𝐐 ⊢ φ atau tidak. 35.11 Kelengkapan Σ 1

Walaupun 𝐐 dan perluasan-perluasannya yang konsisten serta dapat diaksiomatisasi tidak lengkap, telah kita lihat bahwa 𝐐 memang membuktikan banyak fakta dasar tentang numeral. Bahkan, hasil ini dapat diperluas secara cukup berarti. Untuk memahami cakupan hal-hal yang dapat dibuktikan dalam  𝐐 , kita memperkenalkan gagasan formula Δ 0 , Σ 1 , dan Π 1 . Secara kasar, formula Σ 1 ialah formula berbentuk ∃ x ψ ( x ) , dengan ψ dibentuk hanya menggunakan penghubung proposisional dan kuantor terbatas. Kita akan menunjukkan bahwa jika φ adalah kalimat Σ 1 yang benar dalam 𝔑 , maka 𝐐 ⊢ φ (Teorema 35.38).

Definisi 35.32.

formula eksistensial terbatas ialah formula berbentuk ∃ x ( x < t ∧ φ ( x ) ) , dengan t sebarang suku, yang secara konvensional kita tulis sebagai ( ∃ x < t ) φ ( x ) . formula universal terbatas ialah formula berbentuk ∀ x ( x < t → φ ( x ) ) , dengan t sebarang suku, yang secara konvensional kita tulis sebagai ( ∀ x < t ) φ ( x ) .

Definisi 35.33.

formula ψ merupakan Δ 0 jika dibentuk dari formula atomik hanya dengan menggunakan penghubung proposisional dan kuantifikasi terbatas. formula φ merupakan Σ 1 jika φ ≡ ∃ x ψ ( x ) dengan ψ merupakan Δ 0 . formula φ merupakan Π 1 jika φ ≡ ∀ x ψ ( x ) dengan ψ merupakan Δ 0 .

Lema 35.34.

Andaikan t adalah suku tertutup sedemikian sehingga Val 𝔑 ( t ) = n . Maka 𝐐 ⊢ t = n ― .

Bukti.

Kita membuktikannya dengan induksi pada kompleksitas  t . Untuk kasus dasar, Val 𝔑 ( 0 ) = 0 , dan 𝐐 ⊢ 0 = 0 ― karena 0 ― ≡ 0 . Untuk kasus induktif, misalkan t 1 dan t 2 merupakan suku sedemikian sehingga Val 𝔑 ( t 1 ) = n 1 , Val 𝔑 ( t 2 ) = n 2 , 𝐐 ⊢ t 1 = n ― 1 , dan 𝐐 ⊢ t 2 = n ― 2 .

Maka Val 𝔑 ( ( t 1 ′ ) ) = n 1 + 1 , dan kita mempunyai 𝐐 ⊢ t 1 ′ = n ― 1 ′ berdasarkan aturan orde pertama bagi identitas yang diterapkan pada hipotesis induksi dan formula n 1 ― ′ = n 1 ― ′ , sehingga 𝐐 ⊢ t 1 ′ = n 1 + 1 ― menurut definisi numeral.

Untuk penjumlahan, kita mempunyai Val 𝔑 ( ( t 1 + t 2 ) ) = Val 𝔑 ( t 1 ) + Val 𝔑 ( t 2 ) = n 1 + n 2 . Menurut hipotesis induksi dan aturan identitas, 𝐐 ⊢ t 1 + t 2 = n 1 ― + t 2 , lalu 𝐐 ⊢ t 1 + t 2 = n 1 ― + n 2 ― berdasarkan penerapan kedua aturan identitas. Menurut Lema 35.16, 𝐐 ⊢ n 1 ― + n 2 ― = n 1 + n 2 ― , sehingga 𝐐 ⊢ t 1 + t 2 = n 1 + n 2 ― .

Penalaran serupa juga berlaku bagi  × , dengan menggunakan Lema 35.18. Karena ini mencakup semua suku tertutup aritmetika, kita mempunyai 𝐐 ⊢ t = n ― bagi semua suku tertutup  t sedemikian sehingga Val 𝔑 ( t ) = n .

Lema 35.35.

Andaikan t 1 dan t 2 merupakan suku tertutup. Maka

  1. Jika Val 𝔑 ( t 1 ) = Val 𝔑 ( t 2 ) , maka 𝐐 ⊢ t 1 = t 2 .

  2. Jika Val 𝔑 ( t 1 ) ≠ Val 𝔑 ( t 2 ) , maka 𝐐 ⊢ t 1 ≠ t 2 .

  3. Jika Val 𝔑 ( t 1 ) < Val 𝔑 ( t 2 ) , maka 𝐐 ⊢ t 1 < t 2 .

  4. Jika Val 𝔑 ( t 2 ) ≤ Val 𝔑 ( t 1 ) , maka 𝐐 ⊢ ¬ ( t 1 < t 2 ) .

Bukti.

Diberikan suku t 1 dan t 2 , tetapkan n = Val 𝔑 ( t 1 ) dan m = Val 𝔑 ( t 2 ) .

Andaikan φ ≡ t 1 = t 2 . Menurut Lema 35.34, 𝐐 ⊢ t 1 = n ― dan 𝐐 ⊢ t 2 = m ― . Jika n = m , maka 𝐐 ⊢ n ― = m ― , sehingga 𝐐 ⊢ t 1 = t 2 berdasarkan transitivitas identitas. Jika n ≠ m , maka 𝐐 ⊢ n ― ≠ m ― , dan kembali berdasarkan transitivitas identitas, 𝐐 ⊢ t 1 ≠ t 2 .

Sekarang misalkan φ ≡ t 1 < t 2 . Untuk kedua kasus, kita mengandalkan aksioma  Q 8 , yang menyatakan bahwa x < y ↔ ∃ z z ′ + x = y bagi semua x , y .

Andaikan 𝔑 ⊨ t 1 < t 2 . Maka terdapat suatu k ∈ ℕ sedemikian sehingga n + k + 1 = m . Menurut Lema 35.34, 𝐐 ⊢ t 1 = n ― dan 𝐐 ⊢ t 2 = m ― , dan menurut bagian pertama lema ini, 𝐐 ⊢ k ― ′ + n ― = m ― . Berdasarkan transitivitas identitas, diperoleh 𝐐 ⊢ k ― ′ + t 1 = t 2 , sehingga 𝐐 ⊢ ∃ z z ′ + t 1 = t 2 . Menurut arah kanan-ke-kiri dari  Q 8 , 𝐐 ⊢ t 1 < t 2 .

Sebaliknya, andaikan 𝔑 ⊭ t 1 < t 2 , yakni m ≤ n . Kita bekerja dalam  𝐐 dan mengasumsikan bahwa t 1 < t 2 . Menurut arah kiri-ke-kanan dari  Q 8 , terdapat suatu  z sedemikian sehingga z ′ + t 1 = t 2 . Karena 𝐐 ⊢ t 1 = n ― dan 𝐐 ⊢ t 2 = m ― , diperoleh z ′ + n ― = m ― . Dengan induksi eksternal pada  m menggunakan  Q 5 , diperoleh z ′ + n − m ― = 0 . Jika m = n , maka z ′ = 0 , yang menghasilkan kontradiksi melalui  Q 2 . Jika m < n , maka ( z ′ + n − m − 1 ― ) ′ = 0 menurut  Q 5 sekali lagi, yang menghasilkan kontradiksi melalui  Q 2 . Jadi, 𝐐 ⊢ ¬ ( t 1 < t 2 ) .

Lema 35.36.

Andaikan φ adalah formula, t suku tertutup, dan k = Val 𝔑 ( t ) . Maka

  1. 𝐐 ⊢ ( ∀ x < t ) φ ( x ) jika dan hanya jika 𝐐 ⊢ φ ( 0 ― ) ∧ ⋯ ∧ φ ( k − 1 ― ) .

  2. 𝐐 ⊢ ( ∃ x < t ) φ ( x ) jika dan hanya jika 𝐐 ⊢ φ ( 0 ― ) ∨ ⋯ ∨ φ ( k − 1 ― ) .

Bukti.

Kita membuktikan kasus bagi kuantor universal terbatas. Jika Val 𝔑 ( t ) = 0 , maka ruas kiri ekuivalensi dapat dibuktikan dalam  𝐐 karena tidak ada x < 0 ― menurut Lema 35.23. Demikian pula, konjungsi kosong dapat kita anggap sebagai ⊤ , yang juga dapat dibuktikan dalam  𝐐 . Karena itu, andaikan Val 𝔑 ( t ) = k + 1 untuk suatu bilangan asli  k . Menurut Lema 35.34, kita dapat mengasumsikan bahwa kita bekerja dengan formula berbentuk ( ∀ x < k + 1 ― ) φ ( x ) .

Andaikan 𝐐 ⊢ ( ∀ x < k + 1 ― ) φ ( x ) , dan misalkan n ≤ k . Karena 𝐐 ⊢ n ― < k + 1 ― menurut Lema 35.35, berdasarkan logika diperoleh 𝐐 ⊢ φ ( n ― ) . Dengan menerapkan fakta ini sebanyak k + 1 kali, masing-masing bagi n ≤ k , kita memperoleh 𝐐 ⊢ φ ( 0 ― ) ∧ ⋯ ∧ φ ( k ― ) sebagaimana diinginkan.

Untuk arah lainnya, andaikan 𝐐 ⊢ φ ( 0 ― ) ∧ ⋯ ∧ φ ( k ― ) . Dengan bekerja dalam 𝐐 , andaikan x < k + 1 ― . Menurut Lema 35.24, kita mempunyai x = 0 ― ∨ ⋯ ∨ x = k ― , sehingga berdasarkan logika diperoleh  φ ( x ) , dan dengan demikian klaim universal ( ∀ x < k + 1 ― ) φ ( x ) mengikuti.

Pembuktian ekuivalensi bagi formula yang dikuantifikasi secara eksistensial terbatas serupa.

Lema 35.37.

Jika φ adalah kalimat Δ 0 yang benar dalam 𝔑 , maka 𝐐 ⊢ φ .

Bukti.

Kita membuktikannya dengan induksi pada kompleksitas formula. Kasus dasar diberikan oleh Lema 35.35, sehingga kita beralih ke langkah induksi. Demi kesederhanaan, kita membagi kasus negasi menjadi beberapa subkasus berdasarkan struktur formula yang dikenai negasi.

  1. Andaikan ( φ ∧ ψ ) benar dalam 𝔑 , sehingga φ dan ψ benar dalam  𝔑 . Menurut hipotesis induksi, 𝐐 ⊢ φ dan 𝐐 ⊢ ψ , sehingga berdasarkan logika 𝐐 ⊢ ( φ ∧ ψ ) .

  2. Andaikan ¬ ( φ ∧ ψ ) benar dalam 𝔑 , sehingga ¬ φ atau ¬ ψ benar dalam 𝔑 . Tanpa mengurangi keumuman, andaikan yang pertama. Menurut hipotesis induksi, 𝐐 ⊢ ¬ φ , sehingga berdasarkan logika 𝐐 ⊢ ¬ ( φ ∧ ψ ) .

  3. Andaikan ( φ ∨ ψ ) benar dalam 𝔑 , sehingga φ benar dalam 𝔑 atau ψ benar dalam 𝔑 . Tanpa mengurangi keumuman, andaikan yang pertama berlaku. Menurut hipotesis induksi, 𝐐 ⊢ φ , sehingga berdasarkan logika 𝐐 ⊢ ( φ ∨ ψ ) .

  4. Andaikan ¬ ( φ ∨ ψ ) benar dalam 𝔑 , sehingga ¬ φ dan ¬ ψ benar dalam 𝔑 . Menurut hipotesis induksi, 𝐐 ⊢ ¬ φ dan 𝐐 ⊢ ¬ ψ . Akibatnya, berdasarkan logika 𝐐 ⊢ ¬ ( φ ∨ ψ ) .

  5. Andaikan ( ∀ x < t ) φ ( x ) benar dalam  𝔑 , dengan t merupakan suku tertutup dan k = Val 𝔑 ( t ) . Menurut hipotesis induksi dan logika, jika φ ( n ― ) benar dalam  𝔑 bagi semua n < Val 𝔑 ( t ) , maka 𝐐 ⊢ φ ( 0 ― ) ∧ ⋯ ∧ φ ( k − 1 ― ) . Menurut Lema 35.36, diperoleh 𝐐 ⊢ ( ∀ x < t ) φ ( x ) .

  6. Kasus bagi kuantor eksistensial terbatas, ketika kita mempunyai kalimat berbentuk ( ∃ x < t ) φ ( x ) , serupa dengan kasus bagi kuantor universal terbatas.

  7. Andaikan ¬ ( ∀ x < t ) φ ( x ) benar dalam  𝔑 , dengan t merupakan suku tertutup. kalimat ini ekuivalen dengan kalimat ( ∃ x < t ) ¬ φ ( x ) , dengan ekuivalensinya dapat diturunkan dalam 𝐐 , sehingga kita dapat menerapkan penalaran bagi kuantor eksistensial terbatas.

  8. Demikian pula, andaikan ¬ ( ∃ x < t ) φ ( x ) benar dalam 𝔑 , dengan t merupakan suku tertutup. kalimat ini ekuivalen dalam 𝐐 dengan ( ∀ x < t ) ¬ φ ( x ) , sehingga kita dapat menerapkan penalaran bagi kuantor universal terbatas.

  9. Terakhir, andaikan ¬ φ benar dalam 𝔑 . Satu-satunya kasus yang tersisa ialah ketika φ atomik dan ketika ¬ φ ≡ ¬ ¬ ψ bagi suatu kalimat Δ 0 ψ . Jika φ atomik, maka menurut Lema 35.35, 𝐐 ⊢ ¬ φ . Jika ¬ φ ≡ ¬ ¬ ψ , maka berdasarkan logika formula itu dapat dibuktikan ekuivalen dalam  𝐐 dengan  ψ , yang benar dalam 𝔑 karena ¬ φ benar dalam  𝔑 . Oleh karena itu, menurut hipotesis induksi kita mempunyai 𝐐 ⊢ ¬ φ .

Teorema 35.38.

Jika φ adalah kalimat Σ 1 yang benar dalam  𝔑 , maka 𝐐 ⊢ φ .

Bukti.

Jika ∃ x φ ( x ) adalah kalimat Σ 1 yang benar dalam  𝔑 , maka terdapat bilangan asli  n dan penetapan variabel  s sedemikian sehingga s ( x ) = n dan 𝔑 , s ⊨ φ ( x ) . Menurut fakta-fakta standar tentang relasi kepuasan, diperoleh 𝔑 ⊨ φ ( n ― ) . Namun, φ ( n ― ) merupakan formula Δ 0 , sehingga menurut Lema 35.37 kita mempunyai 𝐐 ⊢ φ ( n ― ) , dan berdasarkan logika kita juga mempunyai 𝐐 ⊢ ∃ x φ ( x ) .
