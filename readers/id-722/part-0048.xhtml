38 Sintaksis dan Semantik

Sintaksis dan semantik dasar bagi SOL telah dibahas sejauh ini. Sebagai sebuah bab, bagian ini terlalu singkat. Substitusi bagi variabel orde kedua harus dibahas agar kita dapat membicarakan sistem derivasi bagi SOL, dan terdapat beberapa persoalan pelik di sana.

38.1 Pengantar

Dalam logika orde pertama, kita menggabungkan simbol-simbol nonlogis suatu bahasa tertentu, yakni simbol konstanta, simbol fungsi, dan simbol predikat yang dimilikinya, dengan simbol-simbol logis untuk mengungkapkan hal-hal mengenai struktur orde pertama. Hal ini dilakukan dengan menggunakan gagasan keterpenuhan, yang menghubungkan struktur  𝔐 , bersama suatu penugasan variabel  s , dengan formula  φ : 𝔐 , s ⊨ φ berlaku jika dan hanya jika apa yang diungkapkan oleh  φ adalah benar ketika simbol konstanta, simbol fungsi, dan simbol predikat yang muncul di dalamnya ditafsirkan sebagaimana ditentukan oleh  𝔐 , dan variabel-variabel bebasnya ditafsirkan sebagaimana ditentukan oleh  s . Interpretasi predikat identitas  = sudah melekat dalam definisi 𝔐 , s ⊨ φ , demikian pula interpretasi  ∀ dan ∃ . Yang pertama selalu ditafsirkan sebagai relasi identitas pada domain  | 𝔐 | struktur tersebut, dan kuantor selalu ditafsirkan sebagai merentang atas seluruh domain. Namun, yang sangat penting, kuantifikasi hanya diperbolehkan atas anggota-anggota domain, sehingga hanya variabel objek yang diperbolehkan mengikuti suatu kuantor.

Dalam logika orde kedua, baik bahasa maupun definisi keterpenuhan diperluas sehingga mencakup variabel fungsi dan predikat bebas maupun terikat, serta kuantifikasi atas variabel-variabel tersebut. Variabel-variabel ini berhubungan dengan simbol fungsi dan simbol predikat dengan cara yang sama seperti variabel objek berhubungan dengan simbol konstanta. Variabel-variabel tersebut memainkan peran yang sama dalam pembentukan suku dan formula logika orde kedua, dan kuantifikasi atasnya ditangani dengan cara serupa. Dalam semantik standar, kuantor orde kedua merentang atas semua objek yang mungkin dari tipe yang tepat (fungsi beraritas  n dari | 𝔐 | n ke  | 𝔐 | bagi variabel fungsi, dan relasi beraritas  n bagi variabel predikat). Misalnya, meskipun ∀ 𝘷 0 ( 𝘗 0 1 ( 𝘷 0 ) ∨ ¬ 𝘗 0 1 ( 𝘷 0 ) ) merupakan suatu formula baik dalam logika orde pertama maupun dalam logika orde kedua, dalam logika orde kedua kita juga dapat mempertimbangkan ∀ 𝘝 0 1 ∀ 𝘷 0 ( 𝘝 0 1 ( 𝘷 0 ) ∨ ¬ 𝘝 0 1 ( 𝘷 0 ) ) dan ∃ 𝘝 0 1 ∀ 𝘷 0 ( 𝘝 0 1 ( 𝘷 0 ) ∨ ¬ 𝘝 0 1 ( 𝘷 0 ) ) . Karena kedua formula ini tidak memuat variabel bebas, keduanya merupakan kalimat logika orde kedua. Di sini, 𝘝 0 1 merupakan variabel predikat orde kedua beraritas  1 . Interpretasi yang diperbolehkan bagi  𝘝 0 1 sama dengan yang dapat kita tetapkan kepada suatu simbol predikat beraritas  1 seperti  𝘗 0 1 , yakni himpunan-himpunan bagian dari  | 𝔐 | . Kuantifikasi atasnya lalu berarti menyatakan bahwa ∀ 𝘷 0 ( 𝘝 0 1 ( 𝘷 0 ) ∨ ¬ 𝘝 0 1 ( 𝘷 0 ) ) berlaku bagi semua cara menetapkan suatu himpunan bagian dari  | 𝔐 | sebagai nilai  𝘝 0 1 , atau bagi setidaknya satu cara. Karena setiap himpunan memuat atau tidak memuat suatu objek tertentu, kedua kalimat itu benar dalam setiap struktur.

38.2 Suku dan Formula

Seperti dalam logika orde pertama, ungkapan-ungkapan logika orde kedua dibangun dari kosakata dasar yang memuat variabel, simbol konstanta, simbol predikat, dan kadang-kadang simbol fungsi. Dari unsur-unsur tersebut, bersama penghubung logis, kuantor, dan simbol tanda baca seperti tanda kurung dan koma, dibentuk suku dan formula. Perbedaannya ialah bahwa selain variabel untuk objek, logika orde kedua juga memuat variabel untuk relasi dan fungsi, serta memperbolehkan kuantifikasi atasnya. Jadi, simbol-simbol logis logika orde kedua adalah simbol-simbol logika orde pertama, dengan tambahan:

  1. Suatu himpunan variabel relasi orde kedua yang terbilang untuk setiap aritas  n : 𝘝 0 n , 𝘝 1 n , 𝘝 2 n , …

  2. Suatu himpunan variabel fungsi orde kedua yang terbilang: 𝘶 0 n , 𝘶 1 n , 𝘶 2 n , …

Sebagaimana kita menggunakan x , y , dan  z sebagai metavariabel bagi variabel orde pertama 𝘷 i , kita akan menggunakan X , Y , Z , dan seterusnya sebagai metavariabel bagi  𝘝 i n , serta u , v , dan seterusnya sebagai metavariabel bagi  𝘶 i n .

Simbol-simbol nonlogis suatu bahasa orde kedua ditentukan dengan cara yang sama seperti bagi suatu bahasa orde pertama: dengan mencantumkan simbol konstanta, simbol fungsi, dan simbol predikat dalam bahasa tersebut.

Dalam logika orde pertama, predikat identitas  = biasanya disertakan. Dalam logika orde pertama, simbol-simbol nonlogis suatu bahasa  ℒ sangat penting agar kita dapat mengungkapkan sesuatu yang menarik. Tentu saja ada kalimat yang tidak menggunakan simbol nonlogis, tetapi hanya dengan  = sulit untuk menyatakan sesuatu yang menarik. Dalam logika orde kedua, karena kita mempunyai persediaan variabel relasi dan fungsi yang tidak terbatas, kita dapat menyatakan apa pun yang dapat kita nyatakan dalam suatu bahasa orde pertama, bahkan tanpa persediaan khusus simbol nonlogis.

38.4 Gagasan Semantis

Gagasan logis utama berupa validitas, perikutan, dan keterpenuhan didefinisikan dengan cara yang sama bagi logika orde kedua seperti bagi logika orde pertama, kecuali bahwa relasi keterpenuhan yang mendasarinya sekarang adalah relasi bagi formula orde kedua. Tentu saja, suatu kalimat orde kedua merupakan formula yang semua variabelnya, termasuk variabel predikat dan fungsi, terikat.

Definisi 38.11.

Validitas

Suatu kalimat φ valid, ⊨ φ , jika dan hanya jika 𝔐 ⊨ φ bagi setiap struktur  𝔐 .

Definisi 38.12.

Perikutan

Suatu himpunan kalimat  Γ mengakibatkan suatu kalimat  φ , Γ ⊨ φ , jika dan hanya jika bagi setiap struktur  𝔐 dengan 𝔐 ⊨ Γ , berlaku 𝔐 ⊨ φ .

Definisi 38.13.

Keterpenuhan

Suatu himpunan kalimat  Γ dapat dipenuhi jika 𝔐 ⊨ Γ bagi suatu struktur  𝔐 . Jika Γ tidak dapat dipenuhi, himpunan itu disebut tak dapat dipenuhi.

38.5 Daya Ekspresif

Kuantifikasi atas variabel orde kedua menghasilkan peningkatan yang sangat besar dalam daya ekspresif bahasa dibandingkan dengan logika orde pertama. Kuantifikasi eksistensial orde kedua memungkinkan kita menyatakan bahwa terdapat fungsi atau relasi yang mempunyai sifat-sifat tertentu. Dalam logika orde pertama, satu-satunya cara untuk melakukan hal itu ialah menentukan suatu simbol nonlogis (yakni, simbol fungsi atau simbol predikat) bagi tujuan tersebut. Kuantifikasi universal orde kedua memungkinkan kita menyatakan bahwa semua himpunan bagian dan relasi pada domain, serta semua fungsi dari domain itu ke dirinya sendiri, mempunyai suatu sifat. Dalam logika orde pertama, kita hanya dapat menyatakan bahwa himpunan bagian, relasi, atau fungsi yang ditetapkan kepada salah satu simbol nonlogis bahasa mempunyai suatu sifat. Dan ketika kita menyatakan bahwa terdapat himpunan bagian, relasi, atau fungsi yang mempunyai suatu sifat, atau bahwa semuanya mempunyai sifat itu, kita juga dapat menggunakan kuantifikasi orde kedua dalam menentukan sifat tersebut. Hal ini memungkinkan kita mendefinisikan relasi yang tidak dapat didefinisikan dalam logika orde pertama dan mengungkapkan sifat-sifat domain yang tidak dapat diungkapkan dalam logika orde pertama.

38.6 Mendeskripsikan Domain Tak Hingga dan Terhitung

Suatu himpunan  M bersifat tak hingga Dedekind jika dan hanya jika terdapat fungsi injektif  f : M → M yang tidak surjektif, yakni, dengan ran ( f ) ≠ M . Dalam logika orde pertama, kita dapat mempertimbangkan suatu simbol fungsi beraritas satu  f dan menyatakan bahwa fungsi  f 𝔐 yang ditetapkan kepadanya dalam struktur  𝔐 bersifat injektif dan ran ( f ) ≠ | 𝔐 | : ∀ x ∀ y ( f ( x ) = f ( y ) → x = y ) ∧ ∃ y ∀ x y ≠ f ( x ) . Jika 𝔐 memenuhi kalimat ini, maka f 𝔐 : | 𝔐 | → | 𝔐 | bersifat injektif, sehingga | 𝔐 | harus tak hingga. Jika | 𝔐 | tak hingga dan karena itu terdapat fungsi semacam itu, kita dapat mengambil f 𝔐 sebagai fungsi tersebut, dan 𝔐 akan memenuhi kalimat itu. Namun, cara ini mengharuskan bahasa kita memuat simbol nonlogis  f yang kita gunakan untuk tujuan tersebut. Dalam logika orde kedua, kita cukup menyatakan bahwa fungsi semacam itu ada. Hal ini tidak lagi memerlukan  f , dan kita memperoleh kalimat dalam logika orde kedua murni Inf ≡ ∃ u ( ∀ x ∀ y ( u ( x ) = u ( y ) → x = y ) ∧ ∃ y ∀ x y ≠ u ( x ) ) . 𝔐 ⊨ Inf jika dan hanya jika | 𝔐 | tak hingga. Selanjutnya, kita dapat mendefinisikan Fin ≡ ¬ Inf ; 𝔐 ⊨ Fin jika dan hanya jika | 𝔐 | berhingga. Tidak ada satu kalimat logika orde pertama murni yang dapat mengungkapkan bahwa domain tak hingga, meskipun suatu himpunan tak hingga kalimat semacam itu dapat mengungkapkannya. Tidak ada himpunan kalimat logika orde pertama murni yang terpenuhi dalam struktur jika dan hanya jika domainnya berhingga.

Proposisi 38.17.

𝔐 ⊨ Inf jika dan hanya jika | 𝔐 | tak hingga.

Bukti.

𝔐 ⊨ Inf jika dan hanya jika 𝔐 , s ⊨ ∀ x ∀ y ( u ( x ) = u ( y ) → x = y ) ∧ ∃ y ∀ x y ≠ u ( x ) bagi suatu  s . Jika hal itu berlaku, s ( u ) merupakan fungsi injektif, dan suatu y ∈ | 𝔐 | tidak berada dalam daerah hasil  s ( u ) . Sebaliknya, jika terdapat injektif f : | 𝔐 | → | 𝔐 | dengan ran ( f ) ≠ | 𝔐 | , maka suatu penugasan variabel dengan s ( u ) = f menjadi saksi yang diperlukan.

Suatu himpunan tak kosong M bersifat terhitung jika terdapat suatu enumerasi m 0 , m 1 , m 2 , … atas anggota himpunan tersebut (tanpa pengulangan, tetapi mungkin berhingga). Enumerasi semacam itu ada jika dan hanya jika terdapat anggota  z ∈ M dan suatu fungsi f : M → M sedemikian sehingga z , f ( z ) , f ( f ( z ) ) , …, mencakup semua anggota dari  M . Sebab, jika enumerasi itu ada, ambil z = m 0 dan f ( m k ) = m k + 1 (atau f ( m k ) = m k jika m k merupakan anggota terakhir dari enumerasi); itulah anggota dan fungsi yang diperlukan. Sebaliknya, jika z dan f semacam itu ada, maka dengan menghapus pengulangan dari z , f ( z ) , f ( f ( z ) ) , … diperoleh suatu enumerasi atas  M , sehingga M bersifat terhitung. Kita dapat mengungkapkan keberadaan z dan  f dalam logika orde kedua untuk menghasilkan suatu kalimat yang benar dalam struktur jika dan hanya jika domain struktur tersebut terhitung: Count ≡ ∃ z ∃ u ∀ X ( ( X ( z ) ∧ ∀ x ( X ( x ) → X ( u ( x ) ) ) ) → ∀ x X ( x ) )

Bukti.

Andaikan | 𝔐 | terhitung, dan misalkan m 0 , m 1 , …, merupakan suatu enumerasi. Dengan menghapus pengulangan, kita dapat menjamin bahwa tidak ada m k yang muncul dua kali. Definisikan f ( m k ) = m k + 1 bagi setiap anggota yang bukan anggota terakhir; jika enumerasinya berhingga, petakan anggota terakhir itu ke dirinya sendiri. Lalu, tetapkan s ( z ) = m 0 dan s ( u ) = f . Kita tunjukkan bahwa 𝔐 , s ⊨ ∀ X ( ( X ( z ) ∧ ∀ x ( X ( x ) → X ( u ( x ) ) ) ) → ∀ x X ( x ) ) Misalkan N ⊆ | 𝔐 | sebarang. Andaikan pula bahwa 𝔐 , s [ N / X ] ⊨ ( X ( z ) ∧ ∀ x ( X ( x ) → X ( u ( x ) ) ) ) . Maka s [ N / X ] ( z ) ∈ N , dan setiap kali a ∈ N , berlaku pula ( s [ N / X ] ( u ) ) ( a ) ∈ N . Dengan kata lain, karena s [ N / X ] ∼ X s , m 0 ∈ N dan jika a ∈ N , maka f ( a ) ∈ N ; jadi m 0 ∈ N , m 1 = f ( m 0 ) ∈ N , m 2 = f ( f ( m 0 ) ) ∈ N , dan seterusnya. Dengan demikian, N = | 𝔐 | , sehingga 𝔐 , s [ N / X ] ⊨ ∀ x X ( x ) . Karena N ⊆ | 𝔐 | dipilih secara sebarang, kita selesai: 𝔐 ⊨ Count .

Sekarang andaikan 𝔐 ⊨ Count , yakni, 𝔐 , s ⊨ ∀ X ( ( X ( z ) ∧ ∀ x ( X ( x ) → X ( u ( x ) ) ) ) → ∀ x X ( x ) ) bagi suatu  s . Misalkan m = s ( z ) dan f = s ( u ) , lalu perhatikan N = { m , f ( m ) , f ( f ( m ) ) , … } . Himpunan N yang didefinisikan demikian jelas terhitung. Jadi, karena anteseden maupun kondisional tersebut terpenuhi, konsekuennya juga harus terpenuhi: 𝔐 , s [ N / X ] ⊨ ∀ x X ( x ) . Namun, ini berarti bahwa N = | 𝔐 | , sehingga | 𝔐 | terhitung, sebab berdasarkan definisi N bersifat demikian.
