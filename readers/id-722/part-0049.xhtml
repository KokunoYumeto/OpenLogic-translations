39 Metateori Logika Orde Kedua

39.1 Pendahuluan

Logika orde pertama mempunyai sejumlah sifat yang baik. Kita tahu bahwa logika ini tidak dapat diputuskan, tetapi setidaknya dapat diaksiomatisasi. Artinya, terdapat sistem pembuktian bagi logika orde pertama yang sahih dan lengkap, yakni sistem tersebut menghasilkan relasi keterderivasian  ⊢ dengan sifat bahwa untuk setiap himpunan kalimat  Γ dan setiap kalimat  φ , Γ ⊨ φ jika dan hanya jika Γ ⊢ φ . Secara khusus, ini berarti bahwa himpunan validitas logika orde pertama terenumerasi secara komputabel. Terdapat suatu fungsi yang dapat dihitung  f : ℕ → Sent ( ℒ ) sedemikian sehingga nilai-nilai  f tepat merupakan semua kalimat valid dari  ℒ . Hal ini berlaku karena derivasi dapat dienumerasi, lalu derivasi-derivasi yang menurunkan satu kalimat dipetakan ke kalimat tersebut. Logika orde kedua lebih ekspresif daripada logika orde pertama, sehingga secara umum lebih rumit untuk mencakup semua validitasnya. Bahkan, kita akan menunjukkan bahwa logika orde kedua bukan hanya tidak dapat diputuskan, melainkan validitas-validitasnya bahkan tidak terenumerasi secara komputabel. Ini berarti bahwa tidak mungkin ada sistem pembuktian yang sahih dan lengkap bagi logika orde kedua (meskipun tersedia sistem pembuktian yang sahih tetapi tidak lengkap, dan sistem-sistem tersebut bahkan merupakan objek penelitian yang penting).

Logika orde pertama juga mempunyai dua sifat lain: logika ini kompak (jika setiap himpunan bagian berhingga dari suatu himpunan kalimat  Γ dapat dipenuhi, maka Γ sendiri dapat dipenuhi) dan Teorema Löwenheim–Skolem berlaku baginya (jika Γ mempunyai model tak hingga, maka himpunan itu mempunyai model terbilang). Kedua hasil ini tidak berlaku bagi logika orde kedua. Sekali lagi, alasannya ialah bahwa logika orde kedua dapat mengungkapkan fakta-fakta tentang ukuran domain yang tidak dapat diungkapkan oleh logika orde pertama.

39.2 Aritmetika Orde Kedua

Ingat bahwa teori 𝐏𝐀 dari aritmetika Peano mencakup delapan aksioma dari  𝐐 , ∀ x x ′ ≠ 0 ∀ x ∀ y ( x ′ = y ′ → x = y ) ∀ x ( x = 0 ∨ ∃ y x = y ′ ) ∀ x ( x + 0 ) = x ∀ x ∀ y ( x + y ′ ) = ( x + y ) ′ ∀ x ( x × 0 ) = 0 ∀ x ∀ y ( x × y ′ ) = ( ( x × y ) + x ) ∀ x ∀ y ( x < y ↔ ∃ z ( z ′ + x ) = y ) bersama semua kalimat berbentuk ( φ ( 0 ) ∧ ∀ x ( φ ( x ) → φ ( x ′ ) ) ) → ∀ x φ ( x ) . Yang terakhir merupakan suatu “skema”, yakni pola yang menghasilkan tak hingga banyak kalimat dalam bahasa aritmetika, satu untuk setiap formula  φ ( x ) . Skema ini kita sebut skema aksioma induksi (orde pertama). Dalam aritmetika Peano orde kedua  𝐏𝐀 𝟐 , induksi dapat dinyatakan sebagai satu kalimat. 𝐏𝐀 𝟐 terdiri atas delapan aksioma pertama di atas bersama aksioma induksi (orde kedua): ∀ X ( ( X ( 0 ) ∧ ∀ x ( X ( x ) → X ( x ′ ) ) ) → ∀ x X ( x ) ) . Aksioma tersebut menyatakan bahwa jika suatu himpunan bagian  X dari domain memuat  0 𝔐 dan, bersama setiap  x ∈ | 𝔐 | , juga memuat  ′ 𝔐 ( x ) (yakni, himpunan itu “tertutup terhadap penerus”), maka himpunan itu memuat segala sesuatu dalam domain (yakni, X = | 𝔐 | ) .

Aksioma induksi menjamin bahwa setiap struktur yang memenuhinya hanya memuat anggota dari  | 𝔐 | yang keberadaannya dituntut oleh aksioma-aksioma tersebut, yakni nilai-nilai  n ― untuk n ∈ ℕ . Suatu model dari 𝐏𝐀 𝟐 tidak memuat bilangan nonstandar.

Teorema 39.1.

Jika 𝔐 ⊨ 𝐏𝐀 𝟐 , maka | 𝔐 | = { Val 𝔐 ( n ― ) : n ∈ ℕ } .

Bukti.

Misalkan N = { Val 𝔐 ( n ― ) : n ∈ ℕ } , dan andaikan 𝔐 ⊨ 𝐏𝐀 𝟐 . Tentu saja, untuk setiap n ∈ ℕ , Val 𝔐 ( n ― ) ∈ | 𝔐 | , sehingga N ⊆ | 𝔐 | .

Sekarang tinjau inklusi ke arah sebaliknya. Tinjau suatu penugasan variabel s dengan s ( X ) = N . Berdasarkan asumsi, 𝔐 ⊨ ∀ X ( ( X ( 0 ) ∧ ∀ x ( X ( x ) → X ( x ′ ) ) ) → ∀ x X ( x ) ) ,  sehingga 𝔐 , s ⊨ ( X ( 0 ) ∧ ∀ x ( X ( x ) → X ( x ′ ) ) ) → ∀ x X ( x ) . Tinjau anteseden implikasi ini. Val 𝔐 ( 0 ) ∈ N , sehingga 𝔐 , s ⊨ X ( 0 ) . Konjungsi kedua, ∀ x ( X ( x ) → X ( x ′ ) ) , juga dipenuhi. Sebab, andaikan x ∈ N . Menurut definisi  N , x = Val 𝔐 ( n ― ) untuk suatu  n . Hal ini memberikan ′ 𝔐 ( x ) = Val 𝔐 ( n + 1 ― ) ∈ N . Jadi, ′ 𝔐 ( x ) ∈ N .

Kita memperoleh 𝔐 , s ⊨ X ( 0 ) ∧ ∀ x ( X ( x ) → X ( x ′ ) ) . Akibatnya, 𝔐 , s ⊨ ∀ x X ( x ) . Namun, ini berarti bahwa untuk setiap x ∈ | 𝔐 | berlaku x ∈ s ( X ) = N . Jadi, | 𝔐 | ⊆ N .

Akibat 39.2.

Sembarang dua model dari  𝐏𝐀 𝟐 saling isomorfik.

Bukti.

Menurut Teorema 39.1, domain setiap model dari 𝐏𝐀 𝟐 seluruhnya terdiri atas Val 𝔐 ( n ― ) . Setiap model semacam itu juga merupakan model dari  𝐐 . Menurut Proposisi 26.3, setiap model semacam itu standar, yakni isomorfik dengan  𝔑 .

Di atas kita mendefinisikan 𝐏𝐀 𝟐 sebagai teori yang memuat delapan aksioma aritmetika pertama bersama aksioma induksi orde kedua. Sebenarnya, berkat daya ekspresif logika orde kedua, hanya dua aksioma pertama dari aksioma-aksioma aritmetika itu bersama induksi yang diperlukan bagi aritmetika Peano orde kedua.

Proposisi 39.3.

Misalkan 𝐏𝐀 𝟐 † adalah teori orde kedua yang memuat dua aksioma aritmetika pertama (aksioma-aksioma penerus) dan aksioma induksi orde kedua. Maka ≤ , + , dan × dapat didefinisikan dalam 𝐏𝐀 𝟐 † .

Bukti.

Untuk menunjukkan bahwa ≤ dapat didefinisikan, kita harus menemukan suatu formula  φ ≤ ( x , y ) sedemikian sehingga 𝔑 ⊨ φ ≤ ( n ― , m ― ) jika dan hanya jika n ≤ m . Tinjau formula ψ ( x , Y ) ≡ Y ( x ) ∧ ∀ y ( Y ( y ) → Y ( y ′ ) ) Jelas bahwa ψ ( n ― , Y ) dipenuhi oleh suatu himpunan Y ⊆ ℕ jika dan hanya jika { m : n ≤ m } ⊆ Y , sehingga kita dapat mengambil φ ≤ ( x , y ) ≡ ∀ Y ( ψ ( x , Y ) → Y ( y ) ) .

Untuk melihat bahwa penjumlahan dapat didefinisikan, amati bahwa k + l = m jika dan hanya jika terdapat suatu fungsi u sedemikian sehingga u ( 0 ) = k , u ( n ′ ) = u ( n ) ′ untuk semua n , dan m = u ( l ) . Kita dapat menggunakan ekuivalensi ini untuk mendefinisikan penjumlahan dalam 𝐏𝐀 𝟐 † dengan formula berikut: φ + ( x , y , z ) ≡ ∃ u ( u ( 0 ) = x ∧ ∀ w u ( w ′ ) = u ( w ) ′ ∧ u ( y ) = z ) Harus jelas bahwa 𝔑 ⊨ φ + ( k ― , l ― , m ― ) jika dan hanya jika k + l = m .

39.3 Logika Orde Kedua Tidak Dapat Diaksiomatisasi

Teorema 39.4.

Logika orde kedua tidak dapat diputuskan.

Bukti.

Suatu kalimat orde pertama valid dalam logika orde pertama jika dan hanya jika kalimat itu valid dalam logika orde kedua, sedangkan logika orde pertama tidak dapat diputuskan.

Teorema 39.5.

Tidak ada sistem derivasi yang sahih dan lengkap bagi logika orde kedua.

Bukti.

Misalkan φ adalah kalimat dalam bahasa aritmetika. 𝔑 ⊨ φ jika dan hanya jika 𝐏𝐀 𝟐 ⊨ φ . Misalkan P adalah konjungsi kesembilan aksioma dari  𝐏𝐀 𝟐 . 𝐏𝐀 𝟐 ⊨ φ jika dan hanya jika ⊨ P → φ , yakni 𝔐 ⊨ P → φ . Sekarang tinjau kalimat ∀ z ∀ u ∀ u ′ ∀ u ″ ∀ L ( P ′ → φ ′ ) yang diperoleh dengan mengganti 0 dengan z , ′ dengan variabel fungsi satu-tempat u , + dan × masing-masing dengan variabel fungsi dua-tempat u ′ dan u ″ , serta < dengan variabel relasi dua-tempat  L , lalu menguantifikasi semuanya secara universal. Kalimat ini valid dalam logika orde kedua murni jika dan hanya jika kalimat asal valid, jika dan hanya jika 𝐏𝐀 𝟐 ⊨ φ , jika dan hanya jika 𝔑 ⊨ φ . Jadi, jika terdapat sistem pembuktian yang sahih dan lengkap bagi logika orde kedua, kita dapat menggunakannya untuk mendefinisikan suatu enumerasi yang dapat dihitung f : ℕ → Sent ( ℒ A ) atas kalimat yang benar dalam  𝔑 . Fungsi ini dapat direpresentasikan dalam  𝐐 oleh suatu formula orde pertama  ψ f ( x , y ) . Maka formula  ∃ x ψ f ( x , y ) akan mendefinisikan himpunan kalimat orde pertama yang benar dalam  𝔑 , bertentangan dengan Teorema Tarski.

39.4 Logika Orde Kedua Tidak Kompak

Sebut suatu himpunan kalimat  Γ dapat dipenuhi secara berhingga jika setiap himpunan bagian berhingganya dapat dipenuhi. Logika orde pertama mempunyai sifat bahwa jika suatu himpunan kalimat  Γ dapat dipenuhi secara berhingga, maka himpunan itu dapat dipenuhi. Sifat ini disebut kekompakan. Sifat ini mempunyai bentuk ekuivalen yang melibatkan perikutan: jika Γ ⊨ φ , maka sudah berlaku Γ 0 ⊨ φ untuk suatu himpunan bagian berhingga  Γ 0 ⊆ Γ . Dalam bentuk ini, sifat tersebut merupakan konsekuensi langsung dari teorema kelengkapan: sebab jika Γ ⊨ φ , berdasarkan kelengkapan Γ ⊢ φ . Namun, suatu derivasi hanya dapat menggunakan berhingga banyak kalimat dari  Γ .

Kekompakan tidak berlaku bagi logika orde kedua. Terdapat himpunan kalimat orde kedua yang dapat dipenuhi secara berhingga tetapi tidak dapat dipenuhi, dan yang memperikutkan suatu  φ tanpa ada himpunan bagian berhingga yang memperikutkan  φ .

Teorema 39.6.

Logika orde kedua tidak kompak.

Bukti.

Ingat bahwa Inf ≡ ∃ u ( ∀ x ∀ y ( u ( x ) = u ( y ) → x = y ) ∧ ∃ y ∀ x y ≠ u ( x ) ) dipenuhi dalam struktur jika dan hanya jika domainnya tak hingga. Misalkan φ ≥ n suatu kalimat yang menyatakan bahwa domain mempunyai sekurang-kurangnya n  anggota, misalnya, φ ≥ n ≡ ∃ x 1 … ∃ x n ( x 1 ≠ x 2 ∧ x 1 ≠ x 3 ∧ ⋯ ∧ x n − 1 ≠ x n ) . Tinjau himpunan kalimat Γ = { ¬ Inf , φ ≥ 1 , φ ≥ 2 , φ ≥ 3 , … } . Himpunan ini dapat dipenuhi secara berhingga, sebab untuk setiap himpunan bagian berhingga  Γ 0 ⊆ Γ terdapat suatu k ≥ 1 sedemikian sehingga setiap φ ≥ n ∈ Γ 0 mempunyai n ≤ k . Jika | 𝔐 | mempunyai k  anggota, maka 𝔐 ⊨ Γ 0 . Namun, Γ tidak dapat dipenuhi: jika 𝔐 ⊨ ¬ Inf , maka | 𝔐 | harus berhingga, katakanlah berukuran  k . Kemudian 𝔐 ⊭ φ ≥ k + 1 .

39.5 Teorema Löwenheim–Skolem Tidak Berlaku bagi Logika Orde Kedua

Teorema Löwenheim–Skolem (ke Bawah) menyatakan bahwa setiap himpunan kalimat yang mempunyai model tak hingga mempunyai model terhitung. Teorema ini pun merupakan konsekuensi dari teorema kelengkapan: pembuktian kelengkapan menghasilkan suatu model bagi setiap himpunan kalimat yang konsisten, dan model tersebut terhitung. Terdapat pula Teorema Löwenheim–Skolem ke Atas, yang menjamin bahwa jika suatu himpunan kalimat mempunyai model terbilang, maka himpunan itu juga mempunyai model takterhitung. Kedua teorema tersebut tidak berlaku dalam logika orde kedua.

Teorema 39.7.

Teorema Löwenheim–Skolem tidak berlaku bagi logika orde kedua: terdapat kalimat yang mempunyai model tak hingga, tetapi tidak mempunyai model terhitung.

Bukti.

Ingat bahwa Count ≡ ∃ z ∃ u ∀ X ( ( X ( z ) ∧ ∀ x ( X ( x ) → X ( u ( x ) ) ) ) → ∀ x X ( x ) ) benar dalam struktur  𝔐 jika dan hanya jika | 𝔐 | terhitung, sehingga ¬ Count benar dalam  𝔐 jika dan hanya jika | 𝔐 | takterhitung. Terdapat struktur semacam itu—ambil sembarang himpunan takterhitung sebagai domain, misalnya ℘ ( ℕ ) atau  ℝ . Jadi, ¬ Count mempunyai model tak hingga, tetapi tidak mempunyai model terhitung.

Teorema 39.8.

Terdapat kalimat yang mempunyai model terbilang, tetapi tidak mempunyai model takterhitung.

Bukti.

Count ∧ Inf benar dalam ℕ , tetapi tidak benar dalam struktur  𝔐 mana pun dengan | 𝔐 | takterhitung.

Soal

Soal 39.1.

Lengkapi pembuktian Proposisi 39.3.

Soal 39.2.

Berikan contoh suatu himpunan  Γ dan kalimat  φ sedemikian sehingga Γ ⊨ φ , tetapi untuk setiap himpunan bagian berhingga  Γ 0 ⊆ Γ , berlaku Γ 0 ⊭ φ .
