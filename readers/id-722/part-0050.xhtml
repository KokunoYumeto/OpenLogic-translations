40 Logika Orde Kedua dan Teori Himpunan

Bagian ini membahas pengodean himpunan kuasa dan kontinuum dalam logika orde kedua. Hasil-hasilnya telah dinyatakan, tetapi bukti-buktinya masih belum dilengkapi. Belum ada soal—dan definisi serta hasil itu sendiri mungkin bermasalah. Gunakan dengan hati-hati dan laporkan segala hal yang keliru atau tidak jelas.

40.1 Pendahuluan

Karena logika orde kedua dapat menguantifikasi atas himpunan-himpunan bagian domain maupun atas fungsi, dapat diduga bahwa setidaknya sebagian teori himpunan dapat dijalankan dalam logika orde kedua. Dengan “dijalankan,” yang kita maksud ialah bahwa sifat dan pernyataan teori himpunan dapat diungkapkan dalam logika orde kedua, dan hal itu dapat dilakukan tanpa kosakata nonlogis khusus untuk himpunan (misalnya, simbol predikat keanggotaan dalam teori himpunan). Sebagai contoh, kita dapat mendefinisikan gabungan dan irisan himpunan serta relasi himpunan bagian, tetapi juga membandingkan ukuran himpunan dan menyatakan hasil seperti Teorema Cantor.

40.2 Membandingkan Himpunan

Proposisi 40.1.

Formula ∀ x ( X ( x ) → Y ( x ) ) mendefinisikan relasi himpunan bagian, yakni 𝔐 , s ⊨ ∀ x ( X ( x ) → Y ( x ) ) jika dan hanya jika s ( X ) ⊆ s ( Y ) .

Proposisi 40.2.

Formula ∀ x ( X ( x ) ↔ Y ( x ) ) mendefinisikan relasi identitas pada himpunan, yakni 𝔐 , s ⊨ ∀ x ( X ( x ) ↔ Y ( x ) ) jika dan hanya jika s ( X ) = s ( Y ) .

Proposisi 40.3.

Formula ∃ x X ( x ) mendefinisikan sifat tidak kosong, yakni 𝔐 , s ⊨ ∃ x X ( x ) jika dan hanya jika s ( X ) ≠ ∅ .

Suatu himpunan  X tidak lebih besar daripada himpunan  Y , X ⪯ Y , jika dan hanya jika terdapat fungsi injektif f : X → Y . Karena kita dapat mengungkapkan bahwa suatu fungsi bersifat injektif, dan juga bahwa nilai-nilainya untuk argumen dalam  X berada dalam  Y , kita juga dapat mendefinisikan relasi tidak lebih besar daripada di antara himpunan-himpunan bagian domain.

Proposisi 40.4.

Formula ∃ u ( ∀ x ( X ( x ) → Y ( u ( x ) ) ) ∧ ∀ x ∀ y ( ( X ( x ) ∧ X ( y ) ∧ u ( x ) = u ( y ) ) → x = y ) ) mendefinisikan relasi tidak lebih besar daripada.

Dua himpunan berukuran sama, atau “berkardinalitas sama,” X ≈ Y , jika dan hanya jika terdapat fungsi bijektif  f : X → Y .

Proposisi 40.5.

Formula ∃ u ( ∀ x ( X ( x ) → Y ( u ( x ) ) ) ∧ ∀ x ∀ y ( ( X ( x ) ∧ X ( y ) ∧ u ( x ) = u ( y ) ) → x = y ) ∧ ∀ y ( Y ( y ) → ∃ x ( X ( x ) ∧ y = u ( x ) ) ) ) mendefinisikan relasi berkardinalitas sama.

Kita akan menyingkat formula ini, secara berturut-turut, sebagai X ⊆ Y , X = Y , X ≠ ∅ , X ⪯ Y , dan X ≈ Y . (Ini mungkin sedikit membingungkan karena kita menggunakan notasi yang sama ketika berbicara secara informal tentang himpunan X dan Y —tetapi di sini notasi tersebut merupakan singkatan bagi formula dalam logika orde kedua yang melibatkan variabel relasi satu-tempat X dan  Y .)

Proposisi 40.6.

Kalimat ∀ X ∀ Y ( ( X ⪯ Y ∧ Y ⪯ X ) → X ≈ Y ) valid.

Bukti.

Kalimat tersebut dipenuhi dalam struktur  𝔐 jika untuk sebarang himpunan bagian X ⊆ | 𝔐 | dan Y ⊆ | 𝔐 | , jika X ⪯ Y dan Y ⪯ X , maka X ≈ Y . Namun, hal ini berlaku bagi sebarang himpunan X dan Y —inilah Teorema Schröder–Bernstein.

40.3 Kardinalitas Himpunan

Sebagaimana kita dapat mengungkapkan bahwa domain berhingga atau tak hingga, terhitung atau takterhitung, kita dapat mendefinisikan sifat suatu himpunan bagian dari  | 𝔐 | sebagai berhingga atau tak hingga, terhitung atau takterhitung.

Proposisi 40.7.

Formula Inf ( X ) ≡ ∃ u ( ∀ x ∀ y ( ( X ( x ) ∧ X ( y ) ∧ u ( x ) = u ( y ) ) → x = y ) ∧ ∀ x ( X ( x ) → X ( u ( x ) ) ) ∧ ∃ y ( X ( y ) ∧ ∀ x ( X ( x ) → y ≠ u ( x ) ) ) dipenuhi relatif terhadap suatu penugasan variabel  s jika dan hanya jika s ( X ) tak hingga.

Proposisi 40.8.

Formula Count ( X ) ≡ ¬ ∃ x X ( x ) ∨ ∃ z ∃ u ( X ( z ) ∧ ∀ x ( X ( x ) → X ( u ( x ) ) ) ∧ ∀ Y ( ( Y ( z ) ∧ ∀ x ( Y ( x ) → Y ( u ( x ) ) ) ) → X ⊆ Y ) ) dipenuhi relatif terhadap suatu penugasan variabel  s jika dan hanya jika s ( X ) terhitung.

Kita mengetahui dari Teorema Cantor bahwa terdapat himpunan-himpunan takterhitung, dan bahkan terdapat tak hingga banyak tingkat ukuran tak hingga yang berbeda. Teori himpunan mengembangkan seluruh aritmetika ukuran himpunan dan menetapkan bilangan kardinal tak hingga kepada himpunan. Bilangan asli berperan sebagai bilangan kardinal yang mengukur ukuran himpunan hingga. Kardinalitas himpunan terbilang adalah kardinalitas tak hingga pertama, yang disebut  ℵ 0 (“alef-nol”). Ukuran tak hingga berikutnya ialah  ℵ 1 . Ini adalah ukuran terkecil yang dapat dimiliki suatu himpunan tanpa menjadi terhitung (yakni, tanpa berukuran  ℵ 0 ). Kita dapat mendefinisikan “ X berukuran ℵ 0 ” sebagai Aleph 0 ( X ) ↔ Inf ( X ) ∧ Count ( X ) . X berukuran ℵ 1 jika dan hanya jika semua himpunan bagiannya berhingga atau berukuran  ℵ 0 , tetapi himpunan itu sendiri tidak berukuran  ℵ 0 . Oleh karena itu, kita dapat mengungkapkan hal ini dengan formula Aleph 1 ( X ) ≡ Inf ( X ) ∧ ∀ Y ( Y ⊆ X → ( ¬ Inf ( Y ) ∨ Aleph 0 ( Y ) ) ) ∧ ¬ Aleph 0 ( X ) . Sifat berukuran ℵ 2 didefinisikan secara serupa, dan seterusnya.

Ada satu ukuran yang menarik perhatian secara khusus, yakni apa yang disebut kardinalitas kontinuum. Ukuran ini adalah ukuran ℘ ( ℕ ) , atau, secara ekuivalen, ukuran  ℝ . Bahwa suatu himpunan berkardinalitas kontinuum juga dapat diungkapkan dalam logika orde kedua, tetapi memerlukan sedikit lebih banyak upaya.

40.4 Kuasa Kontinuum

Dalam logika orde kedua kita dapat menguantifikasi atas himpunan-himpunan bagian domain, tetapi tidak atas himpunan yang terdiri atas himpunan-himpunan bagian domain. Untuk melakukannya secara langsung, kita memerlukan logika orde ketiga. Misalnya, jika kita ingin menyatakan Teorema Cantor bahwa tidak terdapat fungsi injektif dari himpunan kuasa suatu himpunan ke himpunan itu sendiri, kita dapat mencoba merumuskannya sebagai “untuk setiap himpunan  X dan setiap himpunan  P , jika P adalah himpunan kuasa dari  X , maka tidak berlaku P ⪯ X ”. Untuk mengatakan bahwa P adalah himpunan kuasa dari  X , kita perlu memformalkan bahwa anggota dari P tepat merupakan semua himpunan bagian dari  X , sehingga diperlukan sesuatu seperti ∀ Y ( P ( Y ) ↔ Y ⊆ X ) . Masalahnya terletak pada P ( Y ) : itu bukan formula logika orde kedua, karena hanya suku yang dapat menjadi argumen bagi variabel relasi satu-tempat seperti  P .

Namun, kita dapat menyimulasikan kuantifikasi atas himpunan yang beranggotakan himpunan jika domain cukup besar. Gagasannya ialah memanfaatkan fakta bahwa relasi dua-tempat  R menghubungkan anggota dari domain dengan anggota dari domain. Jika diberikan relasi  R semacam itu, kita dapat menghimpun semua anggota yang dengannya suatu  x berelasi menurut  R : { y ∈ | 𝔐 | : R ( x , y ) } adalah himpunan yang “dikodekan oleh”  x . Sebaliknya, jika Z ⊆ ℘ ( | 𝔐 | ) adalah suatu koleksi himpunan bagian dari  | 𝔐 | dan anggota dalam | 𝔐 | sekurang-kurangnya sama banyak dengan himpunan-himpunan dalam  Z , maka terdapat pula relasi  R ⊆ | 𝔐 | 2 sedemikian sehingga setiap Y ∈ Z dikodekan oleh suatu  x melalui  R .

Definisi 40.9.

Jika R ⊆ | 𝔐 | 2 , maka x mengodekan dengan  R { y ∈ | 𝔐 | : R ( x , y ) } .

Jika anggota  x ∈ | 𝔐 | mengodekan dengan  R suatu himpunan Z ⊆ | 𝔐 | , maka suatu himpunan Y ⊆ | 𝔐 | mengodekan himpunan yang terdiri atas himpunan-himpunan, yakni himpunan-himpunan yang dikodekan oleh anggota dari  Y . Jadi, himpunan Y dapat mengodekan dengan  R himpunan ℘ ( X ) . Hal itu terjadi jika dan hanya jika untuk setiap Z ⊆ X , suatu x ∈ Y mengodekan dengan  R himpunan  Z , dan setiap x ∈ Y mengodekan dengan  R suatu himpunan  Z ⊆ X .

Proposisi 40.10.

Formula Codes ( x , R , Z ) ≡ ∀ y ( Z ( y ) ↔ R ( x , y ) ) menyatakan bahwa s ( x ) mengodekan dengan  s ( R ) himpunan s ( Z ) . Formula Pow ( Y , R , X ) ≡ ∀ Z ( Z ⊆ X → ∃ x ( Y ( x ) ∧ Codes ( x , R , Z ) ) ) ∧ ∀ x ( Y ( x ) → ∀ Z ( Codes ( x , R , Z ) → Z ⊆ X ) ) menyatakan bahwa s ( Y ) mengodekan dengan  s ( R ) himpunan kuasa dari  s ( X ) , yakni anggota-anggota s ( Y ) mengodekan dengan  s ( R ) tepat himpunan-himpunan bagian dari s ( X ) .

Dengan siasat ini, kita dapat mengungkapkan pernyataan tentang himpunan kuasa dengan menguantifikasi atas kode-kode himpunan bagian alih-alih atas himpunan bagian itu sendiri. Misalnya, Teorema Cantor kini dapat diungkapkan dengan mengatakan bahwa tidak terdapat fungsi injektif dari domain sebarang relasi yang mengodekan himpunan kuasa dari  X ke  X sendiri.

Proposisi 40.11.

Kalimat ∀ X ∀ Y ∀ R ( Pow ( Y , R , X ) → ¬ ∃ u ( ∀ x ∀ y ( ( Y ( x ) ∧ Y ( y ) ∧ u ( x ) = u ( y ) ) → x = y ) ∧ ∀ x ( Y ( x ) → X ( u ( x ) ) ) ) ) valid.

Himpunan kuasa dari himpunan terbilang adalah takterhitung, sehingga kardinalitasnya lebih besar daripada kardinalitas sebarang himpunan terbilang (yaitu  ℵ 0 ). Ukuran ℘ ( ℕ ) disebut “kuasa dari kontinuum,” karena sama dengan ukuran himpunan titik-titik pada garis bilangan real,  ℝ . Jika domain cukup besar untuk mengodekan himpunan kuasa dari suatu himpunan terbilang, kita dapat mengungkapkan bahwa suatu himpunan berukuran sama dengan kontinuum dengan mengatakan bahwa himpunan itu berkardinalitas sama dengan sebarang himpunan  Y yang mengodekan himpunan kuasa dari suatu himpunan  X berukuran  ℵ 0 . (Jika domain tidak cukup besar, yakni tidak memuat himpunan bagian yang berkardinalitas sama dengan  ℝ , maka tidak mungkin pula ada relasi yang mengodekan  ℘ ( X ) .)

Proposisi 40.12.

Jika ℝ ⪯ | 𝔐 | , maka formula Cont ( Y ) ≡ ∃ X ∃ R ( ( Aleph 0 ( X ) ∧ Pow ( Y , R , X ) ) ∧ ∀ x ∀ y ( ( Y ( x ) ∧ Y ( y ) ∧ ∀ z R ( x , z ) ↔ R ( y , z ) ) → x = y ) ) menyatakan bahwa s ( Y ) ≈ ℝ .

Bukti.

Pow ( Y , R , X ) menyatakan bahwa s ( Y ) mengodekan dengan  s ( R ) himpunan kuasa dari  s ( X ) , yang menurut Aleph 0 ( X ) terhitung. Jadi, s ( Y ) sekurang-kurangnya sebesar kuasa kontinuum, meskipun mungkin lebih besar (jika beberapa anggota dari s ( Y ) mengodekan himpunan bagian yang sama dari  X ). Kemungkinan ini disingkirkan oleh konjung terakhir, yang mensyaratkan bahwa pengaitan antara anggota-anggota s ( Y ) dan himpunan-himpunan bagian dari s ( X ) melalui s ( R ) bersifat injektif.

Proposisi 40.13.

| 𝔐 | ≈ ℝ jika dan hanya jika 𝔐 ⊨ ∃ X ∃ Y ∃ R ( Aleph 0 ( X ) ∧ Pow ( Y , R , X ) ∧ ∃ u ( ∀ x ∀ y ( u ( x ) = u ( y ) → x = y ) ∧ ∀ y ( Y ( y ) ↔ ∃ x y = u ( x ) ) ) ) .

Hipotesis Kontinuum adalah pernyataan bahwa ukuran kontinuum merupakan kardinalitas takterhitung pertama, yakni bahwa ℘ ( ℕ ) berukuran  ℵ 1 .

Proposisi 40.14.

Hipotesis Kontinuum benar jika dan hanya jika CH ≡ ∀ X ( Aleph 1 ( X ) ↔ Cont ( X ) ) valid.

Perhatikan bahwa tidak benar bahwa ¬ CH valid jika dan hanya jika Hipotesis Kontinuum salah. Dalam domain yang terhitung, tidak terdapat himpunan bagian berukuran  ℵ 1 dan juga tidak terdapat himpunan bagian seukuran kontinuum, sehingga CH selalu benar dalam domain yang terhitung. Namun, kita dapat memberikan kalimat lain yang valid jika dan hanya jika Hipotesis Kontinuum salah:

Proposisi 40.15.

Hipotesis Kontinuum salah jika dan hanya jika NCH ≡ ∀ X ( Cont ( X ) → ∃ Y ( Y ⊆ X ∧ ¬ Count ( Y ) ∧ ¬ X ≈ Y ) ) valid.
