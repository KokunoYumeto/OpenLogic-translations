58 Pendahuluan

Penalaran Konstruktif

Berbeda dari perluasan logika klasik dengan operator modal atau kuantor orde kedua, logika intuisionistik bersifat “nonklasik” karena membatasi logika klasik. Logika klasik bersifat nonkonstruktif dalam berbagai hal. Logika intuisionistik dimaksudkan untuk menangkap jenis penalaran yang lebih “konstruktif”, yang menjadi ciri suatu bentuk matematika konstruktif. Contoh-contoh berikut dapat menggambarkan beberapa motivasi yang mendasarinya.

Andaikan seseorang mengaku telah menentukan suatu bilangan asli  n dengan sifat bahwa jika n genap, hipotesis Riemann benar, dan jika n ganjil, hipotesis Riemann salah. Kabar bagus! Benar atau tidaknya hipotesis Riemann merupakan salah satu pertanyaan terbuka besar dalam matematika, dan orang itu tampaknya telah mereduksi masalah tersebut menjadi masalah perhitungan, yakni menentukan apakah suatu bilangan tertentu genap atau bukan.

Berapakah nilai ajaib  n ? Orang itu menguraikannya sebagai berikut: n adalah bilangan asli yang sama dengan 2 jika hipotesis Riemann benar, dan 3 jika tidak.

Dengan marah, Anda menuntut uang Anda kembali. Dari sudut pandang klasik, uraian di atas memang menentukan satu nilai unik bagi n ; tetapi yang sesungguhnya Anda inginkan ialah nilai n yang diberikan secara eksplisit.

Sebagai contoh lain yang mungkin tidak terlalu dibuat-buat, pertimbangkan pertanyaan berikut. Kita tahu bahwa suatu bilangan irasional dapat dipangkatkan dengan bilangan rasional dan menghasilkan bilangan rasional. Misalnya, 2 2 = 2 . Yang kurang jelas ialah apakah suatu bilangan irasional dapat dipangkatkan dengan bilangan irasional dan menghasilkan bilangan rasional. Teorema berikut memberikan jawaban afirmatif:

Teorema 58.1.

Terdapat bilangan irasional a dan b sedemikian sehingga a b rasional.

Bukti.

Pertimbangkan 2 2 . Jika bilangan ini rasional, kita selesai: kita dapat mengambil a = b = 2 . Jika tidak, bilangan itu irasional. Selanjutnya, ( 2 2 ) 2 = 2 2 ⋅ 2 = 2 2 = 2 , yang rasional. Jadi, dalam kasus ini, ambil a sebagai 2 2 , dan ambil b sebagai  2 .

Apakah ini merupakan bukti yang valid? Kebanyakan matematikawan merasa demikian. Namun, sekali lagi, ada sesuatu yang agak tidak memuaskan di sini: kita telah membuktikan keberadaan sepasang bilangan real dengan sifat tertentu tanpa dapat mengatakan pasangan bilangan mana yang dimaksud. Hasil yang sama dapat dibuktikan dengan cara yang memberikan pasangan a , b di dalam bukti itu sendiri: ambil a = 3 dan b = log 3 ⁡ 4 . Maka a b = 3 log 3 ⁡ 4 = 3 1 / 2 ⋅ log 3 ⁡ 4 = ( 3 log 3 ⁡ 4 ) 1 / 2 = 4 1 / 2 = 2 , karena 3 log 3 ⁡ x = x .

Logika intuisionistik dirancang untuk menangkap jenis penalaran yang tidak memperbolehkan langkah seperti dalam bukti pertama. Membuktikan keberadaan suatu x yang memenuhi  φ ( x ) berarti kita harus memberikan suatu  x tertentu dan bukti bahwa nilai itu memenuhi  φ , seperti dalam bukti kedua. Membuktikan bahwa φ atau ψ berlaku mengharuskan kita dapat membuktikan salah satunya.

Secara formal, logika intuisionistik diperoleh dengan membatasi suatu sistem derivasi bagi logika klasik dengan cara tertentu. Dari sudut pandang matematis, semua itu hanyalah sistem deduktif formal, tetapi, sebagaimana telah dicatat, sistem-sistem tersebut dimaksudkan untuk menangkap suatu jenis penalaran matematis. Orang dapat menganggapnya sebagai jenis penalaran yang dibenarkan oleh pandangan filosofis tertentu tentang matematika (seperti intuisionisme Brouwer); orang dapat menganggapnya sebagai jenis penalaran matematis yang lebih “konkret” dan memuaskan (sejalan dengan konstruktivisme Bishop); dan orang dapat memperdebatkan apakah uraian formal tersebut menangkap motivasi informalnya. Namun, apa pun pendirian filosofis kita, kita dapat mengkaji logika intuisionistik sebagai logika yang disajikan secara formal; dan apa pun alasannya, banyak ahli logika matematika tertarik untuk melakukannya.

58.2 Sintaks Logika Intuisionistik

Sintaks logika intuisionistik sama dengan sintaks logika proposisional. Dalam logika proposisional klasik, suatu konektif dapat didefinisikan melalui konektif lain; misalnya, φ → ψ dapat didefinisikan sebagai ¬ φ ∨ ψ , atau φ ∨ ψ sebagai ¬ ( ¬ φ ∧ ¬ ψ ) . Karena itu, penyajian logika klasik sering memperkenalkan beberapa konektif sebagai singkatan bagi definisi-definisi tersebut. Hal ini tidak berlaku dalam logika intuisionistik, dengan dua pengecualian: ¬ φ dapat—dan sering kali memang—didefinisikan sebagai singkatan bagi φ → ⊥ . Dengan demikian, tentu saja, ⊥ sendiri tidak boleh didefinisikan! Selain itu, sebagaimana dalam logika klasik, φ ↔ ψ dapat didefinisikan sebagai ( φ → ψ ) ∧ ( ψ → φ ) .

Formula logika proposisional intuisionistik dibentuk dari variabel proposisi dan konstanta proposisional  ⊥ dengan menggunakan konektif logis. Kita mempunyai:

  1. terbilang himpunan  At 0 dari variabel proposisi 𝘱 0 , 𝘱 1 , …

  2. Konstanta proposisional untuk kepalsuan  ⊥ .

  3. Konektif logis: ∧ (konjungsi), ∨ (disjungsi), → (kondisional).

  4. Tanda baca: (, ), dan koma.

Definisi 58.2.

Formula

Himpunan  Frm ( ℒ 0 ) dari formula logika proposisional intuisionistik didefinisikan secara induktif sebagai berikut:

  1. ⊥ merupakan formula atomik.

  2. Setiap variabel proposisi  𝘱 i merupakan formula atomik.

  3. Jika φ dan ψ merupakan formula, maka ( φ ∧ ψ ) merupakan formula.

  4. Jika φ dan ψ merupakan formula, maka ( φ ∨ ψ ) merupakan formula.

  5. Jika φ dan ψ merupakan formula, maka ( φ → ψ ) merupakan formula.

  6. Tidak ada hal lain yang merupakan formula.

Selain konektif primitif yang diperkenalkan di atas, kita juga menggunakan simbol-simbol terdefinisi berikut: ¬ (negasi) dan ↔ (biimplikasi). Formula yang dibentuk menggunakan operator terdefinisi dipahami sebagai berikut:

  1. ¬ φ menyingkat φ → ⊥ .

  2. φ ↔ ψ menyingkat ( φ → ψ ) ∧ ( ψ → φ ) .

Meskipun ¬ secara resmi diperlakukan sebagai singkatan, kadang-kadang kita akan memberikan aturan dan klausa eksplisit dalam definisi bagi  ¬ seolah-olah simbol itu primitif. Tujuan utamanya ialah agar kita dapat merumuskan soal latihan.

58.3 Interpretasi Brouwer–Heyting–Kolmogorov

Bukti kesahihan proposisi intuisionistik dengan menggunakan interpretasi BHK membingungkan; bukti-bukti tersebut perlu dijelaskan dengan lebih baik.

Terdapat suatu interpretasi konstruktif informal bagi konektif intuisionistik, yang biasanya dikenal sebagai interpretasi Brouwer–Heyting–Kolmogorov. Interpretasi ini menggunakan gagasan “konstruksi”, yang dapat dipandang sebagai bukti konstruktif. (Kita tidak menggunakan istilah “bukti” dalam interpretasi BHK agar tidak tertukar dengan gagasan derivasi dalam suatu sistem derivasi formal.) Berdasarkan gagasan intuitif ini, interpretasi BHK menjelaskan makna konektif intuisionistik.

  1. Kita mengandaikan bahwa kita mengetahui apa yang membentuk suatu konstruksi bagi pernyataan atomik.

  2. Konstruksi bagi φ 1 ∧ φ 2 ialah pasangan ⟨ M 1 , M 2 ⟩ , dengan M 1 suatu konstruksi bagi  φ 1 dan M 2 suatu konstruksi bagi  φ 2 .

  3. Konstruksi bagi φ 1 ∨ φ 2 ialah pasangan ⟨ s , M ⟩ , dengan s bernilai  1 dan M suatu konstruksi bagi  φ 1 , atau s bernilai  2 dan M suatu konstruksi bagi  φ 2 .

  4. Konstruksi bagi φ → ψ ialah fungsi yang mengubah suatu konstruksi bagi  φ menjadi konstruksi bagi  ψ .

  5. Tidak ada konstruksi bagi  ⊥ (absurditas).

  6. ¬ φ didefinisikan sebagai sinonim bagi φ → ⊥ . Artinya, konstruksi bagi ¬ φ ialah fungsi yang mengubah suatu konstruksi bagi  φ menjadi konstruksi bagi  ⊥ .

Contoh 58.3.

Sebagai contoh, ambillah ¬ ⊥ . Suatu konstruksi baginya ialah fungsi yang, ketika menerima sebarang konstruksi bagi ⊥ sebagai masukan, menghasilkan konstruksi bagi  ⊥ sebagai keluaran. Jelaslah bahwa fungsi identitas  Id merupakan konstruksi semacam itu: jika diberi suatu konstruksi  M bagi  ⊥ , maka Id ( M ) = M menghasilkan konstruksi bagi  ⊥ .

Secara umum, ¬ φ berarti “Konstruksi bagi φ mustahil.”

Contoh 58.4.

Mari kita buktikan φ → ¬ ¬ φ bagi sebarang proposisi  φ , yakni φ → ( ( φ → ⊥ ) → ⊥ ) . Konstruksinya harus berupa fungsi  f yang, ketika diberi konstruksi  M bagi φ , mengembalikan konstruksi  f ( M ) bagi ( φ → ⊥ ) → ⊥ . Berikut cara  f membangun konstruksi bagi ( φ → ⊥ ) → ⊥ : Kita harus mendefinisikan fungsi g yang, ketika diberi konstruksi  h bagi φ → ⊥ sebagai masukan, menghasilkan konstruksi bagi  ⊥ . Kita dapat mendefinisikan g sebagai berikut: terapkan masukan  h pada konstruksi  M bagi φ (yang telah kita terima sebelumnya). Karena keluaran  h ( M ) dari h merupakan konstruksi bagi ⊥ , maka f ( M ) ( h ) = h ( M ) merupakan konstruksi bagi  ⊥ jika M merupakan konstruksi bagi  φ .

Contoh 58.5.

Mari kita berikan konstruksi bagi ¬ ( φ ∧ ¬ φ ) , yakni ( φ ∧ ( φ → ⊥ ) ) → ⊥ . Konstruksi ini merupakan fungsi  f yang, ketika diberi konstruksi  M bagi φ ∧ ( φ → ⊥ ) sebagai masukan, menghasilkan konstruksi bagi  ⊥ . Konstruksi bagi konjungsi ψ 1 ∧ ψ 2 ialah pasangan ⟨ N 1 , N 2 ⟩ , dengan N 1 suatu konstruksi bagi  ψ 1 dan N 2 suatu konstruksi bagi  ψ 2 . Kita dapat mendefinisikan fungsi p 1 dan p 2 yang, dari suatu konstruksi bagi ψ 1 ∧ ψ 2 , masing-masing mengambil kembali konstruksi bagi ψ 1 dan ψ 2 : p 1 ( ⟨ N 1 , N 2 ⟩ ) = N 1 p 2 ( ⟨ N 1 , N 2 ⟩ ) = N 2 Berikut yang dilakukan f : Mula-mula, fungsi itu menerapkan p 1 pada masukannya  M . Hasilnya ialah suatu konstruksi bagi  φ . Kemudian fungsi itu menerapkan p 2 pada  M , sehingga menghasilkan konstruksi bagi φ → ⊥ . Konstruksi semacam itu sendiri merupakan fungsi  p 2 ( M ) yang, jika diberi konstruksi bagi  φ sebagai masukan, menghasilkan konstruksi bagi  ⊥ . Dengan kata lain, jika kita menerapkan p 2 ( M ) pada p 1 ( M ) , kita memperoleh konstruksi bagi  ⊥ . Jadi, kita dapat mendefinisikan f ( M ) = p 2 ( M ) ( p 1 ( M ) ) .

Contoh 58.6.

Mari kita berikan konstruksi bagi ( ( φ ∧ ψ ) → χ ) → ( φ → ( ψ → χ ) ) , yakni suatu fungsi f yang mengubah konstruksi  g bagi ( φ ∧ ψ ) → χ menjadi konstruksi bagi ( φ → ( ψ → χ ) ) . Konstruksi g sendiri merupakan fungsi (dari konstruksi bagi φ ∧ ψ ke konstruksi bagi  χ ). Keluaran f ( g ) ialah fungsi  h g dari konstruksi bagi φ ke fungsi dari konstruksi bagi  ψ ke konstruksi bagi  χ .

Baiklah, ini membingungkan. Kita harus membangun fungsi tertentu  h g , yang akan menjadi keluaran f bagi masukan  g . Masukan bagi  h g ialah konstruksi  M bagi  φ . Keluaran h g ( M ) seharusnya berupa fungsi  k g , M dari konstruksi  N bagi  ψ ke konstruksi bagi  χ . Tetapkan k g , M ( N ) = g ( ⟨ M , N ⟩ ) . Ingat bahwa ⟨ M , N ⟩ merupakan konstruksi bagi  φ ∧ ψ . Jadi, k g , M merupakan konstruksi bagi ψ → χ : fungsi ini memetakan konstruksi  N bagi  ψ ke konstruksi bagi  χ . Sekarang tetapkan h g ( M ) = k g , M . Ini merupakan fungsi yang memetakan konstruksi  M bagi  φ ke konstruksi k g , M bagi ψ → χ . Terakhir, tetapkan f ( g ) = h g . Ini merupakan fungsi yang memetakan konstruksi g bagi ( φ ∧ ψ ) → χ ke konstruksi bagi φ → ( ψ → χ ) . Fiuh!

Pernyataan φ ∨ ¬ φ disebut Hukum Tiada Jalan Tengah. Kita dapat membuktikannya bagi beberapa φ tertentu (misalnya, ⊥ ∨ ¬ ⊥ ), tetapi tidak secara umum. Alasannya ialah bahwa disjungsi intuisionistik memerlukan konstruksi bagi salah satu disjungnya, sedangkan ada pernyataan yang saat ini belum dapat dibuktikan ataupun disangkal (misalnya, konjektur Goldbach). Akan tetapi, hukum tiada jalan tengah juga tidak dapat Anda sangkal: yakni, ¬ ¬ ( φ ∨ ¬ φ ) berlaku.

Contoh 58.7.

Untuk membuktikan ¬ ¬ ( φ ∨ ¬ φ ) , kita memerlukan fungsi  f yang mengubah konstruksi bagi ¬ ( φ ∨ ¬ φ ) , yakni bagi ( φ ∨ ( φ → ⊥ ) ) → ⊥ , menjadi konstruksi bagi  ⊥ . Dengan kata lain, kita memerlukan fungsi f sedemikian sehingga f ( g ) merupakan konstruksi bagi  ⊥ jika g merupakan konstruksi bagi ¬ ( φ ∨ ¬ φ ) .

Andaikan g merupakan konstruksi bagi ¬ ( φ ∨ ¬ φ ) , yakni fungsi yang mengubah konstruksi bagi φ ∨ ¬ φ menjadi konstruksi bagi  ⊥ . Konstruksi bagi φ ∨ ¬ φ ialah pasangan ⟨ s , M ⟩ , dengan s = 1 dan M suatu konstruksi bagi φ , atau s = 2 dan M suatu konstruksi bagi ¬ φ . Misalkan h 1 ialah fungsi yang memetakan konstruksi  M 1 bagi φ ke konstruksi bagi φ ∨ ¬ φ : fungsi ini memetakan M 1 ke ⟨ 1 , M 1 ⟩ . Misalkan pula h 2 ialah fungsi yang memetakan konstruksi  M 2 bagi ¬ φ ke konstruksi bagi φ ∨ ¬ φ : fungsi ini memetakan M 2 ke ⟨ 2 , M 2 ⟩ .

Misalkan k adalah g ∘ h 1 : ini merupakan fungsi yang, jika diberi konstruksi bagi  φ , mengembalikan konstruksi bagi  ⊥ ; jadi, fungsi ini merupakan konstruksi bagi  φ → ⊥ atau ¬ φ . Sekarang misalkan l adalah g ∘ h 2 . Ini merupakan fungsi yang, jika diberi konstruksi bagi ¬ φ , menghasilkan konstruksi bagi  ⊥ . Karena k merupakan konstruksi bagi ¬ φ , maka l ( k ) merupakan konstruksi bagi  ⊥ .

Secara keseluruhan, yang telah kita lakukan ialah menguraikan cara mengubah konstruksi  g bagi ¬ ( φ ∨ ¬ φ ) menjadi konstruksi bagi  ⊥ ; yakni, fungsi f yang memetakan konstruksi  g bagi ¬ ( φ ∨ ¬ φ ) ke konstruksi l ( k ) bagi  ⊥ merupakan konstruksi bagi ¬ ¬ ( φ ∨ ¬ φ ) .

Sebagaimana dapat Anda lihat, penggunaan interpretasi BHK untuk menunjukkan kesahihan intuisionistik formula dengan cepat menjadi rumit dan membingungkan. Untunglah, terdapat sistem derivasi yang lebih baik bagi logika intuisionistik, serta interpretasi semantik yang lebih tepat.

58.4 Deduksi Alami

Deduksi alami tanpa aturan ⊥ C merupakan sistem derivasi baku bagi logika intuisionistik. Kita mengulangi aturan-aturannya di sini dan menjelaskan motivasinya dengan menggunakan interpretasi BHK. Dalam setiap kasus, kita dapat memandang suatu aturan sebagai aturan yang memungkinkan kita menyimpulkan bahwa jika premis-premisnya mempunyai konstruksi, kesimpulannya juga mempunyai konstruksi.

Karena derivasi deduksi alami mempunyai asumsi yang belum dilepaskan, kita sebaiknya memandang derivasi semacam itu, misalnya derivasi φ dari asumsi belum dilepaskan  Γ , sebagai fungsi yang mengubah konstruksi bagi semua ψ ∈ Γ menjadi konstruksi bagi  φ . Jika terdapat derivasi bagi  φ tanpa asumsi belum dilepaskan, maka terdapat konstruksi bagi  φ dalam pengertian interpretasi BHK. Namun, untuk keperluan pembahasan, kita akan menghilangkan  Γ jika tidak diperlukan.

Suatu asumsi  φ sendiri merupakan derivasi bagi  φ dari asumsi belum dilepaskan  φ . Hal ini sesuai dengan interpretasi BHK: fungsi identitas pada konstruksi mengubah setiap konstruksi bagi  φ menjadi konstruksi bagi  φ .

Konjungsi

[struktur 382] φ ψ φ ∧ ψ ∧ Intro

 

[struktur 383] φ ∧ ψ φ ∧ Elim

[struktur 384] φ ∧ ψ ψ ∧ Elim

Andaikan kita mempunyai konstruksi N 1 , N 2 masing-masing bagi φ 1 dan φ 2 . Dengan demikian, kita juga mempunyai konstruksi bagi φ 1 ∧ φ 2 , yakni pasangan ⟨ N 1 , N 2 ⟩ .

Menurut interpretasi BHK, konstruksi bagi φ 1 ∧ φ 2 ialah pasangan ⟨ N 1 , N 2 ⟩ . Jadi, andaikan kita mempunyai pasangan semacam itu. Kita pun mempunyai konstruksi bagi setiap konjung: N 1 merupakan konstruksi bagi  φ 1 , dan N 2 merupakan konstruksi bagi φ 2 .

Kondisional

[struktur 385] u [ φ ] u ⋮ ψ φ → ψ → Intro

 

[struktur 386] φ → ψ φ ψ → Elim

Jika kita mempunyai derivasi bagi  ψ dari asumsi belum dilepaskan  φ , terdapat fungsi  f yang mengubah konstruksi bagi  φ menjadi konstruksi bagi  ψ . Fungsi yang sama merupakan konstruksi bagi φ → ψ . Jadi, jika premis → Intro mempunyai konstruksi yang bergantung pada suatu konstruksi bagi  φ , kesimpulan φ → ψ mempunyai konstruksi.

Sebaliknya, andaikan terdapat konstruksi  N bagi φ dan f bagi φ → ψ . Konstruksi bagi φ → ψ ialah fungsi yang mengubah konstruksi bagi φ menjadi konstruksi bagi  ψ . Jadi, f ( N ) merupakan konstruksi bagi  ψ ; yakni, kesimpulan → Elim mempunyai konstruksi.

Disjungsi

[struktur 387] φ φ ∨ ψ ∨ Intro

[struktur 388] ψ φ ∨ ψ ∨ Intro

 

[struktur 389] n φ ∨ ψ [ φ ] n ⋮ χ [ ψ ] n ⋮ χ χ ∨ Elim

Jika kita mempunyai konstruksi  N i bagi  φ i , kita dapat mengubahnya menjadi konstruksi  ⟨ i , N i ⟩ bagi  φ 1 ∨ φ 2 . Sebaliknya, andaikan kita mempunyai konstruksi bagi  φ 1 ∨ φ 2 , yakni pasangan ⟨ i , N i ⟩ dengan N i suatu konstruksi bagi  φ i , serta fungsi f 1 , f 2 yang masing-masing mengubah konstruksi bagi φ 1 , φ 2 menjadi konstruksi bagi  χ . Maka f i ( N i ) merupakan konstruksi bagi  χ , yakni kesimpulan dari  ∨ Elim .

Absurditas

[struktur 390] ⊥ φ ⊥ I

Jika kita mempunyai derivasi bagi  ⊥ dari asumsi belum dilepaskan  ψ 1 , …, ψ n , maka terdapat fungsi  f ( M 1 , … , M n ) yang mengubah konstruksi bagi ψ 1 , …, ψ n menjadi konstruksi bagi  ⊥ . Karena ⊥ tidak mempunyai konstruksi, konstruksi bagi semua ψ 1 , …, ψ n juga tidak mungkin ada. Oleh karena itu, f juga mempunyai sifat bahwa jika M 1 , …, M n masing-masing merupakan konstruksi bagi ψ 1 , …, ψ n , maka f ( M 1 , … , M n ) merupakan konstruksi bagi  φ .

Aturan untuk ¬

Karena ¬ φ didefinisikan sebagai φ → ⊥ , secara ketat kita tidak memerlukan aturan bagi  ¬ . Namun, seandainya kita menggunakannya, aturan tersebut berbentuk sebagai berikut:

Proposisi 58.8.

Jika Γ ⊢ φ dalam deduksi alami bagi logika intuisionistik, maka Γ ⊢ φ dalam logika klasik. Khususnya, jika φ merupakan teorema intuisionistik, formula itu juga merupakan teorema klasik.

Bukti.

Setiap aturan deduksi alami juga merupakan aturan dalam deduksi alami klasik, sehingga setiap derivasi dalam logika intuisionistik juga merupakan derivasi dalam logika klasik.

58.5 Derivasi Aksiomatik

derivasi aksiomatik bagi logika proposisional intuisionistik merupakan sistem derivasi yang paling sederhana secara konseptual dan yang pertama secara historis. Sistem ini bekerja tepat seperti dalam logika proposisional klasik.

Definisi 58.9.

Keterderivasian

Jika Γ merupakan himpunan formula dari ℒ , maka suatu derivasi dari Γ ialah urutan berhingga φ 1 , …,   φ n dari formula sedemikian sehingga, bagi setiap i ≤ n , salah satu dari hal berikut berlaku:

  1. φ i ∈ Γ ; atau

  2. φ i merupakan suatu aksioma; atau

  3. φ i diperoleh dari suatu φ j dan φ k , dengan j < i dan k < i , melalui modus ponens; yakni, φ k ≡ φ j → φ i .

Definisi 58.10.

Aksioma

Himpunan  Ax 0 dari aksioma bagi logika proposisional intuisionistik terdiri atas semua formula dalam bentuk-bentuk berikut: ( φ ∧ ψ ) → φ ( φ ∧ ψ ) → ψ φ → ( ψ → ( φ ∧ ψ ) ) φ → ( φ ∨ ψ ) φ → ( ψ ∨ φ ) ( φ → χ ) → ( ( ψ → χ ) → ( ( φ ∨ ψ ) → χ ) ) φ → ( ψ → φ ) ( φ → ( ψ → χ ) ) → ( ( φ → ψ ) → ( φ → χ ) ) ⊥ → φ

Definisi 58.11.

Keterderivasian

formula  φ dapat diturunkan dari Γ , ditulis Γ ⊢ φ , jika terdapat derivasi dari Γ yang berakhir pada φ .

Definisi 58.12.

Teorema

formula  φ merupakan teorema jika terdapat derivasi bagi  φ dari himpunan kosong. Kita menulis ⊢ φ jika φ merupakan teorema, dan ⊬ φ jika bukan.

Proposisi 58.13.

Jika Γ ⊢ φ dalam sistem derivasi aksiomatik bagi logika intuisionistik, maka Γ ⊢ φ juga dalam logika klasik. Khususnya, jika φ merupakan teorema intuisionistik, formula itu juga merupakan teorema klasik.

Bukti.

Setiap aksioma intuisionistik juga merupakan aksioma klasik, sehingga setiap derivasi dalam logika intuisionistik juga merupakan derivasi dalam logika klasik.

Soal

Soal 58.1.

Berikan derivasi dalam logika intuisionistik bagi formula berikut:

  1. ( ¬ φ ∨ ψ ) → ( φ → ψ )

  2. ¬ ¬ ¬ φ → ¬ φ

  3. ¬ ¬ ( φ ∧ ψ ) ↔ ( ¬ ¬ φ ∧ ¬ ¬ ψ )

  4. ¬ ( φ ∨ ψ ) ↔ ( ¬ φ ∧ ¬ ψ )

  5. ( ¬ φ ∨ ¬ ψ ) → ¬ ( φ ∧ ψ )

  6. ¬ ¬ ( φ ∧ ψ ) → ( ¬ ¬ φ ∨ ¬ ¬ ψ )

Bentuk terstruktur derivasi dalam bacaan ini

Bagian ini menyajikan kembali susunan diagram sumber untuk navigasi tanpa tata letak pohon. “Lihat bagian n” menunjuk bagian diagram yang tercantum dalam daftar, bukan simbol matematika baru. Bagian atas, bagian bawah, serta label kiri dan kanan dipertahankan. Susunan tanpa garis dan dengan dua garis diberi keterangan tersendiri; tidak diasumsikan sebagai aturan inferensi biasa. Teks dan diagram sumber tidak diubah.
