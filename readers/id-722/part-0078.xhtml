62 Pendahuluan

62.1 Kondisional Material

Dalam bentuknya yang paling sederhana, kondisional dalam bahasa Indonesia adalah kalimat berbentuk “Jika …, maka …,” dengan bagian-bagian yang ditunjukkan oleh … itu sendiri merupakan kalimat, seperti “Jika kepala pelayan yang melakukannya, maka tukang kebun tidak bersalah.” Dalam kuliah logika pengantar, kita belajar menyimbolkan kondisional dengan menggunakan konektif  → : bagian-bagian yang ditunjukkan oleh … disimbolkan, misalnya, dengan formula  φ dan  ψ , lalu seluruh kondisional disimbolkan dengan φ → ψ .

Konektif  → bersifat fungsional-kebenaran, yakni nilai kebenaran— 𝕋 atau 𝔽 —dari φ → ψ ditentukan oleh nilai kebenaran φ dan  ψ : φ → ψ benar jika dan hanya jika φ salah atau ψ benar, dan salah dalam keadaan lainnya. Secara relatif terhadap suatu penetapan nilai kebenaran  𝔳 , kita mendefinisikan 𝔳 ⊨ φ → ψ jika dan hanya jika 𝔳 ⊭ φ atau 𝔳 ⊨ ψ . Konektif  → dengan semantik ini disebut kondisional material.

Definisi ini menghasilkan sejumlah fakta logis dasar. Pertama-tama, teorema deduksi berlaku bagi kondisional material: Jika  Γ , φ ⊨ ψ , maka  Γ ⊨ φ → ψ Kondisional ini bersifat fungsional-kebenaran: φ → ψ dan ¬ φ ∨ ψ ekuivalen: φ → ψ ⊨ ¬ φ ∨ ψ ¬ φ ∨ ψ ⊨ φ → ψ Kondisional material diikutkan oleh konsekuennya dan oleh negasi antesedennya: ψ ⊨ φ → ψ ¬ φ ⊨ φ → ψ Kondisional material yang salah ekuivalen dengan konjungsi antesedennya dan negasi konsekuennya: jika  φ → ψ  salah, maka  φ ∧ ¬ ψ  benar, dan sebaliknya: ¬ ( φ → ψ ) ⊨ φ ∧ ¬ ψ φ ∧ ¬ ψ ⊨ ¬ ( φ → ψ ) Kondisional material mendukung modus ponens: φ , φ → ψ ⊨ ψ Kondisional material memungkinkan aglomerasi: φ → ψ , φ → χ ⊨ φ → ( ψ ∧ χ ) Kita selalu dapat memperkuat anteseden; yakni, kondisional tersebut  𝑚𝑜𝑛𝑜𝑡𝑜𝑛 : φ → ψ ⊨ ( φ ∧ χ ) → ψ Kondisional material bersifat transitif; yakni, aturan rantai valid: φ → ψ , ψ → χ ⊨ φ → χ Kondisional material ekuivalen dengan kontraposisinya: φ → ψ ⊨ ¬ ψ → ¬ φ ¬ ψ → ¬ φ ⊨ φ → ψ

Semua inferensi ini berguna dan tidak bermasalah dalam penalaran matematis. Namun, literatur filsafat dan linguistik penuh dengan contoh tandingan yang dikemukakan terhadap inferensi-inferensi sepadan dalam konteks nonmatematis. Contoh-contoh tersebut menyiratkan bahwa kondisional material  → bukan—atau setidaknya tidak selalu merupakan—konektif yang tepat untuk digunakan ketika menyimbolkan pernyataan bahasa alamiah berbentuk “jika …, maka ….”

62.2 Paradoks Kondisional Material

Salah seorang yang pertama mengkritik penggunaan φ → ψ sebagai cara menyimbolkan pernyataan kondisional berbentuk “jika …, maka …” ialah C. I. Lewis. Lewis mengkritik penggunaan kondisional material dalam Principia Mathematica karya Whitehead dan Russell, yang melafalkan → sebagai “mengimplikasikan.” Lewis dengan tepat mengeluhkan bahwa jika → berarti “mengimplikasikan,” maka setiap proposisi salah  p mengimplikasikan bahwa p mengimplikasikan  q , karena p → ( p → q ) benar jika  p salah; dan setiap proposisi benar  q mengimplikasikan bahwa p mengimplikasikan  q , karena q → ( p → q ) benar jika  q benar.

Para ahli logika tentu mengetahui bahwa implikasi, yakni perikutan logis, bukanlah konektif, melainkan relasi antara formula atau pernyataan. Karena itu, untuk menghindari kebingungan, kita sebaiknya tidak membaca → sebagai “mengimplikasikan.”19 Selama kita tidak membacanya demikian, kekhawatiran khusus Lewis sama sekali tidak muncul: p tidak “mengimplikasikan” q sekalipun kita menganggap p mewakili suatu kalimat bahasa alamiah yang salah. Untuk menentukan apakah p ⊨ q , kita harus mempertimbangkan semua valuasi; dan p ⊭ q bahkan ketika kita menggunakan p untuk menyimbolkan suatu kalimat yang kebetulan salah.

Namun, tetap ada sesuatu yang ganjil tentang pernyataan “jika …, maka …” seperti contoh Lewis berikut:

Jika bulan terbuat dari keju hijau, maka 2 + 2 = 4 .

dan tentang inferensi-inferensi berikut:

Bulan tidak terbuat dari keju hijau. Oleh karena itu, jika bulan terbuat dari keju hijau, maka 2 + 2 = 4 .

2 + 2 = 4 . Oleh karena itu, jika bulan terbuat dari keju hijau, maka 2 + 2 = 4 .

Namun, jika “jika …, maka …” hanyalah → , kalimat tersebut benar tanpa masalah dan inferensi-inferensi itu valid tanpa masalah.

Contoh lainnya menyangkut tautologi ( φ → ψ ) ∨ ( ψ → φ ) . Hal ini menyiratkan bahwa jika Anda mengambil secara acak dua kalimat indikatif  S dan  T dari surat kabar, kalimat “Jika S , maka T , atau jika T , maka  S ” seharusnya benar.

62.3 Kondisional Ketat

Lewis memperkenalkan kondisional ketat  ⥽ dan berpendapat bahwa kondisional inilah, bukan kondisional material, yang bersesuaian dengan implikasi. Dalam logika modal aletik, φ ⥽ ψ dapat didefinisikan sebagai ◻ ( φ → ψ ) . Jadi, suatu kondisional ketat benar (pada suatu dunia) jika dan hanya jika kondisional material yang bersesuaian bersifat niscaya.

Bagaimana kondisional ketat menghadapi paradoks-paradoks kondisional material? Kondisional ketat dengan anteseden yang salah, maupun kondisional ketat dengan konsekuen yang benar, mungkin benar atau mungkin salah. Selain itu, ( φ ⥽ ψ ) ∨ ( ψ ⥽ φ ) tidak valid. Kondisional ketat φ ⥽ ψ juga tidak ekuivalen dengan ¬ φ ∨ ψ ; jadi, kondisional itu tidak bersifat fungsional-kebenaran.

Kita mempunyai: φ ⥽ ψ ⊨ ¬ φ ∨ ψ tetapi: ¬ φ ∨ ψ ⊭ φ ⥽ ψ ψ ⊭ φ ⥽ ψ ¬ φ ⊭ φ ⥽ ψ ¬ ( φ ⥽ ψ ) ⊭ φ ∧ ¬ ψ tetapi: φ ∧ ¬ ψ ⊨ ¬ ( φ ⥽ ψ ) Namun, kondisional ketat tetap mendukung modus ponens: φ , φ ⥽ ψ ⊨ ψ Kondisional ketat memungkinkan aglomerasi: φ ⥽ ψ , φ ⥽ χ ⊨ φ ⥽ ( ψ ∧ χ ) Penguatan anteseden berlaku bagi kondisional ketat: φ ⥽ ψ ⊨ ( φ ∧ χ ) ⥽ ψ Kondisional ketat juga bersifat transitif: φ ⥽ ψ , ψ ⥽ χ ⊨ φ ⥽ χ Akhirnya, kondisional ketat ekuivalen dengan kontraposisinya: φ ⥽ ψ ⊨ ¬ ψ ⥽ ¬ φ ¬ ψ ⥽ ¬ φ ⊨ φ ⥽ ψ

Namun, kondisional ketat tetap mempunyai “paradoksnya” sendiri. Sebagaimana kondisional material dengan anteseden salah atau konsekuen benar adalah benar, kondisional ketat dengan anteseden yang niscaya salah atau konsekuen yang niscaya benar adalah benar. Selain itu, setiap kondisional ketat yang benar bersifat niscaya benar, dan setiap kondisional ketat yang salah bersifat niscaya salah. Dengan kata lain, kita mempunyai ◻ ¬ φ ⊨ φ ⥽ ψ ◻ ψ ⊨ φ ⥽ ψ φ ⥽ ψ ⊨ ◻ ( φ ⥽ ψ ) ¬ ( φ ⥽ ψ ) ⊨ ◻ ¬ ( φ ⥽ ψ ) Hal-hal ini bukan masalah jika Anda memandang ⥽ sebagai “mengimplikasikan.” Bagaimanapun, relasi perikutan logis merupakan fakta matematis sehingga tidak mungkin bersifat kontingen. Namun, hal-hal tersebut memang menimbulkan persoalan jika Anda hendak menggunakan ⥽ sebagai konektif logis yang dimaksudkan untuk menangkap “jika …, maka …,” terutama dua yang terakhir. Tentulah ada pernyataan “jika …, maka …” yang benar secara kontingen atau salah secara kontingen—bahkan, pernyataan semacam itu pada umumnya tidak niscaya maupun mustahil.

62.4 Kondisional Kontrafaktual

Salah satu bentuk konstruksi “jika …maka …” yang sangat umum dan penting dalam bahasa Inggris dibentuk dengan memakai bentuk subjungtif lampau dari verba Inggris to be (“menjadi/berada”): “seandainya keadaannya …maka keadaannya akan ….” Karena biasanya anteseden kondisional semacam ini salah, yakni bertentangan dengan fakta, konstruksi itu disebut kondisional kontrafaktual (dan karena memakai bentuk subjungtif dari to be (“menjadi/berada”), juga disebut kondisional subjungtif). Kondisional tersebut dibedakan dari kondisional indikatif, yang berbentuk “jika keadaannya …maka keadaannya ….” Kondisional kontrafaktual dan indikatif mempunyai syarat kebenaran yang berbeda. Perhatikan contoh terkenal dari Adams:

Jika bukan Oswald yang membunuh Kennedy, orang lainlah yang melakukannya.

Seandainya Oswald tidak membunuh Kennedy, orang lain tentu akan melakukannya.

Kalimat pertama bersifat indikatif, sedangkan kalimat kedua kontrafaktual. Kalimat pertama jelas benar: kita tahu bahwa Presiden John F. Kennedy dibunuh oleh seseorang; dan jika orang itu bukan Lee Harvey Oswald (berlawanan dengan Laporan Warren), maka orang lainlah yang membunuh Kennedy. Kalimat kedua menyatakan sesuatu yang berbeda. Kalimat itu mengklaim bahwa seandainya Oswald tidak membunuh Kennedy—yakni, seandainya penembakan di Dallas dapat dihindari atau tidak berhasil—sejarah kemudian akan berlangsung sedemikian rupa sehingga percobaan pembunuhan lain akan berhasil. Agar kalimat itu benar, haruslah ada kekuatan-kekuatan besar yang bersekongkol untuk memastikan kematian JFK (sebagaimana diyakini oleh banyak penganut teori konspirasi JFK).

Masih menjadi perdebatan apakah kondisional indikatif ditangkap secara tepat oleh kondisional material, khususnya apakah paradoks-paradoks kondisional material dapat “dijelaskan” dengan cara yang sesuai dengan pandangan bahwa kondisional material memberikan syarat kebenaran bagi kondisional indikatif dalam bahasa Inggris. Sebaliknya, tidak diperdebatkan bahwa kondisional kontrafaktual tidak dapat dilambangkan secara tepat dengan kondisional material. Hal ini jelas karena, meskipun anteseden kontrafaktual pada umumnya salah, tidak semua kontrafaktual dengan anteseden salah bernilai benar—jika Anda memercayai Laporan Warren dan tidak ada persekongkolan untuk membunuh JFK, maka kondisional kontrafaktual Adams di atas merupakan salah satu contohnya.

Kondisional kontrafaktual berperan penting dalam penalaran kausal: salah satu contoh utama penggunaan kontrafaktual ialah untuk mengungkapkan hubungan sebab-akibat. Sebagai contoh, menggesek sebatang korek api menyebabkannya menyala, dan hal ini dapat diungkapkan dengan mengatakan “seandainya korek api ini digesek, korek ini akan menyala.” Kondisional material, dan kondisional indikatif pada umumnya, tidak dapat dipakai untuk mengungkapkan hal ini: “korek api digesek → korek api menyala” bernilai benar jika korek api tidak pernah digesek, terlepas dari apa yang akan terjadi jika korek itu digesek. Lebih buruk lagi, “korek api digesek → korek api berubah menjadi seikat bunga” juga bernilai benar jika korek itu tidak pernah digesek, padahal korek api tentu tidak akan berubah menjadi seikat bunga jika digesek.

Masih diperdebatkan apa tepatnya logika yang benar bagi kontrafaktual. Suatu analisis kontrafaktual yang berpengaruh diberikan oleh Stalnaker dan Lewis. Menurut mereka, kontrafaktual “seandainya  S maka  T ” bernilai benar jika dan hanya jika T benar dalam situasi kontrafaktual (“dunia mungkin”) yang paling dekat dengan keadaan dunia aktual dan tempat  S benar. Analisis ini disebut analisis “ontik” karena mengacu pada suatu ontologi dunia mungkin. Analisis-analisis lain memakai probabilitas bersyarat atau teori revisi keyakinan. Ada sangat banyak usulan logika kontrafaktual yang berbeda. Bahkan tidak ada satu logika kontrafaktual Lewis–Stalnaker tunggal: meskipun Stalnaker dan Lewis mengajukan penjelasan yang serupa dengan mengacu pada dunia mungkin yang paling dekat, asumsi-asumsi mereka menghasilkan inferensi valid yang berbeda.

Soal

Soal 62.1.

Berikan contoh tandingan dalam  𝐒 𝟓 bagi relasi perikutan yang tidak berlaku untuk kondisional ketat, yakni bagi:

  1. ¬ p ⊭ ◻ ( p → q )

  2. q ⊭ ◻ ( p → q )

  3. ¬ ◻ ( p → q ) ⊭ p ∧ ¬ q

  4. ⊭ ◻ ( p → q ) ∨ ◻ ( q → p )

Soal 62.2.

Tunjukkan bahwa relasi-relasi perikutan yang valid berlaku bagi kondisional ketat dengan memberikan bukti-bukti dalam  𝐒 𝟓 bagi:

  1. ◻ ( φ → ψ ) ⊨ ¬ φ ∨ ψ

  2. φ ∧ ¬ ψ ⊨ ¬ ◻ ( φ → ψ )

  3. φ , ◻ ( φ → ψ ) ⊨ ψ

  4. ◻ ( φ → ψ ) , ◻ ( φ → χ ) ⊨ ◻ ( φ → ( ψ ∧ χ ) )

  5. ◻ ( φ → ψ ) ⊨ ◻ ( ( φ ∧ χ ) → ψ )

  6. ◻ ( φ → ψ ) , ◻ ( ψ → χ ) ⊨ ◻ ( φ → χ )

  7. ◻ ( φ → ψ ) ⊨ ◻ ( ¬ ψ → ¬ φ )

  8. ◻ ( ¬ ψ → ¬ φ ) ⊨ ◻ ( φ → ψ )

Soal 62.3.

Berikan bukti dalam  𝐒 𝟓 bagi:

  1. ◻ ¬ φ ⊨ φ ⥽ ψ

  2. φ ⥽ ψ ⊨ ◻ ( φ ⥽ ψ )

  3. ¬ ( φ ⥽ ψ ) ⊨ ◻ ¬ ( φ ⥽ ψ )

Gunakan definisi ⥽ untuk melakukannya.
