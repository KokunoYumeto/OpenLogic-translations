64 Konsepsi Iteratif

64.1 Ekstensionalitas

Hal pertama yang perlu dikatakan ialah bahwa himpunan dibedakan satu sama lain berdasarkan anggota-nya. Lebih tepatnya:

Aksioma.

Ekstensionalitas

Jika himpunan A dan B mempunyai anggota yang sama, maka A dan B adalah himpunan yang sama. ∀ A ∀ B ( ∀ x ( x ∈ A ↔ x ∈ B ) → A = B )

Kita mengasumsikan hal ini di sepanjang Bagian I. Namun, hal ini patut ditegaskan kembali. Aksioma Ekstensionalitas mengungkapkan gagasan dasar bahwa suatu himpunan ditentukan oleh anggota-nya. (Dengan demikian, himpunan dapat dikontraskan dengan konsep: objek-objek yang persis sama dapat termasuk dalam banyak konsep yang berbeda.)

Mengapa kita menerima prinsip ini? Dapat dikatakan secara masuk akal bahwa menolak Ekstensionalitas berarti memutuskan untuk meninggalkan segala sesuatu yang bahkan masih layak disebut teori himpunan. Teori himpunan tidak lebih dan tidak kurang daripada teori koleksi ekstensional.

Namun, tantangan sesungguhnya dalam Bagian XV ialah menetapkan prinsip-prinsip yang memberi tahu kita himpunan mana yang ada. Ternyata, satu-satunya jawaban yang benar-benar “jelas” atas pertanyaan ini dapat dibuktikan keliru.

64.2 Paradoks Russell (Lagi)

Dalam Bagian I, kita bekerja dengan teori himpunan naif. Namun, menurut suatu konsepsi yang sangat naif, himpunan hanyalah ekstensi predikat. Gagasan naif ini mengharuskan prinsip berikut:

Komprehensi Naif. { x : φ ( x ) } ada untuk setiap formula φ .

Walaupun menggoda, prinsip ini dapat dibuktikan tidak konsisten. Kita telah melihatnya dalam Bagian 1.6, tetapi hasil ini begitu penting dan begitu langsung sehingga layak diulangi. Apa adanya.

Teorema 64.1.

Paradoks Russell

Tidak ada himpunan R = { x : x ∉ x }

Bukti.

Jika R = { x : x ∉ x } ada, maka R ∈ R jika dan hanya jika R ∉ R , yang merupakan kontradiksi.

Russell menemukan hasil ini pada Juni 1901. (Namun, ia tidak menyajikan paradoks itu tepat dalam bentuk yang baru saja kita gunakan, sebab ia sedang mempertimbangkan teori himpunan Frege sebagaimana diuraikan dalam Grundgesetze. Kita akan kembali ke hal ini dalam Bagian 64.6.) Russell menulis surat kepada Frege pada 16 Juni 1902 untuk menjelaskan ketidakkonsistenan dalam sistem Frege. Untuk korespondensi tersebut dan sedikit latar belakang, lihat Heijenoort (1967, pp. 124–8).

Perlu ditekankan bahwa bukti dua baris ini merupakan hasil logika murni. Memang, dalam notasi { x : x ∉ x } kita secara tersirat menggunakan sebuah aksioma (nonlogis?), yaitu Ekstensionalitas; sebab { x : φ ( x ) } dimaksudkan sebagai satu-satunya himpunan (berdasarkan Ekstensionalitas) dari objek-objek yang memenuhi φ , jika himpunan seperti itu ada. Namun, bahkan kesan penggunaan Ekstensionalitas dapat kita hindari dengan menyatakan hasilnya sebagai berikut: tidak ada himpunan yang anggotanya tepat semua himpunan yang bukan anggota dirinya sendiri. Dan hal ini tidak banyak berkaitan dengan himpunan. Sebagaimana diamati Russell sendiri, penalaran yang persis serupa akan membawa Anda pada kesimpulan: tidak ada pria yang mencukur tepat semua pria yang tidak mencukur dirinya sendiri. Atau: tidak ada anjing pug yang mengendus tepat semua anjing pug yang tidak mengendus dirinya sendiri. Dan seterusnya. Secara skematis, bentuk hasilnya hanyalah: ¬ ∃ x ∀ z ( R z x ↔ ¬ R z z ) . Dan itu hanyalah sebuah (skema) teorema logika orde pertama. Akibatnya, kita tidak dapat menghindari Paradoks Russell hanya dengan mengutak-atik teori himpunan kita; paradoks itu muncul bahkan sebelum kita sampai pada teori himpunan. Jika kita hendak menggunakan logika orde pertama (klasik), kita harus menerima bahwa tidak ada himpunan R = { x : x ∉ x } .

Kesimpulannya ialah sebagai berikut. Jika Anda ingin menerima Komprehensi Naif sembari menghindari ketidakkonsistenan, Anda tidak dapat sekadar mengutak-atik teori himpunannya. Sebaliknya, Anda harus merombak logikanya.

Tentu saja, teori-teori himpunan dengan logika nonklasik pernah diajukan. Namun, teori-teori itu—paling tidak—tidak standar. Pendekatan standar terhadap Paradoks Russell ialah memperlakukannya sebagai bukti langsung atas ketiadaan, lalu mencoba mempelajari cara hidup dengannya. Itulah pendekatan yang akan kita ikuti.

64.3 Predikatif dan Impredikatif

Himpunan Russell, R , didefinisikan melalui { x : x ∉ x } . Jika diuraikan lebih lengkap, R adalah himpunan yang memuat semua dan hanya himpunan yang bukan anggota dirinya sendiri. Jadi, ketika mendefinisikan R , kita menguantifikasi atas domain yang akan memuat R (seandainya objek tersebut ada).

Ini merupakan definisi impredikatif. Secara lebih umum, kita dapat mengatakan bahwa suatu definisi impredikatif jika dan hanya jika definisi itu menguantifikasi atas domain yang memuat objek yang sedang didefinisikan.

Sesudah munculnya berbagai paradoks, Whitehead, Russell, Poincaré, dan Weyl menolak definisi impredikatif semacam itu karena membentuk “lingkaran setan”:

Analisis atas paradoks-paradoks yang harus dihindari menunjukkan bahwa semuanya muncul dari sejenis lingkaran setan. Lingkaran-lingkaran setan tersebut timbul dari anggapan bahwa suatu koleksi objek dapat memuat anggota yang hanya dapat didefinisikan melalui koleksi itu secara keseluruhan[…. ¶]

Prinsip yang memungkinkan kita menghindari totalitas yang tidak sah dapat dinyatakan sebagai berikut: ‘Apa pun yang melibatkan semua anggota suatu koleksi tidak boleh menjadi salah satu anggota koleksi itu’; atau, sebaliknya: ‘Jika, seandainya suatu koleksi tertentu mempunyai suatu totalitas, koleksi itu akan mempunyai anggota yang hanya dapat didefinisikan dengan merujuk pada totalitas tersebut, maka koleksi itu tidak mempunyai totalitas.’ Kita akan menyebut ini ‘prinsip lingkaran setan’, karena prinsip ini memungkinkan kita menghindari lingkaran-lingkaran setan yang terlibat dalam pengandaian totalitas yang tidak sah. (Whitehead and Russell, 1910, p. 37)

Jika kita mengikuti mereka dengan menerima prinsip lingkaran setan, kita dapat mencoba mengganti Skema Komprehensi Naif yang membawa bencana (dari Bagian 64.2) dengan sesuatu seperti berikut:

Komprehensi Predikatif. Untuk setiap formula φ yang hanya menguantifikasi atas himpunan: himpunan ′ { x : φ ( x ) } ada.

Selama himpunan ′ bukan merupakan himpunan, tidak akan timbul kontradiksi.

Sayangnya, Komprehensi Predikatif tidak terlalu komprehensif. Bagaimanapun, prinsip itu memperkenalkan entitas baru kepada kita, yakni himpunan ′ . Jadi, kita harus mempertimbangkan formula yang menguantifikasi atas himpunan ′ . Jika formula semacam itu selalu menghasilkan himpunan ′ , Paradoks Russell akan timbul lagi hanya dengan mempertimbangkan himpunan ′ dari semua himpunan ′ yang bukan anggota dirinya sendiri. Dengan melanjutkan gagasan yang sama, kita harus mengatakan bahwa formula yang menguantifikasi atas himpunan ′ menghasilkan himpunan ′ ′ yang bersesuaian. Lalu kita akan memerlukan himpunan ′ ′ ′ , himpunan ′ ′ ′ ′ , dan seterusnya. Untuk mencegah ledakan tanda prima, lebih mudah menganggap semuanya sebagai himpunan 0 , himpunan 1 , himpunan 2 , himpunan 3 , himpunan 4 ,…. Dengan cara ini kita memperoleh jalan menuju teori tipe (sederhana).

Ada beberapa keberatan yang jelas terhadap teori semacam itu (meskipun tidak jelas bahwa keberatan tersebut sangat menentukan). Singkatnya: teori yang dihasilkan rumit digunakan; teori itu boros dalam mendalilkan beragam jenis objek; dan pada akhirnya tidak jelas bahwa definisi impredikatif bahkan seburuk itu.

Untuk menegaskan butir terakhir, perhatikan komentar Ramsey berikut:

kita dapat menyebut seorang pria sebagai yang tertinggi dalam suatu kelompok, sehingga mengidentifikasinya melalui suatu totalitas yang ia sendiri menjadi anggotanya, tanpa adanya lingkaran setan. (Ramsey, 1925)

Butir yang diajukan Ramsey ialah bahwa “pria tertinggi dalam kelompok” merupakan definisi impredikatif; tetapi definisi itu jelas sepenuhnya wajar.

Seseorang mungkin menanggapi bahwa, dalam kasus ini, kita dapat memilih orang tertinggi itu dengan cara predikatif. Misalnya, mungkin kita cukup menunjuk pria yang dimaksud. Karena itu, keberatan terhadap definisi impredikatif jelas harus dibatasi pada entitas yang hanya dapat dipilih secara impredikatif. Namun, sekalipun demikian, kita masih memerlukan penjelasan lebih lanjut tentang mengapa “keimpredikatifan esensial” semacam itu begitu buruk.21

Memang, definisi impredikatif membawa masalah yang sangat serius jika kita ingin definisi kita menyediakan semacam resep untuk menciptakan suatu objek. Sebab, dengan diberikannya definisi impredikatif, kita benar-benar akan terperangkap dalam lingkaran setan: untuk menciptakan objek yang ditentukan secara impredikatif, kita harus terlebih dahulu menciptakan semua objek (termasuk objek yang ditentukan secara impredikatif), karena objek tersebut ditentukan dengan mengacu pada semua objek; jadi, kita harus menciptakan objek yang ditentukan secara impredikatif sebelum kita selesai menciptakan objek itu sendiri. Namun sekali lagi, ini hanya merupakan keberatan serius terhadap himpunan yang ditentukan “secara impredikatif esensial” jika kita menganggap himpunan sebagai benda yang kita ciptakan. Dan (barangkali) kita tidak menganggapnya demikian.

Karena itu—baik atau buruk—pendekatan yang kemudian menjadi umum tidak mengambil sikap keras mengenai (im)­pre­di­ka­tiv­itas. Sebaliknya, pendekatan tersebut menggunakan apa yang kini dianggap sebagai pendekatan kumulatif-iteratif. Pada akhirnya, pendekatan ini memungkinkan kita menstratifikasi himpunan ke dalam “tahap-tahap”—agak menyerupai cara pendekatan predikatif menstratifikasi entitas menjadi himpunan 0 , himpunan 1 , himpunan 2 , …—tetapi kita tidak akan mendalilkan perbedaan jenis apa pun di antara semuanya.

64.4 Pendekatan Kumulatif-Iteratif

Berikut pernyataan yang sedikit lebih lengkap tentang cara kita akan menstratifikasi himpunan ke dalam tahap-tahap:

Himpunan dibentuk dalam tahap-tahap. Untuk setiap tahap S , terdapat tahap-tahap tertentu yang berada sebelum S . Pada tahap S , setiap koleksi yang terdiri atas himpunan yang dibentuk pada tahap sebelum S dibentuk menjadi sebuah himpunan. Tidak ada himpunan selain himpunan yang dibentuk pada tahap-tahap tersebut. (Shoenfield, 1977, p. 323)

Ini merupakan sketsa konsepsi kumulatif-iteratif tentang himpunan. Konsepsi ini akan mendasari teori himpunan formal yang kita sajikan dalam Bagian XV.

Mari kita telaah hal ini dengan sedikit lebih terperinci. Sebagaimana Shoenfield menggambarkan prosesnya, pada setiap tahap kita membentuk himpunan baru dari himpunan yang telah tersedia dari tahap-tahap sebelumnya. Jadi, dalam gambaran Shoenfield, pada tahap awal, yaitu tahap 0 , tidak ada tahap yang lebih awal; karena itu, a fortiori, tidak ada himpunan yang tersedia bagi kita dari tahap sebelumnya.22 Jadi, kita hanya membentuk satu himpunan: himpunan tanpa anggota, ∅ . Pada tahap 1 , tepat satu himpunan tersedia dari tahap sebelumnya, sehingga hanya ada satu himpunan baru, yaitu { ∅ } . Pada tahap 2 , dua himpunan tersedia dari tahap sebelumnya, dan kita membentuk dua himpunan baru, { { ∅ } } dan { ∅ , { ∅ } } . Pada tahap 3 , empat himpunan tersedia dari tahap sebelumnya, sehingga kita membentuk dua belas himpunan baru…. Dengan demikian, gambaran kumulatif-iteratif tentang himpunan akan tampak kira-kira seperti ini (angka menunjukkan tahap):

Jadi, mengapa kita perlu menerima cerita ini?

Salah satu alasannya ialah bahwa cerita ini baik dan mudah dikelola. Setelah cerita yang paling jelas, yaitu Komprehensi Naif, tumbang, kita memerlukan sesuatu yang baik.

Namun, cerita ini bukan sekadar baik. Kita memiliki alasan kuat untuk percaya bahwa setiap teori himpunan yang didasarkan pada cerita ini akan konsisten. Berikut alasannya.

Menurut konsepsi kumulatif-iteratif tentang himpunan, kita membentuk himpunan pada tahap-tahap tertentu; dan anggota-nya harus berupa objek yang sudah tersedia. Jadi, untuk setiap tahap  S , kita dapat membentuk himpunan R S = { x : x ∉ x  dan  x  tersedia sebelum  S } Penalaran dalam pembuktian Paradoks Russell kini akan menetapkan bahwa R S sendiri tidak tersedia sebelum tahap S . Dan itu bukan kontradiksi. Selain itu, jika kita menerima konsepsi kumulatif-iteratif tentang himpunan, kita bahkan tidak semestinya mengharapkan dapat membentuk himpunan Russell itu sendiri. Sebab, himpunan itu akan menjadi himpunan semua himpunan yang bukan anggota dirinya sendiri dan yang “kelak akan tersedia”. Singkatnya: fakta bahwa kita (secara terbukti) tidak dapat membentuk himpunan Russell bukanlah sesuatu yang mengejutkan menurut cerita kumulatif-iteratif; itulah yang akan kita prediksi.

64.5 Urelemen atau Bukan?

Dalam beberapa bab berikutnya, kita akan mencoba menurunkan aksioma-aksioma dari konsepsi kumulatif-iteratif tentang himpunan. Namun, sebelum melangkah lebih jauh, kita perlu mengatakan sesuatu lagi tentang urelemen.

Gambaran dalam Bagian 64.4 hanya memperbolehkan kita membentuk himpunan baru dari himpunan lama. Akan tetapi, kita mungkin ingin memperbolehkan bukan-himpunan tertentu—sapi, babi, butir pasir, atau apa pun—menjadi anggota suatu himpunan. Dalam hal itu, kita akan memulai dengan unsur dasar tertentu, yaitu urelemen, lalu mengatakan bahwa pada setiap tahap S kita membentuk “semua himpunan yang mungkin” yang terdiri atas urelemen atau himpunan yang dibentuk pada tahap sebelum S (dalam kombinasi apa pun). Gambaran yang dihasilkan akan lebih menyerupai ini:

Jadi, sekarang ada keputusan yang harus kita ambil: Haruskah kita memperbolehkan urelemen?

Secara filosofis, memasukkan urelemen ke dalam teori kita masuk akal. Alasan utamanya ialah agar teori himpunan kita dapat diterapkan. Sebagai ilustrasi, ingat dari Bab 4 bahwa kita mengatakan dua himpunan A dan  B berukuran sama, yakni A ≈ B , jika dan hanya jika terdapat suatu bijeksi di antara keduanya. Sekarang, jika sapi di padang dan babi di kandang masing-masing membentuk himpunan, kita dapat memberikan perlakuan teoretis-himpunan terhadap klaim “jumlah sapi sama banyaknya dengan jumlah babi”. Namun, jika kita melarang urelemen sehingga sapi dan babi tidak membentuk himpunan, perlakuan teoretis-himpunan tersebut tidak akan tersedia. Memang, kita tidak akan mempunyai cara langsung untuk menerapkan teori himpunan pada apa pun selain himpunan itu sendiri. (Untuk alasan lain yang mendukung urelemen, lihat Potter 2004, pp. vi, 24, 50–1.)

Namun, secara matematis, urelemen cukup jarang diperbolehkan. Sebagian alasannya ialah bahwa teori himpunan sedikit sekali lebih mudah dirumuskan tanpa urelemen. Akan tetapi, sesekali kita menemukan pembenaran yang lebih menarik untuk mengeluarkan urelemen dari teori himpunan:

Sesuai dengan keyakinan bahwa teori himpunan merupakan fondasi matematika, kita seharusnya dapat mencakup seluruh matematika hanya dengan membicarakan himpunan; karena itu, variabel kita tidak boleh menjangkau objek seperti sapi dan babi. (Kunen, 1980, p. 8)

Jadi, fokus pada keterterapan menyarankan agar urelemen dimasukkan; fokus pada tujuan fondasional yang reduktif (mereduksi matematika menjadi teori himpunan murni) mungkin menyarankan agar urelemen dikeluarkan. Sedikit kemalasan juga mengarah pada pengeluaran urelemen.

Kita akan mengikuti jalan yang paling malas. Namun, sebagian pilihan ini juga memiliki pembenaran pedagogis. Tujuan kita ialah memperkenalkan kepada Anda unsur-unsur teori himpunan yang diperlukan untuk mulai mempelajari filsafat teori himpunan. Dan sebagian besar literatur filosofis tersebut membahas teori himpunan yang dirumuskan tanpa urelemen. Jadi, buku ini barangkali akan lebih berguna jika mengikuti literatur tersebut dengan cukup dekat.

64.6 Lampiran: Hukum Dasar V Frege

Dalam Bagian 64.2, kita menjelaskan bahwa Russell merumuskan paradoksnya sebagai masalah bagi sistem yang diuraikan Frege dalam Grundgesetze. Sistem Frege tidak memuat perumusan langsung Komprehensi Naif. Jadi, dalam lampiran ini, kita akan menjelaskan dengan sangat singkat apa yang termuat dalam sistem Frege, bagaimana hubungannya dengan Komprehensi Naif, dan bagaimana hubungannya dengan Paradoks Russell.

Sistem Frege bersifat orde kedua dan dirancang untuk merumuskan gagasan tentang ekstensi suatu konsep.23 Dengan menggunakan notasi yang diilhami Frege, kita akan menulis ϵ x F ( x ) untuk ekstensi konsep  F . Perangkat ini mengambil sebuah predikat, “ F ”, dan mengubahnya menjadi sebuah term (orde pertama), “ ϵ x F ( x ) ”. Dengan perangkat ini, Frege memberikan definisi keanggotaan berikut: a ∈ b = df ∃ G ( b = ϵ x G ( x ) ∧ G a ) secara kasar: a ∈ b jika dan hanya jika a berada di bawah suatu konsep yang ekstensinya adalah b . (Perhatikan bahwa penguantifikasi “ ∃ G ” bersifat orde kedua.) Frege juga mempertahankan prinsip berikut, yang dikenal sebagai Hukum Dasar V: ϵ x F ( x ) = ϵ x G ( x ) ↔ ∀ x ( F x ↔ G x ) secara kasar: konsep-konsep mempunyai ekstensi identik jika dan hanya jika konsep-konsep itu koekstensif. (Sekali lagi, baik “ F ” maupun “ G ” berada pada posisi predikat.) Kini suatu prinsip sederhana menghubungkan keanggotaan dengan terpenuhinya sifat:

Lema 64.2.

dalam Grundgesetze

∀ F ∀ a ( a ∈ ϵ x F ( x ) ↔ F a )

Bukti.

Tetapkan F dan a . Sekarang a ∈ ϵ x F ( x ) jika dan hanya jika ∃ G ( ϵ x F ( x ) = ϵ x G ( x ) ∧ G a ) (menurut definisi keanggotaan) jika dan hanya jika ∃ G ( ∀ x ( F x ↔ G x ) ∧ G a ) (menurut Hukum Dasar V) jika dan hanya jika F a (menurut logika orde kedua elementer).

Dan hasil ini memberikan Komprehensi Naif hampir seketika:

Lema 64.3.

dalam Grundgesetze.

∀ F ∃ s ∀ a ( a ∈ s ↔ F a )

Bukti.

Tetapkan F ; sekarang Lema 64.2 memberikan ∀ a ( a ∈ ϵ x F ( x ) ↔ F a ) ; jadi ∃ s ∀ a ( a ∈ s ↔ F a ) berdasarkan generalisasi eksistensial. Hasilnya mengikuti karena F dipilih secara sembarang.

Paradoks Russell mengikuti dengan mengambil F sebagaimana diberikan oleh ∀ x ( F x ↔ x ∉ x ) .
