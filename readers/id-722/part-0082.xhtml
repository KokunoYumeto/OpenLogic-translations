65 Langkah-Langkah Menuju 𝐙

65.1 Cerita yang Lebih Terperinci

Dalam Bagian 64.4, kita mengutip uraian Shoenfield tentang proses pembentukan himpunan. Sekarang kita ingin menuliskan beberapa prinsip lagi agar cerita ini sedikit lebih tepat. Berikut prinsip-prinsip tersebut:

  1. 𝑆𝑡𝑎𝑔𝑒𝑠-𝑎𝑟𝑒-𝑘𝑒𝑦 . Setiap himpunan dibentuk pada suatu tahap.

  2. 𝑆𝑡𝑎𝑔𝑒𝑠-𝑎𝑟𝑒-𝑜𝑟𝑑𝑒𝑟𝑒𝑑 . Tahap-tahap terurut: beberapa tahap berada sebelum tahap lainnya.24

  3. 𝑆𝑡𝑎𝑔𝑒𝑠-𝑎𝑐𝑐𝑢𝑚𝑢𝑙𝑎𝑡𝑒 . Untuk setiap tahap S , dan untuk sembarang himpunan yang dibentuk sebelum tahap  S : pada tahap  S dibentuk suatu himpunan yang anggotanya tepat semua himpunan tersebut. Tidak ada hal lain yang dibentuk pada tahap  S .

Ini merupakan prinsip-prinsip informal, tetapi kita akan dapat menggunakannya untuk membenarkan beberapa aksioma teori himpunan Zermelo.

(Kita perlu menyampaikan satu peringatan. Walaupun kita akan menyajikan beberapa aksioma yang sepenuhnya standar dengan nama yang sepenuhnya standar, prinsip-prinsip bercetak miring yang baru saja kita sajikan tidak mempunyai nama khusus dalam literatur. Kita sekadar memberi prinsip-prinsip itu julukan yang kita harap dapat membantu.)

65.2 Pemisahan

Kita mulai dengan sebuah prinsip untuk menggantikan Komprehensi Naif:

Aksioma.

Skema Pemisahan

Untuk setiap formula φ ( x ) , berikut ini merupakan suatu aksioma: untuk setiap A , himpunan { x ∈ A : φ ( x ) } ada.

Perhatikan bahwa ini bukan satu aksioma tunggal, melainkan suatu skema aksioma. Terdapat tak berhingga banyaknya aksioma Pemisahan; satu untuk setiap formula φ ( x ) . Skema ini juga dapat (dan biasanya memang) dituliskan sebagai berikut:

Untuk setiap formula φ ( x ) yang tidak memuat “ S ”, berikut ini merupakan suatu aksioma: ∀ A ∃ S ∀ x ( x ∈ S ↔ ( φ ( x ) ∧ x ∈ A ) ) .

Sesuai dengan konvensi yang dicatat pada awal Bagian XV, formula-formula  φ dalam aksioma Pemisahan dapat mempunyai parameter.25

Pemisahan langsung dibenarkan oleh konsepsi kumulatif-iteratif tentang himpunan yang telah kita uraikan. Untuk melihat alasannya, misalkan A suatu himpunan. Jadi, A dibentuk pada suatu tahap  S (menurut 𝑆𝑡𝑎𝑔𝑒𝑠-𝑎𝑟𝑒-𝑘𝑒𝑦 ). Karena A dibentuk pada tahap  S , semua anggota A dibentuk sebelum tahap S (menurut 𝑆𝑡𝑎𝑔𝑒𝑠-𝑎𝑐𝑐𝑢𝑚𝑢𝑙𝑎𝑡𝑒 ). Sekarang, secara khusus, pertimbangkan semua himpunan yang merupakan anggota A dan juga memenuhi φ ; jelas semua himpunan ini pun dibentuk sebelum tahap  S . Jadi, semua himpunan itu juga dibentuk menjadi himpunan { x ∈ A : φ ( x ) } pada tahap  S (menurut 𝑆𝑡𝑎𝑔𝑒𝑠-𝑎𝑐𝑐𝑢𝑚𝑢𝑙𝑎𝑡𝑒 ).

Tidak seperti Komprehensi Naif, prinsip ini menghindari Paradoks Russell. Kita tidak dapat begitu saja menegaskan keberadaan himpunan { x : x ∉ x } . Sebaliknya, dengan diberikannya suatu himpunan  A , kita dapat menegaskan keberadaan himpunan R A = { x ∈ A : x ∉ x } . Namun, semua ini hanya membuktikan bahwa R A ∉ R A dan R A ∉ A ; tidak satu pun di antaranya sangat mengkhawatirkan.

Namun, Pemisahan mempunyai konsekuensi langsung dan mencolok:

Teorema 65.1.

Tidak ada himpunan semesta; yakni, { x : x = x } tidak ada.

Bukti.

Untuk reductio, andaikan V merupakan himpunan semesta. Maka, menurut Pemisahan, R = { x ∈ V : x ∉ x } = { x : x ∉ x } ada, bertentangan dengan Paradoks Russell.

Ketiadaan himpunan semesta—bahkan, sifat terbuka hierarki himpunan—adalah salah satu gagasan paling mendasar di balik konsepsi kumulatif-iteratif. Jadi, patut diperlihatkan bahwa secara intuitif kita dapat mencapainya melalui jalur lain. Himpunan semesta harus menjadi anggota dari dirinya sendiri. Namun, menurut konsepsi kumulatif-iteratif kita, setiap himpunan muncul (untuk pertama kalinya) dalam hierarki pada tahap pertama tepat sesudah semua anggota-nya. Akan tetapi, ini menyiratkan bahwa tidak ada himpunan yang menjadi anggota dirinya sendiri. Sebab, setiap himpunan yang menjadi anggota dirinya sendiri harus muncul untuk pertama kalinya tepat sesudah tahap tempat himpunan itu pertama kali muncul, dan hal itu mustahil. (Dalam Definisi 67.15 kita akan melihat cara membuat penjelasan ini lebih ketat dengan menggunakan gagasan “peringkat” suatu himpunan. Namun, untuk melakukannya, kita perlu terlebih dahulu memiliki beberapa aksioma tambahan.)

Berikut beberapa konsekuensi lain dari Pemisahan dan Ekstensionalitas.

Proposisi 65.2.

Jika ada suatu himpunan, maka ∅ ada.

Bukti.

Jika A suatu himpunan, ∅ = { x ∈ A : x ≠ x } ada menurut Pemisahan.

Proposisi 65.3.

A ∖ B ada untuk setiap himpunan A dan B .

Bukti.

A ∖ B = { x ∈ A : x ∉ B } ada menurut Pemisahan.

Ternyata, irisan yang (hampir) sembarang juga ada:

Proposisi 65.4.

Jika A ≠ ∅ , maka ⋂ A = { x : ( ∀ y ∈ A ) x ∈ y } ada.

Bukti.

Misalkan A ≠ ∅ , sehingga terdapat suatu c ∈ A . Maka ⋂ A = { x : ( ∀ y ∈ A ) x ∈ y } = { x ∈ c : ( ∀ y ∈ A ) x ∈ y } , yang ada menurut Pemisahan.

Namun, perhatikan syarat A ≠ ∅ ; sebab ⋂ ∅ akan menjadi himpunan semesta secara hampa, bertentangan dengan Teorema 65.1.

65.3 Gabungan

Proposisi 65.4 memberi kita irisan. Namun, jika kita ingin gabungan sembarang selalu ada, kita perlu menetapkan aksioma lain:

Aksioma.

Gabungan

Untuk setiap himpunan A , himpunan ⋃ A = { x : ( ∃ b ∈ A ) x ∈ b } ada. ∀ A ∃ U ∀ x ( x ∈ U ↔ ( ∃ b ∈ A ) x ∈ b )

Aksioma ini juga dibenarkan oleh konsepsi kumulatif-iteratif. Misalkan A suatu himpunan, sehingga A dibentuk pada suatu tahap S (menurut 𝑆𝑡𝑎𝑔𝑒𝑠-𝑎𝑟𝑒-𝑘𝑒𝑦 ). Setiap anggota A dibentuk sebelum S (menurut 𝑆𝑡𝑎𝑔𝑒𝑠-𝑎𝑐𝑐𝑢𝑚𝑢𝑙𝑎𝑡𝑒 ); jadi, dengan penalaran serupa, setiap anggota dari setiap anggota A dibentuk sebelum S . Dengan demikian, semua himpunan tersebut tersedia sebelum S untuk dibentuk menjadi suatu himpunan pada S . Himpunan itu tepat ⋃ A .

65.4 Pasangan

Aksioma berikutnya yang akan kita pertimbangkan adalah sebagai berikut:

Aksioma.

Pasangan

Untuk sebarang himpunan a , b , himpunan { a , b } ada. ∀ a ∀ b ∃ P ∀ x ( x ∈ P ↔ ( x = a ∨ x = b ) )

Berikut cara membenarkan aksioma ini dengan menggunakan konsepsi iteratif. Andaikan a tersedia pada tahap  S , dan b tersedia pada tahap  T . Misalkan M adalah tahap yang lebih akhir di antara S dan  T . Karena a dan b sama-sama tersedia pada tahap  M , himpunan { a , b } merupakan kumpulan yang mungkin dan tersedia pada setiap tahap sesudah  M .

Namun, tunggu! Mengapa kita mengandaikan bahwa memang ada tahap sesudah M ? Jika tidak ada, pembenaran kita gagal. Jadi, untuk membenarkan Pasangan, kita harus menambahkan satu prinsip lagi pada kisah yang disampaikan dalam Bagian 65.1, yakni:

  1. 𝑆𝑡𝑎𝑔𝑒𝑠-𝑘𝑒𝑒𝑝-𝑔𝑜𝑖𝑛𝑔 . Tidak ada tahap terakhir.

Apakah prinsip ini dapat dibenarkan? Tidak ada bagian kisah Shoenfield yang menyatakan secara eksplisit bahwa tidak ada tahap terakhir. Meskipun demikian, sekalipun prinsip itu—secara tegas—merupakan tambahan pada kisah kita, prinsip tersebut sangat selaras dengan gagasan dasar bahwa himpunan dibentuk secara bertahap. Untuk selanjutnya, kita akan menerimanya. Dengan demikian, kita juga menerima Aksioma Pasangan.

Berbekal aksioma baru ini, kita dapat membuktikan keberadaan jauh lebih banyak himpunan. Sebagai contoh:

Proposisi 65.5.

Untuk sebarang himpunan a dan  b , himpunan-himpunan berikut ada:

  1. { a }

  2. a ∪ b

  3. ⟨ a , b ⟩

Bukti.

enumi 1. Berdasarkan Pasangan, { a , a } ada; menurut Ekstensionalitas, himpunan ini sama dengan { a } .

enumi 2. Berdasarkan Pasangan, { a , b } ada. Maka a ∪ b = ⋃ { a , b } ada berdasarkan Gabungan.

enumi 3. Berdasarkan enumi 1, { a } ada. Berdasarkan Pasangan, { a , b } ada. Maka { { a } , { a , b } } = ⟨ a , b ⟩ ada, sekali lagi berdasarkan Pasangan.

65.5 Himpunan Kuasa

Kita lanjutkan dengan aksioma lain:

Aksioma.

Himpunan Kuasa

Untuk sebarang himpunan A , himpunan ℘ ( A ) = { x : x ⊆ A } ada. ∀ A ∃ P ∀ x ( x ∈ P ↔ ( ∀ z ∈ x ) z ∈ A )

Pembenaran bagi aksioma ini cukup langsung. Andaikan A dibentuk pada tahap  S . Maka semua anggota  A telah tersedia sebelum  S (berdasarkan 𝑆𝑡𝑎𝑔𝑒𝑠-𝑎𝑐𝑐𝑢𝑚𝑢𝑙𝑎𝑡𝑒 ). Jadi, dengan penalaran seperti dalam pembenaran kita bagi Pemisahan, setiap himpunan bagian dari  A telah terbentuk paling lambat pada tahap  S . Karena itu, semuanya tersedia untuk dibentuk menjadi satu himpunan pada sebarang tahap sesudah  S . Kita tahu bahwa suatu tahap demikian ada, sebab S bukan tahap terakhir (berdasarkan 𝑆𝑡𝑎𝑔𝑒𝑠-𝑘𝑒𝑒𝑝-𝑔𝑜𝑖𝑛𝑔 ). Jadi, ℘ ( A ) ada.

Berikut suatu konsekuensi yang berguna dari Himpunan Kuasa:

Proposisi 65.6.

Dengan diberikan sebarang himpunan A , B , hasil kali Kartesius A × B ada.

Bukti.

Himpunan ℘ ( ℘ ( A ∪ B ) ) ada berdasarkan Himpunan Kuasa dan Proposisi 65.5. Jadi, berdasarkan Pemisahan, himpunan berikut ada: C = { z ∈ ℘ ( ℘ ( A ∪ B ) ) : ( ∃ x ∈ A ) ( ∃ y ∈ B ) z = ⟨ x , y ⟩ } . Untuk sebarang x ∈ A dan y ∈ B , himpunan ⟨ x , y ⟩ ada berdasarkan Proposisi 65.5. Selain itu, karena x , y ∈ A ∪ B , kita mempunyai { x } , { x , y } ∈ ℘ ( A ∪ B ) , dan ⟨ x , y ⟩ ∈ ℘ ( ℘ ( A ∪ B ) ) . Jadi, A × B = C .

Dalam bukti ini, Himpunan Kuasa berinteraksi dengan Pemisahan. Hal itu tidak mengherankan. Tanpa Pemisahan, Himpunan Kuasa bukanlah prinsip yang sangat kuat. Bagaimanapun, Pemisahan memberi tahu kita himpunan bagian mana dari suatu himpunan yang ada, dan dengan demikian menentukan seberapa “gemuk” setiap himpunan kuasa.

65.6 Ketakhinggaan

Kita sudah memiliki cukup banyak aksioma untuk menjamin adanya tak berhingga banyak himpunan (jika ada himpunan sama sekali). Andaikan suatu himpunan ada; maka ∅ ada (berdasarkan Proposisi 65.2). Untuk setiap himpunan  x , himpunan x ∪ { x } ada berdasarkan Proposisi 65.5. Jadi, dengan menerapkan operasi ini beberapa kali, kita memperoleh himpunan-himpunan berikut:

  1. ∅

  2. { ∅ }

  3. { ∅ , { ∅ } }

  4. { ∅ , { ∅ } , { ∅ , { ∅ } } }

  5. { ∅ , { ∅ } , { ∅ , { ∅ } } , { ∅ , { ∅ } , { ∅ , { ∅ } } } }

dan kita dapat memeriksa bahwa setiap himpunan ini berbeda.

Kita memulai penomoran dari  0 karena beberapa alasan. Salah satunya adalah sebagai berikut. Tidak sulit untuk memeriksa bahwa himpunan yang kita beri label “ n ” mempunyai tepat n anggota dan (secara intuitif) dibentuk pada tahap ke- n .

Namun, konstruksi ini hanya memberikan tak berhingga banyak himpunan; konstruksi ini tidak menjamin adanya suatu himpunan tak hingga, yakni himpunan dengan tak berhingga banyak anggota. Hal ini sungguh penting: jika kita tidak dapat menemukan suatu himpunan yang tak hingga Dedekind, kita tidak dapat mengonstruksi aljabar Dedekind. Padahal kita menginginkan aljabar Dedekind agar dapat memperlakukannya sebagai himpunan bilangan asli. (Bandingkan Bagian 6.4.)

Yang penting, aksioma-aksioma yang telah kita tetapkan sejauh ini tidak menjamin keberadaan himpunan tak hingga apa pun. Jadi, kita harus menetapkan suatu aksioma baru:

Aksioma.

Ketakhinggaan

Terdapat himpunan  I sedemikian sehingga ∅ ∈ I dan x ∪ { x } ∈ I setiap kali x ∈ I . ∃ I ( ( ( ∃ o ∈ I ) ∀ x   x ∉ o ) ∧ ( ∀ x ∈ I ) ( ∃ s ∈ I ) ∀ z ( z ∈ s ↔ ( z ∈ x ∨ z = x ) ) )

Mudah dilihat bahwa himpunan  I yang diberikan oleh Aksioma Ketakhinggaan bersifat tak hingga Dedekind. Anggota istimewanya ialah ∅ , dan injeksi pada  I diberikan oleh s ( x ) = x ∪ { x } . Teorema Teorema 6.5 menunjukkan cara mengekstrak suatu aljabar Dedekind dari himpunan yang tak hingga Dedekind; kita akan memperlakukan aljabar ini sebagai himpunan bilangan asli kita. Secara lebih tepat:

Definisi 65.7.

Misalkan I sebarang himpunan yang diberikan oleh Aksioma Ketakhinggaan. Misalkan s fungsi yang didefinisikan oleh s ( x ) = x ∪ { x } . Tetapkan ω = clo s ( ∅ ) . Kita menyebut anggota-anggota ω sebagai bilangan asli, dan mengatakan bahwa n merupakan hasil dari menerapkan s kepada ∅ sebanyak n kali.

Sekarang Anda dapat kembali memeriksa bahwa himpunan yang beberapa paragraf sebelumnya diberi label “ n ” akan diperlakukan sebagai bilangan  n .

Kita akan membahas arti penting ketetapan ini dalam Bagian 65.8. Untuk saat ini, ketetapan tersebut memungkinkan kita membuktikan hasil yang intuitif:

Proposisi 65.8.

Tidak ada bilangan asli yang bersifat tak hingga Dedekind.

Bukti.

Bukti dilakukan dengan induksi, yakni Teorema 6.6. Jelas bahwa 0 = ∅ tidak bersifat tak hingga Dedekind. Untuk langkah induksi, kita akan membuktikan kontraposisinya: jika (secara absurd) s ( n ) bersifat tak hingga Dedekind, maka n bersifat tak hingga Dedekind.

Andaikan s ( n ) bersifat tak hingga Dedekind; dengan kata lain, terdapat suatu injeksi  f dengan ran ( f ) ⊊ dom ( f ) = s ( n ) = n ∪ { n } . Ada dua kasus yang perlu dipertimbangkan.

Kasus 1: n ∉ ran ( f ) . Maka ran ( f ) ⊆ n dan f ( n ) ∈ n . Misalkan g = f ↾ n ; sekarang ran ( g ) = ran ( f ) ∖ { f ( n ) } ⊊ n = dom ( g ) . Jadi, n bersifat tak hingga Dedekind.

Kasus 2: n ∈ ran ( f ) . Tetapkan suatu m ∈ dom ( f ) ∖ ran ( f ) , dan definisikan fungsi  h dengan domain s ( n ) = n ∪ { n } : h ( x ) = { f ( x ) jika  f ( x ) ≠ n m jika  f ( x ) = n . Jadi, h dan f bernilai sama di semua tempat, kecuali bahwa h ( f − 1 ( n ) ) = m ≠ n = f ( f − 1 ( n ) ) . Karena f merupakan injeksi, berlaku n ∉ ran ( h ) ; dan ran ( h ) ⊊ dom ( h ) = s ( n ) . Sekarang, dengan menggunakan argumen pada Kasus 1, n bersifat tak hingga Dedekind.

Namun, masih tersisa pertanyaan tentang bagaimana kita dapat membenarkan Aksioma Ketakhinggaan. Jawaban singkatnya adalah bahwa kita perlu menambahkan satu prinsip lagi pada kisah kita. Prinsip itu adalah sebagai berikut:

  1. 𝑆𝑡𝑎𝑔𝑒𝑠-ℎ𝑖𝑡-𝑖𝑛𝑓𝑖𝑛𝑖𝑡𝑦 . Terdapat suatu tahap tak hingga. Artinya, terdapat tahap yang (a) bukan tahap pertama, (b) mempunyai beberapa tahap yang mendahuluinya, tetapi (c) tidak mempunyai pendahulu langsung.

Aksioma Ketakhinggaan langsung mengikuti prinsip ini. Kita tahu bahwa bilangan asli  n dibentuk pada tahap  n . Jadi, himpunan ω dibentuk pada tahap tak hingga pertama. ω sendiri menjadi saksi bagi Aksioma Ketakhinggaan.

Namun, hal ini hanya mengembalikan kita pada pertanyaan tentang bagaimana kita dapat membenarkan 𝑆𝑡𝑎𝑔𝑒𝑠-ℎ𝑖𝑡-𝑖𝑛𝑓𝑖𝑛𝑖𝑡𝑦 . Seperti halnya 𝑆𝑡𝑎𝑔𝑒𝑠-𝑘𝑒𝑒𝑝-𝑔𝑜𝑖𝑛𝑔 , prinsip ini bukan bagian eksplisit dari kisah kita mengenai hierarki kumulatif-iteratif. Lebih dari itu, tidak ada apa pun dalam gagasan hierarki iteratif itu sendiri—tempat himpunan dibentuk tahap demi tahap—yang memaksa kita berpikir bahwa proses tersebut melibatkan suatu tahap tak hingga. Sangat masuk akal untuk berpikir bahwa tahap-tahap itu ditata seperti bilangan asli.

Namun, hal ini menimbulkan masalah yang jelas. Dalam Bagian 6.4, kita mempertimbangkan “bukti” Dedekind bahwa terdapat suatu himpunan (pikiran-pikiran) yang tak hingga Dedekind. Mungkin bukti itu tidak terasa sangat memuaskan. Akan tetapi, jika 𝑆𝑡𝑎𝑔𝑒𝑠-ℎ𝑖𝑡-𝑖𝑛𝑓𝑖𝑛𝑖𝑡𝑦 tidak “dipaksakan kepada kita” oleh konsepsi iteratif tentang himpunan (atau oleh “hukum-hukum pemikiran”), kita masih tidak mempunyai pembenaran intrinsik bagi klaim bahwa terdapat suatu himpunan yang tak hingga Dedekind.

Tentu saja, masih banyak yang dapat dikatakan. Namun, semoga sekarang Anda telah sampai pada titik untuk mulai memikirkan apa yang mungkin diperlukan guna membenarkan suatu aksioma (atau prinsip). Dalam pembahasan selanjutnya, kita menerima 𝑆𝑡𝑎𝑔𝑒𝑠-ℎ𝑖𝑡-𝑖𝑛𝑓𝑖𝑛𝑖𝑡𝑦 begitu saja.

65.7 𝐙 − : Sebuah Tonggak Penting

Kita akan kembali membahas 𝑆𝑡𝑎𝑔𝑒𝑠-ℎ𝑖𝑡-𝑖𝑛𝑓𝑖𝑛𝑖𝑡𝑦 dalam bagian berikutnya. Namun, dengan Aksioma Ketakhinggaan, kita telah mencapai tonggak penting. Sekarang kita mempunyai semua aksioma yang diperlukan bagi teori  𝐙 − . Secara terperinci:

Definisi 65.9.

Teori 𝐙 − mempunyai aksioma-aksioma berikut: Ekstensionalitas, Gabungan, Pasangan, Himpunan Kuasa, Ketakhinggaan, dan semua instans skema Pemisahan.

Nama itu merupakan singkatan bagi teori himpunan Zermelo (minus sesuatu yang akan kita jumpai kemudian). Zermelo layak menerima kehormatan ini karena ia pada dasarnya merumuskan teori tersebut pada 1908a.26

Teori ini cukup kuat untuk memungkinkan kita mengerjakan sangat banyak matematika. Secara khusus, Anda sebaiknya melihat kembali seluruh Bagian I dan meyakinkan diri bahwa segala sesuatu yang kita kerjakan secara naif dapat dikerjakan secara lebih formal di dalam  𝐙 − . (Setelah melakukannya cukup lama, Anda mungkin ingin melompat ke depan dan membaca Bagian 65.9.) Jadi, mulai sekarang dan tanpa komentar lebih lanjut, kita menganggap diri kita bekerja sekurang-kurangnya di dalam  𝐙 − .

65.8 Memilih Bilangan Asli Kita

Dalam Definisi 65.7, kita secara eksplisit mendefinisikan ungkapan “bilangan asli.” Bagaimana Anda seharusnya memahami ketetapan ini? Ketetapan itu bukan klaim metafisis, melainkan sekadar keputusan untuk memperlakukan himpunan tertentu sebagai bilangan asli. Kita telah menyinggung alasan untuk berpikir demikian dalam Bagian 2.2, Bagian 5.5, dan Bagian 6.4. Namun, kita dapat mengemukakan alasan-alasan itu dengan lebih tajam.

Aksioma Ketakhinggaan kita mengikuti von Neumann (1925). Akan tetapi, berikut aksioma lain yang dapat kita pilih sebagai gantinya:

Aksioma Ketakhinggaan Zermelo 1908a. Terdapat himpunan  A sedemikian sehingga ∅ ∈ A dan ( ∀ x ∈ A ) { x } ∈ A .

Seandainya kita menggunakan aksioma Zermelo alih-alih Aksioma Ketakhinggaan yang diilhami von Neumann, kita juga akan memperoleh suatu himpunan yang tak hingga Dedekind dan, dengan demikian, suatu aljabar Dedekind. Dalam pendekatan Zermelo, anggota istimewa aljabar kita tetap ∅ (pengganti  0 ), tetapi injeksinya diberikan oleh pemetaan x ↦ { x } , bukan x ↦ x ∪ { x } . Konsekuensi paling sederhana ialah bahwa Zermelo memperlakukan 2 sebagai { { ∅ } } , sedangkan kita (mengikuti von Neumann) memperlakukan 2 sebagai { ∅ , { ∅ } } .

Mengapa memilih satu aksioma Ketakhinggaan dan bukan yang lain? Alasan praktis utama ialah bahwa pendekatan von Neumann dapat “diperluas” dengan baik untuk menangani bilangan transfinit. Kita akan menjelajahinya mulai Bab 66. Namun, dari sudut pandang sederhana mengerjakan aritmetika, kedua pendekatan sama-sama memadai. Jadi, jika seseorang mengatakan bahwa bilangan asli adalah himpunan, pertanyaan yang jelas ialah: Himpunan yang mana?

Pertanyaan persis ini menjadi terkenal berkat Benacerraf (1965). Namun, patut ditekankan bahwa pertanyaan itu hanyalah contoh paling terkenal dari suatu fenomena yang telah kita jumpai berkali-kali. Pokok dasarnya adalah sebagai berikut. Teori himpunan memberi kita cara untuk menyimulasikan berbagai jenis entitas “intuitif”: bilangan real, rasional, bulat, dan asli; tetapi juga pasangan terurut, fungsi, dan relasi. Akan tetapi, teori himpunan tidak pernah memberi kita pilihan simulasi yang unik. Selalu ada pilihan alternatif yang—secara langsung—dapat melayani kita dengan sama baiknya.

65.9 Lampiran: Penutupan, Komprehensi, dan Irisan

Dalam Bagian 65.7, kita menyarankan agar Anda melihat kembali pembahasan naif dalam Bagian I dan memeriksa bahwa semuanya dapat dikerjakan di dalam  𝐙 − . Jika Anda mengikuti saran itu, satu hal mungkin menyulitkan Anda: penggunaan irisan dalam penanganan penutupan oleh Dedekind.

Ingat kembali dari Definisi 6.2 bahwa clo f ( o ) = ⋂ { X : o ∈ X  dan  X  tertutup terhadap  f } . Bentuk umum definisi ini adalah sebagai berikut: C = ⋂ { X : φ ( X ) } . Namun, hal ini seharusnya menjadi tanda bahaya: karena Komprehensi Naif gagal, tidak ada jaminan bahwa { X : φ ( X ) } ada. Dengan demikian, definisi semacam itu tampak sangat mungkin curang.

Untungnya, definisi itu tidak curang; atau, jika dalam bentuk sekarang definisi tersebut memang curang, kita dapat melakukan kerja jujur untuk membuatnya sah. Kerja jujur itu telah diisyaratkan dalam Proposisi 65.4, ketika kita menjelaskan mengapa ⋂ A ada bagi setiap A ≠ ∅ . Namun, sekarang kita akan menjabarkannya secara eksplisit.

Dengan Ekstensionalitas, jika kita mencoba mendefinisikan C sebagai ⋂ { X : φ ( X ) } , yang sebenarnya kita minta hanyalah suatu objek  C yang memenuhi: ∀ x ( x ∈ C ↔ ∀ X ( φ ( X ) → x ∈ X ) ) (*) Sekarang, andaikan terdapat suatu himpunan  S sedemikian sehingga φ ( S ) . Untuk memperoleh Pers. *, kita cukup mendefinisikan C dengan menggunakan Pemisahan sebagai berikut: C = { x ∈ S : ∀ X ( φ ( X ) → x ∈ X ) } . Kita serahkan sebagai latihan pemeriksaan bahwa definisi ini menghasilkan Pers. *, sebagaimana diinginkan. Strategi umum ini memungkinkan kita menghindari setiap penggunaan Komprehensi Naif yang hanya tampak diperlukan untuk mendefinisikan irisan. Dalam kasus khusus yang memulai alur pemikiran ini, yakni clo f ( o ) , strategi itu bekerja sebagai berikut. Kita memulai bukti Lema 6.3 dengan mencatat bahwa o ∈ ran ( f ) ∪ { o } dan ran ( f ) ∪ { o } tertutup terhadap  f . Jadi, kita dapat mendefinisikan objek yang diinginkan sebagai berikut: clo f ( o ) = { x ∈ ran ( f ) ∪ { o } : ( ∀ X ∋ o ) ( X  tertutup terhadap  f → x ∈ X ) } .

Soal

Soal 65.1.

Tunjukkan bahwa, untuk sebarang himpunan a , b , c , himpunan { a , b , c } ada.

Soal 65.2.

Tunjukkan bahwa, untuk sebarang himpunan a 1 , … , a n , himpunan { a 1 , … , a n } ada.

Soal 65.3.

Tunjukkan bahwa, untuk sebarang himpunan A , B : (i) himpunan semua relasi dengan domain  A dan daerah hasil  B ada; dan (ii) himpunan semua fungsi dari A ke  B ada.

Soal 65.4.

Misalkan A suatu himpunan dan ∼ suatu relasi ekuivalensi pada  A . Buktikan bahwa himpunan kelas-kelas ekuivalensi di bawah ∼ pada  A , yakni A / ∼ , ada.
