66 Ordinal

66.1 Pendahuluan

Dalam Bab 65, kita mempostulatkan adanya tahap tak hingga dalam hierarki melalui 𝑆𝑡𝑎𝑔𝑒𝑠-ℎ𝑖𝑡-𝑖𝑛𝑓𝑖𝑛𝑖𝑡𝑦 (lihat pula Aksioma Ketakhinggaan kita). Namun, dengan 𝑆𝑡𝑎𝑔𝑒𝑠-𝑘𝑒𝑒𝑝-𝑔𝑜𝑖𝑛𝑔 , kita tidak dapat berhenti pada tahap tak hingga; kita harus terus melanjutkan. Jadi, pada tahap sesudah tahap tak hingga pertama, kita membentuk semua kumpulan himpunan yang mungkin dari himpunan-himpunan yang tersedia pada tahap tak hingga pertama; lalu mengulanginya lagi, lagi, lagi, …

Secara implisit, yang terjadi di sini ialah kita mulai menggunakan gagasan “intuitif” tentang bilangan, yang menurutnya dapat ada bilangan sesudah semua bilangan asli. Secara khusus, gagasan yang terlibat ialah gagasan ordinal transfinit. Tujuan bab ini adalah membuat gagasan tersebut lebih teliti. Kita akan menjelajahi gagasan umum ordinal, lalu secara eksplisit mendefinisikan himpunan-himpunan tertentu sebagai ordinal kita.

66.3 Pengurutan Baik

Gagasan dasarnya adalah sebagai berikut:

Definisi 66.1.

Relasi  < mengurutkan A dengan baik jika dan hanya jika relasi itu memenuhi kedua syarat berikut:

  1. < terhubung, yakni untuk semua a , b ∈ A , berlaku a < b atau a = b atau b < a ;

  2. setiap himpunan bagian tak kosong dari  A mempunyai suatu anggota yang minimal menurut  < , yakni jika ∅ ≠ X ⊆ A , maka ( ∃ m ∈ X ) ( ∀ z ∈ X ) z ≮ m .

Mudah dilihat bahwa ketiga contoh yang baru saja kita pertimbangkan memang merupakan relasi pengurutan baik.

Berikut beberapa pengamatan elementer tetapi sangat penting mengenai pengurutan baik.

Proposisi 66.2.

Jika < mengurutkan A dengan baik, maka setiap himpunan bagian tak kosong dari  A mempunyai anggota terkecil yang unik menurut  < , dan < bersifat irefleksif, asimetris, serta transitif.

Bukti.

Jika X merupakan himpunan bagian tak kosong dari  A , maka X mempunyai suatu anggota  m yang minimal menurut  < , yakni ( ∀ z ∈ X ) z ≮ m . Karena < terhubung, berlaku ( ∀ z ∈ X ) m ≤ z . Jadi, m merupakan anggota terkecil dari  X menurut  < .

Untuk irefleksivitas, tetapkan a ∈ A ; Anggota terkecil dari { a } menurut  < ialah a , sehingga a ≮ a . Untuk transitivitas, andaikan a < b < c . Jika a ≮ c , keterhubungan memberikan a = c atau c < a . Dalam kasus pertama, { a , b } , dan dalam kasus kedua, { a , b , c } , tidak mempunyai suatu anggota minimal. Keduanya mustahil. Jadi, a < c . Asimetri mengikuti irefleksivitas dan transitivitas.

Proposisi 66.3.

Jika < mengurutkan A dengan baik, maka untuk sebarang formula  φ ( x ) : jika  ( ∀ a ∈ A ) ( ( ∀ b < a ) φ ( b ) → φ ( a ) ) , maka  ( ∀ a ∈ A ) φ ( a ) .

Bukti.

Kita membuktikan kontraposisinya. Andaikan ¬ ( ∀ a ∈ A ) φ ( a ) , yakni X = { x ∈ A : ¬ φ ( x ) } ≠ ∅ . Maka X mempunyai suatu anggota minimal  a menurut  < . Jadi, ( ∀ b < a ) φ ( b ) , tetapi ¬ φ ( a ) .

Sifat terakhir ini seharusnya mengingatkan Anda pada prinsip induksi kuat pada bilangan asli, yakni: jika ( ∀ n ∈ ω ) ( ( ∀ m < n ) φ ( m ) → φ ( n ) ) , maka ( ∀ n ∈ ω ) φ ( n ) . Sifat inilah yang menjadikan pengurutan baik sebagai gagasan yang sangat tangguh.27

66.4 Isomorfisme Urutan

Untuk menjelaskan betapa tangguhnya pengurutan baik, kita akan mulai dengan memperkenalkan suatu cara untuk membandingkan pengurutan-pengurutan baik.

Definisi 66.4.

Suatu pengurutan baik adalah pasangan ⟨ A , < ⟩ sedemikian sehingga < mengurutkan A dengan baik. Pengurutan baik ⟨ A , < ⟩ dan ⟨ B , ⋖ ⟩ isomorfik secara urutan jika dan hanya jika terdapat bijeksi f : A → B sedemikian sehingga: x < y jika dan hanya jika f ( x ) ⋖ f ( y ) . Dalam hal ini, kita menulis ⟨ A , < ⟩ ≅ ⟨ B , ⋖ ⟩ , dan mengatakan bahwa f merupakan suatu isomorfisme urutan.

Dalam pembahasan berikut, demi ringkasnya, kita akan berbicara tentang “isomorfisme” alih-alih “isomorfisme urutan”. Secara intuitif, isomorfisme merupakan bijeksi yang mempertahankan struktur. Berikut beberapa fakta sederhana tentang isomorfisme.

Lema 66.5.

Komposisi isomorfisme-isomorfisme merupakan isomorfisme, yakni: jika f : A → B dan g : B → C merupakan isomorfisme, maka ( g ∘ f ) : A → C merupakan isomorfisme.

Bukti.

Diserahkan sebagai latihan.

Akibat 66.6.

X ≅ Y merupakan suatu relasi ekuivalensi.

Proposisi 66.7.

Jika ⟨ A , < ⟩ dan ⟨ B , ⋖ ⟩ merupakan pengurutan baik yang isomorfik, maka isomorfisme di antara keduanya unik.

Bukti.

Misalkan f dan g merupakan isomorfisme A → B . Kita akan membuktikan hasil ini dengan induksi, yakni menggunakan Proposisi 66.3. Tetapkan a ∈ A , dan andaikan (untuk induksi) bahwa ( ∀ b < a ) f ( b ) = g ( b ) . Tetapkan x ∈ B .

Jika x ⋖ f ( a ) , maka f − 1 ( x ) < a , sehingga g ( f − 1 ( x ) ) ⋖ g ( a ) , dengan menggunakan fakta bahwa f dan g merupakan isomorfisme. Namun, karena f − 1 ( x ) < a , menurut pengandaian kita x = f ( f − 1 ( x ) ) = g ( f − 1 ( x ) ) . Jadi x ⋖ g ( a ) . Serupa dengan itu, jika x ⋖ g ( a ) , maka x ⋖ f ( a ) .

Dengan menggeneralisasi, ( ∀ x ∈ B ) ( x ⋖ f ( a ) ↔ x ⋖ g ( a ) ) . Menurut Proposisi 2.27, dari sini mengikuti bahwa f ( a ) = g ( a ) . Jadi, ( ∀ a ∈ A ) f ( a ) = g ( a ) menurut Proposisi 66.3.

Hal ini memberikan suatu gambaran tentang ketangguhan pengurutan baik. Namun, untuk terus menjelaskannya, akan berguna jika kita memperkenalkan beberapa notasi lagi.

Definisi 66.8.

Jika ⟨ A , < ⟩ merupakan pengurutan baik dengan a ∈ A , misalkan A a = { x ∈ A : x < a } . Kita mengatakan bahwa A a merupakan segmen awal sejati dari A (dan membolehkan A sendiri sebagai segmen awal tak sejati dari A ). Misalkan < a adalah pembatasan < pada segmen awal tersebut, yakni < ↾ A a 2 .

Dengan notasi ini, kita dapat menyatakan dan membuktikan bahwa tidak ada pengurutan baik yang isomorfik dengan salah satu segmen awal sejatinya.

Lema 66.9.

Jika ⟨ A , < ⟩ merupakan pengurutan baik dengan a ∈ A , maka ⟨ A , < ⟩ ≇ ⟨ A a , < a ⟩ .

Bukti.

Untuk reductio, andaikan f : A → A a merupakan suatu isomorfisme. Karena f suatu bijeksi dan A a ⊊ A , dengan menggunakan Proposisi 66.2 misalkan b ∈ A adalah anggota terkecil menurut < dari A sedemikian sehingga b ≠ f ( b ) . Kita akan menunjukkan bahwa ( ∀ x ∈ A ) ( x < b ↔ x < f ( b ) ) , sehingga menurut Proposisi 2.27 akan mengikuti bahwa b = f ( b ) , dan reductio pun selesai.

Andaikan x < b . Jadi x = f ( x ) , berdasarkan pemilihan b . Selain itu, f ( x ) < f ( b ) , karena f merupakan suatu isomorfisme. Jadi x < f ( b ) .

Andaikan x < f ( b ) . Jadi f − 1 ( x ) < b , karena f merupakan suatu isomorfisme, sehingga f − 1 ( x ) = x berdasarkan pemilihan b . Jadi x < b .

Hasil berikutnya menunjukkan, secara kasar, bahwa suatu “segmen awal” dari suatu isomorfisme merupakan suatu isomorfisme:

Lema 66.10.

Misalkan ⟨ A , < ⟩ dan ⟨ B , ⋖ ⟩ merupakan pengurutan baik. Jika f : A → B merupakan suatu isomorfisme dan a ∈ A , maka f ↾ A a : A a → B f ( a ) merupakan suatu isomorfisme.

Bukti.

Karena f merupakan suatu isomorfisme: f [ A a ] = f [ { x ∈ A : x < a } ] = f [ { f − 1 ( y ) ∈ A : f − 1 ( y ) < a } ] = { y ∈ B : y ⋖ f ( a ) } = B f ( a ) Selain itu, f ↾ A a mempertahankan urutan karena f mempertahankannya.

Dua hasil berikutnya menetapkan bahwa pengurutan-pengurutan baik selalu dapat dibandingkan:

Lema 66.11.

Misalkan ⟨ A , < ⟩ dan ⟨ B , ⋖ ⟩ merupakan pengurutan baik. Jika ⟨ A a 1 , < a 1 ⟩ ≅ ⟨ B b 1 , ⋖ b 1 ⟩ dan ⟨ A a 2 , < a 2 ⟩ ≅ ⟨ B b 2 , ⋖ b 2 ⟩ , maka a 1 < a 2  jika dan hanya jika  b 1 ⋖ b 2 .

Bukti.

Kita akan membuktikan dari kiri ke kanan; arah sebaliknya serupa. Andaikan berlaku ⟨ A a 1 , < a 1 ⟩ ≅ ⟨ B b 1 , ⋖ b 1 ⟩ dan ⟨ A a 2 , < a 2 ⟩ ≅ ⟨ B b 2 , ⋖ b 2 ⟩ , dengan f : A a 2 → B b 2 sebagai isomorfisme kita. Misalkan a 1 < a 2 ; maka ⟨ A a 1 , < a 1 ⟩ ≅ ⟨ B f ( a 1 ) , ⋖ f ( a 1 ) ⟩ menurut Lema 66.10. Jadi, ⟨ B b 1 , ⋖ b 1 ⟩ ≅ ⟨ B f ( a 1 ) , ⋖ f ( a 1 ) ⟩ , sehingga b 1 = f ( a 1 ) menurut Lema 66.9. Sekarang b 1 ⋖ b 2 karena rentang f adalah B b 2 .

Teorema 66.12.

Untuk sembarang dua pengurutan baik, salah satunya isomorfik dengan suatu segmen awal (yang tidak harus sejati) dari yang lain.

Bukti.

Misalkan ⟨ A , < ⟩ dan ⟨ B , ⋖ ⟩ merupakan pengurutan baik. Dengan menggunakan Pemisahan, misalkan f = { ⟨ a , b ⟩ ∈ A × B : ⟨ A a , < a ⟩ ≅ ⟨ B b , ⋖ b ⟩ } . Menurut Lema 66.11, a 1 < a 2 jika dan hanya jika b 1 ⋖ b 2 bagi semua ⟨ a 1 , b 1 ⟩ , ⟨ a 2 , b 2 ⟩ ∈ f . Jadi, f : dom ( f ) → ran ( f ) merupakan suatu isomorfisme.

Jika a 2 ∈ dom ( f ) dan a 1 < a 2 , maka a 1 ∈ dom ( f ) menurut Lema 66.10; jadi dom ( f ) merupakan suatu segmen awal dari A . Serupa dengan itu, ran ( f ) merupakan suatu segmen awal dari B . Untuk reductio, andaikan keduanya merupakan segmen awal sejati. Maka, misalkan a adalah anggota terkecil menurut < dari A ∖ dom ( f ) , sehingga dom ( f ) = A a , dan misalkan b adalah anggota terkecil menurut ⋖ dari B ∖ ran ( f ) , sehingga ran ( f ) = B b . Jadi f : A a → B b merupakan suatu isomorfisme, dan karena itu ⟨ a , b ⟩ ∈ f , suatu kontradiksi.

66.5 Konstruksi von Neumann atas Ordinal

Teorema 66.12 memunculkan suatu gagasan. Kita dapat memperkenalkan objek-objek tertentu, yang disebut tipe urutan, untuk bertindak sebagai wakil pengurutan baik. Dengan menulis ord ( A , < ) untuk tipe urutan dari pengurutan baik ⟨ A , < ⟩ , kita berharap dapat memperoleh dua prinsip berikut: ord ( A , < ) = ord ( B , ⋖ )  jika dan hanya jika  ⟨ A , < ⟩ ≅ ⟨ B , ⋖ ⟩ ord ( A , < ) < ord ( B , ⋖ )  jika dan hanya jika  ⟨ A , < ⟩ ≅ ⟨ B b , ⋖ b ⟩  untuk suatu  b ∈ B Selain itu, kita mungkin berharap dapat memperkenalkan tipe-tipe urutan sebagai himpunan-himpunan tertentu, sama seperti kita dapat memperkenalkan bilangan asli sebagai himpunan-himpunan tertentu.

Cara paling umum untuk melakukannya—dan pendekatan yang akan kita ikuti—adalah mendefinisikan tipe-tipe urutan ini melalui himpunan-himpunan terurut baik kanonik tertentu. Himpunan-himpunan kanonik ini pertama kali diperkenalkan oleh von Neumann:

Definisi 66.13.

Himpunan A bersifat transitif jika dan hanya jika ( ∀ x ∈ A ) x ⊆ A . Kemudian, A merupakan suatu ordinal jika dan hanya jika A bersifat transitif dan diurutkan dengan baik oleh ∈ .

Dalam pembahasan berikut, kita akan menggunakan huruf-huruf Yunani untuk ordinal. Langsung dari definisi mengikuti bahwa, jika α merupakan suatu ordinal, maka ⟨ α , ∈ α ⟩ merupakan suatu pengurutan baik, dengan ∈ α = { ⟨ x , y ⟩ ∈ α 2 : x ∈ y } . Jadi, dengan sedikit menyalahgunakan notasi, kita dapat mengatakan bahwa α sendiri merupakan suatu pengurutan baik.

Berikut beberapa ordinal pertama kita: ∅ , { ∅ } , { ∅ , { ∅ } } , { ∅ , { ∅ } , { ∅ , { ∅ } } } , … Anda akan memperhatikan bahwa ini merupakan beberapa ordinal pertama yang kita jumpai dalam Aksioma Ketakhinggaan kita, yakni dalam definisi von Neumann atas ω (lihat Bagian 65.6). Hal ini bukan kebetulan. Definisi von Neumann atas ordinal memperlakukan bilangan asli sebagai ordinal, tetapi juga membolehkan ordinal transfinit.

Seperti biasa, kini kita dapat bertanya: apakah semua ini merupakan ordinal? Ataukah von Neumann sekadar memberi kita beberapa himpunan yang dapat kita perlakukan sebagai ordinal? Jenis pembahasan yang mungkin dilakukan mengenai pertanyaan ini serupa dengan pembahasan kita dalam Bagian 2.2, Bagian 5.5, Bagian 6.4, dan Bagian 65.8, sehingga kita tidak akan berpanjang lebar mengenai hal itu. Sebaliknya, dalam pembahasan berikut, kita cukup menggunakan “ordinal” untuk membicarakan “ordinal von Neumann”.

66.6 Sifat-Sifat Dasar Ordinal

Kita telah mengamati bahwa beberapa ordinal pertama merupakan bilangan asli. Alasan utama untuk mengembangkan teori ordinal adalah memperluas prinsip induksi yang berlaku pada bilangan asli. Kita akan menuju hasil ini melalui serangkaian hasil elementer.

Lema 66.14.

Setiap anggota dari suatu ordinal merupakan suatu ordinal.

Bukti.

Misalkan α suatu ordinal dengan b ∈ α . Karena α bersifat transitif, b ⊆ α . Jadi, ∈ mengurutkan b dengan baik karena ∈ mengurutkan α dengan baik.

Untuk melihat bahwa b bersifat transitif, andaikan x ∈ c ∈ b . Jadi, c ∈ α karena b ⊆ α . Sekali lagi, karena α bersifat transitif, c ⊆ α , sehingga x ∈ α . Jadi x , c , b ∈ α . Namun, ∈ mengurutkan α dengan baik, sehingga ∈ merupakan relasi transitif pada α menurut Proposisi 66.2. Karena itu, dari x ∈ c ∈ b kita memperoleh x ∈ b . Dengan menggeneralisasi, c ⊆ b .

Akibat 66.15.

α = { β ∈ α : β  merupakan suatu ordinal } , untuk setiap ordinal  α .

Bukti.

Langsung dari Lema 66.14.

Gagasan kasar di balik dua hasil utama berikut, Teorema 66.16 dan Teorema 66.17, adalah bahwa ordinal-ordinal itu sendiri diurutkan dengan baik oleh relasi keanggotaan:

Teorema 66.16.

Induksi Transfinit

Untuk sembarang formula φ ( x ) : jika  ∃ α φ ( α ) , maka  ∃ α ( φ ( α ) ∧ ( ∀ β ∈ α ) ¬ φ ( β ) ) dengan kuantor-kuantor yang ditampilkan secara implisit dibatasi pada ordinal.

Bukti.

Andaikan φ ( α ) untuk suatu ordinal α . Jika ( ∀ β ∈ α ) ¬ φ ( β ) , maka pembuktian selesai. Jika tidak, karena α merupakan suatu ordinal, terdapat suatu anggota terkecil menurut ∈ yang memenuhi φ , dan anggota ini merupakan suatu ordinal menurut Lema 66.14.

Perhatikan bahwa kita juga dapat mengungkapkan Teorema 66.16 sebagai skema: jika  ∀ α ( ( ∀ β ∈ α ) φ ( β ) → φ ( α ) ) , maka  ∀ α φ ( α ) cukup dengan mengambil ¬ φ ( α ) dalam Teorema 66.16, lalu melakukan manipulasi logis elementer.

Teorema 66.17.

Trikotomi

α ∈ β ∨ α = β ∨ β ∈ α , untuk sembarang ordinal α dan β .

Bukti.

Pembuktian dilakukan dengan induksi ganda, yakni dengan menggunakan Teorema 66.16 dua kali. Katakan bahwa x dapat dibandingkan dengan y jika dan hanya jika x ∈ y ∨ x = y ∨ y ∈ x .

Untuk induksi, andaikan setiap ordinal dalam  α dapat dibandingkan dengan setiap ordinal. Untuk induksi berikutnya, andaikan α dapat dibandingkan dengan setiap ordinal dalam  β . Kita akan menunjukkan bahwa α dapat dibandingkan dengan  β . Dengan induksi pada  β , akan mengikuti bahwa α dapat dibandingkan dengan setiap ordinal; kemudian, dengan induksi pada  α , setiap ordinal dapat dibandingkan dengan setiap ordinal, sebagaimana diperlukan. Cukup andaikan bahwa α ∉ β dan β ∉ α , lalu tunjukkan bahwa α = β .

Untuk menunjukkan bahwa α ⊆ β , tetapkan γ ∈ α ; ini merupakan suatu ordinal menurut Lema 66.14. Jadi, menurut hipotesis induksi pertama, γ dapat dibandingkan dengan β . Namun, jika γ = β ataupun β ∈ γ , maka β ∈ α (dengan menggunakan fakta bahwa α bersifat transitif jika diperlukan), berlawanan dengan pengandaian kita; jadi γ ∈ β . Dengan menggeneralisasi, α ⊆ β .

Penalaran yang persis serupa, dengan menggunakan hipotesis induksi kedua, menunjukkan bahwa β ⊆ α . Jadi α = β .

Dengan demikian, terkadang kita akan menulis α < β alih-alih α ∈ β , karena ∈ berperilaku sebagai relasi pengurutan. Tidak ada alasan mendalam untuk hal ini, selain kelazimannya dan karena lebih mudah menulis α ≤ β daripada α ∈ β ∨ α = β .28

Berikut dua konsekuensi singkat dari hasil-hasil terakhir kita; yang pertama menerapkan notasi baru kita:

Akibat 66.18.

Jika ∃ α φ ( α ) , maka ∃ α ( φ ( α ) ∧ ∀ β ( φ ( β ) → α ≤ β ) ) . Selain itu, untuk sembarang ordinal α , β , γ , berlaku baik α ∉ α maupun α ∈ β ∈ γ → α ∈ γ .

Bukti.

Sama seperti Proposisi 66.2.

Akibat 66.19.

A merupakan suatu ordinal jika dan hanya jika A merupakan suatu himpunan transitif dari ordinal-ordinal.

Bukti.

Dari kiri ke kanan. Menurut Lema 66.14. Dari kanan ke kiri. Jika A merupakan suatu himpunan transitif dari ordinal-ordinal, maka ∈ mengurutkan A dengan baik menurut Teorema 66.16 dan Teorema 66.17.

Di atas, kita menyarikan Teorema 66.16 dan Teorema 66.17 sebagai pernyataan bahwa ∈ mengurutkan ordinal-ordinal dengan baik. Namun, kita harus sangat berhati-hati terhadap pernyataan semacam ini karena hasil berikut:

Teorema 66.20.

Paradoks Burali–Forti

Tidak ada himpunan semua ordinal.

Bukti.

Untuk reductio, andaikan O merupakan himpunan semua ordinal. Jika α ∈ β ∈ O , maka α merupakan suatu ordinal menurut Lema 66.14, sehingga α ∈ O . Jadi O bersifat transitif, dan karena itu O merupakan suatu ordinal menurut Akibat 66.19. Maka O ∈ O , bertentangan dengan Akibat 66.18.

Hasil ini dinamai menurut Burali-Forti. Namun, Cantor-lah yang pada tahun 1899—dalam sebuah surat kepada Dedekind—pertama kali melihat dengan jelas kontradiksi dalam pengandaian bahwa terdapat suatu himpunan semua ordinal. Sebagaimana dijelaskan van Heijenoort:

Burali-Forti sendiri menganggap kontradiksi tersebut menetapkan, melalui reductio ad absurdum, hasil bahwa pengurutan alami ordinal hanyalah suatu urutan parsial. (Heijenoort, 1967, p. 105)

Dengan mengesampingkan kekeliruan Burali-Forti, kita dapat merangkum uraian di atas sebagai berikut. Ordinal merupakan himpunan-himpunan yang secara individual diurutkan dengan baik oleh keanggotaan, dan secara kolektif diurutkan dengan baik oleh keanggotaan (tanpa secara kolektif membentuk suatu himpunan).

Sebagai penutup, berikut beberapa sifat dasar lain tentang ordinal yang mengikuti dari Teorema 66.16 dan Teorema 66.17.

Proposisi 66.21.

Setiap barisan ordinal yang menurun secara ketat bersifat hingga.

Bukti.

Setiap barisan ordinal tak hingga yang menurun secara ketat α 0 > α 1 > α 2 > … tidak mempunyai anggota minimal menurut < , bertentangan dengan Teorema 66.16.

Proposisi 66.22.

α ⊆ β ∨ β ⊆ α , untuk sembarang ordinal α , β .

Bukti.

Jika α ∈ β , maka α ⊆ β karena β bersifat transitif. Serupa dengan itu, jika β ∈ α , maka β ⊆ α . Jika α = β , maka α ⊆ β dan β ⊆ α . Jadi, menurut Teorema 66.17, pembuktian selesai.

Proposisi 66.23.

α = β jika dan hanya jika α ≅ β , untuk sembarang ordinal α , β .

Bukti.

Ordinal-ordinal merupakan pengurutan baik; jadi, hasil ini langsung mengikuti dari Trikotomi (Teorema 66.17) dan Lema 66.9.

66.7 Penggantian

Dalam Bagian 66.5, kita memotivasi pengenalan ordinal dengan menyarankan bahwa kita dapat memperlakukannya sebagai tipe urutan, yakni sebagai wakil kanonik bagi pengurutan baik. Agar hal itu berhasil, kita perlu membuktikan bahwa setiap pengurutan baik isomorfik dengan suatu ordinal. Ini akan memungkinkan kita mendefinisikan ord ( A , < ) sebagai ordinal α sedemikian sehingga ⟨ A , < ⟩ ≅ α .

Sayangnya, kita tidak dapat membuktikan hasil yang diinginkan hanya dengan aksioma-aksioma yang telah diperkenalkan sejauh ini. (Kita akan melihat alasannya dalam Bagian 68.2, tetapi untuk saat ini pokoknya ialah: kita tidak dapat melakukannya.) Kita memerlukan suatu gagasan baru, yakni:

Aksioma.

Skema Penggantian

Untuk sembarang formula φ ( x , y ) , berikut ini merupakan suatu aksioma:

untuk sembarang A , jika ( ∀ x ∈ A ) ∃ ! y φ ( x , y ) , maka { y : ( ∃ x ∈ A ) φ ( x , y ) } ada.

Seperti Pemisahan, ini merupakan suatu skema: skema tersebut menghasilkan tak berhingga banyaknya aksioma, satu bagi setiap formula φ yang berbeda. Skema ini juga dapat (dan biasanya memang) dituliskan sebagai berikut:

Untuk sembarang formula φ ( x , y ) yang tidak memuat “ B ”, berikut ini merupakan suatu aksioma: ∀ A [ ( ∀ x ∈ A ) ∃ ! y φ ( x , y ) → ∃ B ∀ y ( y ∈ B ↔ ( ∃ x ∈ A ) φ ( x , y ) ) ]

Namun, ketika pertama kali dijumpai, rumus ini cukup berbelit-belit. Konsekuensi singkat Penggantian berikut mungkin mengungkapkan gagasan intuitif yang sedang kita gunakan dengan lebih jelas:29

Akibat 66.24.

Untuk sembarang suku τ ( x ) dan sembarang himpunan A , himpunan berikut ada: { τ ( x ) : x ∈ A } = { y : ( ∃ x ∈ A ) y = τ ( x ) } .

Bukti.

Karena τ merupakan suatu suku, ∀ x ∃ ! y τ ( x ) = y . Terlebih lagi, ( ∀ x ∈ A ) ∃ ! y τ ( x ) = y . Jadi, { y : ( ∃ x ∈ A ) τ ( x ) = y } ada menurut Penggantian.

Hal ini menunjukkan bahwa “Penggantian” merupakan nama yang tepat bagi aksioma tersebut: dengan diberikannya suatu himpunan A , Anda dapat membentuk himpunan baru, { τ ( x ) : x ∈ A } , dengan mengganti setiap anggota A dengan citranya di bawah  τ . Memang, mengikuti notasi bagi citra suatu himpunan di bawah suatu fungsi, kita dapat menulis τ [ A ] untuk { τ ( x ) : x ∈ A } .

Namun, yang penting, τ merupakan suatu suku. Suku itu tidak harus merupakan (nama bagi) suatu fungsi, dalam pengertian Bagian 3.3, yakni suatu himpunan tertentu dari pasangan terurut. Lagi pula, jika f merupakan suatu fungsi (dalam pengertian itu), maka himpunan f [ A ] = { f ( x ) : x ∈ A } hanyalah suatu himpunan bagian tertentu dari ran ( f ) , dan keberadaannya sudah dijamin hanya dengan menggunakan aksioma-aksioma  𝐙 − .30 Sebaliknya, Penggantian merupakan tambahan yang kuat bagi aksioma-aksioma kita, sebagaimana akan kita lihat dalam Bab 68.

66.8 𝐙𝐅 − : suatu tonggak penting

Pertanyaan tentang bagaimana Penggantian dapat dibenarkan (jika memang dapat) tidaklah sederhana. Karena itu, kita akan menundanya hingga Bab 68. Namun, dengan penambahan Penggantian, kita telah mencapai tonggak penting lain. Kini kita mempunyai semua aksioma yang diperlukan bagi teori 𝐙𝐅 − . Secara terperinci:

Definisi 66.25.

Teori 𝐙𝐅 − mempunyai aksioma-aksioma berikut: Ekstensionalitas, Gabungan, Pasangan, Himpunan Kuasa, Ketakhinggaan, serta semua instans skema Pemisahan dan Penggantian. Dengan kata lain, 𝐙𝐅 − menambahkan Penggantian pada 𝐙 − .

Nama ini merupakan singkatan bagi teori himpunan Zermelo–Fraenkel (dikurangi sesuatu yang akan kita bahas kemudian). Fraenkel mendapat kehormatan tersebut karena ia dianggap berjasa merumuskan Penggantian dalam 1922, meskipun perumusan tepat yang pertama berasal dari Skolem (1922).

66.9 Ordinal sebagai Tipe Urutan

Berbekal Penggantian, dan dengan demikian kini bekerja dalam 𝐙𝐅 − , akhirnya kita dapat membuktikan hasil yang telah kita tuju:

Teorema 66.26.

Setiap pengurutan baik isomorfik dengan suatu ordinal yang unik.

Bukti.

Misalkan ⟨ A , < ⟩ suatu pengurutan baik. Menurut Proposisi 66.23, pengurutan itu isomorfik dengan paling banyak satu ordinal. Jadi, untuk reductio, andaikan ⟨ A , < ⟩ tidak isomorfik dengan ordinal mana pun. Pertama-tama kita akan “membuat ⟨ A , < ⟩ sekecil mungkin”. Secara terperinci: jika suatu segmen awal sejati ⟨ A a , < a ⟩ tidak isomorfik dengan ordinal mana pun, terdapat a ∈ A terkecil dengan sifat tersebut; kemudian misalkan B = A a dan ⋖ = < a . Jika tidak, misalkan B = A dan ⋖ = < .

Menurut definisi, setiap segmen awal sejati dari B isomorfik dengan suatu ordinal, yang unik seperti di atas. Jadi, menurut Penggantian, himpunan berikut ada dan merupakan suatu fungsi: f = { ⟨ β , b ⟩ : b ∈ B  dan  β ≅ ⟨ B b , ⋖ b ⟩ } Untuk menyelesaikan reductio, kita akan menunjukkan bahwa f merupakan suatu isomorfisme α → B , untuk suatu ordinal α .

Jelas bahwa ran ( f ) = B . Menurut Lema 66.11, f mempertahankan pengurutan, yakni γ ∈ β jika dan hanya jika f ( γ ) ⋖ f ( β ) . Untuk menunjukkan bahwa dom ( f ) merupakan suatu ordinal, menurut Akibat 66.19 cukup ditunjukkan bahwa dom ( f ) bersifat transitif. Jadi, tetapkan β ∈ dom ( f ) , yakni β ≅ ⟨ B b , ⋖ b ⟩ untuk suatu b . Jika γ ∈ β , maka γ ∈ dom ( f ) menurut Lema 66.10; dengan menggeneralisasi, β ⊆ dom ( f ) .

Hasil ini mengabsahkan definisi berikut, yang ingin kita berikan sejak Bagian 66.5:

Definisi 66.27.

Jika ⟨ A , < ⟩ merupakan suatu pengurutan baik, maka tipe urutannya, ord ( A , < ) , adalah ordinal unik α sedemikian sehingga ⟨ A , < ⟩ ≅ α .

Selain itu, definisi ini mengabsahkan dua prinsip yang baik:

Akibat 66.28.

Jika ⟨ A , < ⟩ dan ⟨ B , ⋖ ⟩ merupakan pengurutan baik: ord ( A , < ) = ord ( B , ⋖ )  jika dan hanya jika  ⟨ A , < ⟩ ≅ ⟨ B , ⋖ ⟩ ord ( A , < ) ∈ ord ( B , ⋖ )  jika dan hanya jika  ⟨ A , < ⟩ ≅ ⟨ B b , ⋖ b ⟩  untuk suatu  b ∈ B

Bukti.

Identitas tersebut berlaku menurut Proposisi 66.23. Untuk membuktikan klaim kedua, misalkan ord ( A , < ) = α dan ord ( B , ⋖ ) = β , dan misalkan f : β → ⟨ B , ⋖ ⟩ merupakan isomorfisme kita. Maka: α ∈ β  jika dan hanya jika  f ↾ α : α → B f ( α )  merupakan suatu isomorfisme  jika dan hanya jika  ⟨ A , < ⟩ ≅ ⟨ B f ( α ) , ⋖ f ( α ) ⟩  jika dan hanya jika  ⟨ A , < ⟩ ≅ ⟨ B b , ⋖ b ⟩  untuk suatu  b ∈ B menurut Proposisi 66.7, Lema 66.10, dan Akibat 66.15.

66.10 Ordinal Suksesor dan Limit

Dalam beberapa bab berikutnya, kita akan banyak menggunakan ordinal. Karena itu, akan berguna jika kita memperkenalkan beberapa gagasan sederhana.

Definisi 66.29.

Untuk sembarang ordinal α , suksesor-nya adalah α + = α ∪ { α } . Kita mengatakan bahwa α merupakan suatu ordinal suksesor jika β + = α untuk suatu ordinal  β . Kita mengatakan bahwa α merupakan suatu ordinal limit jika dan hanya jika α tidak kosong dan bukan ordinal suksesor.

Hasil berikut menunjukkan bahwa ini merupakan gagasan suksesor yang tepat:

Proposisi 66.30.

Untuk sembarang ordinal α :

  1. α ∈ α + ;

  2. α + merupakan suatu ordinal;

  3. tidak ada ordinal β sedemikian sehingga α ∈ β ∈ α + .

Bukti.

Secara trivial, α ∈ α ∪ { α } = α + . Demikian pula, α + merupakan suatu himpunan transitif dari ordinal-ordinal, dan karena itu merupakan suatu ordinal menurut Akibat 66.19. Tidak mungkin pula bahwa α ∈ β ∈ α + , sebab dalam hal itu berlaku β ∈ α atau β = α , bertentangan dengan Akibat 66.18.

Hal ini juga mengabsahkan suatu varian pembuktian dengan induksi transfinit:

Teorema 66.31.

Induksi Transfinit Sederhana

Misalkan φ ( x ) suatu formula sedemikian sehingga:

  1. φ ( ∅ ) ; dan

  2. untuk sembarang ordinal α , jika φ ( α ) maka φ ( α + ) ; dan

  3. jika α merupakan suatu ordinal limit dan ( ∀ β ∈ α ) φ ( β ) , maka φ ( α ) .

Maka ∀ α φ ( α ) .

Bukti.

Kita membuktikan kontraposisinya. Jadi, andaikan terdapat suatu ordinal yang memenuhi ¬ φ ; misalkan γ merupakan ordinal terkecil semacam itu. Maka berlaku salah satu dari: γ = ∅ ; atau γ = α + untuk suatu α sedemikian sehingga φ ( α ) ; atau γ merupakan suatu ordinal limit dan ( ∀ β ∈ γ ) φ ( β ) .

Sedikit notasi terakhir akan berguna kemudian:

Definisi 66.32.

Jika X merupakan suatu himpunan ordinal, maka lsub ( X ) = ⋃ α ∈ X α + .

Di sini, “lsub” merupakan singkatan dari “least strict upper bound” (batas atas ketat terkecil).31 Hasil berikut menjelaskan hal ini:

Proposisi 66.33.

Jika X merupakan suatu himpunan ordinal, lsub ( X ) merupakan ordinal terkecil yang lebih besar daripada setiap ordinal dalam X .

Bukti.

Misalkan Y = { α + : α ∈ X } , sehingga lsub ( X ) = ⋃ Y . Karena ordinal bersifat transitif dan setiap anggota suatu ordinal merupakan suatu ordinal, lsub ( X ) merupakan suatu himpunan transitif dari ordinal-ordinal, dan karena itu merupakan suatu ordinal menurut Akibat 66.19.

Jika α ∈ X , maka α + ∈ Y , sehingga α + ⊆ ⋃ Y = lsub ( X ) , dan karena itu α ∈ lsub ( X ) . Jadi, lsub ( X ) lebih besar secara ketat daripada setiap ordinal dalam X .

Sebaliknya, jika α ∈ lsub ( X ) , maka α ∈ β + ∈ Y untuk suatu β ∈ X , sehingga α ≤ β ∈ X . Jadi, lsub ( X ) merupakan batas atas ketat terkecil bagi X .

Soal

Soal 66.1.

Bagian 66.2 menyajikan tiga contoh pengurutan pada bilangan asli. Periksa bahwa masing-masing merupakan pengurutan baik.

Soal 66.2.

Buktikan Lema 66.5.

Soal 66.3.

Lengkapi “penalaran yang persis serupa” dalam pembuktian Teorema 66.17.

Soal 66.4.

Buktikan bahwa, jika setiap anggota X merupakan suatu ordinal, maka ⋃ X merupakan suatu ordinal.
