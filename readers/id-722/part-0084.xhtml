67 Tahap dan Peringkat

67.1 Mendefinisikan Tahap-Tahap sebagai V α

Dalam Bab 66, kita mendefinisikan pengurutan baik dan ordinal (von Neumann). Dalam bab ini, kita akan menggunakannya untuk mencirikan hierarki himpunan itu sendiri. Untuk melakukannya, ingat bahwa dalam Bagian 66.10, kita mendefinisikan gagasan ordinal suksesor dan limit. Kita menggunakan gagasan-gagasan tersebut dalam definisi berikut:

Definisi 67.1.

V ∅ = ∅ V α + = ℘ ( V α ) untuk sembarang ordinal  α V α = ⋃ γ < α V γ ketika  α  merupakan ordinal limit

Ini akan menjadi definisi melalui rekursi transfinit pada ordinal. Dalam hal ini, kita perlu membandingkannya dengan definisi rekursif fungsi-fungsi pada bilangan asli.32 Seperti ketika menangani bilangan asli, kita mendefinisikan suatu kasus dasar dan kasus-kasus suksesor; tetapi ketika menangani ordinal, kita juga perlu menjelaskan perilaku kasus-kasus limit.

Definisi V α ini akan menjadi suatu tonggak penting. Secara informal, kita telah memotivasi hierarki himpunan sebagai pembentukan himpunan melalui tahap-tahap. Pada dasarnya, V α tepat merupakan tahap-tahap tersebut. Namun, yang penting, ini merupakan pencirian internal atas tahap-tahap. Alih-alih menyarankan suatu model yang mungkin bagi teori tersebut, kita akan mendefinisikan tahap-tahap itu di dalam teori himpunan kita.

67.2 Teorema(-Teorema) Rekursi Transfinit

Namun, hal pertama yang harus kita lakukan ialah memastikan bahwa Definisi 67.1 merupakan definisi yang berhasil. Secara lebih umum, kita perlu membuktikan bahwa setiap upaya memberikan suatu definisi transfinit melalui rekursi (transfinit) akan berhasil. Itulah tujuan bagian ini.

Peringatan: materi ini rumit. Meskipun demikian, pesan utamanya cukup sederhana: Induksi Transfinit bersama Penggantian menjamin keabsahan (beberapa versi) rekursi transfinit.33

Definisi 67.2.

Misalkan τ ( x ) suatu suku; misalkan f suatu fungsi; misalkan α suatu ordinal. Kita mengatakan bahwa f merupakan suatu aproksimasi- α bagi τ jika dan hanya jika berlaku baik dom ( f ) = α maupun ( ∀ β ∈ α ) f ( β ) = τ ( f ↾ β ) .

Lema 67.3.

Rekursi Terbatas

Untuk sembarang suku τ ( x ) dan sembarang ordinal α , terdapat suatu aproksimasi- α yang unik bagi τ .

Bukti.

Kita akan menunjukkan bahwa, untuk setiap γ ≤ α , terdapat suatu aproksimasi- γ yang unik.

Pertama-tama kita menetapkan keunikan. Misalkan g dan h (berturut-turut) merupakan aproksimasi- γ dan aproksimasi- δ . Induksi transfinit pada argumen keduanya menunjukkan bahwa g ( β ) = h ( β ) untuk setiap β ∈ dom ( g ) ∩ dom ( h ) = γ ∩ δ = min ( γ , δ ) . Jadi, aproksimasi kita unik (jika ada), dan semuanya bersepakat pada semua nilai.

Untuk menetapkan keberadaan, kini kita menggunakan induksi transfinit sederhana (Teorema 66.31) pada ordinal δ ≤ α .

Fungsi kosong secara trivial merupakan suatu aproksimasi- ∅ .

Jika g merupakan suatu aproksimasi- γ , maka g ∪ { ⟨ γ , τ ( g ) ⟩ } merupakan suatu aproksimasi- γ + .

Jika γ merupakan suatu ordinal limit dan g δ merupakan suatu aproksimasi- δ untuk semua δ < γ , misalkan g = ⋃ δ ∈ γ g δ . Ini merupakan suatu fungsi karena berbagai g δ kita bersepakat pada semua nilai. Jika δ ∈ γ , maka g ( δ ) = g δ + ( δ ) = τ ( g δ + ↾ δ ) = τ ( g ↾ δ ) .

Ini menyelesaikan pembuktian melalui induksi transfinit.

Jika kita membolehkan diri mendefinisikan suatu suku alih-alih suatu fungsi, maka kita dapat menghapus batas α dari hasil sebelumnya. Dalam pernyataan dan pembuktian hasil berikut, jika σ merupakan suatu suku, kita misalkan σ ↾ α = { ⟨ β , σ ( β ) ⟩ : β ∈ α } .

Teorema 67.4.

Rekursi Umum

Untuk sembarang suku τ ( x ) , kita dapat secara eksplisit mendefinisikan suatu suku σ ( x ) sedemikian sehingga σ ( α ) = τ ( σ ↾ α ) untuk sembarang ordinal  α .

Bukti.

Untuk setiap α , menurut Lema 67.3 terdapat suatu aproksimasi- α yang unik, f α , bagi  τ . Definisikan σ ( α ) sebagai f α + ( α ) . Sekarang: σ ( α ) = f α + ( α ) = τ ( f α + ↾ α ) = τ ( { ⟨ β , f α + ( β ) ⟩ : β ∈ α } ) = τ ( { ⟨ β , f β + ( β ) ⟩ : β ∈ α } ) = τ ( σ ↾ α ) dengan memperhatikan bahwa f β + ( β ) = f α + ( β ) untuk semua β < α , sebagaimana dalam Lema 67.3.

Perhatikan bahwa Teorema 67.4 merupakan suatu skema. Yang penting, kita tidak dapat mengharapkan σ mendefinisikan suatu fungsi, yakni suatu jenis himpunan tertentu, sebab dalam hal itu dom ( σ ) akan menjadi himpunan semua ordinal, bertentangan dengan Paradoks Burali-Forti (Teorema 66.20).

Namun, masih perlu ditunjukkan bahwa Teorema 67.4 mengabsahkan definisi kita atas V α . Hal ini mungkin tidak langsung jelas; tetapi akan tampak dengan suatu versi terakhir yang sederhana dari rekursi transfinit.

Teorema 67.5.

Rekursi Sederhana

Untuk sembarang suku τ ( x ) dan θ ( x ) serta sembarang himpunan A , kita dapat secara eksplisit mendefinisikan suatu suku σ ( x ) sedemikian sehingga: σ ( ∅ ) = A σ ( α + ) = τ ( σ ( α ) ) untuk sembarang ordinal  α σ ( α ) = θ ( ran ( σ ↾ α ) ) ketika  α  merupakan ordinal limit

Bukti.

Kita mulai dengan mendefinisikan suatu suku, ξ ( x ) , sebagai berikut: ξ ( x ) = { A jika  x  bukan fungsi yang domainnya ordinal tak kosong; jika tidak: τ ( x ( α ) ) jika  dom ( x ) = α + θ ( ran ( x ) ) jika  dom ( x )  merupakan ordinal limit Menurut Teorema 67.4, terdapat suatu suku σ ( x ) sedemikian sehingga σ ( α ) = ξ ( σ ↾ α ) untuk setiap ordinal α ; selain itu, σ ↾ α merupakan suatu fungsi dengan domain α . Kita menunjukkan bahwa σ mempunyai sifat-sifat yang diperlukan, dengan induksi transfinit sederhana (Teorema 66.31).

Pertama, σ ( ∅ ) = ξ ( ∅ ) = A .

Berikutnya, σ ( α + ) = ξ ( σ ↾ α + ) = τ ( σ ↾ α + ( α ) ) = τ ( σ ( α ) ) .

Terakhir, σ ( α ) = ξ ( σ ↾ α ) = θ ( ran ( σ ↾ α ) ) , jika α merupakan suatu limit.

Sekarang, untuk mengabsahkan Definisi 67.1, cukup ambil A = ∅ dan τ ( x ) = ℘ ( x ) serta θ ( x ) = ⋃ x . Akhirnya, ini mengabsahkan definisi V α !

67.3 Sifat-Sifat Dasar Tahap

Untuk menonjolkan arti penting definisi V α bagi landasan teori, kita akan menyajikan beberapa hasil dasar mengenainya. Kita mulai dengan sebuah definisi:34

Definisi 67.6.

Himpunan A disebut poten jika dan hanya jika ∀ x ( ( ∃ y ∈ A ) x ⊆ y → x ∈ A ) .

Lema 67.7.

Untuk setiap ordinal α :

  1. Setiap V α bersifat transitif.

  2. Setiap V α bersifat poten.

  3. Jika γ ∈ α , maka V γ ∈ V α (dan karena itu juga V γ ⊆ V α berdasarkan enumi 1).

Bukti.

Kita membuktikannya dengan induksi transfinit (serentak). Untuk langkah induksi, andaikan enumi 1–enumi 3 berlaku bagi setiap ordinal β < α .

Kasus α = ∅ bersifat langsung.

Andaikan α = β + . Untuk menunjukkan enumi 3, jika γ ∈ α , maka V γ ⊆ V β menurut hipotesis, sehingga V γ ∈ ℘ ( V β ) = V α . Untuk menunjukkan enumi 2, andaikan A ⊆ B ∈ V α , yakni A ⊆ B ⊆ V β ; maka A ⊆ V β , sehingga A ∈ V α . Untuk menunjukkan enumi 1, perhatikan bahwa jika x ∈ A ∈ V α , maka A ⊆ V β , sehingga x ∈ V β , lalu x ⊆ V β karena V β transitif menurut hipotesis, dan dengan demikian x ∈ V α .

Andaikan α merupakan ordinal limit. Untuk menunjukkan enumi 3, jika γ ∈ α , maka γ ∈ γ + ∈ α , sehingga V γ ∈ V γ + menurut asumsi, dan karenanya V γ ∈ ⋃ β ∈ α V β = V α . Untuk menunjukkan enumi 1 dan enumi 2, cukup perhatikan bahwa gabungan himpunan-himpunan transitif (berturut-turut, poten) bersifat transitif (berturut-turut, poten).

Lema 67.8.

Untuk setiap ordinal α , V α ∉ V α .

Bukti.

Dengan induksi transfinit. Jelas bahwa V ∅ ∉ V ∅ .

Jika V α + ∈ V α + = ℘ ( V α ) , maka V α + ⊆ V α ; dan karena V α ∈ V α + berdasarkan Lema 67.7, kita memperoleh V α ∈ V α . Dengan mengambil kontraposisinya: jika V α ∉ V α , maka V α + ∉ V α + .

Jika α merupakan limit dan V α ∈ V α = ⋃ β ∈ α V β , maka V α ∈ V β untuk suatu β ∈ α ; tetapi kemudian V β ∈ V α juga, sehingga V β ∈ V β berdasarkan Lema 67.7 (dua kali). Dengan mengambil kontraposisinya, jika V β ∉ V β untuk semua β ∈ α , maka V α ∉ V α .

Akibat 67.9.

Untuk sembarang ordinal α , β : α ∈ β jika dan hanya jika V α ∈ V β .

Bukti.

Lema 67.7 memberikan satu arah. Sebaliknya, andaikan V α ∈ V β . Maka α ≠ β berdasarkan Lema 67.8; dan β ∉ α , sebab jika tidak, kita akan memperoleh V β ∈ V α , dan kemudian V β ∈ V β berdasarkan Lema 67.7 (dua kali), bertentangan dengan Lema 67.8. Jadi, α ∈ β berdasarkan Trikotomi.

Semua ini memungkinkan kita memandang setiap V α sebagai tahap ke- α dalam hierarki. Berikut alasannya.

V α kita tentu dapat dipandang terbentuk melalui suatu proses iteratif, sebab penggunaan ordinal oleh kita melacak gagasan iterasi. Selain itu, jika suatu tahap terbentuk sebelum tahap lain, yakni V β ∈ V α , yakni β ∈ α , maka proses pembentukan kita bersifat kumulatif, karena V β ⊆ V α . Akhirnya, kita memang membentuk semua koleksi himpunan yang mungkin yang tersedia pada suatu tahap sebelumnya, sebab setiap tahap penerus V α + merupakan himpunan kuasa pendahulunya V α .

Singkatnya: dengan 𝐙𝐅 − , kita hampir selesai merumuskan visi kita tentang hierarki kumulatif-iteratif himpunan. (Meskipun, tentu saja, kita masih perlu membenarkan Penggantian.)

67.4 Fondasi

Kita baru hampir selesai—dan belum sepenuhnya selesai—karena tidak ada sesuatu pun dalam 𝐙𝐅 − yang menjamin bahwa setiap himpunan berada dalam suatu V α , yakni bahwa setiap himpunan dibentuk pada suatu tahap.

Sekarang, terdapat suatu pengertian (matematis) yang cukup langsung yang menurutnya kita tidak peduli apakah terdapat himpunan di luar hierarki. (Jika memang ada, kita dapat mengabaikannya begitu saja.) Namun, kita telah memotivasi konsep himpunan kita dengan gagasan bahwa setiap himpunan dibentuk pada suatu tahap (lihat 𝑆𝑡𝑎𝑔𝑒𝑠-𝑎𝑟𝑒-𝑘𝑒𝑦 dalam Bagian 65.1). Jadi, kita hendak meniadakan kemungkinan adanya himpunan yang berada di luar hierarki. Karena itu, kita harus menambahkan aksioma baru yang memastikan bahwa setiap himpunan muncul di suatu tempat dalam hierarki.

Karena V α merupakan tahap-tahap kita, kita dapat saja mempertimbangkan untuk menambahkan pernyataan berikut sebagai aksioma:

Regularitas. ∀ A ∃ α A ⊆ V α

Pendekatan ini sepenuhnya masuk akal. Namun, karena alasan yang akan dijelaskan pada bagian berikutnya, kita justru akan mengadopsi aksioma alternatif:

Aksioma.

Fondasi

( ∀ A ≠ ∅ ) ( ∃ B ∈ A ) A ∩ B = ∅ .

Dengan sedikit usaha, kita dapat menunjukkan (dalam 𝐙𝐅 − ) bahwa Fondasi mengimplikasikan Regularitas:

Definisi 67.10.

Untuk setiap himpunan A , tetapkan: cl 0 ( A ) = A , cl n + 1 ( A ) = ⋃ cl n ( A ) , trcl ( A ) = ⋃ n < ω cl n ( A ) . Kita menyebut trcl ( A ) sebagai penutupan transitif dari A .

Nama “penutupan transitif” memang tepat:

Proposisi 67.11.

A ⊆ trcl ( A ) dan trcl ( A ) merupakan himpunan transitif.

Bukti.

Jelas bahwa A = cl 0 ( A ) ⊆ trcl ( A ) . Dan jika x ∈ b ∈ trcl ( A ) , maka b ∈ cl n ( A ) untuk suatu n , sehingga x ∈ cl n + 1 ( A ) ⊆ trcl ( A ) .

Lema 67.12.

Jika A merupakan himpunan transitif, maka terdapat suatu α sehingga A ⊆ V α .

Bukti.

Dengan mengingat definisi “ lsub ( X ) ” dari Definisi 66.32, definisikan dua himpunan: D = { x ∈ A : ∀ δ   x ⊈ V δ } α = lsub { δ : ( ∃ x ∈ A ) ( x ⊆ V δ ∧ ( ∀ γ ∈ δ ) x ⊈ V γ ) } Andaikan D = ∅ . Jadi, jika x ∈ A , maka terdapat suatu δ sehingga x ⊆ V δ dan, berdasarkan pengurutan baik ordinal, ( ∀ γ ∈ δ ) x ⊈ V γ ; karena itu δ ∈ α , sehingga x ∈ V α berdasarkan Lema 67.7. Maka A ⊆ V α , sebagaimana diperlukan.

Jadi, cukup ditunjukkan bahwa D = ∅ . Untuk reductio, andaikan tidak. Berdasarkan Fondasi, terdapat suatu B ∈ D ⊆ A sehingga D ∩ B = ∅ . Jika x ∈ B , maka x ∈ A karena A transitif; dan karena x ∉ D , diperoleh bahwa ∃ δ   x ⊆ V δ . Sekarang tetapkan β = lsub { δ : ( ∃ x ∈ B ) ( x ⊆ V δ ∧ ( ∀ γ < δ ) x ⊈ V γ ) } . Seperti sebelumnya, B ⊆ V β , bertentangan dengan klaim bahwa B ∈ D .

Teorema 67.13.

Regularitas berlaku.

Bukti.

Tetapkan A ; sekarang A ⊆ trcl ( A ) berdasarkan Proposisi 67.11, dan yang disebut terakhir bersifat transitif. Jadi, terdapat suatu α sehingga A ⊆ trcl ( A ) ⊆ V α berdasarkan Lema 67.12.

Hasil-hasil ini menunjukkan bahwa 𝐙𝐅 − membuktikan implikasi 𝐹𝑜𝑛𝑑𝑎𝑠𝑖 ⇒ 𝑅𝑒𝑔𝑢𝑙𝑎𝑟𝑖𝑡𝑎𝑠 . Dalam Proposisi 67.22, kita akan menunjukkan bahwa 𝐙𝐅 − membuktikan 𝑅𝑒𝑔𝑢𝑙𝑎𝑟𝑖𝑡𝑎𝑠 ⇒ 𝐹𝑜𝑛𝑑𝑎𝑠𝑖 . Dengan demikian, Fondasi dan Regularitas ekuivalen (modulo 𝐙𝐅 − ). Namun, ini berarti bahwa, dengan mengandaikan 𝐙𝐅 − , kita dapat membenarkan Fondasi dengan memperhatikan bahwa aksioma itu ekuivalen dengan Regularitas. Dan kita dapat langsung membenarkan Regularitas berdasarkan 𝑆𝑡𝑎𝑔𝑒𝑠-𝑎𝑟𝑒-𝑘𝑒𝑦 .

67.5 𝐙 dan 𝐙𝐅 : Sebuah Tonggak Penting

Dengan Fondasi, kita mencapai satu lagi tonggak penting. Kita telah mempertimbangkan teori 𝐙 − dan 𝐙𝐅 − , yang kita katakan merupakan teori tertentu yang “dikurangi” sesuatu. Sesuatu itu ialah Fondasi. Jadi:

Definisi 67.14.

Teori 𝐙 menambahkan Fondasi kepada 𝐙 − . Jadi, aksioma-aksiomanya ialah Ekstensionalitas, Gabungan, Pasangan, Himpunan Kuasa, Ketakhinggaan, Fondasi, dan semua instans skema Pemisahan.

Teori 𝐙𝐅 menambahkan Fondasi kepada 𝐙𝐅 − . Dengan kata lain, 𝐙𝐅 menambahkan semua instans Penggantian kepada  𝐙 .

Namun, mungkin satu pertanyaan telah terlintas dalam pikiran Anda. Jika Regularitas ekuivalen dengan Fondasi di atas 𝐙𝐅 − , dan pembenaran Regularitas sudah jelas, mengapa kita harus mengambil jalan memutar dan menjadikan Fondasi, bukan Regularitas, sebagai aksioma dasar kita?

Dengan mengesampingkan alasan historis (mengenai siapa yang merumuskan apa dan kapan), alasan dasarnya adalah bahwa Fondasi dapat disajikan tanpa menggunakan definisi V α . Definisi itu bergantung pada seluruh pekerjaan dalam Bagian 67.2: kita perlu membuktikan Rekursi Transfinit untuk menunjukkan bahwa definisi tersebut dapat dibenarkan. Namun, bukti Rekursi Transfinit kita menggunakan Penggantian. Jadi, meskipun Fondasi dan Regularitas ekuivalen modulo 𝐙𝐅 − , keduanya tidak ekuivalen modulo 𝐙 − .

Sesungguhnya, persoalannya lebih drastis daripada yang disiratkan oleh pengamatan sederhana ini. Walaupun hal itu jauh melampaui cakupan buku ini, ternyata baik 𝐙 − maupun 𝐙 terlalu lemah untuk mendefinisikan V α . Jadi, jika Anda hanya bekerja dalam 𝐙 , Regularitas (sebagaimana kita merumuskannya) bahkan tidak bermakna. Inilah sebabnya aksioma resmi kita ialah Fondasi, bukan Regularitas.

Mulai sekarang, kita akan bekerja dalam 𝐙𝐅 (kecuali dinyatakan lain), tanpa komentar lebih lanjut.

67.6 Peringkat

Sekarang kita telah mendefinisikan tahap-tahap sebagai V α , dan kita tahu bahwa setiap himpunan merupakan himpunan bagian dari suatu tahap, kita dapat mendefinisikan peringkat suatu himpunan. Secara intuitif, peringkat A adalah tahap pertama tempat A terbentuk. Lebih tepatnya:

Definisi 67.15.

Untuk setiap himpunan A , rank ( A ) merupakan ordinal terkecil α sedemikian sehingga A ⊆ V α .

Proposisi 67.16.

rank ( A ) ada, untuk sebarang A .

Bukti.

Ditinggalkan sebagai latihan.

Pengurutan baik peringkat memungkinkan kita membuktikan beberapa hasil penting:

Proposisi 67.17.

Untuk setiap ordinal α , V α = { x : rank ( x ) ∈ α } .

Bukti.

Jika rank ( x ) ∈ α , maka x ⊆ V rank ( x ) ∈ V α , sehingga x ∈ V α karena V α bersifat poten (dengan menggunakan Lema 67.7 beberapa kali). Sebaliknya, jika x ∈ V α , maka x ⊆ V α , sehingga rank ( x ) ≤ α ; sekarang induksi transfinit sederhana menunjukkan bahwa x ∉ V rank ( x ) .

Proposisi 67.18.

Jika B ∈ A , maka rank ( B ) ∈ rank ( A ) .

Bukti.

A ⊆ V rank ( A ) = { x : rank ( x ) ∈ rank ( A ) } berdasarkan Proposisi 67.17.

Dengan menggunakan fakta ini, kita dapat menetapkan suatu hasil yang memungkinkan kita membuktikan berbagai hal tentang semua himpunan melalui suatu bentuk induksi:

Teorema 67.19.

Skema Induksi- ∈

Untuk sebarang formula φ : ∀ A ( ( ∀ x ∈ A ) φ ( x ) → φ ( A ) ) → ∀ A φ ( A ) .

Bukti.

Kita akan membuktikan kontraposisinya. Andaikan ¬ ∀ A φ ( A ) . Berdasarkan Induksi Transfinit (Teorema 66.16), terdapat suatu objek yang tidak bersifat φ dan peringkatnya sekecil mungkin; yakni suatu A sedemikian sehingga ¬ φ ( A ) dan ∀ x ( rank ( x ) ∈ rank ( A ) → φ ( x ) ) . Sekarang, jika x ∈ A , maka rank ( x ) ∈ rank ( A ) berdasarkan Proposisi 67.18, sehingga φ ( x ) ; yakni ( ∀ x ∈ A ) φ ( x ) ∧ ¬ φ ( A ) .

Berikut cara informal untuk menjelaskan hasil yang kuat ini. Katakan bahwa φ bersifat herediter jika dan hanya jika, setiap kali semua anggota suatu himpunan bersifat φ , himpunan itu sendiri juga bersifat φ . Maka Induksi- ∈ memberi tahu Anda hal berikut: jika φ bersifat herediter, setiap himpunan bersifat φ .

Untuk mengakhiri pembahasan peringkat (untuk saat ini), kita akan membuktikan beberapa klaim yang telah beberapa kali kita singgung sebelumnya.

Proposisi 67.20.

rank ( A ) = lsub x ∈ A rank ( x ) .

Bukti.

Misalkan α = lsub x ∈ A rank ( x ) . Berdasarkan Proposisi 67.18, α ≤ rank ( A ) . Namun, jika x ∈ A , maka rank ( x ) ∈ α , sehingga x ∈ V α berdasarkan Proposisi 67.17, dan karenanya A ⊆ V α , yakni rank ( A ) ≤ α . Maka rank ( A ) = α .

Akibat 67.21.

Untuk setiap ordinal α , rank ( α ) = α .

Bukti.

Untuk induksi transfinit, andaikan rank ( β ) = β bagi semua β ∈ α . Sekarang rank ( α ) = lsub β ∈ α rank ( β ) = lsub β ∈ α β = α berdasarkan Proposisi 67.20.

Terakhir, berikut bukti singkat bagi hasil yang dijanjikan pada akhir Bagian 67.4, bahwa 𝐙𝐅 − membuktikan implikasi 𝑅𝑒𝑔𝑢𝑙𝑎𝑟𝑖𝑡𝑎𝑠 ⇒ 𝐹𝑜𝑛𝑑𝑎𝑠𝑖 . (Perhatikan bahwa gagasan “peringkat” dan Proposisi 67.18 tersedia untuk digunakan dalam bukti ini karena—sebagaimana disebutkan pada awal bagian ini—keduanya dapat disajikan dengan menggunakan 𝐙𝐅 − + Regularitas .)

Proposisi 67.22.

dengan bekerja dalam 𝐙𝐅 − + Regularitas

Fondasi berlaku.

Bukti.

Tetapkan A ≠ ∅ , dan suatu B ∈ A yang peringkatnya sekecil mungkin. Jika c ∈ B , maka rank ( c ) ∈ rank ( B ) berdasarkan Proposisi 67.18, sehingga c ∉ A berdasarkan pemilihan B .

Soal

Soal 67.1.

Buktikan Proposisi 67.16.

Soal 67.2.

Lengkapi induksi transfinit sederhana yang disebutkan dalam Proposisi 67.17.
