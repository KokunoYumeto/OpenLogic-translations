69 Aritmetika Ordinal

69.1 Pendahuluan

Dalam Bab 66, kita mengembangkan suatu teori bilangan ordinal. Dalam Bab 67, kita melihat bahwa ordinal dapat dipandang sebagai tulang punggung yang menjadi kerangka konstruksi bagian hierarki selebihnya. Namun, itu bukan satu-satunya peran ordinal. Ada pula tugas melakukan aritmetika ordinal.

Kita telah mengisyaratkan hal ini sebelumnya dalam Bagian 66.2, ketika membicarakan ω , ω + 1 , dan ω + ω . Saat itu kita berbicara secara informal; sekarang tiba waktunya untuk menjabarkannya dengan tepat. Namun, perlu disebutkan bahwa bab ini tidak banyak memuat filsafat: hanya perkembangan teknis, disertai pengamatan yang (agak) menarik bahwa kita dapat melakukan hal yang sama dengan dua cara berbeda.

69.2 Penjumlahan Ordinal

Andaikan kita hendak menjumlahkan α dan  β . Kita cukup menempatkan suatu salinan  β tepat sesudah suatu salinan  α . (Kita perlu mengambil salinan, sebab berdasarkan Proposisi 66.22, kita tahu bahwa α ⊆ β atau β ⊆ α .) Efek intuitifnya ialah menjalani barisan langkah sepanjang  α , lalu menjalani barisan sepanjang  β . Barisan yang dihasilkan akan terurut baik; jadi, berdasarkan Teorema 66.26, barisan itu isomorfik dengan suatu ordinal (unik). Ordinal tersebut dapat dipandang sebagai jumlah α dan  β .

Itulah gagasan intuitif di balik penjumlahan ordinal. Untuk mendefinisikannya secara teliti, kita mulai dengan gagasan mengambil salinan himpunan. Gagasannya ialah menggunakan penanda sebarang, 0 dan  1 , untuk mencatat asal setiap objek:

Definisi 69.1.

Jumlah lepas A dan B ialah A ⊔ B = ( A × { 0 } ) ∪ ( B × { 1 } ) .

Selanjutnya, kita mendefinisikan suatu pengurutan pada pasangan ordinal:

Definisi 69.2.

Untuk sebarang ordinal α 1 , α 2 , β 1 , β 2 , tetapkan bahwa: ⟨ α 1 , α 2 ⟩ ∢ ⟨ β 1 , β 2 ⟩  jika dan hanya jika  α 2 ∈ β 2 , atau α 2 = β 2  dan  α 1 ∈ β 1 .

Ini merupakan pengurutan leksikografis terbalik, karena kita mengurutkan menurut anggota kedua, lalu menurut anggota pertama. Ingat bahwa kita hendak mendefinisikan α + β sebagai tipe urutan suatu salinan  α yang diikuti suatu salinan  β . Untuk mencapainya, kita menetapkan:

Definisi 69.3.

Untuk sebarang ordinal α , β , jumlahnya ialah α + β = ord ( α ⊔ β , ∢ ) .

Perhatikan bahwa kita sedikit menyalahgunakan notasi di sini; secara tegas, kita seharusnya menulis “ { ⟨ x , y ⟩ ∈ α ⊔ β : x ∢ y } ” sebagai ganti “ ∢ ”. Namun, demi keringkasan, selanjutnya kita akan terus menyalahgunakan notasi dengan cara ini.

Hasil berikut, bersama Teorema 66.26, memastikan bahwa definisi kita terbentuk dengan baik:

Lema 69.4.

⟨ α ⊔ β , ∢ ⟩ merupakan pengurutan baik bagi sebarang ordinal α dan  β .

Bukti.

Jelas bahwa ∢ terhubung pada α ⊔ β . Untuk menunjukkan bahwa relasi itu berlandasan baik, tetapkan suatu himpunan tak kosong X ⊆ α ⊔ β . Misalkan Y himpunan bagian dari  X yang koordinat keduanya sekecil mungkin, yakni Y = { ⟨ γ , i ⟩ ∈ X : ( ∀ ⟨ δ , j ⟩ ∈ X ) i ≤ j } . Sekarang pilih anggota  Y dengan koordinat pertama terkecil.

Jadi, kita mempunyai definisi eksplisit yang baik bagi penjumlahan ordinal. Berikut fakta yang tidak mengejutkan (ingat bahwa 1 = { 0 } berdasarkan Definisi 65.7):

Proposisi 69.5.

α + 1 = α + bagi sebarang ordinal  α .

Bukti.

Perhatikan isomorfisme  f dari α + = α ∪ { α } ke α ⊔ 1 = ( α × { 0 } ) ∪ ( { 0 } × { 1 } ) yang diberikan oleh f ( γ ) = ⟨ γ , 0 ⟩ bagi γ ∈ α , dan f ( α ) = ⟨ 0 , 1 ⟩ .

Selain itu, mudah ditunjukkan bahwa penjumlahan memenuhi syarat-syarat rekursif tertentu:

Lema 69.6.

Untuk sebarang ordinal α , β , berlaku: α + 0 = α α + ( β + 1 ) = ( α + β ) + 1 α + β = lsub δ < β ( α + δ ) jika  β  ordinal limit.

Bukti.

Kita memeriksa setiap kasus; pertama: α + 0 = ord ( ( α × { 0 } ) ∪ ( 0 × { 1 } ) , ∢ ) = ord ( α × { 0 } , ∢ ) = α α + ( β + 1 ) = ord ( ( α × { 0 } ) ∪ ( β + × { 1 } ) , ∢ ) = ord ( ( α × { 0 } ) ∪ ( β × { 1 } ) , ∢ ) + 1 = ( α + β ) + 1. Sekarang misalkan β ≠ ∅ suatu limit. Jika δ < β , maka δ + 1 < β , sehingga α + δ merupakan segmen awal sejati dari α + β . Jadi, α + β merupakan batas atas ketat bagi X = { α + δ : δ < β } . Selain itu, jika α ≤ γ < α + β , maka jelas γ = α + δ bagi suatu δ < β . Jadi, α + β = lsub δ < β ( α + δ ) .

Namun, berikut suatu fakta yang mencolok. Untuk mendefinisikan penjumlahan ordinal, kita sebenarnya dapat menggunakan Teorema Rekursi Transfinit dan menetapkan persamaan-persamaan rekursi tepat seperti dalam Lema 69.6 (meskipun menggunakan “ β + ” alih-alih “ β + 1 ”).

Jadi, ada dua cara berbeda untuk mendefinisikan operasi pada ordinal. Kita dapat mendefinisikannya secara sintetis, dengan secara eksplisit mengonstruksi suatu himpunan terurut baik dan mempertimbangkan tipe urutannya. Atau, kita dapat mendefinisikannya secara rekursif, hanya dengan menetapkan persamaan-persamaan rekursi. Jika dilakukan dengan benar, hasilnya sama. Teorema Teorema 66.26 menjamin bahwa persamaan-persamaan rekursi ini menentukan ordinal yang unik.

Dalam banyak hal, aritmetika ordinal berperilaku seperti penjumlahan bilangan asli. Sebagai contoh, kita dapat membuktikan hasil berikut:

Lema 69.7.

Jika α , β , γ ordinal, maka:

  1. jika β < γ , maka α + β < α + γ ;

  2. jika α + β = α + γ , maka β = γ ;

  3. α + ( β + γ ) = ( α + β ) + γ , yakni penjumlahan bersifat asosiatif;

  4. jika α ≤ β , maka α + γ ≤ β + γ .

Bukti.

Kita membuktikan enumi 3 dan menyerahkan sisanya sebagai latihan. Bukti dilakukan dengan Induksi Transfinit Sederhana pada  γ , menggunakan Lema 69.6. Jika γ = 0 : ( α + β ) + 0 = α + β = α + ( β + 0 ) Jika γ = δ + 1 , andaikan sebagai hipotesis induksi bahwa ( α + β ) + δ = α + ( β + δ ) ; sekarang gunakan Lema 69.6 tiga kali: ( α + β ) + ( δ + 1 ) = ( ( α + β ) + δ ) + 1 = ( α + ( β + δ ) ) + 1 = α + ( ( β + δ ) + 1 ) = α + ( β + ( δ + 1 ) ) . Jika γ ordinal limit, andaikan sebagai hipotesis induksi bahwa jika δ ∈ γ , maka ( α + β ) + δ = α + ( β + δ ) ; sekarang: ( α + β ) + γ = lsub δ < γ ( ( α + β ) + δ ) = lsub δ < γ ( α + ( β + δ ) ) = α + lsub δ < γ ( β + δ ) = α + ( β + γ ) .

Dalam berbagai hal ini, penjumlahan ordinal seharusnya terasa sangat akrab. Namun, ada satu perbedaan penting: penjumlahan ordinal tidak seperti penjumlahan bilangan asli.

Proposisi 69.8.

Penjumlahan ordinal tidak komutatif; 1 + ω = ω < ω + 1 .

Bukti.

Perhatikan bahwa 1 + ω = lsub n < ω ( 1 + n ) = ω ∈ ω ∪ { ω } = ω + = ω + 1 .

Walaupun pada mulanya hal ini mungkin mengejutkan, seharusnya tidak. Di satu sisi, ketika mempertimbangkan 1 + ω , kita memikirkan tipe urutan yang diperoleh dengan menempatkan satu anggota tambahan sebelum semua bilangan asli. Dengan penalaran seperti pada Hotel Hilbert dalam Bagian 6.1, secara intuitif anggota pertama tambahan ini seharusnya tidak mengubah tipe urutan keseluruhan. Di sisi lain, ketika mempertimbangkan ω + 1 , kita memikirkan tipe urutan yang diperoleh dengan menempatkan satu anggota tambahan sesudah semua bilangan asli. Itu merupakan sesuatu yang sama sekali berbeda!

69.3 Menggunakan Penjumlahan Ordinal

Dengan menggunakan penjumlahan pada ordinal, kita dapat menghitung secara eksplisit peringkat berbagai himpunan, dalam pengertian Definisi 67.15:

Lema 69.9.

Jika rank ( A ) = α dan rank ( B ) = β , maka:

  1. rank ( ℘ ( A ) ) = α + 1

  2. rank ( { A , B } ) = max ( α , β ) + 1

  3. rank ( A ∪ B ) = max ( α , β )

  4. rank ( ⟨ A , B ⟩ ) = max ( α , β ) + 2

  5. rank ( A × B ) ≤ max ( α , β ) + 2

  6. rank ( ⋃ A ) = α jika α kosong atau merupakan ordinal limit; rank ( ⋃ A ) = γ jika α = γ + 1

Bukti.

Sepanjang bukti ini, kita berulang kali menggunakan Proposisi 67.20.

enumi 1. Jika x ⊆ A , maka rank ( x ) ≤ rank ( A ) . Jadi rank ( ℘ ( A ) ) ≤ α + 1 . Karena khususnya A ∈ ℘ ( A ) , maka rank ( ℘ ( A ) ) = α + 1 .

enumi 2. Berdasarkan Proposisi 67.20.

enumi 3. Berdasarkan Proposisi 67.20.

enumi 4. Berdasarkan enumi 2, diterapkan dua kali.

enumi 5. Perhatikan bahwa A × B ⊆ ℘ ( ℘ ( A ∪ B ) ) , lalu gunakan enumi 1 dua kali bersama enumi 3.

enumi 6. Jika α = γ + 1 , terdapat suatu c ∈ A dengan rank ( c ) = γ , dan tidak ada anggota dari A yang berperingkat lebih tinggi; jadi rank ( ⋃ A ) = γ . Jika α merupakan ordinal limit, maka A mempunyai anggota dengan peringkat yang sedekat apa pun dengan α (tetapi tetap lebih kecil darinya). Karena itu, ⋃ A juga mempunyai anggota dengan peringkat yang sedekat apa pun dengan α (tetapi tetap lebih kecil darinya), sehingga rank ( ⋃ A ) = α .

Kita serahkan sebagai latihan penjelasan mengapa enumi 5 melibatkan suatu pertaksamaan.

Sekarang kita juga dapat menunjukkan bahwa beberapa pengertian wajar tentang apa artinya menyebut suatu ordinal “hingga” atau “tak hingga” ternyata bertepatan:

Lema 69.10.

Untuk sebarang ordinal α , pernyataan-pernyataan berikut ekuivalen:

  1. α ∉ ω , yakni α bukan bilangan asli

  2. ω ≤ α

  3. 1 + α = α

  4. α ≈ α + 1 , yakni α dan α + 1 sama banyak

  5. α bersifat tak hingga Dedekind

Jadi, kita mempunyai lima cara yang terbukti ekuivalen untuk memahami syarat agar suatu ordinal bersifat (tak) hingga.

Bukti.

enumi 1 ⇒ enumi 2. Berdasarkan Trikotomi.

enumi 2 ⇒ enumi 3. Tetapkan α ≥ ω . Berdasarkan Induksi Transfinit, terdapat suatu ordinal terkecil γ (mungkin 0 ) sedemikian sehingga terdapat ordinal limit β dengan α = β + γ . Sekarang: 1 + α = 1 + ( β + γ ) = ( 1 + β ) + γ = lsub δ < β ( 1 + δ ) + γ = β + γ = α . enumi 3 ⇒ enumi 4. Jelas terdapat bijeksi f : ( α ⊔ 1 ) → ( 1 ⊔ α ) . Jika 1 + α = α , terdapat suatu isomorfisme g : ( 1 ⊔ α ) → α . Sekarang perhatikan g ∘ f .

enumi 4 ⇒ enumi 5. Jika α ≈ α + 1 , terdapat bijeksi f : ( α ⊔ 1 ) → α . Definisikan g ( γ ) = f ( γ , 0 ) bagi setiap γ < α ; injeksi ini menyaksikan bahwa α bersifat tak hingga Dedekind, sebab f ( 0 , 1 ) ∈ α ∖ ran ( g ) .

enumi 5 ⇒ enumi 1. Ini merupakan Proposisi 65.8.

69.4 Perkalian Ordinal

Sekarang kita beralih ke perkalian ordinal, yang kita dekati dengan cara yang sangat mirip dengan penjumlahan ordinal. Andaikan kita hendak mengalikan α dengan  β . Untuk melakukannya, bayangkan suatu kisi persegi panjang dengan lebar α dan tinggi β ; hasil kali α dan β diperoleh dengan bergerak sepanjang setiap baris, lalu bergerak melalui baris berikutnya… sampai seluruh kisi telah dilalui. Dengan kata lain, hasil kali α dan β diperoleh dengan mengganti setiap anggota dalam β dengan suatu salinan  α .

Untuk memformalkan gagasan ini, kita cukup menggunakan pengurutan leksikografis terbalik pada hasil kali Kartesius α dan  β :

Definisi 69.11.

Untuk sebarang ordinal α , β , hasil kalinya ialah α ⋅ β = ord ( α × β , ∢ ) .

Sekali lagi, kita harus memastikan bahwa definisi ini terbentuk dengan baik:

Lema 69.12.

⟨ α × β , ∢ ⟩ merupakan pengurutan baik bagi sebarang ordinal α dan  β .

Bukti.

Tepat seperti pada Lema 69.4.

Tidak sulit pula membuktikan bahwa perkalian berperilaku sebagai berikut:

Lema 69.13.

Untuk sebarang ordinal α , β : α ⋅ 0 = 0 α ⋅ ( β + 1 ) = ( α ⋅ β ) + α α ⋅ β = lsub δ < β ( α ⋅ δ ) jika  β  merupakan ordinal limit .

Bukti.

Diserahkan sebagai latihan.

Sesungguhnya, sebagaimana dalam kasus penjumlahan, kita dapat mendefinisikan perkalian ordinal melalui persamaan-persamaan rekursi ini alih-alih memberikan definisi langsung. Seperti halnya penjumlahan, beberapa perilakunya juga terasa akrab:

Lema 69.14.

Jika α , β , γ ordinal, maka:

  1. jika α ≠ 0 dan β < γ , maka α ⋅ β < α ⋅ γ ;

  2. jika α ≠ 0 dan α ⋅ β = α ⋅ γ , maka β = γ ;

  3. α ⋅ ( β ⋅ γ ) = ( α ⋅ β ) ⋅ γ ;

  4. jika α ≤ β , maka α ⋅ γ ≤ β ⋅ γ ;

  5. α ⋅ ( β + γ ) = ( α ⋅ β ) + ( α ⋅ γ ) .

Bukti.

Diserahkan sebagai latihan.

Anda dapat membuktikan (atau mencari) hasil-hasil lain sesuka hati. Akan tetapi, mengingat Proposisi 69.8, hasil berikut seharusnya tidak mengejutkan:

Proposisi 69.15.

Perkalian ordinal tidak komutatif: 2 ⋅ ω = ω < ω ⋅ 2 .

Bukti.

2 ⋅ ω = lsub n < ω ( 2 ⋅ n ) = ω ∈ lsub n < ω ( ω + n ) = ω + ω = ω ⋅ 2 .

Sekali lagi, alasan intuitifnya cukup lugas. Untuk menghitung 2 ⋅ ω , kita mengganti setiap bilangan asli dengan dua entitas. Tipe urutan yang sama akan diperoleh jika kita cukup menyisipkan semua bilangan “setengah” ke dalam bilangan asli, yakni jika kita mempertimbangkan pengurutan alami pada { n 2 : n ∈ ω } . Dengan ungkapan ini, jelas bahwa tipe urutannya sama dengan tipe urutan ω sendiri. Namun, untuk menghitung ω ⋅ 2 , kita menempatkan dua salinan ω , yang satu sesudah yang lain.

69.5 Eksponensiasi Ordinal

Sekarang kita beralih ke eksponensiasi ordinal. Sayangnya, tidak ada definisi sintetis yang bagus bagi eksponensiasi ordinal.

Memang, definisi sintetis yang eksplisit ada. Berikut salah satunya. Misalkan finfun ( α , β ) himpunan semua fungsi f : β → α sedemikian sehingga { γ ∈ β : f ( γ ) ≠ 0 } sama banyak dengan suatu bilangan asli. Definisikan suatu pengurutan baik pada finfun ( α , β ) dengan f ⊏ g jika dan hanya jika f ≠ g dan f ( γ 0 ) < g ( γ 0 ) , dengan γ 0 = max { γ ∈ β : f ( γ ) ≠ g ( γ ) } . Kemudian kita dapat mendefinisikan α ( β ) sebagai ord ( finfun ( α , β ) , ⊏ ) . Potter menggunakan definisi eksplisit ini, lalu langsung menjelaskan:

Pemilihan pengurutan ini ditentukan semata-mata oleh keinginan kita untuk memperoleh definisi eksponensiasi ordinal yang memenuhi syarat rekursif yang sesuai…, dan pengurutan ini jauh lebih sulit dibayangkan daripada jumlah terurut maupun hasil kali terurut. (Potter, 2004, hlm. 199)

Tepat sekali. Kita menjelaskan penjumlahan sebagai “suatu salinan α yang diikuti suatu salinan β ”, dan perkalian sebagai “suatu barisan sepanjang β yang terdiri atas salinan-salinan α ”. Namun, kita tidak mempunyai uraian singkat yang menarik mengenai finfun ( α , γ ) . Karena itu, sebagai gantinya kita akan memberikan definisi eksponensiasi ordinal hanya melalui rekursi transfinit, yakni:

Definisi 69.16.

α ( 0 ) = 1 α ( β + 1 ) = α ( β ) ⋅ α α ( β ) = ⋃ δ < β α ( δ ) jika  β  merupakan ordinal limit

Jika kita bekerja sebagai teoretikus himpunan, kita mungkin ingin menyelidiki beberapa sifat eksponensiasi ordinal. Namun, tidak banyak lagi yang perlu kita tambahkan selain fakta yang tidak mengejutkan bahwa eksponensiasi ordinal tidak komutatif. Jadi 2 ( ω ) = ⋃ δ < ω 2 ( δ ) = ω , sedangkan ω ( 2 ) = ω ⋅ ω . Lagi pula, kita memang tidak seharusnya mengharapkan eksponensiasi bersifat komutatif, sebab pada bilangan asli pun tidak demikian: 2 ( 3 ) = 8 < 9 = 3 ( 2 ) .

Soal

Soal 69.1.

Buktikan bagian selebihnya dari Lema 69.7.

Soal 69.2.

Berikan himpunan A dan B sedemikian sehingga rank ( A × B ) = max ( rank ( A ) , rank ( B ) ) . Berikan himpunan A dan B sedemikian sehingga rank ( A × B ) = max ( rank ( A ) , rank ( B ) ) + 2 . Apakah ada peringkat lain yang mungkin?

Soal 69.3.

Buktikan Lema 69.12, Lema 69.13, dan Lema 69.14.

Soal 69.4.

Dengan menggunakan Induksi Transfinit, buktikan bahwa jika kita mendefinisikan α ( β ) = ord ( finfun ( α , β ) , ⊏ ) , kita memperoleh persamaan-persamaan rekursi dalam Definisi 69.16.
