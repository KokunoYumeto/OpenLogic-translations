72 Pilihan

72.1 Pengantar

Dalam Bab 70–Bab 71, kita mengembangkan suatu teori kardinal dengan memperlakukan kardinal sebagai ordinal. Pendekatan itu bergantung pada Aksioma Pengurutan Baik. Ternyata Pengurutan Baik ekuivalen dengan prinsip lain—Aksioma Pilihan—dan telah terjadi pembahasan filosofis yang serius mengenai dapat diterima atau tidaknya prinsip tersebut. Pertanyaan kita dalam bab ini adalah: Bagaimana Aksioma itu digunakan, dan dapatkah ia dibenarkan?

72.2 Trik Tarski–Scott

Dalam Definisi 70.1, kita mendefinisikan kardinal sebagai ordinal. Untuk melakukannya, kita mengandaikan Aksioma Pengurutan Baik. Kita melakukannya semata-mata karena itulah “standar industri”.

Sebelum membahas persoalan-persoalan filosofis seputar Pengurutan Baik, penting untuk memperjelas bahwa kita dapat menyimpang dari standar industri dan mengembangkan teori kardinal tanpa mengandaikan Pengurutan Baik. Kita masih dapat menggunakan definisi A ≈ B , A ⪯ B , dan A ≺ B sebagaimana muncul dalam Bab 4. Kita hanya memerlukan suatu pengertian kardinal yang baru.

Gagasan naifnya ialah mencoba mendefinisikan kardinalitas A sebagai berikut: { x : A ≈ x } . Anda mungkin ingin membandingkannya dengan definisi Frege tentang # x F x yang diuraikan secara ringkas pada bagian paling akhir Bagian 70.5. Karena alasan yang telah kita singgung di sana, definisi ini gagal. Setiap himpunan singleton sama banyak dengan { ∅ } . Namun, himpunan-himpunan singleton baru terbentuk pada setiap tahap penerus hierarki (perhatikan saja singleton dari tahap sebelumnya). Jadi, { x : A ≈ x } tidak ada karena ia tidak dapat mempunyai peringkat.

Untuk mengatasi masalah ini, kita menggunakan suatu trik yang berasal dari Tarski dan Scott:47

Definisi 72.1.

Tarski–Scott

Untuk sebarang formula φ ( x ) , misalkan [ x : φ ( x ) ] himpunan semua x yang berperingkat serendah mungkin dan memenuhi φ ( x ) (atau ∅ jika tidak ada x yang memenuhi  φ ).

Kita perlu memeriksa bahwa definisi ini sah. Dengan bekerja dalam 𝐙𝐅 , Teorema 67.13 menjamin bahwa rank ( x ) ada bagi setiap x . Sekarang, jika terdapat entitas yang memenuhi φ , kita dapat mengambil α sebagai peringkat terkecil sedemikian sehingga ( ∃ x ⊆ V α ) φ ( x ) , yakni ( ∀ β ∈ α ) ( ∀ x ⊆ V β ) ¬ φ ( x ) . Kemudian, berdasarkan Pemisahan, kita dapat mendefinisikan [ x : φ ( x ) ] sebagai { x ∈ V α + 1 : φ ( x ) } .

Setelah membenarkan trik Tarski–Scott, sekarang kita dapat menggunakannya untuk mendefinisikan suatu pengertian kardinalitas:

Definisi 72.2.

ts-kardinalitas A ialah tsc ( A ) = [ x : A ≈ x ] .

Definisi suatu ts-kardinal tidak menggunakan Pengurutan Baik. Namun, bahkan tanpa Aksioma tersebut, kita dapat menunjukkan bahwa ts-kardinal berperilaku cukup mirip dengan kardinal sebagaimana didefinisikan dalam Definisi 70.1. Sebagai contoh, jika kita menyatakan ulang Lema 70.3 dan Lema 71.4 dalam istilah ts-kardinal, bukti-buktinya tetap berlaku dalam 𝐙𝐅 tanpa mengandaikan Pengurutan Baik.

Selagi membahas hal ini, patut dicatat bahwa kita juga dapat mengembangkan suatu teori ordinal dengan menggunakan trik Tarski–Scott. Jika ⟨ A , < ⟩ merupakan suatu pengurutan baik, misalkan tso ( A , < ) = [ ⟨ X , R ⟩ : ⟨ A , < ⟩ ≅ ⟨ X , R ⟩ ] . Untuk pembahasan lebih lanjut tentang perlakuan terhadap kardinal dan ordinal ini, lihat Potter (2004, bab 9–12).

72.3 Keterbandingan dan Lema Hartogs

Itulah sisi positifnya. Berikut sisi negatifnya. Tanpa Pilihan, keadaan menjadi rumit. Untuk melihat alasannya, berikut suatu hasil bagus dari (Hartogs, 1915):

Lema 72.3.

dalam 𝐙𝐅

Untuk sebarang himpunan A , terdapat suatu ordinal α sedemikian sehingga α ⋠ A .

Bukti.

Jika B ⊆ A dan R ⊆ B 2 , maka ⟨ B , R ⟩ ⊆ V rank ( A ) + 4 berdasarkan Lema 69.9. Jadi, dengan menggunakan Pemisahan, pertimbangkan: C = { ⟨ B , R ⟩ ∈ V rank ( A ) + 5 : B ⊆ A  dan  ⟨ B , R ⟩  merupakan pengurutan baik } Dengan menggunakan Penggantian dan Teorema 66.26, bentuk himpunan: α = { ord ( B , R ) : ⟨ B , R ⟩ ∈ C } . Berdasarkan Akibat 66.19, α merupakan ordinal karena ia merupakan himpunan transitif ordinal-ordinal. Memang, jika γ ∈ β ∈ α , maka β = ord ( B , R ) bagi suatu B ⊆ A . Selanjutnya, γ = ord ( B b , R b ) bagi suatu b ∈ B berdasarkan Lema 66.10, sehingga γ ∈ α .

Untuk reductio, andaikan terdapat injeksi f : α → A . Tetapkan: B = ran ( f ) R = { ⟨ f ( γ ) , f ( δ ) ⟩ ∈ A × A : γ ∈ δ } . Jelas bahwa α = ord ( B , R ) dan ⟨ B , R ⟩ ∈ C . Jadi, α ∈ α , suatu kontradiksi.

Hal ini mengakibatkan suatu hasil yang mendalam:

Teorema 72.4.

dalam 𝐙𝐅

Klaim-klaim berikut ekuivalen:

  1. Aksioma Pengurutan Baik

  2. A ⪯ B atau B ⪯ A , bagi sebarang himpunan A dan B

Bukti.

enumi 1 ⇒ enumi 2. Tetapkan A dan B . Dengan menggunakan enumi 1, terdapat pengurutan baik ⟨ A , R ⟩ dan ⟨ B , S ⟩ . Dengan menggunakan Teorema 66.26, misalkan f : α → ⟨ A , R ⟩ dan g : β → ⟨ B , S ⟩ isomorfisme. Berdasarkan Proposisi 66.22, berlaku α ⊆ β atau β ⊆ α . Jika α ⊆ β , maka g ∘ f − 1 : A → B merupakan injeksi, sehingga A ⪯ B ; demikian pula, jika β ⊆ α , maka B ⪯ A .

enumi 2 ⇒ enumi 1. Tetapkan A ; berdasarkan Lema 72.3, terdapat suatu ordinal β sedemikian sehingga β ⋠ A . Dengan menggunakan enumi 2, kita memperoleh A ⪯ β . Jadi, terdapat suatu injeksi f : A → β , dan kita dapat menggunakan injeksi ini untuk mengurutkan baik anggota-anggota A dengan mendefinisikan pengurutan { ⟨ a , b ⟩ ∈ A × A : f ( a ) ∈ f ( b ) } .

Sebagai konsekuensi langsung, jika Pengurutan Baik gagal, beberapa himpunan secara harfiah tidak dapat dibandingkan menurut ukurannya. Jadi, jika Pengurutan Baik gagal, aritmetika kardinal transfinit akan menjadi rumit. Sebagai contoh, kita harus meninggalkan gagasan bahwa, jika A dan B tak hingga, maka A ⊔ B ≈ M dan A × B ≈ M , dengan M himpunan yang lebih besar di antara A dan B (lihat Teorema 71.11). Masalahnya sederhana: jika kita tidak dapat membandingkan ukuran A dan B , tidak masuk akal untuk bertanya mana yang lebih besar.

72.4 Masalah Pengurutan Baik

Jelas bahwa cukup banyak hal bergantung pada apakah kita menerima Pengurutan Baik. Namun, pembahasan prinsip ini cenderung berfokus pada suatu prinsip yang ekuivalen, yaitu Aksioma Pilihan. Karena itu, sekarang kita akan mengalihkan perhatian kepadanya (dan membuktikan ekuivalensinya).

Pada 1883, Cantor menyatakan dukungannya terhadap Aksioma Pengurutan Baik dengan menyebutnya “suatu hukum pikiran yang bagi saya tampak mendasar, kaya akan konsekuensi, dan khususnya luar biasa karena keberlakuannya yang umum” (dikutip dalam Potter 2004, hlm. 243). Namun, pada akhirnya Cantor menjadi yakin bahwa “Aksioma” itu memerlukan bukti. Komunitas matematika pun berpandangan demikian.

Masalah tersebut “dipecahkan” oleh Zermelo pada 1904. Untuk menjelaskan penyelesaiannya, kita memerlukan beberapa definisi.

Definisi 72.5.

Suatu fungsi f merupakan fungsi pilihan jika dan hanya jika f ( x ) ∈ x bagi semua x ∈ dom ( f ) . Kita mengatakan bahwa f merupakan fungsi pilihan bagi A jika dan hanya jika f merupakan fungsi pilihan dengan dom ( f ) = A ∖ { ∅ } .

Secara intuitif, bagi setiap himpunan (tak kosong) x ∈ A , suatu fungsi pilihan bagi A memilih satu anggota tertentu, f ( x ) , dari  x . Aksioma Pilihan kemudian berbunyi:

Aksioma.

Pilihan

Setiap himpunan mempunyai suatu fungsi pilihan.

Zermelo menunjukkan bahwa Pilihan mengakibatkan pengurutan baik, dan sebaliknya:

Teorema 72.6.

dalam 𝐙𝐅

Pengurutan Baik dan Pilihan ekuivalen.

Bukti.

Dari kiri ke kanan. Misalkan A suatu himpunan yang anggota-anggotanya juga himpunan. Berdasarkan Aksioma Gabungan, ⋃ A ada; jadi, berdasarkan Pengurutan Baik, terdapat suatu < yang mengurutkan baik ⋃ A . Sekarang tetapkan f ( x ) = anggota terkecil- <  dari  x . Ini merupakan fungsi pilihan bagi  A .

Dari kanan ke kiri. Tetapkan A . Jika A = ∅ , pengurutan kosong mengurutkan baik  A ; jadi, andaikan A ≠ ∅ . Berdasarkan Pilihan, terdapat suatu fungsi pilihan f bagi ℘ ( A ) ∖ { ∅ } . Dengan menggunakan Rekursi Transfinit, definisikan: g ( 0 ) = f ( A ) g ( α ) = { berhenti! jika  A = g [ α ] f ( A ∖ g [ α ] ) jika tidak Instruksi untuk “berhenti!” hanya merupakan singkatan bagi definisi yang lebih panjang: rekursi dilanjutkan selama A ≠ g [ α ] , lalu g diambil sebagai pembatasannya pada ordinal terkecil α dengan A = g [ α ] . Pada mulanya, kita hanya dapat memastikan bahwa hal ini mendefinisikan suatu suku (lihat catatan sesudah Teorema 67.4); tetapi kita akan menunjukkan bahwa kita memang memperoleh suatu fungsi.

Karena f merupakan fungsi pilihan, bagi setiap α sebelum konstruksi berhenti berlaku g ( α ) = f ( A ∖ g [ α ] ) ∈ A ∖ g [ α ] ; yakni g ( α ) ∉ g [ α ] . Jadi, jika g ( α ) = g ( β ) , maka g ( β ) ∉ g [ α ] , yakni β ∉ α , dan secara serupa α ∉ β . Berdasarkan Trikotomi, α = β . Jadi, g bersifat injektif.

Selanjutnya, perhatikan bahwa konstruksi memang berhenti; yakni terdapat suatu ordinal terkecil α sedemikian sehingga A = g [ α ] . Andaikan sebaliknya. Karena g bersifat injektif, kita akan memperoleh α ≺ A bagi setiap ordinal α , bertentangan dengan Lema 72.3. Karena itu, ran ( g ) = A .

Dengan menggabungkan fakta-fakta ini, g merupakan bijeksi dari suatu ordinal ke  A . Sekarang g dapat digunakan untuk mengurutkan baik  A .

Jadi, Pengurutan Baik dan Pilihan berdiri atau runtuh bersama-sama. Namun, pertanyaannya tetap ada: apakah keduanya berdiri atau runtuh?

72.5 Pilihan Terhitung

Mudah dibuktikan, tanpa menggunakan Pilihan/Pengurutan Baik sama sekali, bahwa:

Lema 72.7.

dalam 𝐙 −

Setiap himpunan hingga mempunyai suatu fungsi pilihan.

Bukti.

Misalkan a = { b 1 , … , b n } . Demi kesederhanaan, andaikan setiap b i ≠ ∅ . Jadi, terdapat objek-objek c 1 , … , c n sedemikian sehingga c 1 ∈ b 1 , … , c n ∈ b n . Berdasarkan Proposisi 65.5, himpunan { ⟨ b 1 , c 1 ⟩ , … , ⟨ b n , c n ⟩ } ada; himpunan ini merupakan suatu fungsi pilihan bagi  a .

Namun, keadaan menjadi lebih keruh begitu kita mempertimbangkan himpunan-himpunan tak hingga. Sebagai contoh, pertimbangkan perluasan “minimal” berikut dari hasil di atas:

Pilihan Terhitung. Setiap himpunan terhitung mempunyai suatu fungsi pilihan.

Ini merupakan suatu kasus khusus Pilihan. Ternyata prinsip ini cukup sering digunakan tanpa kesadaran yang jelas akan penggunaannya. Berikut dua contoh yang bagus.48

Contoh 72.8.

Berikut suatu gagasan alami: bagi sebarang himpunan A , berlaku ω ⪯ A atau A ≈ n bagi suatu n ∈ ω . Ini merupakan salah satu cara untuk menyatakan gagasan intuitif bahwa setiap himpunan bersifat hingga atau tak hingga. Cantor dan banyak matematikawan lain mengemukakan klaim ini tanpa membuktikannya. Dengan kehati-hatian kita, kita telah membuktikannya dalam Teorema 70.7. Namun, dalam bukti itu kita bekerja dalam 𝐙𝐅𝐂 karena mengandaikan bahwa setiap himpunan A dapat diurutkan baik, sehingga keberadaan | A | terjamin. Artinya, kita secara eksplisit mengandaikan Pilihan.

Sesungguhnya, Dedekind (1888) memberikan buktinya sendiri bagi klaim ini sebagai berikut:

Teorema 72.9.

dalam 𝐙 − + Pilihan Terhitung

Untuk sebarang A , berlaku ω ⪯ A atau A ≈ n bagi suatu n ∈ ω .

Bukti.

Andaikan A ≉ n bagi semua n ∈ ω . Maka, khususnya, bagi setiap n < ω terdapat himpunan bagian A n ⊆ A dengan tepat 2 n anggota. Dengan menggunakan barisan A 0 , A 1 , A 2 , … , bagi setiap n kita definisikan: B n = A n ∖ ⋃ i < n A i . Sekarang perhatikan: | ⋃ i < n A i | ≤ | A 0 | + | A 1 | + … + | A n − 1 | = 1 + 2 + … + 2 n − 1 = 2 n − 1 < 2 n = | A n | Karena itu, setiap B n mempunyai sekurang-kurangnya satu anggota, c n . Selain itu, himpunan-himpunan B n saling lepas; jadi, jika c n = c m , maka n = m . Namun, setiap c n ∈ A . Dengan demikian, fungsi f ( n ) = c n merupakan suatu injeksi ω → A .

Dedekind tidak menandai bahwa ia telah menggunakan Pilihan Terhitung. Namun, apakah Anda melihat penggunaannya? Perhatikan kembali. (Sungguh: perhatikan kembali.)

Bukti tersebut menggunakan Pilihan Terhitung dua kali. Kita menggunakannya sekali untuk memperoleh barisan himpunan A 0 , A 1 , A 2 , … lalu sekali lagi untuk memilih anggota c n dari setiap  B n . Selain itu, penggunaan Pilihan ini tidak dapat dihilangkan. Cohen (1966, hlm. 138) membuktikan bahwa hasil tersebut gagal jika kita sama sekali tidak mempunyai suatu bentuk Pilihan. Artinya, konsisten dengan 𝐙𝐅 bahwa terdapat himpunan-himpunan yang tidak dapat dibandingkan dengan  ω .

Contoh 72.10.

Pada 1878, Cantor menyatakan bahwa suatu gabungan terhitung dari himpunan-himpunan terhitung bersifat terhitung. Ia tidak menyajikan bukti, barangkali karena menganggap bukti tersebut jelas. Dengan kehati-hatian kita, kita telah membuktikan versi yang lebih umum dari hasil ini dalam Proposisi 71.12. Namun, bukti kita secara eksplisit mengandaikan Pilihan. Bahkan bukti hasil yang kurang umum pun memerlukan Pilihan Terhitung.

Teorema 72.11.

dalam 𝐙 − + Pilihan Terhitung

Jika A n terhitung bagi setiap n ∈ ω , maka ⋃ n < ω A n terhitung.

Bukti.

Tanpa mengurangi keumuman, andaikan setiap A n ≠ ∅ . Jadi, bagi setiap n ∈ ω , terdapat surjeksi f n : ω → A n . Definisikan f : ω × ω → ⋃ n < ω A n dengan f ( m , n ) = f n ( m ) . Hasilnya mengikuti karena ω × ω terhitung (Proposisi 4.12) dan f merupakan surjeksi.

Apakah Anda melihat penggunaan Pilihan Terhitung? Prinsip itu digunakan untuk memilih barisan fungsi f 0 , f 1 , f 2 , … .49 Sekali lagi, hasil tersebut gagal jika tidak ada prinsip Pilihan sama sekali. Secara khusus, Feferman and Levy (1963) membuktikan bahwa konsisten dengan 𝐙𝐅 bahwa suatu gabungan terhitung dari himpunan-himpunan terhitung mempunyai kardinalitas  ℶ 1 . Berikut pernyataan yang jauh lebih lucu mengenai pokok ini dari Russell:

Hal ini digambarkan oleh seorang jutawan yang membeli sepasang kaus kaki setiap kali ia membeli sepasang sepatu bot, dan tidak pernah pada waktu lain. Kegemarannya membeli keduanya begitu besar sehingga akhirnya ia mempunyai ℵ 0 pasang sepatu bot dan ℵ 0 pasang kaus kaki… Di antara sepatu bot kita dapat membedakan yang kanan dan yang kiri, sehingga kita dapat memilih satu dari setiap pasang: kita dapat memilih semua sepatu bot kanan atau semua sepatu bot kiri. Namun, bagi kaus kaki tidak ada prinsip pemilihan seperti itu yang tersedia, dan tanpa mengandaikan aksioma multiplikatif [yakni, pada hakikatnya Pilihan], kita tidak dapat memastikan bahwa terdapat suatu kelas yang terdiri atas satu kaus kaki dari setiap pasang. (Russell, 1919, hlm. 126)

Singkatnya, suatu bentuk Pilihan diperlukan untuk membuktikan hal berikut: Jika Anda mempunyai pasangan kaus kaki dalam jumlah terhitung, maka Anda mempunyai (hanya) sejumlah terhitung kaus kaki. Bahkan, tanpa Pilihan Terhitung (atau sesuatu yang ekuivalen), gabungan terhitung dari himpunan-himpunan terhitung dapat gagal bersifat terhitung.

Pelajarannya ialah bahwa Pilihan Terhitung digunakan berulang kali tanpa banyak disadari oleh para penggunanya. Pertanyaan filosofisnya ialah: Bagaimana kita dapat membenarkan Pilihan Terhitung?

Suatu upaya pembenaran intuitif mungkin mengacu pada suatu supertugas. Andaikan kita membuat pilihan pertama dalam 1 2 menit, pilihan kedua dalam 1 4 menit, …, pilihan ke- n dalam 1 2 n menit, … Dalam waktu 1  menit, kita akan telah membuat suatu barisan pilihan sepanjang ω dan mendefinisikan suatu fungsi pilihan.

Namun, apa yang sebenarnya dapat ditunjukkan oleh eksperimen pikiran seperti itu? Pertama, ia bergantung pada pemahaman yang sangat harfiah terhadap gagasan “memilih”. Selain itu, ia tampak mengikat matematika pada kemungkinan metafisis.

Yang lebih penting, hal itu tidak akan memberikan pembenaran bagi Pilihan secara penuh, bukan sekadar Pilihan Terhitung. Sebab, jika kita memerlukan setiap himpunan mempunyai suatu fungsi pilihan, kita perlu mampu melakukan “supertugas dengan panjang ordinal sebarang”. Terus terang, gagasan itu menggelikan.

72.6 Pertimbangan Intrinsik tentang Pilihan

Pertanyaan yang lebih luas ialah apakah Pengurutan Baik, Pilihan, atau bahkan keterbandingan semua himpunan menurut ukurannya—tidak menjadi soal yang mana—dapat dibenarkan.

Berikut suatu upaya pembenaran intrinsik. Sebelumnya, dalam Bagian 65.1, kita memperkenalkan beberapa prinsip tentang hierarki. Salah satunya patut dinyatakan kembali:

  1. 𝑆𝑡𝑎𝑔𝑒𝑠-𝑎𝑐𝑐𝑢𝑚𝑢𝑙𝑎𝑡𝑒 . Untuk sebarang tahap S dan sebarang himpunan yang terbentuk sebelum tahap S : pada tahap S terbentuk suatu himpunan yang anggota-anggotanya tepat merupakan himpunan-himpunan tersebut. Tidak ada hal lain yang terbentuk pada tahap  S .

Sesungguhnya, banyak penulis telah mengemukakan bahwa Aksioma Pilihan dapat dibenarkan melalui prinsip ini (atau sesuatu yang serupa dengannya). Kita akan memberikan suatu uraian ringkas mengenai pendekatan tersebut.

Kita mulai dengan suatu hasil sederhana yang menawarkan satu lagi perumusan ekuivalen bagi Pilihan:

Teorema 72.12.

dalam 𝐙𝐅

Pilihan ekuivalen dengan prinsip berikut. Jika anggota dari A saling lepas dan tak kosong, maka terdapat suatu C sedemikian sehingga C ∩ x merupakan singleton bagi setiap x ∈ A . (Kita menyebut C seperti ini sebagai suatu himpunan pilihan bagi  A .)

Bukti hasil ini lugas dan kita serahkan sebagai latihan kepada pembaca.

Pokok yang mendasar ialah bahwa himpunan pilihan bagi A tidak lain adalah daerah hasil suatu fungsi pilihan bagi  A . Jadi, untuk membenarkan Pilihan, kita cukup mencoba membenarkan perumusan ekuivalennya dalam hal keberadaan himpunan pilihan. Itulah yang sekarang akan kita coba lakukan.

Andaikan anggota dari A saling lepas dan tak kosong. Berdasarkan 𝑆𝑡𝑎𝑔𝑒𝑠-𝑎𝑟𝑒-𝑘𝑒𝑦 (lihat Bagian 65.1), A terbentuk pada suatu tahap  S . Perhatikan bahwa semua anggota dari ⋃ A tersedia sebelum tahap  S . Berdasarkan 𝑆𝑡𝑎𝑔𝑒𝑠-𝑎𝑐𝑐𝑢𝑚𝑢𝑙𝑎𝑡𝑒 , bagi sebarang himpunan yang terbentuk sebelum  S , terbentuk pula suatu himpunan yang anggota-anggotanya tepat merupakan himpunan-himpunan tersebut. Dengan kata lain, setiap koleksi yang mungkin dari himpunan-himpunan yang tersedia sebelumnya akan ada pada tahap  S . Namun, tentu mungkin untuk memilih objek-objek yang dapat membentuk suatu himpunan pilihan bagi  A ; ini hanya merupakan suatu himpunan bagian yang sangat spesifik dari ⋃ A . Dengan demikian, himpunan pilihan seperti itu ada, sebagaimana diperlukan.

Itulah suatu upaya yang sangat singkat untuk membenarkan Pilihan berdasarkan pertimbangan intrinsik. Namun, untuk mendalami gagasan ini, Anda sebaiknya membaca pengembangan yang rapi oleh Potter (2004, §14.8).

72.7 Paradoks Banach–Tarski

Kita juga dapat mencoba membenarkan Pilihan, sebagaimana Boolos mencoba membenarkan Penggantian, dengan mengacu pada pertimbangan ekstrinsik (lihat Bagian 68.3). Lagi pula, menerima Pilihan mempunyai banyak konsekuensi yang diinginkan: kemampuan membandingkan setiap kardinal; kemampuan mengurutkan baik setiap himpunan; kemampuan memperlakukan kardinal sebagai suatu jenis ordinal tertentu; dan sebagainya.

Namun, kadang-kadang diklaim bahwa Pilihan mempunyai konsekuensi yang tidak diinginkan. Sebagian besar klaim ini disebabkan oleh suatu hasil dari (Banach and Tarski, 1924).

Teorema 72.13.

Paradoks Banach–Tarski (dalam 𝐙𝐅𝐂 )

Sebarang bola dapat diuraikan menjadi sejumlah hingga kepingan yang dapat disusun kembali (melalui rotasi dan translasi) untuk membentuk dua salinan bola tersebut.

Sekilas, hasil ini cukup mencengangkan. Jelas bahwa kedua bola mempunyai dua kali volume bola semula. Namun, gerak kaku—rotasi dan translasi—tidak mengubah volume. Jadi, tampaknya Banach–Tarski memungkinkan kita mengada-adakan materi baru.

Keadaannya bahkan lebih buruk.50 Penalaran yang serupa menunjukkan bahwa sebutir kacang polong dapat dipotong menjadi sejumlah hingga kepingan yang kemudian dapat disusun kembali (melalui rotasi dan translasi) untuk membentuk suatu benda dengan bentuk dan ukuran Big Ben.

Namun, tidak satu pun dari hasil ini berlaku hanya dalam 𝐙𝐅 .51 Jadi, kita menghadapi suatu keputusan: menolak Pilihan atau belajar hidup dengan “paradoks” tersebut.

Kita akan mengemukakan bahwa kita sebaiknya belajar hidup dengan “paradoks” itu. Bahkan, kita tidak menganggapnya sebagai paradoks yang berarti. Secara khusus, kita tidak melihat mengapa hasil itu lebih atau kurang paradoksal daripada hasil-hasil berikut:52

  1. Terdapat sama banyak titik dalam interval ( 0 , 1 ) dengan dalam ℝ .
    Bukti: perhatikan tan ⁡ ( π ( r − 1 2 ) ) .

  2. Terdapat sama banyak titik pada suatu garis dengan dalam suatu persegi.
    Lihat Bagian 76.3 dan Bagian 76.5.

  3. Terdapat kurva-kurva pengisi ruang.
    Lihat Bagian 76.3 dan Bagian 76.6.

Tidak satu pun dari ketiga hasil ini memerlukan Pilihan. Bahkan, sekarang kita cukup menganggapnya sebagai bagian matematika yang mengejutkan dan indah. Barangkali kita sebaiknya bersikap sama terhadap Paradoks Banach–Tarski.

Memang, suatu pengamatan teknis diperlukan di sini; tetapi kita hanya perlu tetap berpikir jernih. Gerak kaku mempertahankan volume. Akibatnya, kelima kepingan53 yang menjadi hasil penguraian bola tidak mungkin semuanya terukur. Secara kasar, tidak masuk akal untuk menetapkan volume kepada kepingan-kepingan individual ini. Anda perlu membayangkannya sebagai “hamburan-hamburan tak hingga” titik yang tidak dapat digambarkan. Barangkali memang “aneh” untuk memikirkan himpunan “yang terhambur secara tak hingga” seperti itu. Namun, keberadaannya tampak mengikuti perintah yang terkandung dalam 𝑆𝑡𝑎𝑔𝑒𝑠-𝑎𝑐𝑐𝑢𝑚𝑢𝑙𝑎𝑡𝑒 bahwa kita harus membentuk semua koleksi yang mungkin dari himpunan-himpunan yang telah tersedia sebelumnya.

Jika semua itu tidak meyakinkan, berikut suatu argumen (ekstrinsik) terakhir untuk menerima Paradoks Banach–Tarski. Paradoks itu segera menghasilkan lelucon matematika terbaik sepanjang masa:

  1. Pertanyaan. Apa anagram dari “Banach–Tarski”?

  2. Jawaban. “Banach–Tarski Banach–Tarski”.

72.8 Lampiran: Paradoks Vitali

Untuk benar-benar memahami apakah konstruksi Banach–Tarski dapat diterima, kita perlu memeriksa buktinya. Sayangnya, hal itu memerlukan jauh lebih banyak aljabar daripada yang dapat kita sajikan di sini. Namun, kita dapat memberikan beberapa catatan singkat yang mungkin memperjelas bukti Banach–Tarski,54 dengan berfokus pada hasil berikut:

Teorema 72.14.

Paradoks Vitali (dalam 𝐙𝐅𝐂 )

Sebarang lingkaran dapat diuraikan menjadi sejumlah terhitung kepingan yang dapat disusun kembali (melalui rotasi dan translasi) untuk membentuk dua salinan lingkaran tersebut.

Paradoks Vitali jauh lebih mudah dibuktikan daripada Paradoks Banach–Tarski. Kita menyebutnya “Paradoks Vitali” karena ia mengikuti konstruksi suatu himpunan tak terukur oleh Vitali pada 1905. Namun, aspek teori-himpunan dari bukti Paradoks Vitali dan Paradoks Banach–Tarski sangat serupa. Perbedaan mendasar antara kedua hasil itu hanyalah bahwa Banach–Tarski mempertimbangkan suatu penguraian hingga, sedangkan Paradoks Vitali mempertimbangkan suatu penguraian tak hingga terhitung. Sebagaimana dikatakan Weston (2003), Paradoks Vitali “tentu tidak semencolok paradoks Banach–Tarski, tetapi ia memang menunjukkan bahwa paradoks geometris dapat terjadi bahkan dalam situasi yang sederhana.”

Paradoks Vitali menyangkut suatu bangun dua dimensi, yakni lingkaran. Jadi, kita akan bekerja pada bidang ℝ 2 . Misalkan R himpunan rotasi titik (searah jarum jam) mengelilingi titik asal dengan besar sudut radian rasional dalam interval [ 0 , 2 π ) . Berikut beberapa fakta aljabar mengenai R (jika Anda tidak memahami pernyataan hasilnya, bukti akan memperjelas maknanya):

Lema 72.15.

R membentuk suatu grup abelian di bawah komposisi fungsi.

Bukti.

Dengan menulis 0 R untuk rotasi sebesar 0 radian, rotasi ini merupakan unsur identitas bagi R , sebab ρ ∘ 0 R = 0 R ∘ ρ = ρ bagi sebarang ρ ∈ R .

Setiap anggota mempunyai invers. Jika ρ ∈ R berotasi sebesar r radian, maka ρ − 1 ∈ R berotasi sebesar ( − r ) mod 2 π radian, sehingga ρ ∘ ρ − 1 = 0 R .

Komposisi bersifat asosiatif: ( τ ∘ σ ) ∘ ρ = τ ∘ ( σ ∘ ρ ) bagi sebarang ρ , σ , τ ∈ R .

Komposisi bersifat komutatif: σ ∘ ρ = ρ ∘ σ bagi sebarang ρ , σ ∈ R .

Bahkan, kita dapat membelah grup R menjadi dua, lalu menggunakan salah satu belahan untuk memulihkan seluruh grup:

Lema 72.16.

Terdapat suatu partisi R menjadi dua himpunan saling lepas, R 1 dan R 2 , yang masing-masing merupakan basis bagi R .

Bukti.

Misalkan R 1 terdiri atas rotasi dengan besar sudut radian rasional dalam [ 0 , π ) ; misalkan R 2 = R ∖ R 1 . Berdasarkan aljabar elementer, { ρ ∘ ρ : ρ ∈ R 1 } = R . Hasil serupa dapat diperoleh bagi R 2 .

Kita akan menggunakan fakta tentang grup ini untuk menetapkan Teorema 72.14. Misalkan 𝐒 lingkaran satuan, yakni himpunan titik yang berjarak tepat 1 satuan dari titik asal bidang, yaitu { ⟨ r , s ⟩ ∈ ℝ 2 : r 2 + s 2 = 1 } . Kita akan membagi 𝐒 menjadi beberapa bagian dengan mempertimbangkan relasi berikut pada 𝐒 : r ∼ s  𝑗𝑖𝑘𝑎 𝑑𝑎𝑛 ℎ𝑎𝑛𝑦𝑎 𝑗𝑖𝑘𝑎  ( ∃ ρ ∈ R ) ρ ( r ) = s . Artinya, titik-titik pada 𝐒 dihubungkan oleh relasi ini jika dan hanya jika kita dapat berpindah dari satu titik ke titik lain melalui rotasi bernilai rasional mengelilingi titik asal. Tidak mengejutkan bahwa:

Lema 72.17.

∼ merupakan suatu relasi ekuivalensi.

Bukti.

Trivial, dengan menggunakan Lema 72.15.

Sekarang kita menggunakan Pilihan untuk memperoleh suatu himpunan C yang memuat tepat satu anggota dari setiap kelas ekuivalensi 𝐒 di bawah ∼ . Artinya, kita mempertimbangkan suatu fungsi pilihan f pada himpunan kelas-kelas ekuivalensi,55 E = { [ r ] ∼ : r ∈ 𝐒 } , dan menetapkan C = ran ( f ) . Bagi setiap rotasi ρ ∈ R , himpunan ρ [ C ] terdiri atas titik-titik yang diperoleh dengan menerapkan rotasi ρ kepada setiap titik dalam  C . Dua hasil berikut menunjukkan bahwa himpunan-himpunan ini menutupi lingkaran secara lengkap dan tanpa tumpang tindih:

Lema 72.18.

𝐒 = ⋃ ρ ∈ R ρ [ C ] .

Bukti.

Tetapkan s ∈ 𝐒 ; terdapat suatu r ∈ C sedemikian sehingga r ∈ [ s ] ∼ , yakni r ∼ s , yakni ρ ( r ) = s bagi suatu ρ ∈ R .

Lema 72.19.

Jika ρ 1 ≠ ρ 2 , maka ρ 1 [ C ] ∩ ρ 2 [ C ] = ∅ .

Bukti.

Andaikan s ∈ ρ 1 [ C ] ∩ ρ 2 [ C ] . Jadi, s = ρ 1 ( r 1 ) = ρ 2 ( r 2 ) bagi suatu r 1 , r 2 ∈ C . Karena itu, ρ 2 − 1 ( ρ 1 ( r 1 ) ) = r 2 , dan ρ 2 − 1 ∘ ρ 1 ∈ R , sehingga r 1 ∼ r 2 . Jadi, r 1 = r 2 , sebab C memilih tepat satu anggota dari setiap kelas ekuivalensi di bawah ∼ . Maka s = ρ 1 ( r 1 ) = ρ 2 ( r 1 ) , sehingga ρ 1 = ρ 2 .

Sekarang kita menerapkan fakta-fakta aljabar sebelumnya pada lingkaran kita:

Lema 72.20.

Terdapat suatu partisi 𝐒 menjadi dua himpunan saling lepas, D 1 dan D 2 , sedemikian sehingga D 1 dapat dipartisi menjadi sejumlah terhitung himpunan yang dapat dirotasi untuk membentuk suatu salinan 𝐒 (dan demikian pula bagi D 2 ).

Bukti.

Dengan menggunakan R 1 dan R 2 dari Lema 72.16, tetapkan: D 1 = ⋃ ρ ∈ R 1 ρ [ C ] D 2 = ⋃ ρ ∈ R 2 ρ [ C ] Ini merupakan suatu partisi 𝐒 berdasarkan Lema 72.18, dan D 1 serta D 2 saling lepas berdasarkan Lema 72.19. Berdasarkan konstruksi, D 1 dapat dipartisi menjadi sejumlah terhitung himpunan ρ [ C ] , satu bagi setiap ρ ∈ R 1 . Himpunan-himpunan ini dapat dirotasi untuk membentuk suatu salinan 𝐒 , sebab 𝐒 = ⋃ ρ ∈ R ρ [ C ] = ⋃ ρ ∈ R 1 ( ρ ∘ ρ ) [ C ] berdasarkan Lema 72.16 dan Lema 72.18. Penalaran yang sama berlaku bagi  D 2 .

Hal ini langsung mengakibatkan Paradoks Vitali. Kita dapat menghasilkan dua salinan 𝐒 dari 𝐒 hanya dengan membaginya menjadi sejumlah terhitung kepingan (berbagai ρ [ C ] ) lalu menggerakkannya secara kaku (cukup rotasikan setiap kepingan D 1 , serta translasikan lalu rotasikan setiap kepingan D 2 ).

Mari kita rangkum strategi buktinya. Kita mulai dengan beberapa fakta aljabar tentang grup rotasi pada bidang. Kita menggunakan grup ini untuk mempartisi 𝐒 menjadi kelas-kelas ekuivalensi. Kemudian kita memperoleh suatu “paradoks” dengan menggunakan Pilihan untuk memilih anggota dari setiap kelas.

Kita menggunakan strategi yang persis sama untuk membuktikan Banach–Tarski. Perbedaan utamanya ialah bahwa fakta-fakta aljabar yang digunakan untuk membuktikan Banach–Tarski jauh lebih rumit daripada yang digunakan untuk membuktikan Paradoks Vitali. Namun, fakta-fakta aljabar tersebut tidak berhubungan dengan Pilihan. Kita akan merangkumnya dengan cepat.

Untuk membuktikan Banach–Tarski, kita mulai dengan menetapkan suatu analog dari Lema 72.16: sebarang grup bebas dapat dibagi menjadi empat kepingan yang secara intuitif dapat kita “gerakkan” untuk memulihkan dua salinan seluruh grup.56 Kemudian kita menunjukkan bahwa kita dapat menggunakan dua rotasi tertentu mengelilingi titik asal ℝ 3 untuk menghasilkan suatu grup bebas rotasi, F .57 (Belum ada Pilihan.) Sekarang kita menganggap titik-titik pada permukaan bola “serupa” jika dan hanya jika salah satunya dapat diperoleh dari yang lain melalui suatu rotasi dalam  F . Kemudian kita menggunakan Pilihan untuk memilih tepat satu titik dari setiap kelas ekuivalensi titik-titik “serupa”. Dengan menerapkan pembagian F pada permukaan bola seperti dalam Lema 72.20, kita membagi permukaan itu menjadi empat kepingan yang dapat kita “gerakkan” untuk memperoleh dua salinan permukaan bola. Hal ini menetapkan (Hausdorff, 1914):

Teorema 72.21.

Paradoks Hausdorff (dalam 𝐙𝐅𝐂 )

Permukaan sebarang bola dapat diuraikan menjadi sejumlah hingga kepingan yang dapat disusun kembali (melalui rotasi dan translasi) untuk membentuk dua salinan saling lepas dari bola tersebut.

Beberapa trik aljabar tambahan diperlukan untuk memperoleh Teorema Banach–Tarski sepenuhnya (yang menyangkut bukan hanya permukaan bola, melainkan juga bagian dalamnya). Terus terang, hal ini hanya merupakan hiasan di atas kue aljabar. Karena itu, Weston menulis:

[…] hasil tentang grup bebas merupakan langkah kunci dalam bukti paradoks Banach–Tarski. Dari sudut pandang ini, paradoks Banach–Tarski bukanlah pernyataan mengenai ℝ 3 sebagaimana ia merupakan pernyataan mengenai kompleksitas grup [translasi dan rotasi dalam ℝ 3 ]. (Weston, 2003, hlm. 16)

Artinya, apakah kita dapat memberikan suatu penguraian hingga (seperti dalam Banach–Tarski) atau penguraian tak hingga terhitung (seperti dalam Paradoks Vitali) ditentukan oleh fakta-fakta teori grup tertentu tentang bekerja dalam dua atau tiga dimensi.

Memang, pengamatan terakhir ini sedikit merusak lelucon pada akhir Bagian 72.7. Karena bersifat dua dimensi, “Banach–Tarski” harus dibagi menjadi sejumlah tak hingga terhitung kepingan jika orang ingin menyusun ulang kepingan-kepingan itu untuk membentuk “Banach–Tarski Banach–Tarski”. Untuk memperbaiki leluconnya, orang harus menulis dalam tiga dimensi. Kita serahkan hal ini sebagai latihan kepada pembaca.

Satu komentar terakhir. Dalam Bagian 72.7, kita menyebutkan bahwa “kepingan-kepingan” bola yang diperoleh tidak dapat terukur, melainkan harus merupakan “hamburan-hamburan tak hingga” yang tidak dapat digambarkan. Hal yang sama berlaku pada penggunaan Pilihan untuk memperoleh Lema 72.20. Pokok ini patut dijelaskan.

Sekali lagi, kita harus menguraikan sedikit latar belakang (tetapi ini hanya sebuah uraian ringkas; Anda mungkin ingin membaca entri buku teks tentang ukuran). Mendefinisikan ukuran bagi suatu himpunan X berarti menetapkan suatu nilai μ ( E ) ∈ ℝ kepada setiap E dalam suatu “aljabar- σ ” pada  X . Perinciannya tidak penting di sini, kecuali bahwa fungsi μ harus memenuhi prinsip aditivitas terhitung: ukuran suatu gabungan terhitung dari himpunan-himpunan saling lepas merupakan jumlah ukuran masing-masing, yakni μ ( ⋃ n < ω X n ) = ∑ n < ω μ ( X n ) jika himpunan-himpunan X n saling lepas. Mengatakan bahwa suatu himpunan “tak terukur” berarti tidak ada ukuran yang dapat ditetapkan kepadanya secara semestinya. Sekarang, dengan menggunakan R di atas:

Akibat 72.22.

Vitali

Misalkan μ suatu ukuran sedemikian sehingga μ ( 𝐒 ) = 1 dan μ ( X ) = μ ( Y ) jika X dan Y kongruen. Maka ρ [ C ] tak terukur bagi semua ρ ∈ R .

Bukti.

Untuk reductio, andaikan sebaliknya. Misalkan μ ( σ [ C ] ) = r bagi suatu σ ∈ R dan suatu r ∈ ℝ . Bagi sebarang ρ ∈ R , ρ [ C ] dan σ [ C ] kongruen; karena itu, μ ( ρ [ C ] ) = r bagi sebarang ρ ∈ R . Berdasarkan Lema 72.18 dan Lema 72.19, 𝐒 = ⋃ ρ ∈ R ρ [ C ] merupakan suatu gabungan terhitung dari himpunan-himpunan saling lepas berpasangan. Jadi, aditivitas terhitung mengharuskan bahwa μ ( 𝐒 ) = 1 merupakan jumlah ukuran setiap ρ [ C ] , yakni: 1 = μ ( 𝐒 ) = ∑ ρ ∈ R μ ( ρ [ C ] ) = ∑ ρ ∈ R r Namun, jika r = 0 , maka ∑ ρ ∈ R r = 0 ; dan jika r > 0 , maka ∑ ρ ∈ R r = ∞ .

Soal

Soal 72.1.
