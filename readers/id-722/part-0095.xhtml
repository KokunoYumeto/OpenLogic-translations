76 Sejarah dan Mitologi Teori Himpunan

Bab ini memuat pendahuluan historis dari teks Open Set Theory karya Tim Button.

76.1 Infinitesimal dan Diferensiasi

Newton dan Leibniz menemukan kalkulus (secara independen) pada akhir abad ke-17. Salah satu penerapan kalkulus yang sangat penting ialah diferensiasi. Secara kasar, diferensiasi bertujuan memberikan suatu pengertian tentang “laju perubahan”, atau gradien, suatu fungsi pada suatu titik.

Berikut cara yang jelas untuk menggambarkan gagasan tersebut. Pertimbangkan fungsi f ( x ) = x 2 4 + 1 2 , yang digambarkan dengan warna hitam di bawah ini:

Andaikan kita hendak mencari gradien fungsi pada c = 1 2 . Kita mulai dengan menggambar suatu segitiga yang hipotenusanya menghampiri gradien pada titik tersebut, misalnya segitiga merah di atas. Jika β merupakan panjang alas segitiga kita, tingginya ialah f ( 1 2 + β ) − f ( 1 2 ) , sehingga gradien hipotenusanya ialah: f ( 1 2 + β ) − f ( 1 2 ) β . Jadi, gradien segitiga merah kita, yang panjang alasnya  3 , tepat sama dengan  1 . Hipotenusa segitiga yang lebih kecil, yaitu segitiga biru dengan panjang alas  2 , memberikan hampiran yang lebih baik; gradiennya ialah 3 4 . Segitiga yang lebih kecil lagi, yakni segitiga hijau dengan panjang alas  1 , memberikan hampiran yang lebih baik lagi; gradiennya ialah 1 2 .

Segitiga yang semakin kecil memberikan hampiran yang semakin baik. Karena itu, kita mungkin berkata seperti berikut: hipotenusa suatu segitiga dengan panjang alas infinitesimal memberikan gradien pada c = 1 2 itu sendiri. Dengan cara ini, kita memperoleh suatu rumus bagi turunan (pertama) fungsi f pada titik c : f ′ ( c ) = f ( c + β ) − f ( c ) β  dengan  β  infinitesimal. Secara kasar, inilah yang dikatakan Newton dan Leibniz.

Namun, karena mereka mengatakan demikian, kita harus bertanya: apakah infinitesimal itu? Timbul suatu dilema serius. Jika β = 0 , maka f ′ tidak terdefinisi dengan baik karena melibatkan pembagian oleh  0 . Namun, jika β > 0 , kita hanya memperoleh suatu hampiran gradien, bukan gradien itu sendiri.

Kekhawatiran ini bukan anakronisme. Berikut kritik Berkeley terhadap para pengikut Newton:

Saya mengakui bahwa tanda dapat dibuat untuk menyatakan sesuatu atau tidak menyatakan apa pun; dan karena itu, dalam notasi semula c + β , β dapat menyatakan suatu pertambahan ataupun ketiadaan. Namun, apa pun yang Anda jadikan maknanya, Anda harus bernalar secara konsisten dengan makna itu dan tidak melanjutkan berdasarkan makna ganda; melakukan hal tersebut merupakan sofisme yang nyata. (Berkeley 1734, §XIII, variabel diubah agar sesuai dengan teks sebelumnya)

Untuk membela kalkulus infinitesimal terhadap Berkeley, orang mungkin menjawab bahwa pembicaraan tentang “infinitesimal” hanyalah kiasan. Orang mungkin berkata bahwa, selama kita mengambil segitiga yang sangat kecil, kita akan memperoleh suatu hampiran garis singgung yang cukup baik. Berkeley juga mempunyai jawaban bagi hal ini: walaupun hal itu mungkin cukup baik bagi rekayasa, ia merusak status matematika, sebab

kita diberi tahu bahwa in rebus mathematicis errores quàm minimi non sunt contemnendi. [Dalam matematika, kesalahan yang paling kecil pun tidak boleh diabaikan.] (Berkeley, 1734, §IX)

Petikan bercetak miring tersebut hampir merupakan kutipan kata demi kata dari Quadrature of Curves (1704) karya Newton sendiri.

Keberatan filosofis Berkeley sangat tajam. Meskipun demikian, kalkulus merupakan usaha yang sangat berhasil, dan para matematikawan terus menggunakannya tanpa terjerumus ke dalam kesalahan.

76.2 Definisi Limit yang Ketat

Sekarang, penyelesaian standar bagi masalah di atas ialah menyingkirkan infinitesimal. Berikut caranya.

Kita melihat bahwa ketika β semakin kecil, kita memperoleh hampiran gradien yang semakin baik. Bahkan, ketika β mendekati 0 sedekat apa pun, nilai f ′ ( c ) “cenderung tanpa batas” menuju gradien yang kita inginkan. Jadi, alih-alih mempertimbangkan apa yang terjadi pada β = 0 , kita hanya perlu mempertimbangkan kecenderungan f ′ ( c ) ketika β mendekati  0 .

Dengan ungkapan ini, tantangan umumnya ialah memahami klaim berbentuk:

Ketika x mendekati c , g ( x ) cenderung tanpa batas menuju ℓ .

yang dapat kita tulis dengan lebih ringkas sebagai: lim x → c g ( x ) = ℓ . Pada abad ke-19, dengan mengembangkan karya Cauchy sebelumnya, Weierstrass memberikan suatu definisi yang sepenuhnya ketat bagi ungkapan ini. Gagasannya memang bahwa kita dapat membuat g ( x ) sedekat yang kita inginkan dengan  ℓ dengan membuat x cukup dekat dengan  c . Lebih tepatnya, kita menetapkan bahwa lim x → c g ( x ) = ℓ berarti: ( ∀ ε > 0 ) ( ∃ δ > 0 ) ∀ x ( 0 < | x − c | < δ → | g ( x ) − ℓ | < ε ) . Garis vertikal di sini menyatakan nilai mutlak. Artinya, | x | = x jika x ≥ 0 , dan | x | = − x jika x < 0 ; fungsi tersebut dapat digambarkan sebagai berikut:

Jadi, secara kasar definisi itu mengatakan: Anda dapat membuat “galat” lebih kecil daripada ε (yakni | g ( x ) − ℓ | < ε ) dengan memilih argumen yang tidak sama dengan c dan berjarak kurang dari δ dari  c (yakni 0 < | x − c | < δ ).

Setelah mendefinisikan pengertian limit, kita dapat menggunakannya untuk sepenuhnya menghindari infinitesimal dengan menetapkan bahwa gradien f pada c diberikan oleh: f ′ ( c ) = lim x → 0 ( f ( c + x ) − f ( c ) x )  jika limitnya ada . Namun, penting untuk memahami mengapa definisi kita memerlukan syarat “jika limitnya ada”. Sebagai contoh sederhana, pertimbangkan f ( x ) = | x | , yang grafiknya baru saja kita lihat. Jelas bahwa f ′ ( 0 ) tidak terdefinisi dengan baik: jika kita mendekati 0 “dari kanan”, gradiennya selalu 1 ; jika kita mendekati 0 “dari kiri”, gradiennya selalu − 1 ; jadi, limitnya tidak terdefinisi. Dengan demikian, kita dapat menambahkan bahwa suatu fungsi  f dapat didiferensialkan pada  x jika dan hanya jika limit tersebut ada.

Kita telah melihat cara menangani diferensiasi dengan menggunakan pengertian limit. Kita dapat menggunakan pengertian yang sama untuk mendefinisikan gagasan fungsi kontinu. (Pada hakikatnya, Bolzano telah menyadarinya pada 1817.) Perlakuan Cauchy–Weierstrass terhadap kontinuitas adalah sebagai berikut. Secara kasar, suatu fungsi  f kontinu (pada suatu titik) jika, ketika Anda menuntut tingkat ketelitian tertentu pada keluaran fungsi, tuntutan itu dapat dijamin dengan mengharuskan tingkat ketelitian tertentu pada masukan fungsi. Lebih tepatnya, f kontinu pada c jika, ketika x cenderung ke nol, selisih antara f ( c + x ) dan f ( c ) sendiri cenderung ke  0 . Dengan kata lain, f kontinu pada c jika dan hanya jika f ( c ) = lim x → c f ( x ) .

Melangkah lebih jauh hanya akan membawa kita ke analisis real, padahal pokok bahasan kita ialah teori himpunan. Jadi, sekarang kita perlu berhenti dan menyatakan pelajarannya. Selama abad ke-19, para matematikawan belajar bekerja tanpa infinitesimal dengan menggunakan pengertian limit yang didefinisikan secara ketat.

76.3 Patologi

Namun, ternyata definisi limit memungkinkan beberapa konstruksi yang cukup “patologis”.

Sekitar dasawarsa 1830-an, Bolzano menemukan suatu fungsi yang kontinu di mana-mana, tetapi tidak dapat didiferensialkan di mana pun. (Sayangnya, Bolzano tidak pernah menerbitkan hasil ini; para matematikawan baru menjumpai gagasan tersebut pada 1872 berkat penemuan independen Weierstrass atas gagasan yang sama.)60 Setidaknya, hasil ini cukup mengejutkan. Mudah menemukan fungsi seperti | x | yang kontinu di mana-mana tetapi tidak dapat didiferensialkan pada satu titik tertentu. Namun, suatu fungsi yang kontinu di mana-mana tetapi tidak dapat didiferensialkan di mana pun sungguh merupakan makhluk yang sangat berbeda. Bayangkan sejenak bagaimana Anda mencoba menggambar fungsi seperti itu. Untuk menjamin kontinuitasnya, Anda harus dapat menggambarnya tanpa pernah mengangkat pena dari halaman; tetapi untuk menjamin bahwa ia tidak dapat didiferensialkan di mana pun, Anda harus terus-menerus mengubah arah pena secara mendadak.

“Patologi” lain menyusul. Pada 5 Januari 1874, Cantor menulis surat kepada Dedekind dan mengajukan masalah berikut:

Dapatkah suatu permukaan (misalnya suatu persegi beserta batasnya) dikorelasikan satu-satu dengan suatu garis (misalnya suatu garis lurus beserta titik-titik ujungnya), sehingga setiap titik permukaan berpadanan dengan suatu titik garis dan, sebaliknya, setiap titik garis berpadanan dengan suatu titik permukaan?

Saat ini masih tampak bagi saya bahwa jawaban atas pertanyaan ini sangat sulit—meskipun di sini pun orang begitu terdorong untuk menjawab tidak, sehingga orang ingin menganggap pembuktiannya hampir tidak perlu. [Dikutip dalam Gouvêa 2011]

Namun, pada 1877, Cantor membuktikan bahwa ia keliru. Sesungguhnya, suatu garis dan suatu persegi mempunyai jumlah titik yang tepat sama. Pada 29 Juni 1877, ia menulis kepada Dedekind, “je le vois, mais je ne le crois pas”; yakni, “Saya melihatnya, tetapi saya tidak memercayainya”. Dalam “sejarah yang lazim diterima” mengenai matematika, ucapan ini sering dianggap menunjukkan betapa sungguh sulit dipercayanya hasil-hasil baru tersebut bagi para matematikawan pada masa itu. (Korespondensinya disajikan dalam Gouvêa (2011), dan kita kembali membahasnya dalam Bagian 76.4. Bukti Cantor diuraikan secara ringkas dalam Bagian 76.5.)

Terinspirasi oleh hasil Cantor, Peano mulai mempertimbangkan apakah mungkin memetakan suatu garis secara kontinu ke seluruh bidang. Ini akan menjadi suatu kurva pengisi ruang. Pada 1890, Peano mengonstruksi tepat kurva seperti itu. Hasil ini benar-benar berlawanan dengan intuisi: Euclid mendefinisikan garis sebagai “panjang tanpa lebar” (Buku I, Definisi 2), tetapi Peano menunjukkan bahwa dengan melengkungkan suatu garis secara tepat, panjangnya dapat diubah menjadi lebar. Pada 1891, Hilbert menguraikan suatu kurva pengisi ruang yang agak lebih intuitif, beserta beberapa gambar yang mengilustrasikannya. Kurva itu dikonstruksi secara berurutan; berikut enam tahap pertama konstruksinya:

Pada limit—suatu pengertian yang saat itu telah menerima definisi ketat—seluruh persegi terisi penuh dengan merah. Sebagai catatan, kurva Hilbert kontinu di mana-mana tetapi tidak dapat didiferensialkan di mana pun; secara intuitif karena, pada limit tak hingga, fungsi itu mengubah arah secara mendadak pada setiap saat. (Kita akan menguraikan konstruksi Hilbert secara lebih terperinci dalam Bagian 76.6.)

Entah baik atau buruk, konstruksi geometris “patologis” ini diperlakukan sebagai alasan untuk meragukan penggunaan intuisi geometris. Konstruksi itu menjadi sesuatu yang mendekati propaganda bagi cara baru mengerjakan matematika, yang kelak memuncak pada teori himpunan. Dalam pembentukan mitos tentang bidang ini pada masa berikutnya, sering diulangi bahwa hasil-hasil tersebut sepenuhnya ketat sekaligus sepenuhnya mengejutkan. Karena itu, hasil-hasil tersebut melayani dua tujuan: sebagai peringatan agar tidak bergantung pada intuisi geometris, dan sebagai demonstrasi kesuburan cara berpikir baru.

76.4 Lebih Banyak Mitos daripada Sejarah?

Ketika meninjau kembali peristiwa-peristiwa ini dengan jarak waktu lebih dari satu abad, kita harus berhati-hati agar tidak menerima putusan-putusan tersebut begitu saja. Hasil-hasilnya tentu baru, menarik, dan mengejutkan. Namun, seberapa mengejutkankah hasil-hasil itu sebenarnya? Dan benarkah mereka menunjukkan bahwa kita tidak seharusnya mengandalkan intuisi geometris?

Mengenai persoalan keterkejutan, Gouvêa (2011) menunjukkan bahwa catatan Cantor yang terkenal kepada Dedekind, “je le vois, mais je ne le crois pas”, diambil cukup jauh dari konteksnya. Berikut bagian yang lebih lengkap dari konteks tersebut (dikutip dari Gouvêa):

Maafkan kegairahan saya terhadap pokok ini jika saya begitu banyak menuntut kebaikan dan kesabaran Anda; komunikasi yang baru-baru ini saya kirimkan kepada Anda begitu tidak terduga, begitu baru, bahkan bagi saya, sehingga saya tidak dapat merasa tenang sebelum memperoleh dari Anda, sahabat yang terhormat, suatu putusan mengenai kebenarannya. Selama Anda belum menyetujui saya, saya hanya dapat berkata: je le vois, mais je ne le crois pas.

Cantor mengetahui bahwa hasilnya “begitu tidak terduga, begitu baru”. Namun, diragukan bahwa ia pernah menganggap hasilnya mustahil dipercaya. Sebagaimana ditunjukkan Gouvêa, ia hanya meminta Dedekind memeriksa bukti yang telah diberikannya.

Mengenai persoalan intuisi geometris: Peano menerbitkan kurva pengisi ruangnya tanpa menyertakan diagram apa pun. Namun, ketika Hilbert menerbitkan kurvanya, ia menjelaskan tujuannya: ia hendak memberi pembaca suatu cara yang jelas untuk memahami hasil Peano jika mereka “menggunakan intuisi geometris berikut”; lalu ia menyertakan serangkaian diagram seperti yang diberikan dalam Bagian 76.3.

Secara lebih umum, walaupun diagram agak ketinggalan mode dalam bukti yang diterbitkan, tidak dapat disangkal bahwa para matematikawan sering menggunakan diagram ketika membuktikan sesuatu. (Secara kasar, matematikawan yang baik mengetahui kapan mereka dapat mengandalkan intuisi geometris.)

Singkatnya: jangan percaya begitu saja pada kehebohannya; setidaknya, jangan menerimanya tanpa pemeriksaan. Untuk pembahasan lebih lanjut, Anda dapat membaca Giaquinto (2007).

76.5 Cantor tentang Garis dan Bidang

Beberapa keadaan seputar pembuktian Schröder–Bernstein berkaitan dengan sejarah yang kita bahas dalam Bagian 76.3. Ingat bahwa pada 1877 Cantor membuktikan bahwa terdapat tepat sama banyak titik pada suatu persegi dengan pada salah satu sisinya. Di sini kita akan menyajikan bukti (percobaan pertama) Cantor.

Misalkan L garis satuan, yakni himpunan titik [ 0 , 1 ] . Misalkan S persegi satuan, yakni himpunan titik L × L . Dalam istilah ini, Cantor membuktikan L ≈ S . Ia menulis suatu catatan kepada Dedekind yang pada dasarnya memuat argumen berikut.

Teorema 76.1.

L ≈ S .

Bukti: bagian pertama.

Tetapkan a , b ∈ L . Tuliskan keduanya dalam notasi biner, sehingga kita mempunyai barisan tak hingga angka 0 dan 1 , yaitu a 1 , a 2 , … dan b 1 , b 2 , … , sedemikian sehingga: a = 0. a 1 a 2 a 3 a 4 … b = 0. b 1 b 2 b 3 b 4 … Sekarang pertimbangkan fungsi  f : S → L  yang diberikan oleh f ( a , b ) = 0. a 1 b 1 a 2 b 2 a 3 b 3 a 4 b 4 … Sekarang f merupakan injeksi, sebab jika f ( a , b ) = f ( c , d ) , maka a n = c n dan b n = d n bagi semua n ∈ ℕ , sehingga a = c dan b = d .

Sayangnya, sebagaimana ditunjukkan Dedekind kepada Cantor, hal ini tidak menjawab pertanyaan semula. Pertimbangkan 0. 1 ˙ 0 ˙ = 0.1010101010 … . Kita memerlukan f ( a , b ) = 0. 1 ˙ 0 ˙ , dengan: a = 0. 1 ˙ 1 ˙ = 0.111111 … b = 0 Namun, a = 0. 1 ˙ 1 ˙ = 1 . Jadi, ketika kita berkata “tuliskan a dan b dalam notasi biner”, kita harus memilih notasi mana yang digunakan; dan karena f harus merupakan suatu fungsi, kita hanya dapat menggunakan satu dari kedua notasi yang mungkin. Namun, jika misalnya kita menggunakan notasi sederhana dan menulis a sebagai “ 1.000 … ”, tidak ada pasangan ⟨ a , b ⟩ sedemikian sehingga f ( a , b ) = 0. 1 ˙ 0 ˙ .

Ringkasnya, Dedekind menunjukkan bahwa karena kemungkinan adanya ekspansi biner berulang tertentu, fungsi f dari Cantor merupakan injeksi tetapi bukan surjeksi. Jadi, Cantor hanya menunjukkan S ⪯ L dan bukan S ≈ L .

Cantor segera membalas Dedekind dan pada dasarnya mengemukakan bahwa bukti dapat diselesaikan sebagai berikut:

Bukti: penyelesaian.

Kita telah menunjukkan S ⪯ L . Namun, jelas terdapat injeksi dari L ke S : cukup letakkan garis secara mendatar pada salah satu sisi persegi. Jadi, L ⪯ S dan S ⪯ L . Berdasarkan Schröder–Bernstein (Teorema 4.25), L ≈ S .

Namun, tentu saja Cantor tidak dapat menyelesaikan baris terakhir dengan istilah-istilah ini karena Teorema Schröder–Bernstein belum terbukti. Memang, walaupun kemudian Cantor merumuskannya sebagai dugaan umum, teorema itu baru dibuktikan secara memuaskan pada 1897. (Karena itu, kemudian pada 1877 Cantor memberikan bukti lain bagi Teorema 76.1, yang tidak melalui Schröder–Bernstein.)

76.6 Lampiran: Kurva Pengisi Ruang Hilbert

Dalam bab Bagian 76.3, kita menyebutkan bahwa bukti Cantor bahwa suatu garis dan suatu persegi mempunyai jumlah titik yang tepat sama (Teorema 76.1) mendorong Peano bertanya apakah mungkin terdapat suatu kurva pengisi ruang. Ia memperoleh jawaban positif pada 1890. Dalam bagian ini, kita menjelaskan (secara informal) cara mengonstruksi kurva pengisi ruang Hilbert (dengan sedikit modifikasi).61

Kita harus mendefinisikan suatu fungsi h sebagai limit dari barisan fungsi h 1 , h 2 , h 3 , … Pertama, kita uraikan konstruksinya. Kemudian, kita tunjukkan bahwa ia mengisi ruang. Terakhir, kita tunjukkan bahwa ia merupakan suatu kurva.

Kita akan mengambil daerah hasil h sebagai persegi satuan, S . Berikut hampiran pertama kita terhadap h , yakni  h 1 :

Untuk memudahkan pencatatan, kita menempatkan kisi 2 × 2 pada persegi tersebut. Kita dapat membayangkan kurva bermula di kuadran kiri bawah, bergerak ke kiri atas, lalu ke kanan atas, dan akhirnya ke kanan bawah. Berikut tahap kedua konstruksinya, yakni  h 2 :

Warna-warna yang berbeda membantu menjelaskan cara h 2 dikonstruksi. Mula-mula, kita menempatkan salinan diperkecil dari bagian h 1 selain bagian merah pada kiri bawah, kiri atas, kanan atas, dan kanan bawah persegi kita (digambar hitam). Kemudian, kita menghubungkan keempat bangun ini (dengan garis hijau). Terakhir, kita menghubungkan bangun tersebut dengan batas persegi (menggunakan garis merah).

Sekarang beralih ke h 3 . Sebagaimana h 2 dibuat dari empat salinan terhubung dan diperkecil dari bagian h 1 yang bukan merah, h 3 terdiri atas empat salinan diperkecil dari bagian h 2 yang bukan merah (digambar hitam), yang kemudian dihubungkan (dengan garis hijau) dan akhirnya dihubungkan dengan batas persegi (menggunakan garis merah).

Sekarang kita melihat pola umum untuk mendefinisikan h n + 1 dari  h n . Akhirnya, kita mendefinisikan kurva h itu sendiri dengan mempertimbangkan limit titik demi titik dari fungsi-fungsi berturutan h 1 , h 2 , … Artinya, bagi setiap x ∈ L : h ( x ) = lim n → ∞ h n ( x ) Sekarang kita menunjukkan bahwa kurva ini mengisi ruang. Ketika menggambar kurva h n , kita menempatkan kisi 2 n × 2 n pada S . Berdasarkan Teorema Pythagoras, panjang diagonal setiap petak kisi ialah: ( 1 2 n ) 2 + ( 1 2 n ) 2 = 2 ( 1 2 − n ) dan jelas h n melewati setiap petak kisi. Jadi, setiap titik dalam S berjarak paling jauh 2 ( 1 2 − n ) dari suatu titik pada  h n . Sekarang, h didefinisikan sebagai limit fungsi-fungsi h 1 , h 2 , h 3 , … Jadi, jarak maksimum sebarang titik dari h diberikan oleh: lim n → ∞ 2 ( 1 2 − n ) = 0. Artinya, setiap titik dalam S berjarak 0 dari  h . Dengan kata lain, setiap titik S terletak pada kurva. Jadi, h mengisi ruang!

Masih perlu ditunjukkan bahwa h memang merupakan suatu kurva. Untuk menunjukkannya, kita harus mendefinisikan pengertian tersebut. Definisi modern dikembangkan dari definisi yang diberikan Jordan pada 1887 (yakni hanya beberapa tahun sebelum kurva pengisi ruang pertama diberikan):

Definisi 76.2.

Suatu kurva ialah pemetaan kontinu dari L ke ℝ 2 .

Definisi ini cukup intuitif: secara intuitif, suatu kurva merupakan pemetaan “mulus” yang membawa suatu garis kanonis ke bidang ℝ 2 . Fungsi kita, h , memang merupakan pemetaan dari L ke ℝ 2 . Jadi, kita hanya perlu menunjukkan bahwa h kontinu. Kita mendefinisikan kontinuitas dalam Bagian 76.2 dengan menggunakan notasi ε / δ .

Setiap h n kontinu: fungsi itu menelusuri secara berurutan segmen-segmen garis dalam konstruksi tahap ke- n . Selain itu, konstruksi menjamin bahwa fungsi-fungsi h m dengan m > n memperhalus lintasan di dalam petak-petak kisi tahap ke- n tanpa berpindah ke petak jauh. Karena diameter setiap petak ialah 2 ( 1 2 − n ) , jarak maksimum antara h m ( x ) dan h n ( x ) , seragam bagi semua x ∈ L , cenderung ke  0 ketika n → ∞ . Jadi, h n berkonvergensi secara seragam menuju  h .

Sekarang tetapkan x ∈ L dan ε > 0 . Pilih n sedemikian sehingga h n berada dalam ε 3 dari h pada setiap titik. Karena h n kontinu, terdapat suatu bagian terbuka I dari L yang memuat x sedemikian sehingga, bagi setiap y ∈ I , h n ( y ) berada dalam ε 3 dari h n ( x ) . Berdasarkan pertaksamaan segitiga, h ( y ) kemudian berada dalam ε dari h ( x ) . Dengan demikian, h kontinu, sehingga benar-benar merupakan suatu kurva.
