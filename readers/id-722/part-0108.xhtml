Logika orde pertama

8.1 Pendahuluan

Untuk mengembangkan teori dan metateori logika orde pertama, mula-mula kita harus mendefinisikan sintaks dan semantik ungkapan-ungkapannya. Ungkapan logika orde pertama terdiri atas suku dan formula. Suku dibentuk dari variabel, simbol konstanta, dan simbol fungsi. Selanjutnya, Formula dibentuk dari simbol predikat bersama suku (yang membentuk formula terkecil, atau “atomik”), lalu dari formula atomik kita dapat membentuk formula yang lebih kompleks dengan menggunakan penghubung logis dan kuantor. Ada banyak cara berbeda untuk menetapkan kaidah pembentukan; di sini kita hanya memberikan salah satu cara. Sistem lain akan memilih simbol yang berbeda, memilih himpunan penghubung primitif yang berbeda, serta menggunakan tanda kurung secara berbeda (atau bahkan tidak menggunakannya sama sekali, seperti dalam apa yang disebut notasi Polandia). Namun, semua pendekatan mempunyai kesamaan bahwa kaidah pembentukan mendefinisikan himpunan suku dan formula secara induktif. Jika dilakukan dengan tepat, setiap ungkapan pada dasarnya hanya dapat dihasilkan melalui satu cara menurut kaidah pembentukan. Definisi induktif yang menghasilkan ungkapan yang dapat dibaca secara unik memungkinkan kita memberi makna kepada ungkapan-ungkapan tersebut dengan metode yang sama—definisi induktif.

Pemberian makna kepada ungkapan merupakan ranah semantik. Konsep utama dalam semantik ialah kepuasan dalam struktur. struktur memberi makna kepada unsur-unsur dasar bahasa: domain ialah himpunan objek yang tak kosong. Kuantor ditafsirkan merentang atas domain ini, simbol konstanta diberi elemen dalam domain, simbol fungsi diberi fungsi dari domain ke dirinya sendiri, dan simbol predikat diberi relasi pada domain. domain bersama penetapan bagi kosakata dasar membentuk struktur. Variabel dapat muncul dalam formula; untuk memberikan semantiknya, kita juga harus menetapkan anggota dari domain kepadanya—inilah penetapan variabel. Terakhir, relasi kepuasan memadukan semua hal tersebut. formula dapat terpenuhi dalam struktur  𝔐 relatif terhadap penetapan variabel  s , yang ditulis 𝔐 , s ⊨ φ . Relasi ini juga didefinisikan dengan induksi pada struktur  φ , menggunakan tabel kebenaran bagi penghubung logis untuk mendefinisikan, misalnya, kepuasan φ ∧ ψ berdasarkan terpenuhi atau tidak terpenuhinya φ dan  ψ . Ternyata penetapan variabel tidak relevan jika formula  φ merupakan kalimat, yakni tidak mempunyai variabel bebas; karena itu kita dapat membicarakan kalimat yang terpenuhi (atau tidak) begitu saja dalam struktur.

Berdasarkan relasi kepuasan 𝔐 ⊨ φ bagi kalimat, selanjutnya kita dapat mendefinisikan pengertian semantik dasar berupa validitas, konsekuensi, dan keterpenuhan. Suatu kalimat valid, ⊨ φ , jika setiap struktur memenuhinya. Kalimat itu merupakan konsekuensi dari suatu himpunan kalimat, Γ ⊨ φ , jika setiap struktur yang memenuhi semua kalimat dalam  Γ juga memenuhi  φ . Suatu himpunan kalimat dapat dipenuhi jika terdapat struktur yang memenuhi semua kalimat di dalamnya secara bersamaan. Karena formula didefinisikan secara induktif, dan kepuasan pada gilirannya didefinisikan dengan induksi pada struktur formula, kita dapat menggunakan induksi untuk membuktikan sifat-sifat semantik kita dan menghubungkan pengertian-pengertian semantik yang telah didefinisikan.

8.2 Sifat-Sifat Keterderivasian

Proposisi 8.1.

Monotonisitas

Jika Γ ⊆ Δ dan Γ ⊢ φ , maka Δ ⊢ φ juga.

Bukti.

Setiap Γ 0 ⊆ Γ yang berhingga juga merupakan subhimpunan berhingga dari  Δ , sehingga derivasi atas Γ 0 ⊢ φ juga menunjukkan Δ ⊢ φ .

Proposisi 8.2.

Γ ⊢ φ jika dan hanya jika Γ ∪ { ¬ φ } tak konsisten.

Proposisi 8.3.

  1. Jika Γ ⊢ φ dan Γ ∪ { φ } ⊢ ⊥ , maka Γ tak konsisten.

  2. Jika Γ ∪ { φ } ⊢ ⊥ , maka Γ ⊢ ¬ φ .

  3. Jika Γ ∪ { φ } ⊢ ⊥ dan Γ ∪ { ¬ φ } ⊢ ⊥ , maka Γ ⊢ ⊥ .

  4. Jika Γ ∪ { φ } ⊢ ⊥ dan Γ ∪ { ψ } ⊢ ⊥ , maka Γ ∪ { φ ∨ ψ } ⊢ ⊥ .

  5. Jika Γ ⊢ φ atau Γ ⊢ ψ , maka Γ ⊢ φ ∨ ψ .

  6. Jika Γ ⊢ φ ∧ ψ , maka Γ ⊢ φ dan Γ ⊢ ψ .

  7. Jika Γ ⊢ φ dan Γ ⊢ ψ , maka Γ ⊢ φ ∧ ψ .

  8. Jika Γ ⊢ φ dan Γ ⊢ φ → ψ , maka Γ ⊢ ψ .

  9. Jika Γ ⊢ ¬ φ atau Γ ⊢ ψ , maka Γ ⊢ φ → ψ .

Bukti.

  1. Andaikan Γ 0 ∪ { φ } ⊢ ⊥ .

    1. Γ 0 ∪ { φ } ⊢ ⊥ hip.
    2. Γ 1 ⊢ φ hip.
    3. Γ 0 ∪ Γ 1 ⊢ ⊥ Cut

    Karena Γ 0 ⊆ Γ dan Γ 1 ⊆ Γ , Γ 0 ∪ Γ 1 ⊆ Γ ; jadi, Γ ⊢ ⊥ .

  2. Andaikan Γ 0 ∪ { φ } ⊢ ⊥ .

    1. Γ 0 ∪ { φ } ⊢ ⊥ hip.
    2. Γ 0 ⊢ φ → ⊥ Teorema Deduksi
    3. Γ 0 ⊢ ( φ → ⊥ ) → ¬ φ Ax0
    4. Γ 0 ⊢ ¬ φ MP 2, 3

  3. Andaikan Γ 0 ∪ { φ } ⊢ ⊥ dan Γ 1 ∪ { ¬ φ } ⊢ ⊥ .

    1. Γ 0 ∪ { φ } ⊢ ⊥ hip.
    2. Γ 0 ⊢ φ → ⊥ Teorema Deduksi
    3. Γ 1 ∪ { ¬ φ } ⊢ ⊥ hip.
    4. Γ 0 ⊢ ( φ → ⊥ ) → ¬ φ Ax0
    5. Γ 0 ⊢ ¬ φ MP 2, 4
    6. Γ 0 ∪ Γ 1 ⊢ ⊥ Cut 3, 5

    Karena Γ 0 ⊆ Γ dan Γ 1 ⊆ Γ , Γ 0 ∪ Γ 1 ⊆ Γ . Jadi, Γ ⊢ ⊥ .

  4. Latihan.

  5. Andaikan Γ 0 ⊢ φ .

    1. Γ 0 ⊢ φ hip.
    2. Γ 0 ⊢ φ → ( φ ∨ ψ ) Ax0
    3. Γ 0 ⊢ φ ∨ ψ MP 1, 2

    Jadi, Γ ⊢ φ ∨ ψ . Pembuktian untuk kasus ketika Γ ⊢ ψ serupa.

  6. Andaikan Γ 0 ⊢ φ ∧ ψ .

    1. Γ 0 ⊢ φ ∧ ψ hip.
    2. Γ 0 ⊢ ( φ ∧ ψ ) → φ Ax0
    3. Γ 0 ⊢ φ MP 1, 2

    Jadi, Γ ⊢ φ . derivasi yang serupa menunjukkan bahwa Γ ⊢ ψ .

  7. Latihan.

  8. Andaikan Γ 0 ⊢ φ dan Γ 1 ⊢ φ → ψ .

    1. Γ 0 ⊢ φ hip.
    2. Γ 1 ⊢ φ → ψ hip.
    3. Γ 0 ∪ Γ 1 ⊢ ψ MP 1, 2

    Karena Γ 0 ∪ Γ 1 ⊆ Γ , ini berarti bahwa Γ ⊢ ψ .

  9. Pertama-tama andaikan Γ ⊢ ¬ φ .

    1. Γ 0 ⊢ ¬ φ hip.
    2. Γ 0 ⊢ ¬ φ → ( φ → ψ ) Ax0
    3. Γ 0 ⊢ φ → ψ MP 1, 2

    Pembuktian untuk Γ ⊢ ψ serupa:

    1. Γ 0 ⊢ ψ hip.
    2. Γ 0 ⊢ ψ → ( φ → ψ ) Ax0
    3. Γ 0 ⊢ φ → ψ MP 1, 2

Teorema 8.4.

Generalisasi

Jika Γ ⊢ φ dan x tidak bebas dalam formula mana pun dalam Γ , maka Γ ⊢ ∀ x φ .

Bukti.

Dengan induksi pada 𝖳𝗁𝗆 Γ : jika φ merupakan aksioma, maka ∀ x φ juga merupakan aksioma. Jika φ ∈ Γ , maka x tidak bebas dalam φ , sehingga φ → ∀ x φ merupakan aksioma (Ax3), dan melalui MP kita memperoleh Γ ⊢ ∀ x φ . Sekarang andaikan φ diperoleh melalui MP karena Γ ⊢ ψ dan Γ ⊢ ψ → φ . Menurut hipotesis induksi, Γ ⊢ ∀ x ψ dan Γ ⊢ ∀ x ( ψ → φ ) . Namun, menurut Ax2 kita juga mempunyai Γ ⊢ ∀ x ( ψ → φ ) → ( ∀ x ψ → ∀ x φ ) , dan dua penerapan MP memberikan Γ ⊢ ∀ x φ , seperti yang diinginkan.

Teorema 8.5.

(Generalisasi Lemah atas Konstanta) Jika Γ ⊢ φ dan c merupakan simbol konstanta yang tidak muncul dalam Γ , maka terdapat variabel  x yang tidak muncul dalam φ sedemikian sehingga Γ ⊢ ∀ x φ [ x / c ] , dan pembuktiannya tidak melibatkan  c .

Bukti.

Misalkan φ 1 , … , φ n merupakan pembuktian φ dari Γ , sehingga φ = φ n . Pilih variabel  x yang tidak muncul dalam φ 1 , … , φ n , dan tinjau barisan baru φ 1 [ x / c ] , … , φ n [ x / c ] . Barisan semacam itu merupakan pembuktian φ [ x / c ] dari Γ . Bahkan, bagi setiap i = 1 , … , n :

  • jika φ i merupakan aksioma, maka φ i [ x / c ] juga merupakan aksioma;

  • jika φ i ∈ Γ , maka, karena c tidak muncul dalam Γ , kita mempunyai φ i [ x / c ] = φ i ∈ Γ ;

  • jika φ i diperoleh dari φ j dan φ j → φ i , maka φ i [ x / c ] diperoleh melalui MP dari φ j [ x / c ] dan ( φ j → φ i ) [ x / c ] = φ j [ x / c ] → φ i [ x / c ] .

Jelas bahwa simbol konstanta  c tidak lagi muncul dalam barisan baru tersebut. Sekarang misalkan Γ ′ terdiri atas formula dalam Γ yang muncul dalam derivasi atas φ [ x / c ] ; maka x tidak bebas dalam formula mana pun dalam Γ ′ dan Γ ′ ⊢ φ [ x / c ] . Menurut generalisasi (Teorema 8.4), Γ ′ ⊢ ∀ x φ [ x / c ] ; jadi, menurut monotonisitas, Γ ⊢ ∀ x φ [ x / c ] , seperti yang diinginkan.

Tujuan kita ialah mengganti syarat dalam Teorema 8.5 bahwa x sama sekali tidak muncul dalam φ dengan syarat yang lebih lemah bahwa x tidak bebas dalam φ dan bebas disubstitusikan bagi c dalam φ . Jelas bahwa hal ini dapat dicapai dengan mengganti variabel terikat—jadi, itulah yang mula-mula akan kita buktikan.

Lema 8.6.

Jika x bebas untuk c dalam φ dan y tidak bebas dalam φ , maka x bebas disubstitusikan bagi y dalam φ [ y / c ] .

Bukti.

Jika x tidak bebas disubstitusikan bagi y dalam φ [ y / c ] , maka suatu kemunculan bebas y dalam φ [ y / c ] berada dalam cakupan kuantor  ∀ x . Namun, menurut hipotesis, y tidak bebas dalam φ , sehingga semua kemunculan semacam itu berasal dari substitusi  [ y / c ] . Jadi, suatu kemunculan c berada dalam cakupan ∀ x , dan x tidak bebas disubstitusikan bagi c dalam φ .

Lema 8.7.

Penggantian Variabel Terikat

Jika x dan y tidak bebas dalam φ dan keduanya bebas disubstitusikan bagi c dalam φ , maka ⊢ ∀ x φ [ x / c ] ≡ ∀ y φ [ y / c ] (dan pembuktiannya tidak melibatkan c ).

Bukti.

Dari hipotesis, y bebas disubstitusikan bagi c dalam φ dan x tidak bebas dalam φ ; jadi, menurut Lema 8.6 sebelumnya, y bebas disubstitusikan bagi x dalam φ [ x / c ] . Akibatnya, ∀ x φ [ x / c ] → φ [ x / c ] [ y / x ] merupakan aksioma (Ax1). Karena x tidak bebas dalam φ , kita mempunyai φ [ x / c ] [ y / x ] = φ [ y / c ] , sehingga ⊢ ∀ x φ [ x / c ] → φ [ y / c ] , dan menurut Teorema Deduksi, ∀ x φ [ x / c ] ⊢ φ [ y / c ] . Karena y tidak bebas dalam φ , variabel tersebut juga tidak bebas dalam ∀ x φ [ x / c ] ; jadi, menurut Generalisasi, ∀ x φ [ x / c ] ⊢ ∀ y φ [ y / c ] , dan Teorema Deduksi kembali memberikan ⊢ ∀ x φ [ x / c ] → ∀ y φ [ y / c ] . Pembuktian ⊢ ∀ y φ [ y / c ] → ∀ x φ [ x / c ] sepenuhnya simetris, sehingga kesimpulan mengikuti menurut Taut.

Teorema 8.8.

Generalisasi Kuat atas Konstanta

Jika Γ ⊢ φ , simbol konstanta  c tidak muncul dalam Γ , dan x tidak bebas dalam φ tetapi bebas disubstitusikan bagi c dalam φ , maka Γ ⊢ ∀ x φ [ x / c ] .

Bukti.

Karena Γ ⊢ φ dan c tidak muncul dalam Γ , menurut Generalisasi Lemah terdapat variabel  y yang tidak muncul dalam φ sedemikian sehingga Γ ⊢ ∀ y φ [ y / c ] . Karena y sama sekali tidak muncul dalam φ , variabel tersebut tidak bebas dalam φ dan juga bebas disubstitusikan bagi c dalam φ . Jika, selain itu (menurut hipotesis), x tidak bebas dalam φ dan bebas disubstitusikan bagi c dalam φ , maka syarat untuk penggantian variabel terikat terpenuhi, sehingga ⊢ ∀ x φ [ x / c ] ≡ ∀ y φ [ y / c ] ; akibatnya, Γ ⊢ ∀ x φ [ x / c ] .

Teorema 8.9.

  1. Jika Γ ⊢ φ ( t ) , maka Γ ⊢ ∃ x φ ( x ) .

  2. Jika Γ ⊢ ∀ x φ ( x ) , maka Γ ⊢ φ ( t ) .

Bukti.

  1. Latihan.

  2. Andaikan Γ 0 ⊢ ∀ x φ ( x ) .

    1. Γ 0 ⊢ ∀ x φ ( x ) hip.
    2. Γ 0 ⊢ ∀ x φ ( x ) → φ [ t / x ] Ax1
    3. Γ 0 ⊢ φ [ t / x ] MP 1, 2

8.3 Himpunan Kalimat yang Konsisten Maksimal

Definisi 8.10.

Himpunan konsisten maksimal

Suatu himpunan  Γ dari kalimat bersifat konsisten maksimal jika dan hanya jika

  1. Γ konsisten, dan

  2. jika Γ ⊊ Γ ′ , maka Γ ′ tak konsisten.

Definisi lain yang ekuivalen dengan definisi di atas ialah: suatu himpunan kalimat  Γ bersifat konsisten maksimal jika dan hanya jika

  1. Γ konsisten, dan

  2. jika Γ ∪ { φ } konsisten, maka φ ∈ Γ .

Dengan kata lain, kalimat yang belum berada dalam  Γ tidak dapat ditambahkan kepada himpunan konsisten maksimal  Γ tanpa membuat himpunan lebih besar yang dihasilkan menjadi tak konsisten.

Himpunan konsisten maksimal penting dalam pembuktian kelengkapan karena kita dapat menjamin bahwa setiap himpunan konsisten dari kalimat  Γ termuat dalam suatu himpunan konsisten maksimal  Γ ∗ , dan suatu himpunan konsisten maksimal memuat, untuk setiap kalimat  φ , φ atau negasinya  ¬ φ . Hal ini berlaku khususnya bagi kalimat atomik; karena itu, dari suatu himpunan konsisten maksimal dalam bahasa yang diperluas secara tepat dengan simbol konstanta, kita dapat membangun struktur dengan interpretasi simbol predikat didefinisikan menurut kalimat atomik mana yang berada dalam  Γ ∗ . Selanjutnya dapat ditunjukkan bahwa struktur ini membuat semua kalimat dalam  Γ ∗ (dan karena itu juga semua kalimat dalam  Γ ) benar. Pembuktian fakta terakhir ini mensyaratkan bahwa ¬ φ ∈ Γ ∗ jika dan hanya jika φ ∉ Γ ∗ , bahwa ( φ ∨ ψ ) ∈ Γ ∗ jika dan hanya jika φ ∈ Γ ∗ atau ψ ∈ Γ ∗ , dan seterusnya.

Proposisi 8.11.

Andaikan Γ konsisten maksimal. Maka:

  1. Jika Γ ⊢ φ , maka φ ∈ Γ .

  2. Untuk setiap φ , berlaku φ ∈ Γ atau ¬ φ ∈ Γ .

  3. ( φ ∧ ψ ) ∈ Γ jika dan hanya jika φ ∈ Γ dan ψ ∈ Γ .

  4. ( φ ∨ ψ ) ∈ Γ jika dan hanya jika φ ∈ Γ atau ψ ∈ Γ .

  5. ( φ → ψ ) ∈ Γ jika dan hanya jika φ ∉ Γ atau ψ ∈ Γ .

Bukti.

Untuk seluruh pembahasan berikut, andaikan bahwa Γ konsisten maksimal.

  1. Jika Γ ⊢ φ , maka φ ∈ Γ .

    Andaikan Γ ⊢ φ . Demi memperoleh kontradiksi, andaikan bahwa φ ∉ Γ . Karena Γ konsisten maksimal, Γ ∪ { φ } tak konsisten, sehingga Γ ∪ { φ } ⊢ ⊥ . Menurut Proposisi 19.18 dan Proposisi 20.18, Γ tak konsisten. Hal ini bertentangan dengan asumsi bahwa Γ konsisten. Jadi, tidak mungkin φ ∉ Γ , sehingga φ ∈ Γ .

  2. Untuk setiap φ , berlaku φ ∈ Γ atau ¬ φ ∈ Γ .

    Demi memperoleh kontradiksi, andaikan bahwa untuk suatu  φ berlaku φ ∉ Γ dan ¬ φ ∉ Γ . Karena Γ konsisten maksimal, Γ ∪ { φ } dan Γ ∪ { ¬ φ } keduanya tak konsisten, sehingga Γ ∪ { φ } ⊢ ⊥ dan Γ ∪ { ¬ φ } ⊢ ⊥ . Menurut Proposisi 19.21 dan Proposisi 20.21, Γ tak konsisten, suatu kontradiksi. Jadi, kalimat  φ semacam itu tidak mungkin ada dan, untuk setiap φ , berlaku φ ∈ Γ atau ¬ φ ∈ Γ .

  3. ( φ ∧ ψ ) ∈ Γ jika dan hanya jika φ ∈ Γ dan ψ ∈ Γ :

    Untuk arah maju, andaikan ( φ ∧ ψ ) ∈ Γ . Maka Γ ⊢ φ ∧ ψ . Menurut Proposisi 19.22 dan Proposisi 20.22, Γ ⊢ φ dan Γ ⊢ ψ . Menurut enumi 1, φ ∈ Γ dan ψ ∈ Γ , seperti yang diperlukan.

    Untuk arah sebaliknya, misalkan φ ∈ Γ dan ψ ∈ Γ . Maka Γ ⊢ φ dan Γ ⊢ ψ . Menurut Proposisi 19.22 dan Proposisi 20.22, Γ ⊢ φ ∧ ψ . Menurut enumi 1, ( φ ∧ ψ ) ∈ Γ .

  4. ( φ ∨ ψ ) ∈ Γ jika dan hanya jika φ ∈ Γ atau ψ ∈ Γ .

    Untuk kontrapositif arah maju, andaikan bahwa φ ∉ Γ dan ψ ∉ Γ . Kita hendak menunjukkan bahwa ( φ ∨ ψ ) ∉ Γ . Karena Γ konsisten maksimal, Γ ∪ { φ } ⊢ ⊥ dan Γ ∪ { ψ } ⊢ ⊥ . Menurut Proposisi 19.23 dan Proposisi 20.23, Γ ∪ { ( φ ∨ ψ ) } tak konsisten. Jadi, ( φ ∨ ψ ) ∉ Γ , seperti yang diperlukan.

    Untuk arah sebaliknya, andaikan bahwa φ ∈ Γ atau ψ ∈ Γ . Maka Γ ⊢ φ atau Γ ⊢ ψ . Menurut Proposisi 19.23 dan Proposisi 20.23, Γ ⊢ φ ∨ ψ . Menurut enumi 1, ( φ ∨ ψ ) ∈ Γ , seperti yang diperlukan.

  5. ( φ → ψ ) ∈ Γ jika dan hanya jika φ ∉ Γ atau ψ ∈ Γ :

    Untuk arah maju, misalkan ( φ → ψ ) ∈ Γ , lalu, demi memperoleh kontradiksi, andaikan bahwa φ ∈ Γ dan ψ ∉ Γ . Berdasarkan asumsi-asumsi ini, Γ ⊢ φ → ψ dan Γ ⊢ φ . Menurut Proposisi 19.24 dan Proposisi 20.24, Γ ⊢ ψ . Namun, menurut enumi 1, hal ini berarti ψ ∈ Γ , bertentangan dengan asumsi bahwa ψ ∉ Γ .

    Untuk arah sebaliknya, pertama-tama tinjau kasus ketika φ ∉ Γ . Menurut enumi 2, ¬ φ ∈ Γ , sehingga Γ ⊢ ¬ φ . Menurut Proposisi 19.24 dan Proposisi 20.24, Γ ⊢ φ → ψ . Sekali lagi, menurut enumi 1, kita memperoleh ( φ → ψ ) ∈ Γ , seperti yang diperlukan.

    Sekarang tinjau kasus ketika ψ ∈ Γ . Maka Γ ⊢ ψ , dan menurut Proposisi 19.24 dan Proposisi 20.24, Γ ⊢ φ → ψ . Menurut enumi 1, ( φ → ψ ) ∈ Γ .
