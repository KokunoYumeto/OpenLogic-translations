9.1 Fungsi-Fungsi dalam C

Misalkan C merupakan himpunan fungsi terkecil yang memuat

  1. 0 ,

  2. penerus,

  3. penjumlahan,

  4. perkalian,

  5. proyeksi, dan

  6. fungsi karakteristik kesamaan, χ = ;

serta tertutup terhadap

  1. komposisi, dan

  2. pencarian tak berbatas yang diterapkan pada fungsi reguler.

Ingat bahwa pembatasan terakhir ini hanya berarti bahwa operasi  μ dapat digunakan hanya ketika hasilnya total. Bandingkan hal ini dengan definisi fungsi rekursif umum: di sini kita telah menambahkan penjumlahan, perkalian, dan χ = , tetapi menghilangkan rekursi primitif.

Jelas bahwa segala sesuatu dalam C bersifat rekursif, karena penjumlahan, perkalian, dan χ = juga demikian. Kita akan menunjukkan bahwa kebalikannya juga benar; ini sama dengan mengatakan bahwa, dengan unsur-unsur lain dalam C , kita dapat menjalankan rekursi primitif.

9.2 Fungsi-Fungsi dalam C Dapat Direpresentasikan dalam 𝐐

Kita harus menunjukkan bahwa setiap fungsi dalam C dapat direpresentasikan dalam 𝐐 . Pada akhirnya, kita perlu menunjukkan cara menetapkan kepada setiap fungsi berargumen k , f ( x 0 , … , x k − 1 ) , dalam  C suatu formula φ f ( x 0 , … , x k − 1 , y ) yang merepresentasikannya.

Lema 9.1.

Diberikan bilangan asli n dan m , jika n ≠ m , maka Q ⊢ n ― ≠ m ― .

Bukti.

Gunakan induksi pada n untuk menunjukkan bahwa, bagi setiap m , jika n ≠ m , maka Q ⊢ n ― ≠ m ― .

Dalam kasus dasar, n = 0 . Jika m tidak sama dengan 0 , maka m = k + 1 untuk suatu bilangan asli  k . Kita mempunyai aksioma yang menyatakan ∀ x 0 ≠ x ′ . Menurut suatu aksioma kuantor, dengan mengganti x dengan k ― , kita dapat menyimpulkan 0 ≠ k ― ′ . Namun, k ― ′ tidak lain ialah m ― .

Dalam langkah induksi, kita dapat mengasumsikan bahwa klaim tersebut benar untuk n , lalu mempertimbangkan n + 1 . Misalkan m sebarang bilangan asli. Ada dua kemungkinan: m = 0 , atau terdapat suatu k sedemikian sehingga m = k + 1 . Kasus pertama ditangani seperti di atas. Dalam kasus kedua, andaikan n + 1 ≠ k + 1 . Maka n ≠ k . Menurut hipotesis induksi untuk n , kita mempunyai 𝐐 ⊢ n ― ≠ k ― . Kita mempunyai aksioma yang menyatakan ∀ x ∀ y x ′ = y ′ → x = y . Dengan menggunakan aksioma kuantor, kita mempunyai n ― ′ = k ― ′ → n ― = k ― . Dengan menggunakan logika proposisional, dalam 𝐐 kita dapat menyimpulkan n ― ≠ k ― → n ― ′ ≠ k ― ′ . Dengan modus ponens, kita dapat menyimpulkan n ― ′ ≠ k ― ′ , sebagaimana diinginkan, karena k ― ′ ialah m ― .

Perhatikan bahwa lema tersebut tidak mengatakan banyak hal: pada intinya, lema itu mengatakan bahwa 𝐐 dapat membuktikan bahwa numeral-numeral yang berbeda menunjuk objek yang berbeda. Misalnya, 𝐐 membuktikan 0 ″ ≠ 0 ‴ . Namun, menunjukkan bahwa hal ini berlaku secara umum memerlukan kehati-hatian. Perhatikan pula bahwa meskipun kita menggunakan induksi, induksi itu dilakukan di luar 𝐐 .

Kita akan dapat merepresentasikan nol, penerus, tambah, kali, fungsi karakteristik kesamaan, dan proyeksi. Dalam setiap kasus, formula yang sesuai untuk merepresentasikan fungsi tersebut sepenuhnya langsung; misalnya, nol direpresentasikan oleh formula y = 0 , penerus direpresentasikan oleh formula x 0 ′ = y , dan penjumlahan direpresentasikan oleh formula x 0 + x 1 = y . Pekerjaannya terletak pada menunjukkan bahwa 𝐐 dapat membuktikan pernyataan-pernyataan yang relevan; misalnya, mengatakan bahwa penjumlahan direpresentasikan oleh formula di atas berarti menunjukkan bahwa untuk setiap pasangan bilangan asli m dan n , 𝐐 membuktikan n ― + m ― = n + m ― dan ∀ y ( ( n ― + m ― ) = y → y = n + m ― ) .

Bagaimana dengan komposisi? Andaikan h didefinisikan oleh h ( x 0 , … , x l − 1 ) = f ( g 0 ( x 0 , … , x l − 1 ) , … , g k − 1 ( x 0 , … , x l − 1 ) ) . dengan kita telah menemukan formula φ f , φ g 0 , … , φ g k − 1 yang masing-masing merepresentasikan fungsi f , g 0 , … , g k − 1 . Maka kita dapat mendefinisikan formula  φ h yang merepresentasikan  h dengan mendefinisikan φ h ( x 0 , … , x l − 1 , y ) sebagai ∃ z 0 … ∃ z k − 1 ( φ g 0 ( x 0 , … , x l − 1 , z 0 ) ∧ ⋯ ∧ φ g k − 1 ( x 0 , … , x l − 1 , z k − 1 ) ∧ φ f ( z 0 , … , z k − 1 , y ) ) .

Terakhir, mari kita perhatikan pencarian tak berbatas. Andaikan g ( x , z → ) bersifat reguler dan direpresentasikan dalam 𝐐 , misalnya oleh formula φ g ( x , z → , y ) . Misalkan f didefinisikan oleh f ( z → ) = μ x g ( x , z → ) . Kita ingin menemukan formula φ f ( z → , y ) yang merepresentasikan  f . Berikut merupakan pilihan yang alami: φ f ( z → , y ) ≡ φ g ( y , z → , 0 ) ∧ ∀ w ( w < y → ¬ φ g ( w , z → , 0 ) ) .

Hal ini dapat ditunjukkan berhasil dengan menggunakan beberapa lema tambahan, misalnya:

Lema 9.2.

Bagi setiap variabel  x dan setiap bilangan asli  n , 𝐐 membuktikan ( x ′ + n ― ) = ( x + n ― ) ′ .

Perlu kembali disebutkan bahwa hal ini lebih lemah daripada mengatakan bahwa 𝐐 membuktikan ∀ x ∀ y ( x ′ + y ) = ( x + y ) ′ (yang salah).

Bukti.

Seperti biasa, pembuktian dilakukan dengan induksi pada n . Dalam kasus dasar, n = 0 , kita perlu menunjukkan bahwa 𝐐 membuktikan ( x ′ + 0 ) = ( x + 0 ) ′ . Namun, kita mempunyai: ( x ′ + 0 ) = x ′ menurut aksioma 4 ( x + 0 ) = x menurut aksioma 4 ( x + 0 ) ′ = x ′ menurut baris 2 ( x ′ + 0 ) = ( x + 0 ) ′ menurut baris 1 dan 3 Dalam langkah induksi, kita dapat mengasumsikan bahwa kita telah menurunkan ( x ′ + n ― ) = ( x + n ― ) ′ dalam 𝐐 . Karena n + 1 ― ialah n ― ′ , kita perlu menunjukkan bahwa 𝐐 membuktikan ( x ′ + n ― ′ ) = ( x + n ― ′ ) ′ . Rantai kesamaan berikut dapat diturunkan dalam 𝐐 : ( x ′ + n ― ′ ) = ( x ′ + n ― ) ′ aksioma 5 = ( x + n ― ′ ) ′ menurut hipotesis induksi

Lema 9.3.

  1. 𝐐 membuktikan ¬ ( x < 0 ― ) .

  2. Bagi setiap bilangan asli  n , 𝐐 membuktikan x < n + 1 ― → ( x = 0 ― ∨ ⋯ ∨ x = n ― ) .

Bukti.

Mari kita kerjakan butir 1 dan sebagian butir 2 secara informal (yakni hanya memberi petunjuk tentang cara menyusun derivasi formalnya).

Untuk butir 1, menurut definisi < , kita perlu membuktikan ¬ ∃ y ( y ′ + x ) = 0 dalam 𝐐 , yang ekuivalen (dengan menggunakan aksioma dan kaidah logika orde pertama) dengan ∀ y ( y ′ + x ) ≠ 0 . Berikut gagasannya: andaikan ( y ′ + x ) = 0 . Jika x ialah 0, kita mempunyai ( y ′ + 0 ) = 0 . Namun, menurut aksioma 4 dari 𝐐 , kita mempunyai ( y ′ + 0 ) = y ′ , dan menurut aksioma 2 kita mempunyai y ′ ≠ 0 , suatu kontradiksi. Jadi, ∀ y ( y ′ + x ) ≠ 0 . Jika x bukan 0 , menurut aksioma 3 terdapat suatu  z sedemikian sehingga x = z ′ . Namun, kemudian kita mempunyai ( y ′ + z ′ ) = 0 . Menurut aksioma 5, kita mempunyai ( y ′ + z ) ′ = 0 , yang kembali bertentangan dengan aksioma 2.

Untuk butir 2, gunakan induksi pada n . Mari kita perhatikan kasus dasar ketika n = 0 . Dalam kasus itu, kita perlu menunjukkan x < 1 ― → x = 0 ― . Andaikan x < 1 ― . Maka, menurut aksioma yang mendefinisikan < , kita mempunyai ∃ y ( y ′ + x ) = 0 ′ . Andaikan y mempunyai sifat tersebut; jadi, kita mempunyai y ′ + x = 0 ′ .

Kita perlu menunjukkan x = 0 . Menurut aksioma 3, jika x bukan 0, variabel itu sama dengan z ′ untuk suatu  z . Maka kita mempunyai ( y ′ + z ′ ) = 0 ′ . Menurut aksioma 5 dari 𝐐 , kita mempunyai ( y ′ + z ) ′ = 0 ′ . Menurut aksioma 1, kita mempunyai ( y ′ + z ) = 0 . Namun, menurut definisi, ini berarti z < 0 , bertentangan dengan butir 1.

Kita telah menunjukkan bahwa himpunan fungsi yang dapat dihitung dapat dikarakterisasi sebagai himpunan fungsi yang dapat direpresentasikan dalam 𝐐 . Bahkan, pembuktian tersebut lebih umum. Dari definisi kerepresentasian, tidak sulit melihat bahwa setiap teori yang memperluas 𝐐 (atau yang memungkinkan 𝐐 ditafsirkan di dalamnya) dapat merepresentasikan fungsi-fungsi yang dapat dihitung; sebaliknya, dalam setiap sistem derivasi yang pengertian buktinya dapat dihitung, setiap fungsi yang dapat direpresentasikan juga dapat dihitung. Jadi, sebagai contoh, himpunan fungsi yang dapat dihitung dapat dicirikan sebagai himpunan fungsi yang direpresentasikan dalam aritmetika Peano, atau bahkan teori himpunan Zermelo–Fraenkel. Seperti dicatat Gödel, hal ini agak mengejutkan. Kita akan melihat bahwa, dalam hal keterbuktian, pertanyaan-pertanyaan sangat peka terhadap teori mana yang dipertimbangkan; secara kasar, semakin kuat aksiomanya, semakin banyak yang dapat dibuktikan. Namun, pada cakupan luas teori-teori aksiomatik, fungsi yang dapat direpresentasikan tepat merupakan fungsi yang dapat dihitung.
